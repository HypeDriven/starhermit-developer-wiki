StarHermit বিকাশকারী সরঞ্জাম

প্রকাশযোগ্য স্ক্রিপ্ট-গেম প্যাকেজ তৈরি করুন, সেগুলি StarHermit-এ আপলোড করুন এবং আপনার কোডিং সহকারীকে একটি স্থানীয় MCP সংযোগ দিন। এই সরঞ্জাম প্রয়োজন নেই মরিচা ইনস্টলেশন বা ইঞ্জিন উত্স চেকআউট. খেলার নিজস্ব থাকতে পারে নির্ভরতা তৈরি করুন, যেমন Node.js।

নীচের টেবিল থেকে, বা থেকে আপনার কম্পিউটারের জন্য সংরক্ষণাগার ডাউনলোড করুন https://engine.starhermit.com/engine/tools/latest.json (এটি প্রতিটি তালিকা করে সংরক্ষণাগারের ঠিকানা, আকার এবং SHA-256), এবং এর সাথে এর SHA-256 তুলনা করুন এর পাশে চেকসাম (<archive>.sha256) এটিকে আনপ্যাক করুন এবং এর ডিরেক্টরিটি PATH-এ রাখুন, বা৷ নীচের কমান্ডগুলিতে এক্সিকিউটেবলের সম্পূর্ণ পথটি ব্যবহার করুন। macOS ডাউনলোড হয় অ্যাপল সিলিকনের জন্য আলাদাভাবে সরবরাহ করা হয়েছে (macos-aarch64) এবং ইন্টেল (macos-x86_64) এগুলি অ্যাপল-নোটারাইজড নয় এবং কোনও ডাউনলোডও নেই৷ প্রামাণিক কোড বা বিকাশকারী আইডি স্বাক্ষরিত। অ্যাপল সিলিকন বিল্ড ক্রস-সংকলিত; সমস্যা রিপোর্ট করুন।

একটি খেলা চেক এবং প্যাকেজ

starhermit-tools --version
starhermit-tools check my-game
starhermit-tools package --web my-game --out upload --remote-out remote-objects

গেম ডিরেক্টরি রয়েছে starhermit.txt এবং গেমের প্রয়োজনীয় ফাইলগুলি। engine.version একটি প্রকাশিত ইঞ্জিন রিলিজ পিন; টুল তার পড়া engine.starhermit.com থেকে ম্যানিফেস্ট করে এবং একটি হ্যাশ-পিনযুক্ত লোডার এবং ফাইল লিখে সূচক --engine-version X.Y.Z সুস্পষ্টভাবে একটি সামঞ্জস্যপূর্ণ রিলিজ নির্বাচন করে। দ্বারা ঘোষিত ফাইল engine.remote.files লেখা হয় remote-objects; যখন engine.remote.urls=platform, প্রকাশনা প্রথমে তাদের আপলোড করে।

check ম্যানিফেস্ট, প্যাকেজ পাথ এবং ফাইল গঠন যাচাই করে। এটা করে স্ক্রিপ্ট চালান না। আগে একটি ব্রাউজারে প্যাকেজ করা ওয়েব গেম পরীক্ষা করুন প্রকাশনা ডেভেলপাররা অতিরিক্তভাবে ম্যাচিং নেটিভ ডাউনলোড করতে পারেন একটি ইঞ্জিন রিলিজ থেকে রানটাইম (উইন্ডোজ, লিনাক্স, এবং ইঞ্জিন 1.26.2 থেকে macOS 11 বা তার পরের Intel এবং Apple Silicon) এবং ব্যবহার করুন starhermit check my-game একটি মাথাবিহীন মৃত্যুদন্ড চেক জন্য. ম্যাকোস রানটাইমগুলি অ্যাড-হক স্বাক্ষরিত এবং নোটারাইজড নয় এবং সেগুলি এখনও হয়নি৷ আসল অ্যাপল হার্ডওয়্যারে পরীক্ষা করা হয়েছে। একটি টারবল একটি ব্রাউজারে ডাউনলোড করা হয় quarantined: চালান xattr -d com.apple.quarantine starhermit বা অনুমতি দিন সিস্টেম সেটিংসে।

প্রকাশ করুন

পাবলিক-কি অনবোর্ডিং অনুসরণ করে আপনার নিজস্ব নিবন্ধিত স্থাপনার কী ব্যবহার করুন এবং বিকাশকারী উইকিতে CI/CD নির্দেশিকা। সেট STARHERMIT_PUBLIC_KEY এবং STARHERMIT_PRIVATE_KEY আপনার শেল বা আপনার সিআই গোপন দোকানে। বিকল্পভাবে, সেট STARHERMIT_ACCESS_TOKEN একটি অ্যাকাউন্ট অ্যাক্সেস টোকেনে। এগুলো লাগাবেন না গেমের মান, সেগুলি কমিট করুন বা এমসিপি কনফিগারেশনে যোগ করুন।

starhermit-tools publish --game-id YOUR-GAME-ID --upload upload --remote-out remote-objects

এটি গেমের স্থাপন করা ফাইলগুলিকে প্রতিস্থাপন করে। --mode merge একটি বিদ্যমান প্যাচ পরিবর্তে আপলোড করুন। একটি নতুন গেম তৈরি করতে, প্রতিস্থাপন করুন --game-id YOUR-GAME-ID সঙ্গে --new. --socket আপলোড WebSocket নির্বাচন করে; বড় আপলোড এটি নির্বাচন করুন স্বয়ংক্রিয়ভাবে --display-name এবং --description আপলোড করা ওভাররাইড করুন ম্যানিফেস্টের নাম এবং বিবরণ। প্রকাশক হোস্ট করা URL রিপোর্ট করে এবং আপলোডের পাশে একটি প্রকাশ প্রতিবেদন লেখে।

অ্যাকাউন্টটি অবশ্যই গেমের মালিক হবে। একটি শংসাপত্র ত্রুটি বা অস্বীকার সীমা একটি ত্রুটি অন্য কারো শংসাপত্রের সাথে এটিকে ঘিরে কাজ করবেন না। দূরবর্তী গেম দ্বারা ইতিমধ্যে ধারণ করা বস্তু পুনরায় ব্যবহার করা হয়; বিঘ্নিত বস্তু আপলোড পুনরায় শুরু পরবর্তী অবজেক্ট আপলোড ব্যর্থ হওয়ার আগে একটি নতুন গেম তৈরি করা হতে পারে; আরেকটি তৈরি করার পরিবর্তে পুনরায় চেষ্টা করার জন্য এটির রিপোর্ট করা গেম আইডি ব্যবহার করুন।

STARHERMIT_API_BASE অন্য HTTPS স্থাপনা নির্বাচন করে। STARHERMIT_CA_FILE একটি PEM বিশ্বাস বান্ডিল নির্বাচন করে, উদাহরণস্বরূপ একটি বিকাশ CA; TLS যাচাইকরণ সর্বদা সক্রিয় থাকে। সাধারণ ব্যবহারের জন্য কোন পরিবর্তনশীল প্রয়োজন নেই।

MCP এর সাথে একটি কোডিং সহকারীকে সংযুক্ত করুন

পরম ব্যবহার করে আপনার সহকারীর কনফিগারেশনে একটি stdio MCP সার্ভার যোগ করুন আপনার কম্পিউটারের জন্য উপযুক্ত পাথ:

{
  "mcpServers": {
    "starhermit": {
      "command": "/absolute/path/to/starhermit-tools",
      "args": ["mcp", "--package", "/absolute/path/to/my-game"]
    }
  }
}

সার্ভার অফার করে check_package, package_web, এবং package_native. গেমটিতে যদি Node.js বিল্ড স্ক্রিপ্ট থাকে, তাহলে যুক্ত করুন --build-script এবং তার এমসিপি আর্গুমেন্টের পরম পথ একটি প্রকাশ করার জন্য build টুল এই রান যে কনফিগার করা স্ক্রিপ্ট; এটি MCP থেকে নির্বিচারে আদেশ গ্রহণ করে না। package_web ঐচ্ছিক লাগে outDir, remoteOut, এবং engineVersion; আপেক্ষিক আউটপুট পাথ গেম ডিরেক্টরির সাথে আপেক্ষিক। ডিফল্টরূপে এটি লেখে starhermit-build/upload এবং starhermit-build/remote পাশে গেম ডিরেক্টরি। package_native এর জন্য গেমের নেটিভ ফাইল সূচক লেখে একটি সমর্থিত StarHermit ক্লায়েন্ট দ্বারা ইনস্টলেশন, যা ইঞ্জিন ইনস্টল করে প্লেয়ারের প্ল্যাটফর্মের জন্য রানটাইম (macOS অন্তর্ভুক্ত, ইঞ্জিন 1.26.2 থেকে)। কোন টুল কিছুই প্রকাশ করে না।

একটি নেটিভ রানটাইম ইনস্টল সহ, যুক্ত করুন --runtime এবং তার MCP আর্গুমেন্ট সক্রিয় করার জন্য পরম এক্সিকিউটেবল পাথ run_checks. সেই টুলটি কনফিগার করা রানটাইমে গেমের কোড এক্সিকিউট করে। প্রকাশনা শুধুমাত্র একটি স্পষ্ট CLI কমান্ড হিসাবে উপলব্ধ এবং এটি কখনই একটি MCP টুল নয়।
