একটি ইন্টিগ্রেশন চয়ন করুন

আপনার গেমটি কোথায় চলে এবং কে গেমপ্লে যাচাই করে তা দিয়ে শুরু করুন। একটি হোস্ট করা ব্রাউজার গেমের প্রয়োজন নেই সাইন-ইন, ক্লাউড সেভ, সেটিংস, কন্ট্রোল বা রিয়েলটাইম রুম ব্যবহার করতে সার্ভার ব্যাকএন্ড।

ইন্টিগ্রেশন গেমপ্লে কর্তৃপক্ষ মাল্টিপ্লেয়ার অগ্রগতি স্কোর এবং অর্জন
শুধুমাত্র ব্রাউজার, স্বতন্ত্র একক প্লেয়ার প্লেয়ারের ব্রাউজার কোনোটিই নয় প্রস্তাবিত স্বাক্ষরবিহীন মোডে মেমরিতে রাখুন কোন প্ল্যাটফর্ম লিখছে না
অ্যাকাউন্ট প্লে সহ হোস্ট করা ব্রাউজার গেম প্লেয়ারের ব্রাউজার ঐচ্ছিক হোস্ট-রুটেড রুম সাইন ইন করা খেলোয়াড়দের জন্য ক্লাউড সংরক্ষণ করে গেমের মালিকানাধীন বোর্ড এবং কৃতিত্বগুলি লিখতে একটি স্ক্রিপ্ট বা ধারক যোগ করুন
হোস্ট-রুটেড রিয়েলটাইম রুম হোস্ট প্লেয়ার এর ক্লায়েন্ট লবি, আমন্ত্রণ, যোগদানের কোড, দ্রুত যোগদান; বাইনারি ইনপুট এবং স্ন্যাপশট ক্লায়েন্ট ক্লাউড সংরক্ষণ করে, অথবা একটি ঐচ্ছিক আবদ্ধ সার্ভার সেশন একটি আবদ্ধ ব্যাকএন্ড লিখতে পারে; এটা কি পুরস্কার দেয় তা স্বাধীনভাবে যাচাই করতে হবে
প্রামাণিক স্ক্রিপ্ট আপনার খেলার স্ক্রিপ্ট সেশন ম্যাচমেকিং, বন্ধুদের আমন্ত্রণ, অনুশীলন, বা রুম-বাউন্ড ম্যাচ সেশন এবং প্রতি খেলোয়াড়ের অবস্থা আপনার স্ক্রিপ্ট দ্বারা রক্ষণাবেক্ষণ করা হয় সার্ভার ইলো, স্কোর এবং কৃতিত্ব লেখে
প্রামাণিক ধারক আপনার গেম সার্ভার একই সেশন API; রিয়েলটাইম রুম বড় গ্রিড সমর্থন করে সম্পূর্ণ স্ন্যাপশট এবং প্রতি খেলোয়াড়ের অবস্থা সার্ভার ইলো, স্কোর এবং কৃতিত্ব লেখে
ক্যাটালগ শিরোনাম, যেমন একটি নেটিভ এক্সিকিউটেবল আপনার নির্বাচিত ক্লায়েন্ট/সার্ভার আর্কিটেকচার অ্যাকাউন্ট বা লঞ্চ টোকেন সহ একই API ব্যবহার করুন ক্লাউড-সেভ স্লট অ্যাকাউন্ট ক্লায়েন্ট দ্বারা নির্বাচিত ক্যাটালগ বোর্ড এবং কৃতিত্বের আলাদা প্রকাশক এবং ক্লায়েন্ট-দাবি API আছে

তিনটি সাধারণ শুরুর পয়েন্ট

একটি একক-প্লেয়ার ব্রাউজার গেম: অনুসরণ ব্রাউজার কুইকস্টার্ট. অফার StarHermit দিয়ে সাইন ইন করুন অ্যাকাউন্টের অগ্রগতির জন্য এবং একক প্লেয়ার খেলুন (প্রগতি হয় না সংরক্ষিত) তাৎক্ষণিক খেলার জন্য। ব্যাকএন্ড ছাড়াই শুরু করুন; আপনার যখন বৈধ প্রতিযোগিতামূলক প্রয়োজন তখন একটি যোগ করুন ফলাফল সেটিংস এবং ক্লাউড সংরক্ষণের প্রয়োজন নেই a server= লাইন

বন্ধুদের সাথে নৈমিত্তিক মাল্টিপ্লেয়ার: ব্যবহার রিয়েলটাইম রুম. হোস্ট রান সিমুলেশন, গেস্ট ইনপুট পাঠায় এবং হোস্ট স্ন্যাপশট সম্প্রচার করে। আপনার গেম এআই এবং হোস্ট প্রয়োগ করে মাইগ্রেশন প্ল্যাটফর্মটি আসন, পরিচয় এবং রাউটিং প্রদান করে। হোস্টে বিশ্বাস এই মডেলের অংশ।

র‌্যাঙ্কড বা ক্রমাগত মাল্টিপ্লেয়ার: ব্যবহার একটি স্ক্রিপ্ট বা একটি ধারক, আপনার যদি একটি লবি প্রয়োজন হয় তাহলে রুম সহ। আগে গেমপ্লে যাচাই করুন কিছু পুরস্কার স্ক্রিপ্ট সমর্থিত সিলিং এর মধ্যে একটি টিক রেট অনুরোধ করে (ডিফল্টরূপে 30 Hz); পাত্রে তাদের নিজস্ব সিমুলেশন লুপ চালায়। ধারক সরাসরি ম্যাচমেকিং বর্তমানে একটি অন্তর্নিহিত আছে 1v1 সারি, কিন্তু একটি রুম একটি N-প্লেয়ার কন্টেইনার সেশন তৈরি করতে পারে।

হোস্টিং এবং প্রকাশনা

আপনার বিল্ড মাধ্যমে প্রকাশ করুন পরবর্তী পড়ুন
বিতরণযোগ্য ফোল্ডার ফোল্ডার আপলোড; পরবর্তী রিলিজ বান্ডিল আপলোড ব্যবহার করে উদ্ভাসিত, আপলোড API
পাবলিক GitHub সংগ্রহস্থল সংগ্রহস্থল নিবন্ধন করুন, মালিকানা প্রমাণ করুন, একটি নির্বাচিত সংস্করণ স্থাপন করুন গিটহাব গেমস
ধারক ইমেজ একটি গেম নিবন্ধন/আপলোড করুন, তারপর একটি পিন করা রেজিস্ট্রি চিত্র বা পুশ ঘোষণা করুন server/image.tar কন্টেইনার প্রোটোকল, CI আপলোড করে
বাহ্যিক/নেটিভ গেম ক্লায়েন্ট সরাসরি পাবলিক API কল করুন; প্লেয়ার শংসাপত্র ব্যবহার করুন সর্বজনীন-কী অনবোর্ডিং, ঐক্য SDK
ক্যাটালগ এক্সিকিউটেবল প্রকাশকের শিরোনাম/বিল্ড ওয়ার্কফ্লো; বাইনারি প্রকাশনার জন্য একটি অনুদান প্রয়োজন প্রকাশক, বর্তমান প্রাপ্যতা

একটি হোস্ট করা গেমের UUID হল এর API স্লাগ এবং সাবডোমেন। প্রদর্শনের নাম এবং সংগ্রহস্থলের নাম API নয় শনাক্তকারী দেখুন শংসাপত্র এবং শনাক্তকারী তারের অনুরোধের আগে।

ভলিউম, গ্রাফিক্স, অ্যাক্সেসযোগ্যতা, পছন্দ প্রতি-প্লেয়ার গেম সেটিংস প্লেয়ারের গেম ক্লায়েন্ট
কীবোর্ড ওভাররাইড করে ম্যানিফেস্ট ঘোষণার পরে API নিয়ন্ত্রণ করে প্লেয়ারের গেম ক্লায়েন্ট
বৈধ ম্যাচ/বিশ্বের অবস্থা এবং খেলোয়াড়ের পরিসংখ্যান স্ক্রিপ্ট রিটার্ন বা কন্টেইনার স্ন্যাপশট/ফলাফল প্রামাণিক খেলা ব্যাকএন্ড

ক্লাউড সংরক্ষণে প্রতি স্লটে একটি অস্বচ্ছ নথি থাকে, ম্যাচের ইতিহাস নয়। রিপ্লে ধারণ করে সমাপ্ত সেশনের অবস্থা আপনার ব্যাকএন্ড ধরে রাখতে বেছে নিয়েছে, একটি স্বয়ংক্রিয়ভাবে রেকর্ড করা ভিডিও বা ইনপুট নয় প্রবাহ দেখুন নিরাপদে সংরক্ষণ এবং সেশন জীবনচক্র.
