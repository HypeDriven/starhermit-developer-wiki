স্ক্রিপ্ট গেমের জন্য নেটিভ পারফরম্যান্স

একটি StarHermit ইঞ্জিন গেম ব্রাউজারে এবং স্থানীয়ভাবে একই প্যাকেজ চালায়। দুই আপনার কোড খুব রান ভিন্নভাবে, তাই পোর্ট করার বা লেখার আগে ভারী কাজ কোথায় থাকে তা বেছে নিন। এই পাতা স্ক্রিপ্ট কভার গতি, WebAssembly, GPU- আবদ্ধ দৃশ্য, কর্মী এবং পরিমাপ। পরিসংখ্যান থেকে ইঞ্জিন পরিমাপ হয় অক্টোবর 2026, ইঞ্জিন 1.26.1 হিসাবে।

কিভাবে আপনার কোড রান

ব্রাউজারে দেশীয়ভাবে
খেলা জাভাস্ক্রিপ্ট ব্রাউজারের V8, ফুল স্পিড ইঞ্জিনের নিজস্ব দোভাষী, কোন JIT (নকশা দ্বারা, নিরাপত্তার জন্য)
WebAssembly, প্রধান রাজ্য ব্রাউজারের WebAssembly ইঞ্জিন 1.26.1 থেকে প্ল্যাটফর্ম-সংকলিত নেটিভ কোড (বিস্তারিত); অন্যথায় ইঞ্জিনের দোভাষী (হোস্ট API 1.25 এবং পরবর্তী)
মধ্যে WebAssembly starhermit:script শ্রমিকদের বিট-সঠিক ফলাফলের জন্য ইঞ্জিনের দোভাষী প্ল্যাটফর্ম-সংকলিত নেটিভ কোড, মূল রাজ্যের মতো
  • স্থানীয়ভাবে, আসল গেম জাভাস্ক্রিপ্ট সম্পর্কে V8 এর চেয়ে 15-25× ধীর. মাইক্রো-বেঞ্চমার্ক পরামর্শ দিতে পারে প্রায় 8 ×। তাদের উপর নির্ভর করবেন না।
  • নেটিভ ওয়েব অ্যাসেম্বলি যেটি প্ল্যাটফর্মটি কম্পাইল করেছে তাতে চলে মোটামুটি V8 গতি: প্রায় 7× দ্রুত ইঞ্জিনের সিমুলেশন বেঞ্চমার্কের দোভাষীর চেয়ে, প্রায় 1.4× V8 এর সময়। ব্যাখ্যা করেছেন WebAssembly V8 এর চেয়ে প্রায় 8–18× ধীর।
  • starhermit check জাভাস্ক্রিপ্ট ঠিক যেমন একটি উইন্ডোড গেম চালায়। বেঞ্চমার্ক সহ a --release শুধুমাত্র ইঞ্জিন নির্মাণ।

সংকলিত WebAssembly

ইঞ্জিন 1.26.1 থেকে, যখন আপনি একটি গেম ধারণকারী প্রকাশ করেন .wasm মডিউল, প্ল্যাটফর্ম প্রতিটি কম্পাইল একটি স্যান্ডবক্সযুক্ত বিল্ডে সময়ের আগে মডিউল এবং ফলাফলে স্বাক্ষর করে। নেটিভ রানটাইম এটি ডাউনলোড করে, স্বাক্ষর যাচাই করে, ক্যাশ করে এবং নেটিভ কোড হিসাবে চালায়। আপনার গেমটি পরিবর্তন করার দরকার নেই; শুধু এটা প্রকাশ.

  • কোথায়: Windows x86-64, Linux x86-64 এবং Intel macOS, CPU-তে x86-64-v2 বা নতুন (SSE4.2 এবং POPCNT)। অ্যাপল সিলিকন ম্যাক এবং পুরানো সিপিইউ এখনও ব্যাখ্যা করে এবং মডিউলগুলিও করে SIMD ব্যবহার করুন।
  • কখন: সংকলিত কোড ডাউনলোড হওয়ার আগে তৈরি করা একটি উদাহরণ ব্যাখ্যা করতে থাকে। পরে দৃষ্টান্তগুলি কম্পাইল করা হয়, পরবর্তী লঞ্চ সহ, যা এটি ডিস্ক ক্যাশে থেকে লোড করে।
  • একই ফলাফল: সংকলিত কোড জ্বালানী এবং ফাঁদ সহ বিটের জন্য ইন্টারপ্রেটার বিটের সাথে মেলে।
  • চেক এবং অক্ষম করুন: সঙ্গে --dev, লগ প্রতিটি মডিউলের জন্য দেখায় যে এটি কম্পাইল করা হয়েছে বা ব্যাখ্যা, এবং কেন. STARHERMIT_WASM_AOT=0 সংকলন বন্ধ করে দেয়।
  • ব্রাউজার অপরিবর্তিত: প্রধান ক্ষেত্র ব্রাউজারের WebAssembly ব্যবহার করে, এবং কর্মীরা ব্যবহার করে ইঞ্জিনের দোভাষী।

ফ্রেম প্রতি ভারী কাজ

সিমুলেশন, মেশিং, পাথফাইন্ডিং এবং এন্টিটি বিল্ড হল সাধারণ হট স্পট।

  1. হট কোডটি মরিচা বা অন্য WASM ভাষায় লিখুন এবং এটিকে WebAssembly হিসাবে চালান, আদর্শভাবে a তে starhermit:script কর্মী একবার গেমটি প্রকাশিত হলে, এটি স্থানীয়ভাবে V8 গতির কাছাকাছি চলে, যখন প্লেইন জাভাস্ক্রিপ্ট প্রায় 15-25× ধীর থাকে।
  2. এর সাথে একটি পথ বেছে নিন runtime() থেকে starhermit:engine (হোস্ট API 1.26)। "web" V8 মানে, তাই জাভাস্ক্রিপ্ট সেখানে ঠিক আছে. "native" মানে আপনার WASM পথ পছন্দ করা উচিত। শ্রমিকরা সব সময় নেয় নেটিভ পাথ এবং আমদানি করা যাবে না starhermit:engine.
  3. গেম লজিক, UI এবং অর্কেস্ট্রেশনের জন্য প্লেইন জাভাস্ক্রিপ্ট রাখুন। ফ্রেম জুড়ে বিরল ভারী কাজ ছড়িয়ে দিন।
  4. গতির জন্য WebAssembly-এ JavaScript বা TypeScript কম্পাইল করবেন না। ফলাফল এখনও একটি প্রয়োজন জাভাস্ক্রিপ্ট অবজেক্ট মডেল, তাই এটি কিছুই লাভ করে না।

অনেক অনুরূপ সত্তার জন্য, starhermit:world কার্নেল দেশীয়ভাবেও চালান।

GPU- আবদ্ধ দৃশ্য

স্থানীয়ভাবে, GPU সাধারণত স্ক্রিপ্ট সময় নিয়ন্ত্রণে থাকার পরেই সীমা হয়ে যায়।

  • ব্যবহার করুন InstancedMesh.setLevels([...]) নিম্ন-পলি স্তর এবং একটি ড্র দূরত্ব সহ, এবং তিনটি LOD (হোস্ট API 1.26)।
  • পালা castShadow ছোট বা দূরবর্তী প্রপস জন্য বন্ধ.
  • সঙ্গে ছায়া ক্যাসকেড সীমিত shadow.cascades = { count, maxDistance }, একটি ইঞ্জিন এক্সটেনশন।
  • সেট STARHERMIT_GPU_PASS_TIMES=1 প্রতিটি পাসের জন্য GPU সময় প্রিন্ট করতে।

শ্রমিকরা

  • হোস্ট API 1.27 এর আগে, আপনার ব্যবহার করা প্রতিটি কর্মীর একটি রেফারেন্স রাখুন, কারণ আবর্জনা সংগ্রহ এটি বন্ধ করে দেয়। 1.27 থেকে, শ্রোতাদের সাথে একজন কর্মী পর্যন্ত বেঁচে থাকে terminate().
  • কর্মীরা প্যাকেজ ফাইল পড়তে পারেন (filesহোস্ট API 1.26 থেকে।
  • হোস্ট API 1.25 থেকে কর্মীরা বাইনারি এবং স্থানান্তরযোগ্য বার্তা পাঠাতে পারে।

পরিমাপ

  • একই বিল্ড ব্যবহার করে নেটিভ এবং ওয়েবের তুলনা করুন।
  • ইঞ্জিনের ফ্রেম পরিসংখ্যান ফ্রেম টাইম থেকে আলাদাভাবে স্ক্রিপ্ট সময় রিপোর্ট করে। স্ক্রিপ্ট-বেঞ্চ নম্বরগুলি হল উদ্ধৃতির জন্য উপযুক্ত।
