চ্যাট

StarHermit চ্যাট একটি REST API (api/v1/chat) প্লাস একটি সার্ভার-টু-ক্লায়েন্ট ওয়েবসকেট পুশ চ্যানেল (ws/v1/chat) সমস্ত REST এন্ডপয়েন্টের প্রমাণীকরণ প্রয়োজন। ত্রুটি সংস্থাগুলি পরিবর্তিত হয়; দেখুন এপিআই কনভেনশন.

REST শেষ পয়েন্ট

ভিত্তি: https://api.starhermit.com/api/v1/chat.

পদ্ধতি পথ প্রমাণ বর্ণনা
পোস্ট /conversations জেডব্লিউটি একটি কথোপকথন তৈরি করুন (1 বন্ধু = সরাসরি, ≥2 = গ্রুপ)
প্যাচ /conversations/{id} জেডব্লিউটি একটি কথোপকথনের নাম পরিবর্তন করুন (যে কোনো সদস্য)
পোস্ট /conversations/{id}/invites জেডব্লিউটি একটি গোষ্ঠীতে একজন ব্যবহারকারীকে আমন্ত্রণ জানান
পান /invites জেডব্লিউটি আপনার মুলতুবি চ্যাট আমন্ত্রণ তালিকা
পোস্ট /invites/{id}/accept জেডব্লিউটি একটি চ্যাট আমন্ত্রণ গ্রহণ করুন
পোস্ট /invites/{id}/decline জেডব্লিউটি একটি চ্যাট আমন্ত্রণ প্রত্যাখ্যান করুন
পান /rooms/joinable জেডব্লিউটি ভিতরে ≥1 বন্ধুর সাথে খোলা ঘরের তালিকা করুন
পোস্ট /conversations/{id}/join জেডব্লিউটি একটি খোলা ঘরে যোগদান করুন (একজন সদস্যের সাথে বন্ধু হতে হবে)
পোস্ট /conversations/{id}/participants জেডব্লিউটি একটি কথোপকথনে অংশগ্রহণকারীদের যোগ করুন
মুছুন /conversations/{id}/participants/{userId} জেডব্লিউটি একজন অংশগ্রহণকারীকে সরান (স্ব: যেকোনো সদস্য; অন্যরা: শুধুমাত্র গোষ্ঠীর সৃষ্টিকর্তা)
পোস্ট /conversations/{id}/leave জেডব্লিউটি একটি কথোপকথন ছেড়ে দিন
পান /conversations জেডব্লিউটি প্রতিটি অপঠিত গণনা সহ কথোপকথনের তালিকা করুন
পান /conversations/{id} জেডব্লিউটি এর অপঠিত সংখ্যা সহ একটি কথোপকথন পান
পান /unread জেডব্লিউটি মোট অপঠিত বার্তা সংখ্যা পান
পোস্ট /conversations/{id}/read জেডব্লিউটি একটি কথোপকথন পড়া চিহ্নিত করুন
পান /conversations/{id}/messages?page=&pageSize= জেডব্লিউটি পৃষ্ঠাযুক্ত বার্তা ইতিহাস পান
পোস্ট /conversations/{id}/messages জেডব্লিউটি একটি বার্তা পাঠান (রেট-সীমিত)
PUT /conversations/{conversationId}/messages/{messageId} জেডব্লিউটি একটি বার্তা সম্পাদনা করুন
মুছুন /conversations/{conversationId}/messages/{messageId} জেডব্লিউটি একটি বার্তা মুছুন (সমাধির পাথর)

একটি কথোপকথন তৈরি করুন

POST /conversations

{
  "participantIds": ["<guid>"],
  "name": "Friday night lobby",
  "friendUserId": "<guid>",
  "joinPolicy": "closed"
}

সব ক্ষেত্র ঐচ্ছিক. একজন বন্ধু অংশগ্রহণকারী একটি তৈরি করে সরাসরি কথোপকথন; দুই বা ততোধিক একটি তৈরি করুন দল. joinPolicy হয় "open" বা "closed" (ডিফল্ট "closed") ফেরত a ConversationDto.

একটি কথোপকথনের নাম পরিবর্তন করুন

PATCH /conversations/{id} সঙ্গে { "name": "New name" } → ConversationDto. যে কোনো সদস্যের নাম পরিবর্তন করতে পারেন; সঙ্গে একটি সিস্টেম নোট kind: "system_rename" সম্প্রচার করা হয়।

আমন্ত্রণ জানায়

POST /conversations/{id}/invites সঙ্গে { "toUserId": "<guid>" } → ChatInviteDto. আমন্ত্রণ একটি বন্ধ রুমে একমাত্র উপায়.

GET /invites → ChatInviteDto[]:

[
  {
    "id": "<guid>",
    "conversationId": "<guid>",
    "conversationName": "Friday night lobby",
    "fromUserId": "<guid>",
    "fromUsername": "alice",
    "toUserId": "<guid>",
    "status": "pending",
    "createdAt": "2026-07-22T07:00:00Z"
  }
]

POST /invites/{id}/accept এবং POST /invites/{id}/decline → ChatInviteDto.

রুম যোগদান

GET /rooms/joinable → JoinableRoomDto[] — খোলা ঘর যেখানে আপনার অন্তত একজন বন্ধু আছে:

[
  {
    "id": "<guid>",
    "name": "Friday night lobby",
    "joinPolicy": "open",
    "createdAt": "2026-07-22T07:00:00Z",
    "participants": [{ "userId": "<guid>", "username": "alice" }]
  }
]

POST /conversations/{id}/join → ConversationDto. একটি খোলা ঘরে যোগদান করে; আপনাকে অবশ্যই একজন সদস্যের সাথে বন্ধু হতে হবে।

অংশগ্রহণকারীরা

POST /conversations/{id}/participants সঙ্গে { "participantIds": ["<guid>"] } → ConversationDto.

DELETE /conversations/{id}/participants/{userId} → 204. যে কোনো সদস্য নিজেদের অপসারণ করতে পারেন; অন্যদের অপসারণ করার জন্য গোষ্ঠীর সৃষ্টিকর্তা হওয়া প্রয়োজন।

POST /conversations/{id}/leave → 204.

কথোপকথন পড়া

GET /conversations → ConversationDto[].

GET /conversations/{id} → ConversationDto:

{
  "id": "<guid>",
  "type": "group",
  "name": "Friday night lobby",
  "createdByUserId": "<guid>",
  "joinPolicy": "closed",
  "createdAt": "2026-07-22T07:00:00Z",
  "participants": [{ "userId": "<guid>", "username": "alice" }],
  "otherParticipant": { "userId": "<guid>", "username": "bob" },
  "unreadCount": 3
}

type এক direct, group, game. name, createdByUserId, এবং otherParticipant অনুপস্থিত থাকতে পারে। unreadCount কলারের প্রতি-কথোপকথন পঠিত দিগন্তের পরে অন্যান্য সদস্যদের দ্বারা প্রেরিত অপঠিত পাঠ্য বার্তা গণনা করে।

অপঠিত অবস্থা

GET /unread কলারের সমস্ত কথোপকথন জুড়ে অপঠিত গণনা ফেরত দেয়:

{ "total": 7 }

POST /conversations/{id}/read সেই কথোপকথনের জন্য কলারের পাঠ্য দিগন্তকে অগ্রসর করে। বর্তমান প্রতিলিপি প্রদর্শনের পরে এটি ব্যবহার করুন। সার্ভার নির্গত একটি conversation_read ঘটনা কলারের অন্তর্গত সমস্ত সকেট, একাধিক সাইন-ইন করা ক্লায়েন্টকে তাদের ব্যাজগুলি সাফ করার অনুমতি দেয়। নতুন এবং মুছে ফেলা বার্তাগুলি মোট পরিবর্তন করতে পারে, তাই ক্লায়েন্টদের WebSocket ইভেন্ট থেকে আপডেট করা উচিত বা পর্যায়ক্রমে ফেরত /unread.

বার্তা

GET /conversations/{id}/messages?page=1&pageSize=50 → PagedMessagesDto:

{
  "conversationId": "<guid>",
  "page": 1,
  "pageSize": 50,
  "totalCount": 123,
  "items": []
}

POST /conversations/{id}/messages সঙ্গে { "content": "hello" } → MessageDto. রেট-সীমিত 10টি বার্তা/মিনিট প্রতি ব্যবহারকারী; অতিক্রম করলে তা ফিরে আসে 429.

PUT /conversations/{conversationId}/messages/{messageId} সঙ্গে { "content": "edited" } → MessageDto.

DELETE /conversations/{conversationId}/messages/{messageId} → 204. মুছে ফেলা একটি সমাধি পাথর: বার্তা সঙ্গে থাকে isDeleted: true.

MessageDto:

{
  "id": "<guid>",
  "conversationId": "<guid>",
  "senderId": "<guid>",
  "senderUsername": "alice",
  "content": "hello",
  "kind": "text",
  "metadata": { "key": "value" },
  "sentAt": "2026-07-22T07:00:00Z",
  "editedAt": null,
  "isDeleted": false
}

kind হয় "text" বা "system_rename"; content, metadata (a Dictionary<string,string>), এবং editedAt অনুপস্থিত/শূন্য হতে পারে।

ওয়েবসকেট: ws/v1/chat

সংযোগ করুন wss://api.starhermit.com/ws/v1/chat মাধ্যমে একটি JWT সঙ্গে Authorization শিরোনাম, ?ticket=, বা ?access_token=.

এটি একটি বিশুদ্ধ সার্ভার→ক্লায়েন্ট পুশ চ্যানেল: ক্লায়েন্ট ফ্রেম উপেক্ষা করা হয় (শুধুমাত্র Close সম্মানিত হয়)। প্রতিটি ফ্রেম একটি খাম:

{ "type": "<event>", "payload": { } }
ঘটনা type পেলোড
conversation_created ConversationDto
conversation_renamed ConversationDto
participants_added ConversationDto
participant_removed ConversationDto
chat_invite ChatInviteDto
chat_invite_responded ChatInviteDto
new_message MessageDto
message_updated MessageDto
message_deleted MessageDto
conversation_read সাইন-ইন করা ব্যবহারকারীর জন্য রিড-স্টেট পরিবর্তন; অপঠিত গণনা ফেরত
game_invite { "inviteId", "kind", "gameSlug", "gameName", "roomId", "from": { "userId", "username" }, "createdAt", "acceptPath", "declinePath", "inProgress", "sessionId" } - নীচে দেখুন

game_invite: উভয় আমন্ত্রণ সিস্টেমের জন্য একটি ইভেন্ট

যে কেউ দুটি উপায়ে খেলার জন্য আমন্ত্রিত হতে পারে, এবং এই একক ইভেন্ট উভয়ই বহন করে — একজন ক্লায়েন্ট একটি টোস্ট প্রয়োগ করে, দুটি নয়:

kind দ্বারা জারি এটা মেনে নিচ্ছে
"session" POST /games/{slug}/invites আপনাদের দুজনের জন্য একটি নতুন গেম সেশন তৈরি করে
"room" POST /realtime/rooms/{id}/invites আমন্ত্রণকারী ইতিমধ্যেই বসে আছে এমন একটি ঘরে আসন নেয়; roomId সেই ঘরটি

acceptPath এবং declinePath শেষ পয়েন্ট যে উত্তর এই আমন্ত্রণ - সেগুলি ব্যবহার করুন এবং পার্থক্য কখনই গুরুত্বপূর্ণ নয়। অন্য সিস্টেমের শেষ বিন্দুতে উত্তর দেওয়া হল a 404: দুজনে আলাদা আলাদা ইনভাইট আইডি রাখে।

inProgress হয় true যখন গ্রহণ করা একটি গেমে যোগদান করে যা ইতিমধ্যেই খেলা হচ্ছে — একটি অধিবেশন আমন্ত্রণ যা একটি চলমান অধিবেশনের নাম দেয়, অথবা একটি স্টার্ট রুমে একটি রুম আমন্ত্রণ যা অগ্রগতিতে যোগদানের অনুমতি দেয় — এবং sessionId এটা খেলার সেশন। বলতে ব্যবহার করুন "তাদের খেলায় যোগ দিন" পরিবর্তে "খেলা".

{
  "type": "game_invite",
  "payload": {
    "inviteId": "e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b",
    "kind": "room",
    "gameSlug": "poker",
    "gameName": "StarHermit Poker",
    "roomId": "b1d2c3e4-5f60-4a71-8b92-c3d4e5f60718",
    "from": { "userId": "9b2f8c1a-1111-4222-8333-444455556666", "username": "alice" },
    "createdAt": "2026-07-26T14:10:00Z",
    "acceptPath": "/api/v1/realtime/rooms/invites/e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b/accept",
    "declinePath": "/api/v1/realtime/rooms/invites/e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b/decline"
  }
}

roomId হয় null জন্য "session" আমন্ত্রণ একটি গেম-স্কোপড লঞ্চ টোকেন এই সকেটটি খুলতে বা অ্যাকাউন্ট জুড়ে পড়তে পারে না /me/game-invites ইনবক্স খেলা ক্লায়েন্ট পোল GET /api/v1/games/{slug}/invites অধিবেশন আমন্ত্রণের জন্য এবং GET /api/v1/realtime/rooms/invites তাদের খেলার রুম আমন্ত্রণ জন্য. অ্যাকাউন্ট ক্লায়েন্ট উভয় ধরনের মাধ্যমে পড়তে পারেন GET /api/v1/me/game-invites.

একটি গেম সেশনের ভিতরে চ্যাট করুন

একটি গেম-স্কোপড লঞ্চ টোকেন পারে না খোলা ws/v1/chat — এটি ব্লক করা হয়েছে কারণ সকেট ব্যবহারকারীর সমস্ত কথোপকথন স্ট্রিম করে। টোকেন চালু করুন হতে পারে তাদের নিজস্ব গেম সেশনের সাথে সংযুক্ত কথোপকথনে চ্যাট REST API ব্যবহার করুন: সেশনের বিশদ বিবরণ দেয় a chatConversationId, কথোপকথন টাইপ আছে "game", এর অংশগ্রহণকারীরা সেশনের খেলোয়াড় এবং বন্ধুত্বের নিয়মগুলি বাইপাস করা হয়৷

গেম ক্লায়েন্টরা তাই সাধারণত REST এর উপর ইতিহাস লোড করে এবং সকেট ব্যবহার না করে নতুন বার্তাগুলির জন্য পোল করে। উদাহরণস্বরূপ, দ দাবা রেফারেন্স বাস্তবায়ন প্রতি 5 সেকেন্ডে ভোট:
