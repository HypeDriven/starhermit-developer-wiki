সফটওয়্যার ক্যাটালগ

সফ্টওয়্যার ক্যাটালগ ব্রাউজিং এবং দাবি শিরোনাম, তালিকা তৈরি, ডাউনলোড, ক্লাউড সংরক্ষণ, ইচ্ছা তালিকা, এবং রেটিং কভার করে। পঠিত হয় বেনামী; লেখার জন্য একটি JWT প্রয়োজন।

ভিত্তি URL: https://api.starhermit.com. সব রুট অধীনে আছে /api/v1/....

ব্রাউজিং এবং শিরোনাম দাবি

পদ্ধতি পথ প্রমাণ বর্ণনা
পান /api/v1/software বেনামী অনুসন্ধান করুন এবং ক্যাটালগ পৃষ্ঠা
পান /api/v1/software/{id} বেনামী একটি শিরোনাম পান, বা 404
পান /api/v1/software/{id}/builds?page=&pageSize= বেনামী একটি শিরোনামের জন্য বিল্ডগুলির পৃষ্ঠাযুক্ত তালিকা৷
পোস্ট /api/v1/software/{id}/claim জেডব্লিউটি একটি এনটাইটেলমেন্ট প্রদান করে একটি বিনামূল্যে শিরোনাম স্ব-দাবি করুন
পোস্ট /api/v1/software/{id}/launch জেডব্লিউটি একটি লঞ্চ সেশন শুরু করুন (এনটাইটেলমেন্ট প্রয়োজন)

GET /api/v1/software ক্যোয়ারী প্যারামিটার গ্রহণ করে q (সম্পূর্ণ লেখা), category, tag, publisherId, platform, releaseStatus, sort, page, এবং pageSize. বৈধ sort মান: name, name_desc, created, created_desc, updated, updated_desc. এটি একটি ফেরত দেয় PagedResult:

{
  "items": [
    {
      "id": "…",
      "name": "…",
      "description": "…",
      "publisherId": "…",
      "category": "…",
      "platform": "…",
      "releaseStatus": "…",
      "tags": ["…"],
      "priceCents": 0,
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

GET /api/v1/software/{id}/builds ফেরত a PagedResult এর SoftwareBuild:

      "metadata": "…",
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

POST /api/v1/software/{id}/claim শুধুমাত্র বিনামূল্যে শিরোনামের জন্য কাজ করে (priceCents == 0); এটি কলকারীকে একটি এনটাইটেলমেন্ট প্রদান করে এবং 204 প্রদান করে। প্রদত্ত শিরোনামের জন্য এটি 402 প্রদান করে:

{"error": "purchasing is not available yet"}

POST /api/v1/software/{id}/launch একটি এনটাইটেলমেন্ট প্রয়োজন (অন্যথায় 403) এবং একটি ফেরত দেয় LaunchSession:

{
  "launchId": "…",
  "startTime": "…"
}

এটি একটি লঞ্চ কার্যকলাপ রেকর্ড করে, যা লুকানো থাকে যদি ব্যবহারকারীর গোপনীয়তা সেটিংস তাই বলে (দেখুন profile.md) দিয়ে অধিবেশন শেষ করুন POST /api/v1/activity/launches/{id}/end — দেখুন activity.md. একজন ব্যবহারকারীর এনটাইটেলমেন্ট এর মাধ্যমে তালিকাভুক্ত করা হয় GET /api/v1/me/entitlements (দেখুন profile.md).

ডাউনলোড

পদ্ধতি পথ প্রমাণ বর্ণনা
পোস্ট /api/v1/software/{id}/download জেডব্লিউটি একটি স্বাক্ষরিত ডাউনলোড URL পান (এনটাইটেলমেন্ট প্রয়োজন)

একটি এনটাইটেলমেন্ট প্রয়োজন (অন্যথায় 403)। রিটার্ন:

{
  "downloadUrl": "…"
}

URL সর্বশেষ বিল্ডের প্রথম ডাউনলোডযোগ্য সম্পদকে লক্ষ্য করে। কল একটি ডাউনলোড কার্যকলাপ রেকর্ড. ক্যাটালগ বাইনারি বিতরণ বর্তমানে একটি পূর্বরূপ; প্রত্যাবর্তিত ইউআরএলগুলি নিশ্চিত উত্পাদন নয় ডাউনলোড দেখুন বৈশিষ্ট্য প্রাপ্যতা এই প্রকাশনা প্রবাহের উপর নির্ভর করার আগে।

ক্লাউড সেভ

খেলা প্রতি একটি স্লট, শেষ লিখতে জয়. সমস্ত রুটের জন্য একটি JWT - একটি সম্পূর্ণ ব্যবহারকারীর টোকেন বা একটি গেমের প্রয়োজন৷ সেই গেমের নিজস্ব স্লটের জন্য টোকেন চালু করুন (নীচে)।

10 MB ক্যাপ (10,485,760 বাইট) এর জন্য প্রযোজ্য ডিকোড সেভ, অনুরোধ না. PUT নেয় JSON-এ বেস64-এনকোডেড সেভ করুন, তাই বডি সেভের চেয়ে প্রায় এক তৃতীয়াংশ বড় — মোটামুটিভাবে 14 MB ক্যাপ - এবং API এটি গ্রহণ করে।

সীমা (প্রতি অ্যাকাউন্ট) ডিফল্ট প্রত্যাখ্যান
একটি সংরক্ষণ, ডিকোড 10 MB 413 cloud_save_too_large
একটি সংরক্ষণ সঙ্গে গেম 200 409 cloud_save_slots_exhausted (একটি নতুন গেমের জন্য একটি সংরক্ষণ)
সব একসাথে সংরক্ষণ 1 জিবি 507 cloud_save_quota_exceeded, সঙ্গে used
আপলোড প্রতি মিনিটে ৩০ 429, সঙ্গে Retry-After

প্রতিটি প্রত্যাখ্যান হিসাবে বলবৎ সংখ্যার নাম দেয় limit. মোট হিসাব এর উপর পরিমাপ করা হয় অন্যান্য সংরক্ষণ করে, তাই একটি স্লট সবসময় বড় কিছু দিয়ে ওভাররাইট করা যেতে পারে। অপারেটর যে কোনো পরিবর্তন করতে পারেন এগুলো এক অ্যাকাউন্টের জন্য।

পদ্ধতি পথ প্রমাণ বর্ণনা
পান /api/v1/me/cloud-saves/{gameKey}/info জেডব্লিউটি মেটাডেটা সংরক্ষণ করুন: { exists, sizeBytes, updatedAt? }
পান /api/v1/me/cloud-saves/{gameKey} জেডব্লিউটি application/zip বাইট, 404 যদি না হয়
PUT /api/v1/me/cloud-saves/{gameKey} জেডব্লিউটি একটি সংরক্ষণ আপলোড করুন (ডিকোড করা সংরক্ষণ ≤ 10 এমবি, gameKey ≤ 300 অক্ষর)

শরীর রাখুন:

{
  "dataBase64": "…"
}

উত্তর দিন:

{
  "gameKey": "…",
  "sizeBytes": 0,
  "updatedAt": "…"
}

একটি গেমের ভিতর থেকে সংরক্ষণ করা হচ্ছে (লঞ্চ টোকেন)

লঞ্চ টোকেন সহ চলমান একটি গেম প্লেয়ারের সংরক্ষণ পড়তে এবং লিখতে পারে যে খেলা. আপনার গেমটি যেখানেই চলে সেখানেই সেভ করে — একটি ব্রাউজার, বা StarHermit ডেস্কটপ অ্যাপ, যা চলে একটি ব্রাউজারেও হোস্ট করা গেম - তাই সংরক্ষণ তাদের মধ্যে প্লেয়ার অনুসরণ করে।

মূল হল game:<gameId>, কোথায় <gameId> আপনার গেমের আইডি - এটির স্লাগের মতো একই মান, এটি <gameId>.starhermit.com ঠিকানা, এবং game_scope লঞ্চ টোকেনের দাবি:

const key = `game:${gameScope}`;            // e.g. "game:3fa85f64-5717-4562-b3fc-2c963f66afa6"

// Load on startup — 404 means no save yet.
const res = await fetch(`/api/v1/me/cloud-saves/${key}`, { headers: { Authorization: `Bearer ${launchToken}` } });
if (res.status !== 404 && !res.ok) throw new Error(`Save load failed: ${res.status}`);
const save = res.status === 404 ? null : new Uint8Array(await res.arrayBuffer());
const etag = res.headers.get("ETag");
if (save && !etag) throw new Error("Save version unavailable; do not overwrite it.");
// Validate/decode your own save format before adopting it or enabling uploads.

// Save at checkpoints, not every frame.
const written = await fetch(`/api/v1/me/cloud-saves/${key}`, {
  method: "PUT",
  headers: {
    Authorization: `Bearer ${launchToken}`, "Content-Type": "application/json",
    ...(etag ? { "If-Match": etag } : { "If-None-Match": "*" }),
  },
  body: JSON.stringify({ dataBase64: base64(zipBytes) }), // Your ZIP encoder and bytes.
});
if (written.status === 412) throw new Error("Another device saved. Reload before writing again.");
if (!written.ok) throw new Error(`Save write failed: ${written.status}`);
const acknowledgement = await written.json(); // Retain acknowledgement.etag for your next write.
  • শুধুমাত্র যে সঠিক কী. অন্য কোন কী — অন্য গেমের, একটি স্টোর গেমের, বা একটি ভিন্ন বানান আপনার (বড় হাতের, বেয়ার আইডি) — হয় 403 একটি লঞ্চ টোকেনের জন্য। যে অন্তর্ভুক্ত github:<gameId>, যখন কোনো প্লেয়ার আপনার গেমের জন্য একটি স্থানীয় সংরক্ষণ ফোল্ডার সিঙ্ক করে তখন ডেস্কটপ অ্যাপ ব্যবহার করে আলাদা স্লট সেই সিঙ্ক কখনই আপনার গেমের লেখা সংরক্ষণ ওভাররাইট করতে পারে না।
  • যে কোনো বিন্যাস। প্ল্যাটফর্ম কখনও সংরক্ষণ খোলে না; আপনার গেম যা পড়তে পারে তা সঞ্চয় করুন (এটি হল হিসাবে পরিবেশিত application/zip নির্বিশেষে)। 10 এমবি পর্যন্ত।
  • নিঃশর্ত লেখাই শেষ লেখার জয়, কোন ইতিহাস ছাড়া. সনাক্ত করতে শর্তসাপেক্ষ লিখন ব্যবহার করুন দুটি ট্যাব/ডিভাইস একবারে সেভ করছে। শুরুতে লোড করুন এবং অগ্রভাগের চেকপয়েন্টগুলিতে সংরক্ষণ করুন। পৃষ্ঠা-প্রস্থান আপলোড সর্বোত্তম প্রচেষ্টা এবং ব্রাউজার শরীরের আকার সীমা আছে; দেখুন নিরাপদ সংরক্ষণের রেসিপি.
  • প্রতিটি সংরক্ষণের একটি সংস্করণ আছে। এর ETag ডাউনলোড হচ্ছে, চালু আছে /info (এছাড়াও etag) এবং অন দ PUT প্রতিক্রিয়া হিসাবে এটি ফেরত পাঠান If-Match এবং লেখাটি তখনই ঘটে যখন কেউ সংরক্ষণ না করে যেহেতু; অন্যথায় 412 {"error":"precondition_failed","etag":"<current>"} আপনাকে সংস্করণটি বলে লোড If-Match: * একটি বিদ্যমান সংরক্ষণ প্রয়োজন; If-None-Match: * শুধুমাত্র যখন কিছুই না থাকে তখনই লেখে। কোন শিরোনাম সহ a PUT শর্তহীন - শেষ লিখতে জয়। ক GET সঙ্গে If-None-Match: <etag> উত্তর 304 যখন আপনি ইতিমধ্যেই নতুন সংরক্ষণটি ধরে রেখেছেন।
  • কোন হোস্ট করা তালিকা ছাড়া একটি গেম (একটি অপারেটর-প্রোভিশনেড গেম) কোন স্লট নেই।

ছোট, ঘন ঘন পরিবর্তন হওয়া পছন্দগুলি অন্তর্ভুক্ত প্রতি-প্লেয়ার সেটিংস পরিবর্তে; তারা লঞ্চ টোকেন এবং সমর্থন আংশিক আপডেটের সাথে পৌঁছানো যায়।

পদ্ধতি পথ প্রমাণ বর্ণনা
PUT /api/v1/me/ratings জেডব্লিউটি একটি খেলার জন্য আমার রেটিং বাড়ান
পোস্ট /api/v1/ratings/query জেডব্লিউটি ব্যাচ-আনয়ন রেটিং সারাংশ
পান /api/v1/ratings/reviews?key=&top= জেডব্লিউটি একটি খেলার জন্য পর্যালোচনা (top ডিফল্ট 10)

শরীর রাখুন:

{
  "gameKey": "…",
  "stars": 4,
  "review": "…"
}

stars হল 0-5; review ঐচ্ছিক। প্রতিক্রিয়া হল a RatingSummaryDto:

{
  "gameKey": "…",
  "average": 4.5,
  "count": 12,
  "myStars": 4
}

POST /api/v1/ratings/query শরীর এবং প্রতিক্রিয়া:

{
  "keys": ["…", "…"]
}

রিটার্ন RatingSummaryDto[]. GET /api/v1/ratings/reviews রিটার্ন GameReviewDto[]:
