বহিরাগত লাইব্রেরি

ব্যবহারকারীর স্টিম, এপিক বা GOG লাইব্রেরি লিঙ্ক করা যাতে তাদের বাহ্যিক গেমগুলি তালিকাভুক্ত, লঞ্চ এবং ট্র্যাক করা যায়। সমস্ত রুট একটি JWT প্রয়োজন.

ভিত্তি URL: https://api.starhermit.com. সব রুট অধীনে আছে /api/v1/....

লিঙ্ক করা এবং লিঙ্কমুক্ত করা

পদ্ধতি পথ প্রমাণ বর্ণনা
পান /api/v1/me/external-libraries জেডব্লিউটি আমার লিঙ্ক করা প্রদানকারীদের তালিকা করুন
পোস্ট /api/v1/me/external-libraries/link জেডব্লিউটি একটি প্রদানকারীকে লিঙ্ক করুন এবং তার শিরোনাম সিঙ্ক করুন
মুছুন /api/v1/me/external-libraries/{provider} জেডব্লিউটি একটি লিঙ্ক এবং এর মালিকানা সরান

সংযুক্ত লাইব্রেরি:

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

লিঙ্ক বডি:

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

রিটার্ন 204। লিঙ্কিং প্রদানকারীর শিরোনামও সিঙ্ক করে। লাইব্রেরি সিঙ্ক বর্তমানে ডেমো শিরোনাম প্রদান করে steam/epic/gog যখন প্রকৃত প্রদানকারী ইন্টিগ্রেশন চূড়ান্ত করা হয়।

মালিকানাধীন বাহ্যিক সফ্টওয়্যার এবং লঞ্চ

পদ্ধতি পথ প্রমাণ বর্ণনা
পান /api/v1/me/external-software?provider=&page=&pageSize= জেডব্লিউটি আমার বহিরাগত শিরোনামগুলির পৃষ্ঠাযুক্ত তালিকা
পোস্ট /api/v1/external-software/{ownershipId}/launch জেডব্লিউটি একটি লঞ্চ URI পান এবং একটি বহিরাগত লঞ্চ রেকর্ড করুন৷

বাহ্যিক সফ্টওয়্যার তালিকা:

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

লঞ্চ প্রতিক্রিয়া:

{
  "launchUri": "steam://run/…"
}

প্রদানকারী দ্বারা URI বিন্যাস চালু করুন: steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. লঞ্চ একটি বাহ্যিক লঞ্চ কার্যকলাপ রেকর্ড করে — দেখুন activity.md. বহিরাগত গেম ইউনিফর্ম গেম কী ব্যবহার করে "provider:externalId" রেটিং এবং ফিডের জন্য — দেখুন catalog.md.

দেখুন এপিআই কনভেনশন পার্সিং ত্রুটির জন্য।

দেখুন শংসাপত্রের সামঞ্জস্য এবং মেশিন-পাঠযোগ্য চুক্তি.
