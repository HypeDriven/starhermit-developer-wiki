বন্ধুরা

ফ্রেন্ড এপিআই ফ্রেন্ড রিকোয়েস্ট এবং গৃহীত বন্ধুত্ব পরিচালনা করে। সব রুট অধীনে আছে api/v1/me এবং অনুমোদন প্রয়োজন। ফ্রেন্ডশিপ স্টেট গেটস গেম আমন্ত্রণ জানায়, এবং এটি খোলা চ্যাট রুম এবং ভয়েস রুমগুলিতে অ্যাক্সেস নিয়ন্ত্রণ করে।

ত্রুটি সংস্থাগুলি পরিবর্তিত হয়; দেখুন এপিআই কনভেনশন.

শেষবিন্দু

পদ্ধতি পথ প্রমাণ বর্ণনা
পোস্ট /api/v1/me/friend-requests জেডব্লিউটি একটি বন্ধু অনুরোধ পাঠান
পান /api/v1/me/friend-requests জেডব্লিউটি মুলতুবি আগত বন্ধু অনুরোধ তালিকা
পোস্ট /api/v1/me/friend-requests/{requestId}/accept জেডব্লিউটি একটি বন্ধু অনুরোধ গ্রহণ করুন
পোস্ট /api/v1/me/friend-requests/{requestId}/decline জেডব্লিউটি একটি বন্ধু অনুরোধ প্রত্যাখ্যান
মুছুন /api/v1/me/friends/{friendUserId} জেডব্লিউটি একজন ব্যবহারকারীকে আনফ্রেন্ড করুন
পান /api/v1/me/friends জেডব্লিউটি উপস্থিতি সহ গৃহীত বন্ধুত্বের তালিকা করুন

বন্ধুর অনুরোধ

POST /api/v1/me/friend-requests

{ "toUserId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }

রিটার্ন 204।

GET /api/v1/me/friend-requests

মুলতুবি আগত অনুরোধ:

[
  {
    "id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "senderUserId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "senderUsername": "pk-a1b2c3d4e5f6",
    "createdAt": "2026-07-20T09:30:00Z"
  }
]

POST /api/v1/me/friend-requests/{requestId}/accept

রিটার্ন 204; দুই ব্যবহারকারী বন্ধু হয়ে ওঠে.

POST /api/v1/me/friend-requests/{requestId}/decline

রিটার্ন 204।

বন্ধুরা

GET /api/v1/me/friends

বন্ধুত্ব গ্রহণ করেছে। online উপস্থিতি থেকে আসে, currentGame একটি সক্রিয় লঞ্চ থেকে:

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

ব্যবহারকারীকে আনফ্রেন্ড করে। রিটার্ন 204।

কিভাবে বন্ধুত্ব গেট অন্যান্য বৈশিষ্ট্য

  • খেলা আমন্ত্রণ শুধুমাত্র বন্ধুদের পাঠানো যেতে পারে — দেখুন গেমস.
  • চ্যাট — বন্ধুত্বের দরজা খোলা চ্যাট রুমে যোগদান; চ্যাট নিয়ম অ-খেলা কথোপকথনের জন্য বন্ধুত্ব প্রয়োজন. দেখুন চ্যাট.
  • ভয়েস — ভয়েস রুম অ্যাক্সেসের জন্য ব্যাকিং চ্যাট কথোপকথনের সদস্যতা প্রয়োজন, তাই চ্যাট বন্ধুত্বের নিয়মগুলি পরিবর্তনশীলভাবে প্রযোজ্য। দেখুন ভয়েস.
  • প্রতি সেশন গেম কথোপকথন বন্ধুত্ব নিয়ম বাইপাস — একই গেমের সেশনে থাকা খেলোয়াড়রা বন্ধু না হয়ে এর সংযুক্ত চ্যাট/ভয়েস ব্যবহার করতে পারে।

গেম-স্কোপড লঞ্চ টোকেন

একটি গেম-স্কোপড লঞ্চ টোকেন কল করতে পারে GET /api/v1/me/friends, তাই একটি গেম একটি সেশনের মধ্যে একটি আমন্ত্রণ-একটি-বন্ধু বাছাইকারীকে অফার করতে পারে — দাবা রেফারেন্স বাস্তবায়ন ঠিক এটির জন্য এটি ব্যবহার করে। অন্য বন্ধুর এন্ডপয়েন্টগুলি লঞ্চ টোকেনের জন্য 403 ফেরত দেয়; গেম-স্কোপ ফেন্সিং নিয়ম দেখুন প্রমাণীকরণ.

দেখুন শংসাপত্রের সামঞ্জস্য এবং মেশিন-পাঠযোগ্য চুক্তি.
