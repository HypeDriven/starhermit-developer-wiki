REST এবং WebSocket চুক্তি

এই ডাউনলোডযোগ্য চুক্তিগুলি রেফারেন্স পৃষ্ঠাগুলির পরিপূরক। অপারেশন পরিদর্শন করতে তাদের ব্যবহার করুন, উদাহরণ পেলোড যাচাই করুন, অথবা একটি OpenAPI- সামঞ্জস্যপূর্ণ ক্লায়েন্টে REST অনুরোধগুলি আমদানি করুন।

ফাইল কভারেজ
OpenAPI REST চুক্তি সর্বজনীন REST পদ্ধতি, পথ, পরামিতি, JSON অনুরোধের মডেল, সাফল্যের প্রতিক্রিয়া এবং শংসাপত্রের পরিবার; সংরক্ষিত প্রজন্মের অপারেশন অনুপলব্ধ চিহ্নিত করা হয়
WebSocket JSON স্কিমা প্রোটোকল এবং দিক দ্বারা পরিচিত পাঠ্য ফ্রেম; অ্যাপ্লিকেশন-মালিকানাধীন গেমপ্লে/সিগন্যালিং ডেটা খোলা থাকে
বাইনারি লেআউট রিয়েলটাইম প্রেরক উপসর্গ, ভয়েস প্রিফিক্স, আনফ্রেমযুক্ত রিলে, কন্টেইনার স্ট্রিম হেডার, এবং অংশগুলি আপলোড করুন

REST চুক্তি

REST ফাইল ব্যবহার করে OpenAPI 3.0.3 এবং সর্বজনীন API মূল। প্রতিটি অপারেশন তার রেফারেন্স পৃষ্ঠার সাথে লিঙ্ক করে, যা সম্পূর্ণ অনুমোদন, বৈধতা, সীমা এবং ত্রুটি বিধি বহন করে। x-credentials স্বীকৃত শংসাপত্র পরিবারগুলিকে চিহ্নিত করে; এটি মালিকানা বা সদস্যপদ চেক প্রতিস্থাপন করে না। x-required-policies যেখানে API তাদের প্রয়োগ করে সেখানে নামযুক্ত অনুমতিগুলি বর্ণনা করে।

প্রতিক্রিয়া অতিরিক্ত ক্ষেত্র অন্তর্ভুক্ত হতে পারে. গেম-নির্দিষ্ট JSON, মেটাডেটা, ডায়াগনস্টিকস এবং আপলোড ফলাফলগুলি খোলা আকার ব্যবহার করে যেখানে গেম বা এন্ডপয়েন্ট রেফারেন্স তাদের বিষয়বস্তুকে সংজ্ঞায়িত করে। সফলতা স্কিমা একটি প্রতিশ্রুতি নয় যে প্রতিটি কলার অনুমোদিত। এন্ডপয়েন্ট ত্রুটি JSON হতে পারে, প্লেইন টেক্সট, খালি প্রতিক্রিয়া, বা বৈধতা সমস্যা বিবরণ; ব্যবহার প্রতিরক্ষামূলক প্রতিক্রিয়া পার্সিং.

সংরক্ষিত প্রজন্মের ক্রিয়াকলাপগুলিকে একটি কার্যকরী পরিষেবা হিসাবে বিবেচনা করবেন না। তাদের চুক্তি বর্ণনা বর্তমান 503 overloaded প্রতিক্রিয়া, ভবিষ্যতের অনুরোধ ক্ষেত্র বা প্রজন্মের আচরণ নয়।

WebSocket চুক্তি

একটি নির্বাচন করুন $defs আপনার সকেটের প্রোটোকল এবং দিকনির্দেশের জন্য স্কিমা। উদাহরণস্বরূপ, একটি ক্লায়েন্ট যাচাই বিরুদ্ধে আন্দোলন ফ্রেম GameRealtimeInput, বরং জেনেরিক টেকসই GameCommand:

{ "type": "cmd", "data": { "type": "input", "realtime": true, "seq": 1, "x": 0.5 } }

realtime অন্তর্গত ভিতরে data. এর পরে গেমপ্লে ক্ষেত্রগুলি আপনার গেমের চুক্তি। ব্যবহার a JSON স্কিমা 2020-12 সম্পূর্ণ স্কিমা ডকুমেন্ট সহ বৈধকারী যাতে স্থানীয় রেফারেন্সগুলি সমাধান হয়। মূল নথিতে সংজ্ঞা রয়েছে; একটি ফ্রেম যাচাই করার জন্য একটি সংজ্ঞা নির্বাচন করা প্রয়োজন।

প্রোটোকল ক্লায়েন্ট পাঠ্য সংজ্ঞা সার্ভার পাঠ্য সংজ্ঞা বাইনারি ডেটা
গেমস GameCommand / GameRealtimeInput GameServerFrame শুধুমাত্র টেক্সট গেমপ্লে
রিয়েলটাইম রুম RealtimeClientControl RealtimeServerFrame হোস্ট-রাউটেড গেম ডেটা, প্রাপ্তিতে 16-বাইট প্রেরক অংশগ্রহণকারী উপসর্গ
ভয়েস VoiceClientControl VoiceServerEvent অডিও, প্রাপ্তিতে 16-বাইট প্রেরক ব্যবহারকারী উপসর্গ
চ্যাট কোন ক্লায়েন্ট কমান্ড নেই; REST ব্যবহার করুন ChatServerPush কোনোটিই নয়
পিয়ার রিলে কোনো JSON ফ্রেমিং নেই কোনো JSON ফ্রেমিং নেই পেলোড অপরিবর্তিত; কোনো পরিচয় উপসর্গ নেই
গেম আপলোড UploadClientControl UploadServerFrame আর্কাইভ খণ্ড
ধারক নিয়ন্ত্রণ ContainerControl সার্ভার থেকে কোন সাধারণ স্বীকৃতি খাম গেমপ্লে পৃথক ধারক ব্যবহার করে /stream

ভবিষ্যৎ ফ্রেমের ধরন আপনার ক্লায়েন্টের অজানা-ফ্রেম হ্যান্ডলারের কাছে পৌঁছানো উচিত, প্রাপ্তি ক্র্যাশ না করে লুপ JSON আকৃতির বৈধতা গেমের নিয়মগুলিকে বৈধতা দেয় না, সদস্যতা অনুমোদন করে, বা হার প্রয়োগ করে না সীমা রেফারেন্স পৃষ্ঠা ভূমিকা এবং আকার/হার সীমাবদ্ধতা সংজ্ঞায়িত করে।

GUID বাইট অর্ডার

প্রথম তিনটি UUID গ্রুপ একটি .NET GUID বাইট হেডারে সামান্য-এন্ডিয়ান। যেমন:

UUID:  00112233-4455-6677-8899-aabbccddeeff
Bytes: 33 22 11 00 55 44 77 66 88 99 aa bb cc dd ee ff

16-বাইট উপসর্গের জন্য একটি ব্রাউজার ডিকোডার:

function guidFromDotNet(bytes) {
  if (bytes.length !== 16) throw new Error('Expected a 16-byte GUID');
  const hex = i => bytes[i].toString(16).padStart(2, '0');
  return `${hex(3)}${hex(2)}${hex(1)}${hex(0)}-${hex(5)}${hex(4)}-${hex(7)}${hex(6)}-` +
    `${hex(8)}${hex(9)}-${hex(10)}${hex(11)}${hex(12)}${hex(13)}${hex(14)}${hex(15)}`;
}

রিয়েলটাইম উপসর্গ সনাক্ত করে অংশগ্রহণকারীদের, যখন ভয়েস উপসর্গ সনাক্ত করে ব্যবহারকারীদের. একটি ধারক স্ট্রীমের একটি ওয়ান-বাইট টাইপ আছে তার পরে সেশন/ব্যবহারকারীর UUID, তাই এর JSON বাইট থেকে শুরু হয় 33. দ রিলে কোনো উপসর্গ যোগ করে না। একই বাইনারি লেআউট হিসাবে প্রতিটি সকেট পড়া পেলোড এবং পরিচয়কে দূষিত করে।

দেখুন শংসাপত্র এবং শনাক্তকারী, সেশন জীবনচক্র, এবং ওয়েবসকেট সমস্যা সমাধান.
