ক্র্যাশ এবং বাগ রিপোর্ট

প্লেয়াররা ক্র্যাশ বা বাগ রিপোর্ট করতে পারে যেকোন গেমের ভিতর থেকে যেটিতে স্লগ আছে — শুধুমাত্র ব্রাউজার-এর গেম অন্তর্ভুক্ত — গেমের লঞ্চ টোকেন বা একটি সম্পূর্ণ ব্যবহারকারীর টোকেন ব্যবহার করে। খেলার মালিক পড়া, triages এবং তাদের মাধ্যমে মুছে দেয় /api/v1/me/github-games/{id}/reports.

একটি কন্টেইনার গেমের নিজস্ব সার্ভার আউটপুট এবং ক্র্যাশ রেকর্ডের জন্য, দেখুন কন্টেইনার-হোস্টেড গেম সার্ভার - আপনার সার্ভারের আউটপুট এবং ক্র্যাশ রিপোর্ট.

শেষবিন্দু

পদ্ধতি পথ প্রমাণ বর্ণনা
পোস্ট /api/v1/games/{slug}/reports সেই গেমের জন্য টোকেন বা JWT লঞ্চ করুন একটি ক্র্যাশ বা বাগ রিপোর্ট ফাইল করুন
পান /api/v1/games/{slug}/reports/mine সেই গেমের জন্য টোকেন বা JWT লঞ্চ করুন এই গেমের জন্য আপনার 50টি নতুন প্রতিবেদন, তাদের স্থিতি সহ
পান /api/v1/me/github-games/{id}/reports JWT (মালিক) তালিকা রিপোর্ট: ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
পান /api/v1/me/github-games/{id}/reports/{reportId} JWT (মালিক) একটি রিপোর্ট, এর সংযুক্তি তালিকা সহ
পান /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} JWT (মালিক) একটি সংযুক্তি, সর্বদা একটি ডাউনলোড হিসাবে
প্যাচ /api/v1/me/github-games/{id}/reports/{reportId} JWT (মালিক) সেট status
মুছুন /api/v1/me/github-games/{id}/reports/{reportId} JWT (মালিক) একটি রিপোর্ট মুছুন → 204

একটি রিপোর্ট ফাইল করুন

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind হয় crash বা bug; title প্রয়োজন (≤200 অক্ষর)।
  • বাকি সব ঐচ্ছিক. userAgent অনুরোধ এর ডিফল্ট User-Agent হেডার
  • প্রতিক্রিয়া: 201 { "id", "kind", "status": "open", "createdAt" }.
স্ট্যাটাস অর্থ
400 বিকৃত: অজানা kind, অনুপস্থিত title, অবৈধ base64, বা JSON নয়
404 অজানা বা সরানো খেলা
413 গেমের সীমার উপরে বর্ণনা, সংযুক্তি গণনা বা সংযুক্তি বাইট
429 এই গেমের জন্য দৈনিক প্রতিবেদনের সীমা ছাড়িয়ে গেছে; দেখুন Retry-After

সীমা

পুরো প্ল্যাটফর্ম এবং পৃথক গেমের জন্য অপারেটররা এর প্রতিটি পরিবর্তন করতে পারে; দৈনিক সীমা একজন খেলোয়াড়ের জন্যও সেট করা যেতে পারে।

সীমা ডিফল্ট
প্রতিদিন প্রতি গেম প্রতি খেলোয়াড়ের রিপোর্ট 20
বর্ণনার দৈর্ঘ্য 20,000 অক্ষর
রিপোর্ট প্রতি সংযুক্তি 4
রিপোর্ট প্রতি সংযুক্তি বাইট 2 MiB
খেলা প্রতি রিপোর্ট রাখা 2,000
গেম প্রতি বাইট রাখা 256 MiB
ধরে রাখা 90 দিন

যখন একটি গেম তার সঞ্চয়ের সীমায় পৌঁছে যায়, তখন সবচেয়ে পুরানো প্রতিবেদনগুলি — প্রথমে সমাধান করা হয় — সরিয়ে দেওয়া হয়৷ জায়গা করা পুরো প্রতি-গেম বাইট সীমার চেয়ে বড় একটি একক প্রতিবেদন প্রত্যাখ্যান করা হয়েছে 413.

Triage রিপোর্ট (খেলার মালিক)

তালিকা ফিরে আসে { "items", "total", "page", "pageSize" }; প্রতিটি আইটেম প্রতিবেদকের নাম বহন করে, kind, status, title, ক্লায়েন্টের বিশদ বিবরণ এবং এর সংযুক্তি সংখ্যা। মাধ্যমে একটি রিপোর্ট সরান open → acknowledged → resolved সঙ্গে:

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

সংযুক্তিগুলি ডাউনলোড হিসাবে পরিবেশিত হয় (Content-Disposition: attachment, nosniff, একটি স্যান্ডবক্সিং সিএসপি)। শুধুমাত্র জড় প্রকারগুলি তাদের ঘোষিত সামগ্রীর ধরন রাখে — পাঠ্য, JSON, PNG, JPEG, WebP, GIF, zip এবং gzip; অন্য কিছু, মার্কআপ অন্তর্ভুক্ত, হিসাবে পরিবেশন করা হয় application/octet-stream.

জাভাস্ক্রিপ্ট SDK থেকে

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports

দেখুন জাভাস্ক্রিপ্ট SDK.

শেয়ার করা হয়েছে এপিআই কনভেনশন রেসপন্স পার্সিং, টাইমস্ট্যাম্প, পেজিনেশন এবং পুনঃপ্রচেষ্টা বর্ণনা করুন।

দেখুন শংসাপত্রের সামঞ্জস্য এবং মেশিন-পাঠযোগ্য চুক্তি.
