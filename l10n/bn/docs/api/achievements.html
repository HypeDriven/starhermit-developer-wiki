অর্জন

একটি অর্জন হুবহু অন্তর্গত একজন মালিক, এবং মালিক সিদ্ধান্ত নেয় কে এটি আনলক করতে পারবে:

মালিক দ্বারা ঘোষিত দ্বারা আনলক করা হয়েছে জন্য এটি ব্যবহার করুন
একটি প্রামাণিক খেলা game.achievements একটি স্ক্রিপ্টে, বা achievements একটি পাত্র থেকে /describe — অথবা গেমের মালিকের দ্বারা মাধ্যমে /me/github-games/{id}/achievements গেমের সার্ভার রানটাইম শুধুমাত্র — সার্ভার-অনুমোদিত একটি সঙ্গে গেম server= স্ক্রিপ্ট বা container.image= ব্যাকএন্ড
একটি ক্যাটালগ শিরোনাম (SoftwareTitle) একটি প্রকাশক, মাধ্যমে প্রকাশক API প্লেয়ার এর ক্লায়েন্ট, মাধ্যমে POST /api/v1/me/achievements/unlock (এনটাইটেলমেন্ট প্রয়োজন) বিতরণ করা শিরোনাম যার ক্লায়েন্ট একমাত্র জিনিস যে প্লেয়ার কিছু অর্জন করেছে জানে

দুটি পারস্পরিক একচেটিয়া এবং প্ল্যাটফর্মটি বিভাজন প্রয়োগ করে:

  • POST /api/v1/me/achievements/unlock গেম-স্কোপড কৃতিত্ব অস্বীকার করে - একজন ক্লায়েন্ট কখনই দাবি করতে পারে না।
  • প্রকাশক CRUD এন্ডপয়েন্ট তাদেরও প্রত্যাখ্যান করে। আপনার নিজের একটি গেমের জন্য আপনার প্রকাশকের প্রয়োজন নেই: যেমন এর মালিক আপনি হয় এর প্রকাশক, এবং আপনি এর মাধ্যমে এর অর্জনগুলি পরিচালনা করেন মালিক শেষ পয়েন্ট পরিবর্তে

ভিত্তি URL: https://api.starhermit.com. সব রুট অধীনে আছে /api/v1/....

পদ্ধতি পথ প্রমাণ বর্ণনা
পান /api/v1/games/{slug}/achievements বহনকারী একটি প্রামাণিক গেমের কৃতিত্ব + কলারের আনলক অবস্থা
পান /api/v1/me/github-games/{id}/achievements JWT (গেমের মালিক) আপনার খেলা প্রতিটি অর্জন, তার সঙ্গে origin এবং গণনা আনলক করুন
পোস্ট /api/v1/me/github-games/{id}/achievements JWT (গেমের মালিক) আপনার গেমের জন্য একটি অর্জন তৈরি করুন → 201
PUT /api/v1/me/github-games/{id}/achievements/{achievementId} JWT (গেমের মালিক) আপনার তৈরি করা একটি আপডেট করুন
মুছুন /api/v1/me/github-games/{id}/achievements/{achievementId} JWT (গেমের মালিক) আপনার তৈরি করা একটি মুছুন এবং কেউ আনলক করেনি → 204
পান /api/v1/software/{titleId}/achievements বেনামী একটি ক্যাটালগ শিরোনামের কৃতিত্বের সংজ্ঞা
পান /api/v1/me/achievements?titleId= জেডব্লিউটি কলকারীর আনলক (সমস্ত মালিক, বা একটি শিরোনাম)
পোস্ট /api/v1/me/achievements/unlock জেডব্লিউটি ক্লায়েন্ট-দাবী আনলক — ক্যাটালগ শিরোনাম শুধুমাত্র

রক্ষণাত্মকভাবে ত্রুটিগুলি পড়ুন যেমন বর্ণনা করা হয়েছে এপিআই কনভেনশন. POST /me/achievements/unlock তার ফেরত দেয় 400 সাধারণ পাঠ্য হিসাবে কারণ।

সার্ভার-অনুমোদিত গেম অর্জন

এই যান্ত্রিকতা যেকোনো গেমটি ব্যবহার করা উচিত যখন এটিতে একটি স্ক্রিপ্ট বা ধারক ব্যাকএন্ড থাকে। দ সার্ভার রানটাইম একমাত্র লেখক। এটি অবশ্যই যাচাই করতে হবে যে প্লেয়ার প্রতিটি আনলক অর্জন করেছে; প্রত্যাখ্যান শুধুমাত্র সরাসরি API জমা দেওয়া একটি পরিবর্তিত ক্লায়েন্ট দ্বারা রিপোর্ট করা ঘটনাগুলিকে যাচাই করে না।

1. আপনার স্ক্রিপ্টে তাদের ঘোষণা করুন

একটি স্ট্যাটিক যোগ করুন achievements অ্যারে থেকে game বস্তু - দেখুন গেমের স্ক্রিপ্ট - অর্জন সম্পূর্ণ চুক্তির জন্য:

globalThis.game = {
  achievements: [
    { key: "first-win",  name: "First Win",  description: "Win a match.", points: 10 },
    { key: "flawless",   name: "Flawless",   description: "Win without conceding.",
      points: 50, secret: true, icon: "https://cdn.example/flawless.png" }
  ],
  createSession(ctx) { /* ... */ },
  onPlayerMessage(ctx) { /* ... */ },
  onTick(ctx) { /* ... */ }
};

ঘোষণাটি পাঠ করা হয় যখন গেমটি প্রকাশিত বা আপডেট করা হয় এর ভান্ডার থেকে। একটি পরিবর্তন প্রয়োগ করতে একটি আপডেট প্রকাশ করুন৷

2. যেকোনো লাইফসাইকেল হুক থেকে তাদের আনলক করুন

একটি প্রত্যাবর্তন achievements মানচিত্র — ব্যবহারকারী আইডি → কীগুলির অ্যারে — থেকে createSession, onPlayerMessage, বা onTick:

return {
  ok: true,
  sessionState: state,
  achievements: { [winnerId]: ["first-win", "flawless"] },
  result: { kind: "win", winner: winnerId }
};

আনলক হয় অক্ষমতা — প্লেয়ারের কাছে ইতিমধ্যেই ধারণ করা একটি কী ফেরত দেওয়া একটি নো-অপ, তাই একটি স্ক্রিপ্ট হতে পারে ডুপ্লিকেট সম্পর্কে চিন্তা না করে প্রতিটি টিক-এ একটি কৃতিত্ব পুনঃজারান।

3. প্লেয়ারকে গেমপ্লে সকেটের মাধ্যমে অবহিত করা হয়

প্রতিটি নতুন মঞ্জুরি আনলক শুধুমাত্র উপার্জনকারী প্লেয়ারের কাছে পুশ করা হয়, চালু ws/v1/games, তার নিজস্ব ফ্রেম হিসাবে টাইপ (প্ল্যাটফর্ম সত্য, একটি স্ক্রিপ্ট-রিলেড নয় game বার্তা):

{
  "type": "achievement",
  "data": {
    "key": "first-win",
    "name": "First Win",
    "description": "Win a match.",
    "icon": null,
    "points": 10,
    "unlockedAt": "2026-07-25T09:14:02Z"
  }
}

থেকে মঞ্জুর আনলক createSession যে কেউ একটি সকেট আছে আগে অব্যাহত আছে, তাই তারা সঙ্গে আসা কোন ফ্রেম নেই — লোডের সময় তালিকার শেষ পয়েন্ট থেকে সেগুলি পড়ুন।

কন্টেইনার ব্যাকএন্ড

একটি ধারক একই কৃতিত্ব ক্ষেত্র ঘোষণা করে GET /describe, তারপর একটি পাঠায় achievements তার নিয়ন্ত্রণ WebSocket বার্তা. প্ল্যাটফর্ম একই কী প্রয়োগ করে, অংশগ্রহণকারী, অক্ষমতা, এবং প্রসবের নিয়ম। দেখুন কন্টেইনার গেম সার্ভার.

GET /api/v1/games/{slug}/achievements

কলারের আনলক অবস্থা সহ গেমটি ঘোষণা করে প্রতিটি অর্জন। 404 স্লাগ কোন আছে প্রামাণিক গেমের সংজ্ঞা (একটি স্ক্রিপ্ট বা কন্টেইনার ব্যাকএন্ড ছাড়া একটি গেমের মালিকানা নেই অর্জন - দেখুন কোন গেম এই ব্যবহার করতে পারেন) গোপন অর্জন পর্যন্ত লুকিয়ে থাকে কলার তাদের আনলক করে। সৃষ্টি দ্বারা আদেশ, তারপর কী.

[
  {
    "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "key": "first-win",
    "name": "First Win",
    "description": "Win a match.",
    "icon": null,
    "secret": false,
    "points": 10,
    "unlocked": true,
    "unlockedAt": "2026-07-25T09:14:02Z"
  }
]

একটি সম্পূর্ণ ব্যবহারকারী JWT বা একটি গেম-স্কোপড লঞ্চ টোকেনের সাথে কাজ করে।

কোন গেম এই ব্যবহার করতে পারেন

মেকানিজমটি এমন একটি গেমের জন্য উপলব্ধ যা একটি ঘোষণা করে server= স্ক্রিপ্ট বা ক container.image= ব্যাকএন্ড ইন starhermit.txt. দ সার্ভার রানটাইম আনলককে প্রামাণিক করে তোলে। স্ক্রিপ্ট-সমর্থিত ব্যবহারের ক্ষেত্রে অন্তর্ভুক্ত:

  • স্ক্রিপ্টেড প্ল্যাটফর্ম গেম - থেকে আনলক onPlayerMessage / onTick যেমন ম্যাচ শেষ হয়।
  • রুম-বাউন্ড রিয়েলটাইম গেম — a রিয়েলটাইম রুম একটি জন্য একটি সঙ্গে খেলা server= স্ক্রিপ্ট একটি আবদ্ধ সেশন তৈরি করে যখন এটি শুরু হয়, এবং এর প্রতিটি হুক অধিবেশন কৃতিত্ব প্রদান করতে পারেন.
  • একক খেলোয়াড় এবং অনুশীলন গেম — এআই আসনের বিরুদ্ধে একটি অধিবেশন (POST /api/v1/games/{slug}/sessions/ai) একই স্ক্রিপ্ট এবং একই আনলক পাথ চালায়।
  • হোস্ট-রুটেড রিয়েলটাইম গেম — একটি খেলা যার গেমপ্লে চলে যায় রিয়েলটাইম রুম বাইনারি চ্যানেল এখনও একটি সার্ভার স্ক্রিপ্ট পাঠাতে পারেন বিশুদ্ধভাবে এর কৃতিত্বের কর্তৃপক্ষ হিসাবে: রুম স্টার্ট আবদ্ধ সেশন এবং স্ক্রিপ্ট তৈরি করে থেকে পুরস্কার createSession / onTick / টেকসই cmd বার্তা পাঠানো হয়েছে ws/v1/games যখন দ্রুত পথ প্রবাহিত হয় ws/v1/realtime.

কন্টেইনার-সমর্থিত সেশনগুলি তাদের প্রোটোকলের মাধ্যমে কৃতিত্বগুলি ঘোষণা এবং মঞ্জুর করতে পারে। একটি খেলা সঙ্গে কোন প্রামাণিক ব্যাকএন্ড (একটি বিশুদ্ধ ব্রাউজার গেম, অথবা শুধুমাত্র একটিতে নির্মিত পিয়ার রিলে) কোনো সার্ভার-অনুমোদিত আনলক পাথ নেই। ক্লায়েন্ট-দাবী আনলকিং শুধুমাত্র উপলব্ধ ক্যাটালগ-বিতরিত শিরোনাম, নীচে।

সীমা এবং নিয়ম

নিয়ম মান
খেলা প্রতি কৃতিত্ব ঘোষণা 100 (অতিরিক্ত উপেক্ষা করা হয়েছে)
অর্জন কী দৈর্ঘ্য 128টি অক্ষর
আনলক চাবিগুলি প্লেয়ার প্রতি, প্রতি আহ্বানের জন্য গৃহীত হয় 32
points 0-10000 এ আটকানো; ডিফল্ট 0
name থেকে ডিফল্ট key যখন বাদ দেওয়া হয়
  • একটি বিকৃত ঘোষণা এন্ট্রি হয় এড়িয়ে গেছে. একটি স্ক্রিপ্ট যা মূল্যায়ন করতে ব্যর্থ হয় একটি খালি ফল দেয়৷ তালিকা একটি পাত্রের ঘোষণা স্বাস্থ্য পরীক্ষা পাস করার পরে পড়া হয়। দিয়ে যাচাই করুন GET /api/v1/games/{slug}/achievements স্থাপনার পর।
  • দ্বারা সংজ্ঞা upsert key. আপনার ব্যাকএন্ড ঘোষণা করা বন্ধ করে দেওয়া একটি কী মুছে ফেলা হয়েছে শুধুমাত্র যদি কারো না থাকে এটা আনলক - অর্জিত ইতিহাস কখনো ধ্বংস হয় না। এপিআই এর মাধ্যমে মালিকের কৃতিত্ব এটি দ্বারা স্পর্শ করা হয় না: শুধুমাত্র ঘোষিত ব্যক্তিদের পুনর্মিলন করা হয়।
  • সেশনে অংশগ্রহণকারী নন এমন ব্যবহারকারীদের জন্য আনলক এবং AI আসন উপেক্ষা করা হয়।

অন্যান্য গেম থেকে অর্জন

প্লেয়ার কী আনলক করেছে তার উপর ভিত্তি করে একটি গেম বৈশিষ্ট্য খুলতে পারে অন্য খেলা: একটি সিক্যুয়াল সম্মান মূল, বা একটি সিরিজ ভাগ প্রসাধনী গেম গেম. এগুলি পড়ার দুটি উপায় রয়েছে।

আপনার সার্ভার থেকে: ctx.linkedAchievements (বিশ্বস্ত)

আপনার অন্যান্য ঘোষণার পাশে আপনার স্ক্রিপ্টে অন্যান্য গেমগুলির নাম দিন:

globalThis.game = {
  linkedAchievements: ["83fd04b1-3cbe-4b09-a251-3733ad4b9d94"], // other games' slugs (uids)
  // ...
};

একটি ধারক একই ফেরত linkedAchievements থেকে অ্যারে GET /describe. প্রতিটি স্ক্রিপ্ট invocation এর ctx তারপর সেই গেমগুলিতে প্রতিটি মানব খেলোয়াড়ের আনলক করা কীগুলি বহন করে:

ctx.linkedAchievements = {
  "7c9e6679-...": {                                   // player id
    "83fd04b1-3cbe-4b09-a251-3733ad4b9d94": ["first-win", "checkmate-10"]
  }
};
  • এটা আবার পড়া হয় প্রতিটি আহ্বান, তাই অন্য গেমের মধ্য-ম্যাচে অর্জিত একটি আনলক দেখা যাচ্ছে পরেরটি একটি ধারক এটি ctx এর মধ্যে গ্রহণ করে POST /sessions, যে, তৈরি এবং এ পুনরুদ্ধার
  • সর্বাধিক 8 গেম এন্ট্রি যা খালি স্ট্রিং, ডুপ্লিকেট এবং 100 টির বেশি স্লাগ নয় অক্ষর বাদ দেওয়া হয়। অন্যান্য ঘোষণার মত এটি পড়া হয় যখন খেলা প্রকাশিত হয় বা আপডেট করা হয়েছে
  • এমন একটি খেলা যা ঘোষণা করে কিছুই পায় না linkedAchievements ক্ষেত্র এবং কিছুই প্রদান করে না।
  • প্ল্যাটফর্মের বাধ্যতামূলক যেকোনো কিছুর জন্য এই রুটটি ব্যবহার করুন, যেমন গেমপ্লে আনলক করা বা অনুদান দেওয়া আপনার নিজের অর্জন।

আপনার ক্লায়েন্ট থেকে: GET /api/v1/games/{slug}/linked-achievements/{otherSlug}

কলকারীর নিজের আনলক ইন otherSlug. এটির কোনো ঘোষণার প্রয়োজন নেই, তাই একটি ব্রাউজার-কেবল গেম সার্ভার এটি ব্যবহার করতে পারে এবং এটি লঞ্চ টোকেনের সাথে কাজ করে {slug}: অন্য গেমের নিজস্ব শেষ পয়েন্ট সেই টোকেন থেকে বেড় থাকুন।

একজন ক্লায়েন্ট যা পেয়েছে সে সম্পর্কে মিথ্যা বলতে পারে, তাই এটিকে UI এবং প্রসাধনীর জন্য একটি ইঙ্গিত হিসাবে বিবেচনা করুন, প্রমাণ হিসাবে নয়।

কি প্রকাশ করা হয়

  • শুধুমাত্র আপনার নাম করা গেমটির অবস্থা আনলক করুন: কী এবং আনলক সময়, নাম, বিবরণ বা খেলোয়াড় খেলেছেন অন্যান্য গেমের তালিকা। প্লেয়ার আনলক করেছে একটি গোপন অর্জন অন্তর্ভুক্ত
  • একটি স্লগ যা কোনো গেমের সাথে মেলে না এমন একটি গেমের মতো যা আনলক করা নেই।
  • গোপনীয়তা সম্মান করা হয়. একজন খেলোয়াড় যার অর্জন গোপনীয়তা Private হয় লুকানো: অনুপস্থিত থেকে ctx.linkedAchievements, এবং "hidden": true শেষ পয়েন্ট থেকে একটি খালি তালিকা সহ। লুকানো হিসাবে একই নয় "কোনটি নেই", তাই এটি যেমন হিসাবে আচরণ করবেন না. FriendsOnly (ডিফল্ট) প্রকাশ করা হয়, কারণ পাঠক খেলোয়াড়ের জন্য অভিনয় করছেন।

গেমের মালিক দ্বারা তৈরি কৃতিত্ব

কোডে কৃতিত্ব ঘোষণা করা আপনার গেমটিকে কিছু দেওয়ার একমাত্র উপায় নয়। আপনি যদি একটি খেলার মালিক হন server= স্ক্রিপ্ট বা container.image= ব্যাকএন্ড, আপনি এর মাধ্যমে এটির জন্য অর্জনও তৈরি করতে পারেন API — যেভাবে একজন প্রকাশক একটি ক্যাটালগ শিরোনামের জন্য করে, কোনো প্রকাশক অ্যাকাউন্ট বা অনুমতির প্রয়োজন নেই। খেলার মালিকানা পুরোটাই অনুদান। যখন কোন ডিজাইনার যোগ করতে বা রিওয়ার্ড করতে চান তখন এটি ব্যবহার করুন কোড পরিবর্তন ছাড়াই অর্জন, অথবা যখন আপনার ব্যাকএন্ড কী মঞ্জুর করে তখন এটি ঘোষণা করে না।

শুধুমাত্র আপনার গেমের সার্ভার তাদের আনলক করতে পারে, ঠিক ঘোষিতগুলির মতো: আপনার স্ক্রিপ্ট কীটি ফেরত দেয় মধ্যে achievements, অথবা আপনার ধারক এটি নিয়ন্ত্রণ চ্যানেলে পাঠায়। কিছুই পরিবর্তন আনলকিং সাইড — কীগুলির বিরুদ্ধে সমাধান করা হয় সব গেমের কৃতিত্ব, ঘোষিত এবং তৈরি।

  • যদি আপনার কোড পরে আপনি এখানে তৈরি একটি কী ঘোষণা করে, ঘোষণা যে অর্জন লাগে উপর (origin হয়ে যায় declared) যারা এটি অর্জন করেছে তারা এটি রাখে।
  • কেউ আনলক করেছে এমন একটি অর্জন মুছে ফেলা যাবে না৷ (409).
  • 404 মানে খেলা আপনার নয়; 409 সার্ভার সম্পর্কে একটি বার্তা সহ এই রুটগুলির যেকোনো একটিতে ব্যাকএন্ড মানে গেমটির কিছুই নেই — একটি ব্রাউজার-শুধু গেম এমন কিছু নেই যা আনলক করতে পারে অর্জন
