কার্যকলাপ

কার্যকলাপ API লঞ্চ সেশন, খেলার সময়, এবং কার্যকলাপ ফিড কভার করে — ক্যাটালগ শিরোনাম এবং বহিরাগত (নন-ক্যাটালগ) গেম উভয়ের জন্য। সমস্ত রুটের একটি JWT প্রয়োজন যদি না উল্লেখ করা হয়।

ভিত্তি URL: https://api.starhermit.com. সব রুট অধীনে আছে /api/v1/....

ক্যাটালগ লঞ্চ সেশন এবং খেলার সময়

পদ্ধতি পথ প্রমাণ বর্ণনা
পোস্ট /api/v1/activity/launches/{id}/end জেডব্লিউটি একটি ক্যাটালগ লঞ্চ সেশন শেষ করুন (204)
পান /api/v1/activity/software/{softwareTitleId}/playtime জেডব্লিউটি একটি শিরোনাম জন্য আমার মোট খেলার সময়
পান /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 জেডব্লিউটি শিরোনামের জন্য বন্ধুদের খেলার সময়

লঞ্চ সেশন শুরু হয় POST /api/v1/software/{id}/launch (দেখুন catalog.md) এবং এখানে শেষ হয়েছে। খেলার সময় প্রতিক্রিয়া:

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime রিটার্ন FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

বাহ্যিক লঞ্চ এবং খেলার সময়

নন-ক্যাটালগ গেমগুলির জন্য (লিঙ্কযুক্ত বাহ্যিক লাইব্রেরি — দেখুন external-libraries.md):

পদ্ধতি পথ প্রমাণ বর্ণনা
পোস্ট /api/v1/activity/external-launches জেডব্লিউটি একটি নন-ক্যাটালগ গেমের জন্য একটি সেশন শুরু করুন
পোস্ট /api/v1/activity/external-launches/{id}/end জেডব্লিউটি সেশন শেষ করুন (204)
পান /api/v1/activity/external/playtime?provider=&externalId= জেডব্লিউটি একটি বহিরাগত খেলার জন্য আমার মোট খেলার সময়
পান /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 জেডব্লিউটি বাইরের খেলার জন্য বন্ধুদের খেলার সময়

POST /api/v1/activity/external-launches শরীর (provider ≤ 64 অক্ষর, externalSoftwareId ≤ 256 অক্ষর, name ঐচ্ছিক):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

প্রতিক্রিয়া:

{
  "launchId": "…"
}

বাহ্যিক খেলার সময় প্রতিক্রিয়া:

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

কার্যকলাপ ফিড

পদ্ধতি পথ প্রমাণ বর্ণনা
পান /api/v1/activity/game-feed?key=&limit=20 জেডব্লিউটি একটি গেম কী এর জন্য বন্ধুদের সেশন এবং রেটিং ইভেন্ট
পান /api/v1/activity/friends?since=&until=&limit= জেডব্লিউটি বন্ধুদের কার্যকলাপ
পান /api/v1/activity/public?since=&until=&limit= বেনামী পাবলিক কার্যকলাপ
পান /api/v1/me/activity?since=&until=&limit= জেডব্লিউটি আমার নিজস্ব কার্যকলাপ

গেম ফিড ফিরে আসে GameFeedItemDto[] একটি গেম কীর জন্য (একটি ক্যাটালগ গাইড বা "provider:externalId", দেখুন catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public, এবং me/activity ফিরে ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

কার্যকলাপ type মান: "download", "launch", "external_launch".

/activity/friends উপর কার্যকলাপ প্রকার প্রতি গেট করা হয় মালিকের গোপনীয়তা সেটিং: লঞ্চ অনুসরণ করে recentLaunchActivity, ডাউনলোড অনুসরণ করে recentDownloads. প্রতিটি অন্তর্ভুক্ত করা হয় যখন স্তর হয় FriendsOnly বা Public. একটি অ্যাকাউন্ট যা কখনও বেছে নেয়নি ডিফল্ট পায় (এর সাথে শেয়ার করা লঞ্চ বন্ধুরা, ডাউনলোড ব্যক্তিগত)। একটি অপঠনযোগ্য গোপনীয়তা নথি সম্পূর্ণরূপে ব্যক্তিগত হিসাবে বিবেচিত হয়। দেখুন profile.md.

দেখুন এপিআই কনভেনশন পার্সিং ত্রুটির জন্য।

দেখুন শংসাপত্রের সামঞ্জস্য এবং মেশিন-পাঠযোগ্য চুক্তি.
