প্লাক্স

প্লাক্স (প্রতীক পিএলকে) হল StarHermit এর মুদ্রা। খেলোয়াড়রা সেগুলিকে আপনার গেমের অ্যাক্সেস বা চালু করার জন্য ব্যয় করে আইটেম আপনি এটি ভিতরে বিক্রি. আপনি গ্রহণ 99% প্রতিটি বিক্রয়ের জন্য, এবং প্ল্যাটফর্মটি 1% কমিশন রাখে, সম্পূর্ণ প্লাক পর্যন্ত বৃত্তাকার: 1-100 PLK বিক্রিতে 1 PLK, 101-200-এ 2 PLK, এবং আরও অনেক কিছু৷ প্রতিটি ভারসাম্য শূন্য থেকে শুরু হয়।

প্লেয়াররা কীভাবে প্লাকস কিনবে বা উপার্জন করবে তা এখনও ঠিক করা হয়নি। এটি না হওয়া পর্যন্ত, ভারসাম্য শুধুমাত্র মাধ্যমে পরিবর্তিত হয় বিক্রয় এবং অপারেটর অনুদান।

শেষবিন্দু

পদ্ধতি পথ প্রমাণ বর্ণনা
পান /api/v1/me/plucks জেডব্লিউটি আপনার ব্যালেন্স: { balance, currency: "Plucks", symbol: "PLK" }
পান /api/v1/me/plucks/transactions জেডব্লিউটি আপনার ইতিহাস, নতুন প্রথম: ?before=&limit= (≤100)
PUT /api/v1/me/github-games/{id}/plucks/access-price JWT (মালিক) { price } (1–1,000,000,000, বা null বিনামূল্যে)
পান /api/v1/me/github-games/{id}/plucks/items JWT (মালিক) আপনার আইটেম ক্যাটালগ
PUT /api/v1/me/github-games/{id}/plucks/items/{key} JWT (মালিক) তৈরি করুন বা আপডেট করুন { name, price, active }
মুছুন /api/v1/me/github-games/{id}/plucks/items/{key} JWT (মালিক) একটি আইটেম সরান → 204
পান /api/v1/me/github-games/{id}/plucks/sales JWT (মালিক) প্রদত্ত আইটেম অর্ডার, নতুন প্রথম
পান /api/v1/games/{slug}/plucks/access টোকেন বা JWT লঞ্চ করুন { price, hasAccess, isOwner } কলারের জন্য
পান /api/v1/games/{slug}/plucks/items বেনামী আপনার সক্রিয় আইটেম
পোস্ট /api/v1/games/{slug}/plucks/orders টোকেন বা JWT লঞ্চ করুন প্লেয়ারকে কিনতে বলুন { itemKey }
পান /api/v1/games/{slug}/plucks/orders/{id} টোকেন বা JWT লঞ্চ করুন প্লেয়ারের অর্ডার এবং তার অবস্থা
পান /api/v1/games/{slug}/server/plucks/orders?since= সার্ভার টোকেন প্রদত্ত অর্ডার বিতরণের জন্য, প্রাচীনতম প্রথম
পোস্ট /api/v1/me/plucks/game-access/{gameId} JWT, OAuth সাইন-ইন করুন প্লেয়ার অ্যাক্সেস ক্রয় করে: { expectedPrice }
পোস্ট /api/v1/me/plucks/orders/{id}/confirm JWT, OAuth সাইন-ইন করুন প্লেয়ার একটি অর্ডারের জন্য অর্থ প্রদান করে
পোস্ট /api/v1/me/plucks/orders/{id}/cancel জেডব্লিউটি প্লেয়ার একটি আদেশ প্রত্যাখ্যান

প্রতিটি লেনদেন বলে যে এর প্লাক্স কোথা থেকে এসেছে

প্রতিটি ইতিহাস এন্ট্রি একটি আছে source:

  • sale.game_access: একজন খেলোয়াড় একটি গেমের অ্যাক্সেস কিনেছে।
  • sale.game_item: একজন খেলোয়াড় একটি ইন-গেম আইটেম কিনেছে।
  • grant: একজন অপারেটর Plucks জারি করেছে।

এন্ট্রি এছাড়াও বহন amount (স্বাক্ষরিত), balanceAfter, fee, খেলা, আইটেম কী, অর্ডার এবং অন্য পক্ষ। খাতাটি শুধুমাত্র সংযোজন করা হয়: একটি ভুল একটি নতুন লেনদেনের মাধ্যমে সংশোধন করা হয়, কখনোই নয় একটি পুরানো সম্পাদনা করা।

আপনার গেম অ্যাক্সেস বিক্রি

একটি মূল্য সেট করুন এবং আপনার গেমটি শুধুমাত্র আপনাকে এবং যারা অ্যাক্সেস কিনেছে তাদের জন্য টোকেন লঞ্চ করে। যে কেউ অন্য পায় 402 সঙ্গে code: "purchase_required" এবং price. তাদের কেনার উপায় দেখান।

একটি ক্রয় প্লেয়ারকে যে মূল্য হিসাবে দেখানো হয়েছিল তা পাঠায় expectedPrice. আপনি যদি দাম পরিবর্তন করে থাকেন যেহেতু, ক্রয় সঙ্গে প্রত্যাখ্যান করা হয় 409 (code: "price_changed"), তাই কেউ তাদের মূল্য পরিশোধ করে না দেখতে না অ্যাক্সেস স্থায়ী এবং পরে মূল্য পরিবর্তন থেকে বেঁচে থাকে। একটি গেমের মূল্য নির্ধারণ করা যা বিনামূল্যেও ছিল গেটস তার বিদ্যমান খেলোয়াড়দের.

আপনার গেমের হোস্ট করা ফাইলগুলি এখনও গেট করা হয়নি৷ একটি মূল্য প্ল্যাটফর্মের বৈশিষ্ট্যগুলিকে আটকে রাখে (সাইন-ইন, সেশন, সংরক্ষণ, অর্জন), ব্রাউজার গেমের ফাইল ডাউনলোড নয়।

আইটেম বিক্রি

আপনার খেলা একটি প্লেয়ার এর Plucks খরচ করতে পারে না. আপনার গেমের নিজস্ব কোড প্লেয়ারের লঞ্চ টোকেন ধারণ করে, তাই ক টোকেন যা খরচ করতে পারে তা যেকোনো গেমকে তার খেলোয়াড়দের নিষ্কাশন করতে দেয়। প্রবাহ হল:

  1. আপনার খেলা জিজ্ঞাসা. POST /api/v1/games/{slug}/plucks/orders সঙ্গে { "itemKey": "sword.gold" }. অর্ডারটি আইটেমের বর্তমান নাম এবং দাম নেয়, শুরু হয় pending, এবং 15-এর পরে মেয়াদ শেষ হয় মিনিট একজন খেলোয়াড়ের সর্বোচ্চ ২০টি অর্ডার অপেক্ষা করতে পারে (429, too_many_pending_orders).
  2. প্লেয়ার StarHermit নিশ্চিত করে, কখনও আপনার খেলার ভিতরে. StarHermit ক্লায়েন্ট দেখায় আইটেম, মূল্য এবং আপনার খেলা, এবং পোস্ট /me/plucks/orders/{id}/confirm. যে রুট একটি প্রয়োজন একটি OAuth প্রদানকারীর সাথে সাইন ইন করা অ্যাকাউন্ট, যেটি আপনার গেমে কখনোই নেই৷
  3. আপনি এটা পৌঁছে দিন. পোল GET /api/v1/games/{slug}/plucks/orders/{id} আপনার ক্লায়েন্ট থেকে পর্যন্ত status হয় paid (বা cancelled, বা অতীত expiresAt) একটি ধারক ব্যাকএন্ড পরিবর্তে পড়তে পারেন GET /api/v1/games/{slug}/server/plucks/orders?since=<last completedAt>.

প্ল্যাটফর্ম বিক্রয় রেকর্ড করে; আইটেমটি প্রয়োগ করা আপনার গেমের কাজ। দ্বারা ডেলিভারি idmpotent করা অর্ডার আইডি।

POST /api/v1/games/{slug}/plucks/orders
Authorization: Bearer <launch-token>
Content-Type: application/json

{ "itemKey": "sword.gold" }

{ "id": "2b0e…", "gameId": "c115…", "itemKey": "sword.gold", "itemName": "Golden Sword",
  "price": 100, "status": "pending", "expiresAt": "2026-10-28T14:15:00Z" }

আইটেম কী 1-64 অক্ষর a-z 0-9 . _ -; নাম 1-80 অক্ষর; দাম হয় 1-1,000,000,000 PLK। একটি নিষ্ক্রিয় বা মুছে ফেলা আইটেম অর্ডার করা যাবে না, এবং অর্ডার ইতিমধ্যে রাখা তাদের স্ন্যাপশট।

ত্রুটি

স্ট্যাটাস code অর্থ
402 insufficient_plucks প্লেয়ারের ব্যালেন্স দামের নিচে
402 purchase_required প্লেয়ার কেনা হয়নি এমন দামের গেমের জন্য একটি লঞ্চ টোকেন
409 price_changed expectedPrice দাম আর নেই
409 order_cancelled প্লেয়ার বাতিল করা একটি আদেশ নিশ্চিত করা
410 order_expired পরে নিশ্চিত করা হচ্ছে expiresAt
429 too_many_pending_orders নিশ্চিতকরণের অপেক্ষায় অনেকগুলো অর্ডার

তাদের নিজস্ব খেলা থেকে কেনা একটি মালিক পায় 409.

আপনার আয়

GET /api/v1/me/github-games/{id}/analytics/sales এবং …/analytics/monetization রিপোর্ট ইউনিট, মোট, প্ল্যাটফর্মের কমিশন এবং প্রতিদিন আপনার নেট, খেলোয়াড়দের অর্থ প্রদান, রূপান্তর এবং প্রতি আইটেম মোট তারা শুধুমাত্র মোট রিপোর্ট করে এবং কোন ক্রেতার নাম দেয় না। এ আপনার নিজের ইতিহাস /me/plucks/transactions প্রতিটি বিক্রয় তালিকা.
