এপিআই কনভেনশন

REST ব্যবহার করে https://api.starhermit.com/api/v1/...; সকেট ব্যবহার wss://api.starhermit.com/ws/v1/.... হোস্ট করা গেম কল করতে পারেন /api/v1/... এবং /ws/v1/... তাদের নিজস্ব উত্স উপর. নেটিভ ক্লায়েন্ট ব্যবহার সর্বজনীন API মূল। অন্য উত্সের একটি বিকাশ পৃষ্ঠার জন্য গেমটিতে একটি অনুমোদিত CORS উত্স প্রয়োজন৷ হোস্ট; শুধুমাত্র একটি SDK বেস ইউআরএল সেট করা সেই উৎপত্তিকে অনুমোদন করে না।

অনুরোধ এবং প্রতিক্রিয়া

এর সাথে JSON পাঠান Content-Type: application/json, কাঁচা gzip বান্ডেল আপলোড ছাড়া। JSON সদস্যদের নাম ক্যামেলকেস হয়। REST-এ বাহক শংসাপত্র পাঠান Authorization হেডার

প্রতিক্রিয়া কিভাবে এটা পড়তে
200 / 201 JSON নথিভুক্ত বস্তু বা অ্যারে পার্স করুন; অতিরিক্ত ক্ষেত্র সহ্য করুন
204 শরীর ছাড়া সাফল্য; কল করবেন না response.json()
302 ব্রাউজার সাইন-ইন/নিশ্চিতকরণ পুনঃনির্দেশ; OAuth পৃষ্ঠাগুলি আনার পরিবর্তে নেভিগেট করুন
304 শর্তাধীন পড়া অপরিবর্তিত; আপনি ইতিমধ্যে ধারণ করা ডেটা ধরে রাখুন
ছবি, সংযুক্তি, মেঘ সংরক্ষণ রেসপন্স কন্টেন্ট টাইপ এবং এন্ডপয়েন্ট কন্ট্রাক্ট ব্যবহার করে বাইট পড়ুন
ত্রুটি প্রথমে স্ট্যাটাস পড়ুন, তারপর শরীরকে আত্মরক্ষামূলকভাবে পার্স করুন

সাধারণ ত্রুটি ফর্ম হয় { "error": "...", "code": "..." }, ঐচ্ছিক ক্ষেত্রগুলির উপর নির্ভর করে শেষ বিন্দু error প্রায়ই মানুষের পাঠযোগ্য; code একটি স্থিতিশীল বৈষম্যকারী যেখানে প্রদান করা হয়. শর্তাবলী এবং কিছু অন্যান্য শেষ পয়েন্ট সরাসরি একটি বৈষম্যকারীকে রাখে error. কিছু শেষ পয়েন্ট প্লেইন ফিরে টেক্সট, একটি খালি শরীর, অথবা একটি বৈধতা সমস্যা বিবরণ বস্তুর সাথে title, status এবং errors. ক্লায়েন্টদের অনুমান করা উচিত নয় যে প্রতিটি অসফল প্রতিক্রিয়া JSON বা একই ক্ষেত্র রয়েছে৷

export async function readResponse(response) {
  if (response.status === 204 || response.status === 304) return null;
  const text = await response.text();
  let body;
  try { body = text ? JSON.parse(text) : null; } catch { body = text || null; }
  if (!response.ok) {
    const message = (body && typeof body === 'object' && (body.error || body.message || body.title))
      || (typeof body === 'string' && body) || response.statusText;
    throw Object.assign(new Error(message), {
      status: response.status, code: body?.code, body,
      retryAfter: response.headers.get('Retry-After'),
    });
  }
  return body;
}

সময়, মাপ, এবং শূন্য

  • createdAt, updatedAt, finishedAt, এবং অনুরূপ অ্যাকাউন্ট/রিসোর্স টাইমস্ট্যাম্প হল ISO 8601 স্ট্রিং একটি অফসেট সহ। অনুপস্থিত বা চিকিত্সা null অনুপলব্ধ হিসাবে ঐচ্ছিক মান।
  • ctx.now, summary.deadline, সেশন-তালিকা deadline, এবং /time.serverTime পূর্ণসংখ্যা ইউনিক্স মিলিসেকেন্ড. দিয়ে রূপান্তর করুন new Date(value), না Date.parse(value).
  • বাইটে সীমা মান বাইট, বেস64 অক্ষর নয়। একটি Base64 JSON আপলোড তার থেকে বড় ডিকোড করা বিষয়বস্তু। যখন উপলব্ধ একটি শেষ পয়েন্ট দ্বারা রিপোর্ট কার্যকর সীমা ব্যবহার করুন.
  • বাদ দেওয়া, null, এবং একটি খালি বস্তু সর্বজনীনভাবে সমতুল্য নয়। সেটিংস PATCH অপসারণ করে a নামের কী দিয়ে null; একক-কী সেটিংস PUT দোকান null একটি মান হিসাবে। সংগ্রহ PUT প্রতিস্থাপন করে পুরো মানচিত্র। প্রতিটি শেষ পয়েন্টের আপডেট নিয়ম পড়ুন।
  • একটি সেটিংস প্যাচ একত্রিত হয় শীর্ষ-স্তরের কী. একটি সরবরাহকৃত বস্তুর মান সেই কীটির মান প্রতিস্থাপন করে; এটি পুনরাবৃত্তভাবে নেস্টেড বৈশিষ্ট্যগুলিকে একত্রিত করে না।

পৃষ্ঠা সংখ্যা

পেজিং এক-ভিত্তিক যেখানে page/pageSize সমর্থিত হয় বিভিন্ন API এর ইচ্ছাকৃতভাবে ভিন্ন আছে প্রতিক্রিয়া খাম; একটি পার্সার পুনরায় ব্যবহার করবেন না যা একটি একক গণনা-ক্ষেত্রের নাম ধরে নেয়।

এলাকা সংগ্রহ আকৃতি ডিফল্ট / সর্বোচ্চ পৃষ্ঠার আকার
সফ্টওয়্যার শিরোনাম এবং বিল্ড { items, totalCount, page, pageSize } 20 / 100
চ্যাট বার্তা { conversationId, items, totalCount, page, pageSize } 50 / 100
লিডারবোর্ড এন্ট্রি { items, total, page, pageSize } 20 / 100
বাহ্যিক সফ্টওয়্যার { items, total, page, pageSize } 20; একটি ছোট ইতিবাচক পৃষ্ঠা আকার অনুরোধ করুন
রিপোর্ট, কন্টেইনার ক্র্যাশ রেকর্ড, সংযম তালিকা { items, total, page, pageSize } 20 / 100
সেশন, বন্ধু, গেম তালিকা, কৃতিত্ব অ্যারে এন্ডপয়েন্ট-নির্দিষ্ট ক্যাপ; কোন জেনেরিক পরবর্তী পৃষ্ঠা কার্সার
সংযম প্রত্যাহার ফিড কার্সার ভিত্তিক ফিরে আসা কার্সার রাখুন; থেকে পুনরুদ্ধার 410 নথিভুক্ত হিসাবে

প্রতিক্রিয়া পেজিং মেটাডেটা যেখানে উপলব্ধ সেখানে পরিবেশিত পৃষ্ঠা প্রতিফলিত করে। রেফারেন্স পাতা এবং মেশিন-পাঠযোগ্য চুক্তি এন্ডপয়েন্ট-নির্দিষ্ট ক্যোয়ারী প্যারামিটার বর্ণনা করুন।

পুনরায় চেষ্টা করুন এবং একযোগে

পরিস্থিতি অ্যাকশন
অ্যাকাউন্ট অ্যাক্সেস টোকেন দিয়ে প্রত্যাখ্যান করা হয়েছে 401 একটি শেয়ার করা রিফ্রেশ অনুরোধ ব্যবহার করে একবার রিফ্রেশ করুন; প্রত্যাখ্যান হলে সাইন ইন করুন
লঞ্চ টোকেনের মেয়াদ শেষ হয়েছে৷ সাইন-ইন/লঞ্চারের মাধ্যমে একটি নতুন টোকেন পান; মেয়াদোত্তীর্ণ টোকেন নিজেদের পুনর্নবীকরণ করতে পারে না
403 terms_acceptance_required বর্তমান শর্তাবলী প্রদর্শন করুন এবং স্পষ্টভাবে স্বীকার করুন, তারপর আবার চেষ্টা করুন
অন্যান্য 403 সুযোগ, সদস্যপদ, অনুমতি, বা অ্যাকাউন্ট স্থিতি সমাধান করুন; একটি লুপে রিফ্রেশ করবেন না
409 সদৃশ/রাষ্ট্র/সংশোধন দ্বন্দ্ব সমাধান করুন; একটি সম্পদ পরিবর্তন করার আগে পুনরায় পড়ুন
মেঘ-সংরক্ষণ 412 নতুন সংস্করণ লোড করুন এবং গেমটিকে একত্রিত করতে বা এটি গ্রহণ করতে দিন
429 বা অস্থায়ী 503 সম্মান Retry-After, জিটার যোগ করুন, এবং আবদ্ধ পুনরায় চেষ্টা করুন
একটি লেখার সময় নেটওয়ার্ক ব্যর্থতা ফলাফল অজানা হতে পারে; ক্রিয়াটি পুনরাবৃত্তি করার আগে সম্পদের অবস্থা পরিদর্শন করুন

Retry-After সেকেন্ড বা HTTP তারিখ হতে পারে। একটি idempotency হেডার উদ্ভাবন করবেন না: API তা করে না একটি সাধারণ অক্ষমতা-কী প্রক্রিয়া প্রতিশ্রুতি. সেশন তৈরির পুনরায় চেষ্টা বা একটি আমন্ত্রণ তৈরি করতে পারে আরেকটি সম্পদ বা প্রথমটির সাথে দ্বন্দ্ব। পঠিত এবং স্পষ্টভাবে অদম্য ক্রিয়াকলাপ পছন্দ করুন স্বয়ংক্রিয় পুনরায় চেষ্টা। রিফ্রেশ ঘূর্ণন, সম্পূর্ণ আপলোড, শর্ত সম্মতি, এবং টার্মিনাল খেলা ফলাফল প্রতিটি তাদের নিজস্ব নিয়ম আছে।

তুলনা এবং অদলবদল লেখার জন্য ক্লাউড-সেভ ইটিগস, রুম ব্যবহার করুন expectedRevision, বা সংযম সংশোধন যেখানে সমর্থিত। একটি সফল লেখা অগত্যা একটি সম্পূর্ণ কন্টেইনার স্থাপনার নয়; তার যাচাই করুন নতুন বিল্ডে খেলোয়াড়দের পাঠানোর আগে অবস্থা। দেখুন সমস্যা সমাধান.
