উদাহরণ গেম: ফুটবল কীভাবে স্টারহার্মিট ইঞ্জিন ব্যবহার করে

স্টারহার্মিট ফুটবল একটি সর্বজনীন, সম্পূর্ণ স্ক্রিপ্ট খেলা। এটি 1 থেকে 22 জন খেলোয়াড়ের জন্য রিয়েলটাইম 3D ফুটবল, এআই সতীর্থদের সাথে, একটি ফ্লাডলাইট স্টেডিয়াম, অনলাইন লবি, ভয়েস এবং টেক্সট চ্যাট, রিপ্লে, একটি লিডারবোর্ড, অর্জন এবং নয়টি ভাষা একটি বাস্তব গেম কিভাবে ইঞ্জিন ব্যবহার করে তা দেখানোর জন্য এই পৃষ্ঠাটি ধাপে ধাপে আলাদা করে। প্রতিটি ধাপে জড়িত ইঞ্জিন মডিউলগুলির নাম এবং গেমের উত্সের লিঙ্কগুলি, যেখানে আপনি পড়তে পারেন৷ সম্পূর্ণ কোড।

এই ওয়াকথ্রু ইঞ্জিনের জন্য লেখা 1.41.0, সর্বশেষ রিলিজ. দেখানো প্রতিটি কল তালিকাভুক্ত করা হয় মধ্যে ইঞ্জিন API রেফারেন্স. পড়ুন ইঞ্জিন টিউটোরিয়াল আপনি যদি এখনও একটি স্ক্রিপ্ট গেম তৈরি না করে থাকেন তবে প্রথমে।

সোর্স লিঙ্ক পয়েন্ট এ কমিট 33bd9bd. যে কমিট এ গেম পিন ইঞ্জিন 1.39.0 সঙ্গে engine.minor=39. এটি নতুন কিছু ব্যবহার করে, তাই এটি 1.41.0 এ অপরিবর্তিত রান; এটি সরানো একটি এক লাইন পরিবর্তন engine.version (দেখুন ধাপ 12).

খেলার আকৃতি

পথ ভূমিকা
starhermit.txt ম্যানিফেস্ট: নাম, ইঞ্জিন পিন, সার্ভার স্ক্রিপ্ট, নিয়ন্ত্রণ, ক্ষমতা
server.js এক ম্যাচ সিমুলেশন: প্ল্যাটফর্ম দ্বারা অনুমোদিত সার্ভার হিসাবে চালিত, এবং অফলাইন অনুশীলন এবং পূর্বাভাসের জন্য ক্লায়েন্ট দ্বারা লোড করা হয়
engine/src/main.ts এন্ট্রি মডিউল: লাইফসাইকেল কলব্যাক এবং স্ক্রিন স্টেট মেশিন
engine/src/match.ts, logic/ ম্যাচ ফ্লো, নেটকোড, ইন্টারপোলেশন এবং পূর্বাভাস
engine/src/world/ থ্রিডি দৃশ্যে স্টেডিয়াম, ফুটবলার, বল ও ভিড়
engine/src/screens/, hud.ts মেনু (starhermit:ui) এবং ইন-ম্যাচ HUD (starhermit:draw)
engine/src/net.ts, platform.ts, chat.ts, voice.ts StarHermit প্ল্যাটফর্মের সাথে কথা বলে সবকিছু
engine/src/audio.ts, i18n.ts, quality.ts শব্দ, ভাষা এবং গ্রাফিক্স স্তর
assets/, sfx/ ছবি, স্ট্রিং টেবিল এবং সাউন্ড ক্লিপ

1. প্রকাশ

starhermit.txt ফোল্ডারটিকে একটি স্ক্রিপ্ট গেম তৈরি করে এবং সার্ভার স্ক্রিপ্ট এবং নিয়ন্ত্রণগুলিও ঘোষণা করে:

name=Football
launch=index.html
server=server.js
control.up=KeyW+ArrowUp | Run forward
control.shoot=Space+KeyJ | Shoot (hold) / tap to pass
control.tackle=KeyK | Slide tackle / pressure
engine.api=1
engine.entry=engine/src/main.ts
engine.version=1.39.0
engine.minor=39
engine.capabilities=platform,voice,clipboard,storage
engine.gamepad.shoot=West+RightTrigger
engine.gamepad.pass=South
  • launch=index.html লোডার পাতা যে starhermit package --web লেখে এটা খেলা খেলে পিন করা রিলিজের ওয়েব রানটাইমে ব্রাউজারে।
  • server=server.js প্ল্যাটফর্মের প্রামাণিক ম্যাচ স্ক্রিপ্ট (ধাপ 6)।
  • control.* এবং engine.gamepad.* লাইন সংজ্ঞায়িত কর্ম. রানটাইম তাদের সাথে কী এবং প্যাড আবদ্ধ করে, এবং খেলোয়াড়রা রানটাইমের বিকল্প মেনুতে সেগুলিকে রিবাইন্ড করে। গেমটি কখনই গেমপ্লের জন্য একটি কী নাম দেয় না।
  • engine.capabilities প্ল্যাটফর্মের জন্য জিজ্ঞাসা করে (রুম, সকেট, লিডারবোর্ড, রিপ্লে, চ্যাট), ভয়েস, ক্লিপবোর্ড (আমন্ত্রণ লিঙ্ক) এবং স্টোরেজ (সেটিংস)। রানটাইম তাদের বাইরে কল প্রত্যাখ্যান.

সম্পূর্ণ কী তালিকা আছে দ starhermit.txt প্রকাশ.

2. এন্ট্রি মডিউল এবং ফ্রেম লুপ

engine/src/main.ts মডিউল সুযোগে রেন্ডারার সেট আপ করে, তারপর থেকে চারটি লাইফসাইকেল কলব্যাক নিবন্ধন করে starhermit:engine:

import { frame, onFixedUpdate, onRender, onStart, onUpdate, setFixedRate } from "starhermit:engine";
import { ACESFilmicToneMapping, PCFSoftShadowMap, PerspectiveCamera, renderer, scene } from "starhermit:scene";

const camera = new PerspectiveCamera(55, 16 / 9, 0.1, 800);
renderer.camera = camera;
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = PCFSoftShadowMap;
renderer.toneMapping = ACESFilmicToneMapping;

onStart(() => {
  setFixedRate(60);
  loadLanguages(); // string tables (step 10)
  sim();           // evaluate server.js once (step 6)
  menuScene.start(); // an AI-vs-AI match behind the menu
  // … platform listeners, settings listeners, invite polling
});

onFixedUpdate((step) => {
  if (match) match.fixedStep(step);
  else if (!replay) menuScene.fixedStep(step);
});

onUpdate((delta) => {
  pollQuality();
  if (match) match.update(Math.min(delta, 0.1));
  // … replay viewer or menu backdrop
});

onRender(() => {
  const fr = frame();
  if (Math.abs(camera.aspect - fr.width / fr.height) > 1e-6) {
    camera.aspect = fr.width / fr.height;
    camera.updateProjectionMatrix();
  }
  hud.draw();
  // … chat, in-match menu or the menu screens
});

অনুলিপি করার প্যাটার্ন:

  • সিমুলেশন সঞ্চালিত হয় onFixedUpdate, একটি নির্দিষ্ট 60 Hz এ।
  • প্রতি-ফ্রেমে লজিক চলে onUpdate, সঙ্গে delta আটকানো যাতে একটি স্থবির ফ্রেম তৈরি না হয় খেলোয়াড়রা লাফ দেয়।
  • অঙ্কন চলে onRender. প্রতিটি কলব্যাক শুধুমাত্র একটি আছে, তাই main.ts ভক্তদের আউট বর্তমান পর্দা: মেনু, লবি, ম্যাচ, রিপ্লে বা ফলাফল।

3. 3D বিশ্ব: starhermit:scene

স্টেডিয়াম, ফুটবলার, বল এবং কর্মকর্তারা সাধারণ থ্রি.জেএস-স্টাইলের বস্তু starhermit:scene: Mesh, Group, MeshStandardMaterial, CylinderGeometry, Sprite, CanvasTexture এবং তাই তিন.js থেকে পোর্ট করা কোড বেশিরভাগ কাজ করে অপরিবর্তিত পড়ার মতো কিছু বিবরণ:

  • world/stadium.ts পিচ, স্ট্যান্ড, ফ্লাডলাইট এবং কুয়াশা তৈরি করে। এটি পোস্ট প্রভাব সেট করে (renderer.bloom, renderer.grade, renderer.antialias) এবং প্রতিটি গ্রাফিক্স স্তরের জন্য ছায়া।
  • world/environment.ts দিয়ে একটি পরিবেশ মানচিত্র তৈরি করে PMREMGenerator থেকে a DataTexture.
  • world/crest.ts এবং world/nametags.ts একটি উপর দলের ক্রেস্ট এবং ভাসমান ডাকনাম আঁকা starhermit:canvas OffscreenCanvas, তারপর তাদের হিসাবে ব্যবহার করুন CanvasTextures এবং Sprites.

4. হাজার হাজার চলমান অংশ: starhermit:world

22 জন ফুটবলারকে যুগ্মভাবে অ্যানিমেট করা, প্লাস হাজার হাজার ভিড়ের সদস্য, খুব ধীর হবে নেটিভ ইন্টারপ্রেটারে প্রতি-অবজেক্ট স্ক্রিপ্ট। ফুটবল যে কাজ করে starhermit:world টেবিল (টাইপ করা কলামের সারি) এবং কার্নেল (রানটাইমটি নেটিভভাবে প্রতিটি সারির উপর চলে)

import { kernel, schedule, table } from "starhermit:world";

const crowd = table("crowd", CROWD_ROWS, {
  bx: "f32", by: "f32", bz: "f32", ph: "f32", fr: "f32", av: "f32",
  q: "quat", s: "f32", sy: "f32", x: "f32", y: "f32", z: "f32",
});
const sway = kernel(crowd, (r, u: { t: number; amp: number; spd: number; sway: number; shake: number }) => {
  const j = Math.sin(u.t * u.spd * r.fr + r.ph);
  r.y = r.by + (j > 0 ? j * j : 0) * u.amp * r.av;
  // …
});
// An eighth of the crowd each frame: the work is sliced across frames.
const swayRun = schedule.update(sway, { t: 0, amp: 0, spd: 0, sway: 0, shake: 0 }, { slices: 8 });

ফুটবলার ঢুকে পড়ে world/rig.ts একই পদ্ধতি ব্যবহার করুন। ক rigs টেবিলে প্রতিটি ফুটবলারের অ্যানিমেশন অবস্থা রয়েছে। ক joints টেবিল সঙ্গে a ref:rigs কলাম, প্রতি রিগ 15 জয়েন্ট ধারণ করে, এবং বাঁধাই এটি থেকে দৃশ্য নোডগুলি চালান। দুটি কার্নেল পরে নির্ধারিত onUpdate ভঙ্গি গণনা করে, এবং রানটাইম নোড লিখে নিজেকে রূপান্তরিত করে। প্রতি ফুটবলার স্ক্রিপ্টের কাজ প্রায় এক ডজন সংখ্যার ফ্রেমে আসে।

5. ইনপুট: অ্যাকশন, টাচ এবং গেমপ্যাড

engine/src/input.ts এর মাধ্যমে ম্যানিফেস্টের কাজ পড়ে starhermit:input:

  • value(action) একটি ক্রিয়া কতদূর অনুষ্ঠিত হয় তা ফেরত দেয় (আন্দোলন হল value("up") - value("down")). onAction প্রেস এবং রিলিজ প্রান্ত প্রদান করে।
  • মাউস লুক ব্যবহার করে requestPointerLock, onPointerDelta এবং onPointerLockChange. ক্যামেরার ডান লাঠি থেকে আসে gamepads(), এবং vibrate একটি ছোট হ্যাপটিক টিক দেয়।
  • টাচ স্ক্রিনে (primaryPointer() মোটা) setTouchControls একটি জয়স্টিক দেখায় এবং রানটাইম দ্বারা আঁকা শ্যুট/পাস/ট্যাকল বোতাম। বোতামগুলি একই ক্রিয়াতে আবদ্ধ:
setTouchControls([
  { kind: "stick", up: "up", down: "down", left: "left", right: "right", anchor: "bottom-left", offset: [90, 90], radius: 66 },
  { kind: "button", action: "shoot", label: T("SHOOT").slice(0, 16), anchor: "bottom-right", offset: [66, 66], radius: 46 },
  // … PASS and TACKLE
]);

screens/controls.ts বর্তমানের তালিকা করে bindings() এবং কল requestRebind. রানটাইম তখন নতুন কী ক্যাপচার করে বা বোতাম

6. ক্লায়েন্ট এবং সার্ভারের জন্য একটি সিমুলেশন: starhermit:script

server.js কোনো আমদানি ছাড়াই একটি সাধারণ ক্লাসিক স্ক্রিপ্ট, Date বা Math.random, প্ল্যাটফর্মের স্যান্ডবক্স হিসাবে প্রয়োজন এটি দুটি বিশ্বকে সংজ্ঞায়িত করে:

  • globalThis.game প্ল্যাটফর্ম এন্ট্রি পয়েন্ট ধরে রাখে (createSession, onPlayerMessage, onTick) এবং স্ট্যাটিক ঘোষণা প্রকাশের সময় পড়া হয়:

    globalThis.game = {
  tickRateHz: 30,
  replays: true,
  achievements: [
    { key: 'debut', name: 'Debut', description: 'Finish your first match.', points: 10 },
    { key: 'hat-trick', name: 'Hat-Trick', description: 'Score three goals in one match.', points: 50 },
    // …
  ],
  createSession: function (ctx) { /* seats, AI, seed from ctx.random */ },
  // …
};

  • globalThis.FootballSim একই সিমুলেশন ধারণ করে (createMatch, stepMatch, AI) এর জন্য ক্লায়েন্ট

ক্লায়েন্ট একই ফাইলটি তার নিজস্ব রাজ্যে লোড করে loadClassic থেকে starhermit:script (engine/src/sim.ts):

import { loadClassic } from "starhermit:script";

loadClassic("server.js");
const S = (globalThis as unknown as { FootballSim?: FootballSimApi }).FootballSim;

অফলাইন অনুশীলন পদক্ষেপ FootballSim স্থানীয়ভাবে 60 Hz-এ AI সহ প্রতিটি অন্য সিটে। অনলাইন, দ প্ল্যাটফর্ম চলে server.js অনুমোদিতভাবে 30 Hz এ। গেমটি কখনই এর দুটি কপি বজায় রাখে না নিয়ম

7. অনলাইন ম্যাচ: রুম এবং গেম সকেট

লবি প্ল্যাটফর্মের কক্ষগুলি ব্যবহার করে starhermit:platform (screens/lobby.ts):

import * as P from "starhermit:platform";

// Quick play: join any open room, or open one.
let room = await P.rooms.quickJoin();
if (!room) {
  room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, metadata: { game: "football" } });
  room = await P.rooms.open(room.id);
}

// Ranked solo vs AI: every other seat is an AI player, so starting begins the match at once.
room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, aiPlayers: 2 * teamSize - 1, metadata: { game: "football" } });
room = await P.rooms.start(room.id);

বন্ধুরা, আমন্ত্রণ এবং আসন পরিবর্তনের মধ্য দিয়ে যায় P.friends.list, P.rooms.invite, P.rooms.acceptInvite এবং P.rooms.seat. P.rooms.mine একজন খেলোয়াড়কে তাদের ছেড়ে যাওয়া ম্যাচে পুনরায় যোগদান করতে দেয়।

ম্যাচ শুরু হলেই, engine/src/net.ts দিয়ে গেম সকেট খোলে P.connectGame(sessionId):

  • এটি 30 Hz এ ইনপুট পাঠায় sendInput.
  • এটি একটি সম্পূর্ণ স্ন্যাপশট জন্য জিজ্ঞাসা sendCommand({ type: "sync" }) প্রতিটি খোলা এবং উপর resumed.
  • এটা জন্য শোনে game (স্ন্যাপশট এবং ঘটনা), achievement এবং stopped. stopped কেন রিপোর্ট সকেট বন্ধ: সাইন আউট, আপডেট শর্তাবলী, বা ম্যাচ চলে গেছে।

রানটাইম প্লেয়ারের শংসাপত্র ধারণ করে এবং নিজে থেকেই পুনরায় সংযোগ করে, তাই গেমটি কোনও টোকেন পরিচালনা করে না এবং কোন পুনঃপ্রচার লুপ নেই।

logic/interp.ts অভিযোজিত ইন্টারপোলেশন সহ সার্ভারের স্ন্যাপশটগুলিকে মসৃণ করে। logic/predict.ts স্থানীয় ফুটবলারের গতিবিধি ভবিষ্যদ্বাণী করে এবং প্রতিটি স্ন্যাপশটের দিকে তা সংশোধন করে। ভবিষ্যদ্বাণী প্রভাবিত করে শুধুমাত্র যা আঁকা হয়; সার্ভার কর্তৃত্বপূর্ণ থাকে।

8. প্ল্যাটফর্ম বাকি

বৈশিষ্ট্য কল উৎস
সাইন-ইন করা প্লেয়ার, সাইন-ইন, সেশন শেষ P.player(), P.onPlayerChange, P.requestSignIn, P.onSessionEnded platform.ts, main.ts
লিডারবোর্ড P.leaderboards.list, P.leaderboards.entries (বোর্ড ঘোষিত leaderboards.json) screens/leaderboard.ts
অর্জন মধ্যে ঘোষিত server.js, পূর্ণ সময় পুরস্কার, সঙ্গে তালিকাভুক্ত P.achievements.list screens/achievements.ts
রিপ্লে game.replays: true মধ্যে server.js; P.replays.list, P.replays.get screens/replays.ts, replayView.ts
টেক্সট চ্যাট P.sessions.get (ম্যাচের কথোপকথন), P.chat.messages, P.chat.subscribe, P.chat.post chat.ts
ভয়েস চ্যাট P.voice.join, P.voice.setVolume এবং P.voice.setPan ফুটবলারদের মধ্যে দূরত্ব দ্বারা, P.voice.setMuted voice.ts
আমন্ত্রণ লিঙ্ক P.inviteLink এবং clipboard থেকে starhermit:engine platform.ts

প্রতিটি কল একটি দিয়ে প্রত্যাখ্যান করতে পারে PlatformError. ফুটবল অনলাইন বৈশিষ্ট্যগুলিকে সর্বোত্তম প্রচেষ্টা হিসাবে বিবেচনা করে: ক ব্যর্থতা দেখায় "অনলাইন অনুপলব্ধ" অথবা নীরবতা ফিরে পড়ে, এবং খেলা শেষ হয় না. সাইন আউট, গেমটি এখনও অফলাইন অনুশীলন অফার করে।

9. মেনু এবং HUD: starhermit:ui, starhermit:draw, starhermit:canvas

  • মেনু (screens/*.ts, ইন-ম্যাচ মেনু এবং ডায়ালগ ইন main.ts) ব্যবহার করুন starhermit:ui, ইঞ্জিনের তাৎক্ষণিক-মোড UI। উইজেট প্রতিটি বলা হয় ফ্রেম থেকে onRender, এবং ui.setTheme তাদের খেলার রং দেয়। রানটাইম এর নিজস্ব বিকল্প এর সাথে মেনু খোলে openMenu.
  • HUD ( hud.ts) স্কোরবোর্ড, ঘড়ি এবং মার্কারগুলি আঁকে starhermit:draw: draw.roundRect, draw.text এবং draw.image (একটি ক্রেস্ট ক্যানভাস), দৃশ্যের উপর কল অর্ডারে।
  • ছবি সঙ্গে লোড করা হয় createImageBitmap থেকে starhermit:canvas, উদাহরণস্বরূপ মেনুর মূল শিল্প।

10. সেটিংস এবং ভাষা: starhermit:storage, স্ট্রিং

  • প্রতি-প্লেয়ার সেটিংস (নিঃশব্দ, ভয়েস, ভাষা, গ্রাফিক্স ওভাররাইড) লাইভ ইন settings থেকে starhermit:storage. এগুলি ডিভাইসে এবং অ্যাকাউন্টে রাখা হয়। settings.onChange অন্য ডিভাইসে করা পরিবর্তন প্রয়োগ করে।
  • i18n.ts লোড assets/strings.json ইঞ্জিনের মধ্যে strings টেবিল (strings.load, strings.t, strings.setLanguage) এটি সংরক্ষিত পছন্দ থেকে ভাষা বেছে নেয়, তারপর প্লেয়ারের StarHermit ভাষা, তারপর ডিভাইসের (preferences). l10n/font.ts সঙ্গে স্ক্রিপ্ট ফন্ট লোড FontFace যে ভাষার প্রয়োজন তাদের জন্য।

11. সাউন্ড এবং গ্রাফিক্স লেভেল

  • audio.ts এর সাথে একটি ওয়েব অডিও গ্রাফ তৈরি করে starhermit:audio:
    • লেখক ক্লিপ তালিকাভুক্ত করা হয় sfx/manifest.json (সহ পড়ুন files.readJson).
    • একটি সিনথেসাইজার ক্লিপ ছাড়াই যেকোন ইভেন্টকে কভার করে, প্লাস ভিড় এবং স্টেডিয়াম রিভার্ব।
    • স্বল্পস্থায়ী নোডগুলি শেষ হওয়ার সাথে সাথে প্রকাশ করা হয়, কারণ হোস্ট গ্রাফটি আবদ্ধ থাকে।
  • quality.ts প্লেয়ারের গ্রাফিক্স স্তর অনুসরণ করে (frame().level, levelSettings) ছায়া, পুষ্প এবং অ্যান্টি-আলিয়াসিং সেই স্তর অনুসরণ করুন। গেমের নিজস্ব বিষয়বস্তু (পিচের বিস্তারিত, ভিড়ের ঘনত্ব, কণা) শীর্ষে প্রতি খেলোয়াড় ওভাররাইড আছে।

12. প্যাকেজ, পরীক্ষা এবং প্রকাশ

  • টাইপ-চেক সঙ্গে tsc -p engine. engine/tsconfig.json রিলিজ এর অন্তর্ভুক্ত starhermit.d.ts এবং সেট "lib": ["ES2022"], "types": [] এবং "allowImportingTsExtensions": true.
  • পরীক্ষা। npm test রান server.js রিগ্রেশন পরীক্ষা। engine/tests/run.sh যুক্তি চালায় নোডের অধীনে পরীক্ষা (ইন্টারপোলেশন, ভবিষ্যদ্বাণী, ভঙ্গি, লবি)। starhermit <folder> --check প্যাকেজ যাচাই করে এবং হেডলেস 120 ফ্রেম চালায়।
  • প্যাকেজ। starhermit package --web . পুনর্লিখন index.html এবং starhermit-files.json, যা প্রতিটি পরিবর্তনের সাথে প্রতিশ্রুতিবদ্ধ।
  • প্রকাশ করুন। গেমটি StarHermit-এ এর রিপোজিটরি URL থেকে যোগ করা হয়েছে। প্ল্যাটফর্ম পড়ে starhermit.txt, রান server.js ম্যাচ স্ক্রিপ্ট হিসাবে এবং থেকে লিডারবোর্ড তৈরি করে leaderboards.json.
