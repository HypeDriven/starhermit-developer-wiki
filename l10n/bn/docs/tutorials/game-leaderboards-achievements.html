টিউটোরিয়াল: আপনার গেমের জন্য লিডারবোর্ড এবং কৃতিত্ব

আপনি যদি StarHermit-এ একটি গেমের মালিক হন তবে আপনি এর প্রকাশক। দিতে পারেন লিডারবোর্ড (উচ্চ স্কোর, দ্রুততম রান, দীর্ঘতম ধারা) এবং অর্জন একটি প্রকাশক অ্যাকাউন্ট বা কোনো বিশেষ ছাড়া অনুমতি খেলার মালিকানা সবই লাগে।

এই পৃষ্ঠায় সবকিছুর পিছনে একটি নিয়ম আছে: আপনি তাদের সংজ্ঞায়িত করেন, আপনার গেমের সার্ভার লিখে তাদের একজন খেলোয়াড়ের ক্লায়েন্ট কখনই একটি স্কোর পোস্ট করতে পারে না বা এর জন্য একটি কৃতিত্ব দাবি করতে পারে না এবং আপনার সার্ভারকে অবশ্যই গেমপ্লে যাচাই করতে হবে যা তাদের উপার্জন করে। সরাসরি API দাখিল প্রত্যাখ্যান একাই একটি পরিবর্তিত ক্লায়েন্টকে গেম ইভেন্ট আবিষ্কার করা থেকে বিরত করে না। সেজন্য গেমটির একটি প্রামাণিক ব্যাকএন্ড প্রয়োজন: ক server= স্ক্রিপ্ট বা ক container.image= মধ্যে starhermit.txt.

এই টিউটোরিয়ালটি একটি ছোট আর্কেড গেমের জন্য উভয়ই তৈরি করে, স্টার কালেক্টর: একটি রান শেষ হয় যখন প্লেয়ার ক্র্যাশ, এবং এটির মোট পয়েন্ট এবং একটি রান টাইম রয়েছে।

  1. আপনি শুরু করার আগে
  2. লিডারবোর্ড তৈরি করুন
  3. অর্জনগুলি তৈরি করুন
  4. স্কোর পোস্ট করুন এবং আপনার স্ক্রিপ্ট থেকে কৃতিত্ব আনলক করুন
  5. একটি পাত্র থেকে একই
  6. আপনার খেলা তাদের দেখান
  7. তাদের দেখাশোনা

আপনি শুরু করার আগে

আপনার প্রয়োজন:

  • একটি সার্ভার ব্যাকএন্ড সঙ্গে একটি খেলা যেটি আপনার মালিকানা: আপনি আপনার নিজস্ব সংগ্রহস্থল থেকে যোগ করেছেন, আপলোড করেছেন৷ একটি ফোল্ডার হিসাবে, বা দাবি করেছে. একটি ব্রাউজার-শুধু গেম উত্তর 409 প্রতিটি কলে নীচে, কেন বলছে একটি বার্তা সহ।
  • একটি সম্পূর্ণ ব্যবহারকারী অ্যাক্সেস টোকেন, একটি গেমের লঞ্চ টোকেন নয়৷ লঞ্চ টোকেন গেইম এর বেড়া দেওয়া হয় প্লেয়ার পৃষ্ঠ এবং পৌঁছতে পারে না /me/....
  • আপনার খেলার আইডি (এটাও তার <id>.starhermit.com ঠিকানা):
ACCESS_TOKEN='your-full-user-access-token'
API=https://api.starhermit.com

curl -s "$API/api/v1/me/github-games" -H "Authorization: Bearer $ACCESS_TOKEN" |
  jq '.[] | {id, displayName, gameSlug}'

GAME_ID='the-id-from-above'

gameSlug আপনার ক্লায়েন্ট যাকে গেম বলে /api/v1/games/{slug}/.... আপনি যোগ করা প্রতিটি খেলা বা আপলোড করা একটি, শুধুমাত্র ব্রাউজার-গেম অন্তর্ভুক্ত, তাই এটি আপনাকে বলে না যে একটি সার্ভার আছে কিনা: GET /api/v1/games/{slug} করে - এটা উত্তর দেয় 404 যতক্ষণ না গেমটির ব্যাকএন্ড থাকে।

1. লিডারবোর্ড তৈরি করুন

স্টার কালেক্টর দুটি বোর্ড পায়: সর্বাধিক পয়েন্ট (উচ্চ হলে ভাল) এবং দ্রুততম দৌড় 100 পয়েন্টে (নিম্ন) ভাল)।

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/leaderboards" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "high-score", "name": "High score",
        "scoreType": "integer", "sortDirection": "desc",
        "minScore": 0, "maxScore": 1000000 }'

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/leaderboards" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "fastest-100", "name": "Fastest to 100",
        "scoreType": "time-ms", "sortDirection": "asc" }'

প্রতিটি কল ফিরে আসে 201 এবং বোর্ড, তার সহ id এবং key. আপনার সার্ভার ব্যবহার করে চাবি, তাই সাবধানে এটি নির্বাচন করুন. চাবি, scoreType এবং sortDirection পরে পরিবর্তন করা যাবে না।

scoreType গ্রহণ করে
integer পূর্ণ সংখ্যা
decimal যেকোনো সংখ্যা
time-ms সম্পূর্ণ, অ নেতিবাচক মিলিসেকেন্ড

সেট minScore/maxScore আপনার গেম আসলে কি তৈরি করতে পারে। তাদের বাইরে একটি স্কোর বাদ পড়েছে, যা আপনার নিজের সার্ভার যুক্তিতে একটি বাগ বিরুদ্ধে একটি সস্তা গার্ড.

2. অর্জনগুলি তৈরি করুন

আপনি দুটি উপায়ে একটি গেমের কৃতিত্ব দিতে পারেন এবং আপনি উভয়ই একবারে ব্যবহার করতে পারেন:

কোডে ঘোষণা করা হয়েছে API এর মাধ্যমে তৈরি করা হয়েছে
যেখানে game.achievements আপনার স্ক্রিপ্টে, বা /describe আপনার পাত্রে POST /me/github-games/{id}/achievements
দ্বারা পরিবর্তিত একটি আপডেট প্রকাশ করা হচ্ছে একটি API কল, অবিলম্বে কার্যকর হচ্ছে
জন্য ভাল অর্জন আপনার কোড চারপাশে নির্মিত হয় রিলিজ ছাড়াই কিছু যোগ করা বা রিওয়ার্ড করা

উভয় ধরনেরই একইভাবে আনলক করা হয়, আপনার সার্ভার চাবি ফেরত দিয়ে। এখানে আমরা দুটি মাধ্যমে তৈরি করি API:

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "century", "name": "Century",
        "description": "Collect 100 stars in one run.", "points": 10 }'

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "untouchable", "name": "Untouchable",
        "description": "Reach 500 points without losing a shield.",
        "points": 50, "secret": true }'

A secret কৃতিত্ব খেলোয়াড়দের কাছ থেকে লুকিয়ে থাকে যতক্ষণ না তারা এটি আনলক করে।

আপনার কোড ঘোষণা করা অর্জনগুলি সহ গেমটির সমস্ত কিছু দেখতে, তাদের তালিকা করুন:

curl -s "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" | jq '.[] | {key, origin, unlocks}'

origin হয় declared আপনার কোড থেকে অর্জনের জন্য এবং owner আপনার তৈরি করা অর্জনের জন্য এখানে আপনি শুধুমাত্র সম্পাদনা এবং মুছে ফেলতে পারেন owner বেশী ক declared একটি আপনার পরবর্তী দ্বারা ফিরে করা হবে আপডেট, তাই API প্রত্যাখ্যান করে (409) এবং আপনি পরিবর্তে কোডে এটি পরিবর্তন করুন।

3. স্কোর পোস্ট করুন এবং আপনার স্ক্রিপ্ট থেকে কৃতিত্বগুলি আনলক করুন৷

আপনার স্ক্রিপ্ট তার রিটার্ন মান উভয় ধরনের ফলাফল রিপোর্ট. এটি যে কোনও হুক থেকে এটি করতে পারে: createSession, onPlayerMessage বা onTick.

  • scores: বোর্ড কী → প্লেয়ার আইডি → নম্বর।
  • achievements: প্লেয়ার আইডি → আনলক করার জন্য কী।
'use strict';

function endRun(ctx, s, playerId) {
  var run = s.runs[playerId];
  var scores = { "high-score": {} };
  scores["high-score"][playerId] = run.points;
  if (run.reached100At) {
    scores["fastest-100"] = {};
    scores["fastest-100"][playerId] = run.reached100At - run.startedAt;
  }

  var unlocked = [];
  if (run.stars >= 100) unlocked.push("century");
  if (run.points >= 500 && !run.lostShield) unlocked.push("untouchable");
  var achievements = {};
  achievements[playerId] = unlocked;

  run.over = true;
  return {
    ok: true,
    sessionState: s,
    scores: scores,
    achievements: achievements,
    broadcast: [{ to: [playerId], data: { type: "run-over", points: run.points } }]
  };
}

globalThis.game = {
  tickRateHz: 10,

  createSession(ctx) {
    var runs = {};
    ctx.players.forEach(function (p) {
      runs[p.id] = { points: 0, stars: 0, lostShield: false, startedAt: ctx.now,
                     reached100At: null, over: false };
    });
    return { ok: true, sessionState: { runs: runs } };
  },

  onPlayerMessage(ctx) {
    var s = ctx.sessionState;
    var from = ctx.message.from;
    var run = s.runs[from];
    var msg = ctx.message.data || {};
    if (!run || run.over) return { ok: false, error: "No run in progress" };

    // The client reports what happened; the script decides what it is worth.
    if (msg.type === "collect") {
      run.stars += 1;
      run.points += 5;
      if (run.points >= 100 && !run.reached100At) run.reached100At = ctx.now;
      return { ok: true, sessionState: s };
    }
    if (msg.type === "shield-lost") {
      run.lostShield = true;
      return { ok: true, sessionState: s };
    }
    if (msg.type === "crash") return endRun(ctx, s, from);
    return { ok: false, error: "Unknown command" };
  },

  onTick(ctx) { return { ok: true }; }
};

আপনি কি জিনিস না পরিচালনা করতে হবে:

  • আরও খারাপ স্কোর। প্রতিটি খেলোয়াড় প্রতিটি বোর্ডে তাদের সেরা স্কোর রাখে, বোর্ডের দ্বারা বিচার করা হয় sortDirection. প্রতিটি রান রিপোর্ট করুন এবং প্ল্যাটফর্ম সেরা রাখে।
  • আনলক পুনরাবৃত্তি করুন. একজন প্লেয়ারের ইতিমধ্যেই আছে এমন কিছু আনলক করলে কিছুই হয় না, তাই চাবিটি ফেরত দিন যখনই শর্ত থাকে।
  • অন্য কারো আইডি। AI সহ যারা সেশনে নেই তাদের জন্য স্কোর এবং আনলক আসন, উপেক্ষা করা হয়।

অজানা কী, নিষ্ক্রিয় বোর্ড এবং রেঞ্জের বাইরের স্কোরগুলি নিঃশব্দে বাদ দেওয়া হয়। আপনার স্ক্রিপ্ট নম্বর পায় তাদের জন্য ত্রুটি, তাই একবার আপনার বোর্ড চেক করুন, হিসাবে অধ্যায় 4.

একটি বাস্তব খেলা সার্ভারের নিজস্ব প্রামাণিক অবস্থা থেকে পয়েন্ট এবং সময় কাজ করা উচিত, না বিশ্বাস collect বার্তা যেমন আছে। রিপোর্টিং দেখানোর জন্য এই উদাহরণটি সংক্ষিপ্ত রাখা হয়েছে। খেলা স্ক্রিপ্ট সম্পূর্ণ রিটার্ন-আকৃতির চুক্তি আছে।

3 খ. একটি পাত্র থেকে একই

একটি ধারক গেম তার নিয়ন্ত্রণ WebSocket এ একই দুটি জিনিস পাঠায়:

{ "type": "scores", "sessionId": "…",
  "scores": { "high-score": { "<userId>": 740 }, "fastest-100": { "<userId>": 41250 } } }

{ "type": "achievements", "sessionId": "…",
  "unlocks": { "<userId>": ["century"] } }

scores আপনার কন্টেইনার ফেরত আসা যেকোনো প্রতিক্রিয়া খামেও অন্তর্ভুক্ত করা যেতে পারে /sessions. দ একই নিয়ম প্রযোজ্য: শুধুমাত্র অংশগ্রহণকারী, সেরা স্কোর রাখা, অজানা কী উপেক্ষা করা হয়েছে। দেখুন কন্টেইনার গেম সার্ভার.

4. আপনার খেলা তাদের দেখান

আপনার ক্লায়েন্ট ইতিমধ্যেই ধারণ করা লঞ্চ টোকেন দিয়ে সবকিছু পড়ে। এখানে কিছুই প্রয়োজন নেই মালিকের টোকেন।

বোর্ড খুঁজুন.

const boards = await api(`/api/v1/games/${slug}/leaderboards`);
// [{ id, key: "high-score", name: "High score", sortDirection: "desc", ... }, ...]
const high = boards.find(b => b.key === "high-score");

শুধুমাত্র সক্রিয় বোর্ড তালিকাভুক্ত করা হয়.

একটি বোর্ড পড়ুন।

const page = await api(`/api/v1/leaderboards/${high.id}/entries?page=1&pageSize=10`);
// { items: [{ rank, username, score, ... }], total, page, pageSize }
const friends = await api(`/api/v1/leaderboards/${high.id}/entries?friendsOnly=true&pageSize=10`);

একটি জন্য time-ms বোর্ড, একটি সময় হিসাবে স্কোর ফর্ম্যাট করুন: 41250 → 0:41.25.

অর্জন।

  • GET /api/v1/games/{slug}/achievements খেলোয়াড়ের সাথে প্রতিটি অর্জনের তালিকা করে unlocked রাষ্ট্র অর্জিত না হওয়া পর্যন্ত গোপন থাকে।
  • আনলক নিজেই লাইভ আসে ws/v1/games হিসাবে {"type":"achievement","data":{key,name,description,points,...}}. এটা হয়ে গেলে একটি টোস্ট দেখান। সকেট বন্ধ থাকার সময় লোডের তালিকায় কল আনলক করা কিছু ধরা পড়ে।

দেখুন অর্জন জন্য ফ্রেম

5. তাদের দেখাশোনা করুন

একটি বোর্ডের নাম পরিবর্তন করুন বা এর সীমানা পরিবর্তন করুন।

curl -s -X PUT "$API/api/v1/me/github-games/$GAME_ID/leaderboards/$BOARD_ID" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "name": "All-time high score", "maxScore": 2000000 }'

নতুন সীমা শুধুমাত্র নতুন স্কোরের জন্য প্রযোজ্য।

একটি বোর্ড অবসর কিন্তু তার স্কোর রাখা. পাঠান { "isActive": false }. বোর্ড গ্রহণ করা বন্ধ করে দেয় স্কোর করে এবং গেমের তালিকা থেকে অদৃশ্য হয়ে যায়। এর এন্ট্রি এখনও আইডি দ্বারা পড়া যাবে.

একটি সময়সূচীতে রিসেট করুন। একটা বোর্ড দাও "resetSchedule": "daily", "weekly" বা "monthly" (চালু তৈরি করুন, বা পরে দিয়ে PUT) এবং এটি প্রতিটি পিরিয়ড 00:00 UTC-এ শুরু হয় — a এর জন্য উপযুক্ত "এই সপ্তাহের সেরা" একটি সর্বকালের পাশে বোর্ড। আপনার স্ক্রিপ্টে কিছুই করার নেই: যথারীতি স্কোর রিপোর্ট করুন এবং প্রতিটি খেলোয়াড়ের একটি নতুন সময়ের প্রথম স্কোর গণনা করা হয়। দেখুন সময়সূচী রিসেট করুন.

হাতে একটি তাজা মরসুম শুরু করুন। একটি সময়সূচীর পরিবর্তে এক-অফ সিজনের জন্য, একটি নতুন বোর্ড তৈরি করুন (high-score-s2), এটিতে আপনার স্ক্রিপ্টটি নির্দেশ করুন এবং পুরানোটিকে অবসর দিন।

একটি বোর্ড মুছুন। DELETE .../leaderboards/{id} বোর্ড এবং এর সমস্ত এন্ট্রি সরিয়ে দেয়, এবং পূর্বাবস্থায় ফেরানো যাবে না।

একটি অর্জন সম্পাদনা করুন। PUT .../achievements/{achievementId} যে কোনটির সাথে name, description, icon, secret এবং points. চাবি কখনো পরিবর্তন হয় না।

একটি অর্জন মুছুন। এটি শুধুমাত্র আপনার তৈরি করা একজনের জন্য কাজ করে যা এখনও কেউ আনলক করেনি। অর্জিত অর্জন চিরস্থায়ী।

কোডে একটি অর্জন সরান। একই কী ঘোষণা করুন game.achievements এবং প্রকাশ করুন। দ ঘোষণা বিদ্যমান কৃতিত্ব দখল করে, এবং যে খেলোয়াড়রা এটি রাখে তারা।
