টিউটোরিয়াল: আপনার গেমে নিয়ন্ত্রণ যোগ করুন

StarHermit সংরক্ষণ করতে পারেন কী বাইন্ডিং আপনার গেমের জন্য: আপনি অ্যাকশন এবং তাদের ডিফল্ট কী ঘোষণা করেন, এবং প্রতিটি খেলোয়াড় তাদের পুনরায় বাঁধতে পারে। তাদের পছন্দ তাদের অনুসরণ করে যে কোনো মেশিনে তারা সাইন ইন করে। আপনার খেলা কন্ট্রোল API থেকে প্লেয়ারের বাইন্ডিং পড়ে এবং নিজের অফার করতে পারে "কী পুনরায় বাঁধা" পর্দা

যদি আপনার গেমটি নিয়ন্ত্রণ API কল করে এবং এটি পায়:

404 {"error":"This game declares no controls."}

প্ল্যাটফর্ম আছে কোন ঘোষিত কর্ম নির্মাণের জন্য এটি পরিবেশন করা হয়. আপনি API এ পাঠাতে পারবেন না কিছুই এটি ঠিক করুন: নিয়ন্ত্রণগুলি আপনার গেমে ঘোষণা করা হয়েছে starhermit.txt এবং যখন পড়ুন খেলা প্রকাশিত হয়। এই পৃষ্ঠাটি দেখায় কিভাবে তাদের ঘোষণা করতে হয়, তাদের প্রকাশ করতে হয়, তারা এসেছে কিনা তা পরীক্ষা করে দেখুন, এবং আপনার ক্লায়েন্ট থেকে তাদের ব্যবহার করুন.

1. কর্ম ঘোষণা

একটি যোগ করুন control.<action>= ক্রিয়া প্রতি লাইন starhermit.txt:

name=Space Hopper
launch=index.html

control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.jump=Space+KeyW | Jump
control.fire=KeyJ | Fire
control.pause=Escape | Pause

প্রতিটি লাইন তিনটি অংশ আছে:

control.<action>=<code>[+<code>...][ | <label>]
অংশ নিয়ম
<action> অ্যাকশনের জন্য আপনার গেমের নাম: ছোট হাতের অক্ষর, অঙ্ক এবং 1-32টি অক্ষর _ (move_left, না move-left) ম্যানিফেস্ট প্রতি অনন্য।
<code> A KeyboardEvent.code মান, যেমন KeyA, ArrowLeft, Space, Digit1, ShiftLeft, Enter বা Escape. একই ক্রিয়াকলাপের জন্য 1-4 কোডে যোগ দিন +.
<label> ঐচ্ছিক। রিবাইন্ডিং স্ক্রিনে দেখানো হয়েছে; সর্বাধিক 64টি অক্ষর। অ্যাকশন নামের ডিফল্ট।

জানার বিষয়:

  • ব্যবহার করুন code, না key. লিখুন KeyA, না a, এবং Space, না " ". কোডগুলি শারীরিক নাম দেয় কী, তাই বাইন্ডিং যেকোন কীবোর্ড লেআউটে কাজ করে। প্ল্যাটফর্ম শুধুমাত্র চেক করে যে একটি কোড 1-32 অক্ষর এবং অঙ্ক, তাই a বা space গৃহীত হয় কিন্তু কোন কী কখনও এটি উত্পাদন করে না। বানান এবং কেস হুবহু মিলতে হবে।
  • একটি কী একটি কর্মের অন্তর্গত। একটি পূর্ববর্তী লাইন দ্বারা ইতিমধ্যে ব্যবহৃত একটি কোড পরবর্তী লাইন তৈরি করে অবৈধ
  • 32টি অ্যাকশন পর্যন্ত খেলা প্রতি 32-এর পরের লাইনগুলি উপেক্ষা করা হয়।
  • অর্ডার রাখা হয়। এপিআই থেকে অ্যাকশনগুলি ম্যানিফেস্ট ক্রমে ফিরে আসে, তাই সেগুলিকে তালিকাভুক্ত করুন৷ আপনার সেটিংস স্ক্রীন তাদের দেখানো উচিত.
  • একটি অবৈধ লাইন নিঃশব্দে এড়িয়ে গেছে। গেমটি এখনও প্রকাশ করে। যদি প্রতিটি লাইন অবৈধ হয়, গেমটির কোনো নিয়ন্ত্রণ নেই এবং API উত্তর 404. প্রকাশের পর চেক করুন.

2. তাদের প্রকাশ করুন

ঘোষণাপত্র পড়া হয় যখন খেলা প্রকাশিত হয়. সম্পাদনা starhermit.txt আপনার সংগ্রহস্থলে অথবা ডিস্কে কিছুই পরিবর্তন হয় না যতক্ষণ না আপনি এটি ধারণকারী একটি বিল্ড প্রকাশ করেন:

কিভাবে আপনার খেলা প্রকাশিত হয় কি নতুন নিয়ন্ত্রণ লাইভ করে তোলে
একটি GitHub সংগ্রহস্থল থেকে আপনার পরবর্তী স্থাপনা. পরিবর্তনটি চাপুন, তারপর সর্বশেষ সংস্করণ স্থাপন করুন (স্থাপিত সংস্করণ আপডেট করুন ড্যাশবোর্ডে, বা PUT /api/v1/me/github-games/{id}/deployment).
আপলোড করা ফোল্ডার বা বান্ডিল একটি নতুন বিল্ড আপলোড করুন (POST /api/v1/me/github-games/{id}/bundle, বা ws/v1/game-upload) যার starhermit.txt লাইন আছে.
একটি নতুন গেম যোগ করা হচ্ছে প্রথম আপলোড বা জমা অবিলম্বে তাদের পড়া.

একটি প্রতিস্থাপন আপলোড তার নিজস্ব ম্যানিফেস্ট থেকে আপনার নিয়ন্ত্রণগুলিকে পুনরুদ্ধার করে৷ প্রতিটি সরান control.* লাইন এবং খেলা নেই. ক ?mode=merge যে প্যাচ কোন বহন করে starhermit.txt বর্তমান নিয়ন্ত্রণ রাখে।

খেলোয়াড়দের নিজস্ব পুনর্বিন্যাস একটি নতুন বিল্ড বেঁচে. একজন খেলোয়াড়ের সংরক্ষিত বাইন্ডিং একটি অ্যাকশনের জন্য যা না আর বিদ্যমান উপেক্ষা করা হয়.

3. তারা এসেছে চেক করুন

নীচের প্রতিটি শেষ পয়েন্ট একটি সম্পূর্ণ ব্যবহারকারী টোকেন বা আপনার গেমের লঞ্চ টোকেনের সাথে কাজ করে। {slug} আপনার গেমের স্লাগ: লঞ্চ টোকেন game_scope দাবি, বা gameSlug মধ্যে GET /api/v1/me/github-games.

curl -s "https://api.starhermit.com/api/v1/games/$SLUG/controls" \
  -H "Authorization: Bearer $TOKEN" | jq

{
  "actions": [
    { "action": "left",  "label": "Move left",  "defaultCodes": ["KeyA", "ArrowLeft"],  "codes": ["KeyA", "ArrowLeft"] },
    { "action": "right", "label": "Move right", "defaultCodes": ["KeyD", "ArrowRight"], "codes": ["KeyD", "ArrowRight"] },
    { "action": "jump",  "label": "Jump",       "defaultCodes": ["Space", "KeyW"],      "codes": ["Space", "KeyW"] },
    { "action": "fire",  "label": "Fire",       "defaultCodes": ["KeyJ"],               "codes": ["KeyJ"] },
    { "action": "pause", "label": "Pause",      "defaultCodes": ["Escape"],             "codes": ["Escape"] }
  ]
}

অনুপস্থিত কর্ম মানে তাদের লাইন অবৈধ ছিল; উপরের নিয়মের সাথে তাদের তুলনা করুন। ক 404 মানে কেউ বেঁচে নেই, বা তাদের ঘোষণা করে এমন বিল্ড এখনও প্রকাশিত হয়নি।

4. আপনার খেলা তাদের ব্যবহার করুন

codes প্লেয়ারের কার্যকরী বাঁধাই: যদি তারা একটি সেট করে তাহলে তাদের ওভাররাইড, অন্যথায় আপনার ডিফল্ট। এটি থেকে একটি লুকআপ তৈরি করুন এবং ম্যাচ করুন event.code:

const auth = { Authorization: `Bearer ${launchToken}` };

// Your built-in defaults, in the same shape the API returns.
const DEFAULT_ACTIONS = [
  { action: "left", label: "Move left", codes: ["KeyA", "ArrowLeft"] },
  { action: "jump", label: "Jump", codes: ["Space", "KeyW"] },
  /* ... */
];

function toControls(actions) {
  const byCode = new Map();
  for (const a of actions) for (const code of a.codes) byCode.set(code, a.action);
  return { actions, byCode };
}

async function loadControls(slug) {
  try {
    const res = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
    if (res.ok) return toControls((await res.json()).actions);
  } catch { /* offline: fall through */ }
  return toControls(DEFAULT_ACTIONS);                   // 404, error, or outside StarHermit
}

let controls = await loadControls(gameScope);

window.addEventListener("keydown", (e) => {
  const action = controls.byCode.get(e.code);   // e.code, never e.key
  if (action) { e.preventDefault(); onAction(action, true); }
});
window.addEventListener("keyup", (e) => {
  const action = controls.byCode.get(e.code);
  if (action) onAction(action, false);
});

অন্তর্নির্মিত ডিফল্ট গেমটিকে অফলাইনে খেলার যোগ্য রাখে, StarHermit এর বাইরে বা নিয়ন্ত্রণে থাকলে অনুরোধ ব্যর্থ হয় আপনার সঙ্গে ধাপে তাদের রাখুন control.* লাইন

একটি রিবাইন্ডিং পর্দা। তালিকা actions তাদের সাথে label. সম্পূর্ণ ওভাররাইড মানচিত্র রাখুন, বা একটি ক্রিয়া পরিবর্তন করার আগে বর্তমান কার্যকর মানচিত্রটি পড়ুন এবং সংরক্ষণ করুন:

async function saveBinding(slug, action, codes) {
  const current = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
  if (!current.ok) throw new Error(`Controls read failed: ${current.status}`);
  const bindings = Object.fromEntries((await current.json()).actions.map(a => [a.action, a.codes]));
  bindings[action] = codes;
  const res = await fetch(`/api/v1/games/${slug}/controls`, {
    method: "PUT",
    headers: { ...auth, "Content-Type": "application/json" },
    body: JSON.stringify({ bindings }),
  });
  if (!res.ok) throw new Error((await res.json()).error);   // e.g. a key already in use
  return res.json();                                         // the new effective map
}

PUT প্লেয়ারের ওভাররাইডগুলিকে আপনার পাঠানো অ্যাকশন দিয়ে প্রতিস্থাপন করে, তাই প্লেয়ারের প্রতিটি অ্যাকশন অন্তর্ভুক্ত করুন পরিবর্তন হয়েছে, শুধু সর্বশেষ নয়। বাকিগুলো আপনার ডিফল্টে থাক। DELETE একই পথে সবকিছু ডিফল্টে রিসেট করে।

আপনার স্ক্রীন থেকে পরিবর্তনগুলি সিরিয়াল করুন; দুটি একযোগে পড়া/লেখা এখনও একে অপরকে ওভাররাইট করতে পারে। ব্রাউজার SDK এর setControl() তার নিজস্ব পরিবর্তনগুলিকে সিরিয়ালাইজ করে এবং বর্তমান কার্যকর মানচিত্র সংরক্ষণ করে। কার্যকর মানচিত্র পাঠানোর ফলে সেই মানগুলিকে ওভাররাইড হিসাবে পিন করা হয়; ব্যবহার DELETE ম্যানিফেস্ট ডিফল্টে ফিরে যেতে।

প্ল্যাটফর্ম একটি সংরক্ষণ প্রত্যাখ্যান (400) যা দুটি কর্মের উপর একটি কী রেখে যাবে পরে খেলোয়াড়ের পরিবর্তনগুলি আপনার ডিফল্টের সাথে একত্রিত হয়। উদাহরণস্বরূপ, বাঁধাই jump থেকে KeyJ যখন fire এখনও এর ডিফল্ট ব্যবহার করে KeyJ প্রত্যাখ্যান করা হয়। ত্রুটি দেখান, অথবা একই সাথে বিরোধপূর্ণ ক্রিয়াটি সরান৷ সংরক্ষণ

সমস্যা সমাধান

প্রতিক্রিয়া কারণ ঠিক করুন
