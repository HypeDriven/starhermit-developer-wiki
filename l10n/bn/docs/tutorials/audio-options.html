টিউটোরিয়াল: স্বয়ংক্রিয়ভাবে সনাক্ত করা শব্দ সীমা সহ অডিও বিকল্প

আপনার খেলা একটি দিন অডিও পাশাপাশি বিভাগ গ্রাফিক্স, থেকে উপলব্ধ প্রধান মেনু এবং খেলার সময়। নীচের বেসলাইন দিয়ে শুরু করুন, খেলোয়াড়দের এটিকে ওভাররাইড করতে দিন এবং একটি প্রয়োগ করুন৷ মিক্সিং এবং স্থানিককরণের কাজকে আবদ্ধ রাখার জন্য সর্বাধিক সংখ্যক একযোগে প্লেব্যাক দৃষ্টান্ত। এগুলি প্রস্তাবিত গেম-সাইড ডিফল্ট, প্ল্যাটফর্ম প্রয়োগ করে সেটিংস নয়। একটি যোগ করুন ভাষা বিভাগ অনুবাদ নির্বাচনের জন্য এই নিয়ন্ত্রণগুলির পাশাপাশি।

audio-options.js ভলিউম বক্ররেখার জন্য নির্ভরতা-মুক্ত সাহায্যকারী সরবরাহ করে, সেটিংস বৈধতা এবং একটি রক্ষণশীল স্বয়ংক্রিয় শব্দ সীমা. এটি কোন অডিও প্রসঙ্গ, মাইক্রোফোন তৈরি করে না ক্যাপচার, মিক্সার, বিকল্প প্যানেল বা নেটওয়ার্ক সংযোগ; আপনার খেলা নিয়ন্ত্রণ এবং প্লেব্যাক তারের.

1. বেসলাইন নিয়ন্ত্রণ

নিয়ন্ত্রণ প্রস্তাবিত প্রারম্ভিক মান আচরণ
মাস্টার ভলিউম 80% প্রাপ্ত ভয়েস সহ সমস্ত গেম প্লেব্যাক নিয়ন্ত্রণ করে
সঙ্গীত ভলিউম 70% মিউজিক বাস, মাষ্টার গুন
শব্দ প্রভাব ভলিউম 100% গেমপ্লে প্রভাব বাস, মাস্টার দ্বারা গুণিত
UI ভলিউম 80% মেনু এবং ইন্টারফেস বাস, মাস্টার দ্বারা গুণিত
ভয়েস ভলিউম 100% প্রাপ্ত ভয়েস বাস, মাস্টার দ্বারা গুণিত; কখনই মাইক্রোফোন লাভ পরিবর্তন করে না
সর্বাধিক সমসাময়িক শব্দ অটো সনাক্ত করা গণনা এবং কার্যকর সীমা প্রদর্শন; অফার স্থির 16, 32, 64, 128 এবং একটি বৈধ কাস্টম গণনা গেম সিলিং এর মধ্যে
ভয়েস চ্যাট বন্ধ স্পষ্ট সেশন অপ্ট-ইন; ভয়েস সমর্থিত হলে পুশ-টু-টক অফার করুন এবং মাইক্রোফোন খুলুন
মাইক্রোফোন / আউটপুট ডিভাইস সিস্টেম ডিফল্ট অফার নির্বাচন যেখানে সমর্থিত; ডিভাইস শনাক্তকারী স্থানীয় রাখুন
ইকো বাতিল/শব্দ দমন চালু/চালু সমর্থিত ক্যাপচার প্রক্রিয়াকরণের অনুরোধ; কার্যকর ফলাফল প্রদর্শন
স্বয়ংক্রিয় মাইক্রোফোন লাভ বন্ধ ঐচ্ছিক ক্যাপচার প্রক্রিয়াকরণ, প্লেব্যাক ভলিউম থেকে স্বাধীন

ভয়েস ছাড়া গেমে ভয়েস নিয়ন্ত্রণ লুকান। প্রতিটি স্লাইডারকে একটি দৃশ্যমান শতাংশ, অ্যাক্সেসযোগ্য লেবেল দিন, কীবোর্ড সমর্থন এবং একটি ব্যবহারযোগ্য স্পর্শ লক্ষ্য; প্যানেলটিকে ছোট পর্দায় স্ক্রোল করতে দিন। একটি স্পষ্ট অন্তর্ভুক্ত করুন নিঃশব্দ নিয়ন্ত্রণ যা পূর্ববর্তী স্তর মনে রাখে। পুনরায় লোড না করে অবিলম্বে পরিবর্তনগুলি প্রয়োগ করুন৷ ঐচ্ছিক প্রতি-অংশগ্রহণকারী ভলিউম এবং স্থানীয় নিঃশব্দ খেলোয়াড়দের একটি ভয়েস রুম ভারসাম্য সাহায্য করে।

স্লাইডারের অবস্থানকে 0-1 হিসাবে বিবেচনা করুন এবং ব্যবহার করুন volumeGain(position) (অবস্থান ঘনক) একটি অনুধাবনযোগ্য বক্ররেখার জন্য। প্রতিটি বাসকে তার নিজস্ব লাভের মাধ্যমে সংযুক্ত করুন, তারপর মাস্টার লাভ, তাই মাস্টার ঠিক একবার প্রয়োগ করা হয়। ক্লিক এড়াতে র‌্যাম্প প্রায় 20 মি.সে. শূন্য নীরব হতে হবে। সম্পদকে স্বাভাবিক করুন এবং আউটপুট প্রদান করুন শব্দ ওভারল্যাপ হলে ক্লিপিং প্রতিরোধ করতে হেডরুম বা লিমিটার। ব্যবহারকারীর কাছ থেকে ব্রাউজার প্লেব্যাক আনলক করুন অঙ্গভঙ্গি এবং স্থগিত প্রসঙ্গ পরিচালনা; অনুপলব্ধ অডিও গেম খেলার যোগ্য ছেড়ে যেতে হবে.

2. স্বয়ংক্রিয়ভাবে একটি সংবেদনশীল সঙ্গতি সীমা সনাক্ত করুন৷

গ্রাফিক্স প্রিসেট বা GPU থেকে স্বাধীনভাবে ডিভাইস-টাইপ, CPU এবং মেমরির ইঙ্গিত ব্যবহার করুন। শুরুর নীতি হল:

উপলব্ধ ইঙ্গিত (উপর থেকে নীচে মূল্যায়ন) গণনা শুরু হচ্ছে
একটি ফোন বা ট্যাবলেট, সর্বাধিক দুটি যৌক্তিক CPU, বা সর্বাধিক 2 GB রিপোর্ট করা মেমরি 16
উপরোক্ত সীমাবদ্ধতা ছাড়া কমপক্ষে চারটি যৌক্তিক CPU 64
অজানা ক্ষমতা, বা উপরের সীমাবদ্ধতা ছাড়া চারটিরও কম CPU 32

রেফারেন্স হেল্পার গেমের হার্ড সিলিং-এ এই গণনাগুলি ক্যাপ করে, ডিফল্টরূপে 64, এবং সীমানা কাস্টম সিলিং 1-256। একজন ডেভেলপার গেম প্রোফাইল করার পর ম্যানুয়ালি 128 বা 256 এর অনুমতি দিতে পারে; অটো একা কোর গণনা থেকে এই বাছাই না. একটি ছোট গেম 16 বা 32 এর সিলিং সেট করতে পারে। একটি ফোন বা ট্যাবলেট হল এমন একটি যার ব্রাউজার Chromium-এর মোবাইল ইঙ্গিত বা একটি টাচ স্ক্রীনকে প্রাথমিক হিসাবে রিপোর্ট করে৷ (মোটা) পয়েন্টার, একই সংকেত গ্রাফিক্স মডিউল ব্যবহার করে; এটি শুরু হয় 16 থেকে তার মূল সংখ্যা যাই হোক না কেন, থেকে তাপ এবং ব্যাটারি নিষ্কাশন সীমিত. অনুপস্থিত বা অবৈধ ইঙ্গিত অজানা থেকে যায়. এই সংখ্যাগুলি প্রাথমিক হিউরিস্টিক, পরিমাপ করা হার্ডওয়্যার নয় ক্ষমতা: যৌক্তিক CPU সংখ্যা ব্রাউজার দ্বারা হ্রাস করা যেতে পারে, এবং মেমরি ইঙ্গিত আনুমানিক এবং গোপনীয়তা সীমাবদ্ধ.

import { detectAudioSystem, resolveAudio, volumeGain } from './audio-options.js';

const system = detectAudioSystem();
const GAME_SOUND_CEILING = 64;
let saved = {}; // Load your player's validated preferences; empty means defaults.

function applyAudio() {
  const settings = resolveAudio(saved, system, GAME_SOUND_CEILING);
  // mixer is your own adapter, not a StarHermit SDK API.
  mixer.setPlaybackLimit(settings.effectiveConcurrentSounds);
  mixer.setBusGain('master', volumeGain(settings.master));
  for (const bus of ['music', 'effects', 'ui', 'voice']) {
    mixer.setBusGain(bus, volumeGain(settings[bus]));
  }
  return settings; // Show recommendedConcurrentSounds and effectiveConcurrentSounds.
}

function setSoundLimit(value) {
  // A select supplies 'auto'; parse and validate the custom integer before calling.
  saved = { ...saved, maxConcurrentSounds: value };
  applyAudio();
  // Persist the requested choice, including 'auto', through your settings store.
}

প্রতিটি ডিভাইসে এবং প্রাসঙ্গিক মিক্সার/আউটপুট-ফরম্যাট পরিবর্তনের পরে আবার অটো চালান। সংরক্ষণ করুন 'auto', তার নয় সনাক্ত করা সংখ্যা। একটি ম্যানুয়াল গণনা ম্যানুয়াল থাকে, গেম/ব্যাকএন্ড সিলিং সাপেক্ষে। একটি ব্যাখ্যা দেখান যখন কার্যকর গণনা অনুরোধকৃত গণনা থেকে পৃথক হয়।

একটি যন্ত্রযুক্ত মিক্সারের জন্য, একটি আবদ্ধ, অশ্রাব্য প্রতিনিধি কাজের চাপ দিয়ে অটোকে পরিমার্জন করুন: পরীক্ষা প্রকৃত রিস্যাম্পলিং, স্থানিককরণ এবং প্রভাবের চেইন এবং লক্ষ্যমাত্রা একটি অডিও ব্লকের সর্বাধিক 25% মিশ্রণের জন্য সময়কাল। উদাহরণস্বরূপ, 48 kHz এ একটি 128-ফ্রেম ব্লক সেই লক্ষ্যের জন্য প্রায় 0.67 ms দেয়। সক্রিয় গেমপ্লে থেকে দূরে প্রোফাইলিং সময়সূচী. একা একটি নীরব লাভ প্রতিনিধির গ্যারান্টি দেয় না কাজ কারণ একটি ব্যাকএন্ড নীরবতা অপ্টিমাইজ করতে পারে। স্ট্যান্ডার্ড ওয়েব অডিও প্রতি-গ্রাফ সিপিইউ সময় প্রকাশ করে না; ইঙ্গিত ফলব্যাক ব্যবহার করুন যদি না আপনার নিজস্ব ব্যাকএন্ড নির্ভরযোগ্য সময় প্রদান করে। অডিও CPU খরচ অনুমান করবেন না FPS বা আউটপুট চ্যানেল গণনা থেকে।

হিস্টেরেসিস সহ টেকসই পরিমাপ করা ওভারলোড বা আন্ডাররানে সেশনের জন্য স্বয়ংক্রিয় পদ থেকে নেমে যেতে পারে দোলন এড়ানো; সংরক্ষিত পছন্দ ওভাররাইট করবেন না। স্থানীয়ভাবে ক্যাশে পরিমাপ করা সুপারিশ ব্যাকএন্ড, বিন্যাস, প্রভাব কনফিগারেশন এবং কোড সংস্করণ। সেই পরিবর্তনের পরে পুনরায় মূল্যায়ন করুন। দৃষ্টান্ত আবদ্ধ মিশ্রণ কাজ গণনা, কিন্তু ডিকোডিং, মাইক্রোফোন প্রক্রিয়াকরণ এবং নেটওয়ার্কিং পৃথক বাজেট প্রয়োজন.

3. প্লেব্যাকে ক্যাপ প্রয়োগ করুন

গণনা প্রতিটি সক্রিয় প্লেব্যাক উদাহরণ সঙ্গীত, লুপ, প্রভাব, UI এবং প্রাপ্ত ভয়েস জুড়ে। স্টেরিও একটি উদাহরণ. বিরাম দেওয়া/বন্ধ করা শব্দ, মাইক্রোফোন ক্যাপচার এবং ভার্চুয়াল সাউন্ড কোন সক্রিয় ছাড়াই রেন্ডারিং গণনা না. মিউজিক ক্রসফেড এবং রিলিজ লেজগুলি শেষ না হওয়া পর্যন্ত গণনা করা হয়। ভবিষ্যৎ নির্ধারণ করুন একই বরাদ্দকারীর মাধ্যমে শুরু হয় এবং তাদের মুলতুবি সারিতে আবদ্ধ করে।

মিডিয়া উপাদান এবং WebRTC আউটপুট সহ প্রতিটি প্লেব্যাক পথের জন্য একটি আবদ্ধ বরাদ্দকারী ব্যবহার করুন:

  1. সঙ্গীত, গুরুত্বপূর্ণ ইঙ্গিত এবং প্রত্যাশিত ভয়েস অংশগ্রহণকারীদের জন্য মোটের অংশ সংরক্ষণ করুন। রিজার্ভেশন টুপি ভাগ করুন; তারা অতিরিক্ত স্লট যোগ না. ঘরের আকার বা সীমা পরিবর্তিত হলে তাদের মানিয়ে নিন।
  2. ক্ষমতায়, একটি ইনকামিং কম-অগ্রাধিকার প্রভাব ফেলে দিন বা একটি নিম্ন-অগ্রাধিকার সক্রিয় উদাহরণ প্রতিস্থাপন করুন। দূরত্ব, শ্রবণযোগ্যতা এবং পুনরাবৃত্ত প্রভাব অগ্রাধিকারের বন্ধন ভেঙ্গে দিতে পারে। ডিডুপ্লিকেট বিস্ফোরণ এবং সীমা অডিও নোড তৈরি করার আগে বা নতুন বাফার ডিকোড করার আগে বারবার ইমিটার।
  3. একটি বিবর্ণ শিকার এখনও তার স্লট দখল করে: এটি বন্ধ না হওয়া পর্যন্ত তার প্রতিস্থাপন সারিবদ্ধ করুন, বা এটি একটি নিরাপদে থামান প্রতিস্থাপন শুরু করার আগে সীমানা। অস্থায়ীভাবে বিবর্ণ জন্য ক্যাপ অতিক্রম না.
  4. রিলিজ এবং সমাপ্ত উত্স সংযোগ বিচ্ছিন্ন. সীমা হ্রাস করা স্লট পুনরুদ্ধার করতে হবে, লুপ এবং সহ tails, নতুন প্লেব্যাক স্বীকার করার আগে. ভার্চুয়ালাইজড লুপ শুধুমাত্র সস্তা অবস্থান/রাষ্ট্র ডেটা ধরে রাখে; তাদের ব্যয়বহুল প্রক্রিয়াকরণ এবং আবদ্ধ ভার্চুয়াল-ইনস্ট্যান্স বুককিপিং সংযোগ বিচ্ছিন্ন করুন।

পরিবেশের উপর ভয়েস এবং অর্থপূর্ণ গেমপ্লের ইঙ্গিতের পক্ষে। মিক্সারের সাথে সংযুক্ত একটি WebRTC ট্র্যাক আবশ্যক৷ ডুপ্লিকেট অডিও এবং অগণিত প্লেব্যাক প্রতিরোধ করতে সরাসরি মিডিয়া-এলিমেন্ট প্লেব্যাক অক্ষম করা আছে। একা লাভ মিউট করা ডিকোডিং বা স্থানিককরণ বন্ধ করে না; কাজ দমন, বিরতি বা সংযোগ বিচ্ছিন্ন যেখানে ব্যাকএন্ড অনুমতি দেয়। বিকাশে সক্রিয়, চাপা এবং ভার্চুয়ালাইজড গণনা প্রকাশ করুন ডায়াগনস্টিক যাতে সিপিইউ বাউন্ড যাচাই করা যায়।

4. ভয়েস চ্যাট নিয়ন্ত্রণ

অনুসরণ করুন ভয়েস API কথোপকথনের সদস্যতার জন্য, যোগদান/ত্যাগ, সংকেত, নিজের নিঃশব্দ এবং হোস্ট নিঃশব্দ. প্লেয়ার ক্যাপচার সক্ষম করার পরেই স্পষ্টভাবে যোগদান করুন এবং মাইক্রোফোন অ্যাক্সেসের অনুরোধ করুন; মাইক্রোফোন ছাড়া শোনা উপলব্ধ থাকতে পারে। ব্রাউজার ক্যাপচার প্রয়োজন অনুমতি এবং একটি নিরাপদ প্রসঙ্গ. অনুমতি অস্বীকার একটি দরকারী অবস্থা দেখাতে হবে এবং প্লেব্যাক এবং পাঠ্য চ্যাট ব্যবহারযোগ্য ছেড়ে দিন।

ভয়েস সক্ষম করার সময় প্রস্তাবিত মোড হিসাবে পুশ-টু-টক ব্যবহার করুন। একটি রিবাইন্ডেবল কী প্রদান করুন এবং ক টিপুন এবং ধরে রাখুন স্পর্শ নিয়ন্ত্রণ; কী/পয়েন্টার রিলিজে রিলিজ ট্রান্সমিশন, বাতিল ইনপুট, ব্লার এবং লুকানো-পৃষ্ঠা রূপান্তর। খোলা মাইক্রোফোন একটি সুস্পষ্ট বিকল্প। মাইক্রোফোন অনুমতি দেখান, ইনপুট লেভেল, স্পিকিং স্টেট, মিউট/ডেফেন এবং যেকোনো হোস্ট মিউট। একটি মাইক্রোফোন পরীক্ষা শুধুমাত্র অনুরোধে সঞ্চালিত হয়। ডেফেন নিঃশব্দ ভয়েস গ্রহণ করে এবং সক্রিয় থাকাকালীন স্থানীয় সংক্রমণকে দমন করে।

স্থানীয়ভাবে আউটবাউন্ড অডিও গেট করার পাশাপাশি প্ল্যাটফর্মের নিজস্ব-নিঃশব্দ অবস্থা আপডেট করা। প্রতি যোগদান বা পুনঃসংযোগ করুন, মিডিয়া পাঠানোর আগে উদ্দেশ্যমূলক নিঃশব্দ পুনরুদ্ধার করুন: যোগদান অংশগ্রহণকারীর নিজের নিঃশব্দকে সাফ করে এপিআই-তে, হোস্ট মিউট বেঁচে থাকার সময়। পিয়ার-টু-পিয়ার মিডিয়াকে স্থানীয়ভাবেও হোস্ট মিউটকে সম্মান করতে হবে; সংকেত প্ল্যাটফর্মকে সরাসরি পিয়ার অডিও স্ট্রিম ফিল্টার করতে দেয় না। ক্যাপচার ট্র্যাক বন্ধ করুন এবং মিডিয়া বন্ধ করুন ভয়েস অক্ষম বা অধিবেশন শেষ হলে সংযোগ। একটি পছন্দের মোড সংরক্ষণ করা হয় নিঃশব্দে পরবর্তী লঞ্চে মাইক্রোফোন পুনরায় খোলে।

5. সংরক্ষণ করুন এবং যাচাই করুন

গেমের মধ্যে সাধারণ পছন্দগুলি সংরক্ষণ করুন প্রতি-প্লেয়ার সেটিংস, উদাহরণস্বরূপ অধীনে audio হিসাবে { saved: { master: 0.8, maxConcurrentSounds: 'auto', voiceMode: 'off' }, at: … }. স্বতন্ত্র খেলার জন্য একটি নামস্থান স্থানীয় ক্যাশে রাখুন। লেখার আগে পড়ুন, টাইমস্ট্যাম্প পুনর্মিলন করুন এবং ব্লক ক্লাউড গ্রাফিক্স টিউটোরিয়ালের মতো সফল পুনঃপ্রচেষ্টা না হওয়া পর্যন্ত ব্যর্থ পড়ার পরে লিখে। তাদের প্রয়োগ করার আগে দূরবর্তী সেটিংস যাচাই করুন। ডিভাইস আইডি, অনুমতি, প্রোফাইলিং ফলাফল, রাখুন অধিবেশন সদস্যপদ এবং বর্তমান মাইক্রোফোন কার্যকলাপ স্থানীয়; পছন্দের ভয়েস মোড আলাদাভাবে সংরক্ষণ করুন ক্যাপচার বর্তমানে সক্ষম কিনা তা থেকে।
