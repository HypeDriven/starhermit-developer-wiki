ঐক্য SDK

দ স্টারহার্মিট ইউনিটি এসডিকে (HypeDriven/starhermit-unity-sdk) প্ল্যাটফর্মের জন্য টাইপ করা, অ্যাসিঙ্ক্রোনাস C# ক্লায়েন্ট সহ একটি ইউনিটি প্যাকেজ ম্যানেজার প্যাকেজ। এটি পরিচালনা করে HTTP অনুরোধ, JSON পার্সিং, টোকেন রিফ্রেশ এবং WebSocket পুনঃসংযোগ।
প্যাকেজ com.starhermit.sdk, সংস্করণ 0.1.0
নামস্থান Starhermit
API বেসলাইন REST v1 এবং WebSocket v1
নতুন REST বৈশিষ্ট্য ব্যবহার করুন client.Raw এবং মডেল RawJson যখন এই SDK সংস্করণে কোনো টাইপ করা সদস্য নেই
ওয়েবসকেট প্রোটোকল সব 6, একটি সংযোগ শ্রেণী প্রতিটি
লাইসেন্স এমআইটি

SDK একটি ক্লায়েন্ট, প্ল্যাটফর্মের দ্বিতীয় বাস্তবায়ন নয়। অনুমোদন, বন্ধুত্ব, এনটাইটেলমেন্ট, রুম মেম্বারশিপ, স্কোর যাচাইকরণ, গেমের ফলাফল এবং স্টোরেজ বাজেট থাকে সার্ভার-অনুমোদিত হুবহু নীচের পৃষ্ঠাগুলিতে নথিভুক্ত করা হয়েছে — SDK সার্ভারের উত্তরটি প্রকাশ করে এবং এর প্রকাশিত সীমা নিজের সিদ্ধান্ত নেওয়া বা ক্যাশ করার পরিবর্তে।

এই পৃষ্ঠাটি ইন্টিগ্রেশন গাইড। সম্পূর্ণ প্যাকেজ ডকুমেন্টেশনের অধীনে সংগ্রহস্থলে থাকে Packages/com.starhermit.sdk/Documentation~.

প্রয়োজনীয়তা

  • ইউনিটি 2021.3 LTS বা নতুন, API সামঞ্জস্যের স্তর .NET স্ট্যান্ডার্ড 2.1, C# 9.
  • Mono এবং IL2CPP, অক্ষম থেকে পরিচালিত স্ট্রিপিং সহ উচ্চ (প্যাকেজ তার নিজস্ব জাহাজ Runtime/link.xml).
  • কোন প্রতিফলন নেই, কোন গতিশীল কোড জেনারেশন নেই, কোন বাধ্যতামূলক নেটিভ প্লাগইন নেই।

প্রতিটি মডিউল প্রতিটি বিল্ড টার্গেটের জন্য কম্পাইল করে। যেখানে একটি লক্ষ্য প্রকৃতপক্ষে একটি ক্ষমতা অভাব - না একটি হেডলেস সার্ভারে মাইক্রোফোন, ব্রাউজারে কোনো হ্যান্ডশেক হেডার নেই — কল বাড়ে৷ StarhermitFeatureUnavailableException একটি স্থিতিশীল সঙ্গে Reason, পরিবর্তে বিল্ড ব্যর্থ বা সম্পর্কহীন বৈশিষ্ট্য নিষ্ক্রিয় করা।

ইনস্টল করুন

প্যাকেজ ম্যানেজার → গিট ইউআরএল থেকে প্যাকেজ যোগ করুন, অথবা একটি এন্ট্রি Packages/manifest.json. প্যাকেজ সংগ্রহস্থলের একটি সাবফোল্ডারে বসে, তাই URL-এর প্রয়োজন path=:

{
  "dependencies": {
    "com.starhermit.sdk": "https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk"
  }
}

যুক্ত করে একটি রিলিজ পিন করুন #<tag-or-commit>:

https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk#v0.1.0

ঐক্য শেল আউট টু git, তাই একটি ব্যক্তিগত সংগ্রহস্থল শুধুমাত্র তখনই সমাধান করে যখন সম্পাদকের গিট প্রমাণীকরণ করতে পারে অ-ইন্টারেক্টিভলি — একটি SSH কী (git@github.com:HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk) বা ক কনফিগার করা শংসাপত্র সহকারী। একটি স্থানীয় পথ বা একটি স্কোপড রেজিস্ট্রি একই ভাবে কাজ করে। আমদানি নং পরিবর্তন প্রকল্প সেটিংস এবং কোন নেটওয়ার্ক অ্যাক্সেস সঞ্চালন.

একটি ক্লায়েন্ট তৈরি করুন

using Starhermit;

var client = StarhermitClient.Create(new StarhermitOptions
{
    ApiBaseUri = new Uri("https://api.starhermit.com/api/v1/"),
    GameSlug   = "83fd04b1-3cbe-4b09-a251-3733ad4b9d94",
    TokenStore = myPlatformSecureStore,
    LogLevel   = StarhermitLogLevel.Warning
});

await client.InitializeAsync();               // loads a stored session, refreshes it if expired
var me = await client.Me.GetProfileAsync();

Create কোন I/O সম্পাদন করে না। আপনি আরম্ভ না করা পর্যন্ত, একটি পরিষেবা কল বা একটি খুলুন পর্যন্ত কিছুই নেটওয়ার্ক স্পর্শ করে না সংযোগ WebSocket বেস থেকে উদ্ভূত হয় ApiBaseUri (wss://<host>/ws/v1/) যদি না আপনি সেট করেন WebSocketBaseUri নিজেকে

StarhermitClient হয় IDisposable: নিষ্পত্তি ইন-ফ্লাইট অনুরোধ বাতিল করে, প্রতিটি সংযোগ এটি বন্ধ করে দেয় হস্তান্তর করা, হৃদস্পন্দন বন্ধ করে এবং অডিও প্রকাশ করে। প্যাকেজে কোন স্ট্যাটিক পরিবর্তনযোগ্য অবস্থা নেই, তাই দুটি ক্লায়েন্ট বিভিন্ন পরিবেশের বিরুদ্ধে পাশাপাশি চলতে পারে এবং একজন ক্লায়েন্ট দৃশ্যের লোড থেকে বেঁচে যায়।

প্ল্যাটফর্মে প্রকাশিত একটি খেলা থেকে পরিবেশন করা হয় https://<slug>.starhermit.com সঙ্গে /api এবং /ws প্রক্সি একই-অরিজিন (দেখুন গিটহাব গেমস) একটি WebGL বিল্ড এটি প্রকাশ করেছে উপায়টি তার নিজস্ব উত্সের দিকে নির্দেশ করা উচিত যাতে ব্রাউজার একই-অরিজিন কল করে:

ApiBaseUri = new Uri("https://83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com/api/v1/") // your game's uid

একটি স্থানীয় ব্যাকএন্ডের জন্য, AllowInsecureTransport = true অনুমতি http/ws. ক্লায়েন্ট নির্মাণ প্রত্যাখ্যান a এটি ছাড়া নন-HTTPS ঠিকানা, এবং সম্পাদকের বিল্ড বৈধতা একটি নন-ডেভেলপমেন্ট প্লেয়ার বিল্ড ব্যর্থ করে যে এখনও এটি সেট আছে. এটি কখনই শংসাপত্রের বৈধতা অক্ষম করে না।

সাইন ইন করা হচ্ছে

তিনটি শংসাপত্রের ধরন বর্ণনা করা হয়েছে প্রমাণীকরণ পৃথক পৃথক পৃথক ধরনের হয় SDK-তে দোকান; কেউ অন্যের পক্ষে দাঁড়াতে পারে না।

OAuth — SDK একটি ইনজেকশনের মাধ্যমে অনুমোদিত URL খোলে IStarhermitOAuthBrowser এবং সম্পূর্ণ করে বিনিময়:

var session = await client.Auth.SignInWithOAuthAsync("google");

ব্যবহার করুন BuildAuthorizeUri(provider) প্লাস CompleteOAuthAsync(...) পরিবর্তে যখন আপনার প্ল্যাটফর্ম হাতে এর নিজস্ব ডিপ-লিঙ্ক বা এমবেডেড-ব্রাউজার প্লাম্বিংয়ের মাধ্যমে ফিরে পুনঃনির্দেশিত করুন।

পাবলিক কী — এমবেডেড, কনসোল এবং ডেডিকেটেড সার্ভার প্লেয়ারের জন্য পাসওয়ার্ডহীন প্রবাহ (দেখুন ডেডিকেটেড সার্ভার + এমবেডেড প্লেয়ার অনবোর্ডিং) সমর্থিত কী ধরনের হয় Ed25519, ECDSA-P256 এবং RSA-PSS; SDK কখনই একটি তৈরি বা সঞ্চয় করে না ব্যক্তিগত কী, এটি একটি ইনজেকশন কল IStarhermitSigner:

var session = await client.Auth.SignInWithPublicKeyAsync(signer);   // or (), using Options.Signer

চুক্তির বিস্তারিত জানার মতো। স্থাপনা তার নিজের বিরুদ্ধে একটি চ্যালেঞ্জ স্বাক্ষর যাচাই করে প্যাসকালকেস চ্যালেঞ্জের সিরিয়ালাইজেশন, যখন আপনি যে JSONটি পেয়েছেন তা হল CamelCase — পুনরায় সিরিয়ালাইজ করা হচ্ছে প্রতিক্রিয়া যাচাই করা হবে না. StarhermitChallenge.CanonicalPayload সঠিক বাইট পুনরুত্পাদন করে সাইন, তাই হ্যান্ড রোলড সাইনিং অবশ্যই একই কাজ করবে।

গেম লঞ্চ টোকেন — প্রতি গেমে মিন্ট করা হয়েছে এবং সেই গেমের পৃষ্ঠে বেড়া দেওয়া হয়েছে:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();
var fenced = chess.WithLaunchToken();     // subsequent calls authorise with the launch token

একটি লঞ্চ টোকেন মিন্ট করা কখনই অ্যাকাউন্ট সেশন প্রতিস্থাপন করে না। একটি অনুরোধ বহন করে কোন শংসাপত্র অনুরোধ পাইপলাইন দ্বারা সিদ্ধান্ত নেওয়া হয়েছে, আপনার কল করা পরিষেবা দ্বারা নয়।

অ্যাক্সেস-টোকেন রিফ্রেশ সমন্বিত হয়: ক 401 সর্বাধিক একটি রিফ্রেশ এবং একটি রিপ্লে, এবং সমসাময়িক ক্রয় করে৷ কলকারীরা একাধিক শুরু করার পরিবর্তে একই রিফ্রেশের জন্য অপেক্ষা করে — একটি ঘোরানো রিফ্রেশ টোকেন সহ, এক সেকেন্ড বিনিময় পরিবার প্রত্যাহার এবং খেলোয়াড় সাইন আউট হবে. একটি নির্দিষ্ট প্রত্যাখ্যান উত্থাপন SessionExpired একবার একটি পরিবহন ব্যর্থতা অধিবেশন অক্ষত ছেড়ে.

বর্তমান শর্তাবলী গ্রহণ

হার্টবিট, গেমের অনুরোধ বা সকেট শুরু করার আগে গ্রহণযোগ্যতা পরীক্ষা করুন। সংস্করণ 0.1.0 আছে AcceptTermsAsync, কিন্তু নতুন প্রোফাইল ক্ষেত্র এবং শর্তাবলী আবিষ্কার এর কাঁচা JSON সমর্থন ব্যবহার করে:

var profile = await client.Me.GetProfileAsync(ct);
var needsAcceptance = profile.RawJson["termsAcceptanceRequired"].AsBooleanOrDefault();
var terms = await client.Raw.SendForJsonAsync(new StarhermitRequest("GET", "terms"), ct);
var textToDisplay = terms["text"].AsStringOrNull();
var displayedHash = terms["hash"].AsStringOrNull();
// Display textToDisplay. Retain displayedHash for this displayed revision.
// Only in the user's Accept handler, using an account session:
// await client.Me.AcceptTermsAsync(displayedHash, ct);

যেমন একটি নমুনা সংশোধন লেবেল ব্যবহার করবেন না terms-2026-08: API থেকে শুধুমাত্র বর্তমান হ্যাশ হয় গৃহীত চালু 409, অন্য একটি গ্রহণযোগ্যতার জন্য নতুন পাঠ্য আনুন এবং প্রদর্শন করুন৷ চালু 403 terms_acceptance_required, পুনরায় চেষ্টা করার আগে গ্রহণযোগ্যতা সমাধান করুন; প্লেয়ার লঞ্চ টোকেনগুলিও স্পষ্ট সম্মতির পরে API এর মাধ্যমে গ্রহণযোগ্যতা জমা দিতে পারে। দেখুন প্রোফাইল সম্পূর্ণ প্রবাহের জন্য।

একটি অধিবেশন শেষ থেকে শেষ

থেকে জীবনচক্র ইন্টিগ্রেশন ওয়াকথ্রু, C# এ:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();

var ticket = await chess.EnqueueMatchmakingAsync();
while (!ticket.IsMatched)
{
    await Task.Delay(TimeSpan.FromSeconds(2), ct);
    ticket = await chess.GetMatchmakingAsync(ct) ?? ticket;
}

using var game = client.CreateGameConnection(ticket.SessionId!.Value, "83fd04b1-3cbe-4b09-a251-3733ad4b9d94", useLaunchToken: true);
game.FrameReceived       += frame => ApplyServerState(frame);
game.AchievementUnlocked += unlock => ShowToast(unlock);
game.PresenceChanged     += (userId, online) => UpdateOpponentDot(userId, online);
game.ErrorReceived       += message => ShowError(message);

await game.ConnectAsync(ct);
await game.SendCommandAsync(writer =>
{
    writer.Write("type", "move");
    writer.Write("from", "e2");
    writer.Write("to",   "e4");
}, ct);

SendCommandAsync হিসাবে পেলোড মোড়ানো {"type":"cmd","data":…}; SendRealtimeInputAsync হয় ক্রমাগত ইনপুটের জন্য হার-সীমিত পথ। সংযোগ খেলা যুক্তি টিক না, প্রামাণিক ভবিষ্যদ্বাণী একটি অস্পষ্টতার পরে একটি ফলাফল প্রকাশ করুন, বা একটি সম্ভাব্য অ-অদম্য কমান্ড পুনরায় পাঠান সংযোগ বিচ্ছিন্ন করুন - সার্ভার কি ঘটেছে তার একমাত্র কর্তৃত্ব রয়ে গেছে।

প্রতিটি সংযোগ একটি রাষ্ট্র মেশিন ভাগ করে: Disconnected, Connecting, Connected, Reconnecting, Closing, Faulted, সঙ্গে StateChanged, Closed এবং Faulted ঘটনা, সঙ্গে আউটবাউন্ড সারি আবদ্ধ সুস্পষ্ট ব্যাকপ্রেশার, এবং আদেশ পাঠান. পুনঃসংযোগ বিভ্রান্ত ব্যাকঅফ ব্যবহার করে, একটি কারেন্ট পুনরায় অর্জন করে প্রতিটি প্রচেষ্টার আগে টোকেন, এবং একটি অনুমোদন বা নীতি বন্ধ ভাল জন্য বন্ধ বরং একটি দরজা হাতুড়ি প্ল্যাটফর্ম বন্ধ. এটি কখনই অনুমান করে না যে সদস্যপদ ফাঁক থেকে বেঁচে গেছে: প্রতিটি প্রোটোকল পুনঃসংযোগে পুনরায় ফেরত বা পুনরায় যোগদান করুন।

শংসাপত্র রাইড Authorization শিরোনাম যেখানে প্ল্যাটফর্ম এটি অনুমতি দেয় এবং ?access_token= অন /ws/** অন্যথায়, কারণ একটি ব্রাউজার হ্যান্ডশেক হেডার সেট করতে পারে না। ক্যোয়ারী টোকেন থেকে রিডাক্ট করা হয়েছে প্রতিটি লগ

অ্যাসিঙ্ক, থ্রেডিং এবং ইউনিটি

প্রতিটি I/O অপারেশন ফিরে আসে Task এবং একটি ট্রেলিং লাগে CancellationToken. নেই async void পদ্ধতি এবং কোনো পাবলিক পদ্ধতি কলিং থ্রেড ব্লক করে না।

ইভেন্ট এবং অগ্রগতি কলব্যাকগুলি সিঙ্ক্রোনাইজেশন প্রসঙ্গে পোস্ট করা হয় যাতে ক্লায়েন্ট তৈরি করা হয়েছিল — তাই আপনি যদি এটি ইউনিটির মূল থ্রেডে তৈরি করেন, একটি হ্যান্ডলার স্পর্শ করতে পারে GameObjectসরাসরি। একটি মাথাবিহীন সার্ভার সঙ্গে হপ এড়িয়ে যেতে পারেন options.CallbackDispatcher = ImmediateCallbackDispatcher.Instance. কলব্যাক হয় সংযোগ প্রতি আদেশ, এবং নিক্ষেপ যে একটি হ্যান্ডলার বন্ধ না করে ডায়গনিস্টিক রিপোর্ট করা হয় লুপ গ্রহণ।

StarhermitLifecycle.Attach(client) ব্রিজ ইউনিটির অ্যাপ্লিকেশন ইভেন্ট: উপস্থিতি হার্টবিট থামিয়ে দেয় সাসপেনশনে এবং রিজিউমে অবিলম্বে পাঠায়, এবং ক্লায়েন্ট সিঙ্ক্রোনাস ছাড়াই প্রস্থান করার সময় নিষ্পত্তি করা হয় নেটওয়ার্ক কাজ।

মডেল কখনও উল্লেখ করে না GameObject, MonoBehaviour বা একটি দৃশ্য। StarhermitTextures অবতার রূপান্তরিত করে এবং কভার-আর্ট বাইট একটি মধ্যে Texture2D মূল থ্রেডে — কলার ফলাফলের মালিক এবং এটি অবশ্যই ধ্বংস করতে হবে।

ত্রুটি, পুনরায় চেষ্টা এবং পৃষ্ঠা সংখ্যা

স্ট্যাটাস ব্যতিক্রম
400 / 422 StarhermitBadRequestException, StarhermitValidationException (ক্ষেত্রের ত্রুটিগুলি তারের নাম দ্বারা চাবি করা হয়েছে)
401 StarhermitAuthenticationException
402 StarhermitEntitlementException
403 StarhermitAuthorizationException
404 StarhermitNotFoundException
409 StarhermitConflictException
429 StarhermitRateLimitException (বহন করে RetryAfter)
5xx StarhermitServerException

প্রতিটি অবস্থা, সার্ভার বহন করে {"error":"..."} বার্তা, যেকোনো মেশিন-পাঠযোগ্য কোড, অনুরোধ আইডি, Retry-After, রিডাক্টেড হেডার এবং একটি সাইজ-ক্যাপড রিডাক্টেড বডি। একটি অনুরোধ যা পৌঁছায় না এপিআই বাড়ায় StarhermitTransportException বা StarhermitTimeoutException - পরিবহন ব্যর্থতা কখনই নয় একটি API প্রতিক্রিয়া হিসাবে সজ্জিত. বাতিলকরণ সবসময় হিসাবে পৃষ্ঠ OperationCanceledException.

পুনঃপ্রচেষ্টা আবদ্ধ, জীর্ণ, সম্মান Retry-After একটি ক্যাপ পর্যন্ত, এবং এক সেকেন্ডের ব্যর্থতায় সীমাবদ্ধ প্রচেষ্টা বেঁচে থাকতে পারে: সংযোগ ত্রুটি, সময়সীমা, 408, 429 এবং ক্ষণস্থায়ী 5xx. 403, 404, 409 এবং বৈধতা ব্যর্থতার জন্য পুনরায় চেষ্টা করা হয় না, এবং একটি POST শুধুমাত্র তখনই পুনরায় চেষ্টা করা হয় যখন এটি এর সাথে নির্বাচন করে AsIdempotent. একটি প্রক্রিয়া-ব্যাপী পুনঃপ্রচেষ্টার বাজেট অনেক ক্লায়েন্টকে একটি বিভ্রাটকে ঝড়ে পরিণত করা বন্ধ করে দেয়।

তালিকা শেষ বিন্দু ফিরে StarhermitPage<T> সার্ভারের নিজস্ব পেজিং মেটাডেটা বহন করে, প্লাস অলস গণনা যা একটি পৃষ্ঠাকে কেবলমাত্র গ্রহণ করার সাথে সাথে নিয়ে আসে:

await foreach (var title in client.Software.EnumerateTitlesAsync(query, cancellationToken: ct)) { … }

ডাউনলোড স্ট্রিম একটি IStarhermitFileStore একটি অস্থায়ী ফাইলের মাধ্যমে, একটি সরবরাহকৃত SHA-256 যাচাই করুন এবং পারমাণবিকভাবে উন্নীত করা হয়; OpenDownloadAsync রিপোর্ট IsResumed শুধুমাত্র একটি বাস্তব জন্য 206, কারণ একটি আংশিক ফাইলে একটি সম্পূর্ণ ফাইল যুক্ত করা এটিকে দূষিত করবে যখন এখনও একটি দৈর্ঘ্য পরীক্ষা পাস করবে।

শংসাপত্র সংরক্ষণ করা হচ্ছে

প্যাকেজ নিরাপদ বলে দাবি করে এমন কোনো দোকান পাঠায় না। ডিফল্ট হল ইন-মেমরি; অপ্ট-ইন EncryptedFileTokenStore (HMAC-SHA256-এর সাথে AES-CBC আপনার অ্যাপ্লিকেশন সরবরাহের একটি কী) নথিভুক্ত বিশ্রামে অস্পষ্টতা হিসাবে, একটি কীচেন নয়। তার IStarhermitTokenStore প্ল্যাটফর্মের নিজস্ব নিরাপদে স্টোরেজ — কীচেন, কীস্টোর, কনসোল SDK-এর ব্যবহারকারী স্টোরেজ। PlayerPrefs হিসাবে উপস্থাপন করা হয় না নিরাপদ

টোকেন, রিফ্রেশ টোকেন, প্রাইভেট কী, ক্লায়েন্ট সিক্রেটস এবং ইনভোক কীগুলি কখনই সিরিয়াল করা হয় না ScriptableObjectএকটি দৃশ্য, Resources, একটি লগ, একটি ব্যতিক্রম বার্তা, একটি টেলিমেট্রি ইভেন্ট বা একটি বিল্ড৷ শিল্পকর্ম StarhermitSettings শুধুমাত্র অ-গোপন প্রকল্প ডিফল্ট ধারণ করে: ঠিকানা, স্লাগ, লগ স্তর, সময়সীমা এবং উন্নয়ন পতাকা.

রিডাকশন কাঠামোগত — শিরোনাম, ক্যোয়ারী-প্যারামিটার এবং JSON সদস্যের নাম অনুসারে, প্রতিটি গভীরতায় — তাই একটি এই SDK সংস্করণের শংসাপত্রটি এখনও লগ, ব্যতিক্রম এবং টেলিমেট্রি থেকে ছিনিয়ে নেওয়া হয়েছে। URL খন্ড সম্পূর্ণরূপে বাদ দেওয়া হয়. কোনো টেলিমেট্রি ডিফল্টরূপে সংগ্রহ করা হয় না; একটি ইনজেকশনযুক্ত সিঙ্ক গ্রহণ করে ইভেন্টের নাম, অপারেশন আইডি, সময়কাল, অবস্থা পরিবার, পুনরায় চেষ্টা গণনা, অনুরোধ আইডি এবং ফলাফল, কখনই ইউআরএল নয়, সংস্থা বা প্লেয়ার সামগ্রী।

যখন প্ল্যাটফর্ম নতুন কিছু জাহাজ

মডেলগুলি অপরিবর্তনীয় এবং JSON যে থেকে তাদের পার্স করা হয়েছিল তা রাখে, তাই পরে স্থাপনায় একটি ক্ষেত্র যোগ করা হয়েছে এই SDK সংস্করণটি এখনও পঠনযোগ্য, এবং এই সংস্করণটি টাইপ করে না এমন একটি এন্ডপয়েন্ট এখনও কলযোগ্য টাইপ করা কল হিসাবে একই শংসাপত্র, পুনঃপ্রয়াস এবং সংশোধন:

var value = profile.RawJson["shippedAfterThisSdk"].AsStringOrNull();

var json  = await client.Raw.SendForJsonAsync(
    new StarhermitRequest("GET", "some/new/route").WithQuery("page", 1), ct);

সকেট ফ্রেমগুলি তাদের টাইপ ডিসক্রিমিনেটারে একটি অজানা-ফ্রেম ফলব্যাক সহ প্রেরণ করে যা সংরক্ষণ করে পেলোড, অজানা enum স্ট্রিংগুলি জোরপূর্বক না করে স্ট্রিং হিসাবে রাখা হয় এবং একটি অজানা গোপনীয়তা স্তর হিসাবে পড়া সর্বাধিক ব্যক্তিগত ব্যাখ্যা। Optional<T> বাদ দেওয়া, স্পষ্ট নাল এবং মান, যা একটি প্যাচ বডির প্রয়োজন।

client.GetDiagnostics() সংযোগের অবস্থা, সারির গভীরতা, পুনঃসংযোগ গণনা, টোকেনের মেয়াদ, ঘড়ি ফেরত দেয় সতেজতা, ইন-ফ্লাইট অনুরোধ, পুনরায় চেষ্টা করা এবং শেষ সংশোধন করা ত্রুটি — একটি সাথে সংযুক্ত করার জন্য স্ন্যাপশট বাগ রিপোর্ট।

নমুনা

আটটি নমুনা প্যাকেজের সাথে পাঠানো হয় এবং সিআই-তে সংকলিত হয়, তাই তারা API থেকে সরে যেতে পারে না প্রদর্শন করুন: প্রমাণীকরণ এবং প্রোফাইল, বন্ধু এবং চ্যাট, ম্যাচমেকিং গেম, রিয়েলটাইম এবং রিলে, ভয়েস, ক্যাটালগ পরিষেবা, প্রকাশক টুল, এবং ডেডিকেটেড সার্ভার।

যাচাই অবস্থা

SDK-এর নিজস্ব স্যুট (এর অধীনে 144 হারমেটিক পরীক্ষা dotnet test, ইউনিটি এডিটমোড হিসাবে চলমান একই ফাইল পরীক্ষা) এবং একটি জেনারেটেড কভারেজ ম্যানিফেস্ট যা বিল্ডে ব্যর্থ হয় যখন একটি API অপারেশনে SDK ম্যাপিং না থাকে প্রতিটি পরিবর্তন চালানো; আরও পাঁচটি পরীক্ষা একটি লাইভ স্থাপনা পড়ে যখন একটিতে নির্দেশিত হয় এবং এড়িয়ে যায় অন্যথায় সম্পাদক ম্যাট্রিক্স এবং IL2CPP লিনাক্স, অ্যান্ড্রয়েড এবং ওয়েবজিএল-এর জন্য প্লেয়ার বিল্ডগুলি সিআই-তে সংজ্ঞায়িত করা হয়েছে তবে লাইসেন্সপ্রাপ্ত বিল্ড ফার্ম প্রয়োজন, তাই উপরের প্ল্যাটফর্ম সারণীতে বলা হয়েছে যে সহায়তার উদ্দেশ্য — আপনি একবার তৈরি করার পরই একটি লক্ষ্যকে যোগ্য হিসাবে বিবেচনা করুন এটা নিজেই
