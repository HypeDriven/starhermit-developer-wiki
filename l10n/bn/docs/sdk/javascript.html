জাভাস্ক্রিপ্ট SDK (ব্রাউজার গেম)

starhermit-sdk.js ব্রাউজার গেমগুলির জন্য একটি একক-ফাইল, নির্ভরতা-মুক্ত ক্লায়েন্ট StarHermit এ প্রকাশিত। এটি লঞ্চ টোকেন পড়ে, এটি পুনর্নবীকরণ রাখে এবং সাধারণের জন্য সাহায্যকারী প্রদান করে গেম-স্কোপড লঞ্চ-টোকেন API: পরিচয়, ক্লাউড সংরক্ষণ, প্রতি-প্লেয়ার সেটিংস এবং নিয়ন্ত্রণ, আমন্ত্রণ, ম্যাচমেকিং, সেশন এবং গেমপ্লে সকেট, অর্জন, লিডারবোর্ড, রিপ্লে, চ্যাট, ভয়েস এবং রিয়েলটাইম রুম।
ফাইল docs/sdk/starhermit-sdk.js - এটি আপনার গেমে অপরিবর্তিত অনুলিপি করুন
গ্লোবাল window.StarHermit (এছাড়াও module.exports নোডের অধীনে, পরীক্ষার জন্য)
নির্ভরতা কোনোটিই নয় — এটি ব্রাউজারের নিজস্ব ব্যবহার করে fetch, WebSocket এবং (সংকুচিত সংরক্ষণগুলি পড়তে) DecompressionStream
API বেসলাইন REST v1 এবং WebSocket v1, শুধুমাত্র লঞ্চ-টোকেন পৃষ্ঠ

SDK একটি ক্লায়েন্ট, প্ল্যাটফর্মের দ্বিতীয় বাস্তবায়ন নয়। স্কোর এবং কৃতিত্ব আনলক করে শুধুমাত্র গেমের সার্ভার দ্বারা লেখা হয় (একটি স্ক্রিপ্ট ফলাফল বা একটি ধারক নিয়ন্ত্রণ বার্তা) - একটি ক্লায়েন্ট সেগুলি কখনই পোস্ট করতে পারে না এবং SDK শুধুমাত্র সেগুলি পড়ে৷ অন্য সবকিছু সার্ভার-অনুমোদিত থাকে ঠিক যেমন নথিভুক্ত API পৃষ্ঠা.

প্রমাণীকৃত সাহায্যকারীরা লঞ্চ টোকেন ছাড়া কোনো API অনুরোধ করে না। পড়া সাধারণত সমাধান থেকে null, [], অথবা একটি খালি মানচিত্র; লিখলে সমাধান হতে পারে null/false এবং ডিবাউন্স করা সঞ্চয় কোন অবিলম্বে আছে রিটার্ন মান। একটি সকেট সংযোগ বিচ্ছিন্ন থাকে। প্লেয়ার বেছে নিলে মেমরিতে স্বতন্ত্র অগ্রগতি রাখুন আনট্র্যাকড খেলা কল signOut() অ্যাকাউন্ট প্লে থেকে সেই মোডে স্যুইচ করার আগে যাতে পুনর্নবীকরণ বন্ধ হয়ে যায়।

ইনস্টল করুন

আপনার গেমের অন্যান্য স্ট্যাটিক স্ক্রিপ্টগুলির পাশে ফাইলটি অনুলিপি করুন — যেখানেই আপনার বিল্ড সেগুলি পাঠায় — এবং লোড করুন এটি আপনার নিজের কোডের আগে:

<script src="starhermit-sdk.js"></script>
<script>
  StarHermit.init();          // as early as possible: it reads and strips the token from the URL fragment
</script>

কল init() একবার, কোনো রাউটার স্পর্শ করার আগে location.hash. বিকল্প: init({ base, gameId, autoRefresh, launcherUrl }) — base পয়েন্ট REST একটি অনুমোদিত উত্স থেকে কল স্থানীয় উন্নয়নের সময় (প্ল্যাটফর্ম-হোস্ট করা গেম একই-অরিজিন ব্যবহার করে)। gameId, সরবরাহ করা হলে অবশ্যই মিলবে সাইন-ইন করার জন্য হোস্ট করা UUID; স্থানীয়/বাহ্যিক পৃষ্ঠাগুলি বৈধ গেম সাইন-ইন রিটার্ন উত্স নয়৷ autoRefresh: false একটি খেলা যে টোকেন পুনর্নবীকরণ ছেড়ে তার নিজস্ব চেইন চালায়, এবং launcherUrl যেখানে ওভাররাইড করে relaunch() প্লেয়ার পাঠায় (ডিফল্ট https://dashboard.starhermit.com/).

সাইন ইন এবং পরিচয়

প্রয়োজন কল
একজন খেলোয়াড় কি সাইন ইন করেছেন? StarHermit.signedIn, StarHermit.userId, StarHermit.slug
সাইন-ইন / সাইন-আউট / মেয়াদ শেষ হওয়ার প্রতিক্রিয়া দিন StarHermit.on('auth', ({ signedIn, reason }) => …)
দেখান a সাইন ইন করুন বোতাম শুধুমাত্র যখন StarHermit.canSignIn() (কোন টোকেন ছাড়াই একটি গেম UUID সাবডোমেনে সত্য); ক্লিক StarHermit.signIn()
খেলোয়াড়ের নাম/অবতার await StarHermit.profile() → { userId, username, nickname, displayName }; StarHermit.avatarUrl()
বন্ধুরা await StarHermit.friends()

SDK উভয় লঞ্চ আকার পরিচালনা করে — #game_token=<jwt>[&session_id=…] লাইব্রেরি থেকে বা একটি আমন্ত্রণ, এবং #access_token=<jwt> সরাসরি সাইন-ইন থেকে ফিরে আসা — এবং এর মাধ্যমে টোকেন রিনিউ করে POST /api/v1/games/{slug}/launch-token মেয়াদ শেষ হওয়ার আগে (দেখুন টোকেন চালু করুন) প্রদর্শনের নাম হল প্রোফাইল nickname; /api/v1/me হয় না লঞ্চ টোকেন দিয়ে পৌঁছানো যায়।

ক্লাউড সেভ

গেমের স্লট হল game:<slug> (ক্যাটালগ: একটি খেলার ভিতর থেকে সংরক্ষণ করা); SDK পথ তৈরি করে, পেলোড জিপ করে এবং পরিচালনা করে /info চেক

const remote = await StarHermit.loadJSON();          // null: empty slot, signed out — or a failed read
if (StarHermit.saveLoadFailed()) showSyncError();    // tell those apart when it matters
else if (remote && isNewer(remote, local)) adopt(remote);

StarHermit.saveJSON(state);                          // debounced (2 s) checkpoint upload
addEventListener('pagehide', () => StarHermit.flushSave(true));   // keepalive flush
StarHermit.on('saved', ok => setSyncIndicator(ok));

সংরক্ষণ করার আগে লোড করুন। কোন লেখা পৌঁছতে পারে তার আগে ক্লাউড কপি তুলনা করুন এবং গ্রহণ করুন saveJSON — সেটিংস সহ, ডাকনাম বা চেকপয়েন্ট বুটে লিখছে — অথবা একটি বাসি স্থানীয় অনুলিপি করতে পারেন অন্য ডিভাইসে করা একটি নতুন সংরক্ষণ ওভাররাইট করুন। স্টার্ট-আপ লোড স্থির না হওয়া পর্যন্ত তাড়াতাড়ি সেভগুলি ধরে রাখুন।

SDK সেই রেসের বাকি অর্ধেককে রক্ষা করে: যখন একটি রিড ব্যর্থ হয় (নেটওয়ার্ক বা সার্ভার ত্রুটি, যেমন একটি খালি স্লটের বিপরীতে) এটি সেট করে saveLoadFailed(), নির্গত করে saveerror, এবং প্রত্যাখ্যান পর্যন্ত লিখছে /info নিশ্চিত করে যে স্লট খালি বা পরে loadSave() সফল হয় একটি প্রত্যাখ্যান লিখিত সমাধান false এবং নির্গত করে saved সঙ্গে false.

লোডের পরে লেখা শর্তসাপেক্ষ। SDK সংস্করণটি মনে রাখে (ETag) এটি শেষ সংরক্ষণ করুন পড়ুন বা লিখুন এবং এটি ফেরত পাঠান, তাই একটি লেখা শুধুমাত্র সেই সংরক্ষণের উপরই ল্যান্ড করে যার উপর ভিত্তি করে ছিল — অথবা, একটি স্লটের জন্য যে খালি ছিল, শুধুমাত্র যখন এটি এখনও আছে. যখন অন্য ডিভাইসের মধ্যে সংরক্ষণ করা হয়, তখন লেখাটি প্রত্যাখ্যান করা হয় (412): SDK নির্গত হয় saveconflict, সেট saveConflicted(), এবং প্রত্যাখ্যান করে আরও লেখা পর্যন্ত a loadSave() গেমটিকে একত্রিত করতে বা নতুন সংরক্ষণ গ্রহণ করতে দেয়। একটি খেলা যা লোড হয় না লিখতে নিঃশর্তভাবে, আগের মত।

StarHermit.on('saveconflict', async () => {
  const remote = await StarHermit.loadJSON();       // lifts the block
  StarHermit.saveJSON(merge(remote, local));        // conditional on the version just loaded
});

নিম্ন স্তর: loadSave() / writeSave(text) কাঁচা স্ট্রিং জন্য, saveInfo() জন্য { exists, sizeBytes, updatedAt, etag }.

ক্র্যাশ এবং বাগ রিপোর্ট

খেলোয়াড়রা গেমের ভিতর থেকে সমস্যার রিপোর্ট করতে পারে; মালিক তাদের মাধ্যমে triages রিপোর্ট API.

await StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', {
  clientVersion: '1.4.2',
  attachments: [{ fileName: 'state.json', contentType: 'application/json', data: JSON.stringify(state) }],
});
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports
const mine = await StarHermit.myReports();               // [{ id, kind, status, title, ... }]

report(kind, title, description, opts) সাধারণ ফর্ম (reportBug এবং reportCrash ঠিক করুন ধরনের)। captureCrashes ফাইলগুলি প্রতি স্বতন্ত্র বার্তায় সর্বাধিক একটি রিপোর্ট এবং প্রতি পৃষ্ঠা লোড তিনটি, তাই ক ক্র্যাশ লুপ খেলোয়াড়ের দৈনিক ভাতা ব্যবহার করতে পারে না (ডিফল্টভাবে প্রতি গেম 20)। আগে খেলোয়াড়কে জিজ্ঞাসা করুন ব্যক্তিগত কিছু সংযুক্ত করা।

সেটিংস এবং নিয়ন্ত্রণ

প্রয়োজন কল
প্রতি-প্লেয়ার পছন্দ (ভলিউম, গ্রাফিক্স প্রিসেট, ভাষা, অ্যাক্সেসযোগ্যতা...) getSettings(), getSetting(key), setSetting(key, value), patchSettings({…}) (a null মান কী সরিয়ে দেয়), deleteSetting(key), clearSettings()
কীবোর্ড বাইন্ডিং ঘোষণা করা হয়েছে starhermit.txt হিসাবে control.<action>=… await loadBindings(defaults) → { action: codes[] } প্লেয়ারের ওভাররাইড প্রয়োগ করে
একটি রিবাইন্ডিং পর্দা getControls(), setControl(action, codes), setControls(bindings), resetControls()

রুট keydown মাধ্যমে event.code এবং থেকে বাঁধাই loadBindings. দেখুন আপনার খেলা নিয়ন্ত্রণ যোগ করুন এবং starhermit.txt প্রকাশ.

একটি গ্রাফিক্স মেনুর জন্য, graphics-options.js সেটিংস কলের উপরে বসে: এটি একটি গুণমান প্রিসেট স্বয়ংক্রিয়ভাবে সনাক্ত করে, প্লেয়ারের পছন্দকে রাখে localStorage এবং তাদের প্রতি খেলা সেটিংস, এবং একটি রেডিমেড প্যানেল পাঠায়। দেখুন স্বয়ংক্রিয়ভাবে সনাক্ত করা গুণমান সহ গ্রাফিক্স বিকল্প.

একটি অডিও বিভাগের জন্য, দেখুন একটি স্বয়ংক্রিয় সনাক্ত শব্দ সীমা সহ অডিও বিকল্প: প্রস্তাবিত ভলিউম এবং ভয়েস নিয়ন্ত্রণ, খাঁটি audio-options.js সাহায্যকারী, এবং আপনার মিক্সার দ্বারা প্রয়োগ করা একটি প্লেব্যাক ক্যাপ।

মাল্টিপ্লেয়ার, আমন্ত্রণ এবং সামাজিক

সেশন গেমপ্লে, ম্যাচমেকিং, গেমের অর্জন, লিডারবোর্ড এবং রিপ্লেগুলির জন্য একটি সার্ভার প্রয়োজন (স্ক্রিপ্ট বা ধারক) রিয়েলটাইম রুম এবং বন্ধুরা না। সেশন চ্যাট এবং ভয়েস সংশ্লিষ্ট কথোপকথন সদস্যতা প্রয়োজন.

একক-প্লেয়ার লিডারবোর্ড

একজন ক্লায়েন্ট কখনই স্কোর পোস্ট করতে পারে না — শুধুমাত্র গেমের সার্ভারই পারে — তাই একটি একক প্লেয়ার গেমের প্রয়োজন হয় ছোট প্ল্যাটফর্ম স্ক্রিপ্ট তার বোর্ড মালিকানাধীন. score-script.js একটি হল: এটি পরবর্তী অনুলিপি করুন আপনার খেলা, এটা ঘোষণা starhermit.txt হিসাবে server=score-script.js, এবং শুধুমাত্র তার সম্পাদনা করুন BOARDS ব্লক, যা আপনার হিসাবে প্রতিটি বোর্ড তালিকাভুক্ত করে এটি তৈরি করুন:

var BOARDS = {
  "high-score": { "name": "High score", "scoreType": "integer", "sortDirection": "desc", "minScore": 0, "maxScore": 1000000 }
};

যখন একটি রান শেষ হয়, এটি পোস্ট করুন এবং প্লেয়ারের স্থান দেখান:

const accepted = await StarHermit.submitScores({ 'high-score': total });   // [] when signed out or refused
if (accepted.includes('high-score')) {
  const board = await StarHermit.leaderboard('high-score', { pageSize: 100 });
  const me = board.items.find(e => e.userId === StarHermit.userId);
  showRank(me && me.rank);
}

submitScores একটি অনুশীলন সেশন খোলে (POST .../sessions/ai), পাঠায় {type:'result', scores} অন গেমপ্লে সকেট, এবং স্ক্রিপ্ট গৃহীত বোর্ড কীগুলি সমাধান করে; এটি নির্গত হয় scores সঙ্গে যে তালিকা স্ক্রিপ্ট এমন একটি স্কোর ড্রপ করে যা বোর্ডের প্রকারের সংখ্যা নয় বা এর বাইরে পড়ে minScore/maxScore, তার মাধ্যমে বাকি পোস্ট scores ফিরে, এবং অধিবেশন শেষ. ক্লায়েন্ট এখনও ফলাফল রিপোর্ট. একটি ইন-রেঞ্জ উদ্ভাবিত স্কোর পাস করতে পারে; এই বোর্ড নৈমিত্তিক জন্য উপযুক্ত খেলা প্রতিযোগিতার জন্য, পুরস্কার দেওয়ার আগে স্ক্রিপ্ট বা পাত্রে রান যাচাই করুন। স্বীকৃতি স্ক্রিপ্ট-স্বীকৃত কীগুলি তালিকাভুক্ত করে; এটা প্রমাণ নয় যে প্রতিটি বোর্ড সক্রিয় ছিল বা একটি নতুন ব্যক্তিগত সেরা সংরক্ষিত ছিল। দেখুন বিশ্বাস এবং প্রাপ্যতা.

পুনঃসংযোগ এবং মেয়াদ উত্তীর্ণ টোকেন

একটি সকেট তার URL-এ লঞ্চ টোকেন বহন করে এবং একটি মেয়াদ উত্তীর্ণ টোকেন সহ একটি হ্যান্ডশেক আগে প্রত্যাখ্যান করা হয় আপগ্রেড - ব্রাউজার শুধুমাত্র বন্ধ কোড রিপোর্ট 1006, ঠিক একটি নেটওয়ার্ক ড্রপ মত. তাই একটি ব্যর্থ পুনঃসংযোগ একটি প্রমাণীকরণ ব্যর্থতা হতে পারে, এবং একই URL পুনরায় চেষ্টা করা কখনই পুনরুদ্ধার করা যাবে না। পুনর্নবীকরণ শুধুমাত্র কাজ করে যখন বর্তমান টোকেনটি বৈধ এবং আসল লঞ্চের 12 ঘন্টার মধ্যে; তার পরে শুধুমাত্র লঞ্চার একটি নতুন টোকেন মিন্ট করতে পারে।

connect() এটি নিজেই পরিচালনা করে: প্রতিটি পুনঃসংযোগের আগে এটি টোকেনটি পুনর্নবীকরণ করে POST /api/v1/games/{slug}/launch-token (যদি না এটি সকেট খোলার পর থেকে পুনর্নবীকরণ করা হয়) এবং পুনরায় খোলে নতুনের সাথে। একটি নেটওয়ার্ক বা সার্ভারের ত্রুটি পুনর্নবীকরণের সময় বন্ধ হয়ে যায় এবং আবার পুনর্নবীকরণ হয় - এটি কখনই নয় পুরানো URL পুনরায় খোলে। যখন পুনর্নবীকরণ প্রত্যাখ্যান করা হয় বা টোকেনের মেয়াদ শেষ হয়ে যায়, তখন SDK সাইন আউট করে (auth সঙ্গে reason: 'expired'), পুনরায় সংযোগ এবং কল বন্ধ করে onAuthLost():

const conn = StarHermit.connect(sessionId, {
  onGame, onClose,
  onAuthLost: () => showReconnectPanel(),   // e.g. "Session expired — Back to StarHermit"
});
backButton.onclick = () => StarHermit.relaunch();

relaunch() খেলোয়াড়কে একটি নতুন লঞ্চ টোকেনের জন্য ফেরত পাঠায়: গেমটি খোলার সময় সাইন-ইন করার মাধ্যমে যেভাবে (StarHermit.launchKind === 'sign-in'), অন্যথায় লঞ্চারে। লঞ্চারের ভিতরে গেম ফ্রেম এটি উপরের উইন্ডোতে নেভিগেট করে, যা ব্রাউজার শুধুমাত্র একটি ব্যবহারকারীর অঙ্গভঙ্গি থেকে অনুমতি দেয়, তাই এটি কল করুন একটি ক্লিক থেকে; এটা ফিরে আসে false যখন নেভিগেশন প্রত্যাখ্যান করা হয়েছিল।

একটি ব্রাউজার সমাপ্ত-সেশন, শর্তাবলী, সদস্যপদ, বা বিল্ড ব্যর্থতা লুকাতে পারে 1006. আগে একটি স্বয়ংক্রিয় পুনরায় চেষ্টা, connect() REST এবং কখন সেশনের অবস্থা চেক করে opts.build সরবরাহ করা হয়, গেমের তথ্যের সাথে তুলনা করে। onUnavailable(error) একটি স্থায়ী REST ব্যর্থতা বা শেষ হয় অধিবেশন; onTermsRequired(body) সুস্পষ্ট শর্তাবলী গ্রহণ অনুরোধ. পরে একটি নতুন সংযোগ তৈরি করুন এগুলো সমাধান করা। onClose(1008) মানে সংযোগটি বাতিল বা নীতি লঙ্ঘন করা হয়েছে; না স্বয়ংক্রিয়ভাবে এটি পুনরায় খুলুন।

সকেট আপনার গেম নিজেই খোলে (realtime.socketUrl(roomId), voice.socketUrl(roomId)) প্রয়োজন একই নিয়ম একটি পুনরায় খোলার আগে, কল করুন renewForReconnect() এবং এর ফলাফলের উপর কাজ করুন:

async function reopen() {
  const r = await StarHermit.renewForReconnect();
  if (r === 'renewed') ws = new WebSocket(StarHermit.realtime.socketUrl(roomId)); // fresh token in the URL
  else if (r === 'retry') setTimeout(reopen, backoff());                         // renewal itself failed
  else if (r === 'terms-required') showTermsPanel();                              // explicit acceptance
  else showReconnectPanel();                                                     // 'relaunch'
}

সমবর্তী পুনর্নবীকরণ একটি অনুরোধ শেয়ার করুন. terms-required প্লেয়ার টোকেন সংরক্ষণ করে এবং নির্গত করে termsrequired; প্রদর্শন getTerms() এবং কল acceptTerms(displayed.hash) শুধুমাত্র খেলোয়াড়ের উপর অ্যাকশন গ্রহণ করুন, তারপর আবার চেষ্টা করুন। আপনার গেম যে সকেটগুলি পরিচালনা করে সেগুলিরও শেষ সংস্থানগুলির জন্য REST চেকের প্রয়োজন৷ এবং পলিসি ক্লোজে থামতে হবে। দেখুন সমস্যা সমাধান.

ঘটনা

StarHermit.on(type, fn) একটি আনসাবস্ক্রাইব ফাংশন প্রদান করে; off(type, fn) এছাড়াও কাজ করে।

আপনার কপি বর্তমান রাখা

ফাইলটিকে বিক্রেতা হিসাবে বিবেচনা করুন: এটি অপরিবর্তিত অনুলিপি করুন, কখনই আপনার অনুলিপি সম্পাদনা করবেন না এবং যখন এটি পাইকারি প্রতিস্থাপন করুন এই পৃষ্ঠার ফাইল পরিবর্তন. নিশ্চিত করুন যে আপনার বিল্ড বা প্যাকেজিং স্টেপ এটি গেমের পাশাপাশি পাঠানো হয়েছে অন্যান্য স্ট্যাটিক ফাইল।
