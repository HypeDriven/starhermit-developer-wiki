Amis

L'API Friends gère les demandes d'amis et les amitiés acceptées. Tous les itinéraires sont sous api/v1/me et nécessitent une autorisation. Les invitations au jeu Friendship State Gates et contrôlent également l'accès aux salles de discussion et aux salles vocales ouvertes.

Les corps d’erreur varient ; voir Conventions API.

Points de terminaison

Méthode Chemin Authentification Description
POSTE /api/v1/me/friend-requests JWT Envoyer une demande d'ami
OBTENIR /api/v1/me/friend-requests JWT Liste des demandes d'amis entrantes en attente
POSTE /api/v1/me/friend-requests/{requestId}/accept JWT Accepter une demande d'ami
POSTE /api/v1/me/friend-requests/{requestId}/decline JWT Refuser une demande d'ami
SUPPRIMER /api/v1/me/friends/{friendUserId} JWT Supprimer un utilisateur d'ami
OBTENIR /api/v1/me/friends JWT Liste des amitiés acceptées avec présence

Demandes d'amis

POST /api/v1/me/friend-requests

{ "toUserId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }

Renvoie 204.

GET /api/v1/me/friend-requests

Demandes entrantes en attente :

[
  {
    "id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "senderUserId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "senderUsername": "pk-a1b2c3d4e5f6",
    "createdAt": "2026-07-20T09:30:00Z"
  }
]

POST /api/v1/me/friend-requests/{requestId}/accept

Renvoie 204 ; les deux utilisateurs deviennent amis.

POST /api/v1/me/friend-requests/{requestId}/decline

Renvoie 204.

Amis

GET /api/v1/me/friends

Amitiés acceptées. online vient de la présence, currentGame à partir d'un lancement actif :

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

Supprime l'utilisateur. Renvoie 204.

Comment l’amitié contrôle d’autres fonctionnalités

  • Invitations à des jeux ne peut être envoyé qu'à des amis — voir Jeux.
  • Chat — des portes d'amitié rejoignant les forums de discussion ouverts ; les règles de chat exigent l'amitié pour les conversations hors jeu. Voir Chat.
  • Voix — L'accès à la salle vocale nécessite l'adhésion à la conversation de discussion d'origine, de sorte que les règles d'amitié du chat s'appliquent de manière transitive. Voir Voix.
  • Les conversations de jeu par session contournent les règles d'amitié — les joueurs d'une même session de jeu peuvent utiliser le chat/la voix attachée sans être amis.

Jetons de lancement à l'échelle du jeu

Un jeton de lancement à l'échelle du jeu peut appeler GET /api/v1/me/friends, afin qu'un jeu puisse proposer un sélecteur d'invitation à un ami au sein d'une session - l'implémentation de référence d'échecs l'utilise exactement pour cela. Les autres points de terminaison amis renvoient 403 pour les jetons de lancement ; voir les règles d'escrime à l'échelle du jeu dans Authentification.
