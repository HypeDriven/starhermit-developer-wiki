Activité

L'API d'activité couvre les sessions de lancement, la durée de lecture et le flux d'activité, à la fois pour les titres du catalogue et les jeux externes (hors catalogue). Tous les itinéraires nécessitent un JWT, sauf indication contraire.

URL de base : https://api.starhermit.com. Tous les itinéraires sont sous /api/v1/....

Sessions de lancement du catalogue et playtime

Méthode Chemin Authentification Description
POSTE /api/v1/activity/launches/{id}/end JWT Terminer une session de lancement de catalogue (204)
OBTENIR /api/v1/activity/software/{softwareTitleId}/playtime JWT Mon temps de jeu total pour un titre
OBTENIR /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 JWT Temps de jeu entre amis pour un titre

Les sessions de lancement sont démarrées par POST /api/v1/software/{id}/launch (voir catalog.md) et s'est terminé ici. Réponse pendant la récréation :

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime retours FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

Lancements externes et temps de jeu

Pour les jeux hors catalogue (bibliothèques externes liées — voir external-libraries.md):

Méthode Chemin Authentification Description
POSTE /api/v1/activity/external-launches JWT Démarrer une session pour un jeu hors catalogue
POSTE /api/v1/activity/external-launches/{id}/end JWT Terminer cette session (204)
OBTENIR /api/v1/activity/external/playtime?provider=&externalId= JWT Mon temps de jeu total pour un jeu externe
OBTENIR /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 JWT Temps de jeu des amis pour un jeu externe

POST /api/v1/activity/external-launches corps (provider ≤ 64 caractères, externalSoftwareId ≤ 256 caractères, name facultatif):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

Réponse:

{
  "launchId": "…"
}

Réponse de lecture externe :

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

Flux d'activité

Méthode Chemin Authentification Description
OBTENIR /api/v1/activity/game-feed?key=&limit=20 JWT Séances entre amis et événements de notation pour une clé de jeu
OBTENIR /api/v1/activity/friends?since=&until=&limit= JWT Activité des amis
OBTENIR /api/v1/activity/public?since=&until=&limit= Anonyme Activité publique
OBTENIR /api/v1/me/activity?since=&until=&limit= JWT Ma propre activité

Le flux du jeu revient GameFeedItemDto[] pour une clé de jeu (un guide de catalogue ou "provider:externalId", voir catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public, et me/activity retour ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

Activité type valeurs: "download", "launch", "external_launch".

/activity/friends est fermé par type d'activité sur le du propriétaire paramètre de confidentialité : les lancements suivent recentLaunchActivity, les téléchargements suivent recentDownloads. Chacun est inclus lorsque le niveau est FriendsOnly ou Public. Un compte qui n'a jamais choisi obtient les valeurs par défaut (lancements partagés avec amis, téléchargements privés). Un document de confidentialité illisible est traité comme entièrement privé. Voir profile.md.
