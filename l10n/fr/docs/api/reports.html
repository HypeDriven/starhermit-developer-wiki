Rapports de crash et de bugs

Les joueurs peuvent signaler un crash ou un bug depuis n'importe quel jeu doté d'un slug - jeux sur navigateur uniquement inclus - en utilisant le jeton de lancement du jeu ou un jeton d'utilisateur complet. Le propriétaire du jeu lit, trie et les supprime via /api/v1/me/github-games/{id}/reports.

Pour connaître les sorties du serveur et les enregistrements de crash d'un jeu conteneur, voir Serveurs de jeux hébergés par des conteneurs – Rapports de sortie et de plantage de votre serveur.

Points de terminaison

Méthode Chemin Authentification Description
POSTE /api/v1/games/{slug}/reports Jeton de lancement pour ce jeu, ou JWT Déposer un rapport de crash ou de bug
OBTENIR /api/v1/games/{slug}/reports/mine Jeton de lancement pour ce jeu, ou JWT Vos 50 derniers rapports pour ce jeu, avec leur statut
OBTENIR /api/v1/me/github-games/{id}/reports JWT (propriétaire) Liste des rapports : ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
OBTENIR /api/v1/me/github-games/{id}/reports/{reportId} JWT (propriétaire) Un rapport, avec sa liste de pièces jointes
OBTENIR /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} JWT (propriétaire) Une pièce jointe, toujours en téléchargement
CORRECTIF /api/v1/me/github-games/{id}/reports/{reportId} JWT (propriétaire) Ensemble status
SUPPRIMER /api/v1/me/github-games/{id}/reports/{reportId} JWT (propriétaire) Supprimer un rapport → 204

Déposer un rapport

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind est crash ou bug; title est requis (≤200 caractères).
  • Tout le reste est facultatif. userAgent par défaut celui de la demande User-Agent en-tête.
  • Réponse: 201 { "id", "kind", "status": "open", "createdAt" }.
Statut Signification
400 Malformé : inconnu kind, manquant title, base64 invalide ou non JSON
404 Jeu inconnu ou supprimé
413 Description, nombre de pièces jointes ou octets de pièces jointes dépassant les limites du jeu
429 Au-delà de la limite de rapport quotidien pour ce jeu ; voir Retry-After

Limites

Les opérateurs peuvent modifier chacun de ces éléments pour l'ensemble de la plateforme et pour des jeux individuels ; la limite quotidienne peut également être défini pour un seul joueur.

Limite Défaut
Rapports par joueur par match et par jour 20
Longueur de la description 20 000 caractères
Pièces jointes par rapport 4
Octets de pièces jointes par rapport 2 Mo
Rapports conservés par match 2,000
Octets conservés par jeu 256 Mo
Rétention 90 jours

Lorsqu'un jeu atteint sa limite de stockage, les rapports les plus anciens (ceux résolus en premier) sont supprimés. faire de la place. Un seul rapport plus grand que la limite totale d'octets par jeu est refusé avec 413.

Rapports de tri (propriétaire du jeu)

La liste revient { "items", "total", "page", "pageSize" }; chaque élément porte le nom du journaliste, kind, status, title, les détails du client et son nombre de pièces jointes. Déplacer un rapport vers open → acknowledged → resolved avec:

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

Les pièces jointes sont servies sous forme de téléchargements (Content-Disposition: attachment, nosniff, un bac à sable CSP). Seuls les types inertes conservent leur type de contenu déclaré : texte, JSON, PNG, JPEG, WebP, GIF, zip et gzip; tout le reste, balisage inclus, est servi comme application/octet-stream.

À partir du SDK JavaScript

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports
