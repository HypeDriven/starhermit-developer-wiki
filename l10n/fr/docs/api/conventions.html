Conventions API

Utilisations REST https://api.starhermit.com/api/v1/...; utilisation des prises wss://api.starhermit.com/ws/v1/.... Les jeux hébergés peuvent appeler /api/v1/... et /ws/v1/... sur leur propre origine. Les clients natifs utilisent le origine de l'API publique. Une page de développement sur une autre origine nécessite une origine CORS autorisée sur le jeu hôte; la définition d’une URL de base du SDK à elle seule n’autorise pas cette origine.

Demandes et réponses

Envoyez du JSON avec Content-Type: application/json, à l'exception des téléchargements bruts de bundles gzip. Noms des membres JSON sont camelCase. Envoyer les informations d'identification du porteur dans le REST Authorization en-tête.

Réponse Comment le lire
200 / 201 JSON Analyser l'objet ou le tableau documenté ; tolérer des champs supplémentaires
204 Succès sans corps ; n'appelle pas response.json()
302 Redirection de connexion/confirmation du navigateur ; naviguer plutôt que récupérer les pages OAuth
304 Lecture conditionnelle inchangée ; conserver les données que vous détenez déjà
Image, pièce jointe, sauvegarde dans le cloud Lire des octets à l'aide du type de contenu de réponse et du contrat de point de terminaison
Erreur Lisez d'abord le statut, puis analysez le corps de manière défensive

La forme d'erreur courante est { "error": "...", "code": "..." }, avec des champs optionnels selon le point final. error est souvent lisible par l'homme ; code est un discriminateur stable lorsqu'il est fourni. Les termes et certains autres points finaux placent un discriminateur directement dans error. Certains points de terminaison renvoient clairement texte, un corps vide ou un objet de validation Détails du problème avec title, status et errors. Les clients ne doivent pas supposer que chaque réponse infructueuse est JSON ou comporte les mêmes champs.

export async function readResponse(response) {
  if (response.status === 204 || response.status === 304) return null;
  const text = await response.text();
  let body;
  try { body = text ? JSON.parse(text) : null; } catch { body = text || null; }
  if (!response.ok) {
    const message = (body && typeof body === 'object' && (body.error || body.message || body.title))
      || (typeof body === 'string' && body) || response.statusText;
    throw Object.assign(new Error(message), {
      status: response.status, code: body?.code, body,
      retryAfter: response.headers.get('Retry-After'),
    });
  }
  return body;
}

Heure, tailles et valeurs nulles

  • createdAt, updatedAt, finishedAt, et les horodatages de comptes/ressources similaires sont des chaînes ISO 8601 avec un décalage. Traiter absent ou null valeurs facultatives comme indisponibles.
  • ctx.now, summary.deadline, liste de sessions deadline, et /time.serverTime sont des entiers Unix millisecondes. Convertir avec new Date(value), pas Date.parse(value).
  • Les valeurs limites en octets sont des octets et non des caractères Base64. Un téléchargement JSON Base64 est plus volumineux que son contenu décodé. Utilisez la limite effective signalée par un point de terminaison lorsqu'elle est disponible.
  • Omission, null, et un objet vide ne sont pas universellement équivalents. Paramètres PATCH supprime un clé nommée avec null; paramètres à une seule touche PUT magasins null comme valeur. Collection PUT remplace toute la carte. Lisez les règles de mise à jour de chaque point de terminaison.
  • Un patch de paramètres fusionne clés de niveau supérieur. Une valeur d'objet fournie remplace la valeur de cette clé ; il ne fusionne pas de manière récursive les propriétés imbriquées.

Pagination

La pagination est basée sur un emplacement page/pageSize sont pris en charge. Différentes API ont délibérément des enveloppes de réponse ; ne réutilisez pas un analyseur qui prend un seul nom de champ de comptage.

Zone Forme de collecte Taille de page par défaut/maximale
Titres et builds de logiciels { items, totalCount, page, pageSize } 20 / 100
Messages de discussion { conversationId, items, totalCount, page, pageSize } 50 / 100
Entrées au classement { items, total, page, pageSize } 20 / 100
Logiciel externe { items, total, page, pageSize } 20 ; demander une petite taille de page positive
Rapports, enregistrements de crash de conteneur, listes de modération { items, total, page, pageSize } 20 / 100
Sessions, amis, listes de jeux, réalisations Tableaux Plafonds spécifiques aux points de terminaison ; pas de curseur générique de page suivante
Flux de retrait de modération Basé sur un curseur Conserver le curseur renvoyé ; récupérer de 410 comme documenté

Les métadonnées de pagination de réponse reflètent la page servie lorsqu'elle est disponible. Pages de référence et contrats lisibles par machine décrire les paramètres de requête spécifiques au point de terminaison.

Nouvelle tentative et concurrence

Situation Action
Jeton d'accès au compte rejeté avec 401 Actualiser une fois, à l'aide d'une demande d'actualisation partagée ; puis connectez-vous si refusé
Le jeton de lancement a expiré Obtenez un nouveau jeton via la connexion/le lanceur ; les jetons expirés ne peuvent pas se renouveler
403 terms_acceptance_required Afficher et accepter explicitement les conditions actuelles, puis réessayer
Autre 403 Résoudre la portée, l'adhésion, les autorisations ou l'état du compte ; ne pas actualiser en boucle
409 Résoudre les conflits de duplication/état/révision ; relire avant de changer une ressource
Sauvegarde dans le cloud 412 Chargez la version la plus récente et laissez le jeu le fusionner ou l'adopter
429 ou temporaire 503 Honneur Retry-After, ajoute de la gigue et des tentatives liées
Panne de réseau lors d'une écriture Le résultat peut être inconnu ; inspecter l'état de la ressource avant de répéter l'action

Retry-After peut être des secondes ou une date HTTP. N'inventez pas d'en-tête d'idempotence : l'API ne promettre un mécanisme général d’idempotence. Une nouvelle tentative de création de session ou une invitation peut créer une autre ressource ou en conflit avec la première. Préférez les lectures et les opérations explicitement idempotentes pour tentatives automatiques. Actualisez la rotation, terminez les téléchargements, le consentement aux conditions et les résultats du jeu du terminal chacun ont leurs propres règles.

Pour les écritures de comparaison et d'échange, utilisez les ETags enregistrés dans le cloud, room expectedRevision, ou révisions de modération où pris en charge. Une écriture réussie ne signifie pas nécessairement un déploiement de conteneur terminé ; vérifier son statut avant d’envoyer les joueurs vers une nouvelle construction. Voir dépannage.
