Bibliothèques externes

Lier la bibliothèque Steam, Epic ou GOG d'un utilisateur afin que ses jeux externes puissent être répertoriés, lancés et suivis. Tous les itinéraires nécessitent un JWT.

URL de base : https://api.starhermit.com. Tous les itinéraires sont sous /api/v1/....

Lier et dissocier

Méthode Chemin Authentification Description
OBTENIR /api/v1/me/external-libraries JWT Lister mes fournisseurs liés
POSTE /api/v1/me/external-libraries/link JWT Associer un fournisseur et synchroniser ses titres
SUPPRIMER /api/v1/me/external-libraries/{provider} JWT Supprimer un lien et ses propriétés

Bibliothèques liées :

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

Corps du lien :

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

Renvoie 204. La liaison synchronise également les titres du fournisseur. La synchronisation de la bibliothèque renvoie actuellement les titres de démonstration pour steam/epic/gog tandis que les véritables intégrations des fournisseurs sont finalisées.

Logiciel externe possédé et lancement

Méthode Chemin Authentification Description
OBTENIR /api/v1/me/external-software?provider=&page=&pageSize= JWT Liste paginée de mes titres externes
POSTE /api/v1/external-software/{ownershipId}/launch JWT Obtenez un URI de lancement et enregistrez un lancement externe

Liste des logiciels externes :

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

Réponse de lancement :

{
  "launchUri": "steam://run/…"
}

Formats d'URI de lancement par fournisseur : steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. Le lancement enregistre une activité de lancement externe — voir activity.md. Les jeux externes utilisent la clé de jeu uniforme "provider:externalId" pour les notes et les flux - voir catalog.md.
