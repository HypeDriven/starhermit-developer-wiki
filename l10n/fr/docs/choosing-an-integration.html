Choisissez une intégration

Commencez par où votre jeu se déroule et qui valide le gameplay. Un jeu par navigateur hébergé n'a pas besoin d'un backend du serveur pour utiliser la connexion, les sauvegardes dans le cloud, les paramètres, les commandes ou les salles en temps réel.

Trois points de départ communs

Un jeu par navigateur solo : suivre le démarrage rapide du navigateur. Offre Connectez-vous avec StarHermit pour la progression du compte et Jouez en solo (la progression n'est pas enregistré) pour un jeu immédiat. Commencez sans backend ; ajoutez-en un lorsque vous avez besoin d'un concours validé résultats. Les paramètres et les sauvegardes dans le cloud ne nécessitent pas de server= doubler.

Multijoueur occasionnel avec des amis : utiliser salles en temps réel. L'hôte gère le simulation, les invités envoient des entrées et l'hôte diffuse des instantanés. Votre jeu implémente l'IA et l'hôte les migrations. La plateforme fournit des sièges, une identité et un itinéraire. La confiance dans l’hôte fait partie de ce modèle.

Multijoueur classé ou persistant : utiliser un scénario ou un conteneur, avec des chambres si vous avez besoin d'un lobby. Valider le gameplay avant attribuer quoi que ce soit. Les scripts demandent un taux de tick dans le plafond pris en charge (30 Hz par défaut) ; les conteneurs exécutent leur propre boucle de simulation. Le jumelage direct de conteneurs a actuellement un implicite File d'attente 1v1, mais une salle peut créer une session conteneur à N joueurs.

L'UUID d'un jeu hébergé est son slug API et son sous-domaine. Les noms d'affichage et les noms de référentiel ne sont pas des API identifiants. Voir informations d'identification et identifiants avant les demandes de câblage.

Les sauvegardes cloud contiennent un document opaque par emplacement, pas un historique des correspondances. Les rediffusions contiennent le état de session terminée que votre backend a choisi de conserver, pas une vidéo ou une entrée enregistrée automatiquement flux. Voir épargner en toute sécurité et cycle de vie des sessions.
