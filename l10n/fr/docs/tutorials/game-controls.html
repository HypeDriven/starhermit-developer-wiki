Tutoriel : ajouter des contrôles à votre jeu

StarHermit peut stocker raccourcis clavier pour votre jeu : vous déclarez les actions et leurs touches par défaut, et chaque joueur peut les relier. Leur choix les suit jusqu’à n’importe quelle machine sur laquelle ils se connectent. Votre jeu lit les liaisons du lecteur à partir de l'API des contrôles et peut proposer les siennes "relier les clés" écran.

Si votre jeu appelle l'API des contrôles et obtient ceci :

404 {"error":"This game declares no controls."}

la plateforme a aucune action déclarée pour la construction qu'il sert. Rien de ce que vous envoyez à l'API ne peut corrigez cela : les contrôles sont déclarés dans le fichier de votre jeu starhermit.txt et lis quand le jeu est publié. Cette page montre comment les déclarer, les publier, vérifier leur arrivée, et utilisez-les auprès de votre client.

  2. Publiez-les
  3. Vérifiez qu'ils sont arrivés

1. Déclarer les actions

Ajoutez-en un control.<action>= ligne par action à starhermit.txt:

name=Space Hopper
launch=index.html

control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.jump=Space+KeyW | Jump
control.fire=KeyJ | Fire
control.pause=Escape | Pause

Chaque ligne comporte trois parties :

control.<action>=<code>[+<code>...][ | <label>]
Partie Règles
<action> Le nom de votre jeu pour l'action : 1 à 32 caractères de lettres minuscules, de chiffres et _ (move_left, pas move-left). Unique par manifeste.
<code> A KeyboardEvent.code valeur, comme KeyA, ArrowLeft, Space, Digit1, ShiftLeft, Enter ou Escape. Joignez 1 à 4 codes pour la même action avec +.
<label> Facultatif. Affiché dans les écrans de reliure ; au maximum 64 caractères. La valeur par défaut est le nom de l'action.

Choses à savoir :

  • Utiliser code, pas key. Écrire KeyA, pas a, et Space, pas " ". Les codes nomment le physique clé, de sorte que les liaisons fonctionnent sur n’importe quelle disposition de clavier. La plateforme vérifie uniquement qu'un code est compris entre 1 et 32 des lettres et des chiffres, donc a ou space est accepté mais aucune clé ne le produit jamais. Orthographe et casse doit correspondre exactement.
  • Une clé appartient à une action. Un code déjà utilisé par une ligne précédente rend la ligne suivante invalide.
  • Jusqu'à 32 actions par match. Les lignes après le 32 sont ignorées.
  • La commande est conservée. Les actions reviennent de l'API dans l'ordre manifeste, alors listez-les de la manière votre écran de paramètres devrait les afficher.
  • Une ligne invalide est ignorée silencieusement. Le jeu est toujours publié. Si chaque ligne est invalide, le jeu n'a aucun contrôle et l'API répond 404. Vérifier après la publication.

2. Publiez-les

Les déclarations sont lues quand le jeu est publié. Édition starhermit.txt dans votre dépôt ou sur le disque ne change rien jusqu'à ce que vous publiiez une build qui le contient :

Comment votre jeu est publié Qu'est-ce qui rend les nouveaux contrôles actifs
Depuis un dépôt GitHub Votre prochain déploiement. Poussez le changement, puis déployez la dernière version (Mettre à jour la version déployée dans le tableau de bord, ou PUT /api/v1/me/github-games/{id}/deployment).
Dossier ou bundle téléchargé Téléchargez une nouvelle version (POST /api/v1/me/github-games/{id}/bundle, ou ws/v1/game-upload) dont starhermit.txt a les lignes.
Ajouter un nouveau jeu Le premier téléchargement ou soumission les lit immédiatement.

Un téléchargement de remplacement reformule vos contrôles à partir de son propre manifeste. Supprimer chaque control.* ligne et le jeu n'en a pas. UN ?mode=merge patcher ça ne porte pas starhermit.txt conserve les contrôles actuels.

Les propres reliures des joueurs survivent à une nouvelle construction. La liaison enregistrée d'un joueur pour une action qui ne existe plus est ignoré.

3. Vérifiez qu'ils sont arrivés

Chaque point de terminaison ci-dessous fonctionne avec un jeton d'utilisateur complet ou le jeton de lancement de votre jeu. {slug} est votre slug du jeu : le jeton de lancement game_scope réclamation, ou gameSlug dans GET /api/v1/me/github-games.

curl -s "https://api.starhermit.com/api/v1/games/$SLUG/controls" \
  -H "Authorization: Bearer $TOKEN" | jq

{
  "actions": [
    { "action": "left",  "label": "Move left",  "defaultCodes": ["KeyA", "ArrowLeft"],  "codes": ["KeyA", "ArrowLeft"] },
    { "action": "right", "label": "Move right", "defaultCodes": ["KeyD", "ArrowRight"], "codes": ["KeyD", "ArrowRight"] },
    { "action": "jump",  "label": "Jump",       "defaultCodes": ["Space", "KeyW"],      "codes": ["Space", "KeyW"] },
    { "action": "fire",  "label": "Fire",       "defaultCodes": ["KeyJ"],               "codes": ["KeyJ"] },
    { "action": "pause", "label": "Pause",      "defaultCodes": ["Escape"],             "codes": ["Escape"] }
  ]
}

Les actions manquantes signifient que leurs lignes n'étaient pas valides ; comparez-les aux règles ci-dessus. UN 404 signifie qu'aucun n'a survécu ou que la version qui les déclare n'a pas encore été publiée.

4. Utilisez-les dans votre jeu

codes est la liaison effective du joueur : sa priorité s'il en définit une, sinon votre valeur par défaut. Créez une recherche à partir de celui-ci et faites correspondre event.code:

const auth = { Authorization: `Bearer ${launchToken}` };

// Your built-in defaults, in the same shape the API returns.
const DEFAULT_ACTIONS = [
  { action: "left", label: "Move left", codes: ["KeyA", "ArrowLeft"] },
  { action: "jump", label: "Jump", codes: ["Space", "KeyW"] },
  /* ... */
];

function toControls(actions) {
  const byCode = new Map();
  for (const a of actions) for (const code of a.codes) byCode.set(code, a.action);
  return { actions, byCode };
}

async function loadControls(slug) {
  try {
    const res = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
    if (res.ok) return toControls((await res.json()).actions);
  } catch { /* offline: fall through */ }
  return toControls(DEFAULT_ACTIONS);                   // 404, error, or outside StarHermit
}

let controls = await loadControls(gameScope);

window.addEventListener("keydown", (e) => {
  const action = controls.byCode.get(e.code);   // e.code, never e.key
  if (action) { e.preventDefault(); onAction(action, true); }
});
window.addEventListener("keyup", (e) => {
  const action = controls.byCode.get(e.code);
  if (action) onAction(action, false);
});

Les paramètres par défaut intégrés permettent de jouer au jeu hors ligne, en dehors de StarHermit ou si les commandes la demande échoue. Gardez-les en phase avec votre control.* lignes.

Un écran de reliure. Liste actions avec leur label. Conservez la carte de remplacement complète, ou lisez et conservez la carte effective actuelle avant de modifier une action :

async function saveBinding(slug, action, codes) {
  const current = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
  if (!current.ok) throw new Error(`Controls read failed: ${current.status}`);
  const bindings = Object.fromEntries((await current.json()).actions.map(a => [a.action, a.codes]));
  bindings[action] = codes;
  const res = await fetch(`/api/v1/games/${slug}/controls`, {
    method: "PUT",
    headers: { ...auth, "Content-Type": "application/json" },
    body: JSON.stringify({ bindings }),
  });
  if (!res.ok) throw new Error((await res.json()).error);   // e.g. a key already in use
  return res.json();                                         // the new effective map
}

PUT remplace les remplacements du joueur par les actions que vous envoyez, incluez donc chaque action du joueur a changé, pas seulement le dernier. Le reste reste sur vos valeurs par défaut. DELETE sur le même chemin réinitialise tout aux valeurs par défaut.

Sérialisez les modifications depuis votre écran ; deux lectures/écritures simultanées peuvent toujours s'écraser. Les SDK du navigateur setControl() sérialise ses propres modifications et préserve la carte effective actuelle. L'envoi de la carte effective épingle ces valeurs en tant que remplacements ; utiliser DELETE pour revenir aux valeurs par défaut du manifeste.

La plateforme refuse une sauvegarde (400) cela laisserait une clé sur deux actions après celui du joueur les modifications sont fusionnées avec vos valeurs par défaut. Par exemple, la liaison jump à KeyJ alors que fire encore utilise sa valeur par défaut KeyJ est refusé. Afficher l'erreur ou déplacer l'action en conflit dans le même sauvegarder.

Dépannage

Réponse Cause Réparer
404 "Ce jeu ne déclare aucun contrôle." Non valide control.* ligne dans le publié construire. Ajouter des lignes à starhermit.txt, comparez-les les règles, et publier une nouvelle version.
404 "Pas de jeu avec cette limace." Le slug est faux, ou le jeu n'a pas de slug. Utilisez le jeton de lancement game_scope ou gameSlug depuis GET /me/github-games. Chaque jeu ajouté à partir d'un dossier local et chaque jeu de référentiel ajouté par un propriétaire vérifié a un slug, navigateur uniquement ou non. Seule une soumission de référentiel dont le propriétaire n'est pas vérifié n'en a pas ; revendiquez-le pour en obtenir un.
403 "Ce jeton est limité au jeu «…»." Un jeton de lancement utilisé avec le slug d'un autre jeu. Appelez avec le slug dans le jeton game_scope.
400 "Action inconnue '…' — non déclarée dans le manifeste du jeu." PUT nommé une action que le manifeste ne déclare pas. Utiliser action valeurs de GET …/controls.
400 "'…' est lié à la fois à '…' et à '…'." Après avoir fusionné avec vos valeurs par défaut, une touche déclencherait deux actions. Déplacez l'autre action dans le même PUT, ou choisissez une autre clé.
400 "'…' n'est pas une valeur KeyboardEvent.code valide." Un code avec des espaces ou des signes de ponctuation. Envoyer event.code valeurs.
400 "L'action «…» doit lier 1 à 4 codes." Une liste vide, ou plus de quatre. Envoyez 1 à 4 codes ; DELETE pour réinitialiser.
Une action est manquante dans la réponse Sa ligne n'était pas valide : une lettre majuscule ou - dans le nom de l'action, , au lieu de +, plus de 4 codes, un code déjà utilisé, ou passé la 32ème action. Corrigez la ligne et publiez à nouveau.
Une liaison ne se déclenche jamais Le code est accepté mais aucune clé ne le produit, comme par exemple a ou space. Utiliser exactement KeyboardEvent.code orthographe: KeyA, Space.
