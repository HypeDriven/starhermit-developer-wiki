SDK de unidad

El SDK de unidad Starhermit (HypeDriven/starhermit-unity-sdk) es un paquete de Unity Package Manager con clientes C# asincrónicos y escritos para la plataforma. Se encarga Solicitudes HTTP, análisis JSON, actualización de tokens y reconexión WebSocket.
Paquete com.starhermit.sdk, versión 0.1.0
Espacio de nombres Starhermit
Línea base de API REST v1 y WebSocket v1
Funciones REST más nuevas Usar client.Raw y modelo RawJson cuando esta versión del SDK no tiene ningún miembro escrito
Protocolos WebSocket los 6, una clase de conexión cada uno
Licencia MIT

El SDK es un cliente, no una segunda implementación de la plataforma. Autorización, amistad, Permanencia de derechos, membresía de sala, validación de puntuación, resultados de juegos y presupuestos de almacenamiento. servidor autorizado exactamente como se documenta en las páginas siguientes: el SDK muestra la respuesta del servidor y sus límites publicados en lugar de decidir o almacenar en caché los suyos propios.

Esta página es la guía de integración. La documentación completa del paquete se encuentra en el repositorio en Packages/com.starhermit.sdk/Documentation~.

Requisitos

  • Unity 2021.3 LTS o posterior, nivel de compatibilidad API Estándar .NET 2.1, C# 9.
  • Mono e IL2CPP, con eliminación administrada desde Desactivado hasta Alto (el paquete se envía solo Runtime/link.xml).
  • Sin reflexión, sin generación de código dinámico, sin complemento nativo obligatorio.

Cada módulo se compila para cada objetivo de compilación. Cuando un objetivo realmente carece de capacidad, no micrófono en un servidor sin cabeza, sin encabezados de protocolo de enlace en un navegador: la llamada se eleva StarhermitFeatureUnavailableException con un establo Reason, en lugar de fallar la construcción o deshabilitar funciones no relacionadas.

Instalar

Administrador de paquetes → Agregar paquete desde la URL de git, o una entrada en Packages/manifest.json. el paquete se encuentra en una subcarpeta del repositorio, por lo que la URL debe path=:

{
  "dependencies": {
    "com.starhermit.sdk": "https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk"
  }
}

Fijar un lanzamiento agregando #<tag-or-commit>:

https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk#v0.1.0

La unidad desembolsa git, por lo que un repositorio privado se resuelve solo si el git del editor puede autenticarse de forma no interactiva: una clave SSH (git@github.com:HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk) o un asistente de credenciales configurado. Una ruta local o un registro de ámbito funciona de la misma manera. Importar modifica no configuración del proyecto y no realiza ningún acceso a la red.

crear un cliente

using Starhermit;

var client = StarhermitClient.Create(new StarhermitOptions
{
    ApiBaseUri = new Uri("https://api.starhermit.com/api/v1/"),
    GameSlug   = "83fd04b1-3cbe-4b09-a251-3733ad4b9d94",
    TokenStore = myPlatformSecureStore,
    LogLevel   = StarhermitLogLevel.Warning
});

await client.InitializeAsync();               // loads a stored session, refreshes it if expired
var me = await client.Me.GetProfileAsync();

Create no realiza E/S. Nada toca la red hasta que inicializas, llamas a un servicio o abres una conexión. La base de WebSocket se deriva de ApiBaseUri (wss://<host>/ws/v1/) a menos que establezca WebSocketBaseUri tú mismo.

StarhermitClient es IDisposable: la eliminación cancela las solicitudes en vuelo, cierra todas las conexiones que entregado, detiene los latidos del corazón y libera audio. No hay ningún estado mutable estático en el paquete, por lo que dos clientes pueden ejecutarse uno al lado del otro en diferentes entornos y un cliente sobrevive a las cargas de escenas.

Un juego publicado en la plataforma. se sirve de https://<slug>.starhermit.com con /api y /ws proxy del mismo origen (ver Juegos de GitHub). Una compilación de WebGL publicada que way debe apuntar a su propio origen para que el navegador realice llamadas al mismo origen:

ApiBaseUri = new Uri("https://83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com/api/v1/") // your game's uid

Para un servidor local, AllowInsecureTransport = true permisos http/ws. La construcción del cliente rechaza una dirección que no es HTTPS sin ella, y la validación de compilación del editor falla en una compilación de reproductor que no es de desarrollo Eso todavía lo tiene configurado. Nunca deshabilita la validación de certificados.

Iniciar sesión

Los tres tipos de credenciales descritos en Autenticación son tipos separados en separados tiendas en el SDK; ninguno puede sustituir a otro.

OAuth — el SDK abre la URL autorizada a través de una inyección IStarhermitOAuthBrowser y completa el intercambio:

var session = await client.Auth.SignInWithOAuthAsync("google");

Usar BuildAuthorizeUri(provider) más CompleteOAuthAsync(...) en cambio, cuando su plataforma entrega el redireccionar a través de su propio enlace profundo o de su propio sistema de navegación integrado.

Clave pública — el flujo sin contraseña para reproductores integrados, de consola y de servidor dedicado (ver Servidor dedicado + incorporación de jugadores integrados). Los tipos de claves admitidos son Ed25519, ECDSA-P256 y RSA-PSS; el SDK nunca genera ni almacena un clave privada, llama a una inyectada IStarhermitSigner:

var session = await client.Auth.SignInWithPublicKeyAsync(signer);   // or (), using Options.Signer

Detalle del contrato que vale la pena conocer. La implementación verifica una firma de desafío con la suya propia. PascalCase serializa el desafío, mientras que el JSON que recibe es camelCase: re-serializar la respuesta nunca se verificaría. StarhermitChallenge.CanonicalPayload reproduce los bytes exactos a firmar, por lo que la firma enrollada a mano debe hacer lo mismo.

Ficha de lanzamiento del juego — acuñado por juego y cercado en la superficie de ese juego:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();
var fenced = chess.WithLaunchToken();     // subsequent calls authorise with the launch token

La acuñación de un token de lanzamiento nunca reemplaza la sesión de la cuenta. ¿Qué credencial lleva una solicitud? decidido por la canalización de solicitudes, no por el servicio al que llamó.

La actualización del token de acceso se coordina: a 401 compra como máximo una actualización y una repetición, y simultáneamente las personas que llaman esperan la misma actualización en lugar de iniciar varias: con un token de actualización rotativo, un segundo El intercambio revocaría la familia y firmaría la salida del jugador. Se plantea un rechazo definitivo SessionExpired una vez; un error de transporte deja la sesión intacta.

Aceptando los términos actuales

Verifique la aceptación antes de iniciar latidos, solicitudes de juegos o sockets. La versión 0.1.0 tiene AcceptTermsAsync, pero los campos de perfil más nuevos y el descubrimiento de términos utilizan su soporte JSON sin formato:

var profile = await client.Me.GetProfileAsync(ct);
var needsAcceptance = profile.RawJson["termsAcceptanceRequired"].AsBooleanOrDefault();
var terms = await client.Raw.SendForJsonAsync(new StarhermitRequest("GET", "terms"), ct);
var textToDisplay = terms["text"].AsStringOrNull();
var displayedHash = terms["hash"].AsStringOrNull();
// Display textToDisplay. Retain displayedHash for this displayed revision.
// Only in the user's Accept handler, using an account session:
// await client.Me.AcceptTermsAsync(displayedHash, ct);

No utilice una etiqueta de revisión de muestra como terms-2026-08: solo se muestra el hash actual de la API aceptado. En 409, busque y muestre el nuevo texto para otra aceptación. En 403 terms_acceptance_required, resuelva la aceptación antes de volver a intentarlo; Los tokens de lanzamiento del jugador también pueden enviar la aceptación a través de la API después del consentimiento explícito. Ver Perfil para el flujo completo.

Una sesión de principio a fin

El ciclo de vida desde el tutorial de integración, Cª#:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();

var ticket = await chess.EnqueueMatchmakingAsync();
while (!ticket.IsMatched)
{
    await Task.Delay(TimeSpan.FromSeconds(2), ct);
    ticket = await chess.GetMatchmakingAsync(ct) ?? ticket;
}

using var game = client.CreateGameConnection(ticket.SessionId!.Value, "83fd04b1-3cbe-4b09-a251-3733ad4b9d94", useLaunchToken: true);
game.FrameReceived       += frame => ApplyServerState(frame);
game.AchievementUnlocked += unlock => ShowToast(unlock);
game.PresenceChanged     += (userId, online) => UpdateOpponentDot(userId, online);
game.ErrorReceived       += message => ShowError(message);

await game.ConnectAsync(ct);
await game.SendCommandAsync(writer =>
{
    writer.Write("type", "move");
    writer.Write("from", "e2");
    writer.Write("to",   "e4");
}, ct);

SendCommandAsync envuelve la carga útil como {"type":"cmd","data":…}; SendRealtimeInputAsync es el ruta de velocidad limitada para entrada continua. La conexión no sigue la lógica del juego, predice con autoridad. declarar, fabricar un resultado o reenviar una orden posiblemente no idempotente después de una respuesta ambigua. desconectar: el servidor sigue siendo la única autoridad sobre lo sucedido.

Cada conexión comparte una máquina de estados: Disconnected, Connecting, Connected, Reconnecting, Closing, Faulted, con StateChanged, Closed y Faulted eventos, colas salientes acotadas con contrapresión explícita y envíos ordenados. La reconexión utiliza un retroceso nervioso, vuelve a adquirir una corriente ficha antes de cada intento, y se detiene definitivamente en una autorización o cierre de política en lugar de Golpeando una puerta, la plataforma se cerró. Nunca asume que los miembros sobrevivieron a la brecha: cada protocolo vuelve a buscar o se vuelve a unir al volver a conectarse.

Las credenciales viajan Authorization encabezado donde la plataforma lo permite y ?access_token= en /ws/** de lo contrario, porque un navegador no puede configurar encabezados de protocolo de enlace. El token de consulta está redactado de cada registro.

Asíncrono, subprocesos y Unity

Cada operación de E/S regresa Task y toma un rastro CancellationToken. no hay async void métodos y ningún método público bloquea el hilo de llamada.

Los eventos y las devoluciones de llamadas de progreso se publican en el contexto de sincronización en el que se creó el cliente, por lo que si lo crea en el hilo principal de Unity, un controlador puede tocar GameObjects directamente. Un servidor sin cabeza puede saltar el salto con options.CallbackDispatcher = ImmediateCallbackDispatcher.Instance. Las devoluciones de llamada son ordenado por conexión, y un controlador que lanza se informa al diagnóstico sin detener el bucle de recepción.

StarhermitLifecycle.Attach(client) une los eventos de la aplicación de Unity: el latido del corazón de presencia se detiene en suspensión y se envía inmediatamente al currículum, y el cliente es eliminado sin sincrónico trabajo en red.

Los modelos nunca hacen referencia GameObject, MonoBehaviour o una escena. StarhermitTextures convierte avatar y bytes de portada en un Texture2D en el hilo principal: la persona que llama posee el resultado y debe destruirlo.

Cada uno lleva el estado, el del servidor. {"error":"..."} mensaje, cualquier código legible por máquina, la solicitud identificación, Retry-After, encabezados redactados y un cuerpo redactado con límites de tamaño. Una petición que nunca llegó a Aumentos de API StarhermitTransportException o StarhermitTimeoutException — nunca se produce un fallo en el transporte disfrazado de respuesta API. La cancelación siempre surge como OperationCanceledException.

Los reintentos están limitados, nerviosos, honor Retry-After hasta un límite, y están limitados a fallas por segundo el intento podría sobrevivir: errores de conexión, tiempos de espera, 408, 429 y transitorio 5xx. 403, 404, 409 y las fallas de validación nunca se reintentan, y una POST se reintenta solo cuando acepta AsIdempotent. Un presupuesto de reintento en todo el proceso evita que varios clientes conviertan una interrupción en una tormenta.

Lista de retorno de puntos finales StarhermitPage<T> llevar los propios metadatos de paginación del servidor, además de lazy enumeración que recupera una página solo cuando se consume:

await foreach (var title in client.Software.EnumerateTitlesAsync(query, cancellationToken: ct)) { … }

Las descargas se transmiten a un IStarhermitFileStore a través de un archivo temporal, verifique un SHA-256 suministrado y se promueven atómicamente; OpenDownloadAsync informes IsResumed solo de verdad 206, porque agregar un archivo completo a uno parcial lo dañaría y al mismo tiempo pasaría una verificación de longitud.

Almacenamiento de credenciales

el paquete no envía ninguna tienda que pretenda ser segura. El valor predeterminado está en memoria; el opt-in EncryptedFileTokenStore (AES-CBC con HMAC-SHA256 a través de una clave que proporciona su aplicación) está documentado como ofuscación en reposo, no como llavero. Cable IStarhermitTokenStore a la propia plataforma segura almacenamiento: llavero, almacén de claves, almacenamiento de usuario del SDK de la consola. PlayerPrefs nunca se presenta como seguro.

Los tokens, tokens de actualización, claves privadas, secretos de cliente y claves de invocación nunca se serializan en un ScriptableObject, una escena, Resources, un registro, un mensaje de excepción, un evento de telemetría o una compilación artefacto. StarhermitSettings solo contiene valores predeterminados del proyecto no secretos: direcciones, slug, nivel de registro, tiempo de espera y la bandera de desarrollo.

La redacción es estructural (por encabezado, parámetro de consulta y nombre de miembro JSON, en cada profundidad), por lo que una La credencial de la que esta versión del SDK nunca ha oído hablar todavía está eliminada de los registros, excepciones y telemetría. Los fragmentos de URL se eliminan por completo. No se recopila ninguna telemetría de forma predeterminada; un fregadero inyectado recibe nombre del evento, identificación de la operación, duración, familia de estados, recuento de reintentos, identificación de la solicitud y resultado, nunca URL, cuerpos o contenido del reproductor.

Cuando la plataforma envía algo nuevo

Los modelos son inmutables y mantienen el JSON desde el que fueron analizados, por lo que se agrega un campo a la implementación después esta versión del SDK aún se puede leer y un punto final que esta versión no escribe aún se puede llamar con las mismas credenciales, reintentos y redacción que una llamada escrita:

var value = profile.RawJson["shippedAfterThisSdk"].AsStringOrNull();

var json  = await client.Raw.SendForJsonAsync(
    new StarhermitRequest("GET", "some/new/route").WithQuery("page", 1), ct);

Los marcos de socket se envían según su discriminador de tipo con un respaldo de marco desconocido que preserva el carga útil, las cadenas de enumeración desconocidas se mantienen como cadenas en lugar de ser coaccionadas, y un nivel de privacidad desconocido se lee como el mayoría Interpretación privada. Optional<T> distingue nulo omitido, explícito y valor, que es lo que necesita un cuerpo PATCH.

client.GetDiagnostics() devuelve estados de conexión, profundidad de cola, recuentos de reconexión, vencimiento de token, reloj actualización, solicitudes en curso, reintentos realizados y el último error redactado: la instantánea para adjuntar a un informe de error.
