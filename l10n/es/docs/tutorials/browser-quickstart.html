Crea tu primer juego de navegador alojado

Descargar Coleccionista de Estrellas, un pequeño juego completo con dos entradas. opciones: juego en cuenta con guardado en la nube y juego para un jugador cuyo progreso se guarda solo en la memoria. Prueba el juego sin firmar en esta wiki; el inicio de sesión de la cuenta se convierte disponible después de publicar su propia copia en StarHermit.

Necesita una cuenta StarHermit para publicar. El juego en sí no necesita servidor backend ni dependencia. instalación, paso de compilación u organización del editor.

1. Descomprime y juega localmente

El ZIP contiene index.html, app.js, style.css, starhermit.txty los dos archivos auxiliares. Sirva la carpeta extraída con un servidor estático local, por ejemplo:

python3 -m http.server 8000 --directory star-collector

Aquí star-collector es la carpeta en la que extrajiste. Abierto http://localhost:8000 y elige Juega para un jugador (el progreso no se guarda). Haga clic en la estrella. Volver al inicio o recargar inicia una nueva ejecución sin seguimiento. Este modo no escribe ni el progreso local ni el progreso de la cuenta.

2. Publicar la carpeta distribuible.

El manifiesto ya está en la raíz de la carpeta:

name=Star Collector Quickstart
launch=index.html
description=A small single-player game with account saves or untracked play.

En la interfaz de usuario de publicación de juegos de StarHermit, agregue esta carpeta como un juego nuevo. Toda la carpeta seleccionada es la compilación publicada. Conserve sólo los archivos que desea publicar. El equivalente API empaqueta los archivos. bajo client/ y envía un archivo gzip sin formato:

mkdir -p bundle/client
cp -R star-collector/. bundle/client/
cp star-collector/starhermit.txt bundle/starhermit.txt
# Write the archive outside bundle so it cannot include itself.
tar -C bundle -czf star-collector.tar.gz .

curl --fail-with-body -X POST https://api.starhermit.com/api/v1/me/github-games/upload \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H 'Content-Type: application/gzip' \
  --data-binary @star-collector.tar.gz

ACCESS_TOKEN es el token completo de su cuenta, después de la aceptación explícita de los términos actuales. la respuesta game.id, game.gameSlugy el subdominio alojado identifican tu juego. Abra la URL alojada devuelta. Para lanzamientos posteriores, utilice el juego de ese juego. punto final del paquete en lugar de crear otro anuncio. Ver publicación de CI cuando esté listo.

3. Pruebe las dos rutas de ingreso a la cuenta

Lanzamiento desde StarHermit: los suministros del lanzador #game_token=<jwt>. El ayudante lo captura y lo elimina de la URL antes de que se ejecute el módulo del juego. Elegir Continúe con su cuenta StarHermit.

Abra la URL alojada directamente: elegir Iniciar sesión con StarHermit. El selector de proveedores permite al El jugador inicia sesión con una cuenta existente o crea una. Regresa directamente a este juego con un alcance. #access_token=<jwt>; no se envía ninguna credencial de toda la cuenta al juego.

El juego carga el progreso solo cuando el jugador elige jugar con cuenta. Si los términos actuales necesitan aceptación, muestra el documento como texto y ofrece Aceptar y continuar. La aceptación envía solo el hash. de la revisión mostrada. Una revisión modificada se vuelve a mostrar para otra decisión explícita.

4. Verifique el progreso y los fracasos

Recoge algunas estrellas en el modo cuenta, espera Guardadoy recargar. El conteo regresa después de elegir juego de cuenta. Abra una segunda pestaña en el mismo recuento guardado: guarde en una y luego recopile en la otra. el el segundo debe mostrar un conflicto y ofrecer Cargar el último progreso en la nube en lugar de sobrescribirlo.

El documento guardado es { version: 1, points: <non-negative integer> }. El juego carga y valida. antes de escribir, utiliza la ETag cargada para actualizaciones condicionales y bloquea las escrituras después de una lectura fallida. Guarda en cada colección y etiqueta los datos guardados solo después del reconocimiento. Ver la receta salvadora para formatos, migración y documentos de mayor tamaño.

Al seleccionar el juego sin seguimiento, se descarta el token de jugador del juego y se detiene la renovación del fondo. Sin nube Se produce el guardado, el logro, la tabla de clasificación o la escritura de progreso local. Elegir jugar con cuenta nuevamente utiliza Regístrese para obtener un token nuevo.

5. Adáptalo a tu juego

Reemplaza el botón de estrella y el esquema de progreso con tu juego. Mantenga las opciones de entrada, token captura, aceptación de términos explícitos, regla de carga antes de guardar, manejo de errores y estado de guardado. Declare las acciones del teclado en el manifiesto y lea el API de controles cuando tu juego necesita reenlaces. Ponga las preferencias de volumen y gráficos en ajustes.

Para resultados multijugador o competitivos validados, agrega un script o contenedor. El contador en la nube de este inicio rápido es el progreso propiedad del cliente, no una prueba de una puntuación legítima.

Archivo Objetivo
index.html, style.css Interfaz de usuario de entrada, términos, jugabilidad y estado accesibles
app.js Modos de entrada, consentimiento explícito, validación de progreso, puntos de control, conflictos
starhermit-sdk.js Captura de token de lanzamiento, inicio de sesión alojado, renovación de token
cloud-save-store.js Receta de carga JSON sin formato/guardado condicional
starhermit.txt Metadatos de publicación pública

Ver cartas credenciales, Convenciones API, y solución de problemas cuando una solicitud se comporta de manera diferente a lo esperado.
