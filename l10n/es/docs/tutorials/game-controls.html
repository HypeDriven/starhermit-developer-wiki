Tutorial: añade controles a tu juego

StarHermit puede almacenar combinaciones de teclas para tu juego: declaras las acciones y sus claves predeterminadas, y cada jugador puede volver a vincularlos. Su elección los sigue a cualquier máquina en la que inicien sesión. tu juego lee los enlaces del jugador desde la API de controles y puede ofrecer los suyos propios "volver a vincular claves" pantalla.

Si tu juego llama a la API de controles y obtiene esto:

404 {"error":"This game declares no controls."}

la plataforma tiene sin acciones declaradas para la construcción que está sirviendo. Nada de lo que envíes a la API puede Arregle eso: los controles se declaran en el archivo de su juego. starhermit.txt y leer cuando el juego esta publicado. Esta página muestra cómo declararlos, publicarlos, comprobar que llegaron, y úselos de su cliente.

1. Declarar las acciones

Añadir uno control.<action>= línea por acción para starhermit.txt:

name=Space Hopper
launch=index.html

control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.jump=Space+KeyW | Jump
control.fire=KeyJ | Fire
control.pause=Escape | Pause

Cada línea tiene tres partes:

control.<action>=<code>[+<code>...][ | <label>]
Parte Normas
<action> El nombre de tu juego para la acción: 1 a 32 caracteres de letras minúsculas, dígitos y _ (move_left, no move-left). Único por manifiesto.
<code> A KeyboardEvent.code valor, como KeyA, ArrowLeft, Space, Digit1, ShiftLeft, Enter o Escape. Une de 1 a 4 códigos para la misma acción con +.
<label> Opcional. Se muestra en pantallas de reencuadernación; como máximo 64 caracteres. El valor predeterminado es el nombre de la acción.

Cosas que debes saber:

  • Usar code, no key. Escribir KeyA, no a, y Space, no " ". Los códigos nombran lo físico. tecla, por lo que las vinculaciones funcionan en cualquier diseño de teclado. La plataforma sólo comprueba que un código sea del 1 al 32 letras y dígitos, entonces a o space se acepta pero ninguna clave lo produce. Ortografía y caso debe coincidir exactamente.
  • Una clave pertenece a una acción. Un código ya utilizado en una línea anterior hace que la línea posterior inválido.
  • Hasta 32 acciones por juego. Las líneas posteriores al 32 se ignoran.
  • El orden se mantiene. Las acciones regresan de la API en orden manifiesto, así que enumerelas de la manera su pantalla de configuración debería mostrarlos.
  • Una línea no válida se omite silenciosamente. El juego todavía se publica. Si cada línea no es válida, el juego no tiene controles y la API responde 404. Comprobar después de publicar.

2. Publicarlos

Se leen las declaraciones cuando se publica el juego. Edición starhermit.txt en tu repositorio o en el disco no cambia nada hasta que publique una compilación que lo contenga:

Cómo se publica tu juego ¿Qué hace que los nuevos controles vivan?
Desde un repositorio de GitHub Tu próximo despliegue. Empuje el cambio y luego implemente la última versión (Actualizar la versión implementada en el tablero, o PUT /api/v1/me/github-games/{id}/deployment).
Carpeta o paquete cargado Cargar una nueva compilación (POST /api/v1/me/github-games/{id}/bundle, o ws/v1/game-upload) cuyo starhermit.txt tiene las lineas.
Agregar un nuevo juego La primera carga o envío los lee inmediatamente.

Una carga de reemplazo reafirma sus controles desde su propio manifiesto. Eliminar cada control.* línea y el juego no tiene ninguno. A ?mode=merge parchear eso no lleva starhermit.txt mantiene los controles actuales.

Las propias vinculaciones de los jugadores sobreviven a una nueva construcción. La vinculación guardada de un jugador para una acción que no ya existe se ignora.

3. Comprueba que llegaron

Cada punto final a continuación funciona con un token de usuario completo o el token de inicio de tu juego. {slug} es tu slug del juego: el token de lanzamiento game_scope reclamo, o gameSlug en GET /api/v1/me/github-games.

curl -s "https://api.starhermit.com/api/v1/games/$SLUG/controls" \
  -H "Authorization: Bearer $TOKEN" | jq

{
  "actions": [
    { "action": "left",  "label": "Move left",  "defaultCodes": ["KeyA", "ArrowLeft"],  "codes": ["KeyA", "ArrowLeft"] },

    { "action": "jump",  "label": "Jump",       "defaultCodes": ["Space", "KeyW"],      "codes": ["Space", "KeyW"] },
    { "action": "fire",  "label": "Fire",       "defaultCodes": ["KeyJ"],               "codes": ["KeyJ"] },

Las acciones faltantes significan que sus líneas no eran válidas; compararlos con las reglas anteriores. A 404 significa que ninguno sobrevivió o que la compilación que los declara aún no se ha publicado.

4. Úsalos en tu juego

codes es el enlace efectivo del jugador: su anulación si establece uno; de lo contrario, su valor predeterminado. Cree una búsqueda a partir de él y combine event.code:

const auth = { Authorization: `Bearer ${launchToken}` };

// Your built-in defaults, in the same shape the API returns.
const DEFAULT_ACTIONS = [
  { action: "left", label: "Move left", codes: ["KeyA", "ArrowLeft"] },
  { action: "jump", label: "Jump", codes: ["Space", "KeyW"] },
  /* ... */
];

function toControls(actions) {
  const byCode = new Map();
  for (const a of actions) for (const code of a.codes) byCode.set(code, a.action);
  return { actions, byCode };
}

async function loadControls(slug) {
  try {
    const res = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
    if (res.ok) return toControls((await res.json()).actions);
  } catch { /* offline: fall through */ }
  return toControls(DEFAULT_ACTIONS);                   // 404, error, or outside StarHermit
}

let controls = await loadControls(gameScope);

window.addEventListener("keydown", (e) => {
  const action = controls.byCode.get(e.code);   // e.code, never e.key
  if (action) { e.preventDefault(); onAction(action, true); }
});
window.addEventListener("keyup", (e) => {
  const action = controls.byCode.get(e.code);
  if (action) onAction(action, false);
});

Los valores predeterminados incorporados mantienen el juego jugable sin conexión, fuera de StarHermit o si los controles la solicitud falla. Manténgalos al día con su control.* pauta.

Una pantalla de reencuadernación. Lista actions con sus label. Conservar el mapa de anulación completo, o lea y conserve el mapa efectivo actual antes de cambiar una acción:

async function saveBinding(slug, action, codes) {
  const current = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
  if (!current.ok) throw new Error(`Controls read failed: ${current.status}`);
  const bindings = Object.fromEntries((await current.json()).actions.map(a => [a.action, a.codes]));
  bindings[action] = codes;
  const res = await fetch(`/api/v1/games/${slug}/controls`, {
    method: "PUT",
    headers: { ...auth, "Content-Type": "application/json" },
    body: JSON.stringify({ bindings }),
  });
  if (!res.ok) throw new Error((await res.json()).error);   // e.g. a key already in use
  return res.json();                                         // the new effective map
}

PUT reemplaza las anulaciones del jugador con las acciones que envías, así que incluye cada acción que el jugador ha cambiado, no sólo el último. El resto permanece en sus valores predeterminados. DELETE en el mismo camino restablece todo a los valores predeterminados.

Serializar cambios desde su pantalla; dos lecturas/escrituras simultáneas aún pueden sobrescribirse entre sí. El SDK del navegador setControl() serializa sus propios cambios y conserva el mapa efectivo actual. El envío del mapa efectivo fija esos valores como anulaciones; usar DELETE para volver a los valores predeterminados manifiestos.

La plataforma rechaza guardar (400) eso dejaría una clave en dos acciones después el del jugador los cambios se fusionan con sus valores predeterminados. Por ejemplo, vinculante jump a KeyJ mientras fire todavía usa su valor predeterminado KeyJ es rechazado. Mostrar el error o mover la acción conflictiva en el mismo guardar.

Solución de problemas

Respuesta Causa Arreglar
404 "Este juego no declara controles." No válido control.* línea en el publicado construir. Añadir líneas a starhermit.txt, compruébalos con las reglas, y publicar una nueva construcción.
404 "No hay juego con esa babosa." El slug está mal o el juego no tiene slug. Utilice el token de lanzamiento game_scope o gameSlug de GET /me/github-games. Cada juego agregado desde una carpeta local y cada juego de repositorio agregado por un propietario verificado tiene un slug, solo para navegador o no. Sólo un envío de repositorio cuyo propietario no esté verificado no tiene ninguno; reclamalo para conseguir uno.
403 "Este token tiene como ámbito el juego '…'." Un token de lanzamiento usado con el slug de otro juego. Llama con la babosa en la ficha game_scope.
400 "Acción desconocida '…': no ​​declarada en el manifiesto del juego." PUT nombró una acción que el manifiesto no declara. Usar action valores de GET …/controls.
400 "'…' está vinculado tanto a '…' como a '…'." Después de fusionarse con sus valores predeterminados, una tecla desencadenaría dos acciones. Mueve la otra acción en el mismo PUT, o elija otra clave.
400 "'…' no es un valor válido de KeyboardEvent.code." Un código con espacios o puntuación. Enviar event.code valores.
400 "La acción '...' debe vincular entre 1 y 4 códigos." Una lista vacía, o más de cuatro. Envíe de 1 a 4 códigos; DELETE para restablecer.
Falta una acción en la respuesta. Su línea no era válida: una letra mayúscula o - en el nombre de la acción, , en lugar de +, más de 4 códigos, un código ya utilizado o pasada la acción 32. Corrija la línea y publique nuevamente.
Una encuadernación nunca se dispara El código se acepta pero ninguna clave lo produce, como por ejemplo a o space. Usar exacto KeyboardEvent.code ortografía: KeyA, Space.
