Bibliotecas externas

Vincular la biblioteca Steam, Epic o GOG de un usuario para que sus juegos externos puedan enumerarse, iniciarse y rastrearse. Todas las rutas requieren un JWT.

URL básica: https://api.starhermit.com. Todas las rutas están bajo /api/v1/....

Vincular y desvincular

Método Camino autenticación Descripción
CONSEGUIR /api/v1/me/external-libraries JWT Listar mis proveedores vinculados
CORREO /api/v1/me/external-libraries/link JWT Vincular un proveedor y sincronizar sus títulos
BORRAR /api/v1/me/external-libraries/{provider} JWT Eliminar un enlace y sus propiedades

Bibliotecas vinculadas:

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

Cuerpo del enlace:

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

Devuelve 204. La vinculación también sincroniza los títulos del proveedor. La sincronización de la biblioteca actualmente devuelve títulos de demostración para steam/epic/gog mientras se finalizan las integraciones de proveedores reales.

Software externo propio y lanzamiento.

Método Camino autenticación Descripción
CONSEGUIR /api/v1/me/external-software?provider=&page=&pageSize= JWT Lista paginada de mis títulos externos
CORREO /api/v1/external-software/{ownershipId}/launch JWT Obtenga un URI de lanzamiento y registre un lanzamiento externo

Lista de software externo:

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

Respuesta de lanzamiento:

{
  "launchUri": "steam://run/…"
}

Lanzar formatos de URI por proveedor: steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. El lanzamiento registra una actividad de lanzamiento externa; consulte activity.md. Los juegos externos usan la clave de juego uniforme. "provider:externalId" para calificaciones y feeds, consulte catalog.md.

Ver Convenciones API para el análisis de errores.

Ver compatibilidad de credenciales y contratos legibles por máquina.
