Catálogo de software

El catálogo de software cubre la búsqueda y reclamación de títulos, listas de compilaciones, descargas, guardados en la nube, listas de deseos y calificaciones. Las lecturas son anónimas; las escrituras requieren un JWT.

URL básica: https://api.starhermit.com. Todas las rutas están bajo /api/v1/....

Navegar y reclamar títulos

Método Camino autenticación Descripción
CONSEGUIR /api/v1/software Anónimo Buscar y paginar el catálogo
CONSEGUIR /api/v1/software/{id} Anónimo Obtenga un título o 404
CONSEGUIR /api/v1/software/{id}/builds?page=&pageSize= Anónimo Lista paginada de compilaciones para un título
CORREO /api/v1/software/{id}/claim JWT Autoreclamar un título gratuito, otorgando un derecho
CORREO /api/v1/software/{id}/launch JWT Iniciar una sesión de lanzamiento (requiere derecho)

GET /api/v1/software acepta parámetros de consulta q (texto completo), category, tag, publisherId, platform, releaseStatus, sort, page, y pageSize. Válido sort valores: name, name_desc, created, created_desc, updated, updated_desc. Devuelve un PagedResult:

{
  "items": [
    {
      "id": "…",
      "name": "…",
      "description": "…",
      "publisherId": "…",
      "category": "…",
      "platform": "…",
      "releaseStatus": "…",
      "tags": ["…"],
      "priceCents": 0,
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

GET /api/v1/software/{id}/builds devuelve un PagedResult de SoftwareBuild:

{
  "items": [
    {
      "id": "…",
      "titleId": "…",
      "version": "…",
      "releaseDate": "…",
      "releaseNotes": "…",
      "metadata": "…",
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

POST /api/v1/software/{id}/claim funciona sólo para títulos gratuitos (priceCents == 0); otorga a la persona que llama un derecho y devuelve 204. Para títulos pagos, devuelve 402 con:

{"error": "purchasing is not available yet"}

POST /api/v1/software/{id}/launch requiere un derecho (403 en caso contrario) y devuelve un LaunchSession:

{
  "launchId": "…",
  "startTime": "…"
}

Registra una actividad de inicio, que se oculta si la configuración de privacidad del usuario así lo indica (ver profile.md). Terminar la sesión con POST /api/v1/activity/launches/{id}/end - ver activity.md. Los derechos de un usuario se enumeran a través de GET /api/v1/me/entitlements (ver profile.md).

Guardados en la nube

Un espacio por juego, la última escritura gana. Todas las rutas requieren un JWT: un token de usuario completo o un token de juego. token de lanzamiento para la propia ranura de ese juego (abajo).

El límite de 10 MB (10.485.760 bytes) se aplica al guardar decodificado, no la solicitud. PUT toma el guarde codificado en base64 en JSON, por lo que el cuerpo es aproximadamente un tercio más grande que el guardado: aproximadamente 14 MB en el límite, y la API lo acepta.

Límite (por cuenta) Por defecto Negativa
Un guardado, decodificado 10 megas 413 cloud_save_too_large
Juegos con guardado 200 409 cloud_save_slots_exhausted (un guardado para un nuevo juego)
Todos salvan juntos 1GB 507 cloud_save_quota_exceeded, con used
Subidas 30 por minuto 429, con Retry-After

Cada negativa nombra el número vigente como limit. El total se mide sobre el valor de la cuenta. otro guarda, por lo que una ranura siempre se puede sobrescribir con algo que no sea más grande. Los operadores pueden cambiar cualquiera de estos para una cuenta.

Método Camino autenticación Descripción
CONSEGUIR /api/v1/me/cloud-saves/{gameKey}/info JWT Guardar metadatos: { exists, sizeBytes, updatedAt? }
CONSEGUIR /api/v1/me/cloud-saves/{gameKey} JWT application/zip bytes, 404 si ninguno
PONER /api/v1/me/cloud-saves/{gameKey} JWT Cargue un archivo guardado (guardado decodificado ≤ 10 MB, gameKey ≤ 300 caracteres)

PONER cuerpo:

{
  "dataBase64": "…"
}

Poner respuesta:

{
  "gameKey": "…",
  "sizeBytes": 0,
  "updatedAt": "…"
}

Guardar desde dentro de un juego (token de inicio)

Un juego que se ejecuta con su token de inicio puede leer y escribir la partida guardada del jugador. ese juego. Su juego se guarda dondequiera que se ejecute: un navegador o la aplicación de escritorio StarHermit, que se ejecuta También aloja juegos en un navegador, por lo que el guardado sigue al jugador entre ellos.

La clave es game:<gameId>, dónde <gameId> es la identificación de tu juego: el mismo valor que su slug, su <gameId>.starhermit.com dirección, y el game_scope reclamo del token de lanzamiento:

const key = `game:${gameScope}`;            // e.g. "game:3fa85f64-5717-4562-b3fc-2c963f66afa6"

// Load on startup — 404 means no save yet.
const res = await fetch(`/api/v1/me/cloud-saves/${key}`, { headers: { Authorization: `Bearer ${launchToken}` } });
if (res.status !== 404 && !res.ok) throw new Error(`Save load failed: ${res.status}`);
const save = res.status === 404 ? null : new Uint8Array(await res.arrayBuffer());
const etag = res.headers.get("ETag");
if (save && !etag) throw new Error("Save version unavailable; do not overwrite it.");
// Validate/decode your own save format before adopting it or enabling uploads.

// Save at checkpoints, not every frame.
const written = await fetch(`/api/v1/me/cloud-saves/${key}`, {
  method: "PUT",
  headers: {
    Authorization: `Bearer ${launchToken}`, "Content-Type": "application/json",
    ...(etag ? { "If-Match": etag } : { "If-None-Match": "*" }),
  },
  body: JSON.stringify({ dataBase64: base64(zipBytes) }), // Your ZIP encoder and bytes.
});
if (written.status === 412) throw new Error("Another device saved. Reload before writing again.");
if (!written.ok) throw new Error(`Save write failed: ${written.status}`);
const acknowledgement = await written.json(); // Retain acknowledgement.etag for your next write.
  • Sólo esa clave exacta. Cualquier otra clave: la de otro juego, la de un juego de la tienda o una ortografía diferente tuyo (mayúscula, la identificación simple) - es 403 para un token de lanzamiento. Eso incluye github:<gameId>, la ranura separada que usa la aplicación de escritorio cuando un jugador sincroniza una carpeta guardada local para su juego, por lo que esa sincronización nunca puede sobrescribir las escrituras guardadas de tu juego.
  • Cualquier formato. La plataforma nunca abre el guardado; almacena todo lo que tu juego pueda leer (es sirvió como application/zip a pesar de todo). Hasta 10 MB.
  • Las escrituras incondicionales son las últimas victorias en escritura., sin historia. Utilice escrituras condicionales para detectar dos pestañas/dispositivos guardados a la vez. Cargue al inicio y guarde en los puntos de control de primer plano. Salida de página las cargas son el mejor esfuerzo y tienen límites de tamaño corporal del navegador; ver la receta para salvar de forma segura.
  • Cada guardado tiene una versión. Es ETag está en la descarga, en /info (también como etag) y en el PUT respuesta. Envíalo de vuelta como If-Match y la escritura ocurre solo si nadie ha guardado desde; de lo contrario 412 {"error":"precondition_failed","etag":"<current>"} te dice la versión a carga. If-Match: * requiere un guardado existente; If-None-Match: * Escribe sólo cuando no hay ninguno. Sin encabezado PUT es incondicional: la última escritura gana. A GET con If-None-Match: <etag> respuestas 304 cuando ya tienes el guardado más reciente.
  • Un juego sin listado alojado (un juego proporcionado por un operador) no tiene espacio.

Las preferencias pequeñas y que cambian con frecuencia pertenecen a configuración por jugador en cambio; También se puede acceder a ellos con el token de lanzamiento y admiten actualizaciones parciales.

Lista de deseos

Todas las rutas requieren un JWT.

Método Camino autenticación Descripción
CONSEGUIR /api/v1/me/wishlist JWT { titleIds: guid[] }
PONER /api/v1/me/wishlist/{titleId} JWT Añadir a la lista de deseos, 204 (idempotente)
BORRAR /api/v1/me/wishlist/{titleId} JWT Eliminar de la lista de deseos, 204

Calificaciones

Todas las rutas requieren un JWT. La clave uniforme del juego es una guía de catálogo, o "provider:externalId" para juegos externos (ver external-libraries.md).

Método Camino autenticación Descripción
PONER /api/v1/me/ratings JWT Subir mi calificación para un juego
CORREO /api/v1/ratings/query JWT Resúmenes de calificación de recuperación por lotes
CONSEGUIR /api/v1/ratings/reviews?key=&top= JWT Reseñas de un juego (top predeterminado 10)

PONER cuerpo:

{
  "gameKey": "…",
  "stars": 4,
  "review": "…"
}

stars es 0–5; review es opcional. La respuesta es una RatingSummaryDto:

{
  "gameKey": "…",
  "average": 4.5,
  "count": 12,
  "myStars": 4
}

POST /api/v1/ratings/query cuerpo y respuesta:

{
  "keys": ["…", "…"]
}

regresa RatingSummaryDto[]. GET /api/v1/ratings/reviews regresa GameReviewDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "stars": 4,
    "review": "…",
    "timestamp": "…"
  }
]

Ver Convenciones API para el análisis de errores. Relacionado: achievements.md, leaderboards.md.
