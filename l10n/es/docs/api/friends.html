Amigos

La API de amigos gestiona las solicitudes de amistad y las amistades aceptadas. Todas las rutas están bajo api/v1/me y requerir autorización. Invita al juego Friendship State Gates y también controla el acceso a salas de chat abiertas y salas de voz.

Los cuerpos de error varían; ver Convenciones API.

Puntos finales

Método Camino autenticación Descripción
CORREO /api/v1/me/friend-requests JWT Enviar una solicitud de amistad
CONSEGUIR /api/v1/me/friend-requests JWT Lista de solicitudes de amistad entrantes pendientes
CORREO /api/v1/me/friend-requests/{requestId}/accept JWT Aceptar una solicitud de amistad
CORREO /api/v1/me/friend-requests/{requestId}/decline JWT Rechazar una solicitud de amistad
BORRAR /api/v1/me/friends/{friendUserId} JWT Dejar de ser amigo de un usuario
CONSEGUIR /api/v1/me/friends JWT Lista de amistades aceptadas con presencia.

Amigos

GET /api/v1/me/friends

Amistades aceptadas. online viene de la presencia, currentGame desde un lanzamiento activo:

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

Deja de ser amigo del usuario. Devuelve 204.

Cómo la amistad abre otras características

  • invitaciones a juegos sólo se puede enviar a amigos — ver Juegos.
  • Charlar — puertas de amistad que unen salas de chat abiertas; Las reglas del chat requieren amistad para conversaciones fuera del juego. Ver Charlar.
  • Voz — el acceso a la sala de voz requiere ser miembro de la conversación de chat de respaldo, por lo que las reglas de amistad del chat se aplican de forma transitiva. Ver Voz.
  • Las conversaciones de juego por sesión pasan por alto las reglas de la amistad — Los jugadores en la misma sesión de juego pueden usar el chat/voz adjunto sin ser amigos.

Tokens de lanzamiento relacionados con el juego

Un token de lanzamiento con ámbito de juego puede llamar GET /api/v1/me/friends, por lo que un juego puede ofrecer un selector para invitar a un amigo dentro de una sesión; la implementación de referencia de ajedrez lo usa exactamente para eso. Los otros puntos finales amigos devuelven 403 para los tokens de lanzamiento; ver las reglas de esgrima del alcance del juego en Autenticación.
