Motor

Dónde conseguir el motor StarHermit, el tiempo de ejecución que juega juegos de guiones. La API de la plataforma es el lugar para encontrar versiones: enumera todas las versiones, indica cuáles están revocadas y proporciona las URL y hashes de los archivos de cada versión. Las lecturas son anónimas.

URL básica: https://api.starhermit.com. Todas las rutas están bajo /api/v1/....

Método Camino autenticación Descripción
CONSEGUIR /api/v1/engine/releases Anónimo Cada lanzamiento, primero la versión más reciente, incluidas las revocadas
CONSEGUIR /api/v1/engine/releases/{version} Anónimo Un lanzamiento por su versión exacta (X.Y.Z), o 404 
{"releases": [{
  "version": "1.40.0", "api": {"major": 1, "minor": 40}, "revoked": false, "date": "2026-11-12T21:54:08Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.40.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"linux-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.40.0/native/linux-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} responde a uno de esos objetos sin el releases envoltura. Las URL apuntan a wiki.starhermit.com para lanzamientos recientes y en engine.starhermit.com para los mayores; Úselos como se indica.

  • api es la API de host que ofrece la versión. Su mayor es el mayor del lanzamiento y el engine.api un el juego declara; su menor crece a medida que se agregan miembros (un juego puede requerir uno con engine.minor).
  • revoked: true viene con un revokedReason. Una autorización revocada permanece en la lista para que los clientes puedan decir por qué lo rechazan.
  • web es null para una versión sin un tiempo de ejecución web. manifestIntegrity es el hash SRI de la web tiempo de ejecución manifest.json, el valor que fija una página de carga.
  • native tiene una entrada por plataforma (windows-x86_64, linux-x86_64, macos-x86_64, macos-aarch64), o es {}. manifestSha256 es el hexadecimal SHA-256 de esa plataforma native.json; compruébalo antes de confiar en la lista de archivos que contiene.

Ambas rutas envían Cache-Control: public, max-age=60 con un ETag y responder 304 a una coincidencia If-None-Match. Si la plataforma aún no ha leído la lista de lanzamientos desde que inició, responden 503 con Retry-After.

Una versión publicada nunca cambia: una solución es la siguiente versión. el motor tutorial describe la versión más reciente; esta API dice cuál eso es.

descargar el motor

Los desarrolladores descargan el tiempo de ejecución nativo de una versión para escribir, verificar, empaquetar y jugar juegos. Los jugadores hacen nada: el cliente StarHermit y la página de un juego obtienen los pines de liberación del juego.

  1. Pregunta a la API por la versión, la más nueva o la que tu juego fija:

    curl -s https://api.starhermit.com/api/v1/engine/releases/1.40.0

  2. Toma tu plataforma native.<platform>.manifestUrl, trae eso native.json y comprobar su SHA-256 en contra manifestSha256.

  3. native.json's downloads nombra la descarga del desarrollador con su size y sha256. el archivo se sienta al lado native.json: reemplazar native.json al final de manifestUrl con el archivo nombre. Descárgalo y comprueba su SHA-256.

Los mismos pasos que un script (necesita curl, jq y sha256sum; en uso de macOS shasum -a 256):

version=1.40.0 platform=linux-x86_64   # or windows-x86_64, macos-x86_64, macos-aarch64
release=$(curl -fsS "https://api.starhermit.com/api/v1/engine/releases/$version")
manifest_url=$(jq -r --arg p "$platform" '.native[$p].manifestUrl' <<<"$release")
manifest_sha=$(jq -r --arg p "$platform" '.native[$p].manifestSha256' <<<"$release")
curl -fsSO "$manifest_url"
echo "$manifest_sha  native.json" | sha256sum -c -
archive=$(jq -r '.downloads | keys[0]' native.json)
curl -fsSO "${manifest_url%native.json}$archive"
echo "$(jq -r --arg a "$archive" '.downloads[$a].sha256' native.json)  $archive" | sha256sum -c -

En PowerShell, Invoke-RestMethod lee el comunicado y Get-FileHash -Algorithm SHA256 da el hash para comparar. El tutorial cubre desembalaje y la primera carrera.

El herramientas de desarrollo independientes (publicación automatizada y un servidor MCP de desarrollo) se lanzan por separado del tiempo de ejecución.

Integridad

Una cadena de hashes cubre cada byte que ejecuta un cliente:

  1. La API proporciona el SHA-256 de una versión. native.json.
  2. native.json proporciona el SHA-256 y el tamaño de cada archivo, y la descarga del desarrollador se encuentra en downloads.
  3. El cliente StarHermit recupera solo las partes de una versión que aún no posee, verifica cada una, reúne todos los archivos y los verifica antes de colocar la versión en su lugar.

La página de carga de un juego de navegador fija el tiempo de ejecución web. starhermit.js y manifest.json con ISR hashes, y el tiempo de ejecución verifica todos los demás archivos que carga con el manifiesto.

El tiempo de ejecución web

La página de carga de un juego (index.html, escrito por starhermit package --web) cargas starhermit.js y manifest.json de https://engine.starhermit.com/engine/X.Y.Z/, con los mismos hashes SRI que el URL bajo web.base. Usar engine.starhermit.com en cualquier página del cargador escribes tú mismo: se mantiene cada lanzamiento, mientras que las URL bajo web.base mantenga solo los recientes y un lanzamiento antiguo desaparecerá de ellos. Herramientas de escritura 1.26.0 engine.starhermit.com por defecto (--loader-base URL o STARHERMIT_WEB_LOADER_BASE lo anula). Para un juego alojado empaquetado con herramientas más antiguas, la plataforma reescribe las dos URL del motor cuando la versión ya no está bajo web.base; reempaquetar juegos alojados en otro lugar. Una liberación revocada no se entrega desde ninguno de los orígenes.

Juegos de guiones en la plataforma.

Cuando la raíz de un juego starhermit.txt declara engine.version, la plataforma lo trata como un juego de guión:

  • cada publicación registra la liberación del pin de los archivos, como hosting.engineVersion, y conjuntos hosting.deployWarning (también en la respuesta de un paquete push) cuando esa versión no aparece en la lista o no está revocado. Una advertencia nunca detiene una publicación.
  • cada página del juego alojado cuenta con una política de seguridad de contenido que solo admite scripts desde los dos orígenes del motor (y el propio motor) blob: trabajadores), por lo que el único código es un script La página del juego que se puede ejecutar es el motor oficial:
default-src 'self'; script-src https://wiki.starhermit.com https://engine.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com https://engine.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com https://engine.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

Una página de un juego de script sin una compilación de navegador (como la página simple que carga un juego solo para Windows) para navegadores) no necesita script y no se ve afectado.

Revocaciones

Una autorización que se considere insegura se revoca. El cliente StarHermit no lo instala ni lo inicia y le dice al jugador, los comandos de empaquetado se niegan a empaquetar un juego para él y la plataforma advierte a los propietarios de juegos que lo fijan cuando se publican. Una versión revocada siempre va seguida de una versión fija: vuelva a fijarla y publicar (ver Pasar a un motor más nuevo).
