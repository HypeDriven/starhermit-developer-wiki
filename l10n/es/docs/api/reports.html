Informes de fallos y errores

Los jugadores pueden informar un fallo o un error desde dentro de cualquier juego que tenga un slug (juegos solo para navegador). incluido: usando el token de inicio del juego o un token de usuario completo. El propietario del juego lee, clasifica y los elimina a través de /api/v1/me/github-games/{id}/reports.

Para conocer la salida del servidor propio y los registros de fallas de un juego contenedor, consulte Servidores de juegos alojados en contenedores: informes de resultados y fallos de su servidor.

Puntos finales

Método Camino autenticación Descripción
CORREO /api/v1/games/{slug}/reports Token de inicio para ese juego, o JWT Presentar un informe de fallo o error
CONSEGUIR /api/v1/games/{slug}/reports/mine Token de inicio para ese juego, o JWT Tus 50 informes más recientes para este juego, con su estado.
CONSEGUIR /api/v1/me/github-games/{id}/reports JWT (propietario) Informes de lista: ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
CONSEGUIR /api/v1/me/github-games/{id}/reports/{reportId} JWT (propietario) Un informe, con su lista de archivos adjuntos.
CONSEGUIR /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} JWT (propietario) Un archivo adjunto, siempre como descarga
PARCHE /api/v1/me/github-games/{id}/reports/{reportId} JWT (propietario) Colocar status
BORRAR /api/v1/me/github-games/{id}/reports/{reportId} JWT (propietario) Eliminar un informe → 204

Presentar un informe

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind es crash o bug; title es obligatorio (≤200 caracteres).
  • Todo lo demás es opcional. userAgent por defecto es el de la solicitud User-Agent encabezamiento.
  • Respuesta: 201 { "id", "kind", "status": "open", "createdAt" }.
Estado Significado
400 Mal formado: desconocido kind, desaparecido title, base64 no válida o no JSON
404 Juego desconocido o eliminado
413 Descripción, recuento de archivos adjuntos o bytes de archivos adjuntos que superan los límites del juego
429 Por encima del límite de informes diarios para este juego; ver Retry-After

Límites

Los operadores pueden cambiar cada uno de estos para toda la plataforma y para juegos individuales; el límite diario También se puede configurar para un jugador.

Límite Por defecto
Informes por jugador por juego por día 20
Descripción longitud 20.000 caracteres
Adjuntos por informe 4
Bytes de archivos adjuntos por informe 2 MB
Informes mantenidos por juego. 2,000
Bytes guardados por juego 256 MB
Retención 90 dias

Cuando un juego alcanza su límite de almacenamiento, los informes más antiguos (los resueltos primero) se eliminan para hacer espacio. Un único informe mayor que el límite total de bytes por juego se rechaza con 413.

Informes de clasificación (propietario del juego)

La lista regresa { "items", "total", "page", "pageSize" }; cada artículo lleva el nombre del periodista, kind, status, title, detalles del cliente y su recuento de archivos adjuntos. Mover un informe a través open → acknowledged → resolved con:

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

Los archivos adjuntos se sirven como descargas (Content-Disposition: attachment, nosniff, una zona de pruebas CSP). Sólo los tipos inertes mantienen su tipo de contenido declarado: texto, JSON, PNG, JPEG, WebP, GIF, zip y zip; cualquier otra cosa, incluido el marcado, se sirve como application/octet-stream.

Desde el SDK de JavaScript

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports
