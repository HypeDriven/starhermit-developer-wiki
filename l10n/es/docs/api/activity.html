Actividad

La API de actividades cubre las sesiones de lanzamiento, el tiempo de juego y el feed de actividades, tanto para títulos del catálogo como para juegos externos (no incluidos en el catálogo). Todas las rutas requieren un JWT a menos que se indique lo contrario.

URL básica: https://api.starhermit.com. Todas las rutas están bajo /api/v1/....

Sesiones de lanzamiento del catálogo y tiempo de juego.

Método Camino autenticación Descripción
CORREO /api/v1/activity/launches/{id}/end JWT Finalizar una sesión de lanzamiento de catálogo (204)
CONSEGUIR /api/v1/activity/software/{softwareTitleId}/playtime JWT Mi tiempo total de juego para un título
CONSEGUIR /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 JWT Tiempo de juego de amigos por un título

Las sesiones de lanzamiento son iniciadas por POST /api/v1/software/{id}/launch (ver catalog.md) y terminó aquí. Respuesta durante el juego:

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime regresa FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

Lanzamientos externos y tiempo de juego.

Para juegos que no están en el catálogo (bibliotecas externas vinculadas, consulte external-libraries.md):

Método Camino autenticación Descripción
CORREO /api/v1/activity/external-launches JWT Iniciar una sesión para un juego que no está en el catálogo
CORREO /api/v1/activity/external-launches/{id}/end JWT Termina esa sesión (204)
CONSEGUIR /api/v1/activity/external/playtime?provider=&externalId= JWT Mi tiempo total de juego para un juego externo
CONSEGUIR /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 JWT Tiempo de juego de amigos para un juego externo

POST /api/v1/activity/external-launches cuerpo (provider ≤ 64 caracteres, externalSoftwareId ≤ 256 caracteres, name opcional):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

Respuesta:

{
  "launchId": "…"
}

Respuesta externa al tiempo de juego:

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

Feeds de actividad

Método Camino autenticación Descripción
CONSEGUIR /api/v1/activity/game-feed?key=&limit=20 JWT Sesiones de amigos y eventos de calificación para una clave de juego
CONSEGUIR /api/v1/activity/friends?since=&until=&limit= JWT actividad de amigos
CONSEGUIR /api/v1/activity/public?since=&until=&limit= Anónimo Actividad pública
CONSEGUIR /api/v1/me/activity?since=&until=&limit= JWT mi propia actividad

Vuelve la transmisión del juego. GameFeedItemDto[] para una clave de juego (una guía de catálogo o "provider:externalId", ver catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public, y me/activity devolver ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

Actividad type valores: "download", "launch", "external_launch".

/activity/friends está cerrado por tipo de actividad en el del propietario configuración de privacidad: los lanzamientos siguen recentLaunchActivity, las descargas siguen recentDownloads. Cada uno está incluido cuando el nivel es FriendsOnly o Public. Una cuenta que nunca ha elegido obtiene los valores predeterminados (lanzamientos compartidos con amigos, descargas privadas). Un documento de privacidad ilegible se trata como totalmente privado. Ver profile.md.

Ver Convenciones API para el análisis de errores.

Ver compatibilidad de credenciales y contratos legibles por máquina.
