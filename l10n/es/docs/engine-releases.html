Lanzamientos del motor StarHermit

El motor StarHermit: el tiempo de ejecución que juega juegos de guiones - es publicado en este wiki como versiones versionadas e inmutables bajo wiki.starhermit.com/engine/. Los juegos fijan una versión exactamente con engine.version en su starhermit.txt; La página de un juego carga el tiempo de ejecución web de la versión desde aquí en el navegador, el cliente StarHermit para Windows instala el tiempo de ejecución nativo de la versión y reproduce el juego en él, y los desarrolladores descargan el tiempo de ejecución de una versión desde aquí para compilar.

Versiones

una liberación es X.Y.Z. X es el versión principal de la API de host, el engine.api un juego declara, entonces cada versión 1.x.x se ejecuta engine.api=1 juegos; el lanzamiento también registra la versión menor de la API del host, que crece a medida que se agregan miembros (un juego puede requerir uno con engine.minor). Un comunicado publicado nunca cambia: una solución es la próxima versión.

Liberar API de host Tiempos de ejecución Descarga del desarrollador
1.1.0 1.4 Web; Ventanas (x86-64) starhermit-1.1.0-windows-x86_64.zip
1.0.0 1.4 ventanas (x86-64); sin tiempo de ejecución web starhermit-1.0.0-windows-x86_64.zip

versions.json es la lista autorizada, la más nueva primero y el motor La propia página del área enumera lo mismo.

la zona del motor

engine/
  versions.json            every release: host API, date, runtimes, revocation
  X.Y.Z/
    native/windows-x86_64/
      native.json          the Windows runtime's files, each with its size, SHA-256 and chunks
      starhermit-X.Y.Z-windows-x86_64.zip
                           the developer download: the same files as one archive
    manifest.json          the web runtime's files, each with its size and sha384
    starhermit.js          the module a game's loader page loads
    starhermit.wasm, *.js  the runtime, its audio mixer and worklets
    starhermit.d.ts        the host API's declarations
    fonts/, licenses/      the runtime's fonts and every licence notice
                           (all of the web runtime only in a release that has one)
  chunks/ab/<sha256>.z     pieces of the native files, shared by every release
  patches/ab/<sha256>.p    binary patches from earlier releases' files

Cada archivo se publica tal cual (ningún nombre de archivo comienza con _ o .), y GitHub Pages lo sirve con Access-Control-Allow-Origin: *.

versions.json

{
  "format": 2,
  "versions": [
    {
      "api": {"major": 1, "minor": 4},
      "date": "2026-10-20T13:55:50Z",
      "native": {
        "windows-x86_64": {"manifest": "1.1.0/native/windows-x86_64/native.json", "sha256": "<SHA-256 of native.json>"}
      },
      "revoked": false,
      "version": "1.1.0",
      "web": {"manifest": "sha384-<SRI hash of manifest.json>"}
    }
  ]
}

web es {"manifest": "sha384-…"}, el hash SRI de la web del lanzamiento manifest.json, o null para una versión sin un tiempo de ejecución web. native fija cada plataforma native.json por su SHA-256. un lanzamiento retirado porque no es seguro dice "revoked": true con un "revokedReason"; ese es el El único cambio que requiere una entrada publicada.

native.json

native.json enumera los archivos de la carpeta del motor que instala un cliente: starhermit.exe, release.json (la versión del lanzamiento, la API del host y el launcher protocolo habla su tiempo de ejecución), LICENSE-engine y los avisos de terceros, cada uno con su size, sha256 y chunks. un trozo es una extensión de un archivo, almacenado comprimido con zlib como chunks/<first two hex digits>/<sha256>.z y nombrado por el SHA-256 de sus bytes sin comprimir; Los límites de los fragmentos siguen el contenido, por lo que un estiramiento mantiene su porción de una versión a la siguiente. Cuando es más pequeño, un archivo también enumera patches del mismo archivo de versiones anteriores ("from": el SHA-256 del archivo anterior). downloads enumera la descarga del desarrollador con su size y sha256; Los clientes nunca lo instalan. En una versión con tiempo de ejecución web, la carpeta nativa también contiene web-manifest.json, la web del comunicado manifiesto, por lo que el desarrollador descarga paquetes de juegos para la web sin red.

El tiempo de ejecución web

El tiempo de ejecución web de una versión son los archivos al lado de su manifest.json, que enumera cada uno con su size y sha384 y registra la versión del lanzamiento, la API del host y la compilación. La página de carga de un juego (index.html, escrito por starhermit package --web) no tiene script propio: se carga starhermit.js y manifest.json de https://wiki.starhermit.com/engine/X.Y.Z/ con hashes SRI y el motor busca todos los demás archivos que necesita (starhermit.wasm, los worklets de audio, las fuentes) y lo comprueba contra el manifiesto. La página ejecuta solo el motor: entrada, menús de tiempo de ejecución, audio, almacenamiento, el sesión de plataforma y voz, y el TypeScript del juego se ejecuta en un trabajador que inicia y puede detener.

El tiempo de ejecución web incluye sus propias fuentes, Liberation 2.1.5 (SIL Open Font License 1.1) y DejaVu Sans. 2.37 (licencias Bitstream Vera y Arev); sus avisos estan en licenses/ con los demás.

Integridad

Una cadena de hashes cubre cada byte que ejecuta un cliente:

  1. versions.json (o la API de la plataforma a continuación) proporciona el SHA-256 de una versión native.json.
  2. native.json proporciona el SHA-256 de cada archivo y el de cada fragmento.
  3. El cliente recupera solo los fragmentos que aún no contiene, verifica el tamaño almacenado de cada uno, tamaño inflado y SHA-256, junta cada archivo, verifica el SHA-256 del archivo y solo entonces mueve la liberación en su lugar. Un parche se compara con su propio SHA-256 y el archivo parcheado con el del archivo; cualquier fracaso vuelve a los pedazos.

La descarga del desarrollador está cubierta por la misma cadena a través de su entrada en downloads. un navegador La página de carga del juego fija el tiempo de ejecución web. starhermit.js y manifest.json con hashes SRI, y el tiempo de ejecución verifica todos los demás archivos que carga con el manifiesto.

El motor lanza API

La plataforma ofrece la misma lista, con cada URL en este wiki, por lo que los clientes preguntan a la API qué motor para buscar:

GET /api/v1/engine/releases → cada lanzamiento, el más nuevo primero:

{"releases": [{
  "version": "1.1.0", "api": {"major": 1, "minor": 4}, "revoked": false, "date": "2026-10-20T13:55:50Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.1.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"windows-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.1.0/native/windows-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} → una versión, o 404 cuando no figura en la lista. Ambos son anónimo y almacenable en caché (Cache-Control: public, max-age=60 con un ETag). Una liberación revocada lleva revokedReason; web es null para una versión sin un tiempo de ejecución web. Si bien la plataforma nunca ha leído la lista (la wiki es inalcanzable desde que comenzó), responden 503 con Retry-After.

Juegos de guiones en la plataforma.

Cuando la raíz de un juego starhermit.txt declara engine.version, la plataforma lo trata como un guión juego:

  • cada publicación registra la liberación del pin de los archivos, como hosting.engineVersion, y conjuntos hosting.deployWarning (también en la respuesta de un paquete push) cuando esa versión no aparece en la lista o no está revocado. Una advertencia nunca detiene una publicación.
  • cada página del juego alojado cuenta con una política de seguridad de contenido que solo admite scripts de esta wiki (y del propio motor) blob: trabajadores), por lo que el único código que la página de un juego de script puede run es el motor oficial:
default-src 'self'; script-src https://wiki.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

Una página de un juego de script sin una compilación de navegador (como la página simple que carga un juego solo para Windows) para navegadores) no necesita script y no se ve afectado.

Revocaciones

Una autorización revocada permanece en la lista para que los clientes puedan decir por qué la rechazan: el cliente de StarHermit lo hace no lo instala ni lo inicia y le dice al jugador que los comandos de empaquetado se niegan a empaquetar un juego para él. cuando leen versions.json, y la plataforma advierte a los propietarios de juegos que lo fijan cuando publicar. Vuelva a fijar la versión que la reemplaza y publíquela nuevamente. (ver Pasar a un motor más nuevo).
