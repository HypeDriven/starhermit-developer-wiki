星隐者开发者维基

公共 API 的文档 星隐士 — 游戏/软件 分发+社交平台：用户 & OAuth认证、好友、文字聊天、实时语音、 出版商，包含构建/资产、权利、成就、排行榜的软件目录， 对等中继，以及 服务器权威多人游戏 其规则运行在 沙盒 JavaScript 文件或开发人员提供的容器。这个wiki是一个通用的集成 指南 任何 针对平台的游戏。

本 wiki 中使用的参考示例是 HypeDriven/明星隐士国际象棋 — 一个 对应国际象棋游戏（无需构建静态站点+一个服务器端JS规则文件），使用 启动代币、elo 匹配、好友邀请、游戏 WebSocket、游戏内聊天、语音、 排行榜和重播——可在以下位置实时播放 83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com （游戏的地址是其平台分配的 uid，而不是其名称）。 它是此处描述的模式的一种具体实现， 不是文档的主题。

从哪里开始

  • 浏览器快速入门 — 下载完整的游戏，包括帐户登录、明确的条款接受、安全的云保存和未跟踪的单人游戏。

  • 选择集成方式 — 比较纯浏览器游戏、主机路由房间、脚本、容器和目录标题。

  • 教程：使用 StarHermit 引擎构建游戏 — 编写一个 TypeScript 脚本游戏，在引擎的 Windows 运行时上本地运行它，使用本地内核移动数千个对象，登录玩家，并将其发布到引擎的 Web 运行时上的浏览器中以及在 StarHermit 客户端中本地运行。

  • 凭证和标识符 — 哪些代币可以调用哪些 API，以及游戏、用户、会话、房间和参与者 ID 有何不同。

  • API约定 — 响应/错误解析、时间戳单位、分页、更新语义和重试。

  • 故障排除 — 诊断登录、范围、保存冲突、套接字、上传和容器启动。

  • 会话生命周期和恢复 — 暂停/恢复、断开连接与离开、快照限制和恢复到期。

  • 可用性和信任 — 可用、可选、预览和保留的 API；是什么让分数值得信赖。

  • REST 和 WebSocket 合约 — 可下载的 OpenAPI、JSON 框架模式和二进制布局。

  • 安全的云保存同步 — 具有冲突处理功能的完整加载/验证/条件写入助手。

  • 这 starhermit.txt 显现 — 每个已发布游戏的一个文件 需要，它必须位于您上传的文件夹中的位置，以及为什么该文件夹应该是您的 可分发构建：清单旁边的所有内容都会上传并提供给玩家。还涵盖资产缓存生命周期和其他 CORS 来源。

  • 入门 — 基本 URL、版本控制、身份验证模型和 集成方法（从 GitHub 发布或作为文件夹上传的平台游戏，带有 可选脚本或容器服务器，或直接调用 REST/WS API 的外部客户端）。

  • 教程：端到端集成演练（使用国际象棋参考示例） — 从启动令牌到重播查看器的完整生命周期，以及游戏客户端的确切调用 使，由国际象棋参考实现进行说明。

  • 教程：使用 AI 将 StarHermit 连接到您的游戏中 — AI 编码助手的可复制粘贴提示，每个功能一个，再加上一个整体 超级提示。

  • 教程：在游戏中发布专用服务器和玩家 — 推送容器包，更新其服务器令牌，并使用公钥注册来加入 Steam/Epic/GOG/本地玩家无需 OAuth 或 StarHermit 仪表板访问。

  • 教程：使用公钥加入玩家 — 创建 并使用游戏在玩家设备上生成的密钥和一个密钥登录 StarHermit 帐户 通过电子邮件发送确认：密钥格式、要签名的确切字节、等待确认、会话、 第二台设备和丢失密钥，以及仅密钥帐户无法执行的操作。

  • 教程：从 CI/CD 上传构建 — 注册专门的 来自 OAuth 会话的部署公钥、非交互式身份验证以及发布客户端或 容器从 GitHub Actions 构建（包括通过 WebSockets 进行大量上传）。

  • 教程：构建多人卡丁车赛车 — 八辆卡丁车 实时房间中的赛车手：大厅、快速加入、CPU 驱动程序、主机路由的二进制网络代码 套接字的速率限制、主机迁移以及用于排名游戏的服务器权威 30 Hz 脚本变体， 与客户端预测和协调。

  • 教程：持久会话 - 当所有人离开时暂停的游戏 — 选择脚本或容器游戏进入暂停而不是结束的会话，保持游戏时钟静止 与 ctx.pausedMs，并从客户端重新加入暂停的世界。

  • 教程：游戏的排行榜和成就 — 作为游戏的所有者，您是游戏的发行商：创建高分、计时板和成就 通过 API，从脚本或容器中发布分数并解锁成就，并显示 他们在你的客户端。

  • 教程：具有自动检测质量的图形选项 — 顺便过来 graphics-options.js：从 0-20 中选择的质量预设 硬件级别（Galaxy S20 到 RTX 5090）、每个效果覆盖、自适应分辨率、半刷新节奏 手机、手动最大 FPS 选项、选项面板以及设置 通过 StarHermit 跟踪每个 GPU 的玩家；连接到 Three.js 渲染器。

  • 教程：具有自动检测声音限制的音频选项 — 基线音量和语音聊天控制、设备和 CPU 感知的自动并发建议以及有界的 播放策略；包括无依赖性 audio-options.js 帮手。

  • 教程：本地化您的游戏并添加语言设置 — 与 wiki 相同的十种语言、原生标签和 SVG 标志，旁边有一个语言部分 图形/音频/控件、从右到左的文本、翻译包和每个玩家的偏好同步。

  • 教程：向游戏添加控件 — 声明可重新绑定 键盘动作 starhermit.txt，发布它们，使用启动令牌读取玩家的绑定， 构建一个重新绑定屏幕，并修复 "This game declares no controls.".

  • 教程：认领其他人添加的游戏 — 证明存储库控制，接管现有列表，并管理其托管和部署。

验证更改

该网站没有应用程序构建。对于文档和示例检查，请使用 Node.js 22 或更高版本， Python 3，以及 npm ci， 然后 npm test. npm run test:browser 还需要 Chrome/Chromium （CHROME_PATH 可以选择其可执行文件）。

编辑快速入门帮助程序后，运行 python3 scripts/build-quickstart.py 刷新示例并 邮政编码。要从匹配的源签出更新 REST 操作索引，请运行 python3 scripts/build-contracts.py /path/to/platform-checkout，检查合同差异，然后重新运行 测试。响应覆盖保持在 scripts/rest-contract-overrides.json.
