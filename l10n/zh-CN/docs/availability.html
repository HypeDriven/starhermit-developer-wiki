功能可用性和信任度

使用端点的响应和发现字段作为您的目标部署的答案。 已发布的路由或 SDK 包装器并不保证每个可选服务都可用。

可用性

特征 公共整合状态 客户应该做什么
托管游戏发布、登录、保存、设置、控制 符合记录的帐户/游戏要求 使用匹配令牌并处理有效配额
权威脚本和实时房间 可用的;游戏定义选择支持的行为 检查队列形状， gameSessionId、持久性和重播可用性
容器服务器 可在 StarHermit 上找到；托管权限可能因其他部署而异 比赛前确认部署准备情况
语音和对等中继 依赖于部署 处理不可用的服务响应并保持文本/游戏可用
OAuth 提供商 按部署配置 读 /auth/oauth/providers;切勿对提供商列表进行硬编码
重播和加入进行中 依赖游戏 读 replaysEnabled 以及房间配置
目录购买 尚不可用 免费主张作品所有权；已付索赔退货 402
目录二进制分发 当前目录管道是预览 不要依赖目录上传/下载 URL 进行生产分发；使用受支持的托管游戏发布流程
外部 Steam/Epic/GOG 库同步 带演示标题的预览 请勿将返还的演示所有权视为购买证据
内容审核检查 发现通过 /games/{slug}/moderation;目前在公共部署中不可用 在没有当前允许的情况下隐藏共享内容；处理 503 overloaded
一代 预留路线，不可用 不依赖于发电工作、付款、供应商或市场准入

除非明确说明特定于部署的值，否则参考页中的限制均为默认值。 使用返回的限制和 Retry-After. A 503 overloaded 和 Retry-After: 300 意味着重试建议， 不承诺五分钟后即可提供该服务。

预留发电路线

玩家/服务器生成前缀是 /api/v1/games/{slug}/generation：发现、引用和 保留作业创建/读取/删除路由。帐户/所有者和公共提供商路线也是 保留。有效呼叫者当前收到 503 和：

{ "error": "overloaded", "code": "overloaded", "retryAfterSeconds": 300 }

身份验证和游戏范围仍然适用。没有可用的生成结果、购买或提供者 已承诺连接。这些预订单独列在 REST合约.

是什么让结果值得信赖？

图案 平台保障 您的游戏必须验证什么
主机路由的房间 经过身份验证的发件人、分配的主机、席位和路由 模拟和主机诚实；客户端可能会被修改
剧本/容器奖项 只有游戏后端写入游戏拥有的分数和成就；收件人必须是参与者 游戏玩法是否真正获奖
客户报告的单人得分有界限 服务器在写入之前检查数字类型/范围 合理的数字并不能证明运行合法
客户声称的成就目录 帐户和权利检查 客户观察到的解锁条件；修改后的客户端可以声明它
云端保存或设置 经过身份验证的玩家自己的范围数据 文档验证、游戏规则以及比赛进展是否可信
外部身份关联 身份与帐户关联 需要时通过店面验证店面门票/所有权

所提供的 score-script.js 接受配置范围内的客户端报告值。很有用 适用于休闲单人棋盘，但并不妨碍发明范围内的结果。为了有竞争力 在评分之前播放、模拟权威规则或验证记录输入的重播。 切勿仅从拒绝直接分数提交的 API 来推断反作弊保证。

同样，仅附加到奖励成就的后端无法验证它从未观察到的游戏玩法。 定义它接受哪些证据，对其进行验证，并在信任模型出现时向玩家明确说明 很重要。看 选择集成.
