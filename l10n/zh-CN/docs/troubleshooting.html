解决集成问题

从 HTTP 状态、端点和凭证系列开始。使用重现最小请求 相同的游戏ID和凭证，然后检查资源的当前状态。保留代币和玩家 从日志和支持报告中保存数据。

登录和访问

症状 查看 下一步行动
401 休息时 令牌过期以及它是帐户还是启动令牌 刷新一次账户会话；续订仍然有效的启动令牌或登录以进行新启动
403 terms_acceptance_required 当前文档来自 /api/v1/terms 仅在玩家操作时显示它并接受其哈希值；帐户和玩家启动代币有效
403 范围到另一个游戏 game_scope 与游戏/房间/保存请求相比 使用您自己的游戏 UUID 和准确的 game:<gameId> 云保存密钥
403 在 /me/game-invites 从一场比赛 启动令牌无法读取帐户范围的收件箱 轮询 /games/{slug}/invites 和 /realtime/rooms/invites
403 oauth_session_required 该操作更改帐户凭据 通过实时提供商登录；公钥会话只能撤销自己的密钥
403 对于被暂停的帐户 已返回消息 停止自动登录/刷新重试；引导玩家联系帐户支持
直接登录返回 400 returnUrl 必须是游戏托管源上的 HTTPS 使用托管游戏 URL；本地开发 URL 不是允许的返回目的地
登录间歇性失败 Invalid signature. 挑战连载，尤其是 + 暂时 使用准确的 公钥签名字节
登记申报表 429 电子邮件/IP 注册津贴 荣誉 Retry-After;在发送另一个注册之前确认电子邮件

游戏设置和存储

症状 查看 下一步行动
/games/{slug} 回报 404，但设置有效 游戏有脚本或容器后端吗？ 仅浏览器游戏具有设置和启动令牌，但没有权威的游戏信息/会话界面
控制返回 404 有效的 control.* 已发布清单中的行 公布声明；写入不能创建未声明的操作
重新绑定一个键会重置其他键 控制 PUT 替换所有覆盖 发送完整的覆盖图，或者使用SDK setControl() 保留有效地图
设置消失后 PUT 收藏 PUT 替换整个地图 使用 PATCH 对于更改的顶级键；嵌套对象被替换为一个值
新玩家云存档回归 404 该插槽尚不存在任何保存 重新开始只是为了这个结果；其他故障必须阻止上传
保存写入返回 412 另一台设备编写了新版本 在另一个条件写入之前重新加载、验证和合并/采用
保存退货 413, 409， 或者 507 保存大小、槽数或帐户配额 检查退回的 code 和 limit;减小尺寸或解决容量
会话列表中缺少截止日期 summary.deadline 类型 返回以毫秒为单位的整数 Unix 时间戳，而不是 ISO 字符串
分数/成就未出现 键、主动定义、参与者、值界限 验证定义和服务器输出；无效写入被忽略；客户报告并不能作为证据
对接会回报 404 一场比赛后 匹配的会话可能已结束 返回大厅并开始新的搜索，而不是重新打开旧的票证

WebSockets

浏览器升级失败通常显示为关闭代码 1006，隐藏 HTTP 响应。 在重试之前，对同一游戏/会话/房间进行 REST 调用以区分身份验证， 条款、成员资格、已完成的会话和临时服务器启动故障。检查构建兼容性 当您提供游戏信息时 ?build=。每次升级都会获得一张新的转接票。

关闭/结果 意义 行动
1000 常闭 除非玩家明确启动另一个连接，否则停止
1001 加上恢复错误 世界还无法恢复 检查会话状态后通过退避重新连接
1006 网络丢失或升级被拒绝 检查 REST 状态和当前凭据；绑定重试
1008 违反政策或被取代的连接 停止自动重连；修复原因后主动重新连接
1009 消息太大 再次连接之前减小帧大小
HTTP协议 409 build_mismatch 客户端/服务器构建不匹配 重新加载兼容的版本；不要发明匹配的构建值
HTTP协议 410 session_not_active 结束会议 返回大厅或重播；停止重新连接
error: "Too many commands; slow down." 脚本持久命令津贴 步调离散命令；将连续输入放入其中 data 和 type: "input", realtime: true

重新连接后请求完整的游戏状态；不要盲目地重放动作或其他非幂等的动作 命令。 resumed 意味着放弃预测并重新同步。 abandoned 是终端。 看 WebSocket 合约.

发布和容器启动

症状 查看 下一步行动
上传 413 和 limitBytes 有效上传/托管津贴 减少束或生成的合并树
大量 HTTP 上传 413 没有平台错误字段 API 之前的请求正文限制 使用 ws/v1/game-upload;发送 complete 毕竟字节
上传 422 存档布局、启动文件、路径安全、清单 修复命名错误； API 需要原始数据 .tar.gz，不是多部分的
上传成功但服务器不可用 部署准备情况 民意调查部署；接受的字节并不意味着容器已准备好
集装箱房启动暂时恢复 503 服务器可能正在唤醒 保留大厅并通过退避重试；不要退回到客户端模拟
容器请求未通过调用键验证 启动环境和确切的标头比较 读取当前注入的invoke key；使用游戏 ID 和清理日志报告持续失败
持续部署失败 部署状态和所有者可见的日志/崩溃 修复构建或配置并发布新的工作版本

有用的支持报告包括游戏 ID、客户端/构建版本、端点和方法、状态/代码、 大约 UTC 时间、复制步骤和相关的清理日志。会话/房间 ID 有助于定位 资源。未经玩家同意，请勿附加凭据、私钥或玩家的完整保存。
