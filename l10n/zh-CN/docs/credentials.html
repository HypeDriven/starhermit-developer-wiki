令牌生命周期

凭据 默认生命周期 更新
帐户访问令牌 15分钟 交换旋转刷新令牌；替换两个返回的令牌
帐户刷新令牌 7天 一次性轮换使用；并发刷新必须共享一个请求
玩家游戏启动令牌 60分钟 有效期内续订，默认 12 小时启动链内
容器服务器令牌 24小时 专用部署刷新密钥；读取报告的寿命
WebSocket 连接票证 约30秒 仅升级一次；每次尝试都获得一张新票

读取返回的生命周期。玩家启动令牌不是帐户令牌，并且没有刷新令牌。 过期后无法自行恢复。提供游戏登录或返回启动器。 打开的套接字可能会在令牌过期后继续存在，但重新连接需要当前凭据。

发射器供应 #game_token=<jwt>;直接托管游戏登录返回 #access_token=<jwt>。在路由器或其他脚本使用片段之前读取并删除它们。 解码声明仅用于构建 URL 和显示身份； API 验证凭证。

使用 Authorization: Bearer <token> 休息。浏览器套接字使用新鲜的 ?ticket= 从 POST /api/v1/realtime/connection-tickets，或支持 ?access_token=。门票继承 调用者的范围，并且不授予对其他资源的访问权限。切勿将帐户凭据放在您的 公共构建或将它们传递到游戏的 URL 中。看 验证.

身份验证方法很重要

经过 OAuth 身份验证的帐户会话可以注册密钥、撤销其他密钥、更改帐户电子邮件、 并删除提供者身份。公钥帐户会话可以使用普通帐户 API 和 撤销其 自己的 键通过 /me/public-keys/current，但无法管理其他凭据。 启动令牌无法管理帐户密钥，即使它是从公钥会话中创建的。

接受当前条款 是帐户支持的玩家操作 并启动代币。仅在明确接受后才显示文档并提交其哈希值。

标识符不可互换

标识符 意义 使用示例
游戏ID / slug / game_scope 托管游戏的不可变 UUID /games/{slug}, <gameId>.starhermit.com, game:<gameId> 保存密钥
目录标题 ID 分离 SoftwareTitle 通用唯一标识符 /software/{titleId}, 目录权利
用户身份 / sub 星隐者账户UUID 邀请目标；脚本 ctx.message.from
会话ID 权威比赛或世界UUID /sessions/{sessionId}, 游戏套接字
房间号 实时大厅/世界房间UUID /realtime/rooms/{roomId};可能会暴露一个单独的 gameSessionId
参与者ID 实时房间中的一个座位 实时二进制帧上的服务器前缀；不是帐户 ID
对话ID 聊天对话 UUID 会议 chatConversationId、语音室创建
语音房间ID/中继ID 独立的运输资源 语音或中继套接字查询
成就/面板键 一场比赛内名字稳定 服务器授予和分数写入

一个名字，例如 chess 在旧的例子中是说明性的。使用您的游戏返回的实际 UUID 列表或其启动代币。实时和容器二进制 GUID 使用 .NET 字节顺序；看 WebSocket 合约 进行有效的转换。
