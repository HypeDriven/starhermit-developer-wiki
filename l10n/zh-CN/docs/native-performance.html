脚本游戏的本机性能

StarHermit 引擎游戏在浏览器和本机中运行相同的包。两者运行你的代码非常 不同的是，因此在移植或编写繁重的工作之前选择它所在的位置。本页涵盖脚本 速度、WebAssembly、GPU 绑定场景、工作人员和测量。数字是发动机测量值 2026 年 10 月，自引擎 1.26.1 起。

你的代码如何运行

在浏览器中 原生地
游戏JavaScript 浏览器的V8，全速 引擎自己的解释器，无 JIT（出于安全考虑而设计）
WebAssembly，主要领域 浏览器的 WebAssembly 来自引擎 1.26.1 的平台编译的本机代码（细节）；否则引擎的解释器（主机 API 1.25 及更高版本）
WebAssembly 中 starhermit:script 工人 引擎的解释器，用于获得位精确的结果 平台编译的本机代码，与主领域一样
  • 本质上，真正的游戏 JavaScript 是关于 比 V8 慢 15–25 倍。微基准可以建议 约8×。不要依赖他们。
  • 平台已编译的本机 WebAssembly 运行于 大致V8速度：大约快 7 倍 比引擎模拟基准上的解释器耗时大约是 V8 的 1.4 倍。解释 WebAssembly 比 V8 慢大约 8-18 倍。
  • starhermit check 运行 JavaScript 的方式与窗口游戏完全相同。基准测试 --release 仅引擎构建。

编译后的WebAssembly

从引擎 1.26.1 开始，当您发布包含 .wasm 模块，平台编译每个 在沙盒构建中提前模块并对结果进行签名。本机运行时下载它， 验证签名，缓存它并将其作为本机代码运行。你不需要改变游戏； 只是发布它。

  • 在哪里： Windows x86-64、Linux x86-64 和 Intel macOS，使用 x86-64-v2 或更高版本的 CPU （SSE4.2 和 POPCNT）。 Apple Silicon Mac 和较旧的 CPU 仍然可以解释，模块也可以解释 使用SIMD。
  • 什么时候： 在编译代码下载之前创建的实例会继续解释。后来 实例运行已编译，包括下一次启动，它从磁盘缓存加载它。
  • 相同的结果： 编译后的代码与解释器逐位匹配，包括燃料和陷阱。
  • 检查并禁用： 和 --dev，日志显示每个模块是否运行编译或 解释，以及为什么。 STARHERMIT_WASM_AOT=0 关闭编译。
  • 浏览器不变： 主领域使用浏览器的 WebAssembly，工作人员使用 引擎的解释器。

每帧工作繁重

模拟、网格划分、寻路和实体构建是常见的热点。

  1. 用 Rust 或其他 WASM 语言编写热代码 并将其作为 WebAssembly 运行，最好在 starhermit:script 工人。游戏一旦发布，就会以接近 V8 的速度原生运行， 而纯 JavaScript 的速度却慢了大约 15-25 倍。
  2. 选择一条路径 runtime() 从 starhermit:engine （主机 API 1.26）。 "web" 意味着V8，所以 JavaScript 在那里很好。 "native" 意味着您应该更喜欢 WASM 路径。工人们总是把 本机路径，无法导入 starhermit:engine.
  3. 为游戏逻辑、UI 和编排保留简单的 JavaScript。 将罕见的繁重工作分散到各个框架之间。
  4. 不要为了速度而将 JavaScript 或 TypeScript 编译为 WebAssembly。 结果还需要 JavaScript 对象模型，因此它一无所获。

对于许多类似的实体来说， starhermit:world 内核 也可以本地运行。

GPU 密集场景

本质上，GPU 通常只有在脚本时间得到控制后才成为限制。

  • 使用 InstancedMesh.setLevels([...]) 具有低多边形水平和绘制距离，以及三 LOD （主机 API 1.26）。
  • 转动 castShadow 关闭小或远距离的道具。
  • 限制阴影级联 shadow.cascades = { count, maxDistance }，引擎扩展。
  • 放 STARHERMIT_GPU_PASS_TIMES=1 打印每次传递的 GPU 时间。

工人

  • 在主机 API 1.27 之前，请保留对您使用的每个工作线程的引用，因为垃圾收集 终止它。从 1.27 开始，一个有听众的工人生活到 terminate().
  • 工作人员可以读取包文件（files）来自主机 API 1.26。
  • Worker 可以从主机 API 1.25 发送二进制和可传输消息。

测量

  • 使用相同的构建来比较本机和网络。
  • 引擎的帧统计数据将脚本时间与帧时间分开报告。脚本台编号是 适合引用。
