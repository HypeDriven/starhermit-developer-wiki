会话、世界和恢复

通过匹配、接受邀请、练习或启动来创建权威会话 具有服务器后端的实时房间。房间是一个有座位的大厅；它是 gameSessionId 识别 单独的会话运行游戏。看 游戏 和 实时房间.

生命周期

status 是 active 或者 finished。暂停不会引入第三种状态： pausedAt 标记一个 暂停持久会话。已完成的会话无法再次播放。如果启用，则会读取重播 通过他们自己的端点。

事件 普通比赛 持续会话
最后一个游戏套接字断开连接 约5分钟后结束，不返回 约15秒后暂停
24小时无玩家活动 可以退休 暂停而不是因不活动而结束
玩家请求另一个会话 可以退掉一场空的旧比赛 不会退休他们停放的世界
玩家重新连接 仅当仍处于活动状态时 在第一个命令之前恢复
后端返回结果 饰面 饰面
所有者结束会话 获胜者/评级没有变化的情况下结束 相同的

时间和恢复限制可能因部署而异。暂停的世界对每个玩家进行计数 并发会话限制。提供一种明确离开或结束世界的方法。

断线和离开是不同的

关闭套接字可以保留成员资格，以便玩家可以返回。明确的 离开世界 给出 会员资格并访问其游戏套接字。

对于持久会话 没有房间:

POST /api/v1/games/{slug}/sessions/{sessionId}/leave
Authorization: Bearer <player-token>

没有请求正文。成功是 204。游戏将收到关于会员变更的通知以及 离开者的游戏插槽关闭。当最后一个人类成员离开时，世界就结束了 players_left. 404 意味着没有会话， 403 表示不是会员， 410 意味着已经结束，并且 409 意味着这不是一个持久的世界或者它属于一个房间。

对于一个 房间内会话， 使用 POST /api/v1/realtime/rooms/{roomId}/leave。在一个 加入进行中的房间，这将腾出席位并删除会话成员资格。在固定阵容的比赛中， 该席位变为AI，会议可以保留其原来的成员资格。遵守房间规则； 不要调用独立的会话离开端点。

正在运行的正在进行的世界可以在最后一个访问者离开后保持列出状态。一个成员 持久世界也可以使用另一个普通大厅。通过以下方式发现当前会员资格 GET /api/v1/realtime/rooms/joined，不仅仅是 /rooms/mine.

读取恢复信息

会话中的玩家和游戏所有者可以调用：

GET /api/v1/games/{slug}/sessions/{sessionId}/recovery
Authorization: Bearer <player-or-owner-token>

响应描述了此会话的有效恢复和传输限制：

领域 含义/单位
sessionId, status, runtime, persistent 会话标识和类型；运行时间是 script 或者 container
pausedAt, pausedMillis 暂停开始ISO时间戳；累计暂停时间（以毫秒为单位）
snapshotBytes, stateBudgetBytes, lastSnapshotAt 恢复文档大小/预算（以字节为单位）和最新快照 ISO 时间
snapshotIntervalSeconds, maxSnapshotPushHz 集装箱检查站节奏和推顶； null 对于脚本
maxRestoreStalenessSeconds 容器匹配的最大快照年龄； null 不适用的地方，包括持久世界
maxRestores, restoreWindowMinutes, restoreCount 恢复尝试限额、其窗口和报告的恢复计数
retentionDays, recoveryDataExpiresAt 暂停世界保留； 0 和 null 表示没有配置过期时间
transport.maxMessageBytes, transport.maxRealtimeInputsPerSecond 游戏帧/输入限制
transport.tickRateHz, transport.pacingRateHz 有效滴答和传输起搏率（以 Hz 为单位）

请阅读这些值，而不是承诺无限期保留或固定的崩溃倒带窗口。一个 积极的 retentionDays 允许暂停的世界过期。展示 recoveryDataExpiresAt 设置时； 到期结束会话 retention_expired.

恢复客户端和服务器状态

在套接字重新连接时，请求游戏的完整状态消息。在 resumed，丢弃插值 以及基于早期状态的预测； lostMs 报告恢复差距。不要假设移动 其确认丢失可以安全地重新发送。

脚本返回完整的状态文档。容器必须从快照重建整个会话 以及当前的名单，包括自之前快照以来承认的球员。之后推送检查点 重要事件，在报告的上限内。暂停会删除容器的实时会话以及稍后的会话 从保存的快照重新创建它。暂停的游戏时间可以使用 ctx.now - ctx.pausedMs.

失败的恢复会让世界暂停，并在错误后关闭套接字；退出并重试。 失败的恢复可以结束会话。终端 abandoned 原因包括 players_left, idle_no_players, superseded, server_failure, restore_failed, operator_ended， 和 retention_expired。显示原因并停止重新连接。放弃不会授予任何获胜者或 Elo 更改。

看 持续会话 对于服务器代码和 故障排除 用于重新连接决策。
