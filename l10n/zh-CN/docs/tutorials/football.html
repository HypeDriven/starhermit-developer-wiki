示例游戏：Football 如何使用 StarHermit 引擎

星隐足球 是公开的、完整的 脚本游戏。这是 1 至 22 名球员的实时 3D 足球比赛，配有 AI 队友、泛光灯 体育场、在线大厅、语音和文本聊天、重播、排行榜、成就和九 语言。本页将逐步拆解，展示真实游戏如何使用该引擎。每个 步骤命名所涉及的引擎模块并链接到游戏的源代码，您可以在其中阅读 完整代码。

本演练是为引擎编写的 1.40.0，最新发布。显示的每个调用都会列出 在 引擎API参考。阅读 引擎教程 首先，如果您还没有构建脚本游戏。

源链接指向提交 33bd9bd。 在那次提交游戏引脚引擎 1.39.0 engine.minor=39。它没有使用更新的东西，所以它 在 1.40.0 上运行不变；移动它是单行更改 engine.version （看 步骤12).

游戏的形状

小路 角色
starhermit.txt 清单：名称、引擎引脚、服务器脚本、控件、功能
server.js 一场比赛模拟：平台作为权威服务器运行，客户端加载进行离线练习和预测
engine/src/main.ts 入口模块：生命周期回调和屏幕状态机
engine/src/match.ts, logic/ 匹配流程、网络代码、插值和预测
engine/src/world/ 3D 场景中的体育场、足球运动员、球和人群
engine/src/screens/, hud.ts 菜单（starhermit:ui) 和比赛中的 HUD (starhermit:draw)
engine/src/net.ts, platform.ts, chat.ts, voice.ts 与 StarHermit 平台对话的所有内容
engine/src/audio.ts, i18n.ts, quality.ts 声音、语言和图形级别
assets/, sfx/ 图像、弦表和声音片段

1. 清单

starhermit.txt 使该文件夹成为脚本游戏，并声明服务器脚本和控件：

name=Football
launch=index.html
server=server.js
control.up=KeyW+ArrowUp | Run forward
control.shoot=Space+KeyJ | Shoot (hold) / tap to pass
control.tackle=KeyK | Slide tackle / pressure
engine.api=1
engine.entry=engine/src/main.ts
engine.version=1.39.0
engine.minor=39
engine.capabilities=platform,voice,clipboard,storage
engine.gamepad.shoot=West+RightTrigger
engine.gamepad.pass=South
  • launch=index.html 是加载页面 starhermit package --web 写道。它玩游戏 在固定版本的 Web 运行时的浏览器中。
  • server=server.js 是平台的权威匹配脚本（第6步）。
  • control.* 和 engine.gamepad.* 线条定义 行动。运行时将按键和键盘绑定到它们， 玩家可以在运行时的选项菜单中重新绑定它们。游戏从未命名游戏玩法的键。
  • engine.capabilities 请求平台（房间、套接字、排行榜、重播、聊天）、语音、 剪贴板（邀请链接）和存储（设置）。运行时拒绝它们之外的调用。

完整的密钥列表位于 这 starhermit.txt 显现.

2. 入口模块和框架循环

engine/src/main.ts 在模块范围内设置渲染器，然后注册四个生命周期回调 starhermit:engine:

import { frame, onFixedUpdate, onRender, onStart, onUpdate, setFixedRate } from "starhermit:engine";
import { ACESFilmicToneMapping, PCFSoftShadowMap, PerspectiveCamera, renderer, scene } from "starhermit:scene";

const camera = new PerspectiveCamera(55, 16 / 9, 0.1, 800);
renderer.camera = camera;
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = PCFSoftShadowMap;
renderer.toneMapping = ACESFilmicToneMapping;

onStart(() => {
  setFixedRate(60);
  loadLanguages(); // string tables (step 10)
  sim();           // evaluate server.js once (step 6)
  menuScene.start(); // an AI-vs-AI match behind the menu
  // … platform listeners, settings listeners, invite polling
});

onFixedUpdate((step) => {
  if (match) match.fixedStep(step);
  else if (!replay) menuScene.fixedStep(step);
});

onUpdate((delta) => {
  pollQuality();
  if (match) match.update(Math.min(delta, 0.1));
  // … replay viewer or menu backdrop
});

onRender(() => {
  const fr = frame();
  if (Math.abs(camera.aspect - fr.width / fr.height) > 1e-6) {
    camera.aspect = fr.width / fr.height;
    camera.updateProjectionMatrix();
  }
  hud.draw();
  // … chat, in-match menu or the menu screens
});

要复制的模式：

  • 模拟运行于 onFixedUpdate，固定 60 Hz。
  • 每帧逻辑运行在 onUpdate， 和 delta 封顶，因此停滞的框架不会使 玩家跳跃。
  • 绘图运行于 onRender. 每个回调只有一个，所以 main.ts 扇出到 当前屏幕：菜单、大厅、比赛、重播或结果。

3. 3D世界： starhermit:scene

体育场、足球运动员、球和官员是普通的 Three.js 风格对象 starhermit:scene: Mesh, Group, MeshStandardMaterial, CylinderGeometry, Sprite, CanvasTexture 等等。从 Three.js 移植的代码大部分都可以工作 不变。一些值得阅读的细节：

  • world/stadium.ts 建造球场、看台、泛光灯和雾气。它设置后期效果（renderer.bloom, renderer.grade, renderer.antialias）和每个图形级别的阴影。
  • world/environment.ts 制作环境图 PMREMGenerator 从一个 DataTexture.
  • world/crest.ts 和 world/nametags.ts 在上面画上队徽和浮动昵称 starhermit:canvas OffscreenCanvas，然后将它们用作 CanvasTexture沙 Sprites.

4. 数千个活动部件： starhermit:world

动画 22 名足球运动员联合起来，加上数千名人群成员，会太慢，因为 本机解释器上的每个对象脚本。足球运动的作用 starhermit:world 桌子 （键入的列的行）和 内核 （运行时运行在每一行上的函数）：

import { kernel, schedule, table } from "starhermit:world";

const crowd = table("crowd", CROWD_ROWS, {
  bx: "f32", by: "f32", bz: "f32", ph: "f32", fr: "f32", av: "f32",
  q: "quat", s: "f32", sy: "f32", x: "f32", y: "f32", z: "f32",
});
const sway = kernel(crowd, (r, u: { t: number; amp: number; spd: number; sway: number; shake: number }) => {
  const j = Math.sin(u.t * u.spd * r.fr + r.ph);
  r.y = r.by + (j > 0 ? j * j : 0) * u.amp * r.av;
  // …
});
// An eighth of the crowd each frame: the work is sliced across frames.
const swayRun = schedule.update(sway, { t: 0, amp: 0, spd: 0, sway: 0, shake: 0 }, { slices: 8 });

足球运动员装备 world/rig.ts 使用相同的方法。一个 rigs 表保存每个足球运动员的动画状态。一个 joints 表， 与一个 ref:rigs 柱，每个钻机可容纳 15 个接头，并且 绑定 从中驱动场景节点。 两个内核安排在 onUpdate 计算姿势，运行时写入节点 改变自身。每个足球运动员每帧的脚本工作量约为十几个。

5. 输入：动作、触摸和游戏手柄

engine/src/input.ts 通过读取清单的操作 starhermit:input:

  • value(action) 返回动作保持的距离（移动是 value("up") - value("down")). onAction 提供按压和释放边缘。
  • 鼠标外观用途 requestPointerLock, onPointerDelta 和 onPointerLockChange。相机的 右摇杆来自 gamepads()， 和 vibrate 发出短暂的触觉滴答声。
  • 在触摸屏上（primaryPointer() 是粗糙的）， setTouchControls 显示操纵杆和 由运行时绘制的 SHOOT/PASS/TACKLE 按钮。这些按钮绑定到相同的操作：
setTouchControls([
  { kind: "stick", up: "up", down: "down", left: "left", right: "right", anchor: "bottom-left", offset: [90, 90], radius: 66 },
  { kind: "button", action: "shoot", label: T("SHOOT").slice(0, 16), anchor: "bottom-right", offset: [66, 66], radius: 46 },
  // … PASS and TACKLE
]);

screens/controls.ts 列出当前的 bindings() 并打电话 requestRebind。然后运行时捕获新密钥或 按钮。

6. 客户端和服务器端的一次模拟： starhermit:script

server.js 是一个简单的经典脚本，没有导入， Date 或者 Math.random，作为平台的沙箱 需要。它定义了两个全局变量：

  • globalThis.game 持有平台入口点（createSession, onPlayerMessage, onTick） 以及在发布时读取的静态声明：

    globalThis.game = {
  tickRateHz: 30,
  replays: true,
  achievements: [
    { key: 'debut', name: 'Debut', description: 'Finish your first match.', points: 10 },
    { key: 'hat-trick', name: 'Hat-Trick', description: 'Score three goals in one match.', points: 50 },
    // …
  ],
  createSession: function (ctx) { /* seats, AI, seed from ctx.random */ },
  // …
};

  • globalThis.FootballSim 保持相同的模拟（createMatch, stepMatch，人工智能） 客户。

客户端将相同的文件加载到自己的领域中 loadClassic 从 starhermit:script (engine/src/sim.ts):

import { loadClassic } from "starhermit:script";

loadClassic("server.js");
const S = (globalThis as unknown as { FootballSim?: FootballSimApi }).FootballSim;

离线练习步骤 FootballSim 本地频率为 60 Hz，每隔一个座位都有 AI。在线上， 平台运行 server.js 权威的 30 Hz。该游戏从不保留其两份副本 规则。

7. 在线比赛：房间和游戏插座

大堂通过以下方式使用平台的房间 starhermit:platform (screens/lobby.ts):

import * as P from "starhermit:platform";

// Quick play: join any open room, or open one.
let room = await P.rooms.quickJoin();
if (!room) {
  room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, metadata: { game: "football" } });
  room = await P.rooms.open(room.id);
}

// Ranked solo vs AI: every other seat is an AI player, so starting begins the match at once.
room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, aiPlayers: 2 * teamSize - 1, metadata: { game: "football" } });
room = await P.rooms.start(room.id);

好友、邀请和座位变更都会经过 P.friends.list, P.rooms.invite, P.rooms.acceptInvite 和 P.rooms.seat. P.rooms.mine 让玩家重新加入他们离开的比赛。

比赛开始后， engine/src/net.ts 打开游戏套接字 P.connectGame(sessionId):

  • 它以 30 Hz 的频率发送输入 sendInput.
  • 它要求完整的快照 sendCommand({ type: "sync" }) 在每次打开和打开时 resumed.
  • 它监听 game （快照和事件）， achievement 和 stopped. stopped 报告原因 套接字停止：注销、更新条款或比赛消失。

运行时保存玩家的凭据并自行重新连接，因此游戏不处理令牌 并且没有重试循环。

logic/interp.ts 通过自适应插值平滑服务器的快照。 logic/predict.ts 预测当地足球运动员的动作并针对每个快照进行纠正。预测影响 只画什么；服务器保持权威。

排行榜 P.leaderboards.list, P.leaderboards.entries （董事会宣布于 leaderboards.json) screens/leaderboard.ts

每个呼叫都可以拒绝 PlatformError。足球将在线功能视为尽力而为： 故障显示 "在线不可用" 或者陷入沉默，游戏永远不会结束。已退出， 游戏仍然提供离线练习。

9. 菜单和HUD： starhermit:ui, starhermit:draw, starhermit:canvas

  • 菜单 (screens/*.ts，匹配菜单和对话框 main.ts） 使用 starhermit:ui，引擎的即时模式 UI。小部件被称为每个 框架来自 onRender， 和 ui.setTheme 给他们游戏的颜色。运行时自己的选项 菜单打开方式为 openMenu.
  • 平视显示器 ( hud.ts） 绘制记分牌、时钟和标记 starhermit:draw: draw.roundRect, draw.text 和 draw.image （徽章画布），按照场景中的呼叫顺序。
  • 图片 装载有 createImageBitmap 从 starhermit:canvas, 例如菜单的关键艺术。

10. 设置和语言： starhermit:storage, 字符串

  • 每个玩家的设置（静音、语音、语言、图形覆盖）实时显示 settings 从 starhermit:storage。它们保存在设备和帐户中。 settings.onChange 应用在另一台设备上所做的更改。
  • i18n.ts 负载 assets/strings.json 进入发动机的 strings 表（strings.load, strings.t, strings.setLanguage）。它从保存的选择中选择语言，然后选择玩家的语言 StarHermit 语言，然后设备的 (preferences). l10n/font.ts 加载脚本字体 FontFace 对于需要它们的语言。

11.声音和图形级别

  • audio.ts 构建一个网络音频图 starhermit:audio:
    • 创作的剪辑列于 sfx/manifest.json （阅读与 files.readJson).
    • 合成器可以覆盖任何没有剪辑的事件，以及人群和体育场的混响。
    • 短命节点一旦结束就会被释放，因为主机图是有界的。
  • quality.ts 遵循玩家的图形级别（frame().level, levelSettings）。阴影、花朵和 抗锯齿遵循该级别。游戏本身的内容（球场细节、人群密度、粒子） 顶部有每个玩家的覆盖。

12. 打包、测试、发布

  • 类型检查 和 tsc -p engine. engine/tsconfig.json 包括发行版的 starhermit.d.ts 和集 "lib": ["ES2022"], "types": [] 和 "allowImportingTsExtensions": true.
  • 测试。 npm test 运行 server.js 回归测试。 engine/tests/run.sh 运行逻辑 Node 下的测试（插值、预测、姿势、大厅）。 starhermit <folder> --check 验证包并无头播放 120 帧。
  • 包裹。 starhermit package --web . 重写 index.html 和 starhermit-files.json, 每一次变革都会做出承诺。
  • 发布。 该游戏通过其存储库 URL 添加到 StarHermit 上。平台上写道 starhermit.txt，运行 server.js 作为比赛脚本并从中创建排行榜 leaderboards.json.

要将 Football 或您自己的游戏移动到引擎 1.40.0：

  1. 下载 1.40.0 运行时。
  2. 放 engine.version=1.40.0.
  3. 再次运行检查并打包。

增加 engine.minor 仅当您需要主机 API 1.40 时才改为 40 新功能.
