外部库

链接用户的 Steam、Epic 或 GOG 库，以便可以列出、启动和跟踪他们的外部游戏。所有路由都需要 JWT。

基本网址： https://api.starhermit.com。所有路线均在 /api/v1/....

链接和取消链接

方法 小路 授权 描述
得到 /api/v1/me/external-libraries 智威汤逊 列出我链接的提供商
邮政 /api/v1/me/external-libraries/link 智威汤逊 链接提供商并同步其标题
删除 /api/v1/me/external-libraries/{provider} 智威汤逊 删除链接及其所有权

链接库：

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

链接正文：

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

返回 204。链接还会同步提供者的标题。库同步当前返回演示标题 steam/epic/gog 而真正的提供商集成已经完成。

拥有外部软件并启动

方法 小路 授权 描述
得到 /api/v1/me/external-software?provider=&page=&pageSize= 智威汤逊 我的外部标题的分页列表
邮政 /api/v1/external-software/{ownershipId}/launch 智威汤逊 获取启动 URI 并记录外部启动

外部软件列表：

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

启动响应：

{
  "launchUri": "steam://run/…"
}

按提供商启动 URI 格式： steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}。启动记录外部启动活动 - 请参阅 activity.md。外部游戏使用统一游戏键 "provider:externalId" 对于评级和提要 — 请参阅 catalog.md.

看 API约定 用于错误解析。

看 凭证兼容性 和 机器可读的合同.
