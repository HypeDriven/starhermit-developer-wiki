普拉克斯

拔弦（符号 PLK) 是 StarHermit 的货币。玩家将其用于访问您的游戏或 您在其中出售的物品。您收到 99% 每笔销售，平台抽取1%的佣金， 四舍五入为整个 Pluck：销售 1-100 PLK 时为 1 PLK，销售 101-200 时为 2 PLK，依此类推。每个 余额从零开始。

玩家如何购买或赚取勇气尚未决定。在此之前，余额只能通过以下方式改变： 销售和运营商补助。

每笔交易都说明了其 Plucks 的来源

每个历史条目都有一个 source:

  • sale.game_access：玩家购买了游戏的访问权。
  • sale.game_item：玩家购买了游戏内物品。
  • grant：运营商发出的 Plucks。

参赛作品还带有 amount （签名）， balanceAfter, fee、游戏、项目密钥、顺序和 对方。账本是仅附加的：通过新交易来纠正错误，而不是通过 编辑旧的。

出售您的游戏的访问权

设置价格后，您的游戏将仅向您和购买访问权限的玩家发行启动代币。任何人 否则得到 402 和 code: "purchase_required" 和 price。向他们展示一种购买方式。

购买发送玩家显示的价格 expectedPrice。如果您更改了价格 因为，购买被拒绝 409 (code: "price_changed"），所以没有人付出他们所做的代价 没看到。访问权限是永久的，并且在以后的价格变化后仍然有效。为免费游戏定价 限制现有玩家。

您的游戏的托管文件尚未被控制。 价格保留了平台功能（登录、 会话、保存、成就），而不是浏览器游戏文件的下载。

出售物品

您的游戏不能花费玩家的勇气。您的游戏自己的代码保存玩家的启动令牌，因此 可以花费的代币会让任何游戏耗尽其玩家。流程是：

  1. 你的游戏会问。 POST /api/v1/games/{slug}/plucks/orders 和 { "itemKey": "sword.gold" }。 订单采用商品的当前名称和价格，开始 pending，并在 15 后过期 分钟。一个玩家最多可以有 20 个订单等待（429, too_many_pending_orders).
  2. 玩家在StarHermit上确认，永远不要在你的游戏中。 StarHermit 客户端显示 物品、价格和您的游戏以及帖子 /me/plucks/orders/{id}/confirm。该路线需要一个 使用 OAuth 提供商登录的帐户，而您的游戏从未有过该提供商。
  3. 你交付它。 轮询 GET /api/v1/games/{slug}/plucks/orders/{id} 从您的客户直到 status 是 paid （或者 cancelled，或过去 expiresAt）。容器后端可以改为读取 GET /api/v1/games/{slug}/server/plucks/orders?since=<last completedAt>.

平台记录销售情况；应用该项目是您游戏的工作。通过以下方式使交付幂等 订单编号。

POST /api/v1/games/{slug}/plucks/orders
Authorization: Bearer <launch-token>
Content-Type: application/json

{ "itemKey": "sword.gold" }

{ "id": "2b0e…", "gameId": "c115…", "itemKey": "sword.gold", "itemName": "Golden Sword",
  "price": 100, "status": "pending", "expiresAt": "2026-10-28T14:15:00Z" }

项目键为 1–64 个字符 a-z 0-9 . _ -;名称为 1-80 个字符；价格是 1–1,000,000,000 PLK。无法订购非活动或已删除的商品，已下的订单将保留 他们的快照。

错误

地位 code 意义
402 insufficient_plucks 玩家余额低于价格
402 purchase_required 玩家尚未购买的定价游戏的启动代币
409 price_changed expectedPrice 不再是价格
409 order_cancelled 确认玩家取消的订单
410 order_expired 确认后 expiresAt
429 too_many_pending_orders 太多订单等待确认

购买自己游戏的所有者可以获得 409.

您的收入

GET /api/v1/me/github-games/{id}/analytics/sales 和 …/analytics/monetization 报告单位、 毛额、平台佣金和每日净收入、付费玩家、转化率和每件商品 总计。他们只报告总数，从不透露买家的名字。您自己的历史 /me/plucks/transactions 列出每笔销售。
