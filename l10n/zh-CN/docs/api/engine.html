引擎

哪里可以得到StarHermit引擎，运行时 脚本游戏。 平台 API 是查找版本的地方：它列出了每个版本，说明哪些版本被撤销，以及 给出每个版本文件的 URL 和哈希值。阅读是匿名的。

基本网址： https://api.starhermit.com。所有路线均在 /api/v1/....

方法 小路 授权 描述
得到 /api/v1/engine/releases 匿名的 每个版本，最新版本优先，包括撤销版本
得到 /api/v1/engine/releases/{version} 匿名的 按其确切版本发布的一个版本 (X.Y.Z）， 或者 404 
{"releases": [{
  "version": "1.41.0", "api": {"major": 1, "minor": 41}, "revoked": false, "date": "2026-11-13T18:26:01Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.41.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"linux-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.41.0/native/linux-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} 回答一个这样的对象，而不需要 releases 包装纸。 网址指向 wiki.starhermit.com 对于最近发布的版本以及 engine.starhermit.com 对于年长的人； 按给定的方式使用它们。

  • api 是该版本提供的主机 API。它的专业是发行版的专业，并且 engine.api 一个 游戏声明；它的次要随着成员的增加而增长（游戏可能需要一个 engine.minor).
  • revoked: true 配有一个 revokedReason。已撤销的版本会保留在列表中，以便客户可以说出原因 他们拒绝了。
  • web 是 null 对于没有 Web 运行时的版本。 manifestIntegrity 是网络的 SRI 哈希值 运行时的 manifest.json，加载器页面固定的值。
  • native 每个平台有一个条目（windows-x86_64, linux-x86_64, macos-x86_64, macos-aarch64），或者是 {}. manifestSha256 是该平台的十六进制 SHA-256 native.json; 在信任里面的文件列表之前检查一下。

两条路线均发送 Cache-Control: public, max-age=60 与一个 ETag 并回答 304 到一个匹配的 If-None-Match。如果平台自启动以来尚未读取发布列表，他们会回答 503 和 Retry-After.

已发布的版本永远不会改变：修复是下一个版本。发动机 教程 描述最新版本；这个API说明了哪一个 也就是说。

下载引擎

开发人员下载版本的本机运行时来编写、检查、打包和玩游戏。玩家做 什么也没有：StarHermit 客户端和游戏页面获取游戏引脚的发布。

  1. 向 API 询问版本、最新版本或您的游戏固定版本：

    curl -s https://api.starhermit.com/api/v1/engine/releases/1.41.0

  2. 采取您的平台 native.<platform>.manifestUrl，获取那个 native.json 并检查其 SHA-256 反对 manifestSha256.

  3. native.json's downloads 命名开发者下载及其 size 和 sha256。档案馆 坐在旁边 native.json： 代替 native.json 结束时 manifestUrl 与档案的 名字。下载它并检查其 SHA-256。

与一个脚本相同的步骤（需要 curl, jq 和 sha256sum;在 macOS 上使用 shasum -a 256):

version=1.41.0 platform=linux-x86_64   # or windows-x86_64, macos-x86_64, macos-aarch64
release=$(curl -fsS "https://api.starhermit.com/api/v1/engine/releases/$version")
manifest_url=$(jq -r --arg p "$platform" '.native[$p].manifestUrl' <<<"$release")
manifest_sha=$(jq -r --arg p "$platform" '.native[$p].manifestSha256' <<<"$release")
curl -fsSO "$manifest_url"
echo "$manifest_sha  native.json" | sha256sum -c -
archive=$(jq -r '.downloads | keys[0]' native.json)
curl -fsSO "${manifest_url%native.json}$archive"
echo "$(jq -r --arg a "$archive" '.downloads[$a].sha256' native.json)  $archive" | sha256sum -c -

在 PowerShell 中， Invoke-RestMethod 阅读新闻稿并 Get-FileHash -Algorithm SHA256 给出 进行比较的哈希值。这 教程 封面拆箱 和第一次运行。

这 独立开发者工具 （自动出版和 开发 MCP 服务器）与运行时分开发布。

正直

一个哈希链涵盖了客户端运行的每个字节：

  1. 该 API 提供了版本的 SHA-256 native.json.
  2. native.json 给出每个文件的 SHA-256 和大小，其开发人员下载位于 downloads.
  3. StarHermit 客户端仅获取它尚未保存的版本的各个部分，检查每个部分， 将每个文件放在一起并在将版本移动到位之前进行检查。

浏览器游戏的加载器页面固定网络运行时的 starhermit.js 和 manifest.json 与 SRI 哈希值，运行时会根据清单检查它加载的所有其他文件。

网络运行时

游戏的加载页面（index.html，写者 starhermit package --web) 负载 starhermit.js 和 manifest.json 从 https://engine.starhermit.com/engine/X.Y.Z/，具有与 下的网址 web.base。使用 engine.starhermit.com 在您自己编写的任何加载器页面中：它会保留 每个版本，而下面的 URL web.base 只保留最近的版本，旧版本会消失 来自他们。 1.26.0 开始编写的工具 engine.starhermit.com 默认情况下 （--loader-base URL 或者 STARHERMIT_WEB_LOADER_BASE 覆盖它）。对于由旧工具打包的托管游戏，该平台 当版本不再存在时重写两个引擎 URL web.base;重新打包托管的游戏 其他地方。任何一个来源都不会提供已撤销的发布。

平台上的脚本游戏

当游戏的根 starhermit.txt 宣称 engine.version, 平台 将其视为脚本游戏：

  • 每次发布都会记录文件 pin 的发布，如 hosting.engineVersion，并设置 hosting.deployWarning （也在捆绑推送的答案中）当该版本未列出或已列出时 撤销。警告永远不会停止发布。
  • 托管游戏的每个页面都提供仅允许脚本的内容安全策略 来自两个引擎的起源（以及引擎自己的 blob: 工人），所以只编码一个脚本 游戏页面可以运行的是官方引擎：
default-src 'self'; script-src https://wiki.starhermit.com https://engine.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com https://engine.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com https://engine.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

没有浏览器构建的脚本游戏页面（例如仅限 Windows 的游戏上传的纯页面 对于浏览器）不需要脚本并且不受影响。

撤销

发现不安全的版本将被撤销。 StarHermit 客户端不会安装或启动它并告诉 玩家，打包命令拒绝为其打包游戏，平台向业主发出警告 发布时固定它的游戏。撤销的版本后面总是紧跟着一个固定的版本：重新固定它 并发布（参见 转向更新的引擎).
