轮廓

配置文件 API 涵盖经过身份验证的用户自己的帐户（/api/v1/me/...）、其他用户的公开查找、公钥、链接身份、隐私设置、权利和存在心跳。账户路由需要授权；当前的条款文件是公开的。

错误体各不相同；看 API约定.

端点

GET /api/v1/me

{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "username": "pk-a1b2c3d4e5f6",
  "nickname": "Al",
  "email": "dev@example.com",
  "metadata": "{}",
  "createdAt": "2026-07-01T12:00:00Z",
  "updatedAt": "2026-07-20T09:30:00Z",
  "termsAcceptedHash": "9f86d081884c7d65...",
  "termsAcceptedAt": "2026-07-30T11:02:44Z",
  "currentTermsHash": "9f86d081884c7d65...",
  "termsAcceptanceRequired": false,
  "privacy": {
    "onlineStatus": 1,
    "currentlyPlaying": 1,
    "recentLaunchActivity": 0,
    "hoursPlayed": 0,
    "recentDownloads": 0,
    "achievements": 2,
    "friendDiscoverability": 1,
    "profileVisibility": 2
  }
}

PATCH /api/v1/me

所有字段都是可选的。限制条件： username 1–32 个字符； nickname ≤64 个字符（很多 帐户没有）； metadata ≤4096 个字符。 用户名和昵称共用一个 不区分大小写的命名空间： 409 当另一个帐户使用该名称作为其用户名或昵称时， 忽略大小写。昵称是 NFKC 标准化的，控制字符或不可见字符是 400。改变 email 另外还需要一个 OAuth 验证的会话，因为帐户电子邮件可以批准凭证链接；公钥或 电子邮件验证会话获取 403 对于该字段，但仍可能更新其他字段。返回 204 成功，冲突时返回 409（用户名或昵称已被占用）。

{
  "username": "newname",
  "email": "new@example.com",
  "metadata": "{}",
  "nickname": "New Nick"
}

条款接受

在使用受保护的 REST 端点或打开 WebSocket 之前，帐户必须接受 当前 星隐条款。这适用于帐户令牌和玩家启动令牌，包括以下帐户： 接受了较旧的修订版。它不适用于匿名资源/登录或容器服务器的 自己的部署令牌。 GET /api/v1/me 并且接受端点仍然可用 等待接受时的帐户权限。

GET /api/v1/me 包括 currentTermsHash 和 termsAcceptanceRequired。所存储的 termsAcceptedHash 和 termsAcceptedAt 在第一次接受之前为空。中显示的哈希值 上面的配置文件示例已缩写；始终使用 API 返回的完整哈希值。

GET /api/v1/terms

匿名的;也可以通过玩家启动令牌读取。退货 200 和 Cache-Control: no-store:

{ "hash": "<current-64-character-lowercase-sha256>", "text": "<complete terms text>" }

使成为 text 作为纯文本。 hash 是确切 UTF-8 文档字节的 SHA-256；使用返回的 值而不是散列重新格式化显示文本。

POST /api/v1/me/terms/accept

用户阅读并明确接受显示的修订后，发送其哈希值：

POST /api/v1/me/terms/accept
Authorization: Bearer <account-access-token>
Content-Type: application/json

{ "hash": "<hash-returned-with-the-displayed-text>" }

退货 200 和 { "termsAcceptedHash", "termsAcceptedAt" }。 OAuth 和公钥帐户会话 和 玩家游戏范围的启动代币 可以接受。容器服务器令牌不能代表玩家。 接受将存储在帐户中并于 使用相同的仍然有效的令牌的下一个请求；刷新令牌是不必要的。

返回缺失/空白哈希值或长度超过 64 个字符的哈希值 400。不完全是一个哈希值 匹配当前修订返回 409:

{
  "error": "terms_version_mismatch",
  "termsHash": "<current-hash>",
  "termsUrl": "/api/v1/terms"
}

获取并显示新文档并再次请求接受；不要默默接受更换 修订。其他待接受返回的受保护请求 403:

{
  "error": "terms_acceptance_required",
  "message": "Accept the latest terms of service before using the API.",
  "termsHash": "<current-hash>",
  "termsUrl": "/api/v1/terms",
  "acceptUrl": "/api/v1/me/terms/accept"
}

托管游戏可以显示条款并使用其玩家启动令牌提交显示的哈希值 当玩家按下“接受”时，然后重试。它还可能会将玩家发送到他们的帐户 UI。 重复登录或令牌刷新并不能修复待接受的问题。 WebSocket 升级被 HTTP 拒绝 403 打开之前；浏览器可能会隐藏响应正文， 因此在连接之前通过 REST 处理接受。

帐户或游戏客户端的示例（调用 acceptDisplayedTerms 仅来自用户的接受操作）：

const api = 'https://api.starhermit.com';
async function loadTerms() {
  const response = await fetch(`${api}/api/v1/terms`);
  if (!response.ok) throw new Error(`Terms fetch failed: ${response.status}`);
  return response.json(); // Display text, retain this document's hash.
}
async function acceptDisplayedTerms(accountToken, displayedTerms) {
  const response = await fetch(`${api}/api/v1/me/terms/accept`, {
    method: 'POST',
    headers: { Authorization: `Bearer ${accountToken}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ hash: displayedTerms.hash })
  });
  if (response.status === 409) {
    throw new Error('Terms changed. Reload and display them for a new acceptance.');
  }
  if (!response.ok) throw new Error(`Acceptance failed: ${response.status}`);
  return response.json();
}

头像

PUT /api/v1/me/avatar 接受 PNG 图像，方形，≤512×512 像素，≤1 MB：

{ "imageBase64": "iVBORw0KGgoAAAANSUhEUg..." }

返回 204。 GET /api/v1/me/avatar 返回您的头像 image/png 字节。

其他用户

  • GET /api/v1/users/{id}/avatar — 任何用户的 PNG 头像。
  • GET /api/v1/users/{id}/profile:
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "username": "pk-a1b2c3d4e5f6",
  "nickname": "Al"
}

公钥

注册密钥是一个 API 凭证：其持有者可以完成 公钥挑战流程 并接收普通访问/刷新令牌 对。这使得单独标记的密钥适合桌面客户端或部署管道。

添加密钥或撤销其他密钥需要经过 OAuth 身份验证的会话。 公钥 会话可以通过以下方式仅撤销自己的密钥 DELETE /api/v1/me/public-keys/current。它不能 注册替换设备或撤销其他设备。任何完整帐户会话均可查看列表； 游戏启动和服务器令牌无法管理帐户密钥。

GET /api/v1/me/public-keys

该列表包含已撤销的行作为审计跟踪：

[
  {
    "id": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "keyType": "Ed25519",
    "keyData": "<base64-raw-32-byte-public-key>",
    "label": "orbit-league-production",
    "fingerprint": "4d9f3c...",
    "createdAt": "2026-07-01T12:00:00Z",
    "lastUsedAt": "2026-07-30T09:00:00Z",
    "isRevoked": false,
    "revokedAt": null,
    "metadata": null
  }
]

POST /api/v1/me/public-keys

需要 OAuth 身份验证的会话并立即附加密钥；与匿名不同 注册，无需电子邮件往返。

{
  "keyType": "Ed25519",
  "keyData": "<base64-raw-32-byte-public-key>",
  "label": "orbit-league-production"
}

label 是可选的（最多 128 个字符）。接受的密钥类型是 Ed25519, ECDSA-P256， 和 RSA-PSS;材料必须是标准 Base64：Ed25519 的原始 32 字节公钥，编码的 P-256 ECDSA 的曲线点或 RSA 的公共 SPKI。 RSA 密钥必须为 2048–8192 位。平台 默认情况下，规范化有效材料并将帐户限制为 20 个活动密钥。 fingerprint 是 规范的小写 SHA-256 十六进制摘要 keyType:keyData 细绳。

退货 201 使用创建的密钥。无效材料退货 400;已经激活的密钥或完整的 键列表返回 409 （后者包括 limit）。活动密钥材料在整个平台范围内是独一无二的。

DELETE /api/v1/me/public-keys/{keyId}

需要 OAuth 验证的会话。撤销是幂等的并结束刷新会话 通过钥匙；命名它的访问令牌在下一个请求时被拒绝。返回：

{ "revoked": [{ "id": "...", "isRevoked": true }], "sessionsEnded": 1 }

此帐户返回未知密钥 404.

DELETE /api/v1/me/public-keys/all

妥协响应操作：撤销每个活动密钥并结束他们验证的所有会话。 它有一个明确的 /all 路径，因此意外的空密钥 ID 不会成为批量撤销。 返回相同的 { revoked, sessionsEnded } 形状。

DELETE /api/v1/me/public-keys/current

使用公钥验证的完整帐户会话可以撤销用于该会话的密钥， 无需命名密钥 ID。用这个来 忘记这个设备。它返回相同的 { revoked, sessionsEnded } 使用该密钥塑造会话并使会话无效。丢弃存储的令牌 以及成功后的本地私钥。没有公钥的会话返回 409 和 code: "no_public_key_session";游戏启动令牌被拒绝。

有关完整的机器部署示例，请参阅 使用 OAuth 注册的公钥从 CI/CD 上传构建.

关联身份

GET /api/v1/me/identities

[
  {
    "id": "5c6d7e8f-9a0b-4c1d-8e2f-3a4b5c6d7e8f",
    "provider": "github",
    "providerUserId": "12345678",
    "createdAt": "2026-07-01T12:00:00Z",
    "metadata": "{\"login\":\"octocat\"}"
  }
]

POST /api/v1/me/identities

{
  "provider": "epic",
  "providerUserId": "your-epic-account-id",
  "metadata": null
}

平台将提供商命名为 OAuth (google, github, discord, twitch, gitlab, linkedin, bitbucket，加上保留名称 microsoft, facebook, twitter, x, apple, steam） 是 被拒绝 此处无论是否配置了该提供程序 - 这些身份是 仅可通过真实登录进行链接。使用非保留名称 (epic, gog，自定义店面 ID）。 看 验证.

DELETE /api/v1/me/identities/{identityId}

删除 OAuth 管理的身份需要经过 OAuth 身份验证的会话，因此公钥被盗 无法将所有者的路由删除回帐户。返回 204。

隐私设置

GET /api/v1/me/privacy 返回你的 PrivacySettings; PUT /api/v1/me/privacy 替换它们（返回 204）：

{
  "onlineStatus": 1,
  "currentlyPlaying": 1,
  "recentLaunchActivity": 0,
  "hoursPlayed": 0,
  "recentDownloads": 0,
  "achievements": 2,
  "friendDiscoverability": 1,
  "profileVisibility": 2
}

每个字段都是一个 PrivacyLevel 枚举： 0 =私人， 1 =仅限朋友， 2 = 公共。

存在心跳

POST /api/v1/me/heartbeat

返回 204。写入 LastSeenAt 服务器端，节流——这是朋友和聊天使用的存在信号。

游戏范围内的启动代币

在此页面上的端点中，游戏范围的启动令牌只能调用：

  • GET /api/v1/users/{id}/avatar
  • GET /api/v1/users/{id}/profile
  • GET /api/v1/me/friends （看 朋友们)
  • GET /api/v1/terms
  • POST /api/v1/me/terms/accept
  • POST /api/v1/me/heartbeat

在游戏范围围栏下，其他所有内容都会返回 403 验证.

显示名称约定

游戏 UI 通常显示 昵称 而不是渲染对手时的用户名，回退到类似的东西 "Player " + id.slice(0,8) 当没有设置昵称时。国际象棋参考实现遵循此约定；其他游戏客户端也应该这样做。

看 凭证兼容性 和 机器可读的合同.
