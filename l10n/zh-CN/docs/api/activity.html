活动

活动 API 涵盖目录游戏和外部（非目录）游戏的启动会话、游戏时间和活动源。除非另有说明，所有路由都需要 JWT。

基本网址： https://api.starhermit.com。所有路线均在 /api/v1/....

目录启动会话和游戏时间

方法 小路 授权 描述
邮政 /api/v1/activity/launches/{id}/end 智威汤逊 结束目录启动会话 (204)
得到 /api/v1/activity/software/{softwareTitleId}/playtime 智威汤逊 我对一款游戏的总游戏时间
得到 /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 智威汤逊 朋友们为了冠军而玩的时间

启动会议由 POST /api/v1/software/{id}/launch （看 catalog.md）并在此结束。游戏时响应：

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime 回报 FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

外部启动和播放时间

对于非目录游戏（链接的外部库 - 请参阅 external-libraries.md):

方法 小路 授权 描述
邮政 /api/v1/activity/external-launches 智威汤逊 启动非目录游戏的会话
邮政 /api/v1/activity/external-launches/{id}/end 智威汤逊 结束该会话 (204)
得到 /api/v1/activity/external/playtime?provider=&externalId= 智威汤逊 我玩外部游戏的总时间
得到 /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 智威汤逊 好友玩外部游戏的时间

POST /api/v1/activity/external-launches 身体 （provider ≤ 64 个字符， externalSoftwareId ≤ 256 个字符， name 选修的）：

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

回复：

{
  "launchId": "…"
}

外部播放时间响应：

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

活动提要

方法 小路 授权 描述
得到 /api/v1/activity/game-feed?key=&limit=20 智威汤逊 一把游戏钥匙的好友会话和评分活动
得到 /api/v1/activity/friends?since=&until=&limit= 智威汤逊 朋友的活动
得到 /api/v1/activity/public?since=&until=&limit= 匿名的 公共活动
得到 /api/v1/me/activity?since=&until=&limit= 智威汤逊 我自己的活动

游戏反馈返回 GameFeedItemDto[] 对于一个游戏密钥（目录指南或 "provider:externalId"， 看 catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public， 和 me/activity 返回 ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

活动 type 价值观： "download", "launch", "external_launch".

/activity/friends 按活动类型进行门控 业主的 隐私设置：启动关注 recentLaunchActivity，下载如下 recentDownloads。当级别为 FriendsOnly 或者 Public。从未选择过的帐户将获得默认值（启动时与 朋友，私人下载）。不可读的隐私文档被视为完全隐私。看 profile.md.

看 API约定 用于错误解析。

看 凭证兼容性 和 机器可读的合同.
