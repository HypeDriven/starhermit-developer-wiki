API约定

休息使用 https://api.starhermit.com/api/v1/...;插座使用 wss://api.starhermit.com/ws/v1/...。 托管游戏可以调用 /api/v1/... 和 /ws/v1/... 就其本身的起源而言。本地客户端使用 公共 API 起源。另一个源上的开发页面需要游戏上允许的 CORS 源 主持人；单独设置 SDK 基本 URL 并不授权该来源。

请求和响应

发送 JSON 使用 Content-Type: application/json，除了原始 gzip 捆绑包上传。 JSON 成员名称 都是驼峰式命名法。在 REST 中发送承载凭证 Authorization 标头。

回复 如何阅读
200 / 201 JSON 解析记录的对象或数组；容忍额外的字段
204 成功无身；不要打电话 response.json()
302 浏览器登录/确认重定向；导航而不是获取 OAuth 页面
304 条件读取不变；保留您已持有的数据
图片、附件、云保存 使用响应内容类型和端点协定读取字节
错误 首先读取状态，然后防御性地解析正文

常见的错误形式是 { "error": "...", "code": "..." }，可选字段取决于 终点。 error 通常是人类可读的； code 是一个稳定的鉴别器（如果提供的话）。 术语和其他一些端点直接将鉴别器放入 error。一些端点返回纯文本 文本、空正文或验证问题详细信息对象 title, status 和 errors。 客户端不得假设每个不成功的响应都是 JSON 或具有相同的字段。

export async function readResponse(response) {
  if (response.status === 204 || response.status === 304) return null;
  const text = await response.text();
  let body;
  try { body = text ? JSON.parse(text) : null; } catch { body = text || null; }
  if (!response.ok) {
    const message = (body && typeof body === 'object' && (body.error || body.message || body.title))
      || (typeof body === 'string' && body) || response.statusText;
    throw Object.assign(new Error(message), {
      status: response.status, code: body?.code, body,
      retryAfter: response.headers.get('Retry-After'),
    });
  }
  return body;
}

时间、大小和空值

  • createdAt, updatedAt, finishedAt，类似的帐户/资源时间戳是 ISO 8601 字符串 有偏移量。治疗缺席或 null 可选值不可用。
  • ctx.now, summary.deadline, 会话列表 deadline， 和 /time.serverTime 是整数 Unix 毫秒。转换为 new Date(value)， 不是 Date.parse(value).
  • 以字节为单位的限制值是字节，而不是 Base64 字符。 Base64 JSON 上传大于其 解码的内容。使用端点报告的有效限制（如果可用）。
  • 省略， null，和空对象并不普遍等价。设置 PATCH 删除一个 命名键与 null;单键设置 PUT 商店 null 作为一个值。收藏 PUT 取代 整个地图。阅读每个端点的更新规则。
  • 设置补丁合并 顶级键。提供的对象值替换该键的值； 它不会递归地合并嵌套属性。

分页

分页是基于一的，其中 page/pageSize 都支持。不同的API故意有不同的 回复信封；不要重复使用采用单个计数字段名称的解析器。

区域 集合形状 默认/最大页面大小
软件标题和版本 { items, totalCount, page, pageSize } 20 / 100
聊天消息 { conversationId, items, totalCount, page, pageSize } 50 / 100
排行榜条目 { items, total, page, pageSize } 20 / 100
外部软件 { items, total, page, pageSize } 20；请求较小的正页面大小
报告、容器崩溃记录、审核列表 { items, total, page, pageSize } 20 / 100
会话、好友、游戏列表、成就 数组 特定于端点的上限；没有通用的下一页光标
适度戒断饲料 基于光标 保持返回的光标；从中恢复 410 据记录

响应分页元数据反映了可用的服务页面。 参考页 和 机器可读的合同 描述端点特定的查询参数。

重试和并发

情况 行动
帐户访问令牌被拒绝 401 刷新一次，使用一个共享刷新请求；如果被拒绝则登录
启动令牌已过期 通过登录/启动器获取新令牌；过期的令牌无法自行更新
403 terms_acceptance_required 显示并明确接受当前条款，然后重试
其他 403 解决范围、成员资格、权限或帐户状态；不要循环刷新
409 解决重复/状态/修订冲突；更改资源之前重读
云保存 412 加载较新的版本并让游戏合并或采用它
429 或暂时的 503 荣誉 Retry-After，添加抖动，并绑定重试
写入期间网络故障 结果可能未知；在重复操作之前检查资源状态

Retry-After 可以是秒或 HTTP 日期。不要发明幂等标头：API 不会 承诺一个通用的幂等性密钥机制。重试会话创建或邀请可以创建 另一种资源或与第一种资源发生冲突。首选读取和显式幂等操作 自动重试。分别刷新轮换、完成上传、条款同意和终端游戏结果 有自己的规则。

对于比较和交换写入，请使用云保存 ETag、room expectedRevision，或审核修订 在支持的地方。成功的写入并不一定意味着容器部署完成；验证其 将玩家发送到新版本之前的状态。看 故障排除.
