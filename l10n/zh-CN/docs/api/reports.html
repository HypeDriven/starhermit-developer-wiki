崩溃和错误报告

玩家可以在任何有 slug 的游戏中报告崩溃或错误 - 仅限浏览器游戏 包括 - 使用游戏的启动令牌或完整的用户令牌。游戏所有者阅读、分类和 通过删除它们 /api/v1/me/github-games/{id}/reports.

容器游戏自带服务器输出和崩溃记录，参见 容器托管的游戏服务器 - 您的服务器的输出和崩溃报告.

端点

方法 小路 授权 描述
邮政 /api/v1/games/{slug}/reports 该游戏的启动令牌或 JWT 提交崩溃或错误报告
得到 /api/v1/games/{slug}/reports/mine 该游戏的启动令牌或 JWT 您对该游戏的 50 份最新报告及其状态
得到 /api/v1/me/github-games/{id}/reports 智威汤逊（所有者） 列表报告： ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
得到 /api/v1/me/github-games/{id}/reports/{reportId} 智威汤逊（所有者） 一份报告及其附件列表
得到 /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} 智威汤逊（所有者） 附件，始终作为下载
修补 /api/v1/me/github-games/{id}/reports/{reportId} 智威汤逊（所有者） 放 status
删除 /api/v1/me/github-games/{id}/reports/{reportId} 智威汤逊（所有者） 删除报告 → 204

提交报告

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind 是 crash 或者 bug; title 为必填项（≤200 个字符）。
  • 其他一切都是可选的。 userAgent 默认为请求的 User-Agent 标头。
  • 回复： 201 { "id", "kind", "status": "open", "createdAt" }.
地位 意义
400 畸形：未知 kind， 丢失的 title、无效的 base64 或不是 JSON
404 未知或已删除的游戏
413 说明、附件计数或附件字节数超出游戏限制
429 超过该游戏每日报告限额；看 Retry-After

限制

运营商可以针对整个平台和单个游戏更改其中的每一项；每日限额 也可以为一名玩家设置。

限制 默认
每个玩家每天每场比赛的报告 20
描述长度 20,000 个字符
每份报告的附件 4
每个报告的附件字节数 2 兆字节
每场比赛保存的报告 2,000
每场比赛保留的字节数 256 字节
保留 90天

当游戏达到其存储限制时，最旧的报告（首先是已解决的报告）将被删除 腾出空间。大于每个游戏的整个字节限制的单个报告将被拒绝 413.

分类报告（游戏所有者）

列表返回 { "items", "total", "page", "pageSize" };每件物品都带有记者的名字， kind, status, title、客户详细信息及其附件数量。通过移动报告 open → acknowledged → resolved 和：

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

附件以下载方式提供（Content-Disposition: attachment, nosniff, 沙箱 客户服务提供商）。只有惰性类型才会保留其声明的内容类型 - text、JSON、PNG、JPEG、WebP、GIF、zip 和 压缩包；其他任何东西，包括标记，都被用作 application/octet-stream.

来自 JavaScript SDK

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports

请参阅 JavaScript SDK.

共享 API约定 描述响应解析、时间戳、分页和重试。

看 凭证兼容性 和 机器可读的合同.
