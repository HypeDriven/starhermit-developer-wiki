朋友们

好友 API 管理好友请求和接受的好友关系。所有路线均在 api/v1/me 并需要授权。友谊国门游戏邀请，它还控制打开聊天室和语音室的访问。

错误体各不相同；看 API约定.

端点

方法 小路 授权 描述
邮政 /api/v1/me/friend-requests 智威汤逊 发送好友请求
得到 /api/v1/me/friend-requests 智威汤逊 列出待处理的好友请求
邮政 /api/v1/me/friend-requests/{requestId}/accept 智威汤逊 接受好友请求
邮政 /api/v1/me/friend-requests/{requestId}/decline 智威汤逊 拒绝好友请求
删除 /api/v1/me/friends/{friendUserId} 智威汤逊 与用户取消好友关系
得到 /api/v1/me/friends 智威汤逊 列出已接受的好友关系

好友请求

POST /api/v1/me/friend-requests

{ "toUserId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }

返回 204。

GET /api/v1/me/friend-requests

待处理的传入请求：

[
  {
    "id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "senderUserId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "senderUsername": "pk-a1b2c3d4e5f6",
    "createdAt": "2026-07-20T09:30:00Z"
  }
]

POST /api/v1/me/friend-requests/{requestId}/accept

返回204；两个用户成为朋友。

POST /api/v1/me/friend-requests/{requestId}/decline

返回 204。

朋友们

GET /api/v1/me/friends

接受了友谊。 online 来自于存在， currentGame 从主动启动：

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

与用户解除好友关系。返回 204。

友谊如何影响其他功能

  • 游戏邀请 只能发送给朋友 — 请参阅 游戏.
  • 聊天 — 友谊之门加入开放的聊天室；聊天规则要求非游戏对话为友谊。看 聊天.
  • 嗓音 — 语音室访问需要支持聊天对话的成员资格，因此聊天友谊规则可传递应用。看 嗓音.
  • 每会话游戏对话绕过友谊规则 — 同一游戏会话中的玩家可以使用其附加的聊天/语音，而无需成为朋友。

游戏范围内的启动代币

游戏范围内的启动令牌可能会调用 GET /api/v1/me/friends，因此游戏可以在会话中提供邀请朋友选择器 - 国际象棋参考实现正是使用它来实现这一目的。其他好友端点返回 403 以获取启动令牌；请参阅游戏范围的击剑规则 验证.

看 凭证兼容性 和 机器可读的合同.
