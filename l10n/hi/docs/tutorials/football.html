उदाहरण खेल: फुटबॉल स्टारहर्मिट इंजन का उपयोग कैसे करता है

स्टारहर्मिट फुटबॉल एक सार्वजनिक है, पूर्ण स्क्रिप्ट गेम. यह 1 से 22 खिलाड़ियों के लिए रीयलटाइम 3डी फ़ुटबॉल है, जिसमें एआई टीम के साथी, एक फ्लडलाइट है स्टेडियम, ऑनलाइन लॉबी, वॉयस और टेक्स्ट चैट, रीप्ले, एक लीडरबोर्ड, उपलब्धियां और नौ भाषाएँ। यह पृष्ठ इसे चरण दर चरण अलग करके दिखाता है कि एक वास्तविक गेम इंजन का उपयोग कैसे करता है। प्रत्येक चरण में शामिल इंजन मॉड्यूल के नाम और गेम के स्रोत से लिंक हैं, जहां आप पढ़ सकते हैं पूरा कोड.

यह वॉकथ्रू इंजन के लिए लिखा गया है 1.40.0, नवीनतम रिलीज। दिखाई गई प्रत्येक कॉल सूचीबद्ध है में इंजन एपीआई संदर्भ. को पढ़िए इंजन ट्यूटोरियल सबसे पहले यदि आपने अभी तक कोई स्क्रिप्ट गेम नहीं बनाया है।

स्रोत लिंक प्रतिबद्धता की ओर इशारा करते हैं 33bd9bd. उस पर गेम पिन इंजन 1.39.0 के साथ प्रतिबद्ध करें engine.minor=39. यह कुछ भी नया उपयोग नहीं करता है, इसलिए यह 1.40.0 पर अपरिवर्तित चलता है; इसे स्थानांतरित करना एक-पंक्ति परिवर्तन है engine.version (देखना चरण 12).

खेल का स्वरूप

पथ भूमिका
starhermit.txt प्रकट: नाम, इंजन पिन, सर्वर स्क्रिप्ट, नियंत्रण, क्षमताएं
server.js एक मैच सिमुलेशन: प्लेटफ़ॉर्म द्वारा आधिकारिक सर्वर के रूप में चलाया जाता है, और ऑफ़लाइन अभ्यास और भविष्यवाणी के लिए क्लाइंट द्वारा लोड किया जाता है
engine/src/main.ts प्रवेश मॉड्यूल: जीवनचक्र कॉलबैक और स्क्रीन स्टेट मशीन
engine/src/match.ts, logic/ मिलान प्रवाह, नेटकोड, प्रक्षेप और भविष्यवाणी
engine/src/world/ 3डी दृश्य में स्टेडियम, फुटबॉल खिलाड़ी, गेंद और भीड़
engine/src/screens/, hud.ts मेनू (starhermit:ui) और इन-मैच HUD (starhermit:draw)
engine/src/net.ts, platform.ts, chat.ts, voice.ts वह सब कुछ जो StarHermit प्लेटफ़ॉर्म पर बात करता है
engine/src/audio.ts, i18n.ts, quality.ts ध्वनि, भाषाएँ और ग्राफ़िक्स स्तर
assets/, sfx/ छवियां, स्ट्रिंग टेबल और ध्वनि क्लिप

1. प्रकट

starhermit.txt फ़ोल्डर को एक स्क्रिप्ट गेम बनाता है, और सर्वर स्क्रिप्ट और नियंत्रण भी घोषित करता है:

name=Football
launch=index.html
server=server.js
control.up=KeyW+ArrowUp | Run forward
control.shoot=Space+KeyJ | Shoot (hold) / tap to pass
control.tackle=KeyK | Slide tackle / pressure
engine.api=1
engine.entry=engine/src/main.ts
engine.version=1.39.0
engine.minor=39
engine.capabilities=platform,voice,clipboard,storage
engine.gamepad.shoot=West+RightTrigger
engine.gamepad.pass=South
  • launch=index.html वह लोडर पेज है starhermit package --web लिखता है. यह गेम खेलता है पिन किए गए रिलीज़ के वेब रनटाइम पर ब्राउज़र में।
  • server=server.js प्लेटफ़ॉर्म की आधिकारिक मिलान स्क्रिप्ट (चरण 6) है।
  • control.* और engine.gamepad.* पंक्तियाँ परिभाषित करती हैं कार्रवाई. रनटाइम चाबियाँ और पैड को उनसे जोड़ता है, और खिलाड़ी उन्हें रनटाइम के विकल्प मेनू में दोबारा जोड़ते हैं। गेम कभी भी गेमप्ले के लिए कुंजी का नाम नहीं देता है।
  • engine.capabilities प्लेटफ़ॉर्म (कमरे, सॉकेट, लीडरबोर्ड, रिप्ले, चैट), आवाज़, मांगता है क्लिपबोर्ड (आमंत्रित लिंक) और भंडारण (सेटिंग्स)। रनटाइम उनके बाहर कॉल को अस्वीकार कर देता है।

पूरी कुंजी सूची यहां है starhermit.txt घोषणापत्र.

2. प्रवेश मॉड्यूल और फ़्रेम लूप

engine/src/main.ts मॉड्यूल स्कोप पर रेंडरर सेट करता है, फिर चार जीवनचक्र कॉलबैक को पंजीकृत करता है starhermit:engine:

import { frame, onFixedUpdate, onRender, onStart, onUpdate, setFixedRate } from "starhermit:engine";
import { ACESFilmicToneMapping, PCFSoftShadowMap, PerspectiveCamera, renderer, scene } from "starhermit:scene";

const camera = new PerspectiveCamera(55, 16 / 9, 0.1, 800);
renderer.camera = camera;
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = PCFSoftShadowMap;
renderer.toneMapping = ACESFilmicToneMapping;

onStart(() => {
  setFixedRate(60);
  loadLanguages(); // string tables (step 10)
  sim();           // evaluate server.js once (step 6)
  menuScene.start(); // an AI-vs-AI match behind the menu
  // … platform listeners, settings listeners, invite polling
});

onFixedUpdate((step) => {
  if (match) match.fixedStep(step);
  else if (!replay) menuScene.fixedStep(step);
});

onUpdate((delta) => {
  pollQuality();
  if (match) match.update(Math.min(delta, 0.1));
  // … replay viewer or menu backdrop
});

onRender(() => {
  const fr = frame();
  if (Math.abs(camera.aspect - fr.width / fr.height) > 1e-6) {
    camera.aspect = fr.width / fr.height;
    camera.updateProjectionMatrix();
  }
  hud.draw();
  // … chat, in-match menu or the menu screens
});

कॉपी करने का पैटर्न:

  • सिमुलेशन चलता है onFixedUpdate, एक निश्चित 60 हर्ट्ज़ पर।
  • प्रति-फ़्रेम तर्क चलता है onUpdate, साथ delta छाया हुआ है ताकि रुका हुआ फ्रेम न बने खिलाड़ी कूदते हैं.
  • ड्राइंग चल रही है onRender. प्रत्येक कॉलबैक में से केवल एक ही है, इसलिए main.ts प्रशंसकों के लिए बाहर वर्तमान स्क्रीन: मेनू, लॉबी, मैच, रीप्ले या परिणाम।

3. 3डी दुनिया: starhermit:scene

स्टेडियम, फ़ुटबॉल खिलाड़ी, गेंद और अधिकारी सामान्य तीन.जेएस-शैली की वस्तुएं हैं starhermit:scene: Mesh, Group, MeshStandardMaterial, CylinderGeometry, Sprite, CanvasTexture और इसी तरह। तीन.जेएस से पोर्ट किया गया कोड अधिकतर काम करता है अपरिवर्तित. पढ़ने लायक कुछ विवरण:

  • world/stadium.ts पिच, स्टैंड, फ्लडलाइट और कोहरा बनाता है। यह पोस्ट इफ़ेक्ट सेट करता है (renderer.bloom, renderer.grade, renderer.antialias) और प्रत्येक ग्राफ़िक्स स्तर के लिए छाया।
  • world/environment.ts के साथ एक पर्यावरण मानचित्र बनाता है PMREMGenerator ए से DataTexture.
  • world/crest.ts और world/nametags.ts ए पर टीम क्रेस्ट और फ्लोटिंग उपनाम बनाएं starhermit:canvas OffscreenCanvas, फिर उन्हें इस रूप में उपयोग करें CanvasTextureरेत Sprites.

4. हजारों गतिशील हिस्से: starhermit:world

22 फुटबॉल खिलाड़ियों को संयुक्त रूप से और हजारों की संख्या में भीड़ के सदस्यों को सजीव बनाना बहुत धीमा होगा मूल दुभाषिया पर प्रति-ऑब्जेक्ट स्क्रिप्ट। फ़ुटबॉल उस काम को आगे बढ़ाता है starhermit:world टेबल (टाइप किए गए कॉलम की पंक्तियाँ) और कर्नेल (कार्यक्रम रनटाइम प्रत्येक पंक्ति पर मूल रूप से चलता है):

import { kernel, schedule, table } from "starhermit:world";

const crowd = table("crowd", CROWD_ROWS, {
  bx: "f32", by: "f32", bz: "f32", ph: "f32", fr: "f32", av: "f32",
  q: "quat", s: "f32", sy: "f32", x: "f32", y: "f32", z: "f32",
});
const sway = kernel(crowd, (r, u: { t: number; amp: number; spd: number; sway: number; shake: number }) => {
  const j = Math.sin(u.t * u.spd * r.fr + r.ph);
  r.y = r.by + (j > 0 ? j * j : 0) * u.amp * r.av;
  // …
});
// An eighth of the crowd each frame: the work is sliced across frames.
const swayRun = schedule.update(sway, { t: 0, amp: 0, spd: 0, sway: 0, shake: 0 }, { slices: 8 });

फुटबॉलर सक्रिय हो जाता है world/rig.ts उसी दृष्टिकोण का उपयोग करें. ए rigs तालिका प्रत्येक फुटबॉलर की एनीमेशन स्थिति रखती है। ए joints मेज़, एक के साथ ref:rigs कॉलम, प्रति रिग 15 जोड़ रखता है, और बंधन इससे दृश्य नोड्स चलाएँ। दो गुठली बाद में निर्धारित onUpdate पोज़ की गणना करें, और रनटाइम नोड लिखता है खुद को बदल लेता है. प्रति फुटबॉलर स्क्रिप्ट का काम एक फ्रेम में लगभग एक दर्जन नंबरों तक आता है।

5. इनपुट: क्रियाएँ, स्पर्श और गेमपैड

engine/src/input.ts मेनिफेस्ट के कार्यों को पढ़ता है starhermit:input:

  • value(action) यह बताता है कि कोई कार्रवाई कितनी दूर तक आयोजित की गई है (आंदोलन है)। value("up") - value("down")). onAction प्रेस और रिलीज़ एज प्रदान करता है।
  • माउस लुक का उपयोग करता है requestPointerLock, onPointerDelta और onPointerLockChange. कैमरे का दाहिनी ओर से छड़ी आती है gamepads(), और vibrate एक छोटा हैप्टिक टिक देता है।
  • टच स्क्रीन पर (primaryPointer() मोटा है), setTouchControls एक जॉयस्टिक दिखाता है और रनटाइम द्वारा खींचे गए शूट/पास/टैकल बटन। बटन समान क्रियाओं से बंधे हैं:
setTouchControls([
  { kind: "stick", up: "up", down: "down", left: "left", right: "right", anchor: "bottom-left", offset: [90, 90], radius: 66 },
  { kind: "button", action: "shoot", label: T("SHOOT").slice(0, 16), anchor: "bottom-right", offset: [66, 66], radius: 46 },
  // … PASS and TACKLE
]);

screens/controls.ts वर्तमान को सूचीबद्ध करता है bindings() और कॉल करता है requestRebind. फिर रनटाइम नई कुंजी कैप्चर करता है या बटन.

6. क्लाइंट और सर्वर के लिए एक सिमुलेशन: starhermit:script

server.js यह बिना किसी आयात वाली एक सादा क्लासिक स्क्रिप्ट है, Date या Math.random, प्लेटफ़ॉर्म के सैंडबॉक्स के रूप में आवश्यकता है. यह दो ग्लोबल्स को परिभाषित करता है:

  • globalThis.game प्लेटफ़ॉर्म प्रवेश बिंदु रखता है (createSession, onPlayerMessage, onTick) और स्थिर घोषणाएँ प्रकाशन समय पर पढ़ी जाती हैं:

    globalThis.game = {
  tickRateHz: 30,
  replays: true,
  achievements: [
    { key: 'debut', name: 'Debut', description: 'Finish your first match.', points: 10 },
    { key: 'hat-trick', name: 'Hat-Trick', description: 'Score three goals in one match.', points: 50 },
    // …
  ],
  createSession: function (ctx) { /* seats, AI, seed from ctx.random */ },
  // …
};

  • globalThis.FootballSim वही अनुकरण रखता है (createMatch, stepMatch, एआई) के लिए ग्राहक.

क्लाइंट उसी फ़ाइल को अपने दायरे में लोड करता है loadClassic से starhermit:script (engine/src/sim.ts):

import { loadClassic } from "starhermit:script";

loadClassic("server.js");
const S = (globalThis as unknown as { FootballSim?: FootballSimApi }).FootballSim;

ऑफ़लाइन अभ्यास चरण FootballSim हर दूसरी सीट पर एआई के साथ स्थानीय स्तर पर 60 हर्ट्ज़ पर। ऑनलाइन, मंच चलता है server.js आधिकारिक तौर पर 30 हर्ट्ज पर। गेम कभी भी इसकी दो प्रतियां नहीं रखता नियम.

7. ऑनलाइन मैच: कमरे और गेम सॉकेट

लॉबी मंच के कमरों का उपयोग करते हैं starhermit:platform (screens/lobby.ts):

import * as P from "starhermit:platform";

// Quick play: join any open room, or open one.
let room = await P.rooms.quickJoin();
if (!room) {
  room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, metadata: { game: "football" } });
  room = await P.rooms.open(room.id);
}

// Ranked solo vs AI: every other seat is an AI player, so starting begins the match at once.
room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, aiPlayers: 2 * teamSize - 1, metadata: { game: "football" } });
room = await P.rooms.start(room.id);

दोस्तों, निमंत्रण और सीट परिवर्तन का दौर चलता रहता है P.friends.list, P.rooms.invite, P.rooms.acceptInvite और P.rooms.seat. P.rooms.mine किसी खिलाड़ी को उसके द्वारा छोड़े गए मैच में फिर से शामिल होने देता है।

एक बार मैच शुरू होने पर, engine/src/net.ts के साथ गेम सॉकेट खोलता है P.connectGame(sessionId):

  • यह 30 हर्ट्ज़ पर इनपुट भेजता है sendInput.
  • यह एक पूर्ण स्नैपशॉट मांगता है sendCommand({ type: "sync" }) हर खुले पर और पर resumed.
  • यह सुनता है game (स्नैपशॉट और घटनाएँ), achievement और stopped. stopped रिपोर्ट क्यों सॉकेट बंद हो गया: साइन आउट, अद्यतन शर्तें, या मिलान समाप्त हो गया।

रनटाइम खिलाड़ी की साख रखता है और अपने आप पुनः जुड़ जाता है, इसलिए गेम कोई टोकन संभाल नहीं पाता है और इसमें कोई पुनः प्रयास लूप नहीं है।

logic/interp.ts अनुकूली प्रक्षेप के साथ सर्वर के स्नैपशॉट को सुचारू बनाता है। logic/predict.ts स्थानीय फ़ुटबॉलर की गतिविधि की भविष्यवाणी करता है और प्रत्येक स्नैपशॉट में उसे सही करता है। भविष्यवाणी प्रभावित करती है केवल वही खींचा गया है; सर्वर आधिकारिक रहता है.

प्रत्येक कॉल को एक के साथ अस्वीकार किया जा सकता है PlatformError. फ़ुटबॉल ऑनलाइन सुविधाओं को सर्वोत्तम प्रयास मानता है: a विफलता दर्शाती है "ऑनलाइन अनुपलब्ध" या फिर मौन हो जाता है, और खेल कभी ख़त्म नहीं होता। साइन आउट किया गया, गेम अभी भी ऑफ़लाइन अभ्यास प्रदान करता है।

9. मेनू और HUD: starhermit:ui, starhermit:draw, starhermit:canvas

  • मेनू (screens/*.ts, इन-मैच मेनू और संवाद main.ts) उपयोग starhermit:ui, इंजन का तत्काल-मोड यूआई। विजेट्स को हर कहा जाता है फ़्रेम से onRender, और ui.setTheme उन्हें खेल का रंग देता है। रनटाइम के अपने विकल्प मेनू इसके साथ खुलता है openMenu.
  • एचयूडी ( hud.ts) स्कोरबोर्ड, घड़ी और मार्करों को खींचता है starhermit:draw: draw.roundRect, draw.text और draw.image (एक शिखा कैनवास), दृश्य पर कॉल क्रम में।
  • इमेजिस से भरे हुए हैं createImageBitmap से starhermit:canvas, उदाहरण के लिए मेनू की मुख्य कला।

10. सेटिंग्स और भाषाएँ: starhermit:storage, तार

  • प्रति-खिलाड़ी सेटिंग्स (म्यूट, आवाज, भाषा, ग्राफिक्स ओवरराइड) लाइव रहती हैं settings से starhermit:storage. उन्हें डिवाइस पर और खाते में रखा जाता है. settings.onChange किसी अन्य डिवाइस पर किए गए परिवर्तन को लागू करता है।
  • i18n.ts भार assets/strings.json इंजन में strings टेबल (strings.load, strings.t, strings.setLanguage). यह सहेजे गए विकल्पों में से भाषा चुनता है, फिर खिलाड़ी की StarHermit भाषा, फिर डिवाइस की (preferences). l10n/font.ts स्क्रिप्ट फ़ॉन्ट को लोड करता है FontFace उन भाषाओं के लिए जिन्हें उनकी आवश्यकता है।

11. ध्वनि और ग्राफ़िक्स स्तर

  • audio.ts के साथ एक वेब ऑडियो ग्राफ़ बनाता है starhermit:audio:
    • लेखकीय क्लिप सूचीबद्ध हैं sfx/manifest.json (साथ पढ़ें files.readJson).
    • एक सिंथेसाइज़र बिना किसी क्लिप के किसी भी घटना को कवर करता है, साथ ही भीड़ और स्टेडियम की गूंज को भी कवर करता है।
    • अल्पकालिक नोड्स समाप्त होते ही जारी हो जाते हैं, क्योंकि होस्ट ग्राफ़ घिरा हुआ है।
  • quality.ts खिलाड़ी के ग्राफ़िक्स स्तर का अनुसरण करता है (frame().level, levelSettings). छाया, खिलना और एंटी-अलियासिंग उस स्तर का पालन करें। खेल की अपनी सामग्री (पिच विवरण, भीड़ घनत्व, कण) शीर्ष पर प्रति-खिलाड़ी ओवरराइड है।

12. पैकेज, परीक्षण और प्रकाशन

  • टाइप-चेक करें साथ tsc -p engine. engine/tsconfig.json रिलीज़ शामिल है starhermit.d.ts और सेट "lib": ["ES2022"], "types": [] और "allowImportingTsExtensions": true.
  • परीक्षा। npm test चलता है server.js प्रतिगमन परीक्षण. engine/tests/run.sh तर्क चलाता है नोड के अंतर्गत परीक्षण (प्रक्षेप, भविष्यवाणी, मुद्रा, लॉबी)। starhermit <folder> --check पैकेज को मान्य करता है और 120 फ़्रेमों को बिना किसी प्रयास के चलाता है।
  • पैकेट। starhermit package --web . पुनर्लेखन index.html और starhermit-files.json, जो हर परिवर्तन के साथ प्रतिबद्ध हैं।
  • प्रकाशित करें. गेम को StarHermit पर इसके रिपॉजिटरी URL से जोड़ा गया है। मंच पढ़ता है starhermit.txt, चलता है server.js मैच स्क्रिप्ट के रूप में और लीडरबोर्ड बनाता है leaderboards.json.

फ़ुटबॉल, या अपने गेम को इंजन 1.40.0 पर ले जाने के लिए:

  1. 1.40.0 रनटाइम डाउनलोड करें।
  2. तय करना engine.version=1.40.0.
  3. चेक और पैकेज दोबारा चलाएँ।

उठाना engine.minor 40 तक केवल तभी जब आप होस्ट एपीआई 1.40 चाहते हैं नई सुविधाओं.
