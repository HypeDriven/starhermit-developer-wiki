जावास्क्रिप्ट एसडीके (ब्राउज़र गेम)

starhermit-sdk.js ब्राउज़र गेम के लिए एकल-फ़ाइल, निर्भरता-मुक्त क्लाइंट है स्टारहर्मिट पर प्रकाशित। यह लॉन्च टोकन को पढ़ता है, इसे नवीनीकृत रखता है, और आम लोगों के लिए सहायक प्रदान करता है गेम-स्कोप्ड लॉन्च-टोकन एपीआई: पहचान, क्लाउड सेव, प्रति-खिलाड़ी सेटिंग्स और नियंत्रण, आमंत्रण, मंगनी, सत्र और गेमप्ले सॉकेट, उपलब्धियां, लीडरबोर्ड, रीप्ले, चैट, आवाज और वास्तविक समय के कमरे।
फ़ाइल docs/sdk/starhermit-sdk.js - इसे बिना किसी बदलाव के अपने गेम में कॉपी करें
वैश्विक window.StarHermit (भी module.exports नोड के अंतर्गत, परीक्षण के लिए)
निर्भरताएँ कोई नहीं - यह ब्राउज़र का स्वयं का उपयोग करता है fetch, WebSocket और (संपीड़ित सेव पढ़ने के लिए) DecompressionStream
एपीआई बेसलाइन REST v1 और WebSocket v1, केवल लॉन्च-टोकन सतह

एसडीके एक क्लाइंट है, प्लेटफ़ॉर्म का दूसरा कार्यान्वयन नहीं। स्कोर और उपलब्धि अनलॉक हो जाती है केवल गेम के सर्वर (एक स्क्रिप्ट परिणाम या एक कंटेनर नियंत्रण संदेश) - एक क्लाइंट द्वारा लिखे जाते हैं उन्हें कभी पोस्ट नहीं किया जा सकता, और SDK केवल उन्हें पढ़ता है। बाकी सब कुछ सर्वर-प्राधिकृत रहता है बिल्कुल वैसा ही जैसा कि पर प्रलेखित है एपीआई पेज.

प्रमाणीकृत सहायक लॉन्च टोकन के बिना कोई एपीआई अनुरोध नहीं करते हैं। पढ़ता है आम तौर पर हल को null, [], या एक खाली नक्शा; लिखने से समाधान हो सकता है null/false और डिबाउंस किए गए सेव का कोई तत्काल प्रभाव नहीं है वापसी मूल्य. एक सॉकेट डिस्कनेक्ट रहता है. यदि खिलाड़ी ने चुना है तो स्टैंडअलोन प्रगति को स्मृति में रखें ट्रैक न किया गया खेल. पुकारना signOut() अकाउंट प्ले से उस मोड पर स्विच करने से पहले नवीनीकरण रुक जाता है।

स्थापित करना

फ़ाइल को अपने गेम की अन्य स्थिर स्क्रिप्ट के बगल में कॉपी करें - जहां भी आपका बिल्ड उन्हें शिप करता है - और लोड करें यह आपके अपने कोड से पहले है:

<script src="starhermit-sdk.js"></script>
<script>
  StarHermit.init();          // as early as possible: it reads and strips the token from the URL fragment
</script>

पुकारना init() किसी भी राउटर को छूने से पहले एक बार location.hash. विकल्प: init({ base, gameId, autoRefresh, launcherUrl }) — base अधिकृत मूल स्थान पर REST कॉल को इंगित करता है स्थानीय विकास के दौरान (प्लेटफ़ॉर्म-होस्ट किए गए गेम समान-मूल का उपयोग करते हैं)। gameId, यदि आपूर्ति की गई है, तो मेल खाना चाहिए साइन-इन के लिए होस्ट किया गया यूयूआईडी; स्थानीय/बाहरी पृष्ठ मान्य गेम साइन-इन रिटर्न मूल नहीं हैं। autoRefresh: false एक गेम के लिए टोकन नवीनीकरण छोड़ देता है अपनी श्रृंखला चलाता है, और launcherUrl कहां ओवरराइड करता है relaunch() खिलाड़ी को भेजता है (डिफ़ॉल्ट https://dashboard.starhermit.com/).

साइन-इन और पहचान

ज़रूरत पुकारना
क्या कोई खिलाड़ी साइन इन है? StarHermit.signedIn, StarHermit.userId, StarHermit.slug
साइन-इन/साइन-आउट/समाप्ति पर प्रतिक्रिया दें StarHermit.on('auth', ({ signedIn, reason }) => …)
दिखाओ ए दाखिल करना बटन केवल जब StarHermit.canSignIn() (टोकन के बिना गेम यूयूआईडी उपडोमेन पर सच); क्लिक करने पर StarHermit.signIn()
खिलाड़ी का नाम/अवतार await StarHermit.profile() → { userId, username, nickname, displayName }; StarHermit.avatarUrl()
दोस्त await StarHermit.friends()

SDK दोनों लॉन्च आकृतियों को संभालता है - #game_token=<jwt>[&session_id=…] पुस्तकालय से या एक आमंत्रित करें, और #access_token=<jwt> सीधे साइन-इन से लौटना - और टोकन को नवीनीकृत करना POST /api/v1/games/{slug}/launch-token इसके समाप्त होने से पहले (देखें) टोकन लॉन्च करें). प्रदर्शन नाम प्रोफ़ाइल है nickname; /api/v1/me नहीं है लॉन्च टोकन के साथ पहुंच योग्य।

क्लाउड सेव

गेम का स्लॉट है game:<slug> (कैटलॉग: गेम के अंदर से बचत); एसडीके पथ बनाता है, पेलोड को ज़िप करता है और संभालता है /info जाँच करना।

const remote = await StarHermit.loadJSON();          // null: empty slot, signed out — or a failed read
if (StarHermit.saveLoadFailed()) showSyncError();    // tell those apart when it matters
else if (remote && isNewer(remote, local)) adopt(remote);

StarHermit.saveJSON(state);                          // debounced (2 s) checkpoint upload
addEventListener('pagehide', () => StarHermit.flushSave(true));   // keepalive flush
StarHermit.on('saved', ok => setSyncIndicator(ok));

सहेजने से पहले लोड करें. किसी भी लेखन तक पहुंचने से पहले क्लाउड कॉपी की तुलना करें और उसे अपनाएं saveJSON - बूट पर सेटिंग्स, उपनाम या चेकपॉइंट राइट्स सहित - या एक पुरानी स्थानीय प्रतिलिपि किसी अन्य डिवाइस पर किए गए नए सेव को अधिलेखित करें। जब तक स्टार्ट-अप लोड व्यवस्थित न हो जाए, तब तक प्रारंभिक बचत करें।

एसडीके उस दौड़ के दूसरे हिस्से की सुरक्षा करता है: जब कोई रीड विफल हो जाता है (नेटवर्क या सर्वर त्रुटि, जैसे)। एक खाली स्लॉट के विपरीत) यह सेट हो जाता है saveLoadFailed(), उत्सर्जित करता है saveerror, और तब तक लिखने से इंकार कर देता है /info पुष्टि करता है कि स्लॉट खाली है या बाद वाला है loadSave() सफल होता है. एक अस्वीकृत लेखन का समाधान हो जाता है false और उत्सर्जित करता है saved साथ false.

लोड के बाद लिखना सशर्त है। SDK संस्करण को याद रखता है (ETag) अंतिम बार इसे सेव करें पढ़ता है या लिखता है और इसे वापस भेजता है, इसलिए एक लेखन केवल उसी सेव पर लैंड करता है जिस पर यह आधारित था - या, एक स्लॉट के लिए वह ख़ाली था, केवल तब जब वह अभी भी है। जब कोई अन्य उपकरण बीच में सहेजा जाता है, तो लिखने से इनकार कर दिया जाता है (412): एसडीके उत्सर्जित करता है saveconflict, सेट saveConflicted(), और आगे लिखने से इंकार कर देता है जब तक कि ए loadSave() गेम को मर्ज करने देता है या नया सेव अपनाने देता है। एक गेम जो कभी लोड नहीं होता लिखता है बिना शर्त, पहले की तरह।

StarHermit.on('saveconflict', async () => {
  const remote = await StarHermit.loadJSON();       // lifts the block
  StarHermit.saveJSON(merge(remote, local));        // conditional on the version just loaded
});

निचले स्तर: loadSave() / writeSave(text) कच्ची डोरियों के लिए, saveInfo() के लिए { exists, sizeBytes, updatedAt, etag }.

क्रैश और बग रिपोर्ट

खिलाड़ी खेल के अंदर से समस्याओं की रिपोर्ट कर सकते हैं; मालिक उनका परीक्षण करता है रिपोर्ट एपीआई.

await StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', {
  clientVersion: '1.4.2',
  attachments: [{ fileName: 'state.json', contentType: 'application/json', data: JSON.stringify(state) }],
});
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports
const mine = await StarHermit.myReports();               // [{ id, kind, status, title, ... }]

report(kind, title, description, opts) सामान्य रूप है (reportBug और reportCrash ठीक करें दयालु)। captureCrashes फ़ाइलें प्रति विशिष्ट संदेश में अधिकतम एक रिपोर्ट और प्रति पृष्ठ लोड तीन, इसलिए a क्रैश लूप खिलाड़ी के दैनिक भत्ते (डिफ़ॉल्ट रूप से प्रति गेम 20) का उपयोग नहीं कर सकता। पहले खिलाड़ी से पूछें कुछ भी व्यक्तिगत संलग्न करना।

सेटिंग्स और नियंत्रण

ज़रूरत पुकारना
प्रति-खिलाड़ी प्राथमिकताएं (वॉल्यूम, ग्राफ़िक्स प्रीसेट, भाषा, पहुंच...) getSettings(), getSetting(key), setSetting(key, value), patchSettings({…}) (a null मान कुंजी हटा देता है), deleteSetting(key), clearSettings()
कीबोर्ड बाइंडिंग घोषित की गई starhermit.txt जैसा control.<action>=… await loadBindings(defaults) → { action: codes[] } खिलाड़ी के ओवरराइड लागू होने के साथ
एक रिबाइंडिंग स्क्रीन getControls(), setControl(action, codes), setControls(bindings), resetControls()

मार्ग keydown के माध्यम से event.code और बाइंडिंग से loadBindings. देखना अपने गेम में नियंत्रण जोड़ें और यह starhermit.txt घोषणापत्र.

ग्राफ़िक्स मेनू के लिए, graphics-options.js सेटिंग कॉल के शीर्ष पर बैठता है: यह गुणवत्ता प्रीसेट का स्वत: पता लगाता है, खिलाड़ी की पसंद को ध्यान में रखता है localStorage और उनका प्रति गेम सेटिंग्स, और एक तैयार पैनल भेजता है। देखना स्वचालित रूप से पहचानी गई गुणवत्ता के साथ ग्राफ़िक्स विकल्प.

ऑडियो अनुभाग के लिए, देखें स्वचालित रूप से पहचानी गई ध्वनि सीमा के साथ ऑडियो विकल्प: अनुशंसित ध्वनि और ध्वनि नियंत्रण, शुद्ध audio-options.js मददगार, और आपके मिक्सर द्वारा लागू प्लेबैक कैप।

मल्टीप्लेयर, आमंत्रण और सामाजिक

सत्र गेमप्ले, मैचमेकिंग, गेम उपलब्धियां, लीडरबोर्ड और रीप्ले के लिए एक सर्वर की आवश्यकता होती है (लिखी हुई कहानी या CONTAINER). रीयलटाइम कमरे और दोस्त नहीं. सत्र चैट और आवाज के लिए संगत वार्तालाप सदस्यता की आवश्यकता होती है।

क्षेत्र कॉल
सत्र mySessions(), getSession(id), sessionRecovery(id), leaveSession(id), startAiSession(); StarHermit.launchSessionId आमंत्रण लॉन्च के बाद
गेमप्ले सॉकेट const conn = connect(sessionId, { onGame, onError, onPresence, onAchievement, onResumed, onAbandoned, onOpen, onClose, onAuthLost }), तब conn.send(data); बैक-ऑफ के साथ पुनः कनेक्ट होता है, पहले टोकन को नवीनीकृत करता है, और सामान्य/पॉलिसी/ओवरसाइज़ बंद होने पर रुक जाता है (1000/1008/1009), 4403/4404, या जब नवीनीकरण से इनकार कर दिया जाता है (देखें) पुन: कनेक्ट)
मंगनी करना queues(), joinQueue([keys]), matchStatus(), cancelMatch(), waitForMatch(opts)
आमंत्रण sendInvite(toUserId[, sessionId]) (के साथ sessionId मित्र उस चल रहे सत्र में शामिल हो जाता है), invites(), acceptInvite(id), declineInvite(id); inviteLink(query) एक शेयर लिंक के लिए
अपने लीडरबोर्ड पर एक रन पोस्ट करें submitScores({ boardKey: number }) → स्वीकृत कुंजियाँ (देखें एकल-खिलाड़ी लीडरबोर्ड)
उपलब्धियां और लीडरबोर्ड (केवल पढ़ने के लिए) achievements(), linkedAchievements(otherSlug), leaderboards(), leaderboard(key, opts), leaderboardEntries(boardId, opts); के माध्यम से टोस्ट अनलॉक करें on('achievement', …)
रिप्ले myReplays(limit), getReplay(id)
सत्र चैट chatMessages(id), sendChat(id, text), pollChat(id, onMessages, intervalMs) - REST और पोलिंग केवल लॉन्च टोकन के लिए
आवाज/वास्तविक समय कमरे StarHermit.voice.* (REST; WebRTC सिग्नलिंग को गेम पर छोड़ दिया गया है), StarHermit.realtime.* (कमरे प्लस ws/v1/realtime)

जो कुछ भी लपेटा नहीं गया है वह एक कॉल दूर है: StarHermit.api(path, { method, body }) एक भेजता है प्रमाणित JSON अनुरोध (समाधान)। null 404/204 पर या साइन आउट होने पर अस्वीकार कर देता है { status, message } अन्य विफलताओं पर, 401 पर एक बार नवीनीकरण करें)।

एकल-खिलाड़ी लीडरबोर्ड

एक क्लाइंट कभी भी स्कोर पोस्ट नहीं कर सकता - केवल गेम का सर्वर ही कर सकता है - इसलिए एकल-खिलाड़ी गेम को एक की आवश्यकता होती है अपने बोर्डों के मालिक होने के लिए छोटी प्लेटफ़ॉर्म स्क्रिप्ट। score-script.js एक है: इसे आगे कॉपी करें अपने गेम में, इसे घोषित करें starhermit.txt जैसा server=score-script.js, और केवल उसका संपादन करें BOARDS ब्लॉक, जो प्रत्येक बोर्ड को आपके रूप में सूचीबद्ध करता है इसे बनाएं:

var BOARDS = {
  "high-score": { "name": "High score", "scoreType": "integer", "sortDirection": "desc", "minScore": 0, "maxScore": 1000000 }
};

जब कोई रन समाप्त हो जाए, तो उसे पोस्ट करें और खिलाड़ी का स्थान दिखाएं:

const accepted = await StarHermit.submitScores({ 'high-score': total });   // [] when signed out or refused
if (accepted.includes('high-score')) {
  const board = await StarHermit.leaderboard('high-score', { pageSize: 100 });
  const me = board.items.find(e => e.userId === StarHermit.userId);
  showRank(me && me.rank);
}

submitScores एक अभ्यास सत्र खोलता है (POST .../sessions/ai), भेजता है {type:'result', scores} पर गेमप्ले सॉकेट, और स्वीकृत स्क्रिप्ट द्वारा बोर्ड कुंजियों का समाधान करता है; यह उत्सर्जन भी करता है scores के साथ वह सूची. स्क्रिप्ट एक ऐसा स्कोर छोड़ देती है जो बोर्ड के प्रकार का नंबर नहीं है या उसके बाहर आता है minScore/maxScore, बाकी को इसके माध्यम से पोस्ट करता है scores वापस लौटें और सत्र समाप्त करें। ग्राहक अभी भी परिणाम की रिपोर्ट करता है। एक इन-रेंज आविष्कृत स्कोर पास हो सकता है; ये बोर्ड कैज़ुअल के लिए उपयुक्त हैं खेलो. प्रतियोगिता के लिए, पुरस्कार देने से पहले स्क्रिप्ट या कंटेनर में रन को मान्य करें। स्वीकृति स्क्रिप्ट-स्वीकृत कुंजियाँ सूचीबद्ध करता है; यह इस बात का प्रमाण नहीं है कि प्रत्येक बोर्ड सक्रिय था या कोई नया व्यक्तिगत सर्वश्रेष्ठ था संग्रहीत किया गया था. देखना विश्वास और उपलब्धता.

पुनः कनेक्ट करना और समाप्त हो चुके टोकन

एक सॉकेट अपने यूआरएल में लॉन्च टोकन रखता है, और समाप्त टोकन के साथ हैंडशेक से पहले इनकार कर दिया जाता है अपग्रेड - ब्राउज़र केवल क्लोज़ कोड की रिपोर्ट करता है 1006, बिल्कुल नेटवर्क ड्रॉप की तरह। तो एक असफल पुन: कनेक्ट करना एक प्रमाणीकरण विफलता हो सकता है, और उसी URL को पुनः प्रयास करने से कभी भी पुनर्प्राप्त नहीं किया जा सकता है। नवीनीकरण ही कार्य करता है जबकि वर्तमान टोकन वैध है और मूल लॉन्च के 12 घंटों के भीतर है; उसके बाद ही लॉन्चर एक नया टोकन बना सकता है।

connect() इसे स्वयं संभालता है: प्रत्येक पुनः कनेक्ट करने से पहले यह टोकन को नवीनीकृत करता है POST /api/v1/games/{slug}/launch-token (जब तक कि सॉकेट खुलने के बाद से इसे नवीनीकृत नहीं किया गया था) और फिर से खुल जाता है नये के साथ. नवीनीकरण करते समय एक नेटवर्क या सर्वर त्रुटि वापस आ जाती है और फिर से नवीनीकृत हो जाती है - ऐसा कभी नहीं होता पुराने URL को पुनः खोलता है. जब नवीनीकरण से इनकार कर दिया जाता है या टोकन समाप्त हो जाता है, तो एसडीके साइन आउट कर देता है (auth साथ reason: 'expired'), पुनः कनेक्ट करना और कॉल करना बंद कर देता है onAuthLost():

const conn = StarHermit.connect(sessionId, {
  onGame, onClose,
  onAuthLost: () => showReconnectPanel(),   // e.g. "Session expired — Back to StarHermit"
});
backButton.onclick = () => StarHermit.relaunch();

relaunch() खिलाड़ी को नए लॉन्च टोकन के लिए वापस भेजता है: साइन-इन के माध्यम से जब गेम खोला गया था उस तरह (StarHermit.launchKind === 'sign-in'), अन्यथा लॉन्चर के लिए। लॉन्चर के अंदर गेम फ्रेम यह शीर्ष विंडो को नेविगेट करता है, जिसे ब्राउज़र केवल उपयोगकर्ता के इशारे से अनुमति देते हैं, इसलिए इसे कॉल करें एक क्लिक से; यह वापस आता है false जब नेविगेशन से इनकार कर दिया गया था.

एक ब्राउज़र समाप्त-सत्र, शर्तों, सदस्यता को छुपा सकता है, या विफलताओं का निर्माण कर सकता है 1006. एक से पहले स्वचालित पुनः प्रयास, connect() REST और कब के माध्यम से सत्र स्थिति की जाँच करता है opts.build आपूर्ति की जाती है, इसकी तुलना गेम की जानकारी से करता है। onUnavailable(error) स्थायी REST विफलता प्राप्त होती है या समाप्त हो जाती है सत्र; onTermsRequired(body) स्पष्ट शर्तों की स्वीकृति का अनुरोध करता है। इसके बाद नया कनेक्शन बनाएं इनका समाधान कर रहे हैं. onClose(1008) इसका मतलब है कि कनेक्शन हटा दिया गया था या नीति का उल्लंघन किया गया था; मत करो स्वचालित रूप से इसे पुनः खोलें.

सॉकेट आपका गेम स्वयं खुलता है (realtime.socketUrl(roomId), voice.socketUrl(roomId)) की आवश्यकता है वही नियम. किसी को दोबारा खोलने से पहले कॉल करें renewForReconnect() और इसके परिणाम पर कार्य करें:

async function reopen() {
  const r = await StarHermit.renewForReconnect();
  if (r === 'renewed') ws = new WebSocket(StarHermit.realtime.socketUrl(roomId)); // fresh token in the URL
  else if (r === 'retry') setTimeout(reopen, backoff());                         // renewal itself failed
  else if (r === 'terms-required') showTermsPanel();                              // explicit acceptance
  else showReconnectPanel();                                                     // 'relaunch'
}

समवर्ती नवीनीकरण एक अनुरोध साझा करते हैं। terms-required प्लेयर टोकन को सुरक्षित रखता है और उत्सर्जित करता है termsrequired; प्रदर्शन getTerms() और कॉल करें acceptTerms(displayed.hash) केवल खिलाड़ी पर कार्रवाई स्वीकार करें, फिर पुनः प्रयास करें. आपके गेम द्वारा प्रबंधित सॉकेट को भी समाप्त संसाधनों के लिए REST जांच की आवश्यकता होती है और पॉलिसी बंद होने पर रुकना चाहिए। देखना समस्या निवारण.
