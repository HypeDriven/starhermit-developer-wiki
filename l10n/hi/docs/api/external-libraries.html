बाहरी पुस्तकालय

उपयोगकर्ता की स्टीम, एपिक, या जीओजी लाइब्रेरी को लिंक करना ताकि उनके बाहरी गेम को सूचीबद्ध, लॉन्च और ट्रैक किया जा सके। सभी मार्गों के लिए JWT की आवश्यकता होती है।

आधार यूआरएल: https://api.starhermit.com. सभी मार्ग नीचे हैं /api/v1/....

लिंक करना और अनलिंक करना

तरीका पथ प्रमाणीकरण विवरण
पाना /api/v1/me/external-libraries जेडब्ल्यूटी मेरे लिंक किए गए प्रदाताओं की सूची बनाएं
डाक /api/v1/me/external-libraries/link जेडब्ल्यूटी किसी प्रदाता को लिंक करें और उसके शीर्षकों को सिंक करें
मिटाना /api/v1/me/external-libraries/{provider} जेडब्ल्यूटी एक लिंक और उसके स्वामित्व हटाएँ

लिंक की गई लाइब्रेरी:

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

लिंक बॉडी:

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

रिटर्न 204. लिंकिंग प्रदाता के शीर्षकों को भी सिंक करता है। लाइब्रेरी सिंक वर्तमान में डेमो शीर्षक लौटाता है steam/epic/gog जबकि वास्तविक प्रदाता एकीकरण को अंतिम रूप दे दिया गया है।

स्वामित्व वाला बाहरी सॉफ्टवेयर और लॉन्चिंग

तरीका पथ प्रमाणीकरण विवरण
पाना /api/v1/me/external-software?provider=&page=&pageSize= जेडब्ल्यूटी मेरे बाहरी शीर्षकों की पृष्ठांकित सूची
डाक /api/v1/external-software/{ownershipId}/launch जेडब्ल्यूटी एक लॉन्च यूआरआई प्राप्त करें और एक बाहरी लॉन्च रिकॉर्ड करें

बाहरी सॉफ़्टवेयर सूची:

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

लॉन्च प्रतिक्रिया:

{
  "launchUri": "steam://run/…"
}

प्रदाता द्वारा यूआरआई प्रारूप लॉन्च करें: steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. लॉन्चिंग एक बाहरी लॉन्च गतिविधि को रिकॉर्ड करती है - देखें activity.md. बाहरी गेम एकसमान गेम कुंजी का उपयोग करते हैं "provider:externalId" रेटिंग और फ़ीड के लिए - देखें catalog.md.

देखना एपीआई कन्वेंशन त्रुटि पार्सिंग के लिए.

देखना क्रेडेंशियल अनुकूलता और मशीन-पठनीय अनुबंध.
