गतिविधि

गतिविधि एपीआई कैटलॉग शीर्षक और बाहरी (गैर-कैटलॉग) गेम दोनों के लिए लॉन्च सत्र, प्लेटाइम और गतिविधि फ़ीड को कवर करती है। जब तक उल्लेख न किया गया हो, सभी मार्गों के लिए JWT की आवश्यकता होती है।

आधार यूआरएल: https://api.starhermit.com. सभी मार्ग नीचे हैं /api/v1/....

कैटलॉग लॉन्च सत्र और खेल का समय

तरीका पथ प्रमाणीकरण विवरण
डाक /api/v1/activity/launches/{id}/end जेडब्ल्यूटी कैटलॉग लॉन्च सत्र समाप्त करें (204)
पाना /api/v1/activity/software/{softwareTitleId}/playtime जेडब्ल्यूटी एक शीर्षक के लिए मेरा कुल विश्राम समय
पाना /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 जेडब्ल्यूटी एक शीर्षक के लिए दोस्तों का खेल का समय

लॉन्च सत्र शुरू हो गए हैं POST /api/v1/software/{id}/launch (देखना catalog.md) और यहीं समाप्त हुआ। खेल के समय प्रतिक्रिया:

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime रिटर्न FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

बाहरी लॉन्च और प्लेटाइम

गैर-कैटलॉग गेम्स के लिए (जुड़े हुए बाहरी पुस्तकालय - देखें external-libraries.md):

तरीका पथ प्रमाणीकरण विवरण
डाक /api/v1/activity/external-launches जेडब्ल्यूटी गैर-कैटलॉग गेम के लिए एक सत्र प्रारंभ करें
डाक /api/v1/activity/external-launches/{id}/end जेडब्ल्यूटी उस सत्र को समाप्त करें (204)
पाना /api/v1/activity/external/playtime?provider=&externalId= जेडब्ल्यूटी किसी बाहरी गेम के लिए मेरा कुल खेलने का समय
पाना /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 जेडब्ल्यूटी बाहरी खेल के लिए दोस्तों का खेल का समय

POST /api/v1/activity/external-launches शरीर (provider ≤ 64 वर्ण, externalSoftwareId ≤ 256 वर्ण, name वैकल्पिक):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

प्रतिक्रिया:

{
  "launchId": "…"
}

बाहरी खेल के समय प्रतिक्रिया:

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

गतिविधि फ़ीड्स

तरीका पथ प्रमाणीकरण विवरण
पाना /api/v1/activity/game-feed?key=&limit=20 जेडब्ल्यूटी एक गेम कुंजी के लिए मित्रों के सत्र और रेटिंग इवेंट
पाना /api/v1/activity/friends?since=&until=&limit= जेडब्ल्यूटी मित्रों की गतिविधि
पाना /api/v1/activity/public?since=&until=&limit= गुमनाम सार्वजनिक गतिविधि
पाना /api/v1/me/activity?since=&until=&limit= जेडब्ल्यूटी मेरी अपनी गतिविधि

गेम फ़ीड वापस आती है GameFeedItemDto[] एक गेम कुंजी के लिए (एक कैटलॉग गाइड या "provider:externalId", देखना catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public, और me/activity वापस करना ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

गतिविधि type मान: "download", "launch", "external_launch".

/activity/friends पर प्रति गतिविधि प्रकार गेट किया गया है मालिक का गोपनीयता सेटिंग: लॉन्च का पालन करें recentLaunchActivity, डाउनलोड अनुसरण करते हैं recentDownloads. स्तर होने पर प्रत्येक को शामिल किया जाता है FriendsOnly या Public. जिस खाते ने कभी चयन नहीं किया है उसे डिफ़ॉल्ट (लॉन्च के साथ साझा किया गया) मिलता है मित्रो, डाउनलोड निजी)। एक अपठनीय गोपनीयता दस्तावेज़ को पूरी तरह से निजी माना जाता है। देखना profile.md.

देखना एपीआई कन्वेंशन त्रुटि पार्सिंग के लिए.

देखना क्रेडेंशियल अनुकूलता और मशीन-पठनीय अनुबंध.
