दोस्त

मित्र एपीआई मित्र अनुरोधों और स्वीकृत मित्रता का प्रबंधन करता है। सभी मार्ग नीचे हैं api/v1/me और प्राधिकरण की आवश्यकता है. फ्रेंडशिप स्टेट गेट्स गेम आमंत्रण देता है, और यह खुले चैट रूम और वॉयस रूम तक पहुंच को भी नियंत्रित करता है।

त्रुटि निकाय अलग-अलग होते हैं; देखना एपीआई कन्वेंशन.

अंतिमबिंदुओं

तरीका पथ प्रमाणीकरण विवरण
डाक /api/v1/me/friend-requests जेडब्ल्यूटी मित्र अनुरोध भेजें
पाना /api/v1/me/friend-requests जेडब्ल्यूटी लंबित आने वाले मित्र अनुरोधों की सूची बनाएं
डाक /api/v1/me/friend-requests/{requestId}/accept जेडब्ल्यूटी मित्र अनुरोध स्वीकार करें
डाक /api/v1/me/friend-requests/{requestId}/decline जेडब्ल्यूटी मित्र अनुरोध अस्वीकार करें
मिटाना /api/v1/me/friends/{friendUserId} जेडब्ल्यूटी किसी उपयोगकर्ता को अनफ्रेंड करें
पाना /api/v1/me/friends जेडब्ल्यूटी उपस्थिति के साथ स्वीकृत मित्रता की सूची बनाएं

मित्र अनुरोध

POST /api/v1/me/friend-requests

{ "toUserId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }

रिटर्न 204.

GET /api/v1/me/friend-requests

लंबित आने वाले अनुरोध:

[
  {
    "id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "senderUserId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "senderUsername": "pk-a1b2c3d4e5f6",
    "createdAt": "2026-07-20T09:30:00Z"
  }
]

POST /api/v1/me/friend-requests/{requestId}/accept

रिटर्न 204; दो उपयोगकर्ता दोस्त बन जाते हैं।

POST /api/v1/me/friend-requests/{requestId}/decline

रिटर्न 204.

दोस्त

GET /api/v1/me/friends

मित्रता स्वीकार की. online उपस्थिति से आता है, currentGame सक्रिय लॉन्च से:

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

उपयोगकर्ता को अनफ्रेंड करता है. रिटर्न 204.

मित्रता अन्य सुविधाओं को कैसे प्रवेश देती है

  • गेम आमंत्रण केवल मित्रों को भेजा जा सकता है - देखें खेल.
  • बात करना - खुले चैट रूम से जुड़ने वाले मैत्री द्वार; चैट नियमों के अनुसार गैर-गेम वार्तालापों के लिए मित्रता की आवश्यकता होती है। देखना बात करना.
  • आवाज़ - वॉयस रूम एक्सेस के लिए बैकिंग चैट वार्तालाप की सदस्यता की आवश्यकता होती है, इसलिए चैट मैत्री नियम परिवर्तनीय रूप से लागू होते हैं। देखना आवाज़.
  • प्रति-सत्र खेल वार्तालाप मित्रता नियमों को दरकिनार कर देते हैं - एक ही खेल सत्र में खिलाड़ी मित्र बने बिना इसकी संलग्न चैट/आवाज का उपयोग कर सकते हैं।

गेम-स्कोप्ड लॉन्च टोकन

गेम-स्कोप्ड लॉन्च टोकन कॉल कर सकता है GET /api/v1/me/friends, इसलिए एक गेम एक सत्र के अंदर एक मित्र को आमंत्रित करने वाले चयनकर्ता की पेशकश कर सकता है - शतरंज संदर्भ कार्यान्वयन ठीक उसी के लिए इसका उपयोग करता है। अन्य मित्र समापन बिंदु लॉन्च टोकन के लिए 403 लौटाते हैं; गेम-स्कोप फेंसिंग नियम देखें प्रमाणीकरण.

देखना क्रेडेंशियल अनुकूलता और मशीन-पठनीय अनुबंध.
