सॉफ्टवेयर कैटलॉग

सॉफ़्टवेयर कैटलॉग में ब्राउज़िंग और शीर्षकों का दावा करना, लिस्टिंग बिल्ड, डाउनलोडिंग, क्लाउड सेव, विशलिस्ट और रेटिंग शामिल हैं। पढ़ी गई बातें गुमनाम हैं; लिखने के लिए JWT की आवश्यकता होती है।

आधार यूआरएल: https://api.starhermit.com. सभी मार्ग नीचे हैं /api/v1/....

शीर्षकों को ब्राउज़ करना और दावा करना

तरीका पथ प्रमाणीकरण विवरण
पाना /api/v1/software गुमनाम कैटलॉग खोजें और पेज करें
पाना /api/v1/software/{id} गुमनाम एक शीर्षक प्राप्त करें, या 404
पाना /api/v1/software/{id}/builds?page=&pageSize= गुमनाम किसी शीर्षक के लिए बिल्ड की पृष्ठांकित सूची
डाक /api/v1/software/{id}/claim जेडब्ल्यूटी एक निःशुल्क उपाधि का स्व-दावा करें, एक पात्रता प्रदान करें
डाक /api/v1/software/{id}/launch जेडब्ल्यूटी एक लॉन्च सत्र प्रारंभ करें (पात्रता की आवश्यकता है)

GET /api/v1/software क्वेरी पैरामीटर स्वीकार करता है q (पूर्ण पाठ), category, tag, publisherId, platform, releaseStatus, sort, page, और pageSize. वैध sort मान: name, name_desc, created, created_desc, updated, updated_desc. यह एक लौटाता है PagedResult:

{
  "items": [
    {
      "id": "…",
      "name": "…",
      "description": "…",
      "publisherId": "…",
      "category": "…",
      "platform": "…",
      "releaseStatus": "…",
      "tags": ["…"],
      "priceCents": 0,
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

GET /api/v1/software/{id}/builds रिटर्न ए PagedResult का SoftwareBuild:

{
  "items": [
    {
      "id": "…",
      "titleId": "…",
      "version": "…",
      "releaseDate": "…",
      "releaseNotes": "…",
      "metadata": "…",
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

POST /api/v1/software/{id}/claim केवल निःशुल्क शीर्षकों के लिए काम करता है (priceCents == 0); यह कॉल करने वाले को एक पात्रता देता है और 204 लौटाता है। भुगतान किए गए शीर्षकों के लिए यह 402 लौटाता है:

{"error": "purchasing is not available yet"}

POST /api/v1/software/{id}/launch एक पात्रता की आवश्यकता है (403 अन्यथा) और एक रिटर्न देता है LaunchSession:

{
  "launchId": "…",
  "startTime": "…"
}

यह एक लॉन्च गतिविधि को रिकॉर्ड करता है, जो उपयोगकर्ता की गोपनीयता सेटिंग्स के कहने पर छिपी रहती है (देखें)। profile.md). के साथ सत्र समाप्त करें POST /api/v1/activity/launches/{id}/end - देखना activity.md. उपयोगकर्ता की पात्रताएँ इसके माध्यम से सूचीबद्ध हैं GET /api/v1/me/entitlements (देखना profile.md).

डाउनलोड

तरीका पथ प्रमाणीकरण विवरण
डाक /api/v1/software/{id}/download जेडब्ल्यूटी एक हस्ताक्षरित डाउनलोड यूआरएल प्राप्त करें (पात्रता की आवश्यकता है)

एक पात्रता की आवश्यकता है (403 अन्यथा)। रिटर्न:

{
  "downloadUrl": "…"
}

यूआरएल नवीनतम बिल्ड की पहली डाउनलोड करने योग्य संपत्ति को लक्षित करता है। कॉल एक डाउनलोड गतिविधि रिकॉर्ड करती है। कैटलॉग बाइनरी वितरण वर्तमान में एक पूर्वावलोकन है; लौटाए गए यूआरएल के उत्पादन की गारंटी नहीं है डाउनलोड. देखना सुविधा उपलब्धता इस प्रकाशन प्रवाह पर भरोसा करने से पहले।

क्लाउड सेव

प्रति गेम एक स्लॉट, अंतिम लेखन जीतता है। सभी मार्गों के लिए JWT की आवश्यकता होती है - एक पूर्ण उपयोगकर्ता टोकन, या एक गेम उस गेम के अपने स्लॉट के लिए लॉन्च टोकन (नीचे)।

10 एमबी की सीमा (10,485,760 बाइट्स) लागू होती है डिकोडेड सेव, अनुरोध नहीं. PUT लेता है JSON में बेस64-एनकोडेड को सेव करें, इसलिए बॉडी सेव से लगभग एक तिहाई बड़ी है - लगभग 14 एमबी टोपी - और एपीआई इसे स्वीकार करता है।

सीमा (प्रति खाता) गलती करना इनकार
एक सेव, डिकोड किया गया 10 एमबी 413 cloud_save_too_large
बचत के साथ खेल 200 409 cloud_save_slots_exhausted (एक नए गेम के लिए बचत)
सब मिलकर बचाते हैं 1 जीबी 507 cloud_save_quota_exceeded, साथ used
अपलोड 30 प्रति मिनट 429, साथ Retry-After

प्रत्येक इनकार में लागू संख्या को इस प्रकार बताया गया है limit. कुल को खाते के ऊपर मापा जाता है अन्य बचाता है, इसलिए एक स्लॉट को हमेशा किसी बड़ी चीज़ से अधिलेखित किया जा सकता है। ऑपरेटर इनमें से कोई भी बदल सकते हैं ये एक खाते के लिए.

तरीका पथ प्रमाणीकरण विवरण
पाना /api/v1/me/cloud-saves/{gameKey}/info जेडब्ल्यूटी मेटाडेटा सहेजें: { exists, sizeBytes, updatedAt? }
पाना /api/v1/me/cloud-saves/{gameKey} जेडब्ल्यूटी application/zip बाइट्स, 404 यदि कोई नहीं
रखना /api/v1/me/cloud-saves/{gameKey} जेडब्ल्यूटी एक सेव अपलोड करें (डीकोडेड सेव ≤ 10 एमबी, gameKey ≤ 300 वर्ण)
मिटाना /api/v1/me/cloud-saves/{gameKey} JWT (पूर्ण उपयोगकर्ता टोकन) स्लॉट हटाएँ, 204 (निष्क्रिय)

DELETE खाता स्वामी का है - केवल पूर्ण उपयोगकर्ता टोकन। गेम का लॉन्च टोकन पढ़ सकता है और अपना स्वयं का स्लॉट लिखें लेकिन नही सकता इसे हटा (403), इसलिए कोई गेम कभी भी सेव प्लेयर को नहीं मिटा सकता रखने की उम्मीद है.

शरीर रखो:

{
  "dataBase64": "…"
}

प्रतिक्रिया दें:

{
  "gameKey": "…",
  "sizeBytes": 0,
  "updatedAt": "…"
}

गेम के अंदर से बचत (लॉन्च टोकन)

अपने लॉन्च टोकन के साथ चलने वाला गेम खिलाड़ी के सेव को पढ़ और लिख सकता है वह खेल. आपका गेम जहां भी चलता है, खुद को सेव कर लेता है - ब्राउज़र, या स्टारहर्मिट डेस्कटॉप ऐप, जो चलता है गेम को ब्राउज़र में भी होस्ट किया जाता है - इसलिए सेव उनके बीच के प्लेयर का अनुसरण करता है।

कुंजी है game:<gameId>, कहाँ <gameId> आपके गेम की आईडी है - उसके स्लग के समान मूल्य, इसका <gameId>.starhermit.com पता, और game_scope लॉन्च टोकन का दावा:

const key = `game:${gameScope}`;            // e.g. "game:3fa85f64-5717-4562-b3fc-2c963f66afa6"

// Load on startup — 404 means no save yet.
const res = await fetch(`/api/v1/me/cloud-saves/${key}`, { headers: { Authorization: `Bearer ${launchToken}` } });
if (res.status !== 404 && !res.ok) throw new Error(`Save load failed: ${res.status}`);
const save = res.status === 404 ? null : new Uint8Array(await res.arrayBuffer());
const etag = res.headers.get("ETag");
if (save && !etag) throw new Error("Save version unavailable; do not overwrite it.");
// Validate/decode your own save format before adopting it or enabling uploads.

// Save at checkpoints, not every frame.
const written = await fetch(`/api/v1/me/cloud-saves/${key}`, {
  method: "PUT",
  headers: {
    Authorization: `Bearer ${launchToken}`, "Content-Type": "application/json",
    ...(etag ? { "If-Match": etag } : { "If-None-Match": "*" }),
  },
  body: JSON.stringify({ dataBase64: base64(zipBytes) }), // Your ZIP encoder and bytes.
});
if (written.status === 412) throw new Error("Another device saved. Reload before writing again.");
if (!written.ok) throw new Error(`Save write failed: ${written.status}`);
const acknowledgement = await written.json(); // Retain acknowledgement.etag for your next write.
  • केवल वही सटीक कुंजी. कोई अन्य कुंजी - किसी अन्य गेम की, किसी स्टोर गेम की, या किसी भिन्न वर्तनी की आपका (अपर केस, नंगे आईडी) - है 403 लॉन्च टोकन के लिए. इसमें शामिल है github:<gameId>, जब कोई खिलाड़ी आपके गेम के लिए स्थानीय सेव फ़ोल्डर को सिंक करता है तो डेस्कटॉप ऐप अलग स्लॉट का उपयोग करता है वह सिंक कभी भी आपके गेम द्वारा लिखे गए सेव को ओवरराइट नहीं कर सकता है।
  • कोई भी प्रारूप. प्लेटफ़ॉर्म कभी भी सेव नहीं खोलता; जो कुछ भी आपका गेम वापस पढ़ सकता है उसे संग्रहीत करें (यह है के रूप में सेवा की application/zip ध्यान दिए बगैर)। 10 एमबी तक.
  • बिना शर्त लेखन अंतिम लेखन जीत है, बिना किसी इतिहास के। पता लगाने के लिए सशर्त लेखन का उपयोग करें दो टैब/डिवाइस एक साथ सहेजे जा रहे हैं। प्रारंभ पर लोड करें और अग्रभूमि चौकियों पर सहेजें। पृष्ठ-निकास अपलोड सर्वोत्तम प्रयास हैं और ब्राउज़र बॉडी-आकार की सीमाएं हैं; देखना सुरक्षित बचत नुस्खा.
  • प्रत्येक सेव का एक संस्करण होता है। इसका ETag डाउनलोड पर है, चालू /info (के रूप में भी etag) और आगे द PUT प्रतिक्रिया। के रूप में इसे वापस भेजें If-Match और लिखना तभी होता है जब किसी ने नहीं बचाया हो चूँकि; अन्यथा 412 {"error":"precondition_failed","etag":"<current>"} आपको संस्करण बताता है भार. If-Match: * मौजूदा बचत की आवश्यकता है; If-None-Match: * केवल तभी लिखता है जब कोई नहीं होता। न ही हेडर के साथ ए PUT बिना शर्त है - अंतिम लेखन जीतता है। ए GET साथ If-None-Match: <etag> जवाब 304 जब आपके पास पहले से ही नवीनतम सेव हो।
  • बिना होस्टेड लिस्टिंग वाले गेम (ऑपरेटर द्वारा प्रदत्त गेम) में कोई स्लॉट नहीं होता है।

छोटी, बार-बार बदलती प्राथमिकताएँ इसमें शामिल हैं प्रति-खिलाड़ी सेटिंग्स बजाय; वे लॉन्च टोकन के साथ भी उपलब्ध हैं और आंशिक अपडेट का समर्थन करते हैं।

इच्छा-सूची

सभी मार्गों के लिए JWT की आवश्यकता होती है।

तरीका पथ प्रमाणीकरण विवरण
पाना /api/v1/me/wishlist जेडब्ल्यूटी { titleIds: guid[] }
रखना /api/v1/me/wishlist/{titleId} जेडब्ल्यूटी इच्छा सूची में जोड़ें, 204 (निष्क्रिय)
मिटाना /api/v1/me/wishlist/{titleId} जेडब्ल्यूटी इच्छा सूची से हटाएँ, 204

रेटिंग

सभी मार्गों के लिए JWT की आवश्यकता होती है। यूनिफ़ॉर्म गेम कुंजी एक कैटलॉग गाइड है, या "provider:externalId" बाहरी खेलों के लिए (देखें external-libraries.md).

तरीका पथ प्रमाणीकरण विवरण
रखना /api/v1/me/ratings जेडब्ल्यूटी किसी गेम के लिए मेरी रेटिंग बढ़ाएँ
डाक /api/v1/ratings/query जेडब्ल्यूटी बैच-फ़ेच रेटिंग सारांश
पाना /api/v1/ratings/reviews?key=&top= जेडब्ल्यूटी किसी गेम के लिए समीक्षाएं (top डिफ़ॉल्ट 10)

शरीर रखो:

{
  "gameKey": "…",
  "stars": 4,
  "review": "…"
}

stars 0-5 है; review वैकल्पिक है. प्रतिक्रिया एक है RatingSummaryDto:

{
  "gameKey": "…",
  "average": 4.5,
  "count": 12,
  "myStars": 4
}

POST /api/v1/ratings/query शरीर और प्रतिक्रिया:

{
  "keys": ["…", "…"]
}

रिटर्न RatingSummaryDto[]. GET /api/v1/ratings/reviews रिटर्न GameReviewDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "stars": 4,
    "review": "…",
    "timestamp": "…"
  }
]
