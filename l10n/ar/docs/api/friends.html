أصدقاء

تدير واجهة برمجة تطبيقات الأصدقاء طلبات الصداقة والصداقات المقبولة. جميع الطرق تحت api/v1/me وتتطلب الحصول على إذن. لعبة بوابات دولة الصداقة تدعوك، كما أنها تتحكم في الدخول إلى غرف الدردشة المفتوحة وغرف الصوت.

تختلف أجسام الخطأ؛ يرى اتفاقيات API.

نقاط النهاية

طريقة طريق مصادقة وصف
بريد /api/v1/me/friend-requests JWT أرسل طلب صداقة
يحصل /api/v1/me/friend-requests JWT قائمة طلبات الصداقة الواردة المعلقة
بريد /api/v1/me/friend-requests/{requestId}/accept JWT قبول طلب الصداقة
بريد /api/v1/me/friend-requests/{requestId}/decline JWT رفض طلب الصداقة
يمسح /api/v1/me/friends/{friendUserId} JWT قم بإلغاء صداقة المستخدم
يحصل /api/v1/me/friends JWT قائمة الصداقات المقبولة مع الحضور

طلبات الصداقة

POST /api/v1/me/friend-requests

{ "toUserId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }

العودة 204.

GET /api/v1/me/friend-requests

الطلبات الواردة المعلقة:

[
  {
    "id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "senderUserId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "senderUsername": "pk-a1b2c3d4e5f6",
    "createdAt": "2026-07-20T09:30:00Z"
  }
]

POST /api/v1/me/friend-requests/{requestId}/accept

إرجاع 204؛ يصبح المستخدمان صديقين.

POST /api/v1/me/friend-requests/{requestId}/decline

العودة 204.

أصدقاء

GET /api/v1/me/friends

الصداقات المقبولة online يأتي من الوجود currentGame من الإطلاق النشط:

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

إلغاء صداقة المستخدم. العودة 204.

كيف أبواب الصداقة ميزات أخرى

  • دعوات اللعبة لا يمكن إرسالها إلا إلى الأصدقاء — انظر ألعاب.
  • محادثة - بوابات الصداقة للانضمام إلى غرف الدردشة المفتوحة؛ تتطلب قواعد الدردشة الصداقة للمحادثات غير المتعلقة باللعبة. يرى محادثة.
  • صوت - يتطلب الوصول إلى الغرفة الصوتية عضوية محادثة الدردشة الداعمة، لذلك تنطبق قواعد الصداقة في الدردشة بشكل انتقالي. يرى صوت.
  • تتجاوز محادثات اللعبة في كل جلسة قواعد الصداقة - يمكن للاعبين في نفس جلسة اللعبة استخدام الدردشة/الصوت المرفق دون أن يكونوا أصدقاء.

رموز الإطلاق على مستوى اللعبة

قد يتم استدعاء رمز الإطلاق المميز على نطاق اللعبة GET /api/v1/me/friends، لذلك يمكن للعبة أن تقدم منتقي دعوة صديق داخل الجلسة - يستخدمه تطبيق مرجع الشطرنج لهذا الغرض بالضبط. تقوم نقاط النهاية الصديقة الأخرى بإرجاع 403 لرموز الإطلاق؛ راجع قواعد المبارزة على نطاق اللعبة في المصادقة.

يرى التوافق الاعتماد و العقود المقروءة آليا.
