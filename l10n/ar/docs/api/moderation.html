الاعتدال في المحتوى

تتحقق الألعاب من النص المشترك ومستندات JSON وصور PNG/JPEG/WebP قبل عرضها للآخرين اللاعبين. تيار فقط allow يسمح بالمشاركة. review, block، غير معروف، معلق، فاشل، تؤدي جميع نتائج السياسة منتهية الصلاحية وغير المتوافقة إلى إبقاء المحتوى مخفيًا.

عمليات التحقق من الإشراف غير متاحة حاليًا عند النشر العام. قراءة الاكتشاف من قبل تمكين المشاركة. عودة الشيكات 503 overloaded مع Retry-After: 300; هذا لا يعد التوفر بعد خمس دقائق. احتفظ بالمحتوى مخفيًا حتى تتلقى قرار السماح الحالي. الجيل هو أيضا غير متاح.

يصف العقد أدناه مكالمات الإشراف المدعومة وسلوكها عند توفرها. فقط يتم إرجاع الأدلة التي تم فحصها والتي يمكن الوصول إليها من خلال واجهات برمجة التطبيقات الخاصة بمراجعة المالك.

المتصلين والطرق

بادئة اللاعب هي /api/v1/games/{slug}/moderation. JWTs ورموز الإطلاق تحمل اللاعب. يجب أن يتطابق رمز الإطلاق مع هذه اللعبة. يجب أيضًا أن يتطابق الرمز المميز لخادم الحاوية المباشرة مع اللعبة. أصلي يستخدم العملاء عنوان URL الأساسي لواجهة برمجة التطبيقات؛ يمكن لألعاب المتصفح استخدام أصول اللعبة الخاصة بها /api الوكيل.

طريقة لاحقة المتصل نتيجة
يحصل (جذر) لاعب أو خادم التوفر والحدود الفعالة والمحتوى المدعوم والسياسة الحالية
بريد /check لاعب أو خادم 200 دفعة كاملة أو 202 في انتظار الاختيار
يحصل /checks/{checkId} اللاعب المنسوب أو إنشاء خادم اللعبة 200 حالة؛ 410 بعد الاحتفاظ بالنتيجة
بريد /decisions/lookup لاعب أو خادم 200 التجزئة المؤهلة المعروفة/غير المعروفة
بريد /flags لاعب 201 إيصال العلم؛ لا يمكن للخوادم تقديم العلامات
يحصل /removed?since=&pageSize= لاعب أو خادم عمليات السحب المقسمة إلى صفحات والمؤشر التالي

لا يمكن للاعبين التحقق كلاعب آخر. يرسل الخادم عادة sessionId و participantUserId; يجب أن يكون المشارك في جلسة نشطة لهذه اللعبة، ويتم فرض سعر الشيك الخاص به. ل إعادة فحص العالم المستمر مع عدم وجود أحد عبر الإنترنت، أرسل attribution: "game" وحذف كلا الحقلين. يستهلك هذا معدل خادم منفصل وميزانية اللعبة، ولا يسجل أي لاعب ويسمح بالاقتراع فقط من خلال هوية الخادم المعتمد للعبة. لا يؤدي تحديث الرمز المميز إلى تغيير تلك الهوية المنطقية.

التوفر

GET /api/v1/games/{slug}/moderation العوائد:

{
  "checksAvailable": false,
  "contentReportingAvailable": false,
  "disabledReason": "moderation_not_configured",
  "policyVersion": "<current effective version>",
  "supportedKinds": ["text", "image"],
  "supportedContexts": ["chat", "name", "generated-content", "user-content"],
  "limits": { "moderation.check.items": 20, "moderation.decision.allow_ttl_seconds": 3600 },
  "acceptedPreviousPolicyVersion": null,
  "previousPolicyValidUntil": null,
  "deliveredContentGraceSeconds": 0
}

limits يحتوي على قيم تسجيل الإشراف الفعال، بخلاف القيمتين الموضحتين. لاعب تتضمن القيم تجاوزات ذلك اللاعب؛ اكتشاف الخادم يكشف عن صلاحيات اللعبة، لا شيء آخر اللاعب. تؤدي ميزانية عنصر اللعبة الصفرية أيضًا إلى تعطيل التحقق (game_budget_disabled). استخدم قيم تداخل السياسات وقيم السماح التي تم إرجاعها؛ لا توفر الإعدادات الافتراضية أيًا منهما.

تحقق من المحتوى الدقيق

POST /api/v1/games/{slug}/moderation/check
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "items": [
    { "id": "story", "kind": "text", "context": "user-content", "text": "abc" }
  ]
}

تعتبر معرفات العناصر فريدة ضمن الدفعة ولا تزيد عن 128 حرفًا. النص يحمل فقط text; الصور حمل contentType ومبطن بمعايير صارمة dataBase64، بدون مسافة بيضاء. الصورة المعلنة يجب أن تتطابق الأنواع مع رؤوسها، ويجب أن تكون وحدات البايت والبكسلات محدودة. واف، أوج فوربيس، نماذج وخطوط glTF غير مدعومة (415 unsupported_kind); تم تأجيل الدعم الصوتي.

التجزئة هي sha256: متبوعًا بـ 64 رقمًا سداسيًا صغيرًا من SHA-256 على بايتات المحتوى المحددة:

  • بالنسبة للنص، يقوم JSON بفك تشفير السلسلة وترميز قيم Unicode العددية الخاصة بها كـ UTF-8 بدون قائمة مكونات الصنف (BOM). الحفاظ على المسافات البيضاء ونهايات الأسطر وتطبيع Unicode؛ رفض البدائل غير المقترنة.
  • يتم تجزئة مستند JSON الذي يتم إرساله كنص باعتباره سلسلة المستند الدقيقة، دون تحليل، إعادة ترتيبها أو إعادة تسلسلها.
  • بالنسبة للصورة، قم بتجزئة البايتات التي تم فك تشفيرها قبل تغيير الحجم أو تحويل الشفرة أو تغيير البيانات الوصفية.

بايتات ASCII الثلاثة abc التجزئة ل sha256:ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad. تؤدي إضافة سطر جديد إلى تغيير التجزئة. مظروف الطلب ومعرف العنصر والسياق ونوع الوسائط وbase64 الترميز ليس مدخلات التجزئة. تقوم المنصة بحساب التجزئات المقدمة؛ يجب أن تتلقى الألعاب أيضا قم بتجزئة البايتات التي يحتفظون بها بالفعل وقارن المعرف.

هناك عنصر كامل status: "complete", contentHash, decisionالتصنيفات المراجعة, checkedAt و decisionPolicyVersion. يحمل فقط السماح validUntil. غلاف الرد لديه الفعالية الحالية policyVersion. التحقق من الصحة يرفض الدفعة بأكملها في حالة وجود أي عنصر مشوه. يمكن أن يفشل العنصر المقبول بشكل منفصل، مع status: "failed"، رمز ولا قرار.

الموعد النهائي المتزامن الافتراضي هو ثانيتين. إنتاج العناصر غير المكتملة 202 مع checkId, pollAfterSeconds, expiresAt و Retry-After. استطلاع الشيك؛ العناصر المعلقة ليس لها قرار. الموعد النهائي الافتراضي للخلفية هو 60 ثانية، ثم يفشل العنصر غير المكتمل timeout و يتم مسح مدخلاتها العادية. تظل النتائج النهائية قابلة للقراءة لمدة ساعة واحدة بشكل افتراضي.

يستشير استطلاع العنصر المكتمل القرار المؤهل المباشر والسياسة الحالية والاحتفاظ به. لا يمكن للشيك القديم تجديد الموافقة المسحوبة. يتم إرجاع الكتل/المراجعات الحالية على هذا النحو؛ تؤدي القرارات التي لا معنى لها أو منتهية الصلاحية أو الغائبة إلى عنصر فاشل بدون صلاحية متجددة.

البحث والاسترداد الانسحاب

{
  "hashes": ["sha256:ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"],
  "kind": "text",
  "context": "user-content"
}

أرسل هذا إلى /decisions/lookup. عمليات البحث عن الصور تحمل أيضًا اسمًا contentType. الموافقة مؤهلة من قبل اللعبة والنوع ونوع الوسائط والسياق الذي تم التحقق منه. الإدخالات هي known مع القرار والمراجعة decisionPolicyVersion والسماح بالصلاحية، أو unknown مع not_checked, policy_changed أو expired. تظل الكتل البشرية فعالة بعد تغييرات السياسة والاحتفاظ بالقرار العادي.

السماح بافتراضيات الصلاحية لمدة ساعة واحدة ويمكن للمشغل خفضها. إعادة التحقق قبل انتهاء الصلاحية؛ لا توجد فترة سماح ممكّنة لانقطاع الخدمة ولا يوجد إصدار أساسي سابق مقبول. تغيير تؤدي سياسة اللعبة إلى إبطال الموافقات السابقة على الفور. التصريح البشري يبقى بعد إعادة الفحص فقط للحصول على نتائج متطابقة لا تزال تتجاوز خط الأساس الحالي بموجب نفس السياسة.

استطلاع /removed قبل توزيع الحزمة المشتركة وبشكل منتظم أثناء اللعب. إخفاء التجزئة المطابقة وإيقاف التوزيع عند السحب؛ تشمل عمليات الإزالة كلا من الأعلام المؤيدة وإعادة التصنيف من السماح بالمراجعة/الحظر. تتضمن إدخالات الخلاصة المؤهلات، والنطاق، والقرار، والمراجعة، والسياسة، وقت الإزالة وسبب آمن. المؤشرات هي علامات ترتيب غير شفافة؛ استخدم المؤشر الذي تم إرجاعه بدلاً من اشتقاق مؤشر من وقت واحد.

يعود مؤشر منتهي الصلاحية 410 cursor_expired. جلب مؤشر جديد بدون since، بحث دفعة جميع التجزئة المشتركة المحملة، ولا تستأنف إلا بعد التحقق من صحتها. الغياب عن التغذية لا يعتبر موافقة أبداً. النسخة المحلية المحفوظة لا تسمح بإعادة التوزيع. تبلغ مدة الخلاصة الافتراضية 90 يومًا من التاريخ؛ كتل بشرية متينة تدوم أكثر من ذلك.

الأعلام ومراجعة المالك

يرسل أحد اللاعبين /flags a reason (64 حرفًا على الأكثر)، محدد اختياريًا note، والمحتوى، لاعب مستهدف، أو كليهما. يستخدم دليل المحتوى نفس شكل العنصر مثل الشيك. لو contentHash يتم توفيره أيضًا، وتقوم المنصة بإعادة حسابه وتتطلب المساواة. التجزئة العارية ليست دليلا. لم يتم تنفيذ مراجع الوظيفة/التحقق. تتطلب علامة هدف اللاعب وجود sessionId الذي قائمته يشمل كلا من المراسل والهدف. إن تقديم العلم لا يغير القرار ولا تلقائيًا يمنع أي شخص.

يتم حجز دليل المحتوى وتخزينه في الحجر الصحي قبل التصنيف للتوجيه. تأخر، الفحص الفاشل أو غير المتاح لا يفتح أبدًا وصول المالك. يسمح الفحص الحالي للمالك الآمن القائمة/التفاصيل/التنزيل/الفرز. تخفي نتائج فريق العمل العلم وتقيد العلامات والمراجعات الموجودة من نفس الأدلة. بدون مصنف، تعود إشارات المحتوى 403 content_reporting_disabled بدون نصيحة إعادة المحاولة أو الاحتفاظ بالأدلة؛ تظل أعلام اللاعب فقط قابلة للاستخدام.

تتطلب مسارات المالك ملكية JWT كاملة للعبة، ضمن /api/v1/me/github-games/{id}/moderation:

طريقة لاحقة سلوك
الحصول على / وضع /policy قراءة/تعيين التصنيف وعتبات الفئات الأكثر صرامة مع expectedVersion
يحصل /flags / /flags/{flagId} بيانات تعريف مقسمة إلى صفحات / علامة واحدة يمكن الوصول إليها
يحصل /flags/{flagId}/evidence تنزيل متحكم فيه؛ 410 بعد انتهاء الأدلة
رقعة /flags/{flagId} action: "uphold" أو "dismiss"، ملاحظة اختيارية و expectedRevision
يحصل /reviews / /reviews/{reviewId} البيانات الوصفية للمراجعة المقسمة إلى صفحات / مراجعة واحدة يمكن الوصول إليها
يحصل /reviews/{reviewId}/content تنزيل متحكم فيه؛ 410 review_expired عندما لا تكون متاحة
رقعة /reviews/{reviewId} action: "allow" أو "block"، ملاحظة اختيارية و expectedRevision

تأخذ القوائم status, page و pageSize (الافتراضي 20، الحد الأقصى 100). فقط سياسة المالك الأكثر صرامة قد يُسمح بالاحتفاظ الذي يتجاوز حاليًا خط الأساس للمنصة؛ تتطلب عمليات الحجز الأساسية منصة المراجعة خارج واجهة برمجة تطبيقات مالك اللعبة. الأدلة المقيدة لا تكون مرئية للمالك أبدًا. المراجعة التي لا معنى لها هي 409 revision_conflict. يؤدي اتخاذ قرار بشأن المراجعة إلى محو محتواها المحتفظ به؛ انتهاء الصلاحية أيضا يمنع تنزيله أو الموافقة عليه. لا يؤدي تجاهل العلامة إلى التراجع عن كتلة أخرى ولا مالك لها الطريق يرفع كتلة بشرية.

الدليل هو application/octet-stream المرفق مع nosniffو Sandbox CSP و no-store. احتفظ بالملاحظات/الأسباب كنص غير موثوق به في واجهة مستخدم المراجعة الخاصة بك. لا تجعلها ترميزًا أو تستخدمها كـ عناوين URL للمرفقات.

الحدود والأخطاء الافتراضية

يمكن للمشغلين ضبط حدود اللعبة؛ تدعم أسعار اللاعبين أيضًا التجاوزات لكل مستخدم. قراءة الاكتشاف ل القيم الفعلية المعمول بها.

يؤدي استنفاد قائمة الانتظار/التخزين إلى رفض الأدلة الجديدة بدلاً من طرد الحالات النشطة. احترام إمكانية الوصول وانتهاء الصلاحية المبلغ عنها بواسطة كل نقطة نهاية للأدلة/المراجعة.

الأخطاء هي { error, code, retryAfterSeconds? }. 400 يغطي المحتوى/المؤهلات المشوهة، 401 المصادقة المفقودة, 403 النطاق/التفويض أو القيود الأساسية، 404 غائب / يتعذر الوصول إليه السجلات, 409 التجزئة/المراجعة/صراعات السياسة ، 410 محتوى منتهي الصلاحية/الشيكات/المؤشرات، 413 بايت / البند / حدود البكسل، و 415 الأنواع/الأنواع غير المدعومة. 429 يغطي الأسعار/الميزانيات/قوائم الانتظار/التخزين Retry-After. انقطاعات المصنف هي 503 moderation_unavailable; الحالي غير تكوينه يبقى العنصر النائب 503 overloaded. لا يوجد خطأ أو إعادة المحاولة أو بدائل الدفع لقرار السماح.

مشترك اتفاقيات API وصف تحليل الاستجابة، والطوابع الزمنية، وترقيم الصفحات، وإعادة المحاولة.

يرى التوافق الاعتماد و العقود المقروءة آليا.
