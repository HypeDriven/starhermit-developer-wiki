محادثة

تغطي دردشة StarHermit الرسائل المباشرة وغرف المجموعات ومحادثات جلسات الألعاب عبر REST API (api/v1/chat) بالإضافة إلى قناة دفع WebSocket من الخادم إلى العميل (ws/v1/chat). تتطلب جميع نقاط نهاية REST المصادقة. تختلف أجسام الخطأ؛ يرى اتفاقيات API.

نقاط النهاية REST

قاعدة: https://api.starhermit.com/api/v1/chat.

طريقة طريق مصادقة وصف
بريد /conversations JWT إنشاء محادثة (صديق واحد = مباشر، ≥2 = مجموعة)
رقعة /conversations/{id} JWT إعادة تسمية محادثة (أي عضو)
بريد /conversations/{id}/invites JWT دعوة مستخدم إلى مجموعة
يحصل /invites JWT قم بإدراج دعوات الدردشة المعلقة
بريد /invites/{id}/accept JWT قبول دعوة للدردشة
بريد /invites/{id}/decline JWT رفض دعوة للدردشة
يحصل /rooms/joinable JWT قم بإدراج الغرف المفتوحة التي يوجد بداخلها صديق واحد أو أكثر
بريد /conversations/{id}/join JWT الانضمام إلى غرفة مفتوحة (يجب أن يكون لديك أصدقاء مع أحد الأعضاء)
بريد /conversations/{id}/participants JWT إضافة مشاركين إلى محادثة
يمسح /conversations/{id}/participants/{userId} JWT إزالة مشارك (النفس: أي عضو؛ الآخرون: منشئ المجموعة فقط)
بريد /conversations/{id}/leave JWT اترك محادثة
يحصل /conversations JWT قائمة المحادثات، بما في ذلك عدد غير المقروءة
يحصل /conversations/{id} JWT احصل على محادثة، بما في ذلك عدد الرسائل غير المقروءة
يحصل /unread JWT احصل على إجمالي عدد الرسائل غير المقروءة
بريد /conversations/{id}/read JWT وضع علامة على المحادثة كمقروءة
يحصل /conversations/{id}/messages?page=&pageSize= JWT الحصول على سجل الرسائل المقسم إلى صفحات
بريد /conversations/{id}/messages JWT إرسال رسالة (السعر محدود)
يضع /conversations/{conversationId}/messages/{messageId} JWT تحرير رسالة
يمسح /conversations/{conversationId}/messages/{messageId} JWT حذف رسالة (علامة مميزة)

قم بإنشاء محادثة

POST /conversations

{
  "participantIds": ["<guid>"],
  "name": "Friday night lobby",
  "friendUserId": "<guid>",
  "joinPolicy": "closed"
}

جميع الحقول اختيارية. يقوم أحد الأصدقاء المشاركين بإنشاء ملف مباشر محادثة؛ اثنان أو أكثر ينشئون أ مجموعة. joinPolicy يكون "open" أو "closed" (تقصير "closed"). يعود أ ConversationDto.

إعادة تسمية محادثة

PATCH /conversations/{id} مع { "name": "New name" } → ConversationDto. يجوز لأي عضو إعادة التسمية؛ مذكرة النظام مع kind: "system_rename" يتم بثه.

يدعو

POST /conversations/{id}/invites مع { "toUserId": "<guid>" } → ChatInviteDto. الدعوات هي الطريقة الوحيدة للدخول إلى غرفة مغلقة.

GET /invites → ChatInviteDto[]:

[
  {
    "id": "<guid>",
    "conversationId": "<guid>",
    "conversationName": "Friday night lobby",
    "fromUserId": "<guid>",
    "fromUsername": "alice",
    "toUserId": "<guid>",
    "status": "pending",
    "createdAt": "2026-07-22T07:00:00Z"
  }
]

POST /invites/{id}/accept و POST /invites/{id}/decline → ChatInviteDto.

الانضمام إلى الغرف

GET /rooms/joinable → JoinableRoomDto[] - الغرف المفتوحة التي يوجد بداخلها أحد أصدقائك على الأقل:

[
  {
    "id": "<guid>",
    "name": "Friday night lobby",
    "joinPolicy": "open",
    "createdAt": "2026-07-22T07:00:00Z",
    "participants": [{ "userId": "<guid>", "username": "alice" }]
  }
]

POST /conversations/{id}/join → ConversationDto. ينضم إلى غرفة مفتوحة؛ يجب أن تكون صديقًا لأحد الأعضاء.

مشاركون

POST /conversations/{id}/participants مع { "participantIds": ["<guid>"] } → ConversationDto.

DELETE /conversations/{id}/participants/{userId} → 204. يجوز لأي عضو إزالة نفسه؛ تتطلب إزالة الآخرين أن تكون منشئ المجموعة.

POST /conversations/{id}/leave → 204.

قراءة المحادثات

GET /conversations → ConversationDto[].

GET /conversations/{id} → ConversationDto:

{
  "id": "<guid>",
  "type": "group",
  "name": "Friday night lobby",
  "createdByUserId": "<guid>",
  "joinPolicy": "closed",
  "createdAt": "2026-07-22T07:00:00Z",
  "participants": [{ "userId": "<guid>", "username": "alice" }],
  "otherParticipant": { "userId": "<guid>", "username": "bob" },
  "unreadCount": 3
}

type هو واحد من direct, group, game. name, createdByUserId، و otherParticipant قد يكون غائبا. unreadCount يحسب الرسائل النصية غير المقروءة المرسلة من قبل الأعضاء الآخرين بعد أفق قراءة المتصل لكل محادثة.

حالة غير مقروءة

GET /unread إرجاع عدد الرسائل غير المقروءة في جميع محادثات المتصل:

{ "total": 7 }

POST /conversations/{id}/read يتقدم أفق قراءة المتصل لتلك المحادثة. استخدمه بعد عرض النص الحالي. يصدر الخادم أ conversation_read حدث ل جميع المقابس التابعة للمتصل، مما يسمح للعديد من العملاء الذين قاموا بتسجيل الدخول بمسح شاراتهم. قد تؤدي الرسائل الجديدة والمحذوفة إلى تغيير الإجمالي، لذلك يجب على العملاء التحديث من أحداث WebSocket أو إعادة بشكل دوري /unread.

رسائل

GET /conversations/{id}/messages?page=1&pageSize=50 → PagedMessagesDto:

{
  "conversationId": "<guid>",
  "page": 1,
  "pageSize": 50,
  "totalCount": 123,
  "items": []
}

POST /conversations/{id}/messages مع { "content": "hello" } → MessageDto. يقتصر السعر على 10 رسائل/دقيقة لكل مستخدم؛ يتجاوز ذلك يعود 429.

PUT /conversations/{conversationId}/messages/{messageId} مع { "content": "edited" } → MessageDto.

DELETE /conversations/{conversationId}/messages/{messageId} → 204. الحذف علامة قبر: تبقى الرسالة مع isDeleted: true.

MessageDto:

{
  "id": "<guid>",
  "conversationId": "<guid>",
  "senderId": "<guid>",
  "senderUsername": "alice",
  "content": "hello",
  "kind": "text",
  "metadata": { "key": "value" },
  "sentAt": "2026-07-22T07:00:00Z",
  "editedAt": null,
  "isDeleted": false
}

kind يكون "text" أو "system_rename"; content, metadata (a Dictionary<string,string>)، و editedAt قد تكون غائبة/فارغة.

مقبس ويب: ws/v1/chat

الاتصال ب wss://api.starhermit.com/ws/v1/chat مع JWT عبر Authorization رأس, ?ticket=، أو ?access_token=.

هذا هو خادم نقي → قناة دفع العميل: يتم تجاهل إطارات العميل (فقط Close يتم تكريمه). كل إطار عبارة عن مظروف:

{ "type": "<event>", "payload": { } }
حدث type الحمولة
conversation_created ConversationDto
conversation_renamed ConversationDto
participants_added ConversationDto
participant_removed ConversationDto
chat_invite ChatInviteDto
chat_invite_responded ChatInviteDto
new_message MessageDto
message_updated MessageDto
message_deleted MessageDto
conversation_read تغيير حالة القراءة للمستخدم الذي قام بتسجيل الدخول؛ إعادة جلب التهم غير المقروءة
game_invite { "inviteId", "kind", "gameSlug", "gameName", "roomId", "from": { "userId", "username" }, "createdAt", "acceptPath", "declinePath", "inProgress", "sessionId" } - انظر أدناه

game_invite: حدث واحد لكلا نظامي الدعوة

يمكن دعوة أي شخص للعب بطريقتين، وهذا الحدث الفردي يحمل كليهما - ينفذ العميل نخبًا واحدًا، وليس اثنين:

kind صادرة عن قبول ذلك
"session" POST /games/{slug}/invites إنشاء جلسة لعب جديدة لكما
"room" POST /realtime/rooms/{id}/invites يشغل مقعدًا في غرفة يجلس فيها الداعي بالفعل؛ roomId هي تلك الغرفة

acceptPath و declinePath هي نقاط النهاية التي تجيب هذا دعوة - ​​استخدمها والتمييز لا يهم أبدًا. الإجابة عند نقطة نهاية النظام الآخر هي أ 404: يحتفظ الاثنان بمعرفات دعوة منفصلة.

inProgress يكون true عند قبول الانضمام إلى لعبة يتم لعبها بالفعل — دعوة جلسة تحدد جلسة قيد التشغيل، أو دعوة غرفة إلى غرفة بدأت تسمح بالانضمام قيد التقدم — و sessionId هي جلسة تلك اللعبة. استخدامه ليقول "انضم إلى لعبتهم" بدلاً من "يلعب".

{
  "type": "game_invite",
  "payload": {
    "inviteId": "e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b",
    "kind": "room",
    "gameSlug": "poker",
    "gameName": "StarHermit Poker",
    "roomId": "b1d2c3e4-5f60-4a71-8b92-c3d4e5f60718",
    "from": { "userId": "9b2f8c1a-1111-4222-8333-444455556666", "username": "alice" },
    "createdAt": "2026-07-26T14:10:00Z",
    "acceptPath": "/api/v1/realtime/rooms/invites/e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b/accept",
    "declinePath": "/api/v1/realtime/rooms/invites/e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b/decline"
  }
}

roomId يكون null ل "session" يدعو. لا يمكن لرمز الإطلاق المميز على مستوى اللعبة فتح هذا المقبس أو قراءة الحساب على مستوى الحساب /me/game-invites البريد الوارد. استطلاع عملاء اللعبة GET /api/v1/games/{slug}/invites لدعوات الجلسة و GET /api/v1/realtime/rooms/invites لدعوات غرفة لعبتهم. يمكن لعملاء الحساب قراءة كلا النوعين من خلال GET /api/v1/me/game-invites.

الدردشة داخل جلسة اللعبة

رمز إطلاق على نطاق اللعبة لا أستطيع يفتح ws/v1/chat - تم حظره لأن المقبس يبث جميع محادثات المستخدم. إطلاق الرموز المميزة يمكن استخدم واجهة برمجة تطبيقات REST للدردشة في المحادثات المرفقة بجلسات اللعبة الخاصة بهم: تُرجع تفاصيل الجلسة ملفًا chatConversationId، المحادثة لها نوع "game"المشاركون فيها هم لاعبو الجلسة، ويتم تجاوز قواعد الصداقة.

لذلك عادةً ما يقوم عملاء اللعبة بتحميل السجل عبر REST واستقصاء الرسائل الجديدة بدلاً من استخدام المقبس. على سبيل المثال، تنفيذ مرجع الشطرنج استطلاعات الرأي كل 5 ثواني:

GET /api/v1/chat/conversations/{chatConversationId}/messages?page=1&pageSize=50
Authorization: Bearer <launch-token>

POST /api/v1/chat/conversations/{chatConversationId}/messages
Authorization: Bearer <launch-token>
Content-Type: application/json

{ "content": "good game" }

انظر أيضا

  • صوت - الغرف الصوتية مرساة لمحادثات الدردشة
  • أصدقاء - بوابات الصداقة للمحادثات المباشرة والانضمام للغرف
  • ألعاب — جلسات اللعبة و chatConversationId

يرى التوافق الاعتماد و العقود المقروءة آليا.
