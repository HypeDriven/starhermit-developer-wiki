حساب تعريفي

تغطي واجهة برمجة تطبيقات الملف الشخصي الحساب الخاص بالمستخدم الذي تمت مصادقته (/api/v1/me/...)، عمليات البحث العامة عن المستخدمين الآخرين، والمفاتيح العامة، والهويات المرتبطة، وإعدادات الخصوصية، والاستحقاقات، ونبض الحضور. تتطلب مسارات الحساب تصريحًا؛ وثيقة الشروط الحالية عامة.

تختلف أجسام الخطأ؛ يرى اتفاقيات API.

نقاط النهاية

طريقة طريق مصادقة وصف
يحصل /api/v1/me جوت (Permission-user.profile.read) احصل على ملف التعريف الخاص بك
رقعة /api/v1/me جوت (Permission-user.profile.update) قم بتحديث اسم المستخدم أو البريد الإلكتروني أو البيانات الوصفية أو اللقب
يحصل /api/v1/terms مجهول اقرأ شروط StarHermit الحالية وتجزئةها
بريد /api/v1/me/terms/accept حساب JWT أو الرمز المميز لإطلاق اللاعب اقبل شروط StarHermit الحالية
يضع /api/v1/me/avatar جوت (Permission-user.profile.update) قم بتحميل الصورة الرمزية الخاصة بك
يحصل /api/v1/me/avatar جوت (Permission-user.profile.read) احصل على الصورة الرمزية الخاصة بك
يحصل /api/v1/users/{id}/avatar JWT احصل على الصورة الرمزية لأي مستخدم
يحصل /api/v1/users/{id}/profile JWT احصل على الملف الشخصي العام لأي مستخدم
يحصل /api/v1/me/public-keys جوت (Permission-user.profile.read) قائمة المفاتيح العامة الخاصة بك
بريد /api/v1/me/public-keys تمت مصادقة OAuth جوت (Permission-user.profile.update) أضف مفتاحًا عامًا على الفور
يمسح /api/v1/me/public-keys/{keyId} تمت مصادقة OAuth جوت (Permission-user.profile.update) قم بإلغاء مفتاح واحد وجلساته
يمسح /api/v1/me/public-keys/all تمت مصادقة OAuth جوت (Permission-user.profile.update) قم بإلغاء كل مفتاح نشط وجلساته
يمسح /api/v1/me/public-keys/current جلسة المفتاح العام (Permission-user.profile.update) قم بإلغاء المفتاح الذي تم تسجيل الدخول به إلى هذه الجلسة وجلساتها. ولا يذكر أي مفتاح، لذا لا يمكنه الوصول إلى أحد الأشقاء؛ يحصل على جلسة بدون مفتاح 409 no_public_key_session
يحصل /api/v1/me/identities جوت (Permission-user.profile.read) قائمة الهويات المرتبطة الخاصة بك
بريد /api/v1/me/identities جوت (Permission-user.profile.update) ربط هوية (موفري غير OAuth فقط)
يمسح /api/v1/me/identities/{identityId} جوت (Permission-user.profile.update) إلغاء ربط الهوية
يحصل /api/v1/me/privacy جوت (Permission-user.profile.read) احصل على إعدادات الخصوصية الخاصة بك
يضع /api/v1/me/privacy جوت (Permission-user.profile.update) استبدل إعدادات الخصوصية الخاصة بك
يحصل /api/v1/me/entitlements جوت (Permission-user.profile.read) قائمة استحقاقات البرامج الخاصة بك
بريد /api/v1/me/heartbeat JWT وجود نبض القلب ( مختنق LastSeenAt يكتب)

PATCH /api/v1/me

جميع الحقول اختيارية. قيود: username 1–32 حرفًا؛ nickname ≥64 حرفًا (متعددة الحسابات ليس لها أي شيء)؛ metadata ≥4096 حرفًا. أسماء المستخدمين والألقاب تشترك في واحد مساحة الاسم غير حساسة لحالة الأحرف: 409 عندما يستخدم حساب آخر الاسم كاسم مستخدم أو لقب له، تجاهل القضية. يتم تطبيع الألقاب مع NFKC، كما يتم ضبط أحرف التحكم أو غير المرئية 400. تغيير email يتطلب بالإضافة إلى ذلك جلسة مصادقة OAuth لأن البريد الإلكتروني للحساب يمكنه الموافقة على روابط بيانات الاعتماد؛ مفتاح عام أو تحصل جلسة التحقق من البريد الإلكتروني 403 لهذا الحقل ولكن لا يزال بإمكانه تحديث الحقول الأخرى. يعود 204 على النجاح، 409 في الصراع (اسم المستخدم أو اللقب مأخوذ بالفعل).

{

  "email": "new@example.com",

قبول الشروط

قبل استخدام نقاط نهاية REST المحمية أو فتح WebSockets، يجب أن يقبل الحساب الحالي شروط ستارهيرميت. ينطبق هذا على الرموز المميزة للحساب والرموز المميزة لإطلاق اللاعب، بما في ذلك الحسابات التي قبلت مراجعة أقدم. ولا ينطبق على الموارد المجهولة/تسجيل الدخول أو خادم الحاوية رمز النشر الخاص. GET /api/v1/me وتبقى نقطة نهاية القبول متاحة مع وضعها المعتاد أذونات الحساب بينما القبول معلق.

GET /api/v1/me يشمل currentTermsHash و termsAcceptanceRequired. المخزنة termsAcceptedHash و termsAcceptedAt تكون فارغة قبل القبول الأول. التجزئة المعروضة في تم اختصار مثال الملف الشخصي أعلاه؛ استخدم دائمًا التجزئة الكاملة التي ترجعها واجهة برمجة التطبيقات.

GET /api/v1/terms

مجهول؛ يمكن قراءتها أيضًا باستخدام رمز إطلاق اللاعب. المرتجعات 200 مع Cache-Control: no-store:

{ "hash": "<current-64-character-lowercase-sha256>", "text": "<complete terms text>" }

يجعل text كنص عادي. hash هو SHA-256 من بايتات مستند UTF-8 الدقيقة؛ استخدام عاد القيمة بدلاً من تجزئة نص العرض المعاد تنسيقه.

POST /api/v1/me/terms/accept

بعد أن يقرأ المستخدم المراجعة المعروضة ويقبلها بشكل صريح، أرسل تجزئتها:

POST /api/v1/me/terms/accept
Authorization: Bearer <account-access-token>
Content-Type: application/json

{ "hash": "<hash-returned-with-the-displayed-text>" }

المرتجعات 200 مع { "termsAcceptedHash", "termsAcceptedAt" }. جلسات حساب OAuth والمفتاح العام و رموز الإطلاق على مستوى اللعبة يمكن أن تقبل. لا يمكن لرمز خادم الحاوية أن يعمل لصالح اللاعب. يتم تخزين القبول على الحساب ويصبح ساري المفعول في الطلب التالي بنفس الرمز المميز الذي لا يزال صالحًا؛ تحديث الرمز غير ضروري.

يتم إرجاع التجزئة المفقودة/الفارغة أو التجزئة التي يزيد طولها عن 64 حرفًا 400. التجزئة التي لا بالضبط تطابق عوائد المراجعة الحالية 409:

{
  "error": "terms_version_mismatch",
  "termsHash": "<current-hash>",
  "termsUrl": "/api/v1/terms"
}

إحضار وعرض المستند الجديد وطلب القبول مرة أخرى؛ لا تقبل بصمت بديل مراجعة. الطلبات المحمية الأخرى مع عودة القبول المعلقة 403:

{
  "error": "terms_acceptance_required",
  "message": "Accept the latest terms of service before using the API.",
  "termsHash": "<current-hash>",
  "termsUrl": "/api/v1/terms",
  "acceptUrl": "/api/v1/me/terms/accept"
}

يمكن للعبة المستضافة عرض الشروط وإرسال التجزئة المعروضة باستخدام رمز إطلاق اللاعب الخاص بها عندما يضغط اللاعب على "قبول"، ثم أعد المحاولة. وقد يرسل أيضًا اللاعب إلى واجهة مستخدم حسابه. لا يؤدي تسجيل الدخول المتكرر أو تحديث الرمز المميز إلى إصلاح القبول المعلق. تم رفض ترقيات WebSocket باستخدام HTTP 403 قبل الافتتاح قد تقوم المتصفحات بإخفاء نص الاستجابة، لذا تعامل مع القبول من خلال REST قبل الاتصال.

مثال لحساب أو عميل لعبة (call acceptDisplayedTerms فقط من إجراء قبول المستخدم):

const api = 'https://api.starhermit.com';
async function loadTerms() {
  const response = await fetch(`${api}/api/v1/terms`);
  if (!response.ok) throw new Error(`Terms fetch failed: ${response.status}`);
  return response.json(); // Display text, retain this document's hash.
}
async function acceptDisplayedTerms(accountToken, displayedTerms) {
  const response = await fetch(`${api}/api/v1/me/terms/accept`, {
    method: 'POST',
    headers: { Authorization: `Bearer ${accountToken}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ hash: displayedTerms.hash })
  });
  if (response.status === 409) {
    throw new Error('Terms changed. Reload and display them for a new acceptance.');
  }
  if (!response.ok) throw new Error(`Acceptance failed: ${response.status}`);
  return response.json();
}

الصور الرمزية

PUT /api/v1/me/avatar يقبل صورة PNG، مربعة، ≥512×512 بكسل، ≥1 ميغابايت:

{ "imageBase64": "iVBORw0KGgoAAAANSUhEUg..." }

العودة 204. GET /api/v1/me/avatar إرجاع الصورة الرمزية الخاصة بك كما image/png بايت.

مستخدمين آخرين

  • GET /api/v1/users/{id}/avatar - الصورة الرمزية PNG لأي مستخدم.
  • GET /api/v1/users/{id}/profile:
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "username": "pk-a1b2c3d4e5f6",
  "nickname": "Al"
}

المفاتيح العامة

المفتاح المسجل هو بيانات اعتماد واجهة برمجة التطبيقات (API): يمكن لحاملها إكمال الملف تدفق تحدي المفتاح العام واحصل على رمز وصول/تحديث عادي زوج. وهذا يجعل المفتاح المسمى بشكل منفصل مناسبًا لعميل سطح المكتب أو مسار النشر.

تتطلب إضافة المفاتيح أو إلغاء المفاتيح الأخرى جلسة مصادقة OAuth. مفتاح عام قد تقوم الجلسة بإلغاء مفتاحها الخاص فقط من خلال DELETE /api/v1/me/public-keys/current. لا يمكن ذلك تسجيل البدائل أو إلغاء الأجهزة الأخرى. تظل القائمة متاحة لأي جلسة حساب كاملة؛ لا يمكن لرموز تشغيل اللعبة والخادم إدارة مفاتيح الحساب.

GET /api/v1/me/public-keys

تتضمن القائمة صفوفًا تم إبطالها كمسار تدقيق:

[
  {
    "id": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "keyType": "Ed25519",
    "keyData": "<base64-raw-32-byte-public-key>",
    "label": "orbit-league-production",
    "fingerprint": "4d9f3c...",
    "createdAt": "2026-07-01T12:00:00Z",
    "lastUsedAt": "2026-07-30T09:00:00Z",
    "isRevoked": false,
    "revokedAt": null,
    "metadata": null
  }
]

POST /api/v1/me/public-keys

يتطلب جلسة مصادقة OAuth وإرفاق المفتاح على الفور؛ على عكس مجهول التسجيل، ليست هناك حاجة إلى البريد الإلكتروني ذهابا وإيابا.

{
  "keyType": "Ed25519",
  "keyData": "<base64-raw-32-byte-public-key>",
  "label": "orbit-league-production"
}

label اختياري (128 حرفًا كحد أقصى). أنواع المفاتيح المقبولة هي Ed25519, ECDSA-P256، و RSA-PSS; يجب أن تكون المادة Base64 القياسية: مفتاح عام خام بحجم 32 بايت لـ Ed25519، وP-256 مشفر نقطة منحنى ECDSA، أو SPKI عام لـ RSA. يجب أن تكون مفاتيح RSA 2048-8192 بت. المنصة يحدد المواد الصالحة بشكل أساسي ويحد الحساب من 20 مفتاحًا نشطًا بشكل افتراضي. fingerprint هو الملخص السداسي SHA-256 الصغير للقانون الأساسي keyType:keyData خيط.

المرتجعات 201 بالمفتاح الذي تم إنشاؤه. عوائد المواد غير صالحة 400; مفتاح نشط بالفعل أو كامل إرجاع القائمة الرئيسية 409 (وهذا الأخير يشمل limit). تعتبر المادة الرئيسية النشطة فريدة من نوعها على مستوى النظام الأساسي.

DELETE /api/v1/me/public-keys/{keyId}

يتطلب جلسة مصادقة OAuth. الإلغاء غير فعال وينتهي بجلسات التحديث بالمفتاح يتم رفض تسمية الرموز المميزة للوصول عند طلبهم التالي. العوائد:

{ "revoked": [{ "id": "...", "isRevoked": true }], "sessionsEnded": 1 }

يعود مفتاح غير معروف في هذا الحساب 404.

DELETE /api/v1/me/public-keys/all

عملية الاستجابة للاختراق: قم بإلغاء كل مفتاح نشط وإنهاء جميع الجلسات التي تمت مصادقتها. وفيه صريحة /all المسار بحيث لا يمكن أن يصبح معرف المفتاح الفارغ عن طريق الخطأ بمثابة إبطال مجمع. يعود نفسه { revoked, sessionsEnded } شكل.

DELETE /api/v1/me/public-keys/current

يمكن لجلسة حساب كاملة مصادق عليها بمفتاح عام أن تلغي المفتاح المستخدم لتلك الجلسة، دون تسمية معرف المفتاح. استخدم هذا ل ننسى هذا الجهاز. يعود نفس الشيء { revoked, sessionsEnded } الشكل ويبطل الجلسات باستخدام هذا المفتاح. تجاهل الرموز المخزنة والمفتاح الخاص المحلي بعد النجاح. جلسة بدون إرجاع المفتاح العام 409 مع code: "no_public_key_session"; تم رفض الرموز المميزة لإطلاق اللعبة.

للحصول على مثال كامل لنشر الجهاز، راجع يتم إنشاء التحميل من CI/CD باستخدام مفتاح عام مسجل في OAuth.

أسماء الموفرين التي يعرفها النظام الأساسي باسم OAuth (google, github, discord, twitch, gitlab, linkedin, bitbucketبالإضافة إلى الأسماء المحجوزة microsoft, facebook, twitter, x, apple, steam) نكون مرفوض هنا سواء تم تكوين هذا الموفر أم لا - تلك الهويات قابلة للربط فقط عبر تسجيل دخول حقيقي. استخدم اسمًا غير محجوز (epic, gog، معرف واجهة متجر مخصص). يرى المصادقة.

DELETE /api/v1/me/identities/{identityId}

تتطلب إزالة الهوية المُدارة بواسطة OAuth جلسة مصادقة OAuth، لذا فإن المفتاح العام المسروق لا يمكن إزالة طريق المالك مرة أخرى إلى الحساب. العودة 204.

إعدادات الخصوصية

GET /api/v1/me/privacy إرجاع الخاص بك PrivacySettings; PUT /api/v1/me/privacy يستبدلها (إرجاع 204):

{
  "onlineStatus": 1,
  "currentlyPlaying": 1,
  "recentLaunchActivity": 0,
  "hoursPlayed": 0,
  "recentDownloads": 0,
  "achievements": 2,
  "friendDiscoverability": 1,
  "profileVisibility": 2
}

كل حقل هو PrivacyLevel التعداد: 0 = خاص، 1 = الأصدقاء فقط، 2 = عام.

وجود نبض القلب

POST /api/v1/me/heartbeat

يعود 204. يكتب LastSeenAt من جانب الخادم، مقيد - هذه هي إشارة التواجد التي يستخدمها الأصدقاء والدردشة.

رموز الإطلاق على مستوى اللعبة

من بين نقاط النهاية الموجودة في هذه الصفحة، قد يستدعي رمز الإطلاق المميز على نطاق اللعبة فقط:

  • GET /api/v1/users/{id}/avatar
  • GET /api/v1/users/{id}/profile
  • GET /api/v1/me/friends (يرى أصدقاء)
  • GET /api/v1/terms
  • POST /api/v1/me/terms/accept
  • POST /api/v1/me/heartbeat

كل شيء آخر يُرجع 403 ضمن سياج نطاق اللعبة الموصوف في المصادقة.

اصطلاح اسم العرض

عادةً ما يتم عرض واجهات مستخدم اللعبة ألقاب بدلا من أسماء المستخدمين عند تقديم المعارضين، والعودة إلى شيء من هذا القبيل "Player " + id.slice(0,8) عندما لا يتم تعيين لقب. يتبع تطبيق مرجع الشطرنج هذه الاتفاقية؛ يجب على عملاء اللعبة الآخرين أن يفعلوا الشيء نفسه.

يرى التوافق الاعتماد و العقود المقروءة آليا.
