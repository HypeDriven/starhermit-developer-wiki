تقارير الأعطال والأخطاء

يمكن للاعبين الإبلاغ عن أي عطل أو خلل من داخل أي لعبة تحتوي على سبيكة ثابتة — ألعاب للمتصفح فقط مضمن - باستخدام رمز إطلاق اللعبة أو رمز المستخدم الكامل. يقرأ صاحب اللعبة ويفرز و يحذفها من خلال /api/v1/me/github-games/{id}/reports.

للحصول على مخرجات الخادم وسجلات الأعطال الخاصة بلعبة الحاوية، راجع خوادم الألعاب المستضافة على حاوية — تقارير المخرجات والأعطال الخاصة بخادمك.

نقاط النهاية

طريقة طريق مصادقة وصف
بريد /api/v1/games/{slug}/reports إطلاق الرمز المميز لتلك اللعبة، أو JWT تقديم تقرير عن الأعطال أو الأخطاء
يحصل /api/v1/games/{slug}/reports/mine إطلاق الرمز المميز لتلك اللعبة، أو JWT أحدث 50 تقريرًا لهذه اللعبة، مع حالتها
يحصل /api/v1/me/github-games/{id}/reports جي دبليو تي (مالك) تقارير القائمة: ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
يحصل /api/v1/me/github-games/{id}/reports/{reportId} جي دبليو تي (مالك) تقرير واحد مع قائمة المرفقات الخاصة به
يحصل /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} جي دبليو تي (مالك) مرفق، دائمًا كتنزيل
رقعة /api/v1/me/github-games/{id}/reports/{reportId} جي دبليو تي (مالك) تعيين status
يمسح /api/v1/me/github-games/{id}/reports/{reportId} جي دبليو تي (مالك) حذف تقرير → 204

تقديم تقرير

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind يكون crash أو bug; title مطلوب (أقل من 200 حرف).
  • كل شيء آخر اختياري. userAgent الإعدادات الافتراضية للطلب User-Agent header.
  • إجابة: 201 { "id", "kind", "status": "open", "createdAt" }.
حالة معنى
400 مشوه: غير معروف kind، مفتقد title، base64 غير صالح، أو ليس JSON
404 لعبة غير معروفة أو تمت إزالتها
413 الوصف أو عدد المرفقات أو وحدات بايت المرفقات تتجاوز حدود اللعبة
429 تجاوز الحد الأقصى للتقرير اليومي لهذه اللعبة؛ يرى Retry-After

حدود

يمكن للمشغلين تغيير كل من هذه العناصر للمنصة بأكملها وللألعاب الفردية؛ الحد اليومي يمكن أيضًا ضبطها للاعب واحد.

حد تقصير
تقارير لكل لاعب لكل مباراة يوميا 20
طول الوصف 20.000 حرف
المرفقات لكل تقرير 4
بايت المرفق لكل تقرير 2 ميجابايت
يتم الاحتفاظ بالتقارير لكل لعبة 2,000
البايتات المحفوظة لكل لعبة 256 ميجابايت
حفظ 90 يوما

عندما تصل اللعبة إلى حد التخزين الخاص بها، تتم إزالة التقارير الأقدم - التي تم حلها أولاً - إلى إفساح المجال. يتم رفض تقرير واحد أكبر من الحد الإجمالي للبايت لكل لعبة 413.

تقارير الفرز (مالك اللعبة)

تعود القائمة { "items", "total", "page", "pageSize" }; كل عنصر يحمل اسم المراسل، kind, status, titleوتفاصيل العميل وعدد المرفقات الخاصة به. نقل تقرير من خلال open → acknowledged → resolved مع:

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

يتم تقديم المرفقات كتنزيلات (Content-Disposition: attachment, nosniff، وضع الحماية CSP). الأنواع الخاملة فقط هي التي تحتفظ بنوع المحتوى المعلن عنها - text وJSON وPNG وJPEG وWebP وGIF وzip و غزيب. يتم تقديم أي شيء آخر، بما في ذلك العلامات application/octet-stream.

من جافا سكريبت SDK

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports

انظر جافا سكريبت SDK.

مشترك اتفاقيات API وصف تحليل الاستجابة، والطوابع الزمنية، وترقيم الصفحات، وإعادة المحاولة.

يرى التوافق الاعتماد و العقود المقروءة آليا.
