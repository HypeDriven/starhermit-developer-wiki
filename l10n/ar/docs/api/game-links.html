روابط خارجية

يمكن للعبة StarHermit-engine (مضيف API 1.24) فتح صفحة ويب، ولكن صفحة واحدة فقط يوظفها StarHermit تمت الموافقة على لعبتك. تفتح لعبتك رابطًا حسب المعرف ولا تمرر عنوان URL مطلقًا، لذا لا يمكنها الإضافة أي شيء لأحد.

أعلن عن الروابط الخاصة بك

في starhermit.txt:

engine.minor=24
engine.link.discord=https://discord.gg/abc
engine.link.store=https://example.com/game
  • يمكنك الإعلان عن ما يصل إلى 16 رابطًا. يتكون كل معرف من 1 إلى 32 حرفًا a-z 0-9 - وقد تظهر مرة واحدة فقط.
  • أي engine.link.* الاحتياجات الرئيسية engine.minor=24، لذا فإن أوقات التشغيل الأقدم ترفض اللعبة.
  • استدعاء البرامج النصية الخاصة بك openLink("discord"). يُظهر وقت التشغيل التأكيد الخاص به، مع الرابط المضيف الكامل وعنوان URL، ولا يفتح الصفحة إلا إذا اختار اللاعب فتح.

ما قد يكون الرابط

يجب أن يكون الرابط https، مع عدم وجود ميناء، لا user@، لا يوجد عنوان IP ولا اسم محلي (localhost, .local, .internal). يجب أن يكون مضيفه ASCII، مع كتابة الأسماء الدولية كـ punycode، ولها علامتين على الأقل. لا يجوز أن تحتوي على خطوط مائلة عكسية أو مسافات أو خطوط مائلة مشفرة (%2f, %5c) أو ./.. قطاعات المسار. تحافظ المنصة على الشكل الأساسي: المخطط والمضيف حالة صغيرة، و / لمسار فارغ. يتم الاحتفاظ بكل شيء آخر تمامًا كما كتبته.

يتم رفض الحزمة التي تحتوي على رابط يخالف القاعدة عند النشر، مع 422 invalid_link: engine.link.<id> is not an allowed link (<rule>)، قبل أن يتم نشر أي شيء.

مراجعة

يبدأ كل رابط جديد pending، ولا يفتح وقت التشغيل أي شيء حتى يوافق عليه الموظفون. بعض الروابط هي مرفوض تلقائيًا: خدمات تقصير عناوين URL وإعادة التوجيه، التي تكون وجهتها شخصًا آخر الضوابط والتنزيلات المباشرة للبرامج والمحفوظات (.exe, .dmg, .apk, .zip و مماثل). تتبع المعلمات مثل utm_* تم وضع علامة عليها للمراجع.

تنتمي الموافقة إلى لعبتك وعنوان URL المحدد هذا. إصدار أحدث يدرج نفس عنوان URL، ضمن أي معرف، يبقيه. يحتاج تغيير عنوان URL إلى مراجعة جديدة. يمكن للموظفين إلغاء الموافقة، أو حظر أ المضيف بأكمله، في أي وقت.

راجع الروابط الخاصة بك وحالتها على GET /api/v1/me/github-games/{id}/links:

[ { "id": "discord", "url": "https://discord.gg/abc", "status": "approved", "autoReason": null, "note": null } ]

يتحقق وقت التشغيل GET /api/v1/games/{slug}/links/{id} عند كل فتح، مع إطلاق اللاعب رمز مميز. الجواب هو { id, url, status }، أين status يكون approved, pending, rejected أو revoked، أو 404 link_unknown للحصول على معرف لم يعلن عنه البيان المنشور الخاص بك.

بينما تتطور محليًا (--dev محليًا، أو صفحة استرجاع في المتصفح، بدون تشغيل رمز مميز)، يفتح وقت التشغيل الروابط المعلنة خلف تحذير بأنها لم تتم مراجعتها.
