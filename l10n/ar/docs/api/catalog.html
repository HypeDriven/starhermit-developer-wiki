كتالوج البرمجيات

يغطي كتالوج البرامج التصفح والمطالبة بالعناوين وإنشاء القوائم والتنزيل والحفظ السحابي وقائمة الرغبات والتقييمات. القراءات مجهولة المصدر. تتطلب الكتابة JWT.

عنوان URL الأساسي: https://api.starhermit.com. جميع الطرق تحت /api/v1/....

التصفح والمطالبة بالعناوين

طريقة طريق مصادقة وصف
يحصل /api/v1/software مجهول بحث وصفحة الكتالوج
يحصل /api/v1/software/{id} مجهول احصل على عنوان واحد، أو 404
يحصل /api/v1/software/{id}/builds?page=&pageSize= مجهول قائمة مقسمة إلى صفحات للبنيات للحصول على عنوان
بريد /api/v1/software/{id}/claim JWT المطالبة الذاتية بلقب مجاني، ومنح الاستحقاق
بريد /api/v1/software/{id}/launch JWT بدء جلسة الإطلاق (يتطلب الاستحقاق)

GET /api/v1/software يقبل معلمات الاستعلام q (النص الكامل)، category, tag, publisherId, platform, releaseStatus, sort, page، و pageSize. صالح sort قيم: name, name_desc, created, created_desc, updated, updated_desc. يعود أ PagedResult:

{
  "items": [
    {
      "id": "…",
      "name": "…",
      "description": "…",
      "publisherId": "…",
      "category": "…",
      "platform": "…",
      "releaseStatus": "…",
      "tags": ["…"],
      "priceCents": 0,
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

GET /api/v1/software/{id}/builds يعود أ PagedResult ل SoftwareBuild:

{
  "items": [
    {
      "id": "…",
      "titleId": "…",
      "version": "…",
      "releaseDate": "…",
      "releaseNotes": "…",
      "metadata": "…",
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

POST /api/v1/software/{id}/claim يعمل فقط مع العناوين المجانية (priceCents == 0); يمنح المتصل استحقاقًا ويعيد 204. أما بالنسبة للعناوين المدفوعة فيرجع 402 مع:

{"error": "purchasing is not available yet"}

POST /api/v1/software/{id}/launch يتطلب استحقاقًا (403 بخلاف ذلك) ويعيد أ LaunchSession:

{
  "launchId": "…",
  "startTime": "…"
}

يقوم بتسجيل نشاط الإطلاق، والذي يكون مخفيًا إذا كانت إعدادات خصوصية المستخدم تنص على ذلك (انظر profile.md). انهاء الجلسة ب POST /api/v1/activity/launches/{id}/end - يرى activity.md. يتم سرد استحقاقات المستخدم عبر GET /api/v1/me/entitlements (يرى profile.md).

التنزيلات

طريقة طريق مصادقة وصف
بريد /api/v1/software/{id}/download JWT الحصول على عنوان URL للتنزيل الموقع (يتطلب الاستحقاق)

ويتطلب استحقاقا (403 خلاف ذلك). العوائد:

{
  "downloadUrl": "…"
}

يستهدف عنوان URL أول أصل قابل للتنزيل لأحدث إصدار. تسجل المكالمة نشاط التنزيل. التوزيع الثنائي للكتالوج هو حاليًا معاينة؛ عناوين URL التي تم إرجاعها ليست مضمونة الإنتاج التنزيلات. يرى توفر الميزة قبل الاعتماد على تدفق النشر هذا.

الحفظ السحابي

فتحة واحدة لكل لعبة، الكتابة الأخيرة تفوز. تتطلب كافة المسارات JWT — رمز مستخدم كامل، أو رمز لعبة رمز الإطلاق لفتحة تلك اللعبة الخاصة (أدناه).

ينطبق الحد الأقصى البالغ 10 ميغابايت (10,485,760 بايت) على حفظ فك التشفير، وليس الطلب. PUT يأخذ حفظ بترميز base64 بتنسيق JSON، وبالتالي فإن النص أكبر بمقدار الثلث تقريبًا من الحفظ - حوالي 14 ميجابايت في الحد الأقصى - وتقبل واجهة برمجة التطبيقات (API) ذلك.

الحد (لكل حساب) تقصير رفض
حفظ واحد، فك التشفير 10 ميجابايت 413 cloud_save_too_large
الألعاب مع الحفظ 200 409 cloud_save_slots_exhausted (حفظ للعبة جديدة)
كل شيء يحفظ معا 1 جيجابايت 507 cloud_save_quota_exceeded، مع used
التحميلات 30 دقيقة 429، مع Retry-After

كل رفض يذكر الرقم الساري باسم limit. يتم قياس المجموع على الحساب آخر يحفظ، لذلك يمكن دائمًا استبدال الفتحة بشيء ليس أكبر. يمكن للمشغلين تغيير أي من هذه لحساب واحد.

طريقة طريق مصادقة وصف
يحصل /api/v1/me/cloud-saves/{gameKey}/info JWT حفظ البيانات الوصفية: { exists, sizeBytes, updatedAt? }
يحصل /api/v1/me/cloud-saves/{gameKey} JWT application/zip بايت، 404 إذا لم يكن هناك
يضع /api/v1/me/cloud-saves/{gameKey} JWT تحميل حفظ (حفظ تم فك ترميزه ≥ 10 ميجابايت، gameKey ≥ 300 حرف)

وضع الجسم:

{
  "dataBase64": "…"
}

وضع الاستجابة:

{
  "gameKey": "…",
  "sizeBytes": 0,
  "updatedAt": "…"
}

الحفظ من داخل اللعبة (رمز الإطلاق)

يمكن للعبة التي يتم تشغيلها باستخدام رمز الإطلاق المميز قراءة وكتابة حفظ اللاعب لها تلك اللعبة. تحفظ لعبتك نفسها في أي مكان يتم تشغيله فيه — سواء كان متصفحًا أو تطبيق StarHermit لسطح المكتب الذي يتم تشغيله الألعاب المستضافة في المتصفح أيضًا - وبالتالي فإن عملية الحفظ تتبع اللاعب الموجود بينها.

المفتاح هو game:<gameId>، أين <gameId> هو معرف لعبتك - نفس قيمة سبيكةها <gameId>.starhermit.com العنوان، و game_scope المطالبة برمز الإطلاق:

const key = `game:${gameScope}`;            // e.g. "game:3fa85f64-5717-4562-b3fc-2c963f66afa6"

// Load on startup — 404 means no save yet.
const res = await fetch(`/api/v1/me/cloud-saves/${key}`, { headers: { Authorization: `Bearer ${launchToken}` } });
if (res.status !== 404 && !res.ok) throw new Error(`Save load failed: ${res.status}`);
const save = res.status === 404 ? null : new Uint8Array(await res.arrayBuffer());
const etag = res.headers.get("ETag");
if (save && !etag) throw new Error("Save version unavailable; do not overwrite it.");
// Validate/decode your own save format before adopting it or enabling uploads.

// Save at checkpoints, not every frame.
const written = await fetch(`/api/v1/me/cloud-saves/${key}`, {
  method: "PUT",
  headers: {
    Authorization: `Bearer ${launchToken}`, "Content-Type": "application/json",
    ...(etag ? { "If-Match": etag } : { "If-None-Match": "*" }),
  },
  body: JSON.stringify({ dataBase64: base64(zipBytes) }), // Your ZIP encoder and bytes.
});
if (written.status === 412) throw new Error("Another device saved. Reload before writing again.");
if (!written.ok) throw new Error(`Save write failed: ${written.status}`);
const acknowledgement = await written.json(); // Retain acknowledgement.etag for your next write.
  • فقط هذا المفتاح بالضبط. أي مفتاح آخر - لعبة أخرى، أو لعبة متجر، أو تهجئة مختلفة لك (الحرف الكبير، المعرف العاري) - هو 403 للحصول على رمز الإطلاق. يتضمن ذلك github:<gameId>, الفتحة المنفصلة التي يستخدمها تطبيق سطح المكتب عندما يقوم اللاعب بمزامنة مجلد حفظ محلي للعبتك لا يمكن لهذه المزامنة أبدًا استبدال الحفظ الذي تكتبه لعبتك.
  • أي تنسيق. لا تفتح المنصة الحفظ مطلقًا؛ قم بتخزين كل ما يمكن للعبتك قراءته (إنه كذلك بمثابة application/zip يغض النظر). ما يصل إلى 10 ميغابايت.
  • عمليات الكتابة غير المشروطة هي آخر انتصارات الكتابة، بلا تاريخ. استخدم الكتابة الشرطية للكشف حفظ علامتي تبويب/جهازين في وقت واحد. قم بالتحميل عند البداية وحفظه عند نقاط التفتيش الأمامية. خروج الصفحة تعتبر التحميلات أفضل جهد ولها حدود لحجم جسم المتصفح؛ يرى وصفة الحفظ الآمن.
  • كل حفظ له نسخة. إنه ETag قيد التنزيل، على /info (أيضا كما etag) وعلى ال PUT إجابة. إرسالها مرة أخرى كما If-Match والكتابة تحدث فقط إذا لم يقم أحد بحفظها منذ؛ خلاف ذلك 412 {"error":"precondition_failed","etag":"<current>"} يخبرك الإصدار ل تحميل. If-Match: * يتطلب حفظًا موجودًا؛ If-None-Match: * يكتب فقط عندما لا يكون هناك شيء. مع عدم وجود رأس أ PUT غير مشروط - الكتابة الأخيرة تفوز. أ GET مع If-None-Match: <etag> إجابات 304 عندما يكون لديك بالفعل أحدث عملية حفظ.
  • اللعبة التي لا تحتوي على قائمة مستضافة (لعبة يوفرها المشغل) لا تحتوي على فتحة.

التفضيلات الصغيرة والمتغيرة بشكل متكرر تنتمي إليها إعدادات لكل لاعب بدلاً من؛ ويمكن الوصول إليها أيضًا باستخدام رمز الإطلاق ودعم التحديثات الجزئية.

قائمة الرغبات

تتطلب جميع الطرق JWT.

طريقة طريق مصادقة وصف
يحصل /api/v1/me/wishlist JWT { titleIds: guid[] }
يضع /api/v1/me/wishlist/{titleId} JWT أضف إلى قائمة الرغبات، 204 (عاجز)
يمسح /api/v1/me/wishlist/{titleId} JWT إزالة من قائمة الرغبات، 204

التقييمات

تتطلب جميع الطرق JWT. مفتاح اللعبة الموحد هو دليل الكتالوج، أو "provider:externalId" للألعاب الخارجية (انظر external-libraries.md).

طريقة طريق مصادقة وصف
يضع /api/v1/me/ratings JWT رفع تقييمي للعبة
بريد /api/v1/ratings/query JWT ملخصات تصنيف دفعة الجلب
يحصل /api/v1/ratings/reviews?key=&top= JWT تقييمات للعبة (top الافتراضي 10)

وضع الجسم:

{
  "gameKey": "…",
  "stars": 4,
  "review": "…"
}

stars هو 0-5؛ review هو اختياري. الرد هو أ RatingSummaryDto:

{
  "gameKey": "…",
  "average": 4.5,
  "count": 12,
  "myStars": 4
}

POST /api/v1/ratings/query الجسم والاستجابة:

{
  "keys": ["…", "…"]
}

يعود RatingSummaryDto[]. GET /api/v1/ratings/reviews يعود GameReviewDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "stars": 4,
    "review": "…",
    "timestamp": "…"
  }
]

يرى اتفاقيات API لتحليل الخطأ. متعلق ب: achievements.md, leaderboards.md.

يرى التوافق الاعتماد و العقود المقروءة آليا.
