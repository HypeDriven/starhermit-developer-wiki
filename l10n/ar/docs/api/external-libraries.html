المكتبات الخارجية

ربط مكتبة Steam أو Epic أو GOG الخاصة بالمستخدم حتى يمكن إدراج ألعابه الخارجية وتشغيلها وتتبعها. تتطلب جميع الطرق JWT.

عنوان URL الأساسي: https://api.starhermit.com. جميع الطرق تحت /api/v1/....

الربط وفك الارتباط

طريقة طريق مصادقة وصف
يحصل /api/v1/me/external-libraries JWT قم بإدراج مقدمي الخدمات المرتبطين بي
بريد /api/v1/me/external-libraries/link JWT ربط موفر ومزامنة عناوينه
يمسح /api/v1/me/external-libraries/{provider} JWT إزالة الرابط وملكياته

المكتبات المرتبطة:

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

جسم الرابط:

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

إرجاع 204. يؤدي الارتباط أيضًا إلى مزامنة عناوين الموفر. تقوم مزامنة المكتبة حاليًا بإرجاع العناوين التجريبية لـ steam/epic/gog بينما يتم الانتهاء من عمليات تكامل المزود الحقيقي.

البرامج الخارجية المملوكة وإطلاقها

طريقة طريق مصادقة وصف
يحصل /api/v1/me/external-software?provider=&page=&pageSize= JWT قائمة مقسمة إلى صفحات بعناويني الخارجية
بريد /api/v1/external-software/{ownershipId}/launch JWT احصل على URI الخاص بالإطلاق وقم بتسجيل الإطلاق الخارجي

قائمة البرامج الخارجية:

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

إطلاق الاستجابة:

{
  "launchUri": "steam://run/…"
}

تشغيل تنسيقات URI حسب الموفر: steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. الإطلاق يسجل نشاط إطلاق خارجي — انظر activity.md. تستخدم الألعاب الخارجية مفتاح اللعبة الموحد "provider:externalId" للحصول على التقييمات والخلاصات - راجع catalog.md.

يرى اتفاقيات API لتحليل الخطأ.

يرى التوافق الاعتماد و العقود المقروءة آليا.
