نتف

نتف (رمز بلك) هي عملة StarHermit. ينفقها اللاعبون على الوصول إلى لعبتك أو على العناصر التي تبيعها بداخله. تتلقى 99% من كل عملية بيع، وتحتفظ المنصة بعمولة قدرها 1%، يتم التقريب إلى إجمالي Pluck: 1 PLK عند بيع 1–100 PLK، و2 PLK عند 101–200، وهكذا. كل الرصيد يبدأ من الصفر

لم يتم بعد تحديد كيفية شراء اللاعبين أو كسبهم لـ Plucks. وحتى يتم ذلك، فإن الأرصدة تتغير فقط من خلال منح المبيعات والمشغلين.

نقاط النهاية

طريقة طريق مصادقة وصف
يحصل /api/v1/me/plucks JWT رصيدك: { balance, currency: "Plucks", symbol: "PLK" }
يحصل /api/v1/me/plucks/transactions JWT تاريخك، الأحدث أولاً: ?before=&limit= (≤100)
يضع /api/v1/me/github-games/{id}/plucks/access-price جي دبليو تي (مالك) { price } (1-1,000,000,000، أو null مجانا)
يحصل /api/v1/me/github-games/{id}/plucks/items جي دبليو تي (مالك) كتالوج العناصر الخاصة بك
يضع /api/v1/me/github-games/{id}/plucks/items/{key} جي دبليو تي (مالك) إنشاء أو تحديث { name, price, active }
يمسح /api/v1/me/github-games/{id}/plucks/items/{key} جي دبليو تي (مالك) إزالة عنصر → 204
يحصل /api/v1/me/github-games/{id}/plucks/sales جي دبليو تي (مالك) طلبات العناصر المدفوعة، الأحدث أولاً
يحصل /api/v1/games/{slug}/plucks/access إطلاق الرمز المميز أو JWT { price, hasAccess, isOwner } للمتصل
يحصل /api/v1/games/{slug}/plucks/items مجهول العناصر النشطة الخاصة بك
بريد /api/v1/games/{slug}/plucks/orders إطلاق الرمز المميز أو JWT اطلب من اللاعب الشراء { itemKey }
يحصل /api/v1/games/{slug}/plucks/orders/{id} إطلاق الرمز المميز أو JWT ترتيب اللاعب وحالته
يحصل /api/v1/games/{slug}/server/plucks/orders?since= رمز الخادم الطلبات المدفوعة للتسليم، الأقدم أولاً
بريد /api/v1/me/plucks/game-access/{gameId} JWT، تسجيل الدخول OAuth يشتري اللاعب الوصول: { expectedPrice }
بريد /api/v1/me/plucks/orders/{id}/confirm JWT، تسجيل الدخول OAuth يدفع اللاعب مقابل الطلب
بريد /api/v1/me/plucks/orders/{id}/cancel JWT يرفض اللاعب الأمر

تشير كل معاملة إلى مصدر نتفها

يحتوي كل إدخال تاريخ على source:

  • sale.game_access: لاعب اشترى الوصول إلى اللعبة.
  • sale.game_item: اشترى اللاعب عنصرًا داخل اللعبة.
  • grant: مشغل أصدر النتوءات.

مداخل تحمل أيضا amount (توقيع)، balanceAfter, feeواللعبة ومفتاح العنصر والترتيب و الطرف الآخر. دفتر الأستاذ مُلحق فقط: يتم تصحيح الخطأ من خلال معاملة جديدة، وليس عن طريقها أبدًا تحرير واحدة قديمة.

بيع الوصول إلى لعبتك

حدد سعرًا، وستقوم مشكلات لعبتك بإطلاق الرموز المميزة لك ولللاعبين الذين اشتروا حق الوصول فقط. أي شخص آخر يحصل 402 مع code: "purchase_required" و price. تبين لهم طريقة للشراء.

ترسل عملية الشراء السعر الذي ظهر به اللاعب expectedPrice. إذا قمت بتغيير السعر منذ ذلك الحين، تم رفض الشراء مع 409 (code: "price_changed")، لذلك لا أحد يدفع الثمن الذي دفعوه لا أرى. الوصول دائم ويتحمل تغيرات الأسعار اللاحقة. تسعير لعبة كانت مجانية أيضًا بوابات لاعبيها الحاليين.

الملفات المستضافة في لعبتك لم يتم بوابتها بعد. السعر يحجب ميزات النظام الأساسي (تسجيل الدخول، الجلسات، الحفظ، الإنجازات)، وليس تنزيل ملفات لعبة المتصفح.

بيع العناصر

لعبتك لا يمكن أن تنفق نتف اللاعب. يحمل رمز اللعبة الخاص بك رمز الإطلاق المميز للاعب، لذا أ الرمز المميز الذي يمكن إنفاقه سيسمح لأي لعبة باستنزاف لاعبيها. التدفق هو:

  1. لعبتك تسأل. POST /api/v1/games/{slug}/plucks/orders مع { "itemKey": "sword.gold" }. يأخذ الطلب الاسم والسعر الحالي للعنصر، ويبدأ pending، وتنتهي بعد 15 دقائق. يمكن للاعب أن يكون لديه 20 أمرًا في انتظاره على الأكثر (429, too_many_pending_orders).
  2. يؤكد اللاعب على StarHermit، أبدًا داخل لعبتك. يعرض عميل StarHermit ملف العنصر والسعر واللعبة والمشاركات /me/plucks/orders/{id}/confirm. يحتاج هذا الطريق إلى حساب تم تسجيل الدخول إليه باستخدام موفر OAuth، وهو ما لم تمتلكه لعبتك من قبل.
  3. قمت بتسليمها. استطلاع GET /api/v1/games/{slug}/plucks/orders/{id} من عميلك حتى status يكون paid (أو cancelled، أو الماضي expiresAt). يمكن للواجهة الخلفية للحاوية القراءة بدلاً من ذلك GET /api/v1/games/{slug}/server/plucks/orders?since=<last completedAt>.

تقوم المنصة بتسجيل عملية البيع؛ تطبيق العنصر هو مهمة لعبتك. جعل التسليم عاجزا عن طريق معرف الطلب.

POST /api/v1/games/{slug}/plucks/orders
Authorization: Bearer <launch-token>
Content-Type: application/json

{ "itemKey": "sword.gold" }

{ "id": "2b0e…", "gameId": "c115…", "itemKey": "sword.gold", "itemName": "Golden Sword",
  "price": 100, "status": "pending", "expiresAt": "2026-10-28T14:15:00Z" }

تتكون مفاتيح العناصر من 1 إلى 64 حرفًا a-z 0-9 . _ -; الأسماء مكونة من 1 إلى 80 حرفًا؛ الأسعار هي 1-1,000,000,000 بي إل كيه. لا يمكن طلب عنصر غير نشط أو محذوف، ويتم الاحتفاظ بالطلبات التي تم إجراؤها بالفعل لقطة لهم.

أخطاء

حالة code معنى
402 insufficient_plucks رصيد اللاعب أقل من السعر
402 purchase_required رمز إطلاق للعبة مسعرة لم يشترها اللاعب
409 price_changed expectedPrice لم يعد الثمن
409 order_cancelled تأكيد أمر ألغاه اللاعب
410 order_expired التأكيد بعد expiresAt
429 too_many_pending_orders هناك عدد كبير جدًا من الطلبات في انتظار التأكيد

يحصل المالك الذي يشتري من لعبته الخاصة على 409.

إيراداتك

GET /api/v1/me/github-games/{id}/analytics/sales و …/analytics/monetization وحدات التقرير الإجمالي، عمولة المنصة والشبكة الخاصة بك يوميًا، والدفع للاعبين، والتحويلات، ولكل عنصر المجاميع. إنهم يبلغون عن الإجماليات فقط ولا يذكرون المشتري مطلقًا. التاريخ الخاص بك في /me/plucks/transactions يسرد كل عملية بيع.
