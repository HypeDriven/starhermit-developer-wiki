نشاط

تغطي واجهة برمجة تطبيقات النشاط جلسات الإطلاق ووقت اللعب وموجز النشاط - لكل من عناوين الكتالوج والألعاب الخارجية (غير التابعة للكتالوج). تتطلب كافة المسارات JWT ما لم يُذكر ذلك.

عنوان URL الأساسي: https://api.starhermit.com. جميع الطرق تحت /api/v1/....

جلسات إطلاق الكتالوج ووقت اللعب

طريقة طريق مصادقة وصف
بريد /api/v1/activity/launches/{id}/end JWT إنهاء جلسة إطلاق الكتالوج (204)
يحصل /api/v1/activity/software/{softwareTitleId}/playtime JWT إجمالي وقت اللعب الخاص بي للحصول على اللقب
يحصل /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 JWT وقت لعب الأصدقاء للحصول على اللقب

تبدأ جلسات الإطلاق بواسطة POST /api/v1/software/{id}/launch (يرى catalog.md) وانتهى هنا. استجابة وقت اللعب:

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime يعود FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

عمليات الإطلاق الخارجية ووقت اللعب

بالنسبة للألعاب غير المرتبطة بالكتالوج (المكتبات الخارجية المرتبطة - راجع external-libraries.md):

طريقة طريق مصادقة وصف
بريد /api/v1/activity/external-launches JWT ابدأ جلسة للعبة غير تابعة للكتالوج
بريد /api/v1/activity/external-launches/{id}/end JWT إنهاء تلك الجلسة (204)
يحصل /api/v1/activity/external/playtime?provider=&externalId= JWT إجمالي وقت لعبي للعبة خارجية
يحصل /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 JWT وقت لعب الأصدقاء للعبة خارجية

POST /api/v1/activity/external-launches جسم (provider ≥ 64 حرفًا، externalSoftwareId ≥ 256 حرفًا، name خياري):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

إجابة:

{
  "launchId": "…"
}

استجابة وقت اللعب الخارجي:

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

يغذي النشاط

طريقة طريق مصادقة وصف
يحصل /api/v1/activity/game-feed?key=&limit=20 JWT جلسات الأصدقاء وأحداث التصنيف لمفتاح لعبة واحد
يحصل /api/v1/activity/friends?since=&until=&limit= JWT نشاط الأصدقاء
يحصل /api/v1/activity/public?since=&until=&limit= مجهول النشاط العام
يحصل /api/v1/me/activity?since=&until=&limit= JWT نشاطي الخاص

تعود تغذية اللعبة GameFeedItemDto[] لمفتاح لعبة واحد (دليل الكتالوج أو "provider:externalId"، يرى catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public، و me/activity يعود ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

نشاط type قيم: "download", "launch", "external_launch".

/activity/friends يتم بوابات لكل نوع النشاط على المالك إعداد الخصوصية: يبدأ المتابعة recentLaunchActivity، اتبع التنزيلات recentDownloads. يتم تضمين كل عندما يكون المستوى FriendsOnly أو Public. الحساب الذي لم يتم اختياره مطلقًا يحصل على الإعدادات الافتراضية (عمليات الإطلاق المشتركة مع الأصدقاء، التنزيلات خاصة). يتم التعامل مع مستند الخصوصية غير القابل للقراءة على أنه خاص تمامًا. يرى profile.md.

يرى اتفاقيات API لتحليل الخطأ.

يرى التوافق الاعتماد و العقود المقروءة آليا.
