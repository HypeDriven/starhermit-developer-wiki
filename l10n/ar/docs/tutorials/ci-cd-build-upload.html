تحميل الإصدارات من CI/CD باستخدام مفتاح عام مسجل في OAuth

يمنح هذا البرنامج التعليمي مسار النشر بيانات اعتماد StarHermit الخاصة به دون تخزين Google الخاص بك أو رموز GitHub OAuth في CI. الإعداد لمرة واحدة تفاعلي:

  1. قم بتسجيل الدخول عبر OAuth واقبل شروط StarHermit الحالية.
  2. أضف مفتاحًا عامًا مخصصًا لحساب StarHermit الخاص بك.
  3. ضع فقط النصف الخاص بهذا المفتاح في متجر CI السري.

يوقع كل تشغيل لخط أنابيب على تحدي StarHermit قصير الأمد، ويتلقى 15 دقيقة عادية رمز الوصول، وتحميل البنية الجديدة. يعمل مفتاح خط الأنابيب كحسابك ويمكن تحديثه فقط الألعاب التي يمتلكها الحساب.

لماذا نستخدم مفتاح نشر منفصل؟

لا تقم بحفظ وصول OAuth أو رمز التحديث في CI. المفتاح العام StarHermit هو آلة أفضل الاعتماد لأنه يمكن تصنيفها وتدقيقها وإبطالها بشكل مستقل. تمت مصادقة الجلسة بواسطة ذلك المفتاح لا يمكن إضافة مفاتيح أو إلغاء مفاتيح أخرى; تتطلب هذه العمليات مصادقة OAuth جلسة. يمكنها إلغاء نفسها من خلال /api/v1/me/public-keys/current. إذا تسرب سر CI، فقم بتسجيل الدخول باستخدام Google أو GitHub وقم بإلغاء مفتاح النشر. يؤدي الإلغاء أيضًا إلى إنهاء جلسات التحديث التي تم إنشاؤها بواسطة هذا المفتاح ويجعل رموز الوصول الموجودة الخاصة به تفشل على طلب API التالي.

استخدم مفتاحًا واحدًا لكل مستودع/بيئة، على سبيل المثال orbit-league-production، بدلاً من المشاركة مفتاح خاص واحد بين كل سير عمل.

المتطلبات الأساسية

  • حساب StarHermit تم تسجيل الدخول إليه من خلال Google أو GitHub OAuth.
  • لعبة موجودة يملكها هذا الحساب. احفظها id مثل GAME_ID; تحديثات نقطة نهاية الحزمة أ لعبة ولكن لا يخلق واحدة.
  • بناء عميل قابل للتوزيع و/أو متوافق مع Docker docker save صورة. يرى ألعاب جيثب لتخطيط الأرشيف.
  • Python 3 لأوامر الإعداد وسير العمل النموذجي؛ curl و jq بالنسبة لمثال التسجيل

يمكن لخط الأنابيب تسجيل الدخول بنجاح ولا يزال يتلقى 403 terms_acceptance_required عندما يقوم بتحميل أو فتح مقبس التحميل. اطلب من صاحب الحساب مراجعة و قبول الشروط الحالية بشكل تفاعلي، ثم أعد تشغيل المهمة. يمكن أن يتكرر هذا عندما تتغير المصطلحات؛ لا تقبل تلقائيا شروط من CI.

الإعداد لمرة واحدة

1. قم بإنشاء مفتاح نشر محليًا

يستخدم المثال Ed25519. قم بتشغيل هذا على محطة عمل موثوقة، وليس في مهمة CI:

python -m pip install cryptography
python - <<'PY'
import base64
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.serialization import Encoding, NoEncryption, PrivateFormat, PublicFormat

key = Ed25519PrivateKey.generate()
private = key.private_bytes(Encoding.Raw, PrivateFormat.Raw, NoEncryption())
public = key.public_key().public_bytes(Encoding.Raw, PublicFormat.Raw)
print("STARHERMIT_PRIVATE_KEY=" + base64.b64encode(private).decode())
print("STARHERMIT_PUBLIC_KEY=" + base64.b64encode(public).decode())
PY

القيمة الخاصة هي البذرة ذات 32 بايت وتظهر مرة واحدة في هذه المحطة المحلية الموثوقة. لا تلتزم أبدًا أو قم بطباعته في سجلات CI أو وضعه في قطعة أثرية أو إرساله إلى StarHermit. الحفاظ على القيمة العامة ل الخطوة التالية ولمتغير سير العمل.

2. قم بتسجيل الدخول باستخدام OAuth وأضف المفتاح العام

افتح أحد عناوين URL هذه في المتصفح:

https://api.starhermit.com/api/v1/auth/oauth/github/authorize
https://api.starhermit.com/api/v1/auth/oauth/google/authorize

بعد رد الاتصال، استخدم رمز الوصول المصادق عليه OAuth على الفور. ضعه في مكان محلي متغير البيئة وليس في تاريخ شل:

read -rsp 'OAuth access token: ' OAUTH_ACCESS_TOKEN; echo
read -rp  'Public key: ' STARHERMIT_PUBLIC_KEY

curl -sS -X POST https://api.starhermit.com/api/v1/me/public-keys \
  -H "Authorization: Bearer $OAUTH_ACCESS_TOKEN" \
  -H 'Content-Type: application/json' \
  --data "$(jq -n \
    --arg keyData "$STARHERMIT_PUBLIC_KEY" \
    --arg label 'orbit-league-production' \
    '{keyType:"Ed25519", keyData:$keyData, label:$label}')"

تعود المكالمة 201 والسجل الرئيسي. أ 403 يعني أن هذا الرمز المميز لم يأتي من OAuth الجلسة (لا يكفي التحقق من البريد الإلكتروني أو المفتاح العام أو الرمز المميز لإطلاق اللعبة). أ 409 يعني المفتاح نشط بالفعل أو أن الحساب قد وصل إلى حد المفتاح النشط الخاص به.

التحقق من النتيجة مع GET /api/v1/me/public-keys. تتضمن القائمة الملصقات وبصمات الأصابع وآخر استخدام مرات، والمفاتيح التي تم إبطالها، لذلك فهو أيضًا مسار تدقيق بيانات الاعتماد.

3. تكوين المستودع

في جيثب، أضف:

  • سر الافعال STARHERMIT_PRIVATE_KEY: البذور الخاصة Base64.
  • متغير الأفعال STARHERMIT_PUBLIC_KEY: المفتاح العام الأساسي Base64.
  • متغير الأفعال STARHERMIT_GAME_ID: معرف اللعبة المملوكة.

قم بحماية الإنتاج باستخدام بيئة GitHub إذا كانت الموافقة مطلوبة. يمكن أن تكون القيم المكافئة المخزنة في متغيرات GitLab المحمية أو Azure Key Vault أو أي مخزن سري آخر لـ CI.

أضف مساعد المصادقة/التحميل

ارتكب ما يلي كما ci/starhermit_upload.py. إنه يعيد بناء التحدي الدقيق JSON الذي يقوم StarHermit بالتوقيع داخليًا، والمصادقة باستخدام Ed25519، واختيار HTTP للأرشيفات الصغيرة أو تحميل WebSocket للأرشيفات التي يزيد حجمها عن 90 ميجابايت. يتجنب WebSocket نص HTTP الذي يبلغ حجمه 100 ميجا بايت تقريبًا لشبكة CDN الحد.

#!/usr/bin/env python3
import argparse, asyncio, base64, json, os
from pathlib import Path
from urllib.parse import quote, urlparse, urlunparse

import requests
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey


def authenticate(api, public_key, private_key):
    challenge = requests.post(
        f"{api}/api/v1/auth/public-key/challenge",
        json={"keyType": "Ed25519", "keyData": public_key}, timeout=30)
    challenge.raise_for_status()
    body = challenge.json()
    p = body["payload"]

    # Public JSON is camelCase; the server verifies its ChallengePayload serialization, whose
    # property names and order are the PascalCase sequence below.
    payload = {
        "ChallengeId": p["challengeId"],
        "Fingerprint": p["fingerprint"],
        "Issuer": p["issuer"],
        "Audience": p["audience"],
        "Expiry": p["expiry"],
        "Nonce": p["nonce"],
        "ClientTimestamp": p["clientTimestamp"],
    }
    # System.Text.Json escapes '+' in string fields (the Base64 nonce) as \u002B.
    # DateTimeOffset fields keep literal '+' in their offsets: do not replace globally.
    fields = []
    for name, value in payload.items():
        encoded = json.dumps(value)
        if name == "Nonce":
            encoded = encoded.replace("+", r"\u002B")
        fields.append(json.dumps(name) + ":" + encoded)
    signed_payload = ("{" + ",".join(fields) + "}").encode("utf-8")

    seed = base64.b64decode(private_key, validate=True)
    signature = Ed25519PrivateKey.from_private_bytes(seed).sign(signed_payload)
    complete = requests.post(
        f"{api}/api/v1/auth/public-key/complete",
        json={"challengeId": body["challengeId"],
              "signature": base64.b64encode(signature).decode(),
              "keyType": "Ed25519", "keyData": public_key}, timeout=30)
    complete.raise_for_status()
    return complete.json()["accessToken"]


def upload_http(api, game_id, token, archive, mode):
    with archive.open("rb") as stream:
        response = requests.post(
            f"{api}/api/v1/me/github-games/{game_id}/bundle",
            params={"mode": mode} if mode != "replace" else None,
            headers={"Authorization": f"Bearer {token}",
                     "Content-Type": "application/gzip"},
            data=stream, timeout=1800)
    response.raise_for_status()
    print(json.dumps(response.json()))


async def upload_websocket(api, game_id, token, archive, mode):
    import websockets
    parsed = urlparse(api)
    query = f"gameId={quote(game_id)}&access_token={quote(token)}"
    if mode != "replace":
        query += f"&mode={quote(mode)}"
    uri = urlunparse(("wss" if parsed.scheme == "https" else "ws", parsed.netloc,
                      "/ws/v1/game-upload", "", query, ""))
    async with websockets.connect(uri, max_size=None, ping_interval=20) as ws:
        ready = json.loads(await ws.recv())
        if ready.get("type") != "ready":
            raise RuntimeError(ready)
        with archive.open("rb") as stream:
            while chunk := stream.read(512 * 1024):
                await ws.send(chunk)
        await ws.send(json.dumps({"type": "complete"}))
        while True:
            message = json.loads(await ws.recv())
            if message.get("type") == "result":
                print(json.dumps(message))
                return
            if message.get("type") == "error":
                raise RuntimeError(message)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("archive", type=Path)
    parser.add_argument("--api", default="https://api.starhermit.com")
    parser.add_argument("--mode", choices=("replace", "merge"), default="replace",
                        help="replace the live client files (default) or patch them")
    args = parser.parse_args()
    game_id = os.environ["STARHERMIT_GAME_ID"]
    token = authenticate(args.api.rstrip("/"), os.environ["STARHERMIT_PUBLIC_KEY"],
                         os.environ["STARHERMIT_PRIVATE_KEY"])
    if args.archive.stat().st_size < 90 * 1024 * 1024:
        upload_http(args.api.rstrip("/"), game_id, token, args.archive, args.mode)
    else:
        asyncio.run(upload_websocket(args.api.rstrip("/"), game_id, token, args.archive, args.mode))


if __name__ == "__main__":
    main()

تعامل مع الخروج غير الصفري باعتباره عملية نشر فاشلة. لا تقم بتسجيل رمز الوصول أو نص الطلب الكامل. يستمر رمز الوصول لمدة 15 دقيقة، لذا قم بالمصادقة فورًا قبل التحميل؛ ويب سوكيت يتحقق منه أثناء المصافحة وقد ينتهي بعد انتهاء صلاحية الرمز المميز.

مثال على إجراءات جيثب

ينشر هذا المثال محتويات dist/ في كل دفعة ل main:

{٪ خام ٪}

name: Deploy to StarHermit
on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: production
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'

      - name: Build
        run: |
          npm ci
          npm run build

      - name: Package StarHermit bundle
        run: |
          mkdir -p bundle/client
          cp -R dist/. bundle/client/
          cp starhermit.txt bundle/starhermit.txt
          tar -C bundle -czf game-bundle.tar.gz .

      - name: Install uploader dependencies
        run: python -m pip install 'cryptography>=42,<45' 'requests>=2.31,<3' 'websockets>=12,<13'

      - name: Upload build
        env:
          STARHERMIT_PRIVATE_KEY: ${{ secrets.STARHERMIT_PRIVATE_KEY }}
          STARHERMIT_PUBLIC_KEY: ${{ vars.STARHERMIT_PUBLIC_KEY }}
          STARHERMIT_GAME_ID: ${{ vars.STARHERMIT_GAME_ID }}
        run: python ci/starhermit_upload.py game-bundle.tar.gz

للحصول على خادم مخصص، أضف docker build، احفظ الصورة في bundle/server/image.tar، والاحتفاظ بها starhermit.txt في جذر الحزمة:

docker build -t my-game-server:${GITHUB_SHA} -f Dockerfile.server .
mkdir -p bundle/server
docker save my-game-server:${GITHUB_SHA} -o bundle/server/image.tar
tar -C bundle -czf game-bundle.tar.gz .

يعني نجاح تحميل الحزمة أن StarHermit قبلت الحزمة ونشرتها ذريًا؛ إنه كذلك لا يعني أن الحاوية الجديدة قد اجتازت الفحوصات الصحية. استطلاع GET /api/v1/me/github-games/{id}/deployment بنفس الرمز المميز المصادق عليه حديثًا وقم بتشغيل ملف اختبار الدخان قبل الترويج للإصدار.

التناوب والاستجابة للحوادث

  1. قم بتسجيل الدخول عبر OAuth واقبل شروط StarHermit الحالية.
  2. قم بإضافة مفتاح تم إنشاؤه حديثًا ومسمى بشكل واضح.
  3. استبدل سر ومتغير CI، ثم قم بتشغيل النشر.
  4. قم بإلغاء المفتاح القديم باستخدام DELETE /api/v1/me/public-keys/{keyId}.

من أجل التوصل إلى تسوية واسعة النطاق مشتبه بها، DELETE /api/v1/me/public-keys/all يلغي كل مفتاح نشط. تتطلب كلتا عمليتي الحذف جلسة مصادقة OAuth. خط أنابيب مصادق عليه من تلقاء نفسه لا يمكن للمفتاح إلغاء المفاتيح الأخرى أو إضافة بديل أو تغيير البريد الإلكتروني للحساب أو إزالة هوية OAuth. يمكن أن يلغي نفسه مع DELETE /api/v1/me/public-keys/current; تجاهل الرموز المخزنة بعد ذلك.
