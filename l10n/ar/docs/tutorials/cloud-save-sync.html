تحميل وحفظ التقدم بأمان

استخدم الحفظ السحابي للتقدم المملوك للعميل الخاص باللاعب الذي قام بتسجيل الدخول. خيار اللاعب الفردي غير الموقع يحتفظ بالتقدم في الذاكرة ولا يقرأ أو يكتب حفظ الحساب. التفضيلات تنتمي إلى إعدادات اللعبة، وليس وثيقة التقدم.

يمكن لرمز الإطلاق الوصول بالضبط game:<gameId>، أين gameId هو game_scope. المنصة يخزن وحدات البايت غير الشفافة، مع حفظ واحد لكل فتحة. تحقق من صحة التنسيق الذي تتوقعه لعبتك. يرى الحفظ السحابي للحصص والرؤوس الشرطية.

وصفة JSON صغيرة كاملة

ينسخ cloud-save-store.js في البناء الخاص بك. هذا المثال يخزن الخام UTF-8 بايت JSON؛ المنصة تخدمهم application/zip ولكن لا يتطلب تنسيق ZIP. استخدم قارئًا مختلفًا لحفظ ملفات ZIP، بما في ذلك يحفظ ملف ZIP الخاص بمتصفح SDK. لا تقم بتغيير التنسيقات بدون خطة ترحيل للاعبين الحاليين.

import { CloudSaveStore } from './cloud-save-store.js';

const store = new CloudSaveStore({
  gameId: StarHermit.slug,
  token: () => StarHermit.token, // Always obtain the current renewed token.
});
const valid = value => value?.version === 1 && Number.isSafeInteger(value.points) && value.points >= 0;
let progress = { version: 1, points: 0 };
let saving = false;

async function startAccountGame() {
  // Keep gameplay/saving disabled until this resolves.
  const remote = await store.load(valid);
  progress = remote ?? { version: 1, points: 0 };
  render(progress);
}

async function saveCheckpoint() {
  if (saving) return; // Coalesce checkpoints; do not issue overlapping writes.
  saving = true;
  showSync('Saving…');
  try {
    await store.save(progress);
    showSync('Saved');
  } catch (error) {
    if (error.status === 412) {
      // Keep local progress in memory. Offer Reload cloud or an explicit merge.
      showConflict(() => startAccountGame());
    } else showSync('Save failed; retry after resolving the error');
  } finally {
    saving = false;
  }
}

render, showSync، و showConflict هي واجهة المستخدم الخاصة بك. انتظر startAccountGame() قبل التمكين اللعب أو الحفظ. عند فشل التحميل، احتفظ بالحالة المحلية الحالية للاعب، واعرض الفشل، وإبقاء التحميلات محظورة. أ 404 هي حالة الفتحة الفارغة؛ 401, 403, 5xx، JSON مشوه، أو أن نسخة الحفظ غير المدعومة ليست فتحات فارغة.

الوصفة لا تجدد أوراق الاعتماد. يقوم متصفح SDK بتجديد الرموز المميزة للإطلاق أثناء بقائها صالح. قم بحل الشروط المعلقة أو قم بإعادة المصادقة من خلال تدفق إدخال اللعبة قبل إعادة محاولة القراءة.

الظروف والصراعات

ما تم تحميله رأس على الكتابة القادمة إذا كتب جهاز آخر
الحفظ الحالي باستخدام ETag If-Match: <etag> 412 precondition_failed
لا يوجد حفظ (404) If-None-Match: * 412 precondition_failed
لم يتم تحميل أي شيء بنجاح لا الكتابة استمر في إعادة محاولة القراءة أو اسمح للاعب بالبقاء في اللعب غير المتعقب

استخدم الإصدار من البيانات التي قمت بتحميلها، وليس فحص البيانات الوصفية لاحقًا. احتفظ بعلامة ETag الجديدة التي تم إرجاعها بكل كتابة ناجحة. أ 412 يتم حفظ الكتل بشكل أكبر حتى تقوم اللعبة بتحميل الإصدار الحالي و يتبناها اللاعب أو يدمجها. لا تقم بإزالة الحالة بصمت والكتابة فوق جهاز آخر. لا تقدم واجهة برمجة التطبيقات (API) أي سجل حفظ للتراجع عن عملية الكتابة الفوقية هذه.

إذا كان يجب على جهازين تحديث العدادات أو المخزون بشكل مستقل، فستكون وثيقة واحدة هي الفائزة بالكتابة الأخيرة قد لا تناسب اللعبة. استخدم حالة ترخيص الخادم وحدد أوامر اللعبة التي تم التحقق من صحتها بدلاً من ذلك.

حفظ التنسيق والهجرة

قم بتضمين إصدار التنسيق والتحقق من صحة الأنواع والنطاقات والحقول المطلوبة قبل اعتماد جهاز التحكم عن بعد التقدم. اكتب ترحيلًا للإصدارات الأقدم المدعومة. احتفظ بإصدار أحدث غير معروف سليمًا؛ لا تقم بإعادة تعيينه إلى الإعدادات الافتراضية والتحميل عليه. تخضع البيانات السحابية لتحكم العميل، لذا لا تتعامل معها أبدًا كدليل على النتيجة التنافسية أو الاستحقاق المدفوع.

الحد الافتراضي للحفظ الذي تم فك تشفيره هو 10 ميجابايت. يضيف Base64 ثلث نص الطلب تقريبًا. 413 cloud_save_too_large, 409 cloud_save_slots_exhausted، و 507 cloud_save_quota_exceeded هي فشل القدرات المختلفة؛ فحص code و limit. شرف Retry-After على 429.

نقاط التفتيش وخروج الصفحة

احفظ عند نقاط تفتيش ذات معنى واعرض إجراء حفظ مرئيًا. فضح التغييرات السريعة وإجراء تسلسل يكتب بحيث يستخدم كل واحد الإصدار الأخير المعترف به. احتفظ بمؤشر قذر حتى يتم التعرف عليه. الطلب الفاشل ليس عملية حفظ مؤكدة؛ بعد كتابة غامضة، أعد التحميل قبل كتابة أخرى.

يعد تحميل الخروج من الصفحة أفضل جهد. المتصفح fetch(..., { keepalive: true }) يشارك صغيرة في الرحلة بدل الجسم، عادة 64 كيلو بايت؛ لا يمكن الاعتماد على حفظ 10 ميجابايت. قد يتم إغلاق علامة التبويب قبل أي طلب التشطيبات. استخدم عمليات حفظ المقدمة العادية من أجل المتانة، ولا تقم بتسمية التقدم غير المعترف به على أنه تم الحفظ. يقوم برنامج التشغيل السريع بحفظ مستنده الصغير في كل مجموعة نقاط.

تحقق في لعبتك

  1. ابدأ بفتحة فارغة؛ جمع التقدم وحفظه وإعادة تحميله والتأكد من عودته.
  2. رفض القراءات مع وجود خطأ في الشبكة، 403أو بيانات غير صالحة؛ تأكيد عدم وجود أي تحميل يتبع.
  3. افتح علامتي تبويب في إصدار واحد. احفظ في A، ثم B: يجب على B أن يبرز الصراع ويحافظ على حالته المحلية.
  4. اختبر تنسيقًا أقدم/أحدث وإقرارًا مفقودًا دون الكتابة فوق البيانات غير المعروفة.
  5. أدخل وضع اللاعب الفردي الذي لم يتم تعقبه وتأكد من أن اللعب لا يقدم أي طلبات حفظ على السحابة.

يرى البداية السريعة القابلة للتشغيل, اتفاقيات API، و استكشاف الأخطاء وإصلاحها.
