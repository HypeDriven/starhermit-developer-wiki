البرنامج التعليمي: إضافة عناصر التحكم إلى لعبتك

يمكن تخزين StarHermit الارتباطات الرئيسية للعبتك: تعلن عن الإجراءات ومفاتيحها الافتراضية، ويمكن لكل لاعب إعادة ربطهم. ويتبعهم اختيارهم إلى أي جهاز يقومون بتسجيل الدخول عليه. لعبتك يقرأ روابط اللاعب من واجهة برمجة تطبيقات عناصر التحكم ويمكنه تقديم روابطه الخاصة "إعادة ربط المفاتيح" شاشة.

إذا كانت لعبتك تستدعي واجهة برمجة تطبيقات عناصر التحكم وحصلت على ما يلي:

404 {"error":"This game declares no controls."}

المنصة لديها لا توجد إجراءات معلنة للبناء الذي يخدمه. لا شيء ترسله إلى API يمكن أن يفعل ذلك إصلاح ذلك: تم الإعلان عن عناصر التحكم في لعبتك starhermit.txt وقراءة متى تم نشر اللعبة. توضح هذه الصفحة كيفية التصريح بها، نشرها، التحقق من وصولها، واستخدامها من عميلك.

  3. تحقق من وصولهم
  4. استخدمها في لعبتك
  5. استكشاف الأخطاء وإصلاحها

1. أعلن الأفعال

أضف واحدة control.<action>= سطر لكل إجراء ل starhermit.txt:

name=Space Hopper
launch=index.html

control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.jump=Space+KeyW | Jump
control.fire=KeyJ | Fire
control.pause=Escape | Pause

يتكون كل سطر من ثلاثة أجزاء:

control.<action>=<code>[+<code>...][ | <label>]
جزء قواعد
<action> اسم لعبتك للإجراء: 1–32 حرفًا من الأحرف الصغيرة والأرقام و _ (move_left، لا move-left). فريد لكل مانيفست.
<code> A KeyboardEvent.code قيمة، مثل KeyA, ArrowLeft, Space, Digit1, ShiftLeft, Enter أو Escape. انضم إلى 1-4 رموز لنفس الإجراء +.
<label> خياري. تظهر في شاشات إعادة الربط؛ 64 حرفًا على الأكثر. الإعدادات الافتراضية لاسم الإجراء.

أشياء يجب معرفتها:

  • يستخدم code، لا key. يكتب KeyA، لا a، و Space، لا " ". رموز تسمية المادية مفتاح، وبالتالي فإن الارتباطات تعمل على أي تخطيط لوحة المفاتيح. تتحقق المنصة فقط من أن الرمز هو 1-32 الحروف والارقام وهكذا a أو space تم قبوله ولكن لا يوجد مفتاح ينتجه على الإطلاق. التهجئة والحالة يجب أن تتطابق تماما.
  • المفتاح ينتمي إلى إجراء واحد. الكود المستخدم بالفعل في سطر سابق يجعل السطر الأخير غير صالح.
  • ما يصل إلى 32 إجراء لكل لعبة. يتم تجاهل الأسطر بعد 32.
  • يتم الاحتفاظ بالأمر. تعود الإجراءات من واجهة برمجة التطبيقات (API) بترتيب واضح، لذا قم بإدراجها بهذه الطريقة يجب أن تظهر لهم شاشة الإعدادات الخاصة بك.
  • يتم تخطي سطر غير صالح بصمت. اللعبة لا تزال تنشر. إذا كان كل سطر غير صالح، لا تحتوي اللعبة على ضوابط وتجيب واجهة برمجة التطبيقات (API). 404. التحقق بعد النشر.

2. قم بنشرها

تتم قراءة التصريحات عندما يتم نشر اللعبة. التحرير starhermit.txt في المستودع الخاص بك أو على القرص لا يغير شيئًا حتى تنشر الإصدار الذي يحتوي عليه:

كيف يتم نشر لعبتك ما الذي يجعل الضوابط الجديدة حية
من مستودع جيثب نشرك التالي. ادفع التغيير، ثم انشر الإصدار الأحدث (تحديث النسخة المنشورة في لوحة القيادة، أو PUT /api/v1/me/github-games/{id}/deployment).
المجلد أو الحزمة التي تم تحميلها تحميل بناء جديد (POST /api/v1/me/github-games/{id}/bundle، أو ws/v1/game-upload) لمن starhermit.txt لديه الخطوط.
إضافة لعبة جديدة يقرأها التحميل أو الإرسال الأول على الفور.

يعيد التحميل البديل تحديد عناصر التحكم الخاصة بك من البيان الخاص به. إزالة كل control.* خط و اللعبة ليس لديها أي شيء. أ ?mode=merge تصحيح ذلك لا يحمل starhermit.txt يحافظ على الضوابط الحالية.

تنجو عمليات إعادة الربط الخاصة باللاعبين من البناء الجديد. الارتباط المحفوظ للاعب لإجراء لا يتم تجاهل وجود أطول.

3. تحقق من وصولهم

تعمل كل نقطة نهاية أدناه مع رمز مستخدم كامل أو رمز إطلاق لعبتك. {slug} هو الخاص بك سبيكة اللعبة: رمز الإطلاق game_scope المطالبة، أو gameSlug في GET /api/v1/me/github-games.

curl -s "https://api.starhermit.com/api/v1/games/$SLUG/controls" \
  -H "Authorization: Bearer $TOKEN" | jq

{
  "actions": [
    { "action": "left",  "label": "Move left",  "defaultCodes": ["KeyA", "ArrowLeft"],  "codes": ["KeyA", "ArrowLeft"] },
    { "action": "right", "label": "Move right", "defaultCodes": ["KeyD", "ArrowRight"], "codes": ["KeyD", "ArrowRight"] },
    { "action": "jump",  "label": "Jump",       "defaultCodes": ["Space", "KeyW"],      "codes": ["Space", "KeyW"] },
    { "action": "fire",  "label": "Fire",       "defaultCodes": ["KeyJ"],               "codes": ["KeyJ"] },
    { "action": "pause", "label": "Pause",      "defaultCodes": ["Escape"],             "codes": ["Escape"] }
  ]
}

الإجراءات المفقودة تعني أن خطوطها كانت غير صالحة؛ مقارنتها بالقواعد المذكورة أعلاه. أ 404 يعني أنه لم ينج أي منها، أو أن الإصدار الذي يعلن عنها لم يتم نشره بعد.

4. استخدمها في لعبتك

codes هو الارتباط الفعال للاعب: تجاوزه إذا قام بتعيين واحد، وإلا فهو الافتراضي. بناء بحث منه والمطابقة event.code:

const auth = { Authorization: `Bearer ${launchToken}` };

// Your built-in defaults, in the same shape the API returns.
const DEFAULT_ACTIONS = [
  { action: "left", label: "Move left", codes: ["KeyA", "ArrowLeft"] },
  { action: "jump", label: "Jump", codes: ["Space", "KeyW"] },
  /* ... */
];

function toControls(actions) {
  const byCode = new Map();
  for (const a of actions) for (const code of a.codes) byCode.set(code, a.action);
  return { actions, byCode };
}

async function loadControls(slug) {
  try {
    const res = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
    if (res.ok) return toControls((await res.json()).actions);
  } catch { /* offline: fall through */ }
  return toControls(DEFAULT_ACTIONS);                   // 404, error, or outside StarHermit
}

let controls = await loadControls(gameScope);

window.addEventListener("keydown", (e) => {
  const action = controls.byCode.get(e.code);   // e.code, never e.key
  if (action) { e.preventDefault(); onAction(action, true); }
});
window.addEventListener("keyup", (e) => {
  const action = controls.byCode.get(e.code);
  if (action) onAction(action, false);
});

الإعدادات الافتراضية المضمنة تجعل اللعبة قابلة للعب دون الاتصال بالإنترنت، خارج StarHermit، أو إذا كانت عناصر التحكم فشل الطلب. إبقائهم في خطوة مع الخاص بك control.* خطوط.

شاشة إعادة الربط. قائمة actions مع بهم label. احتفظ بخريطة التجاوز الكاملة، أو اقرأ الخريطة الفعالة الحالية واحفظها قبل تغيير إجراء واحد:

async function saveBinding(slug, action, codes) {
  const current = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
  if (!current.ok) throw new Error(`Controls read failed: ${current.status}`);
  const bindings = Object.fromEntries((await current.json()).actions.map(a => [a.action, a.codes]));
  bindings[action] = codes;
  const res = await fetch(`/api/v1/games/${slug}/controls`, {
    method: "PUT",
    headers: { ...auth, "Content-Type": "application/json" },
    body: JSON.stringify({ bindings }),
  });
  if (!res.ok) throw new Error((await res.json()).error);   // e.g. a key already in use
  return res.json();                                         // the new effective map
}

PUT يستبدل تجاوزات اللاعب بالإجراءات التي ترسلها، لذا قم بتضمين كل إجراء يقوم به اللاعب لقد تغير، وليس فقط أحدث واحد. الباقي يبقى على الإعدادات الافتراضية الخاصة بك. DELETE على نفس الطريق يعيد تعيين كل شيء إلى الإعدادات الافتراضية.

إجراء تسلسل للتغييرات من شاشتك؛ لا يزال بإمكان عمليتي القراءة/الكتابة المتزامنتين الكتابة فوق بعضهما البعض. متصفح SDK setControl() يقوم بتسلسل التغييرات الخاصة به ويحافظ على الخريطة الفعالة الحالية. يؤدي إرسال الخريطة الفعالة إلى تثبيت هذه القيم كتجاوزات؛ يستخدم DELETE للعودة إلى الإعدادات الافتراضية الواضحة.

المنصة ترفض الحفظ (400) من شأنه أن يترك مفتاحًا واحدًا على إجراءين بعد اللاعب يتم دمج التغييرات مع الإعدادات الافتراضية الخاصة بك. على سبيل المثال، ملزمة jump ل KeyJ بينما fire لا يزال يستخدم الافتراضي KeyJ تم رفضه. إظهار الخطأ، أو نقل الإجراء المتعارض في نفسه حفظ.

استكشاف الأخطاء وإصلاحها

إجابة سبب يصلح
404 "هذه اللعبة لا تعلن عن أي ضوابط." لا صالحة control.* خط في نشرت يبني. إضافة خطوط إلى starhermit.txt، التحقق منها ضد القواعد، و نشر بناء جديد.
404 "لا توجد لعبة مع تلك سبيكة." سبيكة غير صحيحة، أو أن اللعبة لا تحتوي على سبيكة. استخدم رمز الإطلاق game_scope أو gameSlug من GET /me/github-games. كل لعبة تتم إضافتها من مجلد محلي وكل لعبة في المستودع أضافها مالك تم التحقق منه تحتوي على سبيكة ثابتة، سواء كانت متصفحًا فقط أم لا. فقط إرسال المستودع الذي لم يتم التحقق من مالكه لا يحتوي على أي شيء؛ المطالبة به للحصول على واحدة.
403 "يتم تحديد نطاق هذا الرمز المميز للعبة "..."." رمز إطلاق يستخدم مع سبيكة لعبة أخرى. اتصل بالسبيكة الموجودة في الرمز المميز game_scope.
400 "إجراء غير معروف '...' — لم يتم الإعلان عنه في بيان اللعبة." PUT تم تسمية الإجراء الذي لم يعلن عنه البيان. يستخدم action القيم من GET …/controls.
400 ""..." مرتبط بكل من "..." و "..."." بعد الدمج مع الإعدادات الافتراضية، سيؤدي مفتاح واحد إلى تشغيل إجراءين. حرك الإجراء الآخر في نفس الشيء PUT، أو اختر مفتاحًا آخر.
400 "'...' ليست قيمة KeyboardEvent.code صالحة." رمز يحتوي على مسافات أو علامات ترقيم. يرسل event.code قيم.
400 "يجب أن يربط الإجراء "..." 1–4 رموز." قائمة فارغة، أو أكثر من أربعة. أرسل 1-4 رموز؛ DELETE لإعادة التعيين.
الإجراء مفقود من الاستجابة كان سطره غير صالح: حرف كبير أو - في اسم الفعل , بدلاً من +، أكثر من 4 رموز، أو رمز مستخدم بالفعل، أو بعد الإجراء الثاني والثلاثين. أصلح الخط وأنشر مرة أخرى.
الربط لا يتم إطلاقه أبدًا يتم قبول الرمز ولكن لا يوجد مفتاح ينتجه، مثل a أو space. استخدم بالضبط KeyboardEvent.code التهجئة: KeyA, Space.

أنظر أيضا: واجهة برمجة تطبيقات الألعاب — ارتباطات التحكم لكل لاعب, starhermit.txt.
