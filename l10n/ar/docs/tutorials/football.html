مثال للعبة: كيف تستخدم كرة القدم محرك StarHermit

ستارهيرميت لكرة القدم هو عام، كامل لعبة السيناريو. إنها كرة قدم ثلاثية الأبعاد في الوقت الفعلي لعدد يتراوح من 1 إلى 22 لاعبًا، مع زملائهم في فريق الذكاء الاصطناعي، ومضاءة الملعب، والردهات عبر الإنترنت، والدردشة الصوتية والنصية، والإعادة، ولوحة المتصدرين، والإنجازات وتسعة اللغات. تقوم هذه الصفحة بتفكيكها خطوة بخطوة لإظهار كيفية استخدام اللعبة الحقيقية للمحرك. كل تحدد الخطوة وحدات المحرك المعنية وتربطها بمصدر اللعبة، حيث يمكنك قراءة ملف الكود الكامل.

هذه الإرشادات مكتوبة للمحرك 1.40.0، الإصدار الأحدث. يتم إدراج كل مكالمة معروضة في مرجع API للمحرك. اقرأ البرنامج التعليمي للمحرك أولاً، إذا لم تكن قد أنشأت لعبة نصية بعد.

تشير روابط المصدر إلى الالتزام 33bd9bd. في ذلك ارتكب محرك دبابيس اللعبة 1.39.0 مع engine.minor=39. فهو لا يستخدم أي شيء أحدث، لذلك يعمل دون تغيير على 1.40.0؛ نقله هو تغيير سطر واحد ل engine.version (يرى الخطوة 12).

شكل اللعبة

طريق دور

server.js محاكاة المباراة الواحدة: يتم تشغيلها بواسطة النظام الأساسي كخادم معتمد، ويتم تحميلها بواسطة العميل للتمرين والتنبؤ دون الاتصال بالإنترنت
engine/src/main.ts وحدة الإدخال: عمليات الاسترجاعات لدورة الحياة وجهاز حالة الشاشات
engine/src/match.ts, logic/ مطابقة التدفق، رمز الشبكة، الاستيفاء والتنبؤ
engine/src/world/ الملعب ولاعبي كرة القدم والكرة والجمهور في مشهد ثلاثي الأبعاد
engine/src/screens/, hud.ts القوائم (starhermit:ui) وشاشة عرض المعلومات (HUD) داخل المباراة (starhermit:draw)
engine/src/net.ts, platform.ts, chat.ts, voice.ts كل ما يتحدث إلى منصة StarHermit
engine/src/audio.ts, i18n.ts, quality.ts مستويات الصوت واللغات والرسومات
assets/, sfx/ الصور والجداول السلسلة ومقاطع الصوت

1. البيان

starhermit.txt يجعل المجلد لعبة نصية، ويعلن أيضًا عن البرنامج النصي للخادم وعناصر التحكم:

name=Football
launch=index.html
server=server.js
control.up=KeyW+ArrowUp | Run forward
control.shoot=Space+KeyJ | Shoot (hold) / tap to pass
control.tackle=KeyK | Slide tackle / pressure
engine.api=1
engine.entry=engine/src/main.ts
engine.version=1.39.0
engine.minor=39
engine.capabilities=platform,voice,clipboard,storage
engine.gamepad.shoot=West+RightTrigger
engine.gamepad.pass=South
  • launch=index.html هي صفحة التحميل التي starhermit package --web يكتب. إنها تلعب اللعبة في المتصفحات الموجودة في وقت تشغيل الويب الخاص بالإصدار المثبت.
  • server=server.js هو نص المطابقة الرسمي للنظام الأساسي (الخطوة 6).
  • control.* و engine.gamepad.* تحديد الخطوط الإجراءات. يربط وقت التشغيل المفاتيح والوسادات بها، ويقوم اللاعبون بإعادة ربطها في قائمة خيارات وقت التشغيل. لا تحتوي اللعبة أبدًا على مفتاح للعب.
  • engine.capabilities يسأل عن المنصة (الغرف، المقابس، المتصدرين، الإعادة، الدردشة)، الصوت، الحافظة (روابط الدعوة) والتخزين (الإعدادات). وقت التشغيل يرفض المكالمات خارجها.

قائمة المفاتيح الكاملة موجودة ال starhermit.txt يظهر.

2. وحدة الإدخال وحلقة الإطار

engine/src/main.ts يقوم بإعداد العارض في نطاق الوحدة النمطية، ثم يقوم بتسجيل عمليات الاسترجاعات الأربعة لدورة الحياة من starhermit:engine:

import { frame, onFixedUpdate, onRender, onStart, onUpdate, setFixedRate } from "starhermit:engine";
import { ACESFilmicToneMapping, PCFSoftShadowMap, PerspectiveCamera, renderer, scene } from "starhermit:scene";

const camera = new PerspectiveCamera(55, 16 / 9, 0.1, 800);
renderer.camera = camera;
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = PCFSoftShadowMap;
renderer.toneMapping = ACESFilmicToneMapping;

onStart(() => {
  setFixedRate(60);
  loadLanguages(); // string tables (step 10)
  sim();           // evaluate server.js once (step 6)
  menuScene.start(); // an AI-vs-AI match behind the menu
  // … platform listeners, settings listeners, invite polling
});

onFixedUpdate((step) => {
  if (match) match.fixedStep(step);
  else if (!replay) menuScene.fixedStep(step);
});

onUpdate((delta) => {
  pollQuality();
  if (match) match.update(Math.min(delta, 0.1));
  // … replay viewer or menu backdrop
});

onRender(() => {
  const fr = frame();
  if (Math.abs(camera.aspect - fr.width / fr.height) > 1e-6) {
    camera.aspect = fr.width / fr.height;
    camera.updateProjectionMatrix();
  }
  hud.draw();
  // … chat, in-match menu or the menu screens
});

النمط المراد نسخه:

  • تعمل المحاكاة في onFixedUpdate، عند تردد ثابت 60 هرتز.
  • يتم تشغيل المنطق لكل إطار onUpdate، مع delta توج حتى لا يجعل الإطار المتوقفة يقفز اللاعبون.
  • الرسم يجري في onRender. هناك واحد فقط من كل رد اتصال، لذلك main.ts المشجعين إلى الشاشة الحالية: القائمة، الردهة، المباراة، الإعادة أو النتيجة.

3. العالم ثلاثي الأبعاد: starhermit:scene

الملعب ولاعبي كرة القدم والكرة والمسؤولين هي أشياء عادية على طراز Three.js starhermit:scene: Mesh, Group, MeshStandardMaterial, CylinderGeometry, Sprite, CanvasTexture وهكذا. الكود المنقول من three.js يعمل في الغالب دون تغيير. بعض التفاصيل تستحق القراءة:

  • world/stadium.ts يبني الملعب والمدرجات والأضواء الكاشفة والضباب. يقوم بتعيين تأثيرات ما بعد (renderer.bloom, renderer.grade, renderer.antialias) والظلال لكل مستوى رسومي.
  • world/environment.ts يصنع خريطة بيئية باستخدام PMREMGenerator من أ DataTexture.
  • world/crest.ts و world/nametags.ts ارسم شعارات الفريق والألقاب العائمة على أ starhermit:canvas OffscreenCanvas، ثم استخدمها كـ CanvasTextureرمل Sprites.

4. آلاف الأجزاء المتحركة: starhermit:world

إن تحريك 22 لاعب كرة قدم معًا، بالإضافة إلى الآلاف من أفراد الجمهور، سيكون بطيئًا للغاية البرنامج النصي لكل كائن على المترجم الأصلي. تحركات كرة القدم التي تعمل فيها starhermit:world الجداول (صفوف الأعمدة المكتوبة) و حبات (يعمل وقت التشغيل على كل صف أصلاً):

import { kernel, schedule, table } from "starhermit:world";

const crowd = table("crowd", CROWD_ROWS, {
  bx: "f32", by: "f32", bz: "f32", ph: "f32", fr: "f32", av: "f32",
  q: "quat", s: "f32", sy: "f32", x: "f32", y: "f32", z: "f32",
});
const sway = kernel(crowd, (r, u: { t: number; amp: number; spd: number; sway: number; shake: number }) => {
  const j = Math.sin(u.t * u.spd * r.fr + r.ph);
  r.y = r.by + (j > 0 ? j * j : 0) * u.amp * r.av;
  // …
});
// An eighth of the crowd each frame: the work is sliced across frames.
const swayRun = schedule.update(sway, { t: 0, amp: 0, spd: 0, sway: 0, shake: 0 }, { slices: 8 });

لاعب كرة القدم يتدخل world/rig.ts استخدم نفس النهج. أ rigs يحمل الجدول حالة الرسوم المتحركة لكل لاعب كرة قدم. أ joints طاولة, مع أ ref:rigs عمود، يحمل 15 مفاصل لكل منصة، و الارتباطات قيادة العقد المشهد منه. نواة مجدولة بعد ذلك onUpdate حساب الوضعيات، ووقت التشغيل يكتب العقدة يحول نفسه. يصل عمل السيناريو لكل لاعب كرة قدم إلى حوالي عشرة أرقام في الإطار.

5. الإدخال: الإجراءات واللمس ولوحات الألعاب

engine/src/input.ts يقرأ إجراءات البيان من خلال starhermit:input:

  • value(action) إرجاع مدى تنفيذ الإجراء (الحركة value("up") - value("down")). onAction يسلم حواف الصحافة والإفراج.
  • استخدامات مظهر الفأرة requestPointerLock, onPointerDelta و onPointerLockChange. الكاميرا العصا اليمنى تأتي من gamepads()، و vibrate يعطي علامة لمسية قصيرة.
  • على شاشات اللمس (primaryPointer() خشنة) setTouchControls يظهر عصا التحكم و أزرار التسديد/التمرير/التدخل التي تم رسمها بواسطة وقت التشغيل. ترتبط الأزرار بنفس الإجراءات:
setTouchControls([
  { kind: "stick", up: "up", down: "down", left: "left", right: "right", anchor: "bottom-left", offset: [90, 90], radius: 66 },
  { kind: "button", action: "shoot", label: T("SHOOT").slice(0, 16), anchor: "bottom-right", offset: [66, 66], radius: 46 },
  // … PASS and TACKLE
]);

screens/controls.ts يسرد الحالي bindings() والمكالمات requestRebind. وقت التشغيل ثم يلتقط المفتاح الجديد أو زر.

6. محاكاة واحدة للعميل والخادم: starhermit:script

server.js هو نص كلاسيكي عادي بدون أي استيرادات، Date أو Math.random، باعتباره وضع الحماية الخاص بالمنصة يتطلب. ويحدد عالميتين:

  • globalThis.game يحمل نقاط دخول المنصة (createSession, onPlayerMessage, onTick) وقراءة الإعلانات الثابتة في وقت النشر:

    globalThis.game = {
  tickRateHz: 30,
  replays: true,
  achievements: [
    { key: 'debut', name: 'Debut', description: 'Finish your first match.', points: 10 },
    { key: 'hat-trick', name: 'Hat-Trick', description: 'Score three goals in one match.', points: 50 },
    // …
  ],
  createSession: function (ctx) { /* seats, AI, seed from ctx.random */ },
  // …
};

  • globalThis.FootballSim يحمل نفس المحاكاة (createMatch, stepMatch، منظمة العفو الدولية) ل العميل.

يقوم العميل بتحميل نفس الملف في المجال الخاص به loadClassic من starhermit:script (engine/src/sim.ts):

import { loadClassic } from "starhermit:script";

loadClassic("server.js");
const S = (globalThis as unknown as { FootballSim?: FootballSimApi }).FootballSim;

خطوات الممارسة دون اتصال بالإنترنت FootballSim محليًا بسرعة 60 هرتز مع وجود الذكاء الاصطناعي في كل مقعد آخر. على الانترنت، تعمل المنصة server.js بشكل رسمي عند 30 هرتز. لا تحتفظ اللعبة أبدًا بنسختين منها القواعد.

7. المباريات عبر الإنترنت: الغرف ومآخذ الألعاب

تستخدم الردهات غرف المنصة من خلالها starhermit:platform (screens/lobby.ts):

import * as P from "starhermit:platform";

// Quick play: join any open room, or open one.
let room = await P.rooms.quickJoin();
if (!room) {
  room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, metadata: { game: "football" } });
  room = await P.rooms.open(room.id);
}

// Ranked solo vs AI: every other seat is an AI player, so starting begins the match at once.
room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, aiPlayers: 2 * teamSize - 1, metadata: { game: "football" } });
room = await P.rooms.start(room.id);

يمر الأصدقاء والدعوات وتغييرات المقاعد P.friends.list, P.rooms.invite, P.rooms.acceptInvite و P.rooms.seat. P.rooms.mine يتيح للاعب الانضمام مرة أخرى إلى المباراة التي غادرها.

وبمجرد أن تبدأ المباراة، engine/src/net.ts يفتح مقبس اللعبة مع P.connectGame(sessionId):

  • يرسل مدخلات عند 30 هرتز مع sendInput.
  • يطلب لقطة كاملة مع sendCommand({ type: "sync" }) على كل فتح وعلى resumed.
  • يستمع ل game ( لقطات وأحداث )، achievement و stopped. stopped تقارير لماذا توقف المقبس: تم تسجيل الخروج، أو تم تحديث الشروط، أو اختفت المباراة.

يحتفظ وقت التشغيل ببيانات اعتماد اللاعب ويعيد الاتصال من تلقاء نفسه، لذا لا تتعامل اللعبة مع أي رموز مميزة وليس لديه حلقة إعادة المحاولة.

logic/interp.ts يعمل على تسهيل لقطات الخادم من خلال الاستيفاء التكيفي. logic/predict.ts يتنبأ بحركة لاعب كرة القدم المحلي ويصححها تجاه كل لقطة. يؤثر التنبؤ إلا ما رسم؛ يبقى الخادم موثوقًا.

8. بقية المنصة

ميزة المكالمات مصدر

المتصدرين P.leaderboards.list, P.leaderboards.entries (أعلن المجلس في leaderboards.json) screens/leaderboard.ts

يمكن رفض كل مكالمة باستخدام أ PlatformError. تتعامل كرة القدم مع الميزات عبر الإنترنت باعتبارها أفضل جهد ممكن: أ يظهر الفشل "غير متوفر على الانترنت" أو يعود إلى الصمت ولا تنتهي اللعبة أبدًا. تم تسجيل الخروج، لا تزال اللعبة تقدم تدريبًا دون الاتصال بالإنترنت.

9. القوائم وHUD: starhermit:ui, starhermit:draw, starhermit:canvas

  • القوائم (screens/*.ts، القائمة ومربعات الحوار في المباراة main.ts) يستخدم starhermit:ui، واجهة مستخدم الوضع الفوري للمحرك. يتم استدعاء الحاجيات كل الإطار من onRender، و ui.setTheme يمنحهم ألوان اللعبة. خيارات وقت التشغيل الخاصة تفتح القائمة مع openMenu.
  • هود ( hud.ts) يرسم لوحة النتائج والساعة والعلامات starhermit:draw: draw.roundRect, draw.text و draw.image (قماش القمة)، في ترتيب الاتصال على مكان الحادث.
  • الصور محملة createImageBitmap من starhermit:canvas, على سبيل المثال الفن الرئيسي للقائمة.

10. الإعدادات واللغات: starhermit:storage، سلاسل

  • إعدادات كل لاعب (كتم الصوت، والصوت، واللغة، وتجاوزات الرسومات) موجودة في اللعبة settings من starhermit:storage. يتم الاحتفاظ بها على الجهاز وفي الحساب. settings.onChange يطبق التغيير الذي تم إجراؤه على جهاز آخر.
  • i18n.ts الأحمال assets/strings.json في المحرك strings الجداول (strings.load, strings.t, strings.setLanguage). فهو يختار اللغة من الاختيار المحفوظ، ثم اختيار اللاعب لغة StarHermit ثم الجهاز (preferences). l10n/font.ts تحميل خطوط البرنامج النصي مع FontFace للغات التي تحتاج إليها.

11. مستويات الصوت والرسومات

  • audio.ts يبني رسمًا بيانيًا صوتيًا على الويب باستخدام starhermit:audio:
    • يتم سرد المقاطع المؤلفة في sfx/manifest.json (اقرأ مع files.readJson).
    • يقوم المركب بتغطية أي حدث بدون مقطع، بالإضافة إلى صدى الجمهور والملعب.
    • يتم تحرير العقد قصيرة العمر بمجرد انتهائها، لأن الرسم البياني المضيف محدد.
  • quality.ts يتبع مستوى رسومات اللاعب (frame().level, levelSettings). الظلال، ازهر و مكافحة التعرج تتبع هذا المستوى. محتوى اللعبة الخاص (تفاصيل الملعب، كثافة الجماهير، الجزيئات) لديه تجاوزات لكل لاعب في الأعلى.

12. التعبئة والاختبار والنشر

  • التحقق من النوع مع tsc -p engine. engine/tsconfig.json يتضمن الإصدار starhermit.d.ts ومجموعات "lib": ["ES2022"], "types": [] و "allowImportingTsExtensions": true.
  • امتحان. npm test يدير server.js اختبارات الانحدار. engine/tests/run.sh يدير المنطق الاختبارات (الاستيفاء، التنبؤ، الوضعية، الردهة) ضمن Node. starhermit <folder> --check يتحقق من صحة الحزمة ويلعب 120 إطارًا مقطوعة الرأس.
  • طَرد. starhermit package --web . يعيد كتابة index.html و starhermit-files.json, والتي تلتزم بكل تغيير.
  • نشر. تتم إضافة اللعبة على StarHermit من عنوان URL للمستودع الخاص بها. تقرأ المنصة starhermit.txt، يدير server.js كنص المباراة ويقوم بإنشاء لوحة المتصدرين من leaderboards.json.

لنقل كرة القدم، أو لعبتك الخاصة، إلى المحرك 1.40.0:

  1. قم بتنزيل وقت التشغيل 1.40.0.
  2. تعيين engine.version=1.40.0.
  3. قم بتشغيل الشيكات والحزمة مرة أخرى.

يرفع engine.minor إلى 40 فقط عندما تريد مضيف API 1.40 ميزات جديدة.
