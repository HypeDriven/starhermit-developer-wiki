الوحدة SDK

ال ستارهيرميت الوحدة SDK (HypeDriven/starhermit-unity-sdk) عبارة عن حزمة Unity Package Manager مع عملاء C# مكتوبين وغير متزامنين للنظام الأساسي. يعالج طلبات HTTP، وتحليل JSON، وتحديث الرمز المميز، وإعادة الاتصال بـ WebSocket.
طَرد com.starhermit.sdkالإصدار 0.1.0
مساحة الاسم Starhermit
خط الأساس لواجهة برمجة التطبيقات (API). REST v1 وWebSocket v1
أحدث ميزات REST يستخدم client.Raw والنموذج RawJson عندما لا يحتوي إصدار SDK هذا على عضو مكتوب
بروتوكولات WebSocket كل 6، فئة اتصال واحدة لكل منهما
رخصة معهد ماساتشوستس للتكنولوجيا

إن SDK هو عميل، وليس تطبيقًا ثانيًا للنظام الأساسي. إذن، صداقة، الاستحقاق وعضوية الغرفة والتحقق من صحة النتيجة ونتائج اللعبة وميزانيات التخزين موثوق بالخادم تمامًا كما هو موثق في الصفحات أدناه - يعرض SDK إجابة الخادم وحدودها المنشورة بدلاً من تحديد حدودها أو تخزينها مؤقتًا.

هذه الصفحة هي دليل التكامل. توجد وثائق الحزمة الكاملة في المستودع أسفل Packages/com.starhermit.sdk/Documentation~.

متطلبات

  • Unity 2021.3 LTS أو مستوى توافق API الأحدث صافي قياسي 2.1, C# 9.
  • Mono وIL2CPP، مع تجريد مُدار من معطل إلى عالي (الحزمة تشحن بنفسها Runtime/link.xml).
  • لا يوجد انعكاس، ولا يوجد إنشاء كود ديناميكي، ولا يوجد مكون إضافي إلزامي.

يتم تجميع كل وحدة لكل هدف بناء. عندما يفتقر الهدف حقًا إلى القدرة - لا ميكروفون على خادم بدون رأس، ولا توجد رؤوس مصافحة في المتصفح - يتم رفع المكالمة StarhermitFeatureUnavailableException مع مستقرة Reason، بدلاً من الفشل في البناء أو تعطيل الميزات غير ذات الصلة.

ثَبَّتَ

مدير الحزم → أضف حزمة من عنوان URL لـ git، أو الدخول Packages/manifest.json. الحزمة يقع في مجلد فرعي للمستودع، لذلك يحتاج URL path=:

{
  "dependencies": {
    "com.starhermit.sdk": "https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk"
  }
}

تثبيت الإصدار عن طريق الإلحاق #<tag-or-commit>:

https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk#v0.1.0

قذائف الوحدة بها git، لذلك لا يتم حل المستودع الخاص إلا إذا كان بإمكان بوابة المحرر المصادقة بشكل غير تفاعلي - مفتاح SSH (git@github.com:HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk) أو أ تكوين مساعد الاعتماد. يعمل المسار المحلي أو التسجيل المحدد بنفس الطريقة. استيراد يعدل لا إعدادات المشروع ولا ينفذ أي وصول إلى الشبكة.

إنشاء عميل

using Starhermit;

var client = StarhermitClient.Create(new StarhermitOptions
{
    ApiBaseUri = new Uri("https://api.starhermit.com/api/v1/"),
    GameSlug   = "83fd04b1-3cbe-4b09-a251-3733ad4b9d94",
    TokenStore = myPlatformSecureStore,
    LogLevel   = StarhermitLogLevel.Warning
});

await client.InitializeAsync();               // loads a stored session, refreshes it if expired
var me = await client.Me.GetProfileAsync();

Create لا ينفذ أي I/O. لا شيء يلمس الشبكة حتى تقوم بالتهيئة أو الاتصال بالخدمة أو فتح ملف اتصال. قاعدة WebSocket مشتقة من ApiBaseUri (wss://<host>/ws/v1/) إلا إذا قمت بتعيين WebSocketBaseUri نفسك.

StarhermitClient يكون IDisposable: التخلص يلغي الطلبات أثناء الرحلة، ويغلق كل اتصال به يتم توزيعه، ويوقف نبضات القلب ويصدر الصوت. لا توجد حالة ثابتة قابلة للتغيير في الحزمة، لذلك يمكن لعميلين العمل جنبًا إلى جنب في بيئات مختلفة، وينجو عميل واحد من أحمال المشهد.

لعبة منشورة على المنصة يتم تقديمه من https://<slug>.starhermit.com مع /api و /ws وكيل نفس الأصل (انظر ألعاب جيثب). نشر بناء WebGL ذلك يجب أن تشير الطريقة إلى مصدرها الخاص حتى يقوم المتصفح بإجراء مكالمات من نفس المصدر:

ApiBaseUri = new Uri("https://83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com/api/v1/") // your game's uid

بالنسبة للواجهة الخلفية المحلية، AllowInsecureTransport = true تصاريح http/ws. بناء العميل يرفض أ عنوان غير HTTPS بدونه، ويفشل التحقق من صحة بناء المحرر في إنشاء مشغل غير قابل للتطوير التي لا تزال لديها مجموعة. لا يقوم أبدًا بتعطيل التحقق من صحة الشهادة.

تسجيل الدخول

أنواع بيانات الاعتماد الثلاثة الموضحة في المصادقة هي أنواع منفصلة في منفصلة مخازن في SDK. لا أحد يستطيع أن يحل محل آخر.

OAuth - يفتح SDK عنوان URL للتفويض من خلال ملف تم إدخاله IStarhermitOAuthBrowser ويكمل التبادل:

var session = await client.Auth.SignInWithOAuthAsync("google");

يستخدم BuildAuthorizeUri(provider) زائد CompleteOAuthAsync(...) بدلاً من ذلك عندما تقوم المنصة الخاصة بك بتسليم إعادة التوجيه مرة أخرى من خلال الرابط العميق الخاص به أو السباكة المضمنة في المتصفح.

المفتاح العام - التدفق بدون كلمة مرور للمشغلات المضمنة ووحدة التحكم والخادم المخصص (انظر خادم مخصص + مشغل مدمج). أنواع المفاتيح المدعومة هي Ed25519, ECDSA-P256 و RSA-PSS; لا يقوم SDK أبدًا بإنشاء أو تخزين ملف المفتاح الخاص، فإنه يستدعي حقنه IStarhermitSigner:

var session = await client.Auth.SignInWithPublicKeyAsync(signer);   // or (), using Options.Signer

تفاصيل العقد تستحق المعرفة. يتحقق النشر من توقيع التحدي مقابل توقيعه الخاص تسلسل PascalCase للتحدي، في حين أن JSON الذي تتلقاه هو CamelCase - إعادة التسلسل لن يتم التحقق من الرد أبدًا. StarhermitChallenge.CanonicalPayload يستنسخ البايتات الدقيقة ل التوقيع، لذلك التوقيع المدلفن يدويا يجب أن تفعل الشيء نفسه.

رمز إطلاق اللعبة - يتم سكها لكل لعبة وتسييجها على سطح تلك اللعبة:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();
var fenced = chess.WithLaunchToken();     // subsequent calls authorise with the launch token

لا يؤدي سك رمز الإطلاق إلى استبدال جلسة الحساب أبدًا. ما هي بيانات الاعتماد التي يحملها الطلب يتم تحديده من خلال مسار الطلب، وليس من خلال الخدمة التي اتصلت بها.

يتم تنسيق تحديث رمز الوصول: أ 401 يشتري تحديثًا واحدًا على الأكثر وإعادة تشغيل واحدة ومتزامنة ينتظر المتصلون نفس التحديث بدلاً من بدء عدة تحديثات - باستخدام رمز تحديث دوار، ثانية سيؤدي التبادل إلى إلغاء العائلة وتسجيل خروج اللاعب. يثير الرفض النهائي SessionExpired مرة واحدة؛ فشل النقل يترك الجلسة سليمة.

قبول الشروط الحالية

تحقق من القبول قبل بدء نبضات القلب أو طلبات الألعاب أو المقابس. الإصدار 0.1.0 لديه AcceptTermsAsync، لكن اكتشاف حقول الملفات الشخصية والمصطلحات الأحدث يستخدم دعم JSON الأولي الخاص بها:

var profile = await client.Me.GetProfileAsync(ct);
var needsAcceptance = profile.RawJson["termsAcceptanceRequired"].AsBooleanOrDefault();
var terms = await client.Raw.SendForJsonAsync(new StarhermitRequest("GET", "terms"), ct);
var textToDisplay = terms["text"].AsStringOrNull();
var displayedHash = terms["hash"].AsStringOrNull();
// Display textToDisplay. Retain displayedHash for this displayed revision.
// Only in the user's Accept handler, using an account session:
// await client.Me.AcceptTermsAsync(displayedHash, ct);

لا تستخدم نموذج تسمية المراجعة مثل terms-2026-08: فقط التجزئة الحالية من API هي مقبول. على 409، قم بإحضار النص الجديد وعرضه لقبول آخر. على 403 terms_acceptance_requiredحل القبول قبل إعادة المحاولة؛ يمكن أيضًا لرموز إطلاق اللاعب إرسال القبول من خلال واجهة برمجة التطبيقات (API) بعد الحصول على موافقة صريحة. يرى حساب تعريفي للتدفق الكامل.

مخطوطات اللعبة لا يحتوي على خدمة SDK: يتم تشغيل البرنامج النصي على النظام الأساسي، ولا يحتوي يتحدث العملاء إليها من خلال واجهة برمجة تطبيقات الألعاب أعلاه.

جلسة من النهاية إلى النهاية

دورة الحياة من إرشادات التكامل، شركة#:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();

var ticket = await chess.EnqueueMatchmakingAsync();
while (!ticket.IsMatched)
{
    await Task.Delay(TimeSpan.FromSeconds(2), ct);
    ticket = await chess.GetMatchmakingAsync(ct) ?? ticket;
}

using var game = client.CreateGameConnection(ticket.SessionId!.Value, "83fd04b1-3cbe-4b09-a251-3733ad4b9d94", useLaunchToken: true);
game.FrameReceived       += frame => ApplyServerState(frame);
game.AchievementUnlocked += unlock => ShowToast(unlock);
game.PresenceChanged     += (userId, online) => UpdateOpponentDot(userId, online);
game.ErrorReceived       += message => ShowError(message);

await game.ConnectAsync(ct);
await game.SendCommandAsync(writer =>
{
    writer.Write("type", "move");
    writer.Write("from", "e2");
    writer.Write("to",   "e4");
}, ct);

SendCommandAsync يلتف الحمولة كما {"type":"cmd","data":…}; SendRealtimeInputAsync هو مسار محدود المعدل للإدخال المستمر. الاتصال لا يحدد منطق اللعبة، توقع موثوقًا الحالة، أو اختلاق نتيجة، أو إعادة إرسال أمر ربما غير فعال بعد أمر غامض قطع الاتصال — يظل الخادم هو المرجع الوحيد فيما حدث.

يشترك كل اتصال في جهاز حالة واحد: Disconnected, Connecting, Connected, Reconnecting, Closing, Faulted، مع StateChanged, Closed و Faulted الأحداث، يحدها قوائم الانتظار الصادرة مع الضغط الخلفي الصريح، ويرسل أمر. تستخدم إعادة الاتصال التراجع المتوتر، وتعيد الحصول على تيار رمز مميز قبل كل محاولة، و يتوقف إلى الأبد عند الترخيص أو إغلاق السياسة بدلا من طرق باب المنصة لإغلاقه. ولا يفترض أبدًا أن العضوية قد نجت من الفجوة: كل بروتوكول يعيد أو ينضم مرة أخرى عند إعادة الاتصال.

أوراق الاعتماد ركوب Authorization header حيث تسمح المنصة بذلك و ?access_token= على /ws/** بخلاف ذلك، لأن المتصفح لا يمكنه تعيين رؤوس المصافحة. تم تنقيح رمز الاستعلام من كل سجل.

المزامنة والخيوط والوحدة

تعود كل عملية إدخال/إخراج Task ويأخذ زائدة CancellationToken. لا يوجد async void الأساليب ولا توجد طريقة عامة تحظر مؤشر ترابط الاستدعاء.

يتم نشر عمليات رد الاتصال للأحداث والتقدم في سياق المزامنة الذي تم إنشاء العميل عليه - لذلك إذا قمت بإنشائه على مؤشر ترابط Unity الرئيسي، فقد يلمس المعالج GameObjectق مباشرة. خادم بلا رأس يمكن تخطي القفزة مع options.CallbackDispatcher = ImmediateCallbackDispatcher.Instance. عمليات الاسترجاعات هي يتم طلبه لكل اتصال، ويتم الإبلاغ عن المعالج الذي يقوم بالرمي للتشخيص دون إيقاف تلقي حلقة.

StarhermitLifecycle.Attach(client) أحداث تطبيق الجسور الوحدة: وجود توقف نبضات القلب عند التعليق وإرسال السيرة الذاتية فورًا، ويتم التخلص من العميل بدون تزامن عمل الشبكة.

النماذج لا تشير أبدا GameObject, MonoBehaviour أو مشهد. StarhermitTextures تحويل الصورة الرمزية و بايتات الغلاف الفني إلى ملف Texture2D في الموضوع الرئيسي - يمتلك المتصل النتيجة ويجب عليه تدميرها.

الأخطاء وإعادة المحاولة وترقيم الصفحات

حالة استثناء
400 / 422 StarhermitBadRequestException, StarhermitValidationException (أخطاء الحقل مرتبطة باسم السلك)
401 StarhermitAuthenticationException
402 StarhermitEntitlementException
403 StarhermitAuthorizationException
404 StarhermitNotFoundException
409 StarhermitConflictException
429 StarhermitRateLimitException (يحمل RetryAfter)
5xx StarhermitServerException

كل يحمل حالة الخادم {"error":"..."} الرسالة، أي رمز يمكن قراءته بواسطة الآلة، الطلب معرف, Retry-Afterوالرؤوس المنقحة والنص المنقح ذو الحجم المحدد. الطلب الذي لم يصل أبدا يثير API StarhermitTransportException أو StarhermitTimeoutException — فشل النقل أبدا يرتدي زي استجابة API. يظهر الإلغاء دائمًا على أنه OperationCanceledException.

إعادة المحاولة محدودة، متوترة، شرف Retry-After تصل إلى الحد الأقصى، وتقتصر على حالات الفشل في الثانية يمكن أن تنجو المحاولة: أخطاء الاتصال، المهلات، 408, 429 وعابرة 5xx. 403, 404, 409 ولا تتم إعادة محاولة فشل التحقق مطلقًا، ولا تتم إعادة محاولة POST إلا عند الاشتراك AsIdempotent. تمنع ميزانية إعادة المحاولة على مستوى العملية العديد من العملاء من تحويل انقطاع الخدمة إلى عاصفة.

قائمة نقاط النهاية العودة StarhermitPage<T> تحمل بيانات تعريف الترحيل الخاصة بالخادم، بالإضافة إلى الكسل التعداد الذي يجلب الصفحة فقط عند استهلاكها:

await foreach (var title in client.Software.EnumerateTitlesAsync(query, cancellationToken: ct)) { … }

تيار التنزيلات إلى IStarhermitFileStore من خلال ملف مؤقت، تحقق من SHA-256 و يتم الترويج لها ذريًا؛ OpenDownloadAsync التقارير IsResumed فقط من أجل حقيقي 206، لأن إن إلحاق ملف كامل بملف جزئي قد يؤدي إلى إتلافه أثناء اجتياز فحص الطول.

تخزين بيانات الاعتماد

الحزمة لا يشحن أي متجر يدعي أنه آمن. الافتراضي هو في الذاكرة؛ الاشتراك EncryptedFileTokenStore (AES-CBC مع HMAC-SHA256 عبر المفتاح الذي يوفره تطبيقك) موثق كتشويش في حالة الراحة، وليس سلسلة مفاتيح. سلك IStarhermitTokenStore إلى النظام الأساسي الآمن التخزين — سلسلة المفاتيح، ومتجر المفاتيح، ومساحة تخزين مستخدم SDK لوحدة التحكم. PlayerPrefs لم يتم تقديمه أبدًا على أنه آمن.

لا يتم إجراء تسلسل للرموز المميزة ورموز التحديث والمفاتيح الخاصة وأسرار العميل ومفاتيح الاستدعاء في ملف ScriptableObjectمشهد, Resourcesأو سجل أو رسالة استثناء أو حدث قياس عن بعد أو إنشاء قطعة أثرية. StarhermitSettings يحمل فقط الإعدادات الافتراضية غير السرية للمشروع: العناوين، والارتباط الثابت، ومستوى السجل، المهلة وعلامة التطوير.

يعد التنقيح هيكليًا - حسب الرأس ومعلمة الاستعلام واسم عضو JSON، في كل عمق - لذا أ لا تزال بيانات الاعتماد التي لم يسمع بها إصدار SDK هذا من قبل يتم تجريدها من السجلات والاستثناءات والقياس عن بعد. يتم إسقاط أجزاء عنوان URL بالكامل. لا يتم جمع القياس عن بعد بشكل افتراضي؛ يستقبل الحوض المحقون اسم الحدث، ومعرف العملية، والمدة، وعائلة الحالة، وعدد مرات إعادة المحاولة، ومعرف الطلب والنتيجة، وليس عناوين URL أبدًا، الهيئات أو محتوى اللاعب.

عندما تقوم المنصة بشحن شيء جديد

النماذج غير قابلة للتغيير وتحتفظ بـ JSON الذي تم تحليلها منه، لذلك تتم إضافة حقل إلى النشر بعد ذلك لا يزال إصدار SDK هذا قابلاً للقراءة، ولا تزال نقطة النهاية التي لم يكتبها هذا الإصدار قابلة للاستدعاء بها نفس بيانات الاعتماد وإعادة المحاولة والتنقيح مثل مكالمة مكتوبة:

var value = profile.RawJson["shippedAfterThisSdk"].AsStringOrNull();

var json  = await client.Raw.SendForJsonAsync(
    new StarhermitRequest("GET", "some/new/route").WithQuery("page", 1), ct);

يتم إرسال إطارات المقبس إلى مُميِّز النوع الخاص بها مع إطار احتياطي غير معروف يحافظ على الحمولة، يتم الاحتفاظ بسلاسل التعداد غير المعروفة كسلاسل بدلاً من أن تكون قسرية، ومستوى خصوصية غير معروف يقرأ كما معظم تفسير خاص. Optional<T> يميز المحذوفة والصريحة الفارغة و القيمة، وهو ما يحتاجه الجسم PATCH.

client.GetDiagnostics() إرجاع حالات الاتصال، وعمق قائمة الانتظار، وأعداد إعادة الاتصال، وانتهاء الرمز المميز، والساعة الحداثة، والطلبات أثناء الرحلة، والمحاولات المستنفدة، وآخر خطأ منقح - اللقطة التي يجب إرفاقها بـ تقرير الشوائب.

عينات

يتم شحن ثماني عينات مع الحزمة ويتم تجميعها في CI، لذلك لا يمكن أن تنحرف عن API العرض التوضيحي: المصادقة والملف الشخصي، الأصدقاء والدردشة، لعبة التوفيق بين اللاعبين، الوقت الفعلي والتتابع، الصوت، خدمات الكتالوج وأداة الناشر والخادم المخصص.

حالة التحقق

مجموعة SDK الخاصة (144 اختبارًا محكمًا تحت dotnet test، نفس الملفات التي تعمل كـ Unity EditMode الاختبارات) وبيان التغطية الذي تم إنشاؤه والذي يفشل في الإنشاء عندما لا تحتوي عملية API على تعيين SDK تشغيل على كل تغيير. خمسة اختبارات أخرى تقرأ النشر المباشر عند الإشارة إلى واحد منها، ويتم تخطيها خلاف ذلك. مصفوفة المحرر وIL2CPP تم تعريف تصميمات المشغل لنظام التشغيل Linux وAndroid وWebGL في CI ولكنها تحتاج إلى مزرعة إنشاءات مرخصة، لذا فإن يوضح جدول النظام الأساسي أعلاه الدعم المقصود - تعامل مع الهدف على أنه مؤهل فقط بمجرد إنشائه بنفسك.
