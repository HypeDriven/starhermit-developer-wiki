Tutorial: adicione controles ao seu jogo

StarHermit pode armazenar atalhos de teclado para o seu jogo: você declara as ações e suas chaves padrão, e cada jogador pode religá-los. A escolha deles os segue até qualquer máquina em que eles façam login. Seu jogo lê as ligações do jogador na API de controles e pode oferecer suas próprias "religar chaves" tela.

Se o seu jogo chamar a API de controles e obtiver isto:

404 {"error":"This game declares no controls."}

a plataforma tem nenhuma ação declarada para a construção que está servindo. Nada que você envia para a API pode conserte isso: os controles são declarados no arquivo do seu jogo starhermit.txt e leia quando o jogo é publicado. Esta página mostra como declará-los, publicá-los, verificar se chegaram, e use-os do seu cliente.

  2. Publique-os
  3. Verifique se eles chegaram

1. Declare as ações

Adicione um control.<action>= linha por ação para starhermit.txt:

name=Space Hopper
launch=index.html

control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.jump=Space+KeyW | Jump
control.fire=KeyJ | Fire
control.pause=Escape | Pause

Cada linha tem três partes:

control.<action>=<code>[+<code>...][ | <label>]
Papel Regras
<action> O nome do jogo para a ação: 1 a 32 caracteres de letras minúsculas, dígitos e _ (move_left, não move-left). Único por manifesto.
<code> A KeyboardEvent.code valor, como KeyA, ArrowLeft, Space, Digit1, ShiftLeft, Enter ou Escape. Junte de 1 a 4 códigos para a mesma ação com +.
<label> Opcional. Mostrado em telas de religação; no máximo 64 caracteres. O padrão é o nome da ação.

Coisas para saber:

  • Usar code, não key. Escrever KeyA, não a, e Space, não " ". Os códigos nomeiam o físico tecla, para que as ligações funcionem em qualquer layout de teclado. A plataforma verifica apenas se o código é 1–32 letras e dígitos, então a ou space é aceito, mas nenhuma chave o produz. Ortografia e caso deve corresponder exatamente.
  • Uma chave pertence a uma ação. Um código já usado por uma linha anterior torna a linha posterior inválido.
  • Até 32 ações por jogo. As linhas após o dia 32 são ignoradas.
  • A ordem é mantida. As ações retornam da API na ordem do manifesto, então liste-as da maneira sua tela de configurações deve mostrá-los.
  • Uma linha inválida é ignorada silenciosamente. O jogo ainda é publicado. Se cada linha for inválida, o jogo não tem controles e a API responde 404. Verifique após a publicação.

2. Publique-os

As declarações são lidas quando o jogo for publicado. Edição starhermit.txt em seu repositório ou no disco nada muda até você publicar uma compilação que o contenha:

Como seu jogo é publicado O que torna os novos controles ativos
De um repositório GitHub Sua próxima implantação. Envie a alteração e implante a versão mais recente (Atualizar versão implantada no painel ou PUT /api/v1/me/github-games/{id}/deployment).
Pasta ou pacote enviado Carregar uma nova compilação (POST /api/v1/me/github-games/{id}/bundle, ou ws/v1/game-upload) cujo starhermit.txt tem as linhas.
Adicionando um novo jogo O primeiro upload ou envio os lê imediatamente.

Um upload substituto reafirma seus controles de seu próprio manifesto. Remover todos control.* linha e o jogo não tem nenhum. UM ?mode=merge consertar isso não carrega starhermit.txt mantém os controles atuais.

As próprias religações dos jogadores sobrevivem a uma nova construção. A vinculação salva de um jogador para uma ação que não não existe mais é ignorado.

3. Verifique se eles chegaram

Cada endpoint abaixo funciona com um token de usuário completo ou com o token de lançamento do seu jogo. {slug} é o seu slug do jogo: o token de lançamento game_scope reivindicar, ou gameSlug em GET /api/v1/me/github-games.

curl -s "https://api.starhermit.com/api/v1/games/$SLUG/controls" \
  -H "Authorization: Bearer $TOKEN" | jq

{
  "actions": [
    { "action": "left",  "label": "Move left",  "defaultCodes": ["KeyA", "ArrowLeft"],  "codes": ["KeyA", "ArrowLeft"] },
    { "action": "right", "label": "Move right", "defaultCodes": ["KeyD", "ArrowRight"], "codes": ["KeyD", "ArrowRight"] },
    { "action": "jump",  "label": "Jump",       "defaultCodes": ["Space", "KeyW"],      "codes": ["Space", "KeyW"] },
    { "action": "fire",  "label": "Fire",       "defaultCodes": ["KeyJ"],               "codes": ["KeyJ"] },
    { "action": "pause", "label": "Pause",      "defaultCodes": ["Escape"],             "codes": ["Escape"] }
  ]
}

Ações ausentes significam que suas linhas eram inválidas; compare-os com as regras acima. UM 404 significa que nenhum sobreviveu ou a compilação que os declara ainda não foi publicada.

4. Use-os em seu jogo

codes é a ligação efetiva do jogador: seu cancelamento se ele definir um, caso contrário, seu padrão. Crie uma pesquisa a partir dele e combine event.code:

const auth = { Authorization: `Bearer ${launchToken}` };

// Your built-in defaults, in the same shape the API returns.
const DEFAULT_ACTIONS = [
  { action: "left", label: "Move left", codes: ["KeyA", "ArrowLeft"] },
  { action: "jump", label: "Jump", codes: ["Space", "KeyW"] },
  /* ... */
];

function toControls(actions) {
  const byCode = new Map();
  for (const a of actions) for (const code of a.codes) byCode.set(code, a.action);
  return { actions, byCode };
}

async function loadControls(slug) {
  try {
    const res = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
    if (res.ok) return toControls((await res.json()).actions);
  } catch { /* offline: fall through */ }
  return toControls(DEFAULT_ACTIONS);                   // 404, error, or outside StarHermit
}

let controls = await loadControls(gameScope);

window.addEventListener("keydown", (e) => {
  const action = controls.byCode.get(e.code);   // e.code, never e.key
  if (action) { e.preventDefault(); onAction(action, true); }
});
window.addEventListener("keyup", (e) => {
  const action = controls.byCode.get(e.code);
  if (action) onAction(action, false);
});

Os padrões integrados mantêm o jogo jogável offline, fora do StarHermit ou se os controles solicitação falha. Mantenha-os em sintonia com o seu control.* linhas.

Uma tela de religação. Lista actions com seus label. Mantenha o mapa de substituição completo ou leia e preserve o mapa efetivo atual antes de alterar uma ação:

async function saveBinding(slug, action, codes) {
  const current = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
  if (!current.ok) throw new Error(`Controls read failed: ${current.status}`);
  const bindings = Object.fromEntries((await current.json()).actions.map(a => [a.action, a.codes]));
  bindings[action] = codes;
  const res = await fetch(`/api/v1/games/${slug}/controls`, {
    method: "PUT",
    headers: { ...auth, "Content-Type": "application/json" },
    body: JSON.stringify({ bindings }),
  });
  if (!res.ok) throw new Error((await res.json()).error);   // e.g. a key already in use
  return res.json();                                         // the new effective map
}

PUT substitui as substituições do jogador pelas ações que você envia, então inclua todas as ações que o jogador mudou, não apenas o mais recente. O resto permanece em seus padrões. DELETE no mesmo caminho redefine tudo para os padrões.

Serialize as alterações da sua tela; duas leituras/gravações simultâneas ainda podem sobrescrever uma à outra. O SDK do navegador setControl() serializa suas próprias alterações e preserva o mapa efetivo atual. O envio do mapa efetivo fixa esses valores como substituições; usar DELETE para retornar aos padrões do manifesto.

A plataforma recusa salvar (400) isso deixaria uma chave em duas ações depois o jogador as alterações são mescladas com seus padrões. Por exemplo, vinculação jump para KeyJ enquanto fire ainda usa seu padrão KeyJ é recusado. Mostre o erro ou mova a ação conflitante no mesmo salve.

Solução de problemas

Resposta Causa Consertar
404 "Este jogo não declara controles." Não é válido control.* linha no publicado construir. Adicione linhas a starhermit.txt, compare-os as regras, e publicar uma nova compilação.
404 "Nenhum jogo com aquela lesma." O slug está errado ou o jogo não tem slug. Use o token de lançamento game_scope ou gameSlug de GET /me/github-games. Cada jogo adicionado de uma pasta local e cada jogo de repositório adicionado por um proprietário verificado possui um slug, somente para navegador ou não. Somente um envio de repositório cujo proprietário não foi verificado não possui nenhum; reivindicá-lo para conseguir um.
403 "Este token tem como escopo o jogo '…'." Um token de lançamento usado com o slug de outro jogo. Chame com o slug no token game_scope.
400 "Ação desconhecida '…' — não declarada no manifesto do jogo." PUT nomeou uma ação que o manifesto não declara. Usar action valores de GET …/controls.
400 "'…' está vinculado a '…' e '…'." Após a fusão com seus padrões, uma tecla acionaria duas ações. Mova a outra ação na mesma PUTou escolha outra chave.
400 "'…' não é um valor KeyboardEvent.code válido." Um código com espaços ou pontuação. Enviar event.code valores.
400 "A ação '…' deve vincular de 1 a 4 códigos." Uma lista vazia ou mais de quatro. Envie de 1 a 4 códigos; DELETE para redefinir.
Falta uma ação na resposta Sua linha era inválida: uma letra maiúscula ou - no nome da ação, , em vez de +, mais de 4 códigos, um código já utilizado ou após a 32ª ação. Corrija a linha e publique novamente.
Uma ligação nunca dispara O código é aceito, mas nenhuma chave o produz, como a ou space. Usar exato KeyboardEvent.code ortografia: KeyA, Space.
