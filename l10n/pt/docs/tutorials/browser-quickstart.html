Crie seu primeiro jogo de navegador hospedado

Baixe o Colecionador de Estrelas, um pequeno jogo completo com duas entradas opções: jogo por conta com salvamento na nuvem e jogo para um jogador cujo progresso é mantido apenas na memória. Experimente o jogo não assinado nesta wiki; o login da conta se torna disponível depois de publicar sua própria cópia no StarHermit.

Você precisa de uma conta StarHermit para publicar. O jogo em si não precisa de backend de servidor, dependência instalação, etapa de construção ou organização do editor.

1. Descompacte e jogue localmente

O ZIP contém index.html, app.js, style.css, starhermit.txte os dois arquivos auxiliares. Sirva a pasta extraída com um servidor estático local, por exemplo:

python3 -m http.server 8000 --directory star-collector

Aqui star-collector é a pasta para a qual você extraiu. Abrir http://localhost:8000 e escolha Jogue no modo single player (o progresso não é salvo). Clique na estrela. Voltando ao início ou recarregando inicia uma nova corrida não rastreada. Este modo não grava o progresso local nem o progresso da conta.

2. Publique a pasta distribuível

O manifesto já está na pasta raiz:

name=Star Collector Quickstart
launch=index.html
description=A small single-player game with account saves or untracked play.

Na interface de publicação de jogos do StarHermit, adicione esta pasta como um novo jogo. Toda a pasta selecionada é a construção publicada. Mantenha apenas os arquivos que você pretende servir. O equivalente da API empacota os arquivos sob client/ e envia um arquivo gzip bruto:

mkdir -p bundle/client
cp -R star-collector/. bundle/client/
cp star-collector/starhermit.txt bundle/starhermit.txt
# Write the archive outside bundle so it cannot include itself.
tar -C bundle -czf star-collector.tar.gz .

curl --fail-with-body -X POST https://api.starhermit.com/api/v1/me/github-games/upload \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H 'Content-Type: application/gzip' \
  --data-binary @star-collector.tar.gz

ACCESS_TOKEN é o token completo da sua conta, após aceitação explícita dos termos atuais. A resposta game.id, game.gameSluge o subdomínio hospedado identifica seu jogo. Abra o URL hospedado retornado. Para versões subsequentes, use o jogo ponto final do pacote em vez de criar outra listagem. Ver Publicação de CI quando estiver pronto.

3. Experimente os dois caminhos de entrada de conta

Lançamento do StarHermit: o lançador fornece #game_token=<jwt>. O ajudante o captura e remove-o do URL antes que o módulo do jogo seja executado. Escolher Continue com sua conta StarHermit.

Abra o URL hospedado diretamente: escolher Faça login com StarHermit. O seletor de provedor permite que o o jogador entra com uma conta existente ou cria uma. Ele retorna diretamente para este jogo com um escopo #access_token=<jwt>; nenhuma credencial de toda a conta é enviada para o jogo.

O jogo carrega o progresso apenas quando o jogador escolhe jogar na conta. Se os termos atuais precisarem de aceitação, ele exibe o documento como texto e oferece Aceite e continue. A aceitação envia apenas o hash da revisão exibida. Uma revisão alterada é exibida novamente para outra decisão explícita.

4. Verifique o progresso e as falhas

Colete algumas estrelas no modo conta, espere Salvoe recarregue. A contagem retorna após escolher jogo de conta. Abra uma segunda aba na mesma contagem salva: salve em uma e colete na outra. O o segundo deve mostrar um conflito e oferecer Carregue o progresso mais recente da nuvem em vez de sobrescrevê-lo.

O documento salvo é { version: 1, points: <non-negative integer> }. O jogo carrega e valida antes da gravação, usa o ETag carregado para atualizações condicionais e bloqueia gravações após uma falha na leitura. Ele salva a cada coleta e rotula os dados salvos somente após o reconhecimento. Ver a receita salvadora para formatos, migração e documentos maiores.

Selecionar jogo não rastreado descarta o token de jogador do jogo e interrompe a renovação do plano de fundo. Sem nuvem ocorre gravação de salvamento, conquista, tabela de classificação ou progresso local. Escolher o jogo de conta novamente usa faça login para obter um novo token.

5. Adapte-o ao seu jogo

Substitua o botão estrela e o esquema de progresso pelo seu jogo. Mantenha as opções de entrada, token captura, aceitação de termos explícitos, regra carregar antes de salvar, tratamento de erros e status de salvamento. Declare as ações do teclado no manifesto e leia o API de controles quando seu jogo precisa de religações. Coloque as preferências de volume e gráficos configurações.

Para resultados multijogador ou competitivos validados, adicione um script ou contêiner. O contador de nuvem deste início rápido é o progresso de propriedade do cliente, e não uma prova de uma pontuação legítima.

Arquivo Propósito
index.html, style.css Entrada, termos, jogabilidade e interface de status acessíveis
app.js Modos de entrada, consentimento explícito, validação de progresso, pontos de verificação, conflitos
starhermit-sdk.js Captura de token de lançamento, login hospedado, renovação de token
cloud-save-store.js Receita de carregamento JSON bruto/salvamento condicional
starhermit.txt Metadados de publicação pública

Ver credenciais, Convenções de API, e solução de problemas quando uma solicitação se comporta de maneira diferente do esperado.
