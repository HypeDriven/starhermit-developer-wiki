Amigos

A API de amigos gerencia solicitações de amizade e amizades aceitas. Todas as rotas estão sob api/v1/me e requer autorização. O estado de amizade bloqueia convites para jogos e também controla o acesso a salas de bate-papo abertas e salas de voz.

Os corpos de erro variam; ver Convenções de API.

Pontos finais

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/me/friend-requests JWT Envie um pedido de amizade
PEGAR /api/v1/me/friend-requests JWT Listar solicitações de amizade recebidas pendentes
PUBLICAR /api/v1/me/friend-requests/{requestId}/accept JWT Aceitar um pedido de amizade
PUBLICAR /api/v1/me/friend-requests/{requestId}/decline JWT Recusar um pedido de amizade
EXCLUIR /api/v1/me/friends/{friendUserId} JWT Desfazer amizade com um usuário
PEGAR /api/v1/me/friends JWT Listar amizades aceitas com presença

Pedidos de amizade

POST /api/v1/me/friend-requests

{ "toUserId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }

Retorna 204.

GET /api/v1/me/friend-requests

Solicitações recebidas pendentes:

[
  {
    "id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "senderUserId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "senderUsername": "pk-a1b2c3d4e5f6",
    "createdAt": "2026-07-20T09:30:00Z"
  }
]

POST /api/v1/me/friend-requests/{requestId}/accept

Retorna 204; os dois usuários se tornam amigos.

POST /api/v1/me/friend-requests/{requestId}/decline

Retorna 204.

Amigos

GET /api/v1/me/friends

Amizades aceitas. online vem da presença, currentGame de um lançamento ativo:

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

Desfaz a amizade do usuário. Retorna 204.

Como a amizade controla outros recursos

  • Convites para jogos só pode ser enviado para amigos - veja Jogos.
  • Bater papo — portões de amizade para ingressar em salas de bate-papo abertas; as regras de bate-papo exigem amizade para conversas fora do jogo. Ver Bater papo.
  • Voz — o acesso à sala de voz requer participação na conversa de chat de apoio, portanto, as regras de amizade do chat se aplicam transitivamente. Ver Voz.
  • As conversas do jogo por sessão ignoram as regras de amizade — os jogadores na mesma sessão de jogo podem usar o bate-papo/voz anexado sem serem amigos.

Tokens de lançamento no escopo do jogo

Um token de lançamento no escopo do jogo pode chamar GET /api/v1/me/friends, então um jogo pode oferecer um seletor de convite para um amigo dentro de uma sessão — a implementação de referência de xadrez o usa exatamente para isso. Os outros endpoints amigos retornam 403 para tokens de lançamento; veja as regras de esgrima do escopo do jogo em Autenticação.

Ver compatibilidade de credenciais e contratos legíveis por máquina.
