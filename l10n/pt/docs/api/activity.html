Atividade

A API de atividades cobre sessões de lançamento, tempo de jogo e feed de atividades — tanto para títulos de catálogo quanto para jogos externos (não catalogados). Todas as rotas requerem um JWT, salvo indicação em contrário.

URL base: https://api.starhermit.com. Todas as rotas estão sob /api/v1/....

Sessões de lançamento de catálogo e tempo de jogo

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/activity/launches/{id}/end JWT Encerrar uma sessão de lançamento de catálogo (204)
PEGAR /api/v1/activity/software/{softwareTitleId}/playtime JWT Meu tempo total de jogo para um título
PEGAR /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 JWT Brincadeira de amigos por um título

As sessões de lançamento são iniciadas por POST /api/v1/software/{id}/launch (ver catalog.md) e terminou aqui. Resposta durante a reprodução:

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime retorna FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

Lançamentos externos e tempo de jogo

Para jogos não catalogados (bibliotecas externas vinculadas — consulte external-libraries.md):

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/activity/external-launches JWT Iniciar uma sessão para um jogo não catalogado
PUBLICAR /api/v1/activity/external-launches/{id}/end JWT Encerre essa sessão (204)
PEGAR /api/v1/activity/external/playtime?provider=&externalId= JWT Meu tempo total de jogo para um jogo externo
PEGAR /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 JWT Tempo de jogo dos amigos para um jogo externo

POST /api/v1/activity/external-launches corpo (provider ≤ 64 caracteres, externalSoftwareId ≤ 256 caracteres, name opcional):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

Resposta:

{
  "launchId": "…"
}

Resposta de reprodução externa:

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

Feeds de atividades

Método Caminho Autenticação Descrição
PEGAR /api/v1/activity/game-feed?key=&limit=20 JWT Sessões de amigos e eventos de classificação para uma chave de jogo
PEGAR /api/v1/activity/friends?since=&until=&limit= JWT Atividade dos amigos
PEGAR /api/v1/activity/public?since=&until=&limit= Anônimo Atividade pública
PEGAR /api/v1/me/activity?since=&until=&limit= JWT Minha própria atividade

O feed do jogo retorna GameFeedItemDto[] para uma chave de jogo (um guia de catálogo ou "provider:externalId", ver catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public, e me/activity retornar ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

Atividade type valores: "download", "launch", "external_launch".

/activity/friends é fechado por tipo de atividade no proprietário configuração de privacidade: lançamentos a seguir recentLaunchActivity, downloads seguem recentDownloads. Cada um é incluído quando o nível é FriendsOnly ou Public. Uma conta que nunca escolheu recebe os padrões (lançamentos compartilhados com amigos, downloads privados). Um documento de privacidade ilegível é tratado como totalmente privado. Ver profile.md.

Ver Convenções de API para análise de erros.
