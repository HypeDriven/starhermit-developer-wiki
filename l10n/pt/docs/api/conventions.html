Convenções de API

REST usa https://api.starhermit.com/api/v1/...; uso de soquetes wss://api.starhermit.com/ws/v1/.... Os jogos hospedados podem ligar /api/v1/... e /ws/v1/... na sua própria origem. Os clientes nativos usam o origem da API pública. Uma página de desenvolvimento em outra origem precisa de uma origem CORS permitida no jogo anfitrião; definir apenas um URL base do SDK não autoriza essa origem.

Solicitações e respostas

Enviar JSON com Content-Type: application/json, exceto uploads de pacotes gzip brutos. Nomes de membros JSON são camelCase. Envie credenciais de portador no REST Authorization cabeçalho.

Resposta Como ler
200 / 201 JSON Analise o objeto ou array documentado; tolerar campos adicionais
204 Sucesso sem corpo; não ligue response.json()
302 Redirecionamento de login/confirmação do navegador; navegar em vez de buscar páginas OAuth
304 Leitura condicional inalterada; reter os dados que você já possui
Imagem, anexo, salvamento na nuvem Leia bytes usando o tipo de conteúdo de resposta e o contrato de endpoint
Erro Leia o status primeiro e depois analise o corpo defensivamente

A forma de erro comum é { "error": "...", "code": "..." }, com campos opcionais dependendo o ponto final. error muitas vezes é legível por humanos; code é um discriminador estável quando fornecido. Os termos e alguns outros pontos finais colocam um discriminador diretamente error. Alguns endpoints retornam simples texto, um corpo vazio ou um objeto de validação de Detalhes do Problema com title, status e errors. Os clientes não devem presumir que todas as respostas malsucedidas são JSON ou possuem os mesmos campos.

export async function readResponse(response) {
  if (response.status === 204 || response.status === 304) return null;
  const text = await response.text();
  let body;
  try { body = text ? JSON.parse(text) : null; } catch { body = text || null; }
  if (!response.ok) {
    const message = (body && typeof body === 'object' && (body.error || body.message || body.title))
      || (typeof body === 'string' && body) || response.statusText;
    throw Object.assign(new Error(message), {
      status: response.status, code: body?.code, body,
      retryAfter: response.headers.get('Retry-After'),
    });
  }
  return body;
}

Tempo, tamanhos e nulos

  • createdAt, updatedAt, finishedAte carimbos de data/hora de conta/recurso semelhantes são strings ISO 8601 com um deslocamento. Tratar ausente ou null valores opcionais como indisponíveis.
  • ctx.now, summary.deadline, lista de sessões deadline, e /time.serverTime são inteiros Unix milissegundos. Converter com new Date(value), não Date.parse(value).
  • Os valores limite em bytes são bytes, não caracteres Base64. Um upload JSON Base64 é maior que seu conteúdo decodificado. Use o limite efetivo relatado por um endpoint, quando disponível.
  • Omissão, nulle um objeto vazio não são universalmente equivalentes. Configurações PATCH remove um chave nomeada com null; configurações de tecla única PUT lojas null como um valor. Coleção PUT substitui todo o mapa. Leia as regras de atualização de cada endpoint.
  • Um patch de configurações é mesclado chaves de nível superior. Um valor de objeto fornecido substitui o valor dessa chave; ele não mescla recursivamente propriedades aninhadas.

Paginação

A paginação é baseada em onde page/pageSize são suportados. APIs diferentes têm deliberadamente diferentes envelopes de resposta; não reutilize um analisador que assume um único nome de campo de contagem.

Área Forma de coleção Tamanho de página padrão/máximo
Títulos e compilações de software { items, totalCount, page, pageSize } 20 / 100
Mensagens de bate-papo { conversationId, items, totalCount, page, pageSize } 50 / 100
Entradas na tabela de classificação { items, total, page, pageSize } 20 / 100
Software externo { items, total, page, pageSize } 20; solicite um tamanho de página pequeno e positivo
Relatórios, registros de falhas de contêineres, listas de moderação { items, total, page, pageSize } 20 / 100
Sessões, amigos, listas de jogos, conquistas Matrizes Limites específicos de endpoint; nenhum cursor genérico da próxima página
Feed de retirada de moderação Baseado em cursor Mantenha o cursor retornado; recuperar de 410 conforme documentado

Os metadados da paginação de resposta refletem a página veiculada, quando disponível. Páginas de referência e contratos legíveis por máquina descrever parâmetros de consulta específicos do endpoint.

Nova tentativa e simultaneidade

Situação Ação
Token de acesso à conta rejeitado com 401 Atualize uma vez, usando uma solicitação de atualização compartilhada; então faça login se for recusado
O token de lançamento expirou Obtenha um novo token através do login/lançador; tokens expirados não podem ser renovados
403 terms_acceptance_required Exibir e aceitar explicitamente os termos atuais e tentar novamente
Outro 403 Resolver escopo, associação, permissões ou status da conta; não atualize em um loop
409 Resolver conflitos de duplicação/estado/revisão; releia antes de alterar um recurso
Salvar na nuvem 412 Carregue a versão mais recente e deixe o jogo fundi-la ou adotá-la
429 ou temporário 503 Honra Retry-After, adicione jitter e novas tentativas vinculadas
Falha de rede durante uma gravação O resultado pode ser desconhecido; inspecionar o estado do recurso antes de repetir a ação

Retry-After pode ser segundos ou uma data HTTP. Não invente um cabeçalho de idempotência: a API não prometer um mecanismo geral de chave de idempotência. Uma nova tentativa de criação de sessão ou um convite pode criar outro recurso ou conflito com o primeiro. Prefira leituras e operações explicitamente idempotentes para novas tentativas automáticas. Rotação de atualização, uploads completos, consentimento de termos e resultados de jogos terminais cada têm suas próprias regras.

Para gravações de comparação e troca, use ETags salvos na nuvem, room expectedRevisionou revisões de moderação onde suportado. Uma gravação bem-sucedida não é necessariamente uma implantação de contêiner concluída; verifique seu status antes de enviar jogadores para uma nova construção. Ver solução de problemas.
