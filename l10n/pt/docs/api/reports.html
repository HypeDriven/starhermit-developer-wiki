Relatórios de falhas e bugs

Os jogadores podem relatar uma falha ou bug dentro de qualquer jogo que tenha um slug – jogos somente para navegador incluído — usando o token de lançamento do jogo ou um token de usuário completo. O proprietário do jogo lê, faz a triagem e exclui-los através /api/v1/me/github-games/{id}/reports.

Para obter a saída do servidor e os registros de falhas do próprio jogo contêiner, consulte Servidores de jogos hospedados em contêiner — relatórios de saída e falhas do seu servidor.

Pontos finais

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/games/{slug}/reports Token de lançamento para esse jogo, ou JWT Arquivar um relatório de falha ou bug
PEGAR /api/v1/games/{slug}/reports/mine Token de lançamento para esse jogo, ou JWT Seus 50 relatórios mais recentes para este jogo, com seus status
PEGAR /api/v1/me/github-games/{id}/reports JWT (proprietário) Listar relatórios: ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
PEGAR /api/v1/me/github-games/{id}/reports/{reportId} JWT (proprietário) Um relatório, com sua lista de anexos
PEGAR /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} JWT (proprietário) Um anexo, sempre como download
CORREÇÃO /api/v1/me/github-games/{id}/reports/{reportId} JWT (proprietário) Definir status
EXCLUIR /api/v1/me/github-games/{id}/reports/{reportId} JWT (proprietário) Excluir um relatório → 204

Arquivar um relatório

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind é crash ou bug; title é obrigatório (≤200 caracteres).
  • Todo o resto é opcional. userAgent o padrão é o da solicitação User-Agent cabeçalho.
  • Resposta: 201 { "id", "kind", "status": "open", "createdAt" }.
Status Significado
400 Malformado: desconhecido kind, ausente title, base64 inválido ou não JSON
404 Jogo desconhecido ou removido
413 Descrição, contagem de anexos ou bytes de anexo acima dos limites do jogo
429 Acima do limite diário de relatórios para este jogo; ver Retry-After

Limites

Os operadores podem alterar cada um deles para toda a plataforma e para jogos individuais; o limite diário também pode ser definido para um jogador.

Limite Padrão
Relatórios por jogador, por jogo, por dia 20
Comprimento da descrição 20.000 caracteres
Anexos por relatório 4
Bytes de anexo por relatório 2 MiB
Relatórios mantidos por jogo 2,000
Bytes mantidos por jogo 256 MiB
Retenção 90 dias

Quando um jogo atinge seu limite de armazenamento, os relatórios mais antigos — os resolvidos primeiro — são removidos para abra espaço. Um único relatório maior que todo o limite de bytes por jogo é recusado com 413.

Relatórios de triagem (proprietário do jogo)

A lista retorna { "items", "total", "page", "pageSize" }; cada item traz o nome do repórter, kind, status, title, detalhes do cliente e sua contagem de anexos. Mover um relatório open → acknowledged → resolved com:

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

Os anexos são servidos como downloads (Content-Disposition: attachment, nosniff, uma caixa de areia CSP). Somente tipos inertes mantêm seu tipo de conteúdo declarado — texto, JSON, PNG, JPEG, WebP, GIF, zip e gzip; qualquer outra coisa, incluindo marcação, é servida como application/octet-stream.

Do SDK JavaScript

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports
