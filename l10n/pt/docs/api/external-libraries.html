Bibliotecas Externas

Vincular a biblioteca Steam, Epic ou GOG de um usuário para que seus jogos externos possam ser listados, iniciados e rastreados. Todas as rotas requerem um JWT.

URL base: https://api.starhermit.com. Todas as rotas estão sob /api/v1/....

Vinculando e desvinculando

Método Caminho Autenticação Descrição
PEGAR /api/v1/me/external-libraries JWT Listar meus provedores vinculados
PUBLICAR /api/v1/me/external-libraries/link JWT Vincule um provedor e sincronize seus títulos
EXCLUIR /api/v1/me/external-libraries/{provider} JWT Remover um link e suas propriedades

Bibliotecas vinculadas:

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

Corpo do link:

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

Retorna 204. A vinculação também sincroniza os títulos do provedor. A sincronização da biblioteca atualmente retorna títulos de demonstração para steam/epic/gog enquanto as integrações reais do provedor são finalizadas.

Software externo próprio e lançamento

Método Caminho Autenticação Descrição
PEGAR /api/v1/me/external-software?provider=&page=&pageSize= JWT Lista paginada dos meus títulos externos
PUBLICAR /api/v1/external-software/{ownershipId}/launch JWT Obtenha um URI de lançamento e registre um lançamento externo

Lista de software externo:

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

Resposta de lançamento:

{
  "launchUri": "steam://run/…"
}

Inicie formatos de URI por provedor: steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. O lançamento registra uma atividade de lançamento externa — consulte activity.md. Jogos externos usam a chave de jogo uniforme "provider:externalId" para classificações e feeds - consulte catalog.md.

Ver Convenções de API para análise de erros.
