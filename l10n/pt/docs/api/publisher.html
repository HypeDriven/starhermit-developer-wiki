Editor

A superfície do editor: gerencie organizações e membros de editores, crie e carregue títulos e compilações de software e gerencie conquistas, direitos e definições de placar para seus títulos.

Publicar um jogo em vez de um título de catálogo? Você não precisa de nada disso. O dono de um jogo com script ou back-end de contêiner é seu editor e gerencia suas tabelas de classificação e conquistas sob /api/v1/me/github-games/{id}/… - ver Tutorial: tabelas de classificação e conquistas para o seu jogo.

URL base: https://api.starhermit.com. Todas as rotas requerem um JWT mais as reivindicações de permissão listadas. Funções: PublisherMember, PublisherOwner. As reivindicações de permissão são atribuídas por meio de funções; os tokens cunhados carregam as reivindicações de permissão.

Editores e membros

Prefixo da rota: api/v1/publisher.

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/publisher JWT (Permission-publisher.content.manage) Crie um editor; o criador se torna um membro com função "Owner" → 201
PEGAR /api/v1/publisher JWT (Permission-publisher.content.manage) Listar editores → Publisher[]
PUBLICAR /api/v1/publisher/{publisherId}/members JWT (Permission-publisher.members.manage) + papel Owner Adicionar um membro → 204
EXCLUIR /api/v1/publisher/{publisherId}/members/{memberUserId} JWT (Permission-publisher.members.manage) + papel Owner Remover um membro → 204 (o proprietário não pode ser removido)
PEGAR /api/v1/publisher/{publisherId}/members/{memberUserId} JWT (Permission-publisher.members.manage) + adesão a essa editora Obtenha um membro → PublisherMember

Quem pode mudar de membro

A solicitação de permissão diz que você pode gerenciar membros editores em algum lugar; não diz qual editor. Portanto, ambas as verificações se aplicam:

  • Adicionar e remover membros é Owner-apenas. A associação confere autoridade de gerenciamento de conteúdo cada um dos títulos da editora, então um membro simples que pudesse adicionar membros poderia conceder isso autoridade para ninguém. Um não-proprietário obtém 401.
  • A leitura de uma assinatura exige pertencer a esse editor. Um chamador de fora recebe o mesmo 404 como um usuário que não é membro, então o endpoint não revela nada sobre editores que você não é parte de.

Crie um editor

POST /api/v1/publisher

{
  "name": "HypeDriven",
  "description": "..."
}

O criador se torna um membro com função "Owner".

Adicionar um membro

POST /api/v1/publisher/{publisherId}/members

{ "userId": "<user id>" }

Títulos e compilações de software

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/publisher/software JWT (Permission-publisher.content.manage) Criar/atualizar um título de software (corpo = metadados do título; adesão ao editor real do título é obrigatória)
PUBLICAR /api/v1/publisher/software/upload JWT (Permission-publisher.content.manage + Permission-publisher.binary.publish) Obtenha URLs de upload para um título → UploadUrlInfo[]
PUBLICAR /api/v1/publisher/software/build/finalize JWT (Permission-publisher.content.manage + Permission-publisher.binary.publish) Finalize uma compilação a partir de recursos carregados → 204
PEGAR /api/v1/publisher/analytics/downloads?publisherId= JWT (Permission-publisher.content.manage) Contagem de downloads por título
PEGAR /api/v1/publisher/analytics/launches?publisherId= JWT (Permission-publisher.content.manage) Contagens de lançamento por título

A publicação de uma compilação precisa da concessão de publicação binária

Os dois endpoints de compilação exigem publisher.binary.publish em cima de publisher.content.manage e associação à editora do título. Sem isso ambos respondem 403, enquanto todos os outros endpoints desta página continuam funcionando — você pode criar e editar títulos, definir conquistas e tabelas de classificação e direitos a subsídios; você simplesmente não pode enviar um executável.

A razão é o que é uma construção. Os ativos de uma compilação são baixados pelo cliente de desktop e executados no máquina do jogador com os privilégios do jogador, fora de qualquer controle da sandbox Starhermit - ao contrário de um jogo de navegador, que roda no navegador. Portanto, o direito de publicar um é concedido por conta por um Administrador Starhermit (o BinaryPublisher função), não adquirida através da criação de um editor. Não outro papel o carrega. Peça a concessão a um administrador antes de criar um fluxo de upload esses pontos finais; ele também é removido quando a conta de um editor é suspensa.

Os jogos de navegador não precisam de nada disso: /api/v1/me/github-games envios, uploads de pastas e pacotes pushes permanecem autoatendidos para qualquer conta conectada.

Crie ou atualize um título de catálogo

POST /api/v1/publisher/software aceita id (omitir para um novo título), publisherId, name, description, category, platform, releaseStatus, tags, e priceCents:

{
  "publisherId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "name": "Orbit League",
  "description": "A space racing game.",
  "category": "game",
  "platform": "windows",
  "releaseStatus": "released",
  "tags": ["racing"],
  "priceCents": 0
}

O sucesso é 201 com o título. Somente metadados de título são aceitos; não envie associação de editor ou objetos de ativos aqui. Criando devoluções de editor 201 sem objeto de editor; lista GET /api/v1/publisher para obter seu ID.

Obtenha URLs de upload

POST /api/v1/publisher/software/upload

{ "titleId": "<title id>" }

Resposta - UploadUrlInfo[]:

[
  {
    "type": "executable",
    "uploadUrl": "...",
    "fieldKey": "..."
  }
]

type é um dos "executable", "data", "metadata".

Finalizar uma compilação

POST /api/v1/publisher/software/build/finalize → 204

{
  "titleId": "<title id>",
  "buildId": "<optional build id>",
  "version": "1.0.0",
  "releaseNotes": "...",
  "assets": [
    { "type": "executable", "checksum": "...", "fieldKey": "..." }
  ]
}

O fluxo de trabalho de criação de catálogo é atualmente uma versão prévia e não fornece entrega binária de produção ou uma garantia de verificação de conteúdo ou verificação de malware. Não trate uma construção ou ativo aceito status como prova de que um executável é seguro. Ver disponibilidade de recursos. A publicação de jogos hospedados usa o API de upload de jogos.

Análise

Ambos os endpoints retornam um ID de título de mapeamento de objeto JSON para contar:

{ "<titleId>": 42 }

Conquistas

Rota api/v1/publisher; todas as rotas de gerenciamento de conquistas exigem Permission-publisher.content.manage.

Esses endpoints gerenciam título do catálogo apenas conquistas. Eles também exigem que o chamador seja um membro da editora proprietária do título, e eles falhar fechado para conquistas que pertencem a um jogo autoritário — eles são declarados pelo script do jogo ou pelo back-end do contêiner e não são gerenciado pelo editor (consulte Conquistas, Scripts de jogos, e Servidores de jogos em contêiner).

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/publisher/titles/{titleId}/achievements JWT Crie uma conquista → AchievementDto
PEGAR /api/v1/publisher/titles/{titleId}/achievements JWT Liste as conquistas de um título → AchievementDto[]
PEGAR /api/v1/publisher/achievements/{id} JWT Obtenha uma conquista → AchievementDto
COLOCAR /api/v1/publisher/achievements/{id} JWT Atualização (todos os campos anuláveis) → AchievementDto
EXCLUIR /api/v1/publisher/achievements/{id} JWT Excluir → 204

Crie uma conquista

POST /api/v1/publisher/titles/{titleId}/achievements

{
  "key": "first_win",
  "name": "First Win",
  "description": "Win your first game.",
  "icon": "...",
  "secret": false,
  "points": 10,
  "visibility": "...",
  "criteria": "..."
}

icon, visibility, e criteria são opcionais. Sobre PUT, todos os campos são anuláveis. Ver achievements.md para a superfície voltada para o jogador.

Direitos

Rota api/v1/publisher/entitlements; ambas as rotas exigem Permission-publisher.content.manage.

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/publisher/entitlements/grant JWT Conceda um título a um usuário → 204
PUBLICAR /api/v1/publisher/entitlements/revoke JWT Revogar um título de um usuário → 204

Corpo para ambos:

{
  "userId": "<user id>",
  "softwareTitleId": "<title id>"
}

Tabelas de classificação

Rota api/v1/publisher/leaderboards; todas as rotas exigem Permission-publisher.content.manage.

Método Caminho Autenticação Descrição
PUBLICAR /api/v1/publisher/leaderboards/ JWT Crie uma definição de placar → LeaderboardDefinitionDto
PEGAR /api/v1/publisher/leaderboards/{id} JWT Obtenha uma definição → LeaderboardDefinitionDto
COLOCAR /api/v1/publisher/leaderboards/{id} JWT Atualização (todos os campos anuláveis) → LeaderboardDefinitionDto
EXCLUIR /api/v1/publisher/leaderboards/{id} JWT Excluir → 204

Crie uma tabela de classificação

POST /api/v1/publisher/leaderboards/

{
  "name": "Global Elo",
  "scoreType": "...",
  "sortDirection": "...",
  "resetSchedule": "...",
  "minScore": 0,
  "maxScore": 4000,
  "scope": "...",
  "region": "...",
  "isActive": true,
  "softwareTitleId": "<optional title id>"
}

resetSchedule, minScore, maxScore, region, e softwareTitleId são opcionais. Sobre PUT, todos os campos são anuláveis. resetSchedule é daily, weekly, monthly ou never; qualquer outra coisa é um 400 - ver Redefinir programações. Ver leaderboards.md para a superfície voltada para o jogador.

Publicar uma compilação: fluxo

  1. Mantenha a concessão de publicação binária: as etapas 3 e 5 exigem publisher.binary.publish, que um Concessões de administrador Starhermit por conta. Ver A publicação de uma compilação precisa da concessão de publicação binária.
  2. Crie um editor: POST /api/v1/publisher com { name, description }.
  3. Crie o título: POST /api/v1/publisher/software com os metadados do título abaixo.
  4. Obtenha URLs de upload: POST /api/v1/publisher/software/upload com { titleId }.
  5. Carregar arquivos para o devolvido uploadUrls.
  6. Finalizar a construção: POST /api/v1/publisher/software/build/finalize com os recursos enviados' { type, checksum, fieldKey } entradas.
  7. Verifique a disponibilidade de distribuição: a visualização atual do catálogo não garante downloads de produção verificados ou verificação de malware; ver disponibilidade.
  8. Os usuários reivindicam e baixam o título através do catálogo - veja catalog.md.

Os corpos de erro variam; ver Convenções de API.
