Motor

Onde obter o mecanismo StarHermit, o tempo de execução que reproduz jogos de roteiro. A API da plataforma é o lugar para encontrar lançamentos: ela lista todos os lançamentos, diz quais são revogados e fornece os URLs e hashes dos arquivos de cada versão. As leituras são anônimas.

URL base: https://api.starhermit.com. Todas as rotas estão sob /api/v1/....

Método Caminho Autenticação Descrição
PEGAR /api/v1/engine/releases Anônimo Cada lançamento, a versão mais recente primeiro, incluindo as revogadas
PEGAR /api/v1/engine/releases/{version} Anônimo Um lançamento por sua versão exata (X.Y.Z), ou 404 
{"releases": [{
  "version": "1.38.0", "api": {"major": 1, "minor": 38}, "revoked": false, "date": "2026-11-06T05:16:08Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.38.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"linux-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.38.0/native/linux-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} responde a um desses objetos sem o releases invólucro. URLs apontam para wiki.starhermit.com para lançamentos recentes e em engine.starhermit.com para os mais velhos; use-os como dados.

  • api é a API host que o lançamento oferece. Seu major é o major do lançamento e o engine.api um declarações do jogo; seu menor cresce à medida que membros são adicionados (um jogo pode exigir um com engine.minor).
  • revoked: true vem com um revokedReason. Uma versão revogada permanece listada para que os clientes possam dizer o motivo eles recusam.
  • web é null para uma versão sem tempo de execução da web. manifestIntegrity é o hash SRI da web tempo de execução manifest.json, o valor que uma página do carregador fixa.
  • native tem uma entrada por plataforma (windows-x86_64, linux-x86_64, macos-x86_64, macos-aarch64), ou é {}. manifestSha256 é o hexadecimal SHA-256 da plataforma native.json; verifique antes de confiar na lista de arquivos contida.

Ambas as rotas enviam Cache-Control: public, max-age=60 com um ETag e responda 304 para uma correspondência If-None-Match. Se a plataforma ainda não leu a lista de lançamentos desde que começou, eles respondem 503 com Retry-After.

Uma versão publicada nunca muda: uma correção é a próxima versão. O motor tutorial descreve o lançamento mais recente; esta API diz qual isso é.

Baixe o mecanismo

Os desenvolvedores baixam o tempo de execução nativo de uma versão para escrever, verificar, empacotar e jogar. Os jogadores fazem nada: o cliente StarHermit e a página do jogo buscam a liberação dos pins do jogo.

  1. Solicite à API o lançamento, o mais novo ou aquele dos pins do seu jogo:

    curl -s https://api.starhermit.com/api/v1/engine/releases/1.38.0

  2. Leve a sua plataforma native.<platform>.manifestUrl, busque isso native.json e verifique seu SHA-256 contra manifestSha256.

  3. native.json's downloads nomeia o download do desenvolvedor com seu size e sha256. O arquivo senta ao lado native.json: substituir native.json no final de manifestUrl com o arquivo nome. Faça o download e verifique seu SHA-256.

As mesmas etapas de um script (precisa curl, jq e sha256sum; no uso do macOS shasum -a 256):

version=1.38.0 platform=linux-x86_64   # or windows-x86_64, macos-x86_64, macos-aarch64
release=$(curl -fsS "https://api.starhermit.com/api/v1/engine/releases/$version")
manifest_url=$(jq -r --arg p "$platform" '.native[$p].manifestUrl' <<<"$release")
manifest_sha=$(jq -r --arg p "$platform" '.native[$p].manifestSha256' <<<"$release")
curl -fsSO "$manifest_url"
echo "$manifest_sha  native.json" | sha256sum -c -
archive=$(jq -r '.downloads | keys[0]' native.json)
curl -fsSO "${manifest_url%native.json}$archive"
echo "$(jq -r --arg a "$archive" '.downloads[$a].sha256' native.json)  $archive" | sha256sum -c -

No PowerShell, Invoke-RestMethod lê o comunicado e Get-FileHash -Algorithm SHA256 dá o hash para comparar. O tutorial cobre desembalagem e a primeira corrida.

O ferramentas de desenvolvedor independentes (publicação automatizada e um servidor MCP de desenvolvimento) são lançados separadamente do tempo de execução.

Integridade

Uma cadeia de hashes cobre cada byte que um cliente executa:

  1. A API fornece o SHA-256 de uma versão native.json.
  2. native.json fornece o SHA-256 e o ​​tamanho de cada arquivo, e o download do desenvolvedor está em downloads.
  3. O cliente StarHermit busca apenas as partes de uma versão que ainda não possui, verifica cada uma, reúne todos os arquivos e os verifica antes de colocar a versão no lugar.

A página de carregamento de um jogo de navegador fixa o tempo de execução da web starhermit.js e manifest.json com SRI hashes e o tempo de execução verifica todos os outros arquivos carregados no manifesto.

O tempo de execução da web

A página de carregamento de um jogo (index.html, escrito por starhermit package --web) cargas starhermit.js e manifest.json de https://engine.starhermit.com/engine/X.Y.Z/, com os mesmos hashes SRI que o URLs abaixo web.base. Usar engine.starhermit.com em qualquer página do carregador que você mesmo escreve: ela mantém cada versão, enquanto os URLs em web.base mantenha apenas os recentes e uma versão antiga desaparecerá deles. Ferramentas de gravação 1.26.0 engine.starhermit.com por padrão (--loader-base URL ou STARHERMIT_WEB_LOADER_BASE substitui). Para um jogo hospedado empacotado por ferramentas mais antigas, a plataforma reescreve os dois URLs do mecanismo quando a versão não está mais sob web.base; reempacotar jogos hospedados em outro lugar. Uma liberação revogada não é veiculada em nenhuma das origens.

Jogos de script na plataforma

Quando a raiz de um jogo starhermit.txt declara engine.version, a plataforma trata isso como um jogo de script:

  • cada publicação registra a liberação do pin dos arquivos, conforme hosting.engineVersione conjuntos hosting.deployWarning (também na resposta de um pacote push) quando esse lançamento não está listado ou é revogado. Um aviso nunca interrompe uma publicação.
  • cada página do jogo hospedado é servida com uma Política de Segurança de Conteúdo que admite apenas scripts das duas origens do motor (e do próprio motor blob: trabalhadores), então o único código é um script a página do jogo pode rodar é o motor oficial:
default-src 'self'; script-src https://wiki.starhermit.com https://engine.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com https://engine.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com https://engine.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

Uma página de um jogo de script sem construção de navegador (como a página simples que um jogo somente para Windows carrega para navegadores) não precisa de script e não é afetado.

Revogações

Uma versão considerada insegura é revogada. O cliente StarHermit não o instala ou inicia e informa ao player, os comandos de empacotamento se recusam a empacotar um jogo para ele, e a plataforma avisa os proprietários sobre jogos que fixam quando são publicados. Uma versão revogada é sempre seguida por uma versão fixa: fixe-a novamente e publicar (ver Mude para um mecanismo mais novo).
