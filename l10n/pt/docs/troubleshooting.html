Solucionar problemas de uma integração

Comece com o status HTTP, o endpoint e a família de credenciais. Reproduza a menor solicitação usando o mesmo ID e credencial do jogo e verifique o estado atual do recurso. Mantenha tokens e jogador salve dados de logs e relatórios de suporte.

Login e acesso

Sintoma Verificar Próxima ação
401 em REST Expiração do token e se é uma conta ou token de lançamento Atualize uma sessão de conta uma vez; renove um token de lançamento ainda válido ou faça login para um novo lançamento
403 terms_acceptance_required Documento atual de /api/v1/terms Exiba-o e aceite seu hash apenas na ação do jogador; tokens de lançamento de conta e jogador funcionam
403 com escopo para outro jogo game_scope versus o jogo/sala/salvamento solicitado Use seu próprio UUID de jogo e o exato game:<gameId> chave para salvar na nuvem
403 sobre /me/game-invites de um jogo O token de inicialização não consegue ler a caixa de entrada de toda a conta Enquete /games/{slug}/invites e /realtime/rooms/invites
403 oauth_session_required A ação altera as credenciais da conta Faça login através de um provedor ativo; uma sessão de chave pública pode revogar apenas sua própria chave
403 para uma conta suspensa Mensagem retornada Interromper tentativas automáticas de login/atualização; direcionar o jogador para o suporte da conta
Retornos de login direto 400 returnUrl deve ser HTTPS exatamente na origem hospedada do jogo Use o URL do jogo hospedado; um URL de desenvolvimento local não é um destino de retorno permitido
O login falha intermitentemente com Invalid signature. Desafie a serialização, especialmente + em um momento Use o exato bytes de assinatura de chave pública
Devoluções de inscrição 429 Permissão de registro de e-mail/IP Honra Retry-After; confirme o e-mail antes de enviar outro cadastro

WebSockets

A falha na atualização de um navegador geralmente aparece como um código fechado 1006, ocultando a resposta HTTP. Antes de tentar novamente, faça uma chamada REST para o mesmo jogo/sessão/sala para distinguir a autenticação, termos, associação, sessão finalizada e falhas temporárias de inicialização do servidor. Verifique a compatibilidade de compilação através de informações do jogo quando você fornece ?build=. Obtenha um novo ticket de conexão para cada upgrade.

Fechar/resultado Significado Ação
1000 Fechamento normal Pare, a menos que o player inicie explicitamente outra conexão
1001 mais erro de currículo O mundo ainda não pôde ser retomado Reconecte-se com espera após verificar o estado da sessão
1006 Perda de rede ou atualização rejeitada Verifique o estado REST e as credenciais atuais; tentativas vinculadas
1008 Violação de política ou conexão substituída Pare a reconexão automática; oferecer uma reconexão deliberada após corrigir a causa
1009 Mensagem muito grande Reduza o tamanho do quadro antes de conectar novamente
HTTP 409 build_mismatch Incompatibilidade de compilação cliente/servidor Recarregue uma compilação compatível; não invente um valor de construção correspondente
HTTP 410 session_not_active Sessão finalizada Retorne ao lobby ou replay; pare de reconectar
error: "Too many commands; slow down." Subsídio de comando durável de script Estimule comandos discretos; coloque entradas contínuas dentro data com type: "input", realtime: true

Solicite um estado completo do jogo após reconectar; não repita cegamente movimentos ou outros movimentos não idempotentes comandos. resumed significa descartar previsão e ressincronizar. abandoned é terminal. Ver Contratos WebSocket.

Publicação e inicialização de contêiner

Sintoma Verificar Próxima ação
Carregar 413 com limitBytes Subsídio efetivo de upload/hospedagem Reduza o pacote ou a árvore mesclada resultante
Grande upload HTTP 413 sem campos de erro de plataforma Limite do corpo da solicitação antes da API Usar ws/v1/game-upload; enviar complete depois de todos os bytes
Carregar 422 Layout de arquivo, arquivo de inicialização, segurança de caminho, manifesto Corrija o erro nomeado; a API espera bruto .tar.gz, não multiparte
Upload bem-sucedido, mas o servidor não está disponível Prontidão de implantação Implantação de enquetes; bytes aceitos não significam que o contêiner esteja pronto
O início da sala de contêineres retorna temporariamente 503 O servidor pode estar acordando Mantenha o lobby e tente novamente com backoff; não volte para uma simulação de cliente
Solicitações de contêiner falham na validação da chave de invocação Ambiente de inicialização e comparação exata de cabeçalho Leia a chave de invocação injetada atual; relatar falha persistente com ID do jogo e registros limpos
Falha persistente na implantação Status de implantação e registros/falhas visíveis ao proprietário Corrija a compilação ou configuração e publique uma nova versão funcional

Para um relatório de suporte útil, inclua ID do jogo, versão do cliente/compilação, endpoint e método, status/código, hora UTC aproximada, etapas de reprodução e registros higienizados relevantes. IDs de sessão/sala ajudam a localizar o recurso. Não anexe credenciais, chaves privadas ou dados salvos completos de um jogador sem o seu consentimento.
