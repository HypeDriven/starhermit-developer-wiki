Unidade SDK

O Starhermit Unidade SDK (HypeDriven/starhermit-unity-sdk) é um pacote Unity Package Manager com clientes C# assíncronos e digitados para a plataforma. Ele lida Solicitações HTTP, análise JSON, atualização de token e reconexão WebSocket.
Pacote com.starhermit.sdk, versão 0.1.0
Espaço para nome Starhermit
Linha de base da API REST v1 e WebSocket v1
Recursos REST mais recentes Usar client.Raw e modelo RawJson quando esta versão do SDK não tem nenhum membro digitado
Protocolos WebSocket todos os 6, uma classe de conexão cada
Licença MIT

O SDK é um cliente, não uma segunda implementação da plataforma. Autorização, amizade, direito, associação à sala, validação de pontuação, resultados de jogos e orçamentos de armazenamento ficam server-authoritative exatamente como documentado nas páginas abaixo — o SDK mostra a resposta do servidor e seus limites publicados, em vez de decidir ou armazenar em cache os seus próprios.

Esta página é o guia de integração. A documentação completa do pacote reside no repositório em Packages/com.starhermit.sdk/Documentation~.

Requisitos

  • Unity 2021.3 LTS ou mais recente, nível de compatibilidade de API Padrão .NET 2.1, C# 9.
  • Mono e IL2CPP, com remoção gerenciada de Desativado até Alto (o pacote envia seu próprio Runtime/link.xml).
  • Sem reflexão, sem geração dinâmica de código, sem plugin nativo obrigatório.

Cada módulo é compilado para cada destino de construção. Quando um alvo carece genuinamente de capacidade - não microfone em um servidor sem cabeça, sem cabeçalhos de handshake em um navegador – a chamada aumenta StarhermitFeatureUnavailableException com um estábulo Reason, em vez de falhar na compilação ou desabilitando recursos não relacionados.

Instalar

Gerenciador de pacotes → Adicionar pacote do URL git, ou uma entrada em Packages/manifest.json. O pacote fica em uma subpasta do repositório, então o URL precisa path=:

{
  "dependencies": {
    "com.starhermit.sdk": "https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk"
  }
}

Fixe um lançamento anexando #<tag-or-commit>:

https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk#v0.1.0

Unity desembolsa para git, portanto, um repositório privado só será resolvido se o git do editor puder autenticar de forma não interativa - uma chave SSH (git@github.com:HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk) ou um auxiliar de credencial configurado. Um caminho local ou um registro com escopo funciona da mesma maneira. Importar modifica não configurações do projeto e não realiza acesso à rede.

Crie um cliente

using Starhermit;

var client = StarhermitClient.Create(new StarhermitOptions
{
    ApiBaseUri = new Uri("https://api.starhermit.com/api/v1/"),
    GameSlug   = "83fd04b1-3cbe-4b09-a251-3733ad4b9d94",
    TokenStore = myPlatformSecureStore,
    LogLevel   = StarhermitLogLevel.Warning
});

await client.InitializeAsync();               // loads a stored session, refreshes it if expired
var me = await client.Me.GetProfileAsync();

Create não executa E/S. Nada toca a rede até que você inicialize, ligue para um serviço ou abra um conexão. A base WebSocket é derivada de ApiBaseUri (wss://<host>/ws/v1/) a menos que você defina WebSocketBaseUri você mesmo.

StarhermitClient é IDisposable: o descarte cancela solicitações em voo, fecha todas as conexões distribuído, interrompe os batimentos cardíacos e libera o áudio. Não há estado mutável estático no pacote, então dois clientes podem ser executados lado a lado em ambientes diferentes e um cliente sobrevive aos carregamentos de cena.

Um jogo publicado na plataforma é servido de https://<slug>.starhermit.com com /api e /ws proxy de mesma origem (veja Jogos GitHub). Uma compilação WebGL publicada que way deve apontar para sua própria origem para que o navegador faça chamadas de mesma origem:

ApiBaseUri = new Uri("https://83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com/api/v1/") // your game's uid

Para um back-end local, AllowInsecureTransport = true licenças http/ws. A construção do cliente recusa um endereço não HTTPS sem ele, e a validação de compilação do editor falha em uma compilação de player que não seja de desenvolvimento isso ainda está definido. Nunca desativa a validação do certificado.

Fazendo login

Os três tipos de credenciais descritos em Autenticação são tipos separados em separado armazena no SDK; ninguém pode substituir outro.

OAuth — o SDK abre o URL de autorização por meio de um arquivo injetado IStarhermitOAuthBrowser e completa a troca:

var session = await client.Auth.SignInWithOAuthAsync("google");

Usar BuildAuthorizeUri(provider) mais CompleteOAuthAsync(...) em vez disso, quando sua plataforma entrega o redirecionar de volta por meio de seu próprio link direto ou encanamento de navegador incorporado.

Chave pública — o fluxo sem senha para players incorporados, de console e de servidores dedicados (veja Servidor dedicado + integração de player incorporado). Os tipos de chave suportados são Ed25519, ECDSA-P256 e RSA-PSS; o SDK nunca gera ou armazena um chave privada, ela chama uma chave injetada IStarhermitSigner:

var session = await client.Auth.SignInWithPublicKeyAsync(signer);   // or (), using Options.Signer

Detalhes do contrato que vale a pena conhecer. A implantação verifica uma assinatura de desafio em relação à sua própria Serialização PascalCase do desafio, enquanto o JSON que você recebe é camelCase — re-serialização a resposta nunca seria verificada. StarhermitChallenge.CanonicalPayload reproduz os bytes exatos para assinar, então a assinatura feita à mão deve fazer o mesmo.

Token de lançamento do jogo - cunhado por jogo e cercado na superfície desse jogo:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();
var fenced = chess.WithLaunchToken();     // subsequent calls authorise with the launch token

A criação de um token de lançamento nunca substitui a sessão da conta. Qual credencial uma solicitação carrega é decidido pelo pipeline de solicitação, não pelo serviço que você chamou.

A atualização do token de acesso é coordenada: um 401 compra no máximo uma atualização e um replay, e simultâneo os chamadores aguardam a mesma atualização em vez de iniciar várias — com um token de atualização rotativo, um segundo a troca revogaria a família e desconectaria o jogador. Uma rejeição definitiva levanta SessionExpired uma vez; uma falha de transporte deixa a sessão intacta.

Aceitando os termos atuais

Verifique a aceitação antes de iniciar batimentos cardíacos, solicitações de jogos ou soquetes. A versão 0.1.0 tem AcceptTermsAsync, mas a descoberta de termos e campos de perfil mais recentes usa seu suporte JSON bruto:

var profile = await client.Me.GetProfileAsync(ct);
var needsAcceptance = profile.RawJson["termsAcceptanceRequired"].AsBooleanOrDefault();
var terms = await client.Raw.SendForJsonAsync(new StarhermitRequest("GET", "terms"), ct);
var textToDisplay = terms["text"].AsStringOrNull();
var displayedHash = terms["hash"].AsStringOrNull();
// Display textToDisplay. Retain displayedHash for this displayed revision.
// Only in the user's Accept handler, using an account session:
// await client.Me.AcceptTermsAsync(displayedHash, ct);

Não use um rótulo de revisão de amostra, como terms-2026-08: apenas o hash atual da API é aceito. Sobre 409, busque e exiba o novo texto para outra aceitação. Sobre 403 terms_acceptance_required, resolva a aceitação antes de tentar novamente; os tokens de lançamento do jogador também podem enviar aceitação por meio da API após consentimento explícito. Ver Perfil para o fluxo completo.

Uma sessão de ponta a ponta

O ciclo de vida de o passo a passo da integração, em C#:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();

var ticket = await chess.EnqueueMatchmakingAsync();
while (!ticket.IsMatched)
{
    await Task.Delay(TimeSpan.FromSeconds(2), ct);
    ticket = await chess.GetMatchmakingAsync(ct) ?? ticket;
}

using var game = client.CreateGameConnection(ticket.SessionId!.Value, "83fd04b1-3cbe-4b09-a251-3733ad4b9d94", useLaunchToken: true);
game.FrameReceived       += frame => ApplyServerState(frame);
game.AchievementUnlocked += unlock => ShowToast(unlock);
game.PresenceChanged     += (userId, online) => UpdateOpponentDot(userId, online);
game.ErrorReceived       += message => ShowError(message);

await game.ConnectAsync(ct);
await game.SendCommandAsync(writer =>
{
    writer.Write("type", "move");
    writer.Write("from", "e2");
    writer.Write("to",   "e4");
}, ct);

SendCommandAsync envolve a carga útil como {"type":"cmd","data":…}; SendRealtimeInputAsync é o caminho com taxa limitada para entrada contínua. A conexão não marca a lógica do jogo, prevê autoridade declarar, fabricar um resultado ou reenviar um comando possivelmente não idempotente após uma resposta ambígua desconectar – o servidor continua sendo a única autoridade sobre o que aconteceu.

Cada conexão compartilha uma máquina de estado: Disconnected, Connecting, Connected, Reconnecting, Closing, Faulted, com StateChanged, Closed e Faulted eventos, filas de saída limitadas com contrapressão explícita e envios ordenados. A reconexão usa backoff instável, readquire uma corrente token antes de cada tentativa, e para definitivamente em uma autorização ou fechamento de política em vez de martelando uma porta e fechando a plataforma. Nunca assume que a adesão sobreviveu à lacuna: cada protocolo busca novamente ou se junta novamente na reconexão.

Credenciais percorrem o Authorization cabeçalho onde a plataforma permite e ?access_token= sobre /ws/** caso contrário, porque um navegador não pode definir cabeçalhos de handshake. O token de consulta é editado de cada registro.

Assíncrono, threading e Unity

Cada operação de E/S retorna Task e dá um rastro CancellationToken. Não há async void métodos e nenhum método público bloqueia o thread de chamada.

Eventos e retornos de chamada de progresso são postados no contexto de sincronização em que o cliente foi criado. se você criá-lo no thread principal do Unity, um manipulador poderá tocar GameObjecté diretamente. Um servidor sem cabeça pode pular o salto com options.CallbackDispatcher = ImmediateCallbackDispatcher.Instance. Os retornos de chamada são ordenado por conexão, e um manipulador que lança é relatado ao diagnóstico sem parar o receber loop.

StarhermitLifecycle.Attach(client) conecta eventos de aplicativos do Unity: a pulsação de presença pausa em suspensão e envia imediatamente em currículo, e o cliente é descartado sem sincronia trabalho em rede.

Modelos nunca fazem referência GameObject, MonoBehaviour ou uma cena. StarhermitTextures converte avatar e bytes de capa em um Texture2D no thread principal — o chamador possui o resultado e deve destruí-lo.

Erros, novas tentativas e paginação

Status Exceção
400 / 422 StarhermitBadRequestException, StarhermitValidationException (erros de campo digitados por nome do fio)
401 StarhermitAuthenticationException
402 StarhermitEntitlementException
403 StarhermitAuthorizationException
404 StarhermitNotFoundException
409 StarhermitConflictException
429 StarhermitRateLimitException (carrega RetryAfter)
5xx StarhermitServerException

Cada um carrega o status, o do servidor {"error":"..."} mensagem, qualquer código legível por máquina, a solicitação identificação, Retry-After, cabeçalhos redigidos e um corpo redigido com tamanho limitado. Um pedido que nunca chegou ao Aumentos de API StarhermitTransportException ou StarhermitTimeoutException — uma falha de transporte nunca é disfarçado como uma resposta da API. O cancelamento sempre surge como OperationCanceledException.

As novas tentativas são limitadas, nervosas, honradas Retry-After até um limite e estão limitados a falhas por segundo tentativa poderia sobreviver: erros de conexão, tempos limite, 408, 429 e transitório 5xx. 403, 404, 409 e as falhas de validação nunca são repetidas, e um POST é tentado novamente apenas quando aceita AsIdempotent. Um orçamento de novas tentativas para todo o processo impede que vários clientes transformem uma interrupção em uma tempestade.

Listar retorno de endpoints StarhermitPage<T> carregando os metadados de paginação do próprio servidor, além de preguiçoso enumeração que busca uma página apenas quando ela é consumida:

await foreach (var title in client.Software.EnumerateTitlesAsync(query, cancellationToken: ct)) { … }

Os downloads são transmitidos para um IStarhermitFileStore através de um arquivo temporário, verifique um SHA-256 fornecido e são promovidos atomicamente; OpenDownloadAsync relatórios IsResumed só de verdade 206, porque anexar um arquivo inteiro a um arquivo parcial o corromperia e ainda passaria na verificação de comprimento.

Armazenando credenciais

O pacote não envia nenhuma loja que afirma ser segura. O padrão é na memória; a adesão EncryptedFileTokenStore (AES-CBC com HMAC-SHA256 sobre uma chave fornecida pela sua aplicação) está documentado como ofuscação em repouso, não como um chaveiro. Arame IStarhermitTokenStore para o próprio seguro da plataforma storage — Keychain, Keystore, o armazenamento do usuário do SDK do console. PlayerPrefs nunca é apresentado como seguro.

Tokens, tokens de atualização, chaves privadas, segredos do cliente e chaves de invocação nunca são serializados em um ScriptableObject, uma cena, Resources, um log, uma mensagem de exceção, um evento de telemetria ou uma compilação artefato. StarhermitSettings contém apenas padrões de projeto não secretos: endereços, slug, nível de log, timeout e o sinalizador de desenvolvimento.

A redação é estrutural — por cabeçalho, parâmetro de consulta e nome de membro JSON, em cada profundidade — portanto, um A credencial da qual esta versão do SDK nunca ouviu falar ainda é removida dos logs, exceções e telemetria. Os fragmentos de URL são totalmente eliminados. Nenhuma telemetria é coletada por padrão; uma pia injetada recebe nome do evento, ID da operação, duração, família de status, contagem de novas tentativas, ID da solicitação e resultado, nunca URLs, corpos ou conteúdo do jogador.

Quando a plataforma envia algo novo

Os modelos são imutáveis e mantêm o JSON do qual foram analisados, portanto, um campo adicionado à implantação após esta versão do SDK ainda pode ser lida e um endpoint que esta versão não digita ainda pode ser chamado com as mesmas credenciais, novas tentativas e redação de uma chamada digitada:

var value = profile.RawJson["shippedAfterThisSdk"].AsStringOrNull();

var json  = await client.Raw.SendForJsonAsync(
    new StarhermitRequest("GET", "some/new/route").WithQuery("page", 1), ct);

Os quadros de soquete são despachados em seu discriminador de tipo com um fallback de quadro desconhecido que preserva o carga útil, strings enum desconhecidas são mantidas como strings em vez de coagidas e um nível de privacidade desconhecido lê como o maioria interpretação privada. Optional<T> distingue omitido, nulo explícito e valor, que é o que um corpo PATCH precisa.

client.GetDiagnostics() retorna estados de conexão, profundidade de fila, contagens de reconexão, expiração de token, relógio atualização, solicitações em andamento, tentativas gastas e o último erro redigido - o instantâneo a ser anexado a um relatório de bug.

Amostras

Oito amostras são enviadas com o pacote e são compiladas em CI, portanto, não podem se desviar da API que utilizam. demonstrar: Autenticação e perfil, amigos e bate-papo, jogo de matchmaking, tempo real e retransmissão, voz, Serviços de catálogo, ferramenta de publicação e servidor dedicado.

Status de verificação

O próprio conjunto do SDK (144 testes herméticos sob dotnet test, os mesmos arquivos em execução como Unity EditMode testes) e um manifesto de cobertura gerado que falha na compilação quando uma operação de API não tem mapeamento de SDK execute em cada mudança; cinco testes adicionais leem uma implantação ativa quando apontados para uma e são ignorados caso contrário. A matriz do editor e IL2CPP compilações de players para Linux, Android e WebGL são definidas em CI, mas precisam de um build farm licenciado, portanto, o a tabela de plataforma acima indica o suporte pretendido - trate um alvo como qualificado apenas depois de ter construído para você mesmo.
