StarHermit انجن جاری کرتا ہے۔

StarHermit انجن - رن ٹائم جو چلتا ہے۔ سکرپٹ کھیل - ہے اس ویکی پر بطور ورژن شدہ، ناقابل تغیر ریلیز کے تحت شائع کیا گیا ہے۔ wiki.starhermit.com/engine/. گیمز بالکل اس کے ساتھ ایک ریلیز کو پن کریں۔ engine.version میں ان کا starhermit.txt; گیم کا صفحہ ریلیز کے ویب رن ٹائم کو لوڈ کرتا ہے۔ یہاں براؤزر میں، StarHermit Windows کلائنٹ ریلیز کا مقامی رن ٹائم انسٹال کرتا ہے اور چلتا ہے۔ اس پر گیم، اور ڈویلپرز بنانے کے لیے یہاں سے ریلیز کا رن ٹائم ڈاؤن لوڈ کرتے ہیں۔

ورژنز

رہائی ہے۔ X.Y.Z. X ہے میزبان API کا بڑا ورژن, the engine.api ایک کھیل اعلان کرتا ہے، تو ہر 1.x.x ریلیز چلتا ہے۔ engine.api=1 کھیل ریلیز میزبان API کے معمولی ورژن کو بھی ریکارڈ کرتی ہے، جو ممبروں کے شامل ہونے کے ساتھ بڑھتا ہے (ایک گیم کے ساتھ ایک کی ضرورت ہوسکتی ہے۔ engine.minor)۔ ایک شائع شدہ ریلیز کبھی تبدیل نہیں ہوتا: ایک فکس اگلا ورژن ہے۔

versions.json مستند فہرست ہے، سب سے نئی پہلی، اور انجن علاقے کا اپنا صفحہ اسی کی فہرست دیتا ہے۔

دستاویزات ہمیشہ تازہ ترین ریلیز کی وضاحت کرتی ہیں۔ یہاں کے صفحات دس تک محفوظ ہو سکتے ہیں۔ ریلیز کے شائع ہونے کے چند منٹ بعد؛ versions.json کہتا ہے کہ کون سی رہائی ہے۔ تازہ ترین

ریلیز نوٹس

1.4.0

میزبان API 1.8۔ پہلے کی ریلیز پر پن کی گئی گیمز اس پر چلتی رہیں۔ ان کو استعمال کرنے کے لیے دوبارہ پن کریں۔

  • JS SDK کے کھلاڑیوں کو اوپر لے جائیں۔: کلاؤڈ کو بچانے والے انجن نے نہیں لکھا (جے ایس ایس ڈی کے کی تعمیر) نہیں ہے۔ ایک طویل غلطی. saves.foreign() اس کا دیتا ہے { text, bytes }محفوظ ریاست ہے "foreign"، اور کچھ بھی نہیں ہے۔ اس وقت تک اپ لوڈ کیا جاتا ہے جب تک کہ گیم اسے ہجرت کر کے کال نہ کرے۔ saves.save(data, { replaceForeign: true })، جو بدلتا ہے۔ صرف وہی ورژن جو اسے دکھایا گیا تھا۔ settings.legacyKeys(), legacy(key), removeLegacy(key) اور onLegacy گیم کی اپنی پرانی سیٹنگ کیز کو پڑھیں اور ہٹا دیں (باہر game.).
  • کمپریشن: compress اور decompress ("gzip", "deflate", "deflate-raw") میں starhermit:engine, مقامی طور پر اور براؤزرز میں ایک ہی بائٹس کے ساتھ پابند؛ atob اور btoa مقامی طور پر بھی.
  • پلیٹ فارم کی میزبانی کردہ ریموٹ فائلیں۔: engine.remote.urls=platform StarHermit سے گیم کی ریموٹ فائلز پیش کرتا ہے۔ کھیل کی اپنی اصل کے تحت، اور cargo starhermit publish صرف ان اشیاء کو اپ لوڈ کرتا ہے جن کی گیم میں کمی ہے۔
  • اہداف پیش کریں۔: WebGLRenderTarget کے ساتھ renderer.setRenderTarget اور render ( شبیہیں، زمینی نشانات) حسب ضرورت مواد (نرم ذرات) کے لیے منظر کی گہرائی، اور میٹریل ہکس میں مزید ساخت کے نمونے لینے۔
  • UI: جب کوئی پریس اور ریلیز دو فریموں کے درمیان گر جائے تو کوئی ضائع نہیں ہوتا ہے (سست فریم پر فوری ٹیپ)؛ ui.scrollArea سکرپٹ کے ذریعہ سکرول اور پڑھا جاسکتا ہے۔ فی ویجیٹ ٹیکسٹ سائز، خاندان اور وزن، اور عام خاندان serif, monospace اور cursive.
  • براؤزرز: loadClip, loadBuffer, createImageBitmap(path) اور FontFace.load() اب نہیں بنائیں صفحہ ایک غیر منقولہ فائل کا انتظار کریں، files.fetch پیکیج فائلوں کو بازیافت کرتا ہے اور انہیں رکھتا ہے، اور زیادہ سے زیادہ 16 بازیافت کرتا ہے۔ ایک ساتھ چلائیں (باقی قطار)۔
  • براؤزرز میں کلاسک اسکرپٹس: وہ کھیل جو کلاسک اسکرپٹ لوڈ کرتے ہیں (loadClassic) اب براؤزر میں شروع کریں؛ دی صفحہ کے عالمی جیسے fetch, WebSocket اور location کھیل کے ذریعہ مقامی طور پر تفویض کیا جاسکتا ہے۔
  • رینج پڑھتا ہے۔: files.readBytes(path, offset, length) پیکیج یا ریموٹ فائل کا حصہ پڑھتا ہے۔
  • اسکرپٹس: Intl.NumberFormat کے ساتھ style: "currency" مقامی طور پر (علامتیں، اکاؤنٹنگ، CLDR 48)، اور formatToParts. اعلان کرنے والا سرور اسکرپٹ tickRateHz: 0 ضرورت نہیں onTick میں authority(), جیسا کہ پر پلیٹ فارم

1.3.0

میزبان API 1.7۔ پہلے کی ریلیز پر پن کی گئی گیمز اس پر چلتی رہیں۔ ان کو استعمال کرنے کے لیے دوبارہ پن کریں۔

  • تیز، دبلی پتلی اسکرپٹس: مقامی مترجم ایک مشینی لفظ میں اقدار رکھتا ہے اور پراپرٹی کو محفوظ کرتا ہے۔ تلاش، اور x | 0, x >>> 0 اور مستقل کی طرف سے تبدیلیاں ایک ہدایات کے طور پر چلتی ہیں۔ آبجیکٹ ہیوی گیمز کا استعمال تقریباً نصف ڈھیر، اور نقشے کی نسل تقریباً 1.2–1.3× تیزی سے چلتی ہے۔ اس کے ڈھیر کی حد سے گزرنے والا کھیل جمع کیا جاتا ہے۔ اور اس کی میزیں ختم ہونے سے پہلے ہی سکڑ گئیں۔ STARHERMIT_HEAP_CENSUS=<seconds> کے ساتھ --dev پرنٹ کرتا ہے کیا ڈھیر رکھتا ہے.
  • ریموٹ فائلیں۔ (میزبان API 1.7): engine.remote.files=, engine.remote.urls= اور engine.remote.redirects= ان فائلوں کو نشان زد کریں جو گیم کے اپنے HTTPS میزبان پیش کرتے ہیں۔ پیکیجنگ کے احکامات انہیں چھوڑ دیتے ہیں۔ اپ لوڈ کریں اور ہر ایک کو سائز اور SHA-256 انچ کے حساب سے پن کریں۔ starhermit-remote.json (--remote-out DIR ان کا لکھتا ہے ہیش کے ذریعہ اشیاء)۔ رن ٹائم انہیں بازیافت کرتا ہے، چیک کرتا ہے اور کیش کرتا ہے۔ files.fetch(paths, onProgress) انہیں بناتا ہے تیار، files.status(path) کہتا ہے کہ ایک فائل کہاں ہے، اور لوڈرز لاتے ہیں جو وہ لوڈ کرتے ہیں۔
  • اپ لوڈ کی حد: --max-upload-mib اور --max-upload-paths (یا STARHERMIT_MAX_UPLOAD_MIB / _PATHS) کھیل کی بڑھی ہوئی حدود کو پاس کریں، اور اس کے ساتھ --game-id ٹولز پلیٹ فارم کی رپورٹوں کی حدود کو پڑھتے ہیں۔
  • glTF: ڈریکو کمپریسڈ میشز (KHR_draco_mesh_compression) اور KHR_mesh_quantization کے ذریعے لوڈ GLTFLoader.
  • جیومیٹری اور مواد (میزبان API 1.7): BufferAttribute.onUpload سے جیومیٹری کی صفوں کو گراتا ہے۔ ڈھیر ایک بار جب وہ GPU تک پہنچ جاتے ہیں۔ کمپیکٹ Int8, Uint8 اور Int16 صفات چار حسب ضرورت vec4s فی مثال (setCustomAt(i, v, slot)); پہلے سے زیادہ اور ضرب ملاوٹ؛ کی طرف سے culling boundingSphere اور frustumCulled = false. 0-1 سے باہر کے عمودی رنگ اب خاموشی سے میش نہیں گراتے ہیں۔
  • ویب: صفحہ کا سٹارٹ اپ کلیئر اب خالی قرعہ اندازی جاری نہیں کرتا، لہذا WebGPU صفر کی چوٹی کی وارننگ روک دیتا ہے۔ شمار

1.2.0

میزبان API 1.6۔ 1.1.0 پر پن کی گئی گیمز 1.1.0 پر چلتی رہیں۔ ان کو استعمال کرنے کے لیے دوبارہ پن کریں۔

  • BigInt مقامی طور پر، جیسا کہ براؤزر میں: 1n << 64n اور باقی ES2022 BigInt (BigInt.asIntN, asUintN, BigInt64Array, BigUint64Array, DataView's BigInt accessors)۔ ایک BigInt زیادہ سے زیادہ رکھتا ہے۔ 220 مقامی طور پر بٹس. میزبان APIs اور JSON.stringify انکار BigInts (TypeError).
  • براؤزر میں ماڈیولز: ایک ماڈیول جو بائنڈنگ درآمد کرتا ہے اور اسے دوبارہ برآمد کرتا ہے اب لوڈ ہوتا ہے جب دو ماڈیول ایک دوسرے کو درآمد کرتے ہیں (اس کے ساتھ ناکام ہوگیا "ایکسپورٹ '…' کی وضاحت ماڈیول میں نہیں کی گئی ہے۔") کے طور پر export { x } from اور import() اس طرح کے چکر میں
  • starhermit check ماڈیولز کو لنک کرتا ہے جیسا کہ براؤزر انہیں حاصل کرتے ہیں اور ناکام ہوجاتے ہیں، فائل اور لائن کے ساتھ، جہاں a براؤزر گیم کو لوڈ نہیں کرے گا۔ بلٹ ان کے بارے میں انتباہ صرف براؤزر کے پاس ہے؛ گیم کو پرنٹ کرتا ہے۔ console آؤٹ پٹ (--quiet اسے چھپاتا ہے) اور ایک ایسا کھیل ناکام ہو جاتا ہے جو سامنے آئے گا۔ "جواب نہیں دے رہا" سکرین
  • وقت کے بجٹ: ماڈیول کی تشخیص میں 60 سیکنڈ کا ایندھن ہے (یہ 2 سیکنڈ تھا) TypedArray set اور fill قیمت صرف وہی ہے جو وہ لکھتے ہیں، اور وقت کے لیے ایک غلطی مرحلے، اس کے چلنے کا وقت اور حد کا نام دیتی ہے۔ مرحلہ وار بجٹ جاری ہیں۔ سبق.
  • 128 ری بانڈ ایبل ایکشنز تک (پلیٹ فارم پہلے 32 کو اکاؤنٹ کے ساتھ رکھتا ہے، رن ٹائم برقرار رہتا ہے۔ باقی کھلاڑی کی مطابقت پذیر ترتیبات میں) اور engine.group.<action>=Heading پر ان کو گروپ کرتا ہے اسکرین کو کنٹرول کرتا ہے۔
  • پیکیجز ترقیاتی فائلوں کو چھوڑ دیتے ہیں۔ (node_modules/, tsconfig.json, package.json، تالا فائلیں، ماخذ کے نقشے، …) اور جو کچھ بھی ہو۔ .starhermitignore فہرستیں package --web --out DIR لکھتا ہے ان کے بغیر ایک اپ لوڈ؛ جگہ پر لکھا ہوا انڈیکس ان کے نیچے درج کرتا ہے۔ "excluded".
  • صفحہ: پیکیجنگ کے بعد تبدیل ہونے والی فائل کا نام ایرر اسکرین پر درج کیا گیا ہے۔ اصل سائز اور SHA-256؛ لوڈر گیم کے آئیکن کو نام دیتا ہے (نمبر /favicon.ico درخواست؛ ایک براؤزر WebGPU یا WebGL 2 کے بغیر ایک واضح پیغام ملتا ہے۔
  • حسب ضرورت مواد (میزبان API 1.6): گیم WGSL ورٹیکس اور سطح کے ہکس معیاری، جسمانی، لیمبرٹ اور بنیادی مواد اور ایک ShaderMaterial, انجن کے ذریعے چیک کیا گیا اور سینڈ باکس کیا گیا۔ ایک additive سطح ہک پر MeshBasicMaterial چمک دیتا ہے.
  • مناظر اور اوزار (میزبان API 1.5): GLTFLoader میں starhermit:scene, engine.setBusy(label) لمبے کام کے لیے جسے کاٹا نہیں جا سکتا، اسکرپٹ ڈھیر ہو جاتا ہے۔ engine.stats()، اور ایک نمونہ لینے والا پروفائلر (STARHERMIT_SAMPLE کے ساتھ --dev).
  • تیز تر اسکرپٹس: ٹائپ شدہ سرنی 25-30% تیزی سے اور Math بلٹ ان کمپیوٹڈ ان لائن۔

1.1.0

ویب رن ٹائم: گیمز اس ویکی کی انجن فائلوں سے براؤزرز میں چلتی ہیں، جو SRI کے ذریعے پن کی گئی ہیں، آن لائن کے ساتھ پلے، آواز اور بنڈل لبریشن اور ڈیجاوو فونٹس؛ starhermit package --web ایک فولڈر لکھتا ہے۔ براؤزرز اور کلائنٹ کے لیے۔

1.0.0

پہلی ریلیز: ونڈوز (x86-64) رن ٹائم، بغیر کسی ویب رن ٹائم کے۔

انجن کا علاقہ

engine/
  versions.json            every release: host API, date, runtimes, revocation
  X.Y.Z/
    native/windows-x86_64/
      native.json          the Windows runtime's files, each with its size, SHA-256 and chunks
      starhermit-X.Y.Z-windows-x86_64.zip
                           the developer download: the same files as one archive
    manifest.json          the web runtime's files, each with its size and sha384
    starhermit.js          the module a game's loader page loads
    starhermit.wasm, *.js  the runtime, its audio mixer and worklets
    starhermit.d.ts        the host API's declarations
    fonts/, licenses/      the runtime's fonts and every licence notice
                           (all of the web runtime only in a release that has one)
  chunks/ab/<sha256>.z     pieces of the native files, shared by every release
  patches/ab/<sha256>.p    binary patches from earlier releases' files

ہر فائل کو ویسا ہی شائع کیا جاتا ہے (کسی فائل کا نام شروع نہیں ہوتا ہے۔ _ یا .)، اور GitHub صفحات اس کی خدمت کرتے ہیں۔ کے ساتھ Access-Control-Allow-Origin: *.

versions.json

{
  "format": 2,
  "versions": [
    {
      "api": {"major": 1, "minor": 4},
      "date": "2026-10-20T13:55:50Z",
      "native": {
        "windows-x86_64": {"manifest": "1.1.0/native/windows-x86_64/native.json", "sha256": "<SHA-256 of native.json>"}
      },
      "revoked": false,
      "version": "1.1.0",
      "web": {"manifest": "sha384-<SRI hash of manifest.json>"}
    }
  ]
}

web ہے {"manifest": "sha384-…"}، ریلیز کے ویب کا SRI ہیش manifest.json، یا null کے لیے ویب رن ٹائم کے بغیر ریلیز۔ native ہر پلیٹ فارم کو پن کرتا ہے۔ native.json اس کے SHA-256 کے ذریعے۔ اے رہائی واپس لے لی گئی کیونکہ یہ غیر محفوظ ہے۔ "revoked": true a کے ساتھ "revokedReason"; یہ ہے صرف شائع شدہ اندراج کو تبدیل کریں۔

native.json

native.json انجن فولڈر کی فائلوں کی فہرست دیتا ہے جو کلائنٹ انسٹال کرتا ہے۔ starhermit.exe, release.json (ریلیز کا ورژن، میزبان API اور launcher پروٹوکول اس کا رن ٹائم بولتا ہے) LICENSE-engine اور فریق ثالث کے نوٹسز - ہر ایک اس کے ساتھ size, sha256 اور chunks. ایک ٹکڑا فائل کا ایک حصہ ہے، zlib-compressed کے طور پر ذخیرہ کیا گیا ہے۔ chunks/<first two hex digits>/<sha256>.z اور نام دیا اس کے غیر کمپریسڈ بائٹس کے SHA-256 کے ذریعے؛ حصہ کی حدیں مواد کی پیروی کرتی ہیں، لہذا ایک غیر تبدیل شدہ اسٹریچ اپنا حصہ ایک ریلیز سے دوسرے تک رکھتا ہے۔ جہاں یہ چھوٹا ہے، وہاں ایک فائل بھی درج ہے۔ patches پہلے کی ریلیز کی اسی فائل سے ("from": پہلے کی فائل کا SHA-256)۔ downloads اس کے ساتھ ڈویلپر ڈاؤن لوڈ کی فہرست دیتا ہے۔ size اور sha256; کلائنٹ اسے کبھی انسٹال نہیں کرتے۔ ویب رن ٹائم کے ساتھ ریلیز میں مقامی فولڈر بھی رکھتا ہے۔ web-manifest.json، ریلیز کا ویب مینی فیسٹ، لہذا ڈویلپر بغیر نیٹ ورک کے ویب کے لیے پیکجز گیمز ڈاؤن لوڈ کرتا ہے۔

ویب رن ٹائم

ریلیز کا ویب رن ٹائم اس کے ساتھ والی فائلیں ہے۔ manifest.json، جو ہر ایک کو اس کے ساتھ فہرست کرتا ہے۔ size اور sha384 اور ریلیز کے ورژن، میزبان API اور تعمیر کو ریکارڈ کرتا ہے۔ گیم کا لوڈر صفحہ (index.html، کی طرف سے لکھا گیا starhermit package --web) کا اپنا کوئی اسکرپٹ نہیں ہے: یہ لوڈ ہوتا ہے۔ starhermit.js اور manifest.json سے https://wiki.starhermit.com/engine/X.Y.Z/ ایس آر آئی ہیشز اور انجن کے ساتھ ہر دوسری فائل لاتا ہے جس کی اسے ضرورت ہے (starhermit.wasm، آڈیو ورک لیٹس، فونٹس) اور اسے چیک کرتا ہے۔ ظاہر کے خلاف صفحہ صرف انجن چلاتا ہے — ان پٹ، رن ٹائم کے مینو، آڈیو، اسٹوریج، پلیٹ فارم سیشن اور آواز — اور گیم کا TypeScript ایک کارکن میں چلتا ہے جو یہ شروع ہوتا ہے اور روک سکتا ہے۔

ویب رن ٹائم اپنے فونٹس، لبریشن 2.1.5 (SIL اوپن فونٹ لائسنس 1.1) اور DejaVu Sans کو بنڈل کرتا ہے۔ 2.37 (بٹ اسٹریم ویرا اور آریو لائسنس)؛ ان کے نوٹسز موجود ہیں۔ licenses/ دوسروں کے ساتھ.

سالمیت

ہیشوں کی ایک زنجیر ہر بائٹ کا احاطہ کرتی ہے جو کلائنٹ چلاتا ہے:

  1. versions.json (یا نیچے پلیٹ فارم کا API) ریلیز کا SHA-256 دیتا ہے۔ native.json.
  2. native.json ہر فائل کا SHA-256 اور ہر حصہ دیتا ہے۔
  3. کلائنٹ صرف وہی ٹکڑا لاتا ہے جو اس کے پاس پہلے سے نہیں ہے، ہر ایک کے ذخیرہ شدہ سائز کو چیک کرتا ہے، فلایا ہوا سائز اور SHA-256، ہر فائل کو ایک ساتھ رکھتا ہے، فائل کے SHA-256 کو چیک کرتا ہے اور اس کے بعد ہی حرکت کرتا ہے۔ جگہ میں رہائی. ایک پیچ کو اس کے اپنے SHA-256 کے خلاف چیک کیا جاتا ہے، اور پیچ شدہ فائل کے خلاف فائل کی؛ کوئی بھی ناکامی ٹکڑوں میں واپس آتی ہے۔

ڈویلپر ڈاؤن لوڈ اس کے اندراج کے ذریعے اسی سلسلہ سے احاطہ کرتا ہے۔ downloads. ایک براؤزر گیم کا لوڈر صفحہ ویب رن ٹائم کو پن کرتا ہے۔ starhermit.js اور manifest.json SRI ہیش کے ساتھ، اور رن ٹائم ہر دوسری فائل کو چیک کرتا ہے جو مینی فیسٹ کے خلاف لوڈ ہوتی ہے۔

انجن API کو جاری کرتا ہے۔

پلیٹ فارم اس ویکی پر ہر یو آر ایل کے ساتھ ایک ہی فہرست پیش کرتا ہے، لہذا کلائنٹ API سے پوچھتے ہیں کہ کون سا انجن ہے۔ لانے کے لیے:

GET /api/v1/engine/releases → ہر ریلیز، تازہ ترین پہلے:

{"releases": [{
  "version": "1.1.0", "api": {"major": 1, "minor": 4}, "revoked": false, "date": "2026-10-20T13:55:50Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.1.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"windows-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.1.0/native/windows-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} → ایک ریلیز، یا 404 جب یہ درج نہیں ہے۔ دونوں ہیں۔ گمنام اور قابل ذخیرہ (Cache-Control: public, max-age=60 ایک کے ساتھ ETag)۔ منسوخ شدہ رہائی لے جاتا ہے revokedReason; web ہے null ویب رن ٹائم کے بغیر ریلیز کے لیے۔ جب کہ پلیٹ فارم نے فہرست کو کبھی نہیں پڑھا ہے (ویکی شروع ہونے کے بعد سے ناقابل رسائی ہے) وہ جواب دیتے ہیں۔ 503 کے ساتھ Retry-After.

پلیٹ فارم پر اسکرپٹ گیمز

جب کھیل کی جڑ starhermit.txt اعلان کرتا ہے engine.version، پلیٹ فارم اسے اسکرپٹ کے طور پر دیکھتا ہے۔ کھیل:

  • ہر ایک پبلش فائلوں کی ریلیز کو ریکارڈ کرتا ہے، جیسا کہ hosting.engineVersion، اور سیٹ hosting.deployWarning (ایک بنڈل پش کے جواب میں بھی) جب وہ ریلیز درج نہیں ہے یا ہے۔ منسوخ کر دیا ایک انتباہ کبھی بھی اشاعت کو نہیں روکتا ہے۔
  • میزبان گیم کے ہر صفحے کو مواد-سیکیورٹی-پالیسی کے ساتھ پیش کیا جاتا ہے جو صرف اسکرپٹ کو تسلیم کرتی ہے اس ویکی سے (اور انجن کا اپنا blob: ورکرز)، اس لیے اسکرپٹ گیم کا صفحہ صرف وہی کوڈ کرسکتا ہے۔ رن سرکاری انجن ہے:
default-src 'self'; script-src https://wiki.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

اسکرپٹ گیم کا ایک صفحہ بغیر براؤزر کی تعمیر کے (جیسے سادہ صفحہ صرف ونڈوز گیم اپ لوڈ کرتا ہے براؤزرز کے لیے) کو اسکرپٹ کی ضرورت نہیں ہے اور یہ غیر متاثر ہے۔

منسوخیاں

منسوخ شدہ ریلیز درج رہتی ہے تاکہ کلائنٹ کہہ سکیں کہ انہوں نے اس سے انکار کیوں کیا: StarHermit کلائنٹ اسے انسٹال یا شروع نہ کریں اور کھلاڑی کو بتاتا ہے، پیکیجنگ کمانڈز اس کے لیے گیم پیک کرنے سے انکار کرتی ہیں۔ جب وہ پڑھتے ہیں versions.json، اور پلیٹ فارم گیمز کے مالکان کو متنبہ کرتا ہے کہ جب وہ اسے پن کرتے ہیں۔ شائع کریں اس ریلیز پر دوبارہ پن کریں جو اسے بدل دے اور دوبارہ شائع کریں۔ (دیکھیں۔ ایک نئے انجن پر جائیں۔).
