انضمام کا انتخاب کریں۔

اس سے شروع کریں کہ آپ کا گیم کہاں چلتا ہے اور کون گیم پلے کی توثیق کرتا ہے۔ ایک میزبان براؤزر گیم کو ایک کی ضرورت نہیں ہے۔ سائن ان، کلاؤڈ سیو، سیٹنگز، کنٹرولز، یا ریئل ٹائم رومز استعمال کرنے کے لیے سرور بیک اینڈ۔

انضمام گیم پلے اتھارٹی ملٹی پلیئر پیش رفت اسکور اور کامیابیاں
صرف براؤزر، اسٹینڈ تنہا واحد کھلاڑی پلیئر کا براؤزر کوئی نہیں۔ تجویز کردہ غیر دستخط شدہ موڈ میں میموری میں رکھیں کوئی پلیٹ فارم نہیں لکھتا
اکاؤنٹ پلے کے ساتھ میزبان براؤزر گیم پلیئر کا براؤزر اختیاری میزبان راستے والے کمرے کلاؤڈ سائن ان کھلاڑیوں کے لیے محفوظ کرتا ہے۔ گیم کی ملکیت والے بورڈز اور کامیابیاں لکھنے کے لیے اسکرپٹ یا کنٹینر شامل کریں۔
ہوسٹ روٹڈ ریئل ٹائم کمرہ میزبان کھلاڑی کا کلائنٹ لابی، دعوتیں، جوائن کوڈ، فوری شمولیت؛ بائنری ان پٹ اور سنیپ شاٹس کلائنٹ کلاؤڈ محفوظ کرتا ہے، یا اختیاری پابند سرور سیشن ایک پابند پسدید لکھ سکتا ہے؛ اسے آزادانہ طور پر اس بات کی توثیق کرنی چاہیے کہ وہ کیا ایوارڈ دیتا ہے۔
مستند رسم الخط آپ کا گیم اسکرپٹ سیشن میچ میکنگ، دوست کی دعوتیں، پریکٹس، یا کمرہ بند میچ سیشن اور فی کھلاڑی کی حالت جو آپ کے اسکرپٹ کے ذریعے برقرار ہے۔ سرور ایلو، اسکور اور کامیابیاں لکھتا ہے۔
مستند کنٹینر آپ کا گیم سرور ایک ہی سیشن API؛ ریئل ٹائم کمرے بڑے گرڈ کو سپورٹ کرتے ہیں۔ مکمل سنیپ شاٹس اور فی کھلاڑی کی حالت سرور ایلو، اسکور اور کامیابیاں لکھتا ہے۔
کیٹلاگ کا عنوان، جیسا کہ مقامی قابل عمل آپ کا منتخب کردہ کلائنٹ/سرور فن تعمیر اکاؤنٹ کے ساتھ وہی APIs استعمال کریں یا ٹوکن لانچ کریں۔ اکاؤنٹ کلائنٹ کے ذریعہ کلاؤڈ سیو سلاٹ کا انتخاب کیا گیا ہے۔ کیٹلاگ بورڈز اور کامیابیوں کے الگ الگ ناشر اور کلائنٹ کلیم APIs ہوتے ہیں۔

تین عام نقطہ آغاز

ایک واحد کھلاڑی والا براؤزر گیم: پیروی کریں براؤزر کوئیک اسٹارٹ. پیشکش StarHermit کے ساتھ سائن ان کریں۔ اکاؤنٹ کی ترقی اور واحد کھلاڑی کھیلیں (ترقی نہیں ہے۔ محفوظ) فوری کھیل کے لیے۔ پسدید کے بغیر شروع کریں؛ جب آپ کو توثیق شدہ مسابقتی کی ضرورت ہو تو ایک شامل کریں۔ نتائج سیٹنگز اور کلاؤڈ سیو کی ضرورت نہیں ہے۔ server= لائن

دوستوں کے ساتھ آرام دہ اور پرسکون ملٹی پلیئر: استعمال کریں حقیقی وقت کے کمرے. میزبان چلاتا ہے۔ تخروپن، مہمان ان پٹ بھیجتے ہیں، اور میزبان اسنیپ شاٹس نشر کرتا ہے۔ آپ کا گیم AI اور میزبان کو لاگو کرتا ہے۔ نقل مکانی پلیٹ فارم نشستیں، شناخت اور روٹنگ فراہم کرتا ہے۔ میزبان پر اعتماد اس ماڈل کا حصہ ہے۔

درجہ بندی یا مستقل ملٹی پلیئر: استعمال کریں ایک سکرپٹ یا ایک کنٹینراگر آپ کو لابی کی ضرورت ہو تو کمروں کے ساتھ۔ پہلے گیم پلے کی توثیق کریں۔ کچھ بھی نوازنا. اسکرپٹس تائید شدہ حد کے اندر ٹک ریٹ کی درخواست کرتی ہیں (30 ہرٹز بذریعہ ڈیفالٹ)؛ کنٹینرز اپنا سمولیشن لوپ چلاتے ہیں۔ کنٹینر براہ راست میچ میکنگ فی الحال ایک مضمر ہے۔ 1v1 قطار، لیکن ایک کمرہ N-player کنٹینر سیشن بنا سکتا ہے۔

ہوسٹنگ اور پبلشنگ

آپ کی تعمیر کے ذریعے شائع کریں۔ اگلا پڑھیں
قابل تقسیم فولڈر فولڈر اپ لوڈ؛ بعد کی ریلیز بنڈل اپ لوڈز کا استعمال کرتی ہیں۔ ظاہر کرنا, API اپ لوڈ کریں۔
عوامی GitHub ذخیرہ ریپوزٹری کو رجسٹر کریں، ملکیت ثابت کریں، ایک منتخب ورژن تعینات کریں۔ GitHub گیمز
کنٹینر کی تصویر کسی گیم کو رجسٹر/اپ لوڈ کریں، پھر پن کی ہوئی رجسٹری امیج کا اعلان کریں یا پش کریں۔ server/image.tar کنٹینر پروٹوکول, CI اپ لوڈز
بیرونی / مقامی گیم کلائنٹ عوامی API کو براہ راست کال کریں؛ کھلاڑی کی اسناد کا استعمال کریں۔ پبلک کلید آن بورڈنگ, اتحاد SDK
کیٹلاگ قابل عمل پبلیشر کا عنوان/تعمیر ورک فلو؛ بائنری پبلشنگ کے لیے گرانٹ درکار ہے۔ پبلشر, موجودہ دستیابی

ایک میزبان گیم کا UUID اس کا API سلگ اور ذیلی ڈومین ہے۔ ڈسپلے کے نام اور مخزن کے نام API نہیں ہیں۔ شناخت کنندگان دیکھیں اسناد اور شناخت کنندگان وائرنگ کی درخواستوں سے پہلے۔

کلائنٹ کی ملکیت میں سائن ان ہونے کی پیشرفت game:<gameId> کلاؤڈ سیو سلاٹ پلیئر کا گیم کلائنٹ
حجم، گرافکس، رسائی، ترجیحات فی کھلاڑی گیم کی ترتیبات پلیئر کا گیم کلائنٹ
کی بورڈ اوور رائیڈ کرتا ہے۔ مینی فیسٹ ڈیکلریشنز کے بعد API کو کنٹرول کرتا ہے۔ پلیئر کا گیم کلائنٹ
توثیق شدہ میچ/عالمی ریاست اور کھلاڑی کے اعدادوشمار اسکرپٹ کی واپسی یا کنٹینر سنیپ شاٹ/نتیجہ مستند گیم پسدید

کلاؤڈ سیو میں فی سلاٹ ایک مبہم دستاویز ہوتی ہے، میچوں کی تاریخ نہیں۔ ری پلے پر مشتمل ہے۔ ختم ہونے والے سیشن کی حالت میں آپ کا پسدید برقرار رکھنے کا انتخاب کرتا ہے، نہ کہ خود بخود ریکارڈ شدہ ویڈیو یا ان پٹ ندی دیکھیں محفوظ طریقے سے بچانا اور سیشن لائف سائیکل.
