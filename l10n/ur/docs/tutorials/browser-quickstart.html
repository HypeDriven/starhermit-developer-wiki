اپنا پہلا میزبان براؤزر گیم بنائیں

اسٹار کلیکٹر ڈاؤن لوڈ کریں۔، دو اندراج کے ساتھ ایک مکمل چھوٹا کھیل اختیارات: کلاؤڈ سیو کے ساتھ اکاؤنٹ پلے، اور سنگل پلیئر پلے جس کی پیشرفت صرف میموری میں رکھی جاتی ہے۔ غیر دستخط شدہ پلے آزمائیں۔ اس ویکی پر؛ اکاؤنٹ سائن ان ہو جاتا ہے۔ StarHermit پر آپ کی اپنی کاپی شائع کرنے کے بعد دستیاب ہے۔

شائع کرنے کے لیے آپ کو StarHermit اکاؤنٹ کی ضرورت ہے۔ گیم کو خود سرور کے پسدید، انحصار کی ضرورت نہیں ہے۔ تنصیب، تعمیر قدم، یا پبلشر تنظیم.

1. ان زپ کریں اور مقامی طور پر کھیلیں

زپ پر مشتمل ہے۔ index.html, app.js, style.css, starhermit.txt، اور دو مددگار فائلیں۔ نکالے گئے فولڈر کو مقامی جامد سرور کے ساتھ پیش کریں، مثال کے طور پر:

python3 -m http.server 8000 --directory star-collector

یہاں star-collector وہ فولڈر ہے جس میں آپ نے نکالا ہے۔ کھولیں۔ http://localhost:8000 اور منتخب کریں واحد کھلاڑی کھیلیں (ترقی محفوظ نہیں ہے). ستارے پر کلک کریں۔ شروع پر واپس جانا یا دوبارہ لوڈ کرنا ایک نیا غیر ٹریک شدہ رن شروع کرتا ہے۔ یہ موڈ نہ تو مقامی پیش رفت لکھتا ہے اور نہ ہی اکاؤنٹ کی پیشرفت۔

2. قابل تقسیم فولڈر شائع کریں۔

مینی فیسٹ پہلے ہی فولڈر کی جڑ میں ہے:

name=Star Collector Quickstart
launch=index.html
description=A small single-player game with account saves or untracked play.

StarHermit کے گیم پبلشنگ UI میں، اس فولڈر کو ایک نئی گیم کے طور پر شامل کریں۔ پورا منتخب فولڈر ہے۔ شائع شدہ تعمیر. صرف وہی فائلیں رکھیں جو آپ پیش کرنا چاہتے ہیں۔ API مساوی فائلوں کو پیک کرتا ہے۔ کے تحت client/ اور ایک خام gzip آرکائیو بھیجتا ہے:

mkdir -p bundle/client
cp -R star-collector/. bundle/client/
cp star-collector/starhermit.txt bundle/starhermit.txt
# Write the archive outside bundle so it cannot include itself.
tar -C bundle -czf star-collector.tar.gz .

curl --fail-with-body -X POST https://api.starhermit.com/api/v1/me/github-games/upload \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H 'Content-Type: application/gzip' \
  --data-binary @star-collector.tar.gz

ACCESS_TOKEN واضح موجودہ شرائط کی منظوری کے بعد، آپ کا پورا اکاؤنٹ ٹوکن ہے۔ جواب ہے۔ game.id, game.gameSlug، اور میزبان ذیلی ڈومین آپ کے گیم کی شناخت کرتا ہے۔ لوٹا ہوا ہوسٹڈ یو آر ایل کھولیں۔ بعد کی ریلیز کے لیے اس گیم کا استعمال کریں۔ بنڈل اختتامی نقطہ ایک اور فہرست بنانے کے بجائے۔ دیکھیں سی آئی پبلشنگ جب تیار ہو.

3. اکاؤنٹ میں داخلے کے دو راستے آزمائیں۔

StarHermit سے لانچ: لانچر کی فراہمی #game_token=<jwt>. مددگار اسے پکڑ لیتا ہے اور گیم ماڈیول چلنے سے پہلے اسے URL سے ہٹاتا ہے۔ منتخب کریں۔ اپنے StarHermit اکاؤنٹ کے ساتھ جاری رکھیں.

میزبان یو آر ایل کو براہ راست کھولیں: منتخب کریں StarHermit کے ساتھ سائن ان کریں۔. فراہم کنندہ کا انتخاب کرنے والا اجازت دیتا ہے۔ کھلاڑی موجودہ اکاؤنٹ کے ساتھ سائن ان کریں یا ایک بنائیں۔ یہ اسکوپڈ کے ساتھ براہ راست اس گیم میں واپس آتا ہے۔ #access_token=<jwt>; گیم کو اکاؤنٹ بھر کی کوئی سند نہیں بھیجی جاتی ہے۔

گیم کی پیشرفت صرف اس وقت ہوتی ہے جب کھلاڑی اکاؤنٹ پلے کا انتخاب کرتا ہے۔ اگر موجودہ شرائط کو قبول کرنے کی ضرورت ہے، یہ دستاویز کو متن اور پیشکش کے طور پر دکھاتا ہے۔ قبول کریں اور جاری رکھیں. قبولیت صرف ہیش بھیجتی ہے۔ دکھائی گئی نظرثانی کا۔ ایک اور واضح فیصلے کے لیے ایک تبدیل شدہ نظرثانی دوبارہ دکھائی جاتی ہے۔

4. ترقی اور ناکامیوں کو چیک کریں۔

اکاؤنٹ موڈ میں چند ستارے جمع کریں، انتظار کریں۔ محفوظ کیا گیا۔، اور دوبارہ لوڈ کریں۔ گنتی منتخب کرنے کے بعد واپس آتی ہے۔ اکاؤنٹ پلے. اسی محفوظ شدہ شمار پر دوسرا ٹیب کھولیں: ایک میں محفوظ کریں، پھر دوسرے میں جمع کریں۔ دی دوسرا ایک تنازعہ اور پیشکش دکھانا ضروری ہے تازہ ترین کلاؤڈ پروگریس لوڈ کریں۔ اسے اوور رائٹ کرنے کے بجائے۔

محفوظ دستاویز ہے۔ { version: 1, points: <non-negative integer> }. گیم لوڈ اور توثیق کرتا ہے۔ لکھنے سے پہلے، مشروط اپ ڈیٹس کے لیے بھری ہوئی ETag کا استعمال کرتا ہے، اور ناکام پڑھنے کے بعد بلاکس لکھتا ہے۔ یہ ہر مجموعہ میں محفوظ کرتا ہے اور صرف اعتراف کے بعد محفوظ کردہ ڈیٹا کو لیبل کرتا ہے۔ دیکھیں بچانے کا نسخہ فارمیٹس، منتقلی اور بڑی دستاویزات کے لیے۔

غیر ٹریک شدہ پلے کو منتخب کرنے سے گیم کا پلیئر ٹوکن ضائع ہو جاتا ہے اور پس منظر کی تجدید رک جاتی ہے۔ کوئی بادل نہیں۔ محفوظ کریں، کامیابی، لیڈر بورڈ، یا مقامی-ترقی لکھنا ہوتا ہے۔ اکاؤنٹ پلے کا انتخاب دوبارہ استعمال کرتا ہے۔ نیا ٹوکن حاصل کرنے کے لیے سائن ان کریں۔

5. اسے اپنے کھیل کے مطابق ڈھالیں۔

اسٹار بٹن اور پروگریس اسکیما کو اپنے گیم پلے سے تبدیل کریں۔ اندراج کے انتخاب، ٹوکن رکھیں کیپچر، واضح شرائط کی قبولیت، لوڈ سے پہلے محفوظ کرنے کا اصول، غلطی سے نمٹنے، اور اسٹیٹس کو محفوظ کرنا۔ مینی فیسٹ میں کی بورڈ کی کارروائیوں کا اعلان کریں اور پڑھیں API کو کنٹرول کرتا ہے۔ جب آپ کے گیم کو ری بائنڈنگ کی ضرورت ہوتی ہے۔ حجم اور گرافکس کی ترجیحات درج کریں۔ ترتیبات.

ملٹی پلیئر یا تصدیق شدہ مسابقتی نتائج کے لیے، شامل کریں۔ ایک اسکرپٹ یا کنٹینر. یہ کوئیک سٹارٹ کلاؤڈ کاؤنٹر کلائنٹ کی ملکیت میں پیش رفت ہے، جائز سکور کا ثبوت نہیں۔

فائل مقصد
index.html, style.css قابل رسائی اندراج، شرائط، گیم پلے، اور اسٹیٹس UI
app.js داخلے کے طریقے، واضح رضامندی، پیش رفت کی توثیق، چوکیاں، تنازعات
starhermit-sdk.js لانچ ٹوکن کیپچر، میزبان سائن ان، ٹوکن کی تجدید
cloud-save-store.js خام JSON لوڈ/مشروط محفوظ کرنے کی ترکیب
starhermit.txt عوامی اشاعت کا میٹا ڈیٹا

دیکھیں اسناد, API کنونشنز، اور خرابیوں کا سراغ لگانا جب کوئی درخواست توقع سے مختلف سلوک کرتی ہے۔
