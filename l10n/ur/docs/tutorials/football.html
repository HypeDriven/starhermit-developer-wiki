مثال کا کھیل: فٹ بال اسٹار ہرمٹ انجن کو کس طرح استعمال کرتا ہے۔

اسٹار ہرمیٹ فٹ بال ایک عوامی، مکمل ہے سکرپٹ کھیل. یہ 1 سے 22 کھلاڑیوں کے لیے ریئل ٹائم 3D فٹ بال ہے، جس میں AI ٹیم کے ساتھی ہیں، ایک فلڈ لائٹ اسٹیڈیم، آن لائن لابیز، وائس اور ٹیکسٹ چیٹ، ری پلے، ایک لیڈر بورڈ، کامیابیاں اور نو زبانیں یہ صفحہ یہ بتانے کے لیے قدم بہ قدم الگ کرتا ہے کہ ایک حقیقی گیم انجن کو کس طرح استعمال کرتی ہے۔ ہر ایک اسٹیپ میں شامل انجن ماڈیولز کے نام اور گیم کے ماخذ سے لنک ہوتے ہیں، جہاں آپ پڑھ سکتے ہیں۔ مکمل کوڈ.

یہ واک تھرو انجن کے لیے لکھا گیا ہے۔ 1.41.0، تازہ ترین ریلیز۔ دکھائی گئی ہر کال درج ہے۔ میں انجن API کا حوالہ. پڑھیں انجن ٹیوٹوریل پہلے اگر آپ نے ابھی تک اسکرپٹ گیم نہیں بنایا ہے۔

سورس لنکس کمٹ کی طرف اشارہ کرتے ہیں۔ 33bd9bd. اس پر گیم پن انجن 1.39.0 کے ساتھ کمٹ کریں۔ engine.minor=39. یہ کچھ بھی نیا استعمال کرتا ہے، تو یہ 1.41.0 پر بغیر کسی تبدیلی کے چلتا ہے۔ اسے منتقل کرنا ایک لائن کی تبدیلی ہے۔ engine.version (دیکھیں۔ مرحلہ 12).

کھیل کی شکل

راستہ کردار
starhermit.txt مینی فیسٹ: نام، انجن پن، سرور اسکرپٹ، کنٹرولز، صلاحیتیں۔
server.js ایک میچ کا تخروپن: پلیٹ فارم کے ذریعے مستند سرور کے طور پر چلایا جاتا ہے، اور کلائنٹ کے ذریعے آف لائن مشق اور پیشین گوئی کے لیے لوڈ کیا جاتا ہے۔
engine/src/main.ts انٹری ماڈیول: لائف سائیکل کال بیکس اور اسکرین اسٹیٹ مشین
engine/src/match.ts, logic/ میچ فلو، نیٹ کوڈ، انٹرپولیشن اور پیشین گوئی
engine/src/world/ 3D منظر میں اسٹیڈیم، فٹبالرز، گیند اور ہجوم
engine/src/screens/, hud.ts مینیو (starhermit:ui) اور میچ میں HUD (starhermit:draw)
engine/src/net.ts, platform.ts, chat.ts, voice.ts ہر وہ چیز جو StarHermit پلیٹ فارم سے بات کرتی ہے۔
engine/src/audio.ts, i18n.ts, quality.ts آواز، زبانیں اور گرافکس کی سطح
assets/, sfx/ امیجز، سٹرنگ ٹیبلز اور ساؤنڈ کلپس

1. ظاہر

starhermit.txt فولڈر کو اسکرپٹ گیم بناتا ہے، اور سرور اسکرپٹ اور کنٹرولز کا بھی اعلان کرتا ہے:

name=Football
launch=index.html
server=server.js
control.up=KeyW+ArrowUp | Run forward
control.shoot=Space+KeyJ | Shoot (hold) / tap to pass
control.tackle=KeyK | Slide tackle / pressure
engine.api=1
engine.entry=engine/src/main.ts
engine.version=1.39.0
engine.minor=39
engine.capabilities=platform,voice,clipboard,storage
engine.gamepad.shoot=West+RightTrigger
engine.gamepad.pass=South
  • launch=index.html لوڈر صفحہ ہے کہ starhermit package --web لکھتا ہے یہ کھیل کھیلتا ہے۔ پن کردہ ریلیز کے ویب رن ٹائم پر براؤزرز میں۔
  • server=server.js پلیٹ فارم کی مستند میچ اسکرپٹ ہے (مرحلہ 6)۔
  • control.* اور engine.gamepad.* لائنوں کی وضاحت اعمال. رن ٹائم ان سے چابیاں اور پیڈ باندھتا ہے، اور کھلاڑی انہیں رن ٹائم کے اختیارات کے مینو میں دوبارہ باندھ دیتے ہیں۔ گیم کبھی بھی گیم پلے کے لیے کسی کلید کا نام نہیں لیتا۔
  • engine.capabilities پلیٹ فارم (کمرے، ساکٹ، لیڈر بورڈ، ری پلے، چیٹ)، آواز، کلپ بورڈ (لنک کو مدعو کریں) اور اسٹوریج (ترتیبات)۔ رن ٹائم ان کے باہر کی کالوں سے انکار کرتا ہے۔

مکمل کلید فہرست میں ہے۔ دی starhermit.txt ظاہر.

2. اندراج ماڈیول اور فریم لوپ

engine/src/main.ts رینڈرر کو ماڈیول اسکوپ پر سیٹ کرتا ہے، پھر چار لائف سائیکل کال بیکس کو رجسٹر کرتا ہے starhermit:engine:

import { frame, onFixedUpdate, onRender, onStart, onUpdate, setFixedRate } from "starhermit:engine";
import { ACESFilmicToneMapping, PCFSoftShadowMap, PerspectiveCamera, renderer, scene } from "starhermit:scene";

const camera = new PerspectiveCamera(55, 16 / 9, 0.1, 800);
renderer.camera = camera;
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = PCFSoftShadowMap;
renderer.toneMapping = ACESFilmicToneMapping;

onStart(() => {
  setFixedRate(60);
  loadLanguages(); // string tables (step 10)
  sim();           // evaluate server.js once (step 6)
  menuScene.start(); // an AI-vs-AI match behind the menu
  // … platform listeners, settings listeners, invite polling
});

onFixedUpdate((step) => {
  if (match) match.fixedStep(step);
  else if (!replay) menuScene.fixedStep(step);
});

onUpdate((delta) => {
  pollQuality();
  if (match) match.update(Math.min(delta, 0.1));
  // … replay viewer or menu backdrop
});

onRender(() => {
  const fr = frame();
  if (Math.abs(camera.aspect - fr.width / fr.height) > 1e-6) {
    camera.aspect = fr.width / fr.height;
    camera.updateProjectionMatrix();
  }
  hud.draw();
  // … chat, in-match menu or the menu screens
});

کاپی کرنے کا پیٹرن:

  • سمولیشن چلتا ہے۔ onFixedUpdate، ایک مقررہ 60 ہرٹج پر۔
  • فی فریم منطق چلتی ہے۔ onUpdateکے ساتھ delta بند کر دیا گیا ہے تاکہ ایک رکا ہوا فریم نہ بن سکے۔ کھلاڑی چھلانگ لگاتے ہیں۔
  • ڈرائنگ اندر چلتی ہے۔ onRender. ہر کال بیک میں سے صرف ایک ہے، تو main.ts کے پرستار باہر موجودہ اسکرین: مینو، لابی، میچ، ری پلے یا نتیجہ۔

3. 3D دنیا: starhermit:scene

اسٹیڈیم، فٹبالرز، گیند اور آفیشلز عام تین. جے ایس طرز کی اشیاء ہیں۔ starhermit:scene: Mesh, Group, MeshStandardMaterial, CylinderGeometry, Sprite, CanvasTexture اور اسی طرح. three.js سے پورٹ شدہ کوڈ زیادہ تر کام کرتا ہے۔ غیر تبدیل شدہ پڑھنے کے قابل کچھ تفصیلات:

  • world/stadium.ts پچ، اسٹینڈ، فلڈ لائٹس اور فوگ بناتا ہے۔ یہ پوسٹ اثرات مرتب کرتا ہے (renderer.bloom, renderer.grade, renderer.antialias) اور ہر گرافکس لیول کے لیے سائے۔
  • world/environment.ts کے ساتھ ماحول کا نقشہ بناتا ہے۔ PMREMGenerator ایک سے DataTexture.
  • world/crest.ts اور world/nametags.ts a پر ٹیم کے کریسٹ اور تیرتے ہوئے عرفی نام بنائیں starhermit:canvas OffscreenCanvas، پھر انہیں بطور استعمال کریں۔ CanvasTextures اور Sprites.

4. ہزاروں حرکت پذیر حصے: starhermit:world

22 فٹ بالرز کو مشترکہ طور پر متحرک کرنا، نیز ہزاروں ہجوم ممبران، جیسا کہ بہت سست ہوگا۔ مقامی ترجمان پر فی آبجیکٹ اسکرپٹ۔ فٹ بال اس میں کام کرتا ہے۔ starhermit:world میزیں (ٹائپ شدہ کالموں کی قطاریں) اور دانا (رن ٹائم کا کام مقامی طور پر ہر قطار پر چلتا ہے):

import { kernel, schedule, table } from "starhermit:world";

const crowd = table("crowd", CROWD_ROWS, {
  bx: "f32", by: "f32", bz: "f32", ph: "f32", fr: "f32", av: "f32",
  q: "quat", s: "f32", sy: "f32", x: "f32", y: "f32", z: "f32",
});
const sway = kernel(crowd, (r, u: { t: number; amp: number; spd: number; sway: number; shake: number }) => {
  const j = Math.sin(u.t * u.spd * r.fr + r.ph);
  r.y = r.by + (j > 0 ? j * j : 0) * u.amp * r.av;
  // …
});
// An eighth of the crowd each frame: the work is sliced across frames.
const swayRun = schedule.update(sway, { t: 0, amp: 0, spd: 0, sway: 0, shake: 0 }, { slices: 8 });

فٹ بالر اندر داخل ہو گیا۔ world/rig.ts ایک ہی نقطہ نظر کا استعمال کریں. اے rigs ٹیبل ہر فٹ بالر کی حرکت پذیری کی حالت رکھتا ہے۔ اے joints میز a کے ساتھ ref:rigs کالم، ہر رگ میں 15 جوڑ رکھتا ہے، اور پابندیاں اس سے منظر نوڈس چلائیں. دو دانا بعد میں طے شدہ onUpdate پوز کی گنتی کریں، اور رن ٹائم نوڈ لکھتا ہے۔ خود کو تبدیل کرتا ہے. اسکرپٹ کا کام فی فٹبالر تقریباً ایک درجن نمبر ایک فریم پر آتا ہے۔

5. ان پٹ: ایکشنز، ٹچ اور گیم پیڈز

engine/src/input.ts کے ذریعے مینی فیسٹ کے اعمال کو پڑھتا ہے۔ starhermit:input:

  • value(action) لوٹاتا ہے کہ ایک عمل کتنی دور ہے (حرکت ہے۔ value("up") - value("down")). onAction پریس اور ریلیز کناروں کو فراہم کرتا ہے۔
  • ماؤس نظر استعمال کرتا ہے requestPointerLock, onPointerDelta اور onPointerLockChange. کیمرے کا دائیں چھڑی سے آتا ہے gamepads()، اور vibrate ایک مختصر ہیپٹک ٹک دیتا ہے۔
  • ٹچ اسکرینوں پر (primaryPointer() موٹا ہے) setTouchControls ایک جوائس اسٹک دکھاتا ہے اور رن ٹائم کے ذریعہ تیار کردہ شوٹ/پاس/ٹیکل بٹن۔ بٹن انہی اعمال کے پابند ہیں:
setTouchControls([
  { kind: "stick", up: "up", down: "down", left: "left", right: "right", anchor: "bottom-left", offset: [90, 90], radius: 66 },
  { kind: "button", action: "shoot", label: T("SHOOT").slice(0, 16), anchor: "bottom-right", offset: [66, 66], radius: 46 },
  // … PASS and TACKLE
]);

screens/controls.ts موجودہ کی فہرست دیتا ہے۔ bindings() اور کالز requestRebind. رن ٹائم پھر نئی کلید کو پکڑتا ہے یا بٹن

6. کلائنٹ اور سرور کے لیے ایک نقلی: starhermit:script

server.js ایک سادہ کلاسک اسکرپٹ ہے جس میں کوئی درآمد نہیں ہے، Date یا Math.random، پلیٹ فارم کے سینڈ باکس کے طور پر کی ضرورت ہے یہ دو عالمیوں کی وضاحت کرتا ہے:

  • globalThis.game پلیٹ فارم کے داخلے کے پوائنٹس (createSession, onPlayerMessage, onTick) اور جامد اعلانات جو اشاعت کے وقت پڑھے جاتے ہیں:

    globalThis.game = {
  tickRateHz: 30,
  replays: true,
  achievements: [
    { key: 'debut', name: 'Debut', description: 'Finish your first match.', points: 10 },
    { key: 'hat-trick', name: 'Hat-Trick', description: 'Score three goals in one match.', points: 50 },
    // …
  ],
  createSession: function (ctx) { /* seats, AI, seed from ctx.random */ },
  // …
};

  • globalThis.FootballSim ایک ہی تخروپن رکھتا ہے (createMatch, stepMatch، AI) کے لیے کلائنٹ

کلائنٹ اسی فائل کو اپنے دائرے میں لوڈ کرتا ہے۔ loadClassic سے starhermit:script (engine/src/sim.ts):

import { loadClassic } from "starhermit:script";

loadClassic("server.js");
const S = (globalThis as unknown as { FootballSim?: FootballSimApi }).FootballSim;

آف لائن مشق کے اقدامات FootballSim مقامی طور پر ہر دوسری سیٹ پر AI کے ساتھ 60 Hz پر۔ آن لائن، دی پلیٹ فارم چلتا ہے server.js مستند طور پر 30 ہرٹج پر۔ کھیل کبھی بھی اس کی دو کاپیاں برقرار نہیں رکھتا ہے۔ قواعد

7. آن لائن میچز: کمرے اور گیم ساکٹ

لابی پلیٹ فارم کے کمروں کو استعمال کرتی ہے۔ starhermit:platform (screens/lobby.ts):

import * as P from "starhermit:platform";

// Quick play: join any open room, or open one.
let room = await P.rooms.quickJoin();
if (!room) {
  room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, metadata: { game: "football" } });
  room = await P.rooms.open(room.id);
}

// Ranked solo vs AI: every other seat is an AI player, so starting begins the match at once.
room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, aiPlayers: 2 * teamSize - 1, metadata: { game: "football" } });
room = await P.rooms.start(room.id);

دوست، دعوتیں اور نشستوں میں تبدیلیاں ہوتی رہتی ہیں۔ P.friends.list, P.rooms.invite, P.rooms.acceptInvite اور P.rooms.seat. P.rooms.mine ایک کھلاڑی کو اس میچ میں دوبارہ شامل ہونے دیتا ہے جو اس نے چھوڑا تھا۔

ایک بار جب میچ شروع ہوتا ہے، engine/src/net.ts کے ساتھ گیم ساکٹ کھولتا ہے۔ P.connectGame(sessionId):

  • یہ 30 ہرٹج کے ساتھ ان پٹ بھیجتا ہے۔ sendInput.
  • اس کے ساتھ مکمل سنیپ شاٹ مانگتا ہے۔ sendCommand({ type: "sync" }) ہر کھلے اور پر resumed.
  • یہ سنتا ہے۔ game (اسنیپ شاٹس اور واقعات) achievement اور stopped. stopped رپورٹ کیوں ساکٹ رک گیا: سائن آؤٹ، اپ ڈیٹ شدہ شرائط، یا میچ چلا گیا۔

رن ٹائم کھلاڑی کی اسناد رکھتا ہے اور خود سے دوبارہ جڑ جاتا ہے، لہذا گیم کوئی ٹوکن ہینڈل نہیں کرتا اور دوبارہ کوشش کرنے کا کوئی لوپ نہیں ہے۔

logic/interp.ts انکولی انٹرپولیشن کے ساتھ سرور کے سنیپ شاٹس کو ہموار کرتا ہے۔ logic/predict.ts مقامی فٹبالر کی نقل و حرکت کی پیشین گوئی کرتا ہے اور اسے ہر اسنیپ شاٹ کی طرف درست کرتا ہے۔ پیشن گوئی متاثر کرتی ہے۔ صرف وہی جو تیار کیا جاتا ہے؛ سرور مستند رہتا ہے۔

8. باقی پلیٹ فارم

فیچر کالز ماخذ
سائن ان کردہ کھلاڑی، سائن ان، سیشن کا اختتام P.player(), P.onPlayerChange, P.requestSignIn, P.onSessionEnded platform.ts, main.ts
لیڈر بورڈ P.leaderboards.list, P.leaderboards.entries (بورڈ میں اعلان کیا گیا ہے۔ leaderboards.json) screens/leaderboard.ts
کامیابیاں میں اعلان کیا۔ server.js, مکمل وقت پر نوازا گیا, کے ساتھ درج P.achievements.list screens/achievements.ts
ری پلے کرتا ہے۔ game.replays: true میں server.js; P.replays.list, P.replays.get screens/replays.ts, replayView.ts
ٹیکسٹ چیٹ P.sessions.get (میچ کی گفتگو) P.chat.messages, P.chat.subscribe, P.chat.post chat.ts
وائس چیٹ P.voice.join, P.voice.setVolume اور P.voice.setPan فٹ بالرز کے درمیان فاصلے کے لحاظ سے، P.voice.setMuted voice.ts
لنکس کو مدعو کریں۔ P.inviteLink اور clipboard سے starhermit:engine platform.ts
بگ رپورٹس P.reportBug screens/settings.ts

ہر کال کو ایک کے ساتھ مسترد کر سکتی ہے۔ PlatformError. فٹ بال آن لائن خصوصیات کو بہترین کوشش سمجھتا ہے: a ناکامی ظاہر کرتا ہے "آن لائن دستیاب نہیں ہے۔" یا پھر خاموشی پر گر جاتا ہے، اور کبھی کھیل ختم نہیں ہوتا ہے۔ سائن آؤٹ، گیم اب بھی آف لائن پریکٹس پیش کرتا ہے۔

9. مینو اور HUD: starhermit:ui, starhermit:draw, starhermit:canvas

  • مینو (screens/*.ts, ان میچ مینو اور ڈائیلاگ ان میں main.ts) استعمال کریں۔ starhermit:ui، انجن کا فوری موڈ UI۔ وجیٹس کو ہر کہا جاتا ہے۔ سے فریم onRender، اور ui.setTheme انہیں کھیل کے رنگ دیتا ہے۔ رن ٹائم کے اپنے اختیارات کے ساتھ مینو کھلتا ہے۔ openMenu.
  • HUD ( hud.ts) کے ساتھ سکور بورڈ، گھڑی اور مارکر کھینچتا ہے۔ starhermit:draw: draw.roundRect, draw.text اور draw.image (ایک کرسٹ کینوس)، منظر کے اوپر کال آرڈر میں۔
  • امیجز کے ساتھ بھری ہوئی ہیں createImageBitmap سے starhermit:canvas, مثال کے طور پر مینو کا کلیدی فن۔

10. ترتیبات اور زبانیں: starhermit:storage, تار

  • فی کھلاڑی کی ترتیبات (خاموش، آواز، زبان، گرافکس اوور رائیڈز) لائیو ان ہیں۔ settings سے starhermit:storage. وہ ڈیوائس پر اور اکاؤنٹ میں رکھے جاتے ہیں۔ settings.onChange کسی دوسرے آلے پر کی گئی تبدیلی کو لاگو کرتا ہے۔
  • i18n.ts بوجھ assets/strings.json انجن میں strings میزیں (strings.load, strings.t, strings.setLanguage)۔ یہ محفوظ کردہ انتخاب سے زبان چنتا ہے، پھر کھلاڑی کا StarHermit زبان، پھر ڈیوائس کی (preferences). l10n/font.ts اسکرپٹ فونٹس کے ساتھ لوڈ کرتا ہے۔ FontFace ان زبانوں کے لیے جن کی ضرورت ہے۔

11. آواز اور گرافکس کی سطح

  • audio.ts کے ساتھ ایک ویب آڈیو گراف بناتا ہے۔ starhermit:audio:
    • تصنیف شدہ کلپس اس میں درج ہیں۔ sfx/manifest.json (کے ساتھ پڑھیں files.readJson).
    • ایک سنتھیسائزر کلپ کے بغیر کسی بھی ایونٹ کا احاطہ کرتا ہے، نیز ہجوم اور اسٹیڈیم ریورب۔
    • قلیل المدتی نوڈس ختم ہوتے ہی جاری کر دیے جاتے ہیں، کیونکہ میزبان گراف پابند ہوتا ہے۔
  • quality.ts کھلاڑی کے گرافکس کی سطح کی پیروی کرتا ہے (frame().level, levelSettings)۔ سائے، کھلنا اور اینٹی ایلائزنگ اس سطح پر عمل کریں۔ گیم کا اپنا مواد (پچ کی تفصیل، ہجوم کی کثافت، ذرات) سب سے اوپر پر فی کھلاڑی اوور رائیڈز ہیں۔

12. پیکیج، جانچ اور شائع کریں۔

  • ٹائپ چیک کے ساتھ tsc -p engine. engine/tsconfig.json ریلیز بھی شامل ہے۔ starhermit.d.ts اور سیٹ "lib": ["ES2022"], "types": [] اور "allowImportingTsExtensions": true.
  • ٹیسٹ npm test چلتا ہے server.js رجعت کے ٹیسٹ engine/tests/run.sh منطق چلاتا ہے نوڈ کے تحت ٹیسٹ (انٹرپولیشن، پیشن گوئی، پوز، لابی)۔ starhermit <folder> --check پیکیج کی توثیق کرتا ہے اور بغیر ہیڈ کے 120 فریم چلاتا ہے۔
  • پیکج starhermit package --web . دوبارہ لکھتا ہے index.html اور starhermit-files.json, جو ہر تبدیلی کے ساتھ پرعزم ہیں۔
  • شائع کریں۔ گیم کو StarHermit پر اس کے ذخیرے کے URL سے شامل کیا گیا ہے۔ پلیٹ فارم پڑھتا ہے۔ starhermit.txt, رنز server.js میچ اسکرپٹ کے طور پر اور اس سے لیڈر بورڈ بناتا ہے۔ leaderboards.json.

  2. سیٹ engine.version=1.41.0.
