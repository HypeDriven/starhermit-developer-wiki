ٹیوٹوریل: StarHermit انجن کے ساتھ ایک گیم بنائیں

دی StarHermit انجن StarHermit پر اشاعت کے لیے گیمز بنانے کا تجویز کردہ طریقہ ہے۔. آپ ایک بار گیم بناتے ہیں، اور وہی پیکیج خود بخود براؤزر میں اور مقامی طور پر چلنے کے قابل ہوتا ہے۔ انجن کے ذریعے تعاون یافتہ تمام پلیٹ فارمز پر۔ مقامی کھیل اضافی کارکردگی اور خصوصیات پیش کرتا ہے۔ دستیابی کا انحصار انجن کی ریلیز پر ہے: 1.1.0 کا ونڈوز رن ٹائم اور ویب رن ٹائم ہے (1.0.0 تھا صرف ونڈوز)۔

StarHermit انجن چلتا ہے۔ سکرپٹ کھیل: TypeScript (یا JavaScript) میں لکھا ہوا ایک پورا گیم اور کسی بھی مقامی کوڈ کو مرتب کیے بغیر، ایک پری بلٹ انجن ایگزیکیوٹیبل، StarHermit رن ٹائم کے ذریعے چلایا جاتا ہے۔ آپ انجن کے بلٹ ان ماڈیولز کے خلاف گیم کی منطق لکھتے ہیں — ایک 3D سین، ان پٹ، ایک HUD، آڈیو، اسٹوریج اور StarHermit پلیٹ فارم - اور رن ٹائم باقی کام کرتا ہے: ونڈونگ، پر رینڈرنگ GPU، آواز، اختیارات کا مینو، سائن ان اور آن لائن کھیل۔ کھلاڑی starhermit.com پر گیم کھولتے ہیں۔ ان کا براؤزر، جہاں اس کا صفحہ اس انجن کو لوڈ کرتا ہے جو آپ کا گیم اس ویکی سے مانگتا ہے، یا اسے مقامی طور پر چلائیں۔ میں StarHermit ونڈوز کلائنٹ، جو اس انجن کو انسٹال کرتا ہے۔

یہ ٹیوٹوریل بناتا ہے۔ سٹار پکڑنے والا، ایک چھوٹا سا کھیل جس میں آپ گرتے ہوئے پکڑنے کے لیے ٹوکری چلاتے ہیں۔ ستارے، اور اسے خالی فولڈر سے شائع شدہ گیم میں لے جاتا ہے:

  1. کیا اسکرپٹ گیم ہے۔
  2. انجن حاصل کریں۔
  3. گیم بنائیں
  4. پہلا ورژن لکھیں۔
  5. اسے مقامی طور پر چلائیں۔
  6. ایک ساتھ بہت سی چیزیں: starhermit:world
  7. کھلاڑی، بچت اور آن لائن کھیل
  8. اسے شائع کریں۔
  9. ایک نئے انجن پر جائیں۔
  10. حدود اور لائسنس

1. اسکرپٹ گیم کیا ہے۔

اسکرپٹ گیم ایک فولڈر ہے (a پیکج) کے ساتھ a starhermit.txt اس پر روٹ، آپ کے ٹائپ اسکرپٹ ماڈیولز اور آپ کے اثاثے۔ تین engine.* مینی فیسٹ میں لائنیں اسے ایک بناتی ہیں:

engine.api=1
engine.entry=src/main.ts
engine.version=1.1.0

engine.api میزبان API کا بڑا ورژن ہے جس کے خلاف آپ کا کوڈ لکھا جاتا ہے، engine.entry دی ماڈیول رن ٹائم شروع ہوتا ہے، اور engine.version عین مطابق انجن ریلیز گیم بنایا گیا ہے اور کے لئے تجربہ کیا. ریلیز اس ویکی پر اس کے تحت شائع کی جاتی ہیں۔ انجن کی ریلیز; دی گیم میں کبھی بھی انجن شامل نہیں ہوتا ہے، لہذا اپ لوڈ میں صرف آپ کی اپنی فائلیں ہوتی ہیں۔

رن ٹائم ہر گیم کو ناقابل اعتماد سمجھتا ہے: آپ کا کوڈ صرف میزبان API کے ذریعے مشین تک پہنچتا ہے۔ (اس کی اپنی پیکیج فائلیں، اس کا اپنا اسٹوریج، اس کی اپنی گیم آئی ڈی کا پلیٹ فارم)، کبھی بھی فائلیں، عمل، صوابدیدی نیٹ ورک کنکشن یا کھلاڑی کی اسناد۔ بدلے میں ایک گیم رن ٹائم کریش نہیں کر سکتا یا ونڈو کو ہینگ کریں: ایک کال جو تین سیکنڈ تک چلتی ہے رن ٹائم کا اپنا لے آتی ہے۔ "جواب نہیں دے رہا" اسکرین، اور ایک نہ پکڑی گئی غلطی ایک ایرر اسکرین پر گیم کو ختم کر دیتی ہے جس سے کھلاڑی دوبارہ شروع کر سکتا ہے۔

2. انجن حاصل کریں۔

کھلاڑی کچھ نہ کریں: ایک براؤزر میں، گیم کا صفحہ اس ویکی سے گیم پن کی ریلیز کو لوڈ کرتا ہے۔ اور صفحہ پر موجود ہیشز کے خلاف اسے چیک کرتا ہے۔ StarHermit ونڈوز کلائنٹ میں، ڈاؤن لوڈز چلائیں۔ ریلیز (ایک بار، ہر گیم کے ذریعے اشتراک کیا جاتا ہے جو اسے پن کرتا ہے)، ریلیز کے خلاف ہر فائل کو چیک کرتا ہے۔ ہیش شائع کرتا ہے اور اسے شروع کرتا ہے۔

ڈویلپرز انجن کے علاقے سے ریلیز کا رن ٹائم ڈاؤن لوڈ کریں:

  • starhermit-1.1.0-windows-x86_64.zip (ونڈوز 10 یا 11، 64 بٹ)، 6.7 ایم بی۔

آرکائیو ایک فولڈر رکھتا ہے، starhermit-1.1.0-windows-x86_64کے ساتھ starhermit.exe, the release.json جو رن ٹائم کو بتاتا ہے کہ یہ کون سا ریلیز ہے، ریلیز کا web-manifest.json, LICENSE-engine اور تیسرے فریق کے نوٹسز۔ یہ وہی انجن ہے جو کلائنٹ انسٹال کرتا ہے، اور یہ بغیر نیٹ ورک کے ریلیز کے ویب رن ٹائم کے لیے پیکج گیمز۔ اس کا سائز اور SHA-256 ذیل میں درج ہیں۔ downloads ریلیز میں native.json; کو PowerShell میں اپنی کاپی چیک کریں، اس کا موازنہ کریں۔ sha256 کے ساتھ:

Get-FileHash .\starhermit-1.1.0-windows-x86_64.zip -Algorithm SHA256

آرکائیو کو کھولیں اور پیک کیے ہوئے فولڈر میں ٹرمینل کھولیں:

.\starhermit.exe --version

starhermit 0.1.0 (host API 1.4, launcher 1; engine release 1.1.0)

نیچے دیے گئے احکامات اس طرح لکھے گئے ہیں۔ starhermit; ان کے طور پر چلائیں .\starhermit.exe اس فولڈر سے، یا فولڈر کو اپنے میں شامل کریں۔ PATH.

3. گیم بنائیں

starhermit new star-catcher --title "Star Catcher"

Created Star Catcher in star-catcher: a script game pinned to engine 1.1.0
Play it: starhermit star-catcher
Check it: starhermit check star-catcher
For a native upload (the StarHermit client plays it): starhermit package --native star-catcher
For the web: starhermit package --web star-catcher --out <upload>

نئے فولڈر میں چلنے کے قابل نقطہ آغاز ہے - ایک مکعب جو اسپیس دبانے پر ہاپ کرتا ہے:

star-catcher/
  starhermit.txt             the manifest, pinned to the runtime's own release (engine.version=1.1.0)
  tsconfig.json              TypeScript settings for checking the game
  src/main.ts                the entry module
  .starhermit/starhermit.d.ts  the host API's declarations, for your editor and the type checker

.starhermit/ ڈاٹ کے ساتھ شروع ہوتا ہے، لہذا یہ کبھی بھی پیکیج کا حصہ نہیں ہوتا ہے۔ starhermit types star-catcher دوبارہ اعلانات لکھتا ہے، مثال کے طور پر جب آپ نئے پر منتقل ہوتے ہیں۔ رن ٹائم میزبان API کا ہر ماڈیول، ممبر، یونٹ، حد اور غلطی اس فائل میں درج ہے۔

رن ٹائم ٹائپ چیک نہیں کرتا ہے: یہ TypeScript کی اقسام کو ہٹاتا ہے کیونکہ یہ ہر ماڈیول کو لوڈ کرتا ہے۔ انہیں چیک کریں۔ خود کو TypeScript 5 یا جدید تر کے ساتھ؛ Node.js انسٹال کے ساتھ، npx اسے انسٹال کیے بغیر چلاتا ہے۔ گیم فولڈر میں کچھ بھی:

cd star-catcher
npx --package typescript tsc -p .

رکھو node_modules اور دیگر ٹولنگ گیم فولڈر سے باہر: فولڈر میں سب کچھ سوائے dot-names پیکیج اور ہر اپ لوڈ کا حصہ ہے۔

4. پہلا ورژن لکھیں۔

پیدا کردہ کو تبدیل کریں۔ starhermit.txt گیم کے مینی فیسٹ کے ساتھ:

name=Star Catcher
description=Catch the falling stars before the time runs out.
launch=index.html
engine.api=1
engine.entry=src/main.ts
engine.version=1.1.0
engine.capabilities=platform,storage
control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.start=Space+Enter | Start a round
engine.gamepad.left=LeftStickLeft+DpadLeft
engine.gamepad.right=LeftStickRight+DpadRight
engine.gamepad.start=South
cache..=0

دی control.* لائنیں گیم کی کارروائیوں کا اعلان اپنی ڈیفالٹ کیز (پلیٹ فارم کی کنٹرول کرتا ہے فارمیٹ) اور engine.gamepad.* ان کے گیم پیڈ ڈیفالٹس۔ کھلاڑی دوبارہ باندھتے ہیں۔ انہیں رن ٹائم کے اختیارات کے مینو میں، تاکہ گیم پڑھے۔ اعمال, چابیاں کبھی نہیں. engine.capabilities کھیل ڈرائنگ اور ان پٹ سے آگے کیا استعمال کرتا ہے کے بارے میں پوچھتا ہے: platform سائن ان کردہ کھلاڑی اور آن لائن کے لیے خصوصیات، storage پلیئر کے ڈیوائس اور اکاؤنٹ پر رکھے گئے ڈیٹا کے لیے۔ launch=index.html کے نام وہ صفحہ جو براؤزر میں گیم کھیلتا ہے، جسے انجن لکھتا ہے جب آپ شائع کریں.

پھر بدل دیں۔ src/main.ts:

// Star Catcher: catch the falling stars in the basket before the time runs out.
import { frame, onFixedUpdate, onRender, onStart, setFixedRate } from "starhermit:engine";
import {
  AmbientLight,
  BoxGeometry,
  Color,
  DirectionalLight,
  Mesh,
  MeshStandardMaterial,
  PerspectiveCamera,
  SphereGeometry,
  renderer,
  scene,
} from "starhermit:scene";
import { onAction, value } from "starhermit:input";
import { storage } from "starhermit:storage";
import { player } from "starhermit:platform";
import * as draw from "starhermit:draw";

// -- The scene ----------------------------------------------------------------
const camera = new PerspectiveCamera(50, 16 / 9, 0.1, 100);
camera.position.set(0, 4, 12);
camera.lookAt(0, 3, 0);
renderer.camera = camera;
scene.background = new Color(0x0b1020);

const sun = new DirectionalLight(0xfff4e0, 1.2);
sun.position.set(3, 8, 5);
scene.add(sun, sun.target, new AmbientLight(0x6070a0, 0.5));

const basket = new Mesh(new BoxGeometry(2, 0.4, 1), new MeshStandardMaterial({ color: 0x4fa3ff, roughness: 0.4 }));
scene.add(basket);

const starGeometry = new SphereGeometry(0.3, 16, 12);
const starMaterial = new MeshStandardMaterial({ color: 0xffd34d, emissive: 0xffb000, emissiveIntensity: 0.6 });
const stars = Array.from({ length: 3 }, () => {
  const mesh = new Mesh(starGeometry, starMaterial);
  scene.add(mesh);
  return { mesh, x: 0, y: 0, previousY: 0, speed: 0 };
});
type Star = (typeof stars)[number];

// -- The rules ----------------------------------------------------------------
const WIDTH = 6; // the basket moves between -WIDTH and WIDTH
const ROUND = 60; // seconds a round lasts
let basketX = 0;
let previousX = 0;
let score = 0;
let timeLeft = 0; // 0 between rounds
const saved = storage.getJson("best");
let best = typeof saved === "number" ? saved : 0;

function drop(star: Star): void {
  star.x = (Math.random() * 2 - 1) * WIDTH;
  star.y = star.previousY = 8 + Math.random() * 4;
  star.speed = 2 + Math.random() * 2 + score * 0.05;
}

onStart(() => {
  setFixedRate(60);
  for (const star of stars) drop(star);
});

onAction((event) => {
  if (event.action === "start" && event.pressed && timeLeft === 0) {
    score = 0;
    timeLeft = ROUND;
    for (const star of stars) drop(star);
  }
});

onFixedUpdate((step) => {
  previousX = basketX;
  for (const star of stars) star.previousY = star.y;
  if (timeLeft === 0) return;
  // An action's value is 0 to 1, so a stick steers gently and a key fully.
  const steer = value("right") - value("left");
  basketX = Math.max(-WIDTH, Math.min(WIDTH, basketX + steer * 9 * step));
  for (const star of stars) {
    star.y -= star.speed * step;
    if (star.y < 0.6 && star.y > 0 && Math.abs(star.x - basketX) < 1.2) {
      score += 1;
      drop(star);
    } else if (star.y < -1) {
      drop(star);
    }
  }
  timeLeft = Math.max(0, timeLeft - step);
  if (timeLeft === 0 && score > best) {
    best = score;
    storage.setJson("best", best);
  }
});

// -- Drawing ------------------------------------------------------------------
onRender((alpha) => {
  // Between two fixed steps: draw where things are at this moment.
  basket.position.set(previousX + (basketX - previousX) * alpha, 0.2, 0);
  for (const star of stars) {
    star.mesh.position.set(star.x, star.previousY + (star.y - star.previousY) * alpha, 0);
  }
  hud();
});

function hud(): void {
  const { width, height, scale } = frame();
  const size = 22 * scale;
  const name = player()?.displayName ?? "Guest";
  draw.text(`${name}   score ${score}   best ${best}`, 16 * scale, 16 * scale, { size, color: "#e8ecf4" });
  if (timeLeft > 0) {
    draw.text(`${Math.ceil(timeLeft)} s`, width - 16 * scale, 16 * scale, { size, color: "#ffd34d", align: "end" });
  } else {
    draw.rect(0, height / 2 - 40 * scale, width, 80 * scale, [0, 0, 0, 0.5]);
    draw.text("Press Space to play", width / 2, height / 2 - 12 * scale, { size, color: "#ffffff", align: "center" });
  }
}

ہر حصہ کیا کرتا ہے:

  • منظر۔ starhermit:scene 3.js کی پیروی کرتا ہے: جیومیٹری سے بنا کیمرہ، لائٹس، میش اور ایک مواد، scene.add. فاصلے میٹر، زاویہ ریڈین، اور رنگ sRGB ہیں۔
  • قواعد۔ onFixedUpdate مقررہ شرح پر چلتا ہے۔ setFixedRate(60) مانگتا ہے، 60 بار ایک دوسرا جو بھی فریم ریٹ ہو، لہذا گیم ہر مشین پر ایک جیسا کھیلتا ہے۔ value("right") ہے ایکشن کی قدر 0 سے 1 تک ہوتی ہے، اس لیے ایک گیم پیڈ اسٹک آہستہ سے چلتا ہے اور کلیدی مکمل طور پر چلتا ہے، اور onAction ہر پریس کو سنتا ہے، یہاں ایک راؤنڈ شروع کرنے کے لیے۔
  • ڈرائنگ۔ onRender کے ساتھ فی فریم ایک بار چلتا ہے۔ alpha، آخری دو کے درمیان فریم کتنی دور ہے۔ مقررہ اقدامات؛ کے درمیان تیار کردہ پوزیشنیں previous اور موجودہ قدریں کسی بھی ریفریش پر آسانی سے حرکت کرتی ہیں۔ شرح starhermit:draw ونڈو پکسلز میں HUD کو منظر پر کھینچتا ہے۔ frame().scale تبدیل کرتا ہے ہائی DPI ڈسپلے کے لیے منطقی پکسلز۔
  • بہترین سکور کے ذریعے کھلاڑی کے آلے پر رہتا ہے۔ starhermit:storageکے لیے الگ رکھا ہر کھلاڑی.

5. اسے مقامی طور پر چلائیں۔

starhermit check star-catcher

package=Directory files=3 bytes=4800 name="Star Catcher" api=1 entry=src/main.ts capabilities=platform,storage actions=left,right,start
runnable=true engine="TypeScript" frames=120 probes=0
PASS package src/main.ts: valid; 120 frames headless

check پیکج (منشور، راستے، سائز) کی توثیق کرتا ہے اور ونڈو کے بغیر 120 فریم چلاتا ہے، لہذا ایک نحو کی خرابی، ایک نامعلوم درآمد یا اسٹارٹ اپ میں ایک استثناء اس کی فائل، لائن اور کالم کے ساتھ یہاں ظاہر ہوتا ہے۔ پھر اسے چلائیں:

starhermit star-catcher

راؤنڈ شروع کرنے کے لیے اسپیس دبائیں اور اسٹیئر کرنے کے لیے تیر والے بٹن (یا A اور D، یا گیم پیڈ) دبائیں۔ F1 ہمیشہ رن ٹائم کا اپنا مینو کھولتا ہے: گرافکس، آڈیو، کنٹرولز (ری بائنڈنگ)، اکاؤنٹ اور چھوڑنا۔ آپ کا گیم اس مینو کو نہیں کھینچ سکتی اور نہ ہی اسے پڑھ سکتی ہے، اور کوئی گیم F1 کو پابند نہیں کر سکتی۔

ترقی کرتے وقت، شامل کریں --dev (starhermit star-catcher --dev): رن ٹائم پھر گیم کو پرنٹ کرتا ہے۔ console.log آپ کی TypeScript لائنوں پر آؤٹ پٹ اور پوائنٹس کی خرابیاں۔

6. ایک ساتھ بہت سی چیزیں: starhermit:world

مقامی طور پر، آپ کے گیم کا TypeScript انجن کے اپنے اسکرپٹ انٹرپریٹر میں چلتا ہے، جو ہر گیم کو برقرار رکھتا ہے۔ اس کے وقت اور میموری بجٹ کے اندر؛ براؤزرز میں یہ براؤزر کے جاوا اسکرپٹ انجن میں چلتا ہے۔ کارکن صفحہ روک سکتا ہے۔ فیصلوں اور چند درجن اشیاء کی قیمت وہاں بہت کم ہے، لیکن فی ہستی کام - ہزاروں ذرات، ایک ہجوم، ایک ریوڑ کو حرکت دینا - کا مطلب ہوگا ہزاروں تشریح شدہ اقدامات ہر فریم. اس کے لیے انجن ہے۔ starhermit:world:

  • میزیں گیم کی میموری میں ہستی کے ڈیٹا کو ٹائپ شدہ کالم (نمبر اور ویکٹر) میں رکھیں۔
  • دانا ایک قطار کے عام افعال ہیں جو رن ٹائم مرتب کرتا ہے اور مقامی طور پر چلتا ہے۔ اسکرپٹ میں داخل کیے بغیر ٹیبل کی ہر قطار؛
  • دی شیڈول دانا ہر فریم چلاتا ہے، اور پابندیاں ایک کے طور پر ایک میز کھینچیں InstancedMesh (یا ڈرائیو سین نوڈس)، ہر مثال کو مقامی طور پر کمپوز کرنا۔

آپ کی اسکرپٹ فیصلے کرتی ہے۔ رن ٹائم فی قطار ریاضی کرتا ہے۔ 4,000 کا ایک رات کا آسمان شامل کریں۔ کے طور پر کھیل کے پیچھے چمک چمک src/sky.ts:

// The night sky behind the game: 4,000 twinkling sparkles. Their data lives
// in a starhermit:world table, a kernel moves every one of them natively each
// frame, and an instance binding draws the table as one InstancedMesh, so the
// game's script runs no per-sparkle code at all.
import { InstancedMesh, MeshBasicMaterial, SphereGeometry, scene } from "starhermit:scene";
import { bind, kernel, schedule, table } from "starhermit:world";

const COUNT = 4_000;

// One row per sparkle: where it hangs, how it twinkles, and what the kernel
// writes each frame (its height and size).
const sky = table("sky", COUNT, {
  base: "vec3",
  phase: "f32",
  rate: "f32",
  y: "f32",
  size: "f32",
});
sky.spawn(COUNT);

// Filled once from script, through typed arrays over the table's memory.
const base = sky.column("base");
const phase = sky.column("phase");
const rate = sky.column("rate");
for (let i = 0; i < COUNT; i++) {
  base[i * 3] = (Math.random() * 2 - 1) * 40;
  base[i * 3 + 1] = Math.random() * 24 - 2;
  base[i * 3 + 2] = -10 - Math.random() * 30;
  phase[i] = Math.random() * Math.PI * 2;
  rate[i] = 0.5 + Math.random() * 2;
}

// An ordinary function of one row. The runtime compiles it and runs it over
// every live row without entering script.
const twinkle = kernel(sky, (r, u: { drift: number }, f) => {
  r.y = r.base.y + Math.sin(f.time * u.drift + r.phase) * 0.3;
  r.size = 0.04 + 0.04 * Math.abs(Math.sin(f.time * r.rate + r.phase));
});

const mesh = new InstancedMesh(new SphereGeometry(1, 6, 4), new MeshBasicMaterial({ color: 0xcfd8ff }), COUNT);
scene.add(mesh);

/** Starts the sky: the kernel runs after every onUpdate, and the binding
 * composes the mesh's instances from the columns after every onRender. */
export function startSky(): void {
  schedule.update(twinkle, { drift: 0.4 });
  bind.instances(mesh, sky, { position: ["base.x", "y", "base.z"], scale: "size" });
}

اور اس سے شروع کریں src/main.ts: اسے دوسری درآمدات کے ساتھ درآمد کریں، اور اسے کال کریں۔ onStart:

import { startSky } from "./sky.js";

onStart(() => {
  setFixedRate(60);
  startSky();
  for (const star of stars) drop(star);
});

درآمد کے نام ./sky.js, ایک ماڈیول کے لیے TypeScript کا کنونشن بطور لکھا گیا ہے۔ sky.ts; رن ٹائم اسے اسی طرح حل کرتا ہے۔ دانا زبان کے ایک ذیلی سیٹ کو قبول کرتے ہیں — اعداد اور بولین، ریاضی، Math, if، پابند for لوپس، قطار کے کالم اور یونیفارم جو آپ پاس کرتے ہیں — اور رن ٹائم a کے ساتھ کسی اور چیز کو مسترد کرتا ہے۔ SyntaxError دانا کی لائن پر جب وہ اسے مرتب کرتا ہے، بجائے اسے آہستہ سے چلائیں. کے اعلانات starhermit:world سب سیٹ کی وضاحت کریں، ایونٹ کی قطاریں دانا خارج ہوتا ہے، ہموار فکسڈ اسٹیپ موشن کے لیے ہسٹری کے ساتھ میزیں، اور نوڈ بائنڈنگز۔

7. کھلاڑی، بچت اور آن لائن کھیل

کھلاڑی۔ player() سے starhermit:platform سائن ان کردہ کھلاڑی ہے، یا null a کے لیے مہمان اسٹار کیچر اپنے HUD میں ان کا نام دکھاتا ہے۔ جب StarHermit Windows کلائنٹ آپ کا گیم شروع کرتا ہے، پلیئر پہلے فریم سے سائن ان ہوتا ہے، کلائنٹ کے اکاؤنٹ کے ساتھ: کلائنٹ ہینڈ کرتا ہے۔ ایک نجی چینل پر آپ کے گیم کے لیے لانچ ٹوکن کا رن ٹائم، گیم کے چلنے کے دوران اس کی تجدید، اور گیم اسے کبھی نہیں دیکھتا ہے (کوئی میزبان کال ٹوکن، کلید یا کوکی واپس نہیں کرتا)۔ کھلاڑی کبھی بھی a کے اندر سائن ان نہیں ہوتے ہیں۔ کھیل سائن ان اور آؤٹ کلائنٹ میں ہوتا ہے۔

براؤزرز میں پلیٹ فارم آپ کے گیم کے لانچ ٹوکن کے ساتھ گیم کا صفحہ کھولتا ہے، جو آپ کے کوڈ کے چلنے سے پہلے انجن صفحہ کے ایڈریس سے باہر لے جاتا ہے اور پلیٹ فارم کے 12 گھنٹے میں تجدید ہو جاتا ہے۔ حد آپ کا کھیل صرف دیکھتا ہے۔ player()بالکل مقامی طور پر۔ ایک مہمان جو منتخب کرتا ہے۔ سائن ان کریں۔ میں رن ٹائم کا اکاؤنٹ ڈائیلاگ StarHermit کے اپنے سائن ان پیج پر جاتا ہے اور سائن ان ہو کر واپس آتا ہے۔ براؤزر کی اپنی اجازت کے پرامپٹ کے بعد براؤزر کا مائیکروفون۔

ترقی چلتی ہے۔ ٹرمینل سے شروع ہوا، ایک پیکج خود سے پلیٹ فارم کی شناخت کا دعوی نہیں کر سکتا، تو starhermit star-catcher مہمان کے طور پر کھیلتا ہے۔ ایک بار جب آپ کا گیم شائع ہوتا ہے، ایک ترقی کا آغاز اس کے نام:

starhermit star-catcher --game <your game's id>

اور آپ اس کے ذریعے سائن ان کریں۔ F1 → اکاؤنٹ…، رن ٹائم کا اپنا ڈائیلاگ (اس کمپیوٹر پر ایک کلید اور ایک ای میل کی توثیق، جیسا کہ میں عوامی کلید آن بورڈنگ)۔ اسٹوریج، ترتیبات، محفوظ کرتا ہے اور آن لائن کھیل پھر اس گیم اور اکاؤنٹ کو فالو کریں۔

محفوظ کرتا ہے اور ترتیبات۔ starhermit:storage تین اسٹورز ہیں، سبھی آپ کے گیم کے لیے نجی ہیں: storage (آلہ پر کلیدی/قدر کا ڈیٹا، جیسا کہ اسٹار کیچر استعمال کرتا ہے) settings (کھیل کے اختیارات، کے ساتھ رکھے گئے ہیں۔ پلیٹ فارم کے تحت کھلاڑی کا اکاؤنٹ فی کھلاڑی کی ترتیبات)، اور saves (د گیم کی بچت، ڈیوائس پر اور پلیئرز میں بادل بچانے کی سلاٹ تنازعہ کے ساتھ ہینڈلنگ)۔

آن لائن کھیل. ہر وہ چیز جو پلیٹ فارم گیم پیش کرتا ہے۔ starhermit:platform آپ کے کھیل کے لیے اپنی شناخت: دوست اور موجودگی، دعوتیں، حقیقی وقت کے کمرے, matchmaking, the کھیل ساکٹ (connectGame)، لیڈر بورڈز، کامیابیاں، ری پلے، چیٹ اور آواز۔ سرور سے مستند ملٹی پلیئر کے لیے، اعلان کریں a کھیل سکرپٹ:

server=server.js

پلیٹ فارم اسے آپ کے گیم کے سیشنز کی اتھارٹی کے طور پر چلاتا ہے۔ starhermit:script's authority("server.js", …) ایک ہی فائل کو مقامی کارکن پر آف لائن پریکٹس کے لیے چلاتا ہے، بالکل اسی طرح پلیٹ فارم کرتا ہے، لہذا آف لائن اور آن لائن پلے ایک کوڈ پاتھ کا اشتراک کرتے ہیں۔ لیڈر بورڈ کے اسکور، کامیابیاں اور میچ کے نتائج صرف سرور اسکرپٹ کے ذریعہ لکھے جاتے ہیں، کبھی بھی خود گیم کے ذریعہ نہیں؛ بورڈز بنائیں جیسا کہ میں بیان کیا گیا ہے۔ لیڈر بورڈ اور کامیابیاں.

8. اسے شائع کریں۔

ایک شائع شدہ اسکرپٹ گیم ایک عام StarHermit گیم ہے جس کی فائلیں آپ کا پیکج ہیں۔ کھلاڑی ڈھونڈتے ہیں۔ اسے starhermit.com پر اور ان کی لائبریری میں: صفحہ اسے براؤزر میں چلاتا ہے، اور StarHermit ونڈوز کلائنٹ اسے اس انجن کے ساتھ انسٹال کرتا ہے جسے یہ پن کرتا ہے اور اسے مقامی طور پر چلاتا ہے۔

اسے پیک کریں۔ ایک کمانڈ، اپ لوڈ کرنے سے پہلے آخری قدم کے طور پر ہر تبدیلی کے بعد چلائیں، لکھتا ہے۔ پلیٹ فارم اور کلائنٹ کو دو فائلیں گیم کے فولڈر میں درکار ہیں:

starhermit package --web star-catcher

  • index.html, the لوڈر صفحہ launch=index.html نام: صرف مارک اپ، اس کی اپنی کوئی اسکرپٹ نہیں۔ یہ ریلیز کو لوڈ کرتا ہے۔ starhermit.js اور manifest.json اس ویکی سے ان کے ایس آر آئی ہیشز کے ذریعے پن کیا گیا، اور انجن اس مینی فیسٹ کے خلاف لوڈ ہونے والی ہر دوسری فائل کو چیک کرتا ہے، لہذا صفحہ صرف چل سکتا ہے۔ وہ عین مطابق رہائی۔ اس میں ترمیم کرنے کے بجائے دوبارہ پیکیج کریں۔
  • starhermit-files.json, the فائل انڈیکس: ہر فائل اس کے سائز اور SHA-256 کے ساتھ۔ براؤزر انجن اس کے ذریعے پیکج کو پڑھتا ہے، اور کلائنٹ اس کے ذریعے گیم کو انسٹال اور اپ ڈیٹ کرتا ہے۔

یہ پلیٹ فارم کے اپ لوڈ قوانین کے خلاف پیکج کو چیک کرتا ہے (نمبر api/ یا ws/ فولڈرز، زیادہ سے زیادہ 9,998 راستے اور 50 MiB) اور آپ کے گیم پن کو جاری کریں، جو ویب رن ٹائم کے ساتھ شائع ہونا ضروری ہے اور منسوخ نہیں کیا. رن ٹائم اپنی ریلیز آف لائن چیک کرتا ہے۔ --engine-version X.Y.Z --manifest <a copy of that release> دوسرے کے لیے پیکجز۔ کھیل کا اپنا نہیں ہونا چاہیے۔ index.html; حکم سے انکار کرتا ہے اسے تبدیل کریں. starhermit package --native star-catcher لوڈر کے بغیر ایک ہی فائل انڈیکس لکھتا ہے، اس گیم کے لیے جو صرف کلائنٹ میں کھیلا جاتا ہے (کسی بھی سادہ صفحے کے ساتھ جس کا نام launch=).

اسے اپ لوڈ کریں۔ فولڈر اپ لوڈ ہے، بالکل جیسا کہ یہ ہے: براؤزر انجن اور کلائنٹ چیک ہر فائل انڈیکس کے خلاف ہے، لہذا فولڈر کی فائلوں کو بغیر تبدیلی کے اسی کے ساتھ اپ لوڈ کریں۔ starhermit.txt دونوں فولڈر کے اندر اور بنڈل کی جڑ پر (پلیٹ فارم فولڈر میں روٹ کاپی شائع کرتا ہے۔ جگہ)۔ جیسا کہ مقامی فولڈر سے ایک گیم شامل کریں۔:

mkdir -p bundle/client
cp -R star-catcher/. bundle/client/
rm -rf bundle/client/.starhermit
cp star-catcher/starhermit.txt bundle/starhermit.txt
tar -C bundle -czf star-catcher.tar.gz .

curl --fail-with-body -X POST https://api.starhermit.com/api/v1/me/github-games/upload \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H 'Content-Type: application/gzip' \
  --data-binary @star-catcher.tar.gz

ACCESS_TOKEN آپ کے اکاؤنٹ تک رسائی کا ٹوکن ہے (دیکھیں۔ CI/CD سے تعمیرات اپ لوڈ کریں۔ براؤزر کے بغیر سائن ان کرنے کے لیے)۔ جواب ہے game.id آپ کے گیم کی آئی ڈی ہے، اور گیم ایک ساتھ لائیو ہے۔ https://<id>.starhermit.com/. ہر بعد کے ورژن کے لیے، دوبارہ پیکج کریں اور اسی قسم کو پش کریں۔ کے ساتھ کھیل کے بنڈل کے POST /api/v1/me/github-games/{id}/bundle; پلیئرز کے کلائنٹ پھر صرف ان فائلوں کو ڈاؤن لوڈ کرتے ہیں جن کی ہیشز تبدیل ہوتی ہیں۔ اے server= اسکرپٹ میں اپ لوڈ شائع ہوتے ہی فولڈر کو گیم کا بیک اینڈ مل جاتا ہے۔

ایک مخزن سے۔ ایک کھیل GitHub سے شائع ہوا۔ اسی طرح کام کرتا ہے: پیکڈ فولڈر کا ارتکاب کریں (starhermit.txt اس کے ساتھ engine.* لائنیں index.html اور starhermit-files.json) مخزن کی جڑ میں۔ کلائنٹ ایک ریپوزٹری گیم کو انسٹال اور اپ ڈیٹ کرتا ہے۔ گٹ کے ساتھ، صرف وہی لانا جو ہر کمٹ میں شامل کرتا ہے۔

پیج کا لاک۔ پلیٹ فارم ایک گیم کے ہر صفحے کی خدمت کرتا ہے۔ starhermit.txt اعلان کرتا ہے engine.version مواد کی حفاظت کی پالیسی کے ساتھ جو صرف اس ویکی سے اسکرپٹ کو تسلیم کرتی ہے، لہذا صرف اسکرپٹ گیم کا صفحہ جو کوڈ چلا سکتا ہے وہ آفیشل انجن ہے (دیکھیں۔ انجن کی ریلیز)۔ آپ کا ٹائپ اسکرپٹ ایک میں چلتا ہے۔ کارکن انجن شروع ہوتا ہے؛ صفحہ خود صرف انجن چلاتا ہے: ان پٹ، رن ٹائم کے مینو، آڈیو، اسٹوریج اور پلیٹ فارم سیشن۔

9. ایک نئے انجن میں منتقل کریں۔

ایک گیم بالکل اسی ریلیز پر چلتی ہے جس پر یہ پن کرتا ہے: کچھ بھی اسے آپ کی پیٹھ کے پیچھے اپ گریڈ نہیں کرتا ہے، اور ایک شائع ہوتا ہے۔ رہائی کبھی نہیں بدلتی۔ کسی نئے پر جانے کے لیے، اس کا رن ٹائم ڈاؤن لوڈ کریں، اپنا گیم چلائیں اور اس کی جانچ کریں۔ اس پر، پھر تبدیل کرکے دوبارہ پن کریں۔ engine.version میں starhermit.txt، دوبارہ پیکج کریں اور شائع کریں۔ پلیئرز کے کلائنٹ نئے انجن کو ایک بار ڈاؤن لوڈ کرتے ہیں (صرف وہی جو ان کی ریلیز سے تبدیل ہوا ہے۔ ہولڈ) اور آپ کے گیم کی فائلوں کو تبدیل کریں۔

ریلیز کا بڑا ورژن میزبان API کا ہے: engine.api=1 گیمز 1.x.x کے اندر آزادانہ طور پر حرکت کرتے ہیں۔ ایک کھیل جس کے لیے ایک معمولی ورژن میں شامل ہوسٹ API ممبران کی ضرورت ہے اس کے ساتھ ایسا کہہ سکتے ہیں۔ engine.minor=N; ایک پرانا رن ٹائم پھر اسے بعد میں ناکام ہونے کے بجائے ایک پیغام کے ساتھ انکار کرتا ہے۔

غیر محفوظ پائی جانے والی ریلیز ہے۔ منسوخ کر دیا: versions.json کے ساتھ نشان زد کرتا ہے۔ وجہ، کلائنٹ اسے انسٹال کرنے یا شروع کرنے سے انکار کرتا ہے (اور کھلاڑی کو بتاتا ہے کہ کیوں)، اور پیکیجنگ جب بھی وہ versions.json پڑھتے ہیں تو کمانڈز اس سے انکار کرتے ہیں۔ منسوخ شدہ ریلیز کے بعد ہمیشہ ایک مقررہ ہوتا ہے۔ اسے دوبارہ پن کریں اور شائع کریں۔

10. حدود اور لائسنس

رن ٹائم ہر گیم کو بجٹ کے اندر رکھتا ہے، جس کے ساتھ پیکج کم ہو سکتا ہے۔ engine.limits.* لیکن کبھی نہ بڑھائیں: ہر کال بیک کے لیے 32 ایم ایس اسکرپٹ ٹائم (ایک کال بیک جو اسے استعمال کرتا ہے اسے روک دیا جاتا ہے اور اگلے فریموں پر جاری ہے؛ تین سیکنڈ کے بعد رن ٹائم "جواب نہیں دے رہا" سکرین کی اجازت دیتا ہے کھلاڑی انتظار کریں یا کھیل کو روکیں)، ایک 256 MiB اسکرپٹ ہیپ، 64 MiB اسٹوریج، زیادہ سے زیادہ 512 MiB اور 65,536 ایک پیکیج میں فائلیں اور، اپ لوڈز کے لیے، پلیٹ فارم کے 50 MiB اور 9,998 راستے۔ جہاں ایک حد سے گزر رہے ہیں۔ ایک آپریشن ناکام ہو سکتا ہے (ایک مختص، ایک میزبان کال) پھینک دیتا ہے a RangeError; ڈھیر یا کال ختم ہو رہی ہے۔ گہرائی غلطی کی سکرین پر کھیل کو ختم کرتی ہے۔ میزبان API کے اعلانات ہر حد کو درج کرتے ہیں۔
