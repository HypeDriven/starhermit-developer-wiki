ٹیوٹوریل: اپنے گیم میں کنٹرولز شامل کریں۔

StarHermit ذخیرہ کر سکتے ہیں کلیدی پابندیاں آپ کے کھیل کے لیے: آپ اعمال اور ان کی ڈیفالٹ کلیدوں کا اعلان کرتے ہیں، اور ہر کھلاڑی انہیں دوبارہ باندھ سکتا ہے۔ ان کی پسند ان کی پیروی کسی بھی مشین پر کرتی ہے جس پر وہ سائن ان کرتے ہیں۔ آپ کا کھیل کنٹرول API سے پلیئر کی پابندیوں کو پڑھتا ہے اور اپنی پیشکش کر سکتا ہے۔ "چابیاں دوبارہ باندھیں۔" سکرین

اگر آپ کا گیم کنٹرول API کو کال کرتا ہے اور اسے ملتا ہے:

404 {"error":"This game declares no controls."}

پلیٹ فارم ہے کوئی اعلان شدہ کارروائیاں نہیں۔ تعمیر کے لئے یہ خدمت کر رہا ہے. آپ جو کچھ بھی API کو بھیجتے ہیں وہ نہیں کر سکتا اسے ٹھیک کریں: آپ کے گیم میں کنٹرولز کا اعلان کیا جاتا ہے۔ starhermit.txt اور جب پڑھیں کھیل شائع ہوا ہے. یہ صفحہ دکھاتا ہے کہ ان کا اعلان کیسے کریں، انہیں شائع کریں، چیک کریں کہ وہ پہنچے ہیں، اور انہیں اپنے کلائنٹ سے استعمال کریں۔

  1. اعمال کا اعلان کریں۔
  2. انہیں شائع کریں۔
  3. چیک کریں کہ وہ پہنچے ہیں۔
  4. انہیں اپنے کھیل میں استعمال کریں۔
  5. خرابی کا سراغ لگانا

1. اعمال کا اعلان کریں۔

ایک شامل کریں۔ control.<action>= لائن فی عمل starhermit.txt:

name=Space Hopper
launch=index.html

control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.jump=Space+KeyW | Jump
control.fire=KeyJ | Fire
control.pause=Escape | Pause

ہر لائن کے تین حصے ہوتے ہیں:

control.<action>=<code>[+<code>...][ | <label>]
حصہ قواعد
<action> کارروائی کے لیے آپ کے گیم کا نام: چھوٹے حروف کے 1–32 حروف، ہندسے اور _ (move_left، نہیں move-left)۔ منفرد فی منشور۔
<code> A KeyboardEvent.code قدر، جیسے KeyA, ArrowLeft, Space, Digit1, ShiftLeft, Enter یا Escape. اسی کارروائی کے لیے 1–4 کوڈز میں شامل ہوں۔ +.
<label> اختیاری ری بائنڈنگ اسکرینوں میں دکھایا گیا ہے۔ زیادہ سے زیادہ 64 حروف۔ کارروائی کے نام سے پہلے سے طے شدہ۔

جاننے کی چیزیں:

  • استعمال کریں۔ code، نہیں key. لکھیں۔ KeyA، نہیں a، اور Space، نہیں " ". کوڈز فزیکل کا نام دیتے ہیں۔ کلید، تو بائنڈنگز کسی بھی کی بورڈ لے آؤٹ پر کام کرتی ہیں۔ پلیٹ فارم صرف چیک کرتا ہے کہ کوڈ 1–32 ہے۔ حروف اور ہندسوں، تو a یا space قبول کیا جاتا ہے لیکن کوئی کلید اسے پیدا نہیں کرتی ہے۔ ہجے اور کیس بالکل مماثل ہونا چاہئے.
  • ایک کلید ایک عمل سے تعلق رکھتی ہے۔ ایک کوڈ جو پہلے سے پہلے کی لائن کے ذریعہ استعمال ہوتا ہے بعد کی لائن بناتا ہے۔ غلط
  • 32 اعمال تک فی کھیل. 32 ویں کے بعد کی لائنوں کو نظر انداز کر دیا گیا ہے۔
  • آرڈر رکھا ہے۔ کارروائیاں API سے مینی فیسٹ آرڈر میں واپس آتی ہیں، لہذا ان کی فہرست بنائیں آپ کی ترتیبات کی سکرین انہیں دکھانی چاہیے۔
  • ایک غلط لائن خاموشی سے چھوڑ دی جاتی ہے۔ گیم اب بھی شائع ہوتا ہے۔ اگر ہر سطر غلط ہے، گیم کا کوئی کنٹرول اور API جوابات نہیں ہیں۔ 404. شائع کرنے کے بعد چیک کریں۔.

2. انہیں شائع کریں۔

اعلانات پڑھے جاتے ہیں۔ جب کھیل شائع ہوتا ہے۔. ترمیم کرنا starhermit.txt آپ کے ذخیرے میں یا ڈسک پر کچھ بھی نہیں بدلتا جب تک کہ آپ کوئی ایسی تعمیر شائع نہ کریں جس میں یہ شامل ہو:

آپ کا گیم کیسے شائع ہوتا ہے۔ جو نئے کنٹرولز کو زندہ کرتا ہے۔
GitHub ذخیرے سے آپ کی اگلی تعیناتی۔ تبدیلی کو دبائیں، پھر تازہ ترین ورژن تعینات کریں (تعینات ورژن کو اپ ڈیٹ کریں۔ ڈیش بورڈ میں، یا PUT /api/v1/me/github-games/{id}/deployment).
اپ لوڈ کردہ فولڈر یا بنڈل ایک نئی تعمیر اپ لوڈ کریں (POST /api/v1/me/github-games/{id}/bundle، یا ws/v1/game-uploadجس کا starhermit.txt لائنیں ہیں.
ایک نیا گیم شامل کرنا پہلا اپ لوڈ یا جمع کروانا انہیں فوراً پڑھتا ہے۔

اپ لوڈ کو تبدیل کرنے سے آپ کے کنٹرولز کو اپنے مینی فیسٹ سے بحال کیا جاتا ہے۔ ہر ایک کو ہٹا دیں۔ control.* لائن اور کھیل کوئی نہیں ہے. اے ?mode=merge اسے پیوند کریں لے جاتا ہے نمبر starhermit.txt موجودہ کنٹرول رکھتا ہے.

کھلاڑیوں کی اپنی ریبائنڈنگ ایک نئی تعمیر سے بچ جاتی ہے۔ ایک کھلاڑی کی ایک کارروائی کے لیے بائنڈنگ کو محفوظ کیا گیا ہے جو نہیں۔ اب موجود کو نظر انداز کر دیا گیا ہے۔

3. چیک کریں کہ وہ پہنچے ہیں۔

ذیل میں ہر اختتامی نقطہ مکمل صارف ٹوکن یا آپ کے گیم کے لانچ ٹوکن کے ساتھ کام کرتا ہے۔ {slug} آپ کا ہے گیم کا سلگ: لانچ ٹوکن game_scope دعوی، یا gameSlug میں GET /api/v1/me/github-games.

curl -s "https://api.starhermit.com/api/v1/games/$SLUG/controls" \
  -H "Authorization: Bearer $TOKEN" | jq

غائب اعمال کا مطلب ہے کہ ان کی لائنیں غلط تھیں۔ مندرجہ بالا قوانین کے خلاف ان کا موازنہ کریں. اے 404 اس کا مطلب ہے کہ کوئی بھی زندہ نہیں بچا، یا وہ تعمیر جو ان کا اعلان کرتی ہے ابھی تک شائع نہیں ہوئی ہے۔

4. انہیں اپنے کھیل میں استعمال کریں۔

codes کھلاڑی کی مؤثر پابندی ہے: اگر وہ ایک سیٹ کرتے ہیں تو ان کا اوور رائڈ، بصورت دیگر آپ کا ڈیفالٹ۔ اس سے ایک تلاش بنائیں اور میچ کریں۔ event.code:

const auth = { Authorization: `Bearer ${launchToken}` };

// Your built-in defaults, in the same shape the API returns.
const DEFAULT_ACTIONS = [
  { action: "left", label: "Move left", codes: ["KeyA", "ArrowLeft"] },
  { action: "jump", label: "Jump", codes: ["Space", "KeyW"] },
  /* ... */
];

function toControls(actions) {
  const byCode = new Map();
  for (const a of actions) for (const code of a.codes) byCode.set(code, a.action);
  return { actions, byCode };
}

async function loadControls(slug) {
  try {
    const res = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
    if (res.ok) return toControls((await res.json()).actions);
  } catch { /* offline: fall through */ }
  return toControls(DEFAULT_ACTIONS);                   // 404, error, or outside StarHermit
}

let controls = await loadControls(gameScope);

window.addEventListener("keydown", (e) => {
  const action = controls.byCode.get(e.code);   // e.code, never e.key
  if (action) { e.preventDefault(); onAction(action, true); }
});
window.addEventListener("keyup", (e) => {
  const action = controls.byCode.get(e.code);
  if (action) onAction(action, false);
});

بلٹ ان ڈیفالٹس گیم کو آف لائن، StarHermit کے باہر، یا اگر کنٹرولز کے قابل رکھتے ہیں۔ درخواست ناکام ہو جاتی ہے. انہیں اپنے ساتھ قدم میں رکھیں control.* لائنیں

ایک ری بائنڈنگ اسکرین۔ فہرست actions ان کے ساتھ label. مکمل اوور رائڈ نقشہ رکھیں، یا ایک عمل کو تبدیل کرنے سے پہلے موجودہ موثر نقشے کو پڑھیں اور محفوظ کریں:

async function saveBinding(slug, action, codes) {
  const current = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
  if (!current.ok) throw new Error(`Controls read failed: ${current.status}`);
  const bindings = Object.fromEntries((await current.json()).actions.map(a => [a.action, a.codes]));
  bindings[action] = codes;
  const res = await fetch(`/api/v1/games/${slug}/controls`, {
    method: "PUT",
    headers: { ...auth, "Content-Type": "application/json" },
    body: JSON.stringify({ bindings }),
  });
  if (!res.ok) throw new Error((await res.json()).error);   // e.g. a key already in use
  return res.json();                                         // the new effective map
}

PUT پلیئر کے اوور رائیڈز کو آپ کی بھیجی ہوئی کارروائیوں سے بدل دیتا ہے، اس لیے کھلاڑی کی ہر کارروائی کو شامل کریں۔ بدل گیا ہے، نہ صرف تازہ ترین۔ باقی آپ کے ڈیفالٹس پر رہیں۔ DELETE اسی راستے پر ہر چیز کو ڈیفالٹس پر ری سیٹ کرتا ہے۔

اپنی اسکرین سے تبدیلیوں کو سیریلائز کریں۔ دو بیک وقت پڑھنا/لکھنا اب بھی ایک دوسرے کو اوور رائٹ کر سکتے ہیں۔ براؤزر SDK کا setControl() اپنی تبدیلیوں کو سیریلائز کرتا ہے اور موجودہ موثر نقشے کو محفوظ رکھتا ہے۔ موثر نقشہ بھیجنا ان اقدار کو اوور رائیڈ کے طور پر پن کرتا ہے۔ استعمال کریں DELETE مینی فیسٹ ڈیفالٹس پر واپس جانے کے لیے۔

پلیٹ فارم محفوظ کرنے سے انکار کرتا ہے (400) جو دو کاموں پر ایک کلید چھوڑ دے گا۔ کے بعد کھلاڑی کی تبدیلیاں آپ کے ڈیفالٹس کے ساتھ مل جاتی ہیں۔ مثال کے طور پر، پابند jump کو KeyJ جبکہ fire اب بھی اپنا ڈیفالٹ استعمال کرتا ہے۔ KeyJ انکار کر دیا ہے. غلطی دکھائیں، یا متضاد کارروائی کو اسی میں منتقل کریں۔ محفوظ کریں

خرابی کا سراغ لگانا

جواب وجہ درست کریں۔
404 "یہ کھیل کسی کنٹرول کا اعلان نہیں کرتا ہے۔" کوئی درست نہیں۔ control.* میں لائن شائع تعمیر میں لائنیں شامل کریں۔ starhermit.txt، ان کے خلاف چیک کریں۔ قوانین، اور ایک نئی تعمیر شائع کریں.
404 "اس سلگ کے ساتھ کوئی کھیل نہیں۔" سلگ غلط ہے، یا گیم میں کوئی سلگ نہیں ہے۔ لانچ ٹوکن کا استعمال کریں۔ game_scope یا gameSlug سے GET /me/github-games. مقامی فولڈر سے شامل کردہ ہر گیم اور تصدیق شدہ مالک کے شامل کردہ ہر ریپوزٹری گیم میں ایک سلگ ہے، صرف براؤزر ہے یا نہیں۔ صرف ایک ذخیرہ جمع کرانا جس کا مالک تصدیق شدہ نہیں ہے کوئی نہیں ہے۔ اس کا دعوی کریں ایک حاصل کرنے کے لئے.
403 "اس ٹوکن کا دائرہ گیم '…' تک ہے۔" کسی دوسرے گیم کے سلگ کے ساتھ استعمال ہونے والا لانچ ٹوکن۔ ٹوکن میں سلگ کے ساتھ کال کریں۔ game_scope.
400 "نامعلوم کارروائی '…' — گیم کے مینی فیسٹ میں اعلان نہیں کیا گیا۔" PUT ایک ایسی کارروائی کا نام دیا جو مینی فیسٹ کا اعلان نہیں کرتا ہے۔ استعمال کریں۔ action سے اقدار GET …/controls.
400 "'…' '…' اور '…' دونوں کا پابند ہے۔" آپ کے ڈیفالٹس کے ساتھ ضم ہونے کے بعد، ایک کلید دو کاموں کو متحرک کرے گی۔ دوسری کارروائی کو اسی میں منتقل کریں۔ PUT، یا کوئی اور کلید چنیں۔
400 "'…' ایک درست KeyboardEvent.code قدر نہیں ہے۔" خالی جگہوں یا اوقاف کے ساتھ ایک کوڈ۔ بھیجیں۔ event.code اقدار
400 "ایکشن '…' کو 1–4 کوڈز کا پابند ہونا چاہیے۔" ایک خالی فہرست، یا چار سے زیادہ۔ 1-4 کوڈ بھیجیں؛ DELETE دوبارہ ترتیب دینے کے لیے
جواب میں ایک عمل غائب ہے۔ اس کی لائن غلط تھی: ایک بڑے حرف یا - عمل کے نام پر، , کے بجائے +، 4 سے زیادہ کوڈز، پہلے سے استعمال شدہ کوڈ، یا 32 ویں کارروائی کے بعد۔ لائن درست کریں اور دوبارہ شائع کریں۔
بائنڈنگ کبھی فائر نہیں ہوتی کوڈ کو قبول کیا جاتا ہے لیکن کوئی کلید اسے تیار نہیں کرتی ہے، جیسے a یا space. عین مطابق استعمال کریں۔ KeyboardEvent.code ہجے: KeyA, Space.

یہ بھی دیکھیں: گیمز API - فی پلیئر کنٹرول بائنڈنگز, starhermit.txt.
