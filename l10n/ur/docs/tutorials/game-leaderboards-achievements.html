ٹیوٹوریل: لیڈر بورڈز اور آپ کے گیم کے لیے کامیابیاں

اگر آپ StarHermit پر ایک گیم کے مالک ہیں، تو آپ اس کے پبلشر ہیں۔ آپ دے سکتے ہیں۔ لیڈر بورڈز (اعلی اسکور، تیز ترین دوڑ، سب سے طویل سلسلہ) اور کامیابیاں پبلشر اکاؤنٹ یا کسی خاص کے بغیر اجازت کھیل کا مالک ہونا بس اتنا ہی ہوتا ہے۔

اس صفحے پر ہر چیز کے پیچھے ایک اصول ہے: آپ ان کی وضاحت کرتے ہیں، آپ کے گیم کا سرور لکھتا ہے۔ انہیں کسی کھلاڑی کا کلائنٹ کبھی بھی اسکور پوسٹ نہیں کر سکتا اور نہ ہی ان کے لیے کامیابی کا دعویٰ کر سکتا ہے، اور آپ کے سرور کو اس گیم پلے کی توثیق کرنی چاہیے جو انہیں کماتا ہے۔ براہ راست API جمع کرانے سے انکار اکیلے ترمیم شدہ کلائنٹ کو گیم ایونٹس ایجاد کرنے سے نہیں روکتا۔ اسی لیے گیم کو ایک مستند پسدید کی ضرورت ہے: a server= سکرپٹ یا a container.image= میں starhermit.txt.

یہ ٹیوٹوریل ایک چھوٹے سے آرکیڈ گیم کے لیے دونوں بناتا ہے، اسٹار کلیکٹر: ایک رن اس وقت ختم ہوتا ہے جب کھلاڑی کریش ہو جاتا ہے، اور اس میں کل پوائنٹس اور رن ٹائم ہوتا ہے۔

  1. اس سے پہلے کہ آپ شروع کریں۔
  2. لیڈر بورڈز بنائیں
  3. کامیابیاں بنائیں
  4. اسکور پوسٹ کریں اور اپنی اسکرپٹ سے کامیابیوں کو غیر مقفل کریں۔
  5. ایک کنٹینر سے وہی
  6. انہیں اپنے کھیل میں دکھائیں۔
  7. ان کا خیال رکھیں

اس سے پہلے کہ آپ شروع کریں۔

آپ کو ضرورت ہے:

  • سرور پسدید کے ساتھ ایک کھیل جو آپ کے مالک ہیں: ایک جو آپ نے اپنے ذخیرے سے شامل کیا، اپ لوڈ کیا۔ ایک فولڈر کے طور پر، یا دعوی کیا. صرف براؤزر گیم جواب دیتا ہے۔ 409 ہر کال پر نیچے، ایک پیغام کے ساتھ کہ کیوں۔
  • ایک مکمل صارف تک رسائی کا ٹوکن، گیم کا لانچ ٹوکن نہیں۔ لانچ ٹوکن گیمز پر باڑ لگے ہوئے ہیں۔ کھلاڑی کی سطح اور پہنچ نہیں سکتے /me/....
  • آپ کے گیم کی آئی ڈی (یہ بھی اس کا ہے۔ <id>.starhermit.com پتہ):
ACCESS_TOKEN='your-full-user-access-token'
API=https://api.starhermit.com

curl -s "$API/api/v1/me/github-games" -H "Authorization: Bearer $ACCESS_TOKEN" |
  jq '.[] | {id, displayName, gameSlug}'

GAME_ID='the-id-from-above'

gameSlug وہی ہے جسے آپ کا کلائنٹ گیم کہتا ہے۔ /api/v1/games/{slug}/.... ہر گیم جو آپ نے شامل کیا۔ یا اپ لوڈ کردہ میں ایک، صرف براؤزر والے گیمز شامل ہیں، لہذا یہ آپ کو نہیں بتاتا کہ آیا کوئی سرور موجود ہے: GET /api/v1/games/{slug} کرتا ہے - یہ جواب دیتا ہے۔ 404 جب تک کہ گیم کا بیک اینڈ نہ ہو۔

1. لیڈر بورڈز بنائیں

سٹار کلیکٹر کو دو بورڈ ملتے ہیں: زیادہ تر پوائنٹس (زیادہ بہتر ہے) اور تیز ترین 100 پوائنٹس (کم) بہتر ہے)۔

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/leaderboards" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "high-score", "name": "High score",
        "scoreType": "integer", "sortDirection": "desc",
        "minScore": 0, "maxScore": 1000000 }'

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/leaderboards" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "fastest-100", "name": "Fastest to 100",
        "scoreType": "time-ms", "sortDirection": "asc" }'

ہر کال واپس آتی ہے۔ 201 اور بورڈ، بشمول اس کے id اور key. آپ کا سرور استعمال کرتا ہے۔ کلید, تو اسے احتیاط سے منتخب کریں. چابی، scoreType اور sortDirection بعد میں تبدیل نہیں کیا جا سکتا.

scoreType قبول کرتا ہے۔
integer پورے نمبر
decimal کوئی بھی نمبر
time-ms مکمل، غیر منفی ملی سیکنڈ

سیٹ minScore/maxScore آپ کا گیم اصل میں کیا پیدا کر سکتا ہے۔ ان کے باہر ایک سکور گرا دیا جاتا ہے، جو آپ کے اپنے سرور کی منطق میں بگ کے خلاف سستا محافظ ہے۔

2. کامیابیاں بنائیں

آپ گیم کی کامیابیاں دو طریقوں سے دے سکتے ہیں، اور آپ دونوں کو ایک ساتھ استعمال کر سکتے ہیں:

کوڈ میں بیان کیا گیا ہے۔ API کے ذریعے تخلیق کیا گیا۔
جہاں game.achievements آپ کے اسکرپٹ میں، یا /describe آپ کے کنٹینر میں POST /me/github-games/{id}/achievements
کی طرف سے تبدیل اپ ڈیٹ شائع کرنا ایک API کال، فوری طور پر نافذ ہو رہی ہے۔
کے لیے اچھا ہے۔ کامیابیاں جن کے ارد گرد آپ کا کوڈ بنایا گیا ہے۔ بغیر کسی ریلیز کے کچھ کو شامل کرنا یا دوبارہ لکھنا

آپ کے سرور کے ذریعہ کلید واپس کرنے کے ذریعہ دونوں قسمیں اسی طرح غیر مقفل ہیں۔ یہاں ہم دو کے ذریعے تخلیق کرتے ہیں۔ API:

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "century", "name": "Century",
        "description": "Collect 100 stars in one run.", "points": 10 }'

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "untouchable", "name": "Untouchable",
        "description": "Reach 500 points without losing a shield.",
        "points": 50, "secret": true }'

A secret کامیابی کھلاڑیوں سے اس وقت تک پوشیدہ رہتی ہے جب تک کہ وہ اسے کھول نہ لیں۔

گیم کے پاس موجود ہر چیز کو دیکھنے کے لیے، بشمول آپ کے کوڈ کا اعلان کردہ کامیابیاں، ان کی فہرست بنائیں:

curl -s "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" | jq '.[] | {key, origin, unlocks}'

origin ہے declared آپ کے کوڈ سے کامیابیوں کے لیے اور owner آپ کی تخلیق کردہ کامیابیوں کے لیے یہاں آپ صرف ترمیم اور حذف کر سکتے ہیں۔ owner والے اے declared ایک آپ کے اگلے کی طرف سے واپس کر دیا جائے گا اپ ڈیٹ کریں، لہذا API انکار کرتا ہے (409) اور آپ اس کے بجائے اسے کوڈ میں تبدیل کرتے ہیں۔

3. اسکور پوسٹ کریں اور اپنی اسکرپٹ سے کامیابیوں کو غیر مقفل کریں۔

آپ کا اسکرپٹ اپنی واپسی کی قیمت میں دونوں قسم کے نتائج کی اطلاع دیتا ہے۔ یہ کسی بھی ہک سے کر سکتا ہے: createSession, onPlayerMessage یا onTick.

  • scores: بورڈ کی کلید → پلیئر آئی ڈی → نمبر۔
  • achievements: پلیئر آئی ڈی → انلاک کرنے کے لیے کیز۔
'use strict';

function endRun(ctx, s, playerId) {
  var run = s.runs[playerId];
  var scores = { "high-score": {} };
  scores["high-score"][playerId] = run.points;
  if (run.reached100At) {
    scores["fastest-100"] = {};
    scores["fastest-100"][playerId] = run.reached100At - run.startedAt;
  }

  var unlocked = [];
  if (run.stars >= 100) unlocked.push("century");
  if (run.points >= 500 && !run.lostShield) unlocked.push("untouchable");
  var achievements = {};
  achievements[playerId] = unlocked;

  run.over = true;
  return {
    ok: true,
    sessionState: s,
    scores: scores,
    achievements: achievements,
    broadcast: [{ to: [playerId], data: { type: "run-over", points: run.points } }]
  };
}

globalThis.game = {
  tickRateHz: 10,

  createSession(ctx) {
    var runs = {};
    ctx.players.forEach(function (p) {
      runs[p.id] = { points: 0, stars: 0, lostShield: false, startedAt: ctx.now,
                     reached100At: null, over: false };
    });
    return { ok: true, sessionState: { runs: runs } };
  },

  onPlayerMessage(ctx) {
    var s = ctx.sessionState;
    var from = ctx.message.from;
    var run = s.runs[from];
    var msg = ctx.message.data || {};
    if (!run || run.over) return { ok: false, error: "No run in progress" };

    // The client reports what happened; the script decides what it is worth.
    if (msg.type === "collect") {
      run.stars += 1;
      run.points += 5;
      if (run.points >= 100 && !run.reached100At) run.reached100At = ctx.now;
      return { ok: true, sessionState: s };
    }
    if (msg.type === "shield-lost") {
      run.lostShield = true;
      return { ok: true, sessionState: s };
    }
    if (msg.type === "crash") return endRun(ctx, s, from);
    return { ok: false, error: "Unknown command" };
  },

  onTick(ctx) { return { ok: true }; }
};

چیزیں جو آپ کرتے ہیں۔ نہیں سنبھالنے کی ضرورت ہے:

  • بدتر سکور۔ ہر کھلاڑی ہر بورڈ پر اپنا بہترین اسکور رکھتا ہے، جس کا فیصلہ بورڈ کے ذریعے کیا جاتا ہے۔ sortDirection. ہر رن کی اطلاع دیں اور پلیٹ فارم بہترین رکھتا ہے۔
  • انلاک کو دہرائیں۔ کسی کھلاڑی کے پاس پہلے سے موجود کسی چیز کو غیر مقفل کرنے سے کچھ نہیں ہوتا، لہذا کلید واپس کریں۔ جب بھی حالت برقرار رہتی ہے۔
  • کسی اور کی آئی ڈی۔ ان لوگوں کے لیے سکور اور انلاک جو سیشن میں نہیں ہیں، بشمول AI نشست، نظر انداز کر رہے ہیں.

نامعلوم کلیدیں، غیر فعال بورڈز اور رینج سے باہر کے سکور خاموشی سے چھوڑ دیے جاتے ہیں۔ آپ کا اسکرپٹ نمبر ملتا ہے۔ ان کے لیے غلطی، اس لیے اپنے بورڈز کو ایک بار چیک کریں۔ سیکشن 4.

ایک حقیقی گیم میں سرور کو اپنی مستند حالت سے پوائنٹس اور اوقات کا کام کرنا چاہیے، نہیں۔ اعتماد collect پیغامات جیسے وہ ہیں۔ رپورٹنگ کو دکھانے کے لیے اس مثال کو مختصر رکھا گیا ہے۔ کھیل ہی کھیل میں سکرپٹ مکمل واپسی کی شکل کا معاہدہ ہے۔

3b. ایک کنٹینر سے وہی

ایک کنٹینر گیم اپنے کنٹرول WebSocket پر ایک ہی دو چیزیں بھیجتا ہے:

{ "type": "scores", "sessionId": "…",
  "scores": { "high-score": { "<userId>": 740 }, "fastest-100": { "<userId>": 41250 } } }

{ "type": "achievements", "sessionId": "…",
  "unlocks": { "<userId>": ["century"] } }

scores کسی بھی جوابی لفافے میں بھی شامل کیا جا سکتا ہے جس سے آپ کا کنٹینر واپس آتا ہے۔ /sessions. دی وہی اصول لاگو ہوتے ہیں: صرف شرکاء، بہترین سکور رکھا گیا، نامعلوم کلیدوں کو نظر انداز کر دیا گیا۔ دیکھیں کنٹینر گیم سرورز.

4. انہیں اپنے کھیل میں دکھائیں۔

آپ کا کلائنٹ پہلے سے موجود لانچ ٹوکن کے ساتھ سب کچھ پڑھتا ہے۔ یہاں کسی چیز کی ضرورت نہیں ہے۔ مالک کا نشان

بورڈز تلاش کریں۔

const boards = await api(`/api/v1/games/${slug}/leaderboards`);
// [{ id, key: "high-score", name: "High score", sortDirection: "desc", ... }, ...]
const high = boards.find(b => b.key === "high-score");

صرف فعال بورڈز درج ہیں۔

ایک بورڈ پڑھیں۔

const page = await api(`/api/v1/leaderboards/${high.id}/entries?page=1&pageSize=10`);
// { items: [{ rank, username, score, ... }], total, page, pageSize }
const friends = await api(`/api/v1/leaderboards/${high.id}/entries?friendsOnly=true&pageSize=10`);

کے لیے time-ms بورڈ، اسکور کو ایک وقت کے طور پر فارمیٹ کریں: 41250 → 0:41.25.

کامیابیاں۔

  • GET /api/v1/games/{slug}/achievements کھلاڑی کے ساتھ ہر کامیابی کی فہرست unlocked ریاست راز اس وقت تک پوشیدہ رہتے ہیں جب تک وہ حاصل نہ کر لیں۔
  • انلاک خود براہ راست پہنچتا ہے۔ ws/v1/games کے طور پر {"type":"achievement","data":{key,name,description,points,...}}. جب ایسا ہو تو ٹوسٹ دکھائیں۔ لوڈ پر فہرست کال ساکٹ کے بند ہونے کے دوران غیر مقفل کسی بھی چیز کو پکڑتی ہے۔

دیکھیں کامیابیاں کے لیے فریم

5. ان کی دیکھ بھال کریں۔

بورڈ کا نام تبدیل کریں یا اس کی حدود کو تبدیل کریں۔

curl -s -X PUT "$API/api/v1/me/github-games/$GAME_ID/leaderboards/$BOARD_ID" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "name": "All-time high score", "maxScore": 2000000 }'

نئی حدیں صرف نئے سکور پر لاگو ہوتی ہیں۔

بورڈ کو ریٹائر کریں لیکن اس کے اسکور رکھیں۔ بھیجیں۔ { "isActive": false }. بورڈ قبول کرنا چھوڑ دیتا ہے۔ اسکور کرتا ہے اور گیم کی فہرست سے غائب ہوجاتا ہے۔ اس کے اندراجات اب بھی id کے ذریعے پڑھے جا سکتے ہیں۔

شیڈول پر دوبارہ ترتیب دیں۔ ایک بورڈ دیں۔ "resetSchedule": "daily", "weekly" یا "monthly" (پر بنائیں، یا بعد میں اس کے ساتھ PUT) اور یہ ہر دور میں 00:00 UTC پر شروع ہوتا ہے — a کے لیے بہترین "یہ ہفتے کا بہترین" ہر وقت کے ساتھ بورڈ۔ آپ کے اسکرپٹ میں کرنے کے لیے کچھ نہیں: معمول کے مطابق اسکورز رپورٹ کریں، اور ہر کھلاڑی کے نئے پیریڈ کا پہلا سکور شمار ہوتا ہے۔ دیکھیں نظام الاوقات کو دوبارہ ترتیب دیں۔.

ہاتھ سے ایک تازہ سیزن شروع کریں۔ شیڈول کے بجائے ایک بار کے سیزن کے لیے، ایک نیا بورڈ بنائیں (high-score-s2)، اپنی اسکرپٹ کو اس کی طرف اشارہ کریں، اور پرانے کو ریٹائر کریں۔

بورڈ کو حذف کریں۔ DELETE .../leaderboards/{id} بورڈ اور اس کے تمام اندراجات کو ہٹاتا ہے، اور کالعدم نہیں کیا جا سکتا۔

کسی کارنامے میں ترمیم کریں۔ PUT .../achievements/{achievementId} کسی کے ساتھ name, description, icon, secret اور points. چابی کبھی نہیں بدلتی۔

ایک کارنامہ حذف کریں۔ یہ صرف اس کے لیے کام کرتا ہے جسے آپ نے بنایا ہے جسے ابھی تک کسی نے غیر مقفل نہیں کیا ہے۔ حاصل کردہ کامیابیاں مستقل ہیں۔

ایک کامیابی کو کوڈ میں منتقل کریں۔ میں اسی کلید کا اعلان کریں۔ game.achievements اور شائع کریں. دی اعلان موجودہ کامیابی پر قبضہ کرتا ہے، اور جن کھلاڑیوں کے پاس یہ ہے وہ اسے برقرار رکھتے ہیں۔

جواب مطلب
404 کھیل آپ کا نہیں ہے، یا بورڈ یا کارنامہ اس کا نہیں ہے۔
409 "…سرور پسدید…" کھیل نہیں ہے server= یا container.image=
409 "پہلے ہی ہے…" کلید ایک بورڈ کے ذریعہ یا اعلان کردہ یا تخلیق شدہ کامیابی کے ذریعہ لی جاتی ہے۔
409 "گیم کے سرور کے ذریعہ اعلان کیا گیا۔" اس کامیابی کو اپنے کوڈ میں تبدیل کریں۔
409 "پہلے سے ہی کھلا" کھلاڑی اسے پکڑتے ہیں، لہذا اسے حذف نہیں کیا جا سکتا
400 دوسرے حروف کے ساتھ ایک کلید، غائب نام، یا minScore > maxScore

حدود: 2048 لیڈر بورڈز اور فی گیم 200 تخلیق کردہ کامیابیاں، نیز 100 تک اعلان کردہ۔

چیک لسٹ

  • کھیل ایک ہے server= سکرپٹ یا container.image=، اور gameSlug میں مقرر ہے GET /me/github-games.
  • ہر بورڈ میں ایک مستحکم کلید اور دائیں ہوتی ہے۔ scoreType اور sortDirection (وہ بعد میں تبدیل نہیں ہو سکتے)۔
  • سرور واپس آتا ہے۔ scores اور achievements (اسکرپٹ) یا کنٹرول پیغامات (کنٹینر) بھیجتا ہے، مستند ریاست سے کام کیا جاتا ہے۔
  • کلائنٹ اس کے ساتھ بورڈ تلاش کرتا ہے۔ GET /games/{slug}/leaderboards، ان کی آئی ڈی کو کبھی ہارڈ کوڈ نہیں کرتا ہے، اور آئی ڈی کے ذریعہ اندراجات پڑھتا ہے۔
  • کلائنٹ لوڈ کرتا ہے۔ GET /games/{slug}/achievements اور پر ٹوسٹ دکھاتا ہے۔ achievement فریم
  • پرانے بورڈز کے ساتھ ریٹائرڈ ہیں۔ isActive: false حذف کرنے کے بجائے، جب تک کہ آپ واقعی اسکور ختم نہیں کرنا چاہتے۔
