ٹیوٹوریل: اپنے گیم کو مقامی بنائیں اور زبان کی ترتیبات شامل کریں۔

اپنا کھیل دیں a زبان اس کے سیٹنگ مینو میں سیکشن کے ساتھ گرافکس, آڈیو، اور کنٹرول کرتا ہے۔. اسے مین مینو سے اور کھیل کے دوران دستیاب کرائیں۔ ایک ہی زبان کا سیٹ اور تصویر پر مبنی استعمال کریں۔ فلیگ سلیکٹر بطور StarHermit ویب سائٹ اور ڈویلپر ویکی۔ یہ گیم سائیڈ سفارشات ہیں۔ StarHermit آپ کی ترجیح کو اسٹور کرتا ہے لیکن گیم کا ترجمہ نہیں کرتا اور نہ ہی پہلے سے موجود لینگویج مینو فراہم کرتا ہے۔

معاون زبانیں اور لیبلز

درج ذیل دس زبانوں سے شروع کریں۔ یہ ویکی کے کل اسپیکر کے انتخاب سے میل کھاتا ہے۔ یہ ایک ہے ابتدائی سیٹ، دوسرے ترجمے کو ہٹانے کی ضرورت نہیں جو آپ کا گیم سپورٹ کرتا ہے۔ صرف زبانوں کی فہرست بنائیں جس کے مینو، گیم پلے ٹیکسٹ، اور فونٹس آپ اصل میں بھیجتے ہیں۔

لوکل کلید لیبل کھلاڑیوں کو دکھایا گیا ہے۔ سمت جھنڈا اثاثہ
en English بائیں سے دائیں برطانیہ
zh-CN 简体中文 بائیں سے دائیں چین
hi हिन्दी بائیں سے دائیں انڈیا
es Español بائیں سے دائیں سپین
ar العربية دائیں بائیں سعودی عرب
fr Français بائیں سے دائیں فرانس
bn বাংলা بائیں سے دائیں بنگلہ دیش
pt Português بائیں سے دائیں برازیل
id Bahasa Indonesia بائیں سے دائیں انڈونیشیا
ur اردو دائیں بائیں پاکستان

ہر زبان کا آبائی نام دکھائیں۔ جھنڈے ضمنی بصری اشارے ہیں: ممالک اور زبانیں۔ قابل تبادلہ نہیں ہیں، اور کئی زبانیں کئی ممالک میں بولی جاتی ہیں۔ متن کا لیبل رکھیں نظر آنے والا چھوٹے مقامی استعمال کریں SVG یا PNG تصاویر، پرچم ایموجی نہیں: کچھ آلات ایموجی جھنڈوں کو بطور دکھاتے ہیں۔ ملک کے کوڈز ان اثاثوں کو رن ٹائم کے وقت ویکی پر انحصار کرنے کے بجائے اپنی تعمیر میں کاپی کریں۔

ہر ترجمہ کی حقیقی علاقائی کوریج کا اعلان کریں۔ مثال کے طور پر، zh-CN یہاں آسان چینی ہے۔ اور پرتگالی جھنڈا برازیل کا اشارہ ہے۔ اے pt-BRاس کے مطابق مخصوص پیک کی نشاندہی کی جانی چاہئے۔ علیحدہ جہاز pt-PT یا روایتی چینی پیک جب آپ ان قسموں کو سپورٹ کرتے ہیں۔

ترتیبات کے مینو میں انتخاب ڈالیں۔

استعمال کریں۔ ترتیبات → زبان → گیم کی زبان. شامل کریں۔ خودکار (سسٹم کی زبان) اور اسے دکھائیں حل شدہ زبان، جیسے خودکار — انگریزی. موجودہ انتخاب کو مرئی رکھیں جب سلیکٹر بند ہے۔ خاکہ ایک واضح انگریزی انتخاب کو ظاہر کرتا ہے۔

سیکشن کو مندرجہ ذیل طرز عمل پیش کرنا چاہئے:

  • مینو، HUD، سبق، ٹول ٹپس، ایکسیسبیلٹی لیبلز اور مستقبل میں فوری طور پر تبدیلیاں لاگو کریں اطلاعات میچ کو دوبارہ شروع کیے بغیر، پیش رفت کو مسترد کیے بغیر، یا نظر آنے والے متن کو ریفریش کریں۔ ساکٹ کو دوبارہ جوڑنا۔ انتخاب کے بعد زبان کے کنٹرول پر توجہ مرکوز رکھیں۔
  • کی بورڈ قابل رسائی ڈراپ ڈاؤن یا انکشاف کا استعمال کریں، مرئی فوکس، ٹچ اہداف، اور ایک سکرول کی فہرست. گیم کے کنٹرولر نیویگیشن کو بھی سپورٹ کریں۔ فرار پر اور باہر بند کریں۔ کلکس؛ مادری زبان کے ناموں کو پڑھنے کے قابل رکھیں یہاں تک کہ جب باقی انٹرفیس بدل جائے۔
  • رکھو خودکار واضح انتخاب سے الگ۔ اسٹور auto, پتہ چلا زبان نہیں، تو دوسرا آلہ اپنی نظام کی زبان استعمال کرسکتا ہے۔ ایک واضح انتخاب کا پتہ لگانے پر جیتنا ضروری ہے۔
  • مؤثر زبان اور استقامت کی حالت دکھائیں: اکاؤنٹ میں محفوظ کر لیا گیا۔, اس ڈیوائس پر محفوظ کیا گیا۔, یا اکاؤنٹ کی مطابقت پذیری دستیاب نہیں ہے۔. ان پیغامات کا ترجمہ بھی کریں؛ محفوظ شدہ کے طور پر ناکام اپ لوڈ کی اطلاع نہ دیں۔

براؤزر گیم کے لیے، اصلی پرچم کی تصاویر والا انکشاف اس طرح نظر آ سکتا ہے۔ جھنڈوں کو اس میں کاپی کریں۔ flags/ اپنے گیم کے آگے، اور اوپر والے ٹیبل سے بقیہ انتخاب کو آباد کریں:

تار data-language آپ کے ترجمہ پیش کنندہ اور ترجیحی اسٹور پر۔ خلاصہ تصویر کو اپ ڈیٹ کریں، نام، منتخب ریاست کا اشارہ، اور حیثیت کا متن ایک ساتھ؛ انکشاف کو بند کریں اور توجہ مرکوز کریں اس کا خلاصہ. بٹنوں کو ایک منتخب ریاستی اشارے اور بامعنی قابل رسائی نام دیں۔ پرچم رکھو ان کے چھوٹے مقررہ سائز پر تصاویر: ڈایاگرام SVGs کے لیے وسیع اسٹائل ان کو بڑا نہیں کرنا چاہیے۔

ترجمہ پیک اور فال بیک

مثال کے طور پر مستحکم کلیدوں کے ساتھ ورژن والے پیک میں پلیئر کا سامنا کرنے والا متن رکھیں locales/en.json, locales/ar.json، اور locales/zh-CN.json. انگریزی کو مکمل سورس پیک بنائیں۔ پیغامات کو مکمل اکائیوں کے طور پر ترجمہ کریں، نامزد پلیس ہولڈرز کو برقرار رکھتے ہوئے؛ ترجمہ شدہ جملے میں شامل ہونے سے گریز کریں۔ ترجمے کے ماخذ کے تاروں میں ٹکڑے یا صارف کا ڈیٹا داخل کرنا۔

{
  "settings.language": "Language",
  "settings.gameLanguage": "Game language",
  "settings.automatic": "Automatic (system language)",
  "settings.saved": "Saved to account",
  "hud.coins": "{count} coins"
}

آخری اندراج ایک مستحکم کلید اور پلیس ہولڈر کی وضاحت کرتا ہے۔ کے لیے جمع سے آگاہ پیغام کا فارمیٹر استعمال کریں۔ حقیقی گنتی کے پیغامات۔ زبانوں کے مختلف جمع قواعد ہوتے ہیں۔ فارمیٹ نمبرز، تاریخیں، اوقات، اور مشکل کوڈ والے جداکاروں یا ورڈ آرڈر کے بجائے منتخب کردہ لوکیل والی کرنسی۔ وقت رکھیں اکائیاں، کرنسی کی مقدار، اور گیم کے قواعد میں کوئی تبدیلی نہیں ہوئی۔

اس ترتیب میں زبان کو حل کریں:

  1. کھلاڑی کی گیم کی ترتیبات سے ایک درست واضح انتخاب، یا ان کا موجودہ غیر مطابقت پذیر انتخاب۔
  2. کے لیے auto، آلہ کی زبان کی ترجیحات سے پہلا تعاون یافتہ میچ۔
  3. انگریزی جب کوئی تعاون یافتہ میچ موجود نہ ہو۔ انفرادی گمشدہ چابیاں کے لیے بھی انگریزی میں واپس آجائیں۔

مقامی ٹیگز کو غیر حساس طریقے سے میچ کریں، کنفیگر کیے جانے سے پہلے درست معاون خطہ/اسکرپٹ کو ترجیح دیتے ہوئے بنیادی زبان کا فال بیک۔ عمومی نقشہ zh یا zh-Hans آسان پیک میں صرف اس صورت میں جب وہ آپ کا ہو۔ شائع شدہ پالیسی؛ صرف ایک آسان پیک کو سپورٹ کے طور پر پیش نہ کریں۔ zh-Hant. ایک غیر تعاون یافتہ یا خراب شدہ ذخیرہ شدہ انتخاب کو محفوظ طریقے سے واپس آنا چاہیے۔ گمشدہ انگریزی سورس کیز کو توثیق میں ناکام ہونا چاہیے۔ خالی بٹن چھوڑنے کے بجائے اشاعت سے پہلے۔

ترقی کے دوران ترجمے تیار کریں اور گیم کے ساتھ پیک بھیجیں۔ مشین ترجمہ کر سکتے ہیں پہلا مسودہ تیار کریں؛ اس سے پہلے اصطلاحات، ہدایات، اور اہم کھلاڑی کا سامنا کرنے والے پیغامات کا جائزہ لیں۔ مکمل طور پر تعاون یافتہ زبان کو کال کرنا۔ غیر جائزہ شدہ تراجم کو مشین سے تیار کردہ کے بطور نشان زد کریں اور پیش کریں۔ انگریزی فال بیک۔ پلیس ہولڈرز، گیم ٹائٹلز، API روٹس، IDs، ایرر کوڈز، سیو کیز اور پروٹوکول رکھیں اقدار برقرار ہیں. غلطی کوڈ کی ظاہر کردہ وضاحت کا ترجمہ کریں، نہ کہ آپ کی منطق کے ذریعے استعمال کردہ کوڈ کا۔

دائیں سے بائیں متن، فونٹس اور گیم پلے

عربی اور اردو کے لیے، UI روٹ پر انٹرفیس کی زبان اور سمت متعین کریں۔ ایک براؤزر میں، مثال کے طور پر:

document.documentElement.lang = effectiveLocale;
document.documentElement.dir = ['ar', 'ur'].includes(effectiveLocale) ? 'rtl' : 'ltr';

منطقی سی ایس ایس خصوصیات کا استعمال کریں جیسے margin-inline-start, padding-inline-end، اور text-align: start. گیم پلے کے معنی کو محفوظ رکھتے ہوئے، مناسب انٹرفیس نیویگیشن اور سیدھ میں آئینے کوآرڈینیٹ، دشاتمک کنٹرول، دنیا کے نقشے، اور نقل و حرکت کے اشارے۔ تکنیکی ٹوکن رکھیں اور کوڈ بائیں سے دائیں دکھاتا ہے۔ کھلاڑیوں کے ناموں اور مخلوط سمت والی اقدار کو الگ کریں۔ <bdi> یا آپ کا انجن کے برابر کھلاڑی کی تصنیف کردہ چیٹ، نام، یا گیم کمانڈز کا خود بخود ترجمہ نہ کریں۔

مطلوبہ چینی، دیوناگری، بنگالی، عربی، اور اردو کے خطوط اور شکل سازی کی معاونت کے ساتھ فونٹس بھیجیں۔ اپنے اصل پیش کنندہ میں جڑے ہوئے عربی حروف، نشانات، لائن کی اونچائی، اور ریپنگ کو یکجا کرتے ہوئے چیک کریں۔ کینوس یا انجن HUDs کے لیے، اس کی تائید شدہ شکل سازی اور دو طرفہ متن کا راستہ استعمال کریں۔ ایچ ٹی ایم ایل dir اکیلے کسی ایسے پیش کنندہ کو ٹھیک نہیں کر سکتا جو متن کو غیر متعلقہ گلائف سمجھتا ہو۔ لمبے لیبلز اور سب ٹائٹلز کو لپیٹنے دیں۔ زبان بدلنے پر رینڈر ہکس کے ذریعے متن کو ریفریش کریں، ہر فریم کو مکمل UI اسکین کرنے سے گریز کریں۔

StarHermit کے ذریعے انتخاب کو محفوظ کریں۔

گیم کا استعمال کریں۔ فی کھلاڑی کی ترتیبات، کلاؤڈ سے بچاؤ کی پیشرفت نہیں۔ یا ایک اکاؤنٹ وسیع پروفائل فیلڈ۔ ایک پلیئر لانچ ٹوکن اپنے گیم کے لیے ترتیبات کو پڑھ اور لکھ سکتا ہے۔ اس کے لیے گیم پلے سرور یا ظاہری زبان کے اعلان کی ضرورت نہیں ہے۔

تجویز کردہ گیم کی ملکیت والی کلید ہے۔ ui.language، ایک قدر کے ساتھ جیسے { "choice": "fr" } یا { "choice": "auto" }. یہ نام آپ کا کنونشن ہیں، پلیٹ فارم کے مخصوص فیلڈز نہیں۔ پڑھیں اور لکھنے سے پہلے ترتیبات کی تصدیق کریں۔ ایک انفرادی کلیدی اپ ڈیٹ استعمال کریں تاکہ گرافکس، آڈیو اور کنٹرولز ترجیحات محفوظ ہیں.

کے ساتھ براؤزر SDKکے بعد StarHermit.init() اور عام سائن ان/ٹرمز فلو:

const supported = new Set(['en', 'zh-CN', 'hi', 'es', 'ar', 'fr', 'bn', 'pt', 'id', 'ur']);
const validChoice = choice => choice === 'auto' || supported.has(choice);
const settingsPath = `/api/v1/games/${encodeURIComponent(StarHermit.slug)}/settings`;

// Run only when StarHermit.signedIn; unsigned play uses no authenticated requests.
const response = await StarHermit.api(settingsPath);
if (!response || !response.settings || Array.isArray(response.settings) ||
    typeof response.settings !== 'object') {
  throw new Error('Settings could not be loaded'); // Keep account writes blocked.
}
const stored = response.settings['ui.language'];
const choice = validChoice(stored?.choice) ? stored.choice : 'auto';

// Later, on an explicit language change, after a successful settings read:
const nextChoice = 'fr'; // Your selector's validated value.
if (!validChoice(nextChoice)) throw new Error('Unsupported language choice');
const saved = await StarHermit.api(`${settingsPath}/ui.language`, {
  method: 'PUT', body: { value: { choice: nextChoice } },
});
if (!saved) throw new Error('Language preference was not acknowledged');

StarHermit.api زیادہ تر ناکامیوں کو مسترد کرتا ہے لیکن حل کرتا ہے۔ null پر 404, 204، یا سائن آؤٹ کالز؛ مثال گمشدہ ترتیبات اور ایک غیر تسلیم شدہ کلیدی اپ ڈیٹ کی جانچ کرتی ہے۔ سہولت getSettings() اور setSetting() مددگار غلطیوں کو فال بیک اقدار میں نرم کرتے ہیں، لہذا جب خام API استعمال کریں۔ ناکام پڑھنے یا لکھنے کو کامیابی کے معاملات سے ممتاز کرنا۔ ایک خالی کامیاب settings نقشہ ہے a نئی ترجیح؛ ایک ناکام درخواست نہیں ہے.
