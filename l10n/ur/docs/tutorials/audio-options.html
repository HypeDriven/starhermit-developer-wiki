ٹیوٹوریل: آڈیو کے اختیارات جس میں خودکار آواز کی حد کا پتہ چلا

اپنے کھیل کو ایک دیں۔ آڈیو ساتھ سیکشن گرافکسسے دستیاب ہے۔ مین مینو اور کھیل کے دوران۔ نیچے کی بنیاد کے ساتھ شروع کریں، کھلاڑیوں کو اسے اوور رائیڈ کرنے دیں، اور ایک کو نافذ کریں۔ اختلاط اور مقامی کاری کے کام کو پابند رکھنے کے لیے بیک وقت پلے بیک کی زیادہ سے زیادہ تعداد۔ یہ تجویز کردہ گیم سائیڈ ڈیفالٹس ہیں، نہ کہ پلیٹ فارم کی جانب سے نافذ کردہ ترتیبات۔ شامل کریں زبان کا سیکشن ترجمہ کے انتخاب کے لیے ان کنٹرولز کے ساتھ۔

audio-options.js حجم کے منحنی خطوط کے لیے انحصار سے پاک مددگار فراہم کرتا ہے، ترتیبات کی توثیق اور ایک قدامت پسند آٹو آواز کی حد۔ یہ کوئی آڈیو سیاق و سباق، مائکروفون نہیں بناتا ہے۔ کیپچر، مکسر، آپشن پینل یا نیٹ ورک کنکشن؛ آپ کا گیم کنٹرولز اور پلے بیک کو تار دیتا ہے۔

1. بیس لائن کنٹرولز

کنٹرول تجویز کردہ ابتدائی قیمت رویہ
ماسٹر والیوم 80% موصول ہونے والی آواز سمیت تمام گیم پلے بیک کو کنٹرول کرتا ہے۔
موسیقی والیوم 70% میوزک بس، ماسٹر سے ضرب
صوتی اثرات کا حجم 100% گیم پلے اثرات بس، ماسٹر سے ضرب
UI والیوم 80% مینو اور انٹرفیس بس، ماسٹر سے ضرب
آواز کا حجم 100% موصول آواز بس، ماسٹر سے ضرب؛ مائیکروفون گین کو کبھی نہیں بدلتا
زیادہ سے زیادہ سمورتی آوازیں۔ آٹو پتہ چلنے والی گنتی اور موثر حد دکھائیں۔ مقررہ 16، 32، 64، 128 اور گیم کی حد کے اندر ایک توثیق شدہ کسٹم گنتی کی پیشکش
وائس چیٹ آف واضح سیشن آپٹ ان؛ آواز سپورٹ ہونے پر پش ٹو ٹاک اور اوپن مائیکروفون پیش کریں۔
مائیکروفون / آؤٹ پٹ ڈیوائس سسٹم ڈیفالٹ پیشکش کا انتخاب جہاں تعاون یافتہ ہو؛ آلہ کے شناخت کنندگان کو مقامی رکھیں
بازگشت منسوخی / شور کو دبانا آن / آن حمایت یافتہ کیپچر پروسیسنگ کی درخواست کریں؛ مؤثر نتیجہ ظاہر کریں
خودکار مائکروفون فائدہ آف اختیاری کیپچر پروسیسنگ، پلے بیک والیوم سے آزاد

آواز کے بغیر گیمز میں صوتی کنٹرول چھپائیں۔ ہر سلائیڈر کو مرئی فیصد، قابل رسائی لیبل، کی بورڈ سپورٹ اور قابل استعمال ٹچ ٹارگٹ؛ پینل کو چھوٹی اسکرینوں پر اسکرول کرنے دیں۔ ایک واضح شامل کریں۔ خاموش کنٹرول جو پچھلی سطح کو یاد رکھتا ہے۔ دوبارہ لوڈ کیے بغیر فوری طور پر تبدیلیاں لاگو کریں۔ اختیاری فی شریک والیوم اور مقامی خاموش کھلاڑیوں کو آواز کے کمرے میں توازن میں مدد دیتے ہیں۔

سلائیڈر کی پوزیشنوں کو 0-1 کے طور پر سمجھیں اور استعمال کریں۔ volumeGain(position) (پوزیشن کیوبڈ) ایک ادراک وکر کے لئے۔ ہر بس کو اس کے اپنے نفع کے ذریعے جوڑیں، پھر ماسٹر گین، تو ماسٹر بالکل ایک بار لاگو ہوتا ہے۔ کلکس سے بچنے کے لیے ریمپ تقریباً 20 ms سے زیادہ حاصل کرتا ہے۔ صفر کو خاموش ہونا چاہیے۔ اثاثوں کو معمول بنائیں اور آؤٹ پٹ فراہم کریں۔ آوازیں اوورلیپ ہونے پر کلپنگ کو روکنے کے لیے ہیڈ روم یا ایک لمیٹر۔ صارف سے براؤزر پلے بیک کو غیر مقفل کریں۔ اشارہ کریں اور معطل سیاق و سباق کو ہینڈل کریں؛ غیر دستیاب آڈیو کو کھیل کے قابل چھوڑنا چاہیے۔

2. ایک سمجھدار ہم آہنگی کی حد کا خود بخود پتہ لگائیں۔

گرافکس پیش سیٹ یا GPU سے آزادانہ طور پر ڈیوائس کی قسم، CPU اور میموری کے اشارے استعمال کریں۔ ابتدائی پالیسی یہ ہے:

دستیاب اشارے (اوپر سے نیچے کا اندازہ کریں) گنتی شروع ہو رہی ہے۔
ایک فون یا ٹیبلیٹ، زیادہ سے زیادہ دو منطقی CPUs، یا زیادہ سے زیادہ 2 GB رپورٹ شدہ میموری 16
کم از کم چار منطقی CPUs، اوپر کی رکاوٹ کے بغیر 64
نامعلوم صلاحیت، یا مندرجہ بالا رکاوٹ کے بغیر چار سے کم CPUs 32

ریفرنس ہیلپر ان گنتی کو گیم کی سخت چھت پر رکھتا ہے، 64 بطور ڈیفالٹ، اور حدود اپنی مرضی کے مطابق چھتیں 1-256 تک۔ ایک ڈویلپر گیم کی پروفائلنگ کے بعد دستی طور پر 128 یا 256 کی اجازت دے سکتا ہے۔ آٹو ان کو اکیلے بنیادی شمار سے نہیں چنتا۔ ایک چھوٹا کھیل 16 یا 32 کی حد مقرر کر سکتا ہے۔ فون یا ٹیبلیٹ وہ ہے جس کا براؤزر Chromium کے موبائل اشارے یا ٹچ اسکرین کو بنیادی طور پر رپورٹ کرتا ہے۔ (موٹے) پوائنٹر، وہی سگنل جو گرافکس ماڈیول استعمال کرتا ہے۔ یہ 16 سے شروع ہوتا ہے جو بھی اس کی بنیادی گنتی سے ہو۔ گرمی اور بیٹری ڈرین کو محدود کریں۔ گمشدہ یا غلط اشارے نامعلوم ہیں۔ یہ نمبر ابتدائی ہورسٹکس ہیں، ناپے گئے ہارڈ ویئر کے نہیں۔ صلاحیت: براؤزر کے ذریعہ منطقی سی پی یو کی تعداد کم ہوسکتی ہے۔, اور میموری اشارے تخمینی ہیں اور رازداری پر پابندی ہے۔.

import { detectAudioSystem, resolveAudio, volumeGain } from './audio-options.js';

const system = detectAudioSystem();
const GAME_SOUND_CEILING = 64;
let saved = {}; // Load your player's validated preferences; empty means defaults.

function applyAudio() {
  const settings = resolveAudio(saved, system, GAME_SOUND_CEILING);
  // mixer is your own adapter, not a StarHermit SDK API.
  mixer.setPlaybackLimit(settings.effectiveConcurrentSounds);
  mixer.setBusGain('master', volumeGain(settings.master));
  for (const bus of ['music', 'effects', 'ui', 'voice']) {
    mixer.setBusGain(bus, volumeGain(settings[bus]));
  }
  return settings; // Show recommendedConcurrentSounds and effectiveConcurrentSounds.
}

function setSoundLimit(value) {
  // A select supplies 'auto'; parse and validate the custom integer before calling.
  saved = { ...saved, maxConcurrentSounds: value };
  applyAudio();
  // Persist the requested choice, including 'auto', through your settings store.
}

ہر ڈیوائس پر اور متعلقہ مکسر/آؤٹ پٹ فارمیٹ کی تبدیلیوں کے بعد آٹو کو دوبارہ چلائیں۔ محفوظ کریں۔ 'auto'، اس کا نہیں۔ پتہ چلا نمبر دستی شمار دستی ہی رہتا ہے، گیم/بیک اینڈ سیلنگ کے تابع۔ وضاحت دکھائیں۔ جب موثر شمار درخواست کردہ گنتی سے مختلف ہو۔

ایک انسٹرومینٹڈ مکسر کے لیے، آٹو کو باؤنڈڈ، ناقابل سماعت نمائندہ ورک بوجھ کے ساتھ بہتر کریں: ٹیسٹ اصل دوبارہ نمونہ سازی، مقامی کاری اور اثرات کا سلسلہ اور ہدف آڈیو بلاک کے زیادہ سے زیادہ 25 فیصد اختلاط کی مدت. مثال کے طور پر، 48 kHz پر ایک 128 فریم بلاک اس ہدف کے لیے تقریباً 0.67 ms دیتا ہے۔ فعال گیم پلے سے دور پروفائلنگ کا شیڈول بنائیں۔ صرف خاموش فائدہ نمائندے کی ضمانت نہیں دیتا کام کریں کیونکہ بیک اینڈ خاموشی کو بہتر بنا سکتا ہے۔ معیاری ویب آڈیو فی گراف CPU وقت کو ظاہر نہیں کرتا ہے۔ اشارہ فال بیک استعمال کریں جب تک کہ آپ کا اپنا بیک اینڈ قابل اعتماد وقت فراہم نہ کرے۔ آڈیو CPU لاگت کا اندازہ نہ لگائیں۔ FPS یا آؤٹ پٹ چینل کی گنتی سے۔

ہسٹریسس کے ساتھ، آٹو مسلسل ناپے ہوئے اوورلوڈ یا انڈررنز پر سیشن کے لیے نیچے جا سکتا ہے دوغلا پن سے بچیں؛ محفوظ کردہ ترجیح کو اوور رائٹ نہ کریں۔ مقامی طور پر کیش ماپا سفارشات کی طرف سے پسدید، فارمیٹ، اثرات کی ترتیب اور کوڈ ورژن۔ ان تبدیلیوں کے بعد دوبارہ جائزہ لیں۔ مثال پابند مکسنگ کے کام کو شمار کرتا ہے، لیکن ضابطہ کشائی، مائکروفون پروسیسنگ اور نیٹ ورکنگ کے لیے الگ بجٹ کی ضرورت ہوتی ہے۔

3. پلے بیک میں ٹوپی کو نافذ کریں۔

شمار ہر فعال پلے بیک مثال موسیقی، لوپس، اثرات، UI اور موصول ہونے والی آواز میں۔ سٹیریو ایک مثال ہے۔ روکی ہوئی/روکی ہوئی آوازیں، مائیکروفون کیپچر اور ورچوئل آوازیں بغیر کسی فعال کے رینڈرنگ شمار نہیں کرتے. میوزک کراس فیڈز اور ریلیز ٹیل کے ختم ہونے تک گنتی ہے۔ مستقبل کا شیڈول بنائیں ایک ہی مختص کرنے والے کے ذریعے شروع ہوتا ہے اور ان کی زیر التواء قطار کو بھی پابند کرتا ہے۔

میڈیا عناصر اور WebRTC آؤٹ پٹ سمیت ہر پلے بیک پاتھ کے لیے ایک باؤنڈڈ ایلوکیٹر استعمال کریں:

  1. موسیقی، اہم اشارے اور متوقع آواز کے شرکاء کے لیے کل کا حصہ محفوظ کریں۔ تحفظات ٹوپی بانٹیں؛ وہ اضافی سلاٹ شامل نہیں کرتے ہیں۔ جب کمرے کا سائز یا حد تبدیل ہو جائے تو انہیں ڈھال لیں۔
  2. صلاحیت پر، آنے والے کم ترجیحی اثر کو چھوڑ دیں یا کم ترجیحی فعال مثال کو تبدیل کریں۔ فاصلہ، سماع اور بار بار اثرات ترجیحی تعلقات کو توڑ سکتے ہیں۔ ڈپلیکیٹ برسٹ اور حد آڈیو نوڈس بنانے یا نئے بفرز کو ڈی کوڈ کرنے سے پہلے بار بار ایمیٹرز۔
  3. ایک دھندلاہٹ کا شکار اب بھی اپنی جگہ پر قابض ہے: اس کے متبادل کو اس وقت تک قطار میں رکھیں جب تک کہ وہ رک نہ جائے، یا اسے کسی محفوظ مقام پر روکیں۔ تبدیلی شروع کرنے سے پہلے حد۔ دھندلا پن کے لیے کبھی بھی عارضی طور پر ٹوپی سے تجاوز نہ کریں۔
  4. ختم شدہ ذرائع کو جاری اور منقطع کریں۔ حد کو کم کرنے سے سلاٹ کا دوبارہ دعوی کرنا چاہیے، بشمول لوپس اور tails، نئے پلے بیک کو تسلیم کرنے سے پہلے۔ ورچوئلائزڈ لوپس صرف سستی پوزیشن/ریاست کا ڈیٹا برقرار رکھتے ہیں۔ ان کی مہنگی پروسیسنگ اور پابند ورچوئل انسٹنس بک کیپنگ کو بھی منقطع کریں۔

ماحول پر آواز اور بامعنی گیم پلے اشاروں کو پسند کریں۔ ایک WebRTC ٹریک مکسر سے منسلک ہونا ضروری ہے۔ ڈپلیکیٹ آڈیو اور بے شمار پلے بیک کو روکنے کے لیے براہ راست میڈیا عنصر پلے بیک کو غیر فعال کر دیا ہے۔ اکیلے کسی فائدے کو خاموش کرنے سے ڈی کوڈنگ یا اسپیشلائزیشن نہیں رکتی ہے۔ کام کو دبانا، روکنا یا منقطع کرنا جہاں پسدید اس کی اجازت دیتا ہے۔ ترقی میں فعال، دبے ہوئے اور ورچوئلائزڈ شماروں کو بے نقاب کریں۔ تشخیصی تاکہ CPU پابند کی تصدیق کی جاسکے۔

4. وائس چیٹ کنٹرولز

کی پیروی کریں وائس API گفتگو کی رکنیت کے لیے، شمولیت/چھوڑیں، سگنلنگ، خود کو خاموش کریں۔ اور میزبان خاموش۔ واضح طور پر شامل ہوں اور مائیکروفون تک رسائی کی درخواست صرف اس کے بعد کریں جب کھلاڑی کیپچر کو قابل بنائے۔ مائیکروفون کے بغیر سننا دستیاب رہ سکتا ہے۔ براؤزر کیپچر کی ضرورت ہے۔ اجازت اور محفوظ سیاق و سباق. اجازت سے انکار کو ایک مفید حالت دکھانی چاہیے اور پلے بیک اور ٹیکسٹ چیٹ کو قابل استعمال چھوڑ دینا چاہیے۔

آواز کو فعال کرتے وقت پش ٹو ٹاک کو تجویز کردہ موڈ کے طور پر استعمال کریں۔ دوبارہ باندھنے کے قابل کلید فراہم کریں اور a دبائیں اور دبائے رکھیں ٹچ کنٹرول؛ کلید/پوائنٹر کی ریلیز، منسوخ شدہ ان پٹ، بلر اور پر ریلیز ٹرانسمیشن پوشیدہ صفحہ کی منتقلی اوپن مائکروفون ایک واضح متبادل ہے۔ مائکروفون کی اجازت دکھائیں، ان پٹ لیول، بولنے کی حالت، خاموش/بہرا اور کوئی بھی میزبان خاموش۔ مائیکروفون ٹیسٹ صرف درخواست پر چلتا ہے۔ بہرے خاموش آوازیں وصول کرتے ہیں اور فعال رہتے ہوئے مقامی ٹرانسمیشن کو دبا دیتے ہیں۔

مقامی طور پر گیٹ آؤٹ باؤنڈ آڈیو کے ساتھ ساتھ پلیٹ فارم کی اپنی خاموش حالت کو اپ ڈیٹ کرنا۔ ہر شمولیت پر یا دوبارہ جڑیں، میڈیا بھیجنے سے پہلے مطلوبہ خاموشی کو بحال کریں: شامل ہونے سے شرکت کنندہ کی اپنی خاموشی صاف ہو جاتی ہے API میں، جبکہ میزبان خاموش زندہ رہتا ہے۔ پیئر ٹو پیئر میڈیا کو مقامی طور پر بھی میزبان گونگا کا احترام کرنا چاہیے۔ سگنلنگ پلیٹ فارم کو براہ راست ہم مرتبہ آڈیو اسٹریم کو فلٹر کرنے نہیں دیتا ہے۔ کیپچر ٹریکس کو بند کریں اور میڈیا کو بند کریں۔ آواز کے غیر فعال ہونے یا سیشن ختم ہونے پر کنکشن۔ کسی ترجیحی موڈ کو کبھی خاموشی سے محفوظ کرنا اگلے لانچ پر مائکروفون کو دوبارہ کھولتا ہے۔

5. محفوظ کریں اور تصدیق کریں۔

کھیل میں عام ترجیحات کو محفوظ کریں۔ فی کھلاڑی کی ترتیبات, مثال کے طور پر نیچے audio کے طور پر { saved: { master: 0.8, maxConcurrentSounds: 'auto', voiceMode: 'off' }, at: … }. اسٹینڈ اسٹون پلے کے لیے نام کی جگہ پر مقامی کیشے رکھیں۔ لکھنے سے پہلے پڑھیں، ٹائم اسٹیمپ کو جوڑیں، اور بلاک کلاؤڈ ایک ناکام پڑھنے کے بعد لکھتا ہے جب تک کہ کامیاب دوبارہ کوشش نہ ہو، جیسا کہ گرافکس ٹیوٹوریل میں ہے۔ ریموٹ ترتیبات کو لاگو کرنے سے پہلے ان کی توثیق کریں۔ ڈیوائس آئی ڈی، اجازت، پروفائلنگ کے نتائج، رکھیں سیشن کی رکنیت اور موجودہ مائکروفون سرگرمی مقامی؛ ترجیحی وائس موڈ کو الگ سے اسٹور کریں۔ کیپچر فی الحال فعال ہے یا نہیں۔

  • node --test tests/audio-options.test.mjs بھیجے گئے مددگار کے نامعلوم/مجبور/مضبوط کو چیک کرتا ہے۔ اور فون/ٹیبلیٹ کا پتہ لگانا، چھتیں، دستی انتخاب، دوسرے ڈیوائس پر آٹو، والیوم باؤنڈز اور وائس ڈیفالٹس۔
  • اپنے گیم میں، حقیقی کنٹرولز کو ماؤس، کی بورڈ اور ٹچ سے چلائیں۔ لائیو حجم کی تبدیلیوں کو چیک کریں، دوبارہ لوڈ کرنے کے بعد خاموش بحالی، استقامت اور آٹو/دستی سوئچنگ۔
  • اوور لیپنگ موسیقی، اثرات، آواز، دھندلا پن اور مقررہ آوازوں کو حد سے زیادہ متحرک کریں۔ تصدیق کریں۔ فعال پلے بیک کبھی بھی اس سے تجاوز نہیں کرتا، بشمول اسے لائیو کم کرتے وقت، اور اہم اشارے زندہ رہتے ہیں۔
  • ٹیسٹ مائیکرو فون کی اجازت سے انکار، پش ٹو ٹاک کینسلیشن، میوٹ کو دوبارہ کنیکٹ کریں، ہوسٹ میوٹ، ڈیوائس نقصان اور آواز چھوڑنا۔ مطلوبہ سیشن آپٹ ان کے بغیر کوئی ٹرانسمیشن دوبارہ شروع نہیں ہو سکتی۔
