اتحاد SDK

دی Starhermit Unity SDK (HypeDriven/starhermit-unity-sdk) پلیٹ فارم کے لیے ٹائپ شدہ، غیر مطابقت پذیر C# کلائنٹس کے ساتھ یونٹی پیکیج مینیجر پیکیج ہے۔ یہ سنبھالتا ہے۔ HTTP درخواستیں، JSON پارسنگ، ٹوکن ریفریش اور WebSocket دوبارہ کنکشن۔
پیکج com.starhermit.sdk، ورژن 0.1.0
نام کی جگہ Starhermit
API بیس لائن REST v1 اور WebSocket v1
REST کی نئی خصوصیات استعمال کریں۔ client.Raw اور ماڈل RawJson جب اس SDK ورژن میں کوئی ٹائپ شدہ ممبر نہیں ہے۔
ویب ساکٹ پروٹوکول تمام 6، ایک کنکشن کلاس ہر ایک
لائسنس ایم آئی ٹی

SDK ایک کلائنٹ ہے، پلیٹ فارم کا دوسرا نفاذ نہیں۔ اجازت، دوستی، استحقاق، کمرے کی رکنیت، اسکور کی توثیق، گیم کے نتائج اور اسٹوریج کے بجٹ باقی ہیں۔ سرور مستند بالکل جیسا کہ ذیل کے صفحات پر دستاویز کیا گیا ہے — SDK سرور کے جواب کو ظاہر کرتا ہے اور اس کی شائع شدہ حدود خود فیصلہ کرنے یا کیش کرنے کے بجائے۔

یہ صفحہ انضمام گائیڈ ہے۔ مکمل پیکج کی دستاویزات زیر ذخیرے میں رہتی ہیں۔ Packages/com.starhermit.sdk/Documentation~.

تقاضے

  • Unity 2021.3 LTS یا جدید تر، API مطابقت کی سطح NET سٹینڈرڈ 2.1, C# 9.
  • Mono اور IL2CPP، جس میں ڈس ایبلڈ سے منظم سٹرپنگ ہے۔ اعلی (پیکج خود ہی بھیجتا ہے۔ Runtime/link.xml).
  • کوئی عکاسی نہیں، کوئی متحرک کوڈ جنریشن نہیں، کوئی لازمی مقامی پلگ ان نہیں۔

ہر ماڈیول ہر تعمیراتی ہدف کے لیے مرتب کرتا ہے۔ جہاں ایک ہدف میں حقیقی طور پر قابلیت کا فقدان ہے - نہیں۔ بغیر ہیڈ لیس سرور پر مائیکروفون، براؤزر میں کوئی ہینڈ شیک ہیڈر نہیں - کال بڑھ جاتی ہے۔ StarhermitFeatureUnavailableException ایک مستحکم کے ساتھ Reason، تعمیر میں ناکام ہونے کے بجائے یا غیر متعلقہ خصوصیات کو غیر فعال کرنا۔

قابلیت ڈیسک ٹاپ / موبائل / کنسول ویب جی ایل بے سر سرور
آرام کریں۔ UnityWebRequestTransport UnityWebRequestTransport HttpClientTransport
ویب ساکٹ ClientWebSocketAdapter WebGLSocketFactory + بنڈل .jslib پل ClientWebSocketAdapter
OAuth انجکشن IStarhermitOAuthBrowser انجیکشن براؤزر اڈاپٹر میزبان سے URL ہینڈ آف
ٹوکن اسٹوریج انجکشن کی دکان؛ EncryptedFileTokenStore آپٹ ان انجیکشن براؤزر اسٹوریج انجیکشن اسٹور یا میموری
فائل ٹرانسفر SystemFileStore انجکشن شدہ سنک SystemFileStore
آواز کی گرفت / پلے بیک UnityMicrophoneCapture / UnityAudioPlayback انجیکشن براؤزر میڈیا اڈاپٹر دستیاب نہیں جب تک کہ انجیکشن نہ ہو۔
عوامی کلید پر دستخط انجکشن IStarhermitSigner انجیکشنڈ سائنر یا براؤزر کرپٹو انجکشن دستخط کنندہ

انسٹال کریں۔

پیکیج مینیجر → گٹ یو آر ایل سے پیکیج شامل کریں۔، یا اندراج Packages/manifest.json. پیکج ریپوزٹری کے ذیلی فولڈر میں بیٹھتا ہے، لہذا URL کی ضرورت ہے۔ path=:

{
  "dependencies": {
    "com.starhermit.sdk": "https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk"
  }
}

شامل کرکے ریلیز کو پن کریں۔ #<tag-or-commit>:

https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk#v0.1.0

اتحاد کے گولے نکلتے ہیں۔ git، لہذا ایک نجی ذخیرہ صرف اس صورت میں حل ہوتا ہے جب ایڈیٹر کا گٹ تصدیق کر سکے۔ غیر انٹرایکٹو - ایک SSH کلید (git@github.com:HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk) یا ایک کنفیگر کردہ سندی مددگار۔ ایک مقامی راستہ یا اسکوپڈ رجسٹری اسی طرح کام کرتی ہے۔ درآمدی ترمیم نمبر پروجیکٹ کی ترتیبات اور نیٹ ورک تک رسائی نہیں کرتا ہے۔

ایک کلائنٹ بنائیں

using Starhermit;

var client = StarhermitClient.Create(new StarhermitOptions
{
    ApiBaseUri = new Uri("https://api.starhermit.com/api/v1/"),
    GameSlug   = "83fd04b1-3cbe-4b09-a251-3733ad4b9d94",
    TokenStore = myPlatformSecureStore,
    LogLevel   = StarhermitLogLevel.Warning
});

await client.InitializeAsync();               // loads a stored session, refreshes it if expired
var me = await client.Me.GetProfileAsync();

Create کوئی I/O نہیں کرتا ہے۔ اس وقت تک نیٹ ورک کو کوئی چیز نہیں چھوتی جب تک کہ آپ شروع نہ کریں، کسی سروس کو کال کریں یا ایک کھولیں۔ کنکشن WebSocket کی بنیاد سے ماخوذ ہے۔ ApiBaseUri (wss://<host>/ws/v1/) جب تک کہ آپ سیٹ نہ کریں۔ WebSocketBaseUri اپنے آپ کو

StarhermitClient ہے IDisposable: ڈسپوزل پرواز میں درخواستوں کو منسوخ کرتا ہے، ہر کنکشن کو بند کر دیتا ہے۔ دیا جاتا ہے، دل کی دھڑکنوں کو روکتا ہے اور آڈیو جاری کرتا ہے۔ پیکیج میں کوئی مستحکم تغیر پذیر حالت نہیں ہے، لہذا دو کلائنٹ مختلف ماحول کے ساتھ ساتھ چل سکتے ہیں، اور ایک کلائنٹ منظر کے بوجھ سے بچ جاتا ہے۔

پلیٹ فارم پر شائع ہونے والا ایک گیم سے پیش کیا جاتا ہے https://<slug>.starhermit.com کے ساتھ /api اور /ws پراکسیڈ ایک ہی اصل (دیکھیں۔ گٹ ہب گیمز)۔ ایک WebGL بلڈ نے اسے شائع کیا۔ راستے کو اس کی اپنی اصل کی طرف اشارہ کرنا چاہئے تاکہ براؤزر ایک ہی اصل کی کال کرے:

ApiBaseUri = new Uri("https://83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com/api/v1/") // your game's uid

مقامی پس منظر کے لیے، AllowInsecureTransport = true اجازت دیتا ہے http/ws. کلائنٹ کی تعمیر سے انکار a اس کے بغیر غیر ایچ ٹی ٹی پی ایس ایڈریس، اور ایڈیٹر کی تعمیر کی توثیق غیر ترقیاتی پلیئر کی تعمیر میں ناکام ہوجاتی ہے جو اب بھی سیٹ ہے. یہ کبھی بھی سرٹیفکیٹ کی توثیق کو غیر فعال نہیں کرتا ہے۔

سائن ان ہو رہا ہے۔

تین اسناد کی قسمیں بیان کی گئی ہیں۔ تصدیق الگ الگ اقسام ہیں SDK میں اسٹورز؛ کوئی دوسرے کے لیے کھڑا نہیں ہو سکتا۔

OAuth - SDK ایک انجیکشن کے ذریعے مجاز URL کو کھولتا ہے۔ IStarhermitOAuthBrowser اور مکمل کرتا ہے تبادلہ:

var session = await client.Auth.SignInWithOAuthAsync("google");

استعمال کریں۔ BuildAuthorizeUri(provider) پلس CompleteOAuthAsync(...) اس کے بجائے جب آپ کا پلیٹ فارم ہاتھ میں آتا ہے۔ اپنے ڈیپ لنک یا ایمبیڈڈ براؤزر پلمبنگ کے ذریعے واپس ری ڈائریکٹ کریں۔

عوامی کلید - ایمبیڈڈ، کنسول اور سرشار سرور پلیئرز کے لیے بغیر پاس ورڈ کا بہاؤ (دیکھیں۔ سرشار سرور + ایمبیڈڈ پلیئر آن بورڈنگ)۔ تائید شدہ کلیدی اقسام ہیں۔ Ed25519, ECDSA-P256 اور RSA-PSS; SDK کبھی بھی تخلیق یا ذخیرہ نہیں کرتا ہے۔ نجی کلید، یہ ایک انجکشن کو کہتے ہیں IStarhermitSigner:

var session = await client.Auth.SignInWithPublicKeyAsync(signer);   // or (), using Options.Signer

معاہدے کی تفصیلات جاننے کے قابل۔ تعیناتی اپنے خلاف چیلنج دستخط کی تصدیق کرتی ہے۔ چیلنج کی پاسکل کیس سیریلائزیشن، جبکہ آپ کو موصول ہونے والا JSON CamelCase ہے — دوبارہ سیریلائز کرنا جواب کبھی بھی تصدیق نہیں کرے گا. StarhermitChallenge.CanonicalPayload کے عین مطابق بائٹس کو دوبارہ تیار کرتا ہے۔ سائن کریں، لہذا ہاتھ سے رولڈ دستخط بھی ایسا ہی کرنا چاہیے۔

گیم لانچ ٹوکن - فی گیم ٹکڑا ہوا اور اس گیم کی سطح پر باڑ لگا دیا گیا:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();
var fenced = chess.WithLaunchToken();     // subsequent calls authorise with the launch token

لانچ ٹوکن کو منٹ کرنا کبھی بھی اکاؤنٹ سیشن کی جگہ نہیں لیتا۔ درخواست میں کون سا سند ہے؟ درخواست پائپ لائن کے ذریعے فیصلہ کیا گیا، نہ کہ آپ کی کال کردہ سروس کے ذریعے۔

رسائی ٹوکن ریفریش کو مربوط کیا گیا ہے: a 401 زیادہ سے زیادہ ایک ریفریش اور ایک ری پلے، اور کنکرنٹ خریدتا ہے۔ کال کرنے والے کئی شروع کرنے کے بجائے ایک ہی ریفریش کا انتظار کرتے ہیں - ایک گھومنے والے ریفریش ٹوکن کے ساتھ، ایک سیکنڈ تبادلہ خاندان کو منسوخ کردے گا اور کھلاڑی کو سائن آؤٹ کردے گا۔ ایک قطعی ردّ اٹھتا ہے۔ SessionExpired ایک بار؛ نقل و حمل کی ناکامی سیشن کو برقرار رکھتی ہے۔

موجودہ شرائط کو قبول کرنا

دل کی دھڑکنیں، گیم کی درخواستیں یا ساکٹ شروع کرنے سے پہلے قبولیت کی جانچ کریں۔ ورژن 0.1.0 ہے۔ AcceptTermsAsync، لیکن نئے پروفائل فیلڈز اور اصطلاحات کی دریافت اس کی خام JSON سپورٹ کا استعمال کرتی ہے:

var profile = await client.Me.GetProfileAsync(ct);
var needsAcceptance = profile.RawJson["termsAcceptanceRequired"].AsBooleanOrDefault();
var terms = await client.Raw.SendForJsonAsync(new StarhermitRequest("GET", "terms"), ct);
var textToDisplay = terms["text"].AsStringOrNull();
var displayedHash = terms["hash"].AsStringOrNull();
// Display textToDisplay. Retain displayedHash for this displayed revision.
// Only in the user's Accept handler, using an account session:
// await client.Me.AcceptTermsAsync(displayedHash, ct);

نمونہ نظر ثانی کا لیبل استعمال نہ کریں جیسے terms-2026-08: API سے صرف موجودہ ہیش ہے۔ قبول کر لیا پر 409، ایک اور قبولیت کے لیے نیا متن بازیافت کریں اور ڈسپلے کریں۔ پر 403 terms_acceptance_requiredدوبارہ کوشش کرنے سے پہلے قبولیت کو حل کریں۔ پلیئر لانچ ٹوکن بھی واضح رضامندی کے بعد API کے ذریعے قبولیت جمع کرا سکتے ہیں۔ دیکھیں پروفائل مکمل بہاؤ کے لئے.

جہاں ہر ویکی صفحہ SDK میں رہتا ہے۔

یہاں دستاویز کردہ ہر REST ایریا میں کلائنٹ پر ایک سروس ہوتی ہے، اور ہر WebSocket پروٹوکول ایک ہوتا ہے۔ کنکشن کلاس.

ویکی صفحہ SDK
تصدیق client.Auth (کلیدی اندراج اور منسوخی بھی جاری ہے۔ client.Me)
پروفائل client.Me, client.Entitlements, StarhermitPresenceHeartbeat
دوستو client.Friends
گپ شپ client.Chat + StarhermitChatConnection
آواز client.Voice + StarhermitVoiceConnection
کیٹلاگ client.Software, client.CloudSaves, client.Ratings, client.Wishlist
سرگرمی client.Activity
بیرونی لائبریریاں client.Activity (لنک، ان لنک، ملکیتی سافٹ ویئر، بیرونی لانچ)
کامیابیاں client.Achievements, client.Games.ForSlug(slug).GetAchievementsAsync()
لیڈر بورڈز client.Leaderboards
گیمز client.Games.ForSlug(slug) + StarhermitGameConnection
ریئل ٹائم کمرے client.RealtimeRooms + StarhermitRealtimeConnection
ریلے client.Relay + StarhermitRelayConnection
کنٹینر گیم سرورز client.GameServer (سرور ٹوکن ایکسچینج اور سیشن تلاش)
گٹ ہب گیمز client.BrowserGames + StarhermitGameUploadConnection
پبلشر client.Publishers, StarhermitBuildPublisher
سرور کی گھڑی client.Time, client.ServerClock

کھیل ہی کھیل میں سکرپٹ کوئی SDK سروس نہیں ہے: پلیٹ فارم پر ایک اسکرپٹ چلتا ہے، اور اس کا کلائنٹ اوپر گیمز API کے ذریعے اس سے بات کرتے ہیں۔

ایک سیشن ختم ہونے کے لیے

سے لائف سائیکل انضمام واک تھرو، C# میں:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();

var ticket = await chess.EnqueueMatchmakingAsync();
while (!ticket.IsMatched)
{
    await Task.Delay(TimeSpan.FromSeconds(2), ct);
    ticket = await chess.GetMatchmakingAsync(ct) ?? ticket;
}

using var game = client.CreateGameConnection(ticket.SessionId!.Value, "83fd04b1-3cbe-4b09-a251-3733ad4b9d94", useLaunchToken: true);
game.FrameReceived       += frame => ApplyServerState(frame);
game.AchievementUnlocked += unlock => ShowToast(unlock);
game.PresenceChanged     += (userId, online) => UpdateOpponentDot(userId, online);
game.ErrorReceived       += message => ShowError(message);

await game.ConnectAsync(ct);
await game.SendCommandAsync(writer =>
{
    writer.Write("type", "move");
    writer.Write("from", "e2");
    writer.Write("to",   "e4");
}, ct);

SendCommandAsync پے لوڈ کو اس طرح لپیٹتا ہے۔ {"type":"cmd","data":…}; SendRealtimeInputAsync ہے مسلسل ان پٹ کے لیے شرح محدود راستہ۔ کنکشن گیم منطق پر نشان نہیں لگاتا، مستند پیش گوئی کرتا ہے۔ مبہم ہونے کے بعد کوئی نتیجہ بیان کرنا، من گھڑت کرنا، یا ممکنہ طور پر غیر قابل عمل کمانڈ دوبارہ بھیجنا منقطع کریں - جو ہوا اس پر سرور واحد اتھارٹی ہے۔

ہر کنکشن ایک ریاستی مشین کا اشتراک کرتا ہے: Disconnected, Connecting, Connected, Reconnecting, Closing, Faultedکے ساتھ StateChanged, Closed اور Faulted واقعات، باہر جانے والی قطاروں کے ساتھ واضح backpressure، اور بھیجنے کا حکم دیا. دوبارہ کنکشن پریشان شدہ بیک آف کا استعمال کرتا ہے، ایک کرنٹ کو دوبارہ حاصل کرتا ہے۔ ہر کوشش سے پہلے ٹوکن، اور اجازت یا پالیسی بند ہونے پر اچھے کے لیے رک جاتا ہے۔ کے بجائے دروازے پر ہتھوڑا مار کر پلیٹ فارم بند کر دیا۔ یہ کبھی نہیں مانتا کہ رکنیت اس خلا سے بچ گئی ہے: ہر پروٹوکول دوبارہ منسلک ہونے پر دوبارہ حاصل کرنا یا دوبارہ شامل ہونا۔

اسناد کی سواری Authorization ہیڈر جہاں پلیٹ فارم اس کی اجازت دیتا ہے اور ?access_token= پر /ws/** دوسری صورت میں، کیونکہ براؤزر ہینڈ شیک ہیڈرز سیٹ نہیں کر سکتا۔ استفسار کا ٹوکن اس سے تبدیل کیا گیا ہے۔ ہر لاگ

Async، تھریڈنگ اور اتحاد

ہر I/O آپریشن واپس آتا ہے۔ Task اور ٹریلنگ لیتا ہے CancellationToken. نہیں ہیں async void طریقے اور کوئی عوامی طریقہ کالنگ تھریڈ کو بلاک نہیں کرتا۔

ایونٹس اور پروگریس کال بیکس کو ہم وقت سازی کے سیاق و سباق میں پوسٹ کیا جاتا ہے جس پر کلائنٹ بنایا گیا تھا۔ اگر آپ اسے یونٹی کے مرکزی دھاگے پر بناتے ہیں تو ایک ہینڈلر چھو سکتا ہے۔ GameObjects براہ راست. ایک سر کے بغیر سرور کے ساتھ ہاپ کو چھوڑ سکتے ہیں۔ options.CallbackDispatcher = ImmediateCallbackDispatcher.Instance. کال بیکس ہیں۔ فی کنکشن کا حکم دیا گیا ہے، اور ایک ہینڈلر جو پھینکتا ہے اسے روکے بغیر تشخیص کو رپورٹ کیا جاتا ہے۔ لوپ وصول کریں.

StarhermitLifecycle.Attach(client) برجز یونٹی کے ایپلیکیشن ایونٹس: موجودگی دل کی دھڑکن رک جاتی ہے۔ معطلی پر اور فوری طور پر دوبارہ شروع کرنے پر بھیج دیا جاتا ہے، اور کلائنٹ کو ہم وقت سازی کے بغیر چھوڑنے پر نمٹا دیا جاتا ہے۔ نیٹ ورک کا کام

ماڈلز کبھی حوالہ نہیں دیتے GameObject, MonoBehaviour یا ایک منظر؟ StarhermitTextures بدلتا ہے اوتار اور کور آرٹ بائٹس کو a میں Texture2D مرکزی دھاگے پر - کال کرنے والا نتیجہ کا مالک ہے اور اسے تباہ کرنا ہوگا۔

غلطیاں، دوبارہ کوششیں اور صفحہ بندی

حیثیت استثنیٰ
400 / 422 StarhermitBadRequestException, StarhermitValidationException (وائر کے نام سے کی گئی فیلڈ کی غلطیاں)
401 StarhermitAuthenticationException
402 StarhermitEntitlementException
403 StarhermitAuthorizationException
404 StarhermitNotFoundException
409 StarhermitConflictException
429 StarhermitRateLimitException (اٹھاتا ہے۔ RetryAfter)
5xx StarhermitServerException

ہر ایک کی حیثیت، سرور کی ہوتی ہے۔ {"error":"..."} پیغام، کوئی بھی مشین پڑھنے کے قابل کوڈ، درخواست شناخت، Retry-After, redacted ہیڈر اور ایک سائز کیپ شدہ redacted باڈی۔ ایک درخواست جو کبھی نہیں پہنچی۔ API اٹھاتا ہے۔ StarhermitTransportException یا StarhermitTimeoutException - نقل و حمل کی ناکامی کبھی نہیں ہوتی ہے۔ API کے جواب کے طور پر تیار۔ منسوخی ہمیشہ اس طرح سامنے آتی ہے۔ OperationCanceledException.

دوبارہ کوششیں پابند ہیں، گھبراہٹ، عزت Retry-After ایک ٹوپی تک، اور ایک سیکنڈ کی ناکامیوں تک محدود ہیں۔ کوشش زندہ رہ سکتی ہے: کنکشن کی خرابیاں، ٹائم آؤٹ، 408, 429 اور عارضی 5xx. 403, 404, 409 اور توثیق کی ناکامیوں کی دوبارہ کوشش نہیں کی جاتی ہے، اور POST کی دوبارہ کوشش صرف اس وقت کی جاتی ہے جب وہ اس کے ساتھ آپٹ ان کرتا ہے۔ AsIdempotent. ایک پراسیس وسیع دوبارہ کوشش کا بجٹ کئی کلائنٹس کو ایک بندش کو طوفان میں بدلنے سے روکتا ہے۔

فہرست اختتامی پوائنٹس کی واپسی۔ StarhermitPage<T> سرور کا اپنا پیجنگ میٹا ڈیٹا لے جانے کے علاوہ سست گنتی جو کسی صفحہ کو صرف اسی طرح حاصل کرتی ہے جیسے اسے استعمال کیا جاتا ہے:

await foreach (var title in client.Software.EnumerateTitlesAsync(query, cancellationToken: ct)) { … }

ڈاؤن لوڈز ایک پر سٹریم ہوتے ہیں۔ IStarhermitFileStore ایک عارضی فائل کے ذریعے، فراہم کردہ SHA-256 کی تصدیق کریں۔ جوہری طور پر فروغ دیا جاتا ہے؛ OpenDownloadAsync رپورٹس IsResumed صرف ایک حقیقی کے لئے 206کیونکہ ایک مکمل فائل کو جزوی فائل میں شامل کرنا اس کو خراب کردے گا جبکہ ابھی بھی لمبائی کی جانچ پڑتال کر رہے ہیں۔

اسناد کو ذخیرہ کرنا

پیکج بحری جہاز کوئی اسٹور نہیں جو محفوظ ہونے کا دعوی کرتا ہو۔ پہلے سے طے شدہ میموری میں ہے؛ آپٹ ان EncryptedFileTokenStore (آپ کی درخواست کی فراہمی کی کلید پر HMAC-SHA256 کے ساتھ AES-CBC) دستاویزی ہے۔ آرام میں الجھن کے طور پر، ایک کیچین نہیں. تار IStarhermitTokenStore پلیٹ فارم کے اپنے محفوظ کرنے کے لیے اسٹوریج — کیچین، کیسٹور، کنسول SDK کا صارف اسٹوریج۔ PlayerPrefs کے طور پر کبھی پیش نہیں کیا جاتا ہے۔ محفوظ

ٹوکنز، ریفریش ٹوکنز، پرائیویٹ کیز، کلائنٹ کے راز اور انووک کیز کو کبھی بھی سیریلائز نہیں کیا جاتا ScriptableObjectایک منظر، Resources، ایک لاگ، ایک استثنائی پیغام، ایک ٹیلی میٹری ایونٹ یا ایک تعمیر آرٹفیکٹ StarhermitSettings صرف غیر خفیہ پروجیکٹ ڈیفالٹس رکھتا ہے: پتے، سلگ، لاگ لیول، ٹائم آؤٹ اور ترقی کا جھنڈا

ریڈیکشن ساختی ہے — ہیڈر، استفسار پیرامیٹر اور JSON ممبر کے نام کے ذریعے، ہر گہرائی میں — اس لیے ایک سند کے اس SDK ورژن کے بارے میں کبھی نہیں سنا ہے اب بھی لاگز، استثناء اور ٹیلی میٹری سے چھین لیا گیا ہے۔ URL کے ٹکڑے مکمل طور پر گرائے گئے ہیں۔ کوئی ٹیلی میٹری بطور ڈیفالٹ جمع نہیں ہوتی ہے۔ ایک انجکشن شدہ سنک موصول ہوتا ہے۔ ایونٹ کا نام، آپریشن آئی ڈی، دورانیہ، اسٹیٹس فیملی، دوبارہ گنتی کی کوشش کریں، درخواست کی شناخت اور نتیجہ، کبھی بھی یو آر ایل نہیں، جسم یا کھلاڑی کا مواد۔

جب پلیٹ فارم کچھ نیا بھیجتا ہے۔

ماڈلز ناقابل تغیر ہوتے ہیں اور JSON کو اپنے پاس رکھتے ہیں جس سے ان کا تجزیہ کیا گیا تھا، اس لیے اس کے بعد تعیناتی میں ایک فیلڈ شامل کیا گیا یہ SDK ورژن اب بھی پڑھنے کے قابل ہے، اور ایک اختتامی نقطہ جو یہ ورژن ٹائپ نہیں کرتا ہے وہ اب بھی قابل کال ہے۔ وہی اسناد، دوبارہ کوششیں اور ایک ٹائپ شدہ کال کی طرح ترمیم:

var value = profile.RawJson["shippedAfterThisSdk"].AsStringOrNull();

var json  = await client.Raw.SendForJsonAsync(
    new StarhermitRequest("GET", "some/new/route").WithQuery("page", 1), ct);

ساکٹ فریم نامعلوم فریم فال بیک کے ساتھ اپنے قسم کے امتیاز کرنے والے پر ڈسپیچ کرتے ہیں جو محفوظ رکھتا ہے پے لوڈ، نامعلوم اینوم سٹرنگز کو زبردستی کے بجائے سٹرنگ کے طور پر رکھا جاتا ہے، اور ایک نامعلوم رازداری کی سطح کے طور پر پڑھتا ہے زیادہ تر نجی تشریح Optional<T> چھوڑے ہوئے، واضح null اور کی تمیز کرتا ہے۔ قدر، جس کی ایک PATCH باڈی کی ضرورت ہوتی ہے۔

client.GetDiagnostics() کنکشن کی حالتیں، قطار کی گہرائیاں، دوبارہ جڑیں شمار، ٹوکن کی میعاد، گھڑی تازگی، پرواز میں درخواستیں، دوبارہ کوششیں خرچ کی گئیں اور آخری ترمیم کی گئی غلطی — اسنیپ شاٹ کو جو منسلک کرنا ہے بگ رپورٹ.

نمونے

آٹھ نمونے پیکیج کے ساتھ بھیجے جاتے ہیں اور CI میں مرتب کیے جاتے ہیں، اس لیے وہ API سے ہٹ نہیں سکتے۔ مظاہرہ کریں: توثیق اور پروفائل، دوست اور چیٹ، میچ میکنگ گیم، ریئل ٹائم اور ریلے، آواز، کیٹلاگ سروسز، پبلشر ٹول، اور سرشار سرور۔

تصدیق کی حیثیت
