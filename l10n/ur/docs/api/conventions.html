API کنونشنز

REST استعمال کرتا ہے۔ https://api.starhermit.com/api/v1/...; ساکٹ استعمال کرتے ہیں wss://api.starhermit.com/ws/v1/.... ہوسٹڈ گیمز کال کر سکتے ہیں۔ /api/v1/... اور /ws/v1/... ان کی اپنی اصل پر. مقامی کلائنٹ استعمال کرتے ہیں۔ عوامی API اصل۔ کسی اور اصل پر ترقیاتی صفحہ کو گیم پر اجازت شدہ CORS اصل کی ضرورت ہے۔ میزبان؛ اکیلے SDK بیس یو آر ایل کو ترتیب دینے سے اس اصل کی اجازت نہیں ہوتی۔

درخواستیں اور جوابات

کے ساتھ JSON بھیجیں۔ Content-Type: application/json، سوائے خام gzip بنڈل اپ لوڈز کے۔ JSON ممبروں کے نام اونٹ کیس ہیں۔ REST میں بیئرر اسناد بھیجیں۔ Authorization ہیڈر

جواب اسے کیسے پڑھنا ہے۔
200 / 201 JSON دستاویزی آبجیکٹ یا صف کو پارس کریں۔ اضافی شعبوں کو برداشت کریں۔
204 بغیر جسم کے کامیابی؛ فون مت کرو response.json()
302 براؤزر سائن ان/تصدیق ری ڈائریکٹ؛ OAuth صفحات کو بازیافت کرنے کے بجائے نیویگیٹ کریں۔
304 مشروط پڑھنا غیر تبدیل شدہ؛ آپ کے پاس پہلے سے موجود ڈیٹا کو برقرار رکھیں
تصویر، اٹیچمنٹ، کلاؤڈ سیو جوابی مواد کی قسم اور اینڈ پوائنٹ کنٹریکٹ کا استعمال کرتے ہوئے بائٹس پڑھیں
خرابی پہلے سٹیٹس کو پڑھیں، پھر جسم کو دفاعی طور پر پارس کریں۔

عام غلطی کی شکل ہے۔ { "error": "...", "code": "..." }پر منحصر ہے اختیاری فیلڈز کے ساتھ اختتامی نقطہ error اکثر انسان کے پڑھنے کے قابل ہوتا ہے۔ code ایک مستحکم امتیازی ہے جہاں فراہم کیا گیا ہے۔ شرائط اور کچھ دوسرے اختتامی نکات امتیازی سلوک کرنے والے کو براہ راست داخل کرتے ہیں۔ error. کچھ اختتامی نقطے سادہ لوٹتے ہیں۔ متن، ایک خالی باڈی، یا توثیق مسئلہ کی تفصیلات آبجیکٹ کے ساتھ title, status اور errors. کلائنٹس کو یہ فرض نہیں کرنا چاہیے کہ ہر ناکام جواب JSON ہے یا اس کی فیلڈز ایک جیسی ہیں۔

export async function readResponse(response) {
  if (response.status === 204 || response.status === 304) return null;
  const text = await response.text();
  let body;
  try { body = text ? JSON.parse(text) : null; } catch { body = text || null; }
  if (!response.ok) {
    const message = (body && typeof body === 'object' && (body.error || body.message || body.title))
      || (typeof body === 'string' && body) || response.statusText;
    throw Object.assign(new Error(message), {
      status: response.status, code: body?.code, body,
      retryAfter: response.headers.get('Retry-After'),
    });
  }
  return body;
}

وقت، سائز، اور nulls

  • createdAt, updatedAt, finishedAt، اور اسی طرح کے اکاؤنٹ/وسائل ٹائم سٹیمپ ISO 8601 سٹرنگز ہیں۔ ایک آفسیٹ کے ساتھ. غیر حاضر یا علاج کریں۔ null اختیاری قدریں بطور دستیاب نہیں۔
  • ctx.now, summary.deadline، سیشن کی فہرست deadline، اور /time.serverTime انٹیجر یونکس ہیں۔ ملی سیکنڈ. کے ساتھ تبدیل کریں۔ new Date(value)، نہیں Date.parse(value).
  • بائٹس میں حد اقدار بائٹس ہیں، نہ کہ Base64 حروف۔ ایک Base64 JSON اپ لوڈ اس سے بڑا ہے۔ ضابطہ کشائی شدہ مواد۔ دستیاب ہونے پر اختتامی نقطہ کے ذریعہ اطلاع دی گئی موثر حد کا استعمال کریں۔
  • کوتاہی، null، اور ایک خالی شے عالمی طور پر مساوی نہیں ہے۔ ترتیبات PATCH ہٹاتا ہے a نام کی کلید کے ساتھ null; واحد کلیدی ترتیبات PUT اسٹورز null ایک قدر کے طور پر. مجموعہ PUT بدل دیتا ہے پورا نقشہ ہر اختتامی نقطہ کے اپ ڈیٹ کے اصول پڑھیں۔
  • ایک سیٹنگ پیچ ضم ہو جاتا ہے۔ اعلی درجے کی چابیاں. ایک سپلائی کردہ آبجیکٹ ویلیو اس کلید کی قدر کو بدل دیتی ہے۔ یہ گھونسلے کی خصوصیات کو بار بار ضم نہیں کرتا ہے۔

صفحہ بندی

صفحہ بندی ایک پر مبنی ہے جہاں page/pageSize حمایت کر رہے ہیں. مختلف APIs جان بوجھ کر مختلف ہوتے ہیں۔ جوابی لفافے؛ کسی ایسے تجزیہ کار کو دوبارہ استعمال نہ کریں جو ایک واحد کاؤنٹ فیلڈ کا نام لے۔

علاقہ مجموعہ کی شکل پہلے سے طے شدہ / زیادہ سے زیادہ صفحہ کا سائز
سافٹ ویئر کے عنوانات اور تعمیرات { items, totalCount, page, pageSize } 20 / 100
چیٹ پیغامات { conversationId, items, totalCount, page, pageSize } 50 / 100
لیڈر بورڈ اندراجات { items, total, page, pageSize } 20 / 100
بیرونی سافٹ ویئر { items, total, page, pageSize } 20; چھوٹے مثبت صفحہ کے سائز کی درخواست کریں۔
رپورٹس، کنٹینر کریش ریکارڈز، اعتدال کی فہرستیں۔ { items, total, page, pageSize } 20 / 100
سیشن، دوست، گیم کی فہرستیں، کامیابیاں صفیں اختتامی نقطہ مخصوص ٹوپیاں؛ کوئی عام اگلے صفحے کا کرسر نہیں ہے۔
اعتدال کی واپسی فیڈ کرسر پر مبنی واپس کرسر رکھیں؛ سے وصولی 410 جیسا کہ دستاویزی ہے۔

رسپانس پیجنگ میٹا ڈیٹا پیش کردہ صفحہ کی عکاسی کرتا ہے جہاں دستیاب ہو۔ حوالہ جات کے صفحات اور مشین پڑھنے کے قابل معاہدے اختتامی نقطہ کے مخصوص استفسار کے پیرامیٹرز کی وضاحت کریں۔

دوبارہ کوشش کریں اور ہم آہنگی کریں۔

صورتحال ایکشن
اکاؤنٹ تک رسائی ٹوکن کے ساتھ مسترد کر دیا گیا۔ 401 ایک بار ریفریش کریں، ایک مشترکہ ریفریش درخواست کا استعمال کرتے ہوئے؛ پھر انکار کرنے پر سائن ان کریں۔
لانچ ٹوکن کی میعاد ختم ہو گئی۔ سائن ان/لانچر کے ذریعے ایک نیا ٹوکن حاصل کریں۔ میعاد ختم ہونے والے ٹوکن خود کو تجدید نہیں کرسکتے ہیں۔
403 terms_acceptance_required موجودہ شرائط کو ظاہر کریں اور واضح طور پر قبول کریں، پھر دوبارہ کوشش کریں۔
دیگر 403 دائرہ کار، رکنیت، اجازت، یا اکاؤنٹ کی حیثیت کو حل کریں؛ ایک لوپ میں تازہ نہ کریں
409 ڈپلیکیٹ/ریاست/نظرثانی تنازعہ کو حل کریں؛ وسائل کو تبدیل کرنے سے پہلے دوبارہ پڑھیں
کلاؤڈ سیو 412 نیا ورژن لوڈ کریں اور گیم کو ضم ہونے دیں یا اسے اپنانے دیں۔
429 یا عارضی؟ 503 عزت Retry-After, jitter , اور پابند دوبارہ کوششیں شامل کریں
لکھنے کے دوران نیٹ ورک کی ناکامی۔ نتیجہ نامعلوم ہو سکتا ہے؛ کارروائی کو دہرانے سے پہلے وسائل کی حالت کا معائنہ کریں۔

Retry-After سیکنڈ یا HTTP تاریخ ہو سکتی ہے۔ آئیڈیمپوٹینسی ہیڈر ایجاد نہ کریں: API ایسا نہیں کرتا ہے۔ ایک عام آئیڈیمپوٹینسی کلیدی میکانزم کا وعدہ کریں۔ سیشن بنانے کی دوبارہ کوشش یا دعوت نامہ تشکیل دے سکتا ہے۔ دوسرا وسیلہ یا پہلے کے ساتھ تنازعہ۔ پڑھنے کو ترجیح دیں اور واضح طور پر idempotent آپریشنز کے لیے خودکار دوبارہ کوششیں ریفریش گردش، مکمل اپ لوڈز، شرائط کی رضامندی، اور ٹرمینل گیم کے نتائج ہر ایک ان کے اپنے قوانین ہیں.

موازنہ اور تبادلہ تحریروں کے لیے کلاؤڈ سیو ای ٹیگز، روم استعمال کریں۔ expectedRevision، یا اعتدال پر نظرثانی جہاں کی حمایت کی. ایک کامیاب تحریر ضروری نہیں کہ مکمل کنٹینر کی تعیناتی ہو۔ اس کی تصدیق کریں کھلاڑیوں کو نئی تعمیر میں بھیجنے سے پہلے کی حیثیت۔ دیکھیں خرابیوں کا سراغ لگانا.
