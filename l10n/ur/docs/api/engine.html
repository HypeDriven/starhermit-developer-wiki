انجن

StarHermit انجن کہاں سے حاصل کیا جائے، رن ٹائم جو چلتا ہے۔ سکرپٹ کھیل. پلیٹ فارم API ریلیزز تلاش کرنے کی جگہ ہے: یہ ہر ریلیز کی فہرست دیتا ہے، جو کہتا ہے کہ کون سا منسوخ کر دیا گیا ہے، اور ہر ریلیز کی فائلوں کے URLs اور ہیش دیتا ہے۔ ریڈز گمنام ہیں۔

بنیادی URL: https://api.starhermit.com. تمام راستے نیچے ہیں۔ /api/v1/....

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/engine/releases گمنام ہر ریلیز، تازہ ترین ورژن پہلے، منسوخ شدہ شامل ہیں۔
حاصل کریں۔ /api/v1/engine/releases/{version} گمنام اس کے عین مطابق ورژن کے ذریعہ ایک ریلیز (X.Y.Z)، یا 404 
{"releases": [{
  "version": "1.41.0", "api": {"major": 1, "minor": 41}, "revoked": false, "date": "2026-11-13T18:26:01Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.41.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"linux-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.41.0/native/linux-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} بغیر اس طرح کے ایک اعتراض کا جواب دیتا ہے۔ releases چادر URLs کی طرف اشارہ کرتے ہیں۔ wiki.starhermit.com حالیہ ریلیز کے لیے اور پر engine.starhermit.com بوڑھوں کے لیے؛ ان کا استعمال کریں جیسا کہ دیا گیا ہے۔

  • api وہ میزبان API ہے جو ریلیز کی پیشکش کرتا ہے۔ اس کی بڑی ریلیز کی بڑی اور ہے engine.api a کھیل کا اعلان؛ ممبروں کے شامل ہونے کے ساتھ ہی اس کا معمولی اضافہ ہوتا ہے (ایک گیم کے ساتھ ایک کی ضرورت ہوسکتی ہے۔ engine.minor).
  • revoked: true a کے ساتھ آتا ہے۔ revokedReason. منسوخ شدہ ریلیز درج رہتی ہے تاکہ کلائنٹ کہہ سکیں کہ کیوں وہ اس سے انکار کرتے ہیں.
  • web ہے null ویب رن ٹائم کے بغیر ریلیز کے لیے۔ manifestIntegrity ویب کا SRI ہیش ہے۔ رن ٹائم کا manifest.jsonایک لوڈر صفحہ پن کی قدر۔
  • native ہر پلیٹ فارم پر ایک اندراج ہے (windows-x86_64, linux-x86_64, macos-x86_64, macos-aarch64)، یا ہے {}. manifestSha256 اس پلیٹ فارم کا ہیکس SHA-256 ہے۔ native.json; اندر کی فائل کی فہرست پر بھروسہ کرنے سے پہلے اسے چیک کریں۔

دونوں راستے بھیجتے ہیں۔ Cache-Control: public, max-age=60 ایک کے ساتھ ETag اور جواب 304 ایک مماثلت کے لئے If-None-Match. اگر پلیٹ فارم نے ابھی تک ریلیز کی فہرست کو شروع ہونے کے بعد نہیں پڑھا ہے، تو وہ جواب دیتے ہیں۔ 503 کے ساتھ Retry-After.

شائع شدہ ریلیز کبھی تبدیل نہیں ہوتی ہے: ایک فکس اگلا ورژن ہے۔ انجن سبق تازہ ترین ریلیز کی وضاحت کرتا ہے؛ یہ API کہتا ہے کہ کون سا یہ ہے

انجن ڈاؤن لوڈ کریں۔

ڈویلپرز لکھنے، چیک کرنے، پیکیج کرنے اور گیم کھیلنے کے لیے ریلیز کا مقامی رن ٹائم ڈاؤن لوڈ کرتے ہیں۔ کھلاڑی کرتے ہیں۔ کچھ بھی نہیں: StarHermit کلائنٹ اور گیم کا صفحہ ریلیز کو گیم پن لاتے ہیں۔

  1. API سے ریلیز، تازہ ترین یا آپ کے گیم پن کے لیے پوچھیں:

    curl -s https://api.starhermit.com/api/v1/engine/releases/1.41.0

  2. اپنا پلیٹ فارم لیں۔ native.<platform>.manifestUrl، اسے لاؤ native.json اور اسے چیک کریں SHA-256 کے خلاف manifestSha256.

  3. native.json's downloads ڈویلپر ڈاؤن لوڈ کو اس کے ساتھ نام دیتا ہے۔ size اور sha256. محفوظ شدہ دستاویزات کے پاس بیٹھتا ہے native.json: بدلنا native.json کے آخر میں manifestUrl محفوظ شدہ دستاویزات کے ساتھ نام اسے ڈاؤن لوڈ کریں اور اس کا SHA-256 چیک کریں۔

ایک ہی اسکرپٹ جیسے اقدامات (ضرورت curl, jq اور sha256sum; macOS کے استعمال پر shasum -a 256):

version=1.41.0 platform=linux-x86_64   # or windows-x86_64, macos-x86_64, macos-aarch64
release=$(curl -fsS "https://api.starhermit.com/api/v1/engine/releases/$version")
manifest_url=$(jq -r --arg p "$platform" '.native[$p].manifestUrl' <<<"$release")
manifest_sha=$(jq -r --arg p "$platform" '.native[$p].manifestSha256' <<<"$release")
curl -fsSO "$manifest_url"
echo "$manifest_sha  native.json" | sha256sum -c -
archive=$(jq -r '.downloads | keys[0]' native.json)
curl -fsSO "${manifest_url%native.json}$archive"
echo "$(jq -r --arg a "$archive" '.downloads[$a].sha256' native.json)  $archive" | sha256sum -c -

پاور شیل میں، Invoke-RestMethod رہائی پڑھتا ہے اور Get-FileHash -Algorithm SHA256 دیتا ہے موازنہ کرنے کے لئے ہیش۔ دی سبق پیک کھولنے کا احاطہ کرتا ہے۔ اور پہلی رن.

دی اسٹینڈ اسٹون ڈویلپر ٹولز (خودکار اشاعت اور a ڈیولپمنٹ MCP سرور) کو رن ٹائم سے الگ سے جاری کیا جاتا ہے۔

سالمیت

ہیشوں کی ایک زنجیر ہر بائٹ کا احاطہ کرتی ہے جو کلائنٹ چلاتا ہے:

  1. API ایک ریلیز کا SHA-256 دیتا ہے۔ native.json.
  2. native.json ہر فائل کا SHA-256 اور سائز دیتا ہے، اور اس کا ڈویلپر ڈاؤن لوڈ کے نیچے ہے۔ downloads.
  3. StarHermit کلائنٹ صرف اس ریلیز کے ٹکڑے لاتا ہے جو اس کے پاس پہلے سے نہیں ہے، ہر ایک کو چیک کرتا ہے، ہر فائل کو ایک ساتھ رکھتا ہے اور ریلیز کو جگہ پر منتقل کرنے سے پہلے اسے چیک کرتا ہے۔

براؤزر گیم کا لوڈر صفحہ ویب رن ٹائم کو پن کرتا ہے۔ starhermit.js اور manifest.json ایس آر آئی کے ساتھ ہیشز، اور رن ٹائم مینی فیسٹ کے خلاف لوڈ ہونے والی ہر دوسری فائل کو چیک کرتا ہے۔

ویب رن ٹائم

گیم کا لوڈر صفحہ (index.html، کے ذریعہ لکھا گیا۔ starhermit package --web) بوجھ starhermit.js اور manifest.json سے https://engine.starhermit.com/engine/X.Y.Z/، اسی SRI ہیش کے ساتھ URLs کے تحت web.base. استعمال کریں۔ engine.starhermit.com کسی بھی لوڈر صفحہ میں آپ خود لکھتے ہیں: یہ برقرار رہتا ہے۔ ہر ریلیز، جبکہ URLs کے تحت web.base صرف حالیہ کو ہولڈ کریں اور ایک پرانی ریلیز غائب ہو جائے گی۔ ان سے 1.26.0 سے ٹولز لکھتے ہیں۔ engine.starhermit.com پہلے سے طے شدہ (--loader-base URL یا STARHERMIT_WEB_LOADER_BASE اسے اوور رائیڈ کرتا ہے)۔ پرانے ٹولز، پلیٹ فارم کے ذریعے پیک کردہ میزبان گیم کے لیے جب ریلیز ختم نہ ہو تو انجن کے دو URLs کو دوبارہ لکھتا ہے۔ web.base; ری پیکج گیمز کی میزبانی کی گئی۔ کہیں اور منسوخ شدہ رہائی کسی بھی اصل سے پیش نہیں کی جاتی ہے۔

پلیٹ فارم پر اسکرپٹ گیمز

جب کھیل کی جڑ starhermit.txt اعلان کرتا ہے engine.version، پلیٹ فارم اسے اسکرپٹ گیم کے طور پر دیکھتا ہے:

  • ہر ایک پبلش فائلوں کی ریلیز کو ریکارڈ کرتا ہے، جیسا کہ hosting.engineVersion، اور سیٹ hosting.deployWarning (ایک بنڈل پش کے جواب میں بھی) جب وہ ریلیز درج نہیں ہے یا ہے۔ منسوخ کر دیا ایک انتباہ کبھی بھی اشاعت کو نہیں روکتا ہے۔
  • میزبان گیم کے ہر صفحے کو مواد-سیکیورٹی-پالیسی کے ساتھ پیش کیا جاتا ہے جو صرف اسکرپٹ کو تسلیم کرتی ہے دو انجن کی اصل سے (اور انجن کا اپنا blob: کارکنان)، تو صرف کوڈ ایک اسکرپٹ گیم کا صفحہ چل سکتا ہے سرکاری انجن ہے:
default-src 'self'; script-src https://wiki.starhermit.com https://engine.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com https://engine.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com https://engine.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

اسکرپٹ گیم کا ایک صفحہ بغیر براؤزر کی تعمیر کے (جیسے سادہ صفحہ صرف ونڈوز گیم اپ لوڈ کرتا ہے براؤزرز کے لیے) کو اسکرپٹ کی ضرورت نہیں ہے اور یہ غیر متاثر ہے۔

منسوخیاں

غیر محفوظ پائی جانے والی ریلیز کو منسوخ کر دیا جاتا ہے۔ StarHermit کلائنٹ اسے انسٹال یا شروع نہیں کرتا ہے اور بتاتا ہے۔ پلیئر، پیکیجنگ کمانڈز اس کے لیے گیم پیک کرنے سے انکار کرتے ہیں، اور پلیٹ فارم مالکان کو خبردار کرتا ہے۔ وہ گیمز جو شائع ہونے پر اسے پن کرتے ہیں۔ منسوخ شدہ ریلیز کے بعد ہمیشہ ایک مقررہ ہوتا ہے: اس پر دوبارہ پن کریں۔ اور شائع کریں (دیکھیں۔ ایک نئے انجن پر جائیں۔).
