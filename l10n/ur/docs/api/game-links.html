بیرونی روابط

ایک StarHermit-انجن گیم (میزبان API 1.24) ایک ویب صفحہ کھول سکتا ہے، لیکن صرف ایک جو StarHermit کا عملہ ہے آپ کے کھیل کے لیے منظوری دے دی ہے۔ آپ کا گیم آئی ڈی کے ذریعہ ایک لنک کھولتا ہے اور کبھی بھی یو آر ایل کو پاس نہیں کرتا ہے، لہذا یہ شامل نہیں ہوسکتا ہے۔ ایک کو کچھ بھی.

اپنے لنکس کا اعلان کریں۔

میں starhermit.txt:

engine.minor=24
engine.link.discord=https://discord.gg/abc
engine.link.store=https://example.com/game
  • آپ 16 لنکس تک کا اعلان کر سکتے ہیں۔ ہر آئی ڈی کے 1–32 حروف ہیں۔ a-z 0-9 - اور صرف ایک بار ظاہر ہو سکتا ہے۔
  • کوئی بھی engine.link.* اہم ضروریات engine.minor=24، لہذا پرانے رن ٹائمز گیم سے انکار کرتے ہیں۔
  • آپ کی اسکرپٹس کال کرتی ہیں۔ openLink("discord"). رن ٹائم لنک کے ساتھ اپنی تصدیق دکھاتا ہے۔ مکمل میزبان اور URL، اور صفحہ صرف اس صورت میں کھولتا ہے جب کھلاڑی اوپن کا انتخاب کرے۔

کیا ایک لنک ہو سکتا ہے

ایک لنک ہونا ضروری ہے۔ httpsبغیر کسی بندرگاہ کے، نہیں۔ user@کوئی IP پتہ اور کوئی مقامی نام نہیں (localhost, .local, .internal)۔ اس کا میزبان ASCII ہونا چاہیے، بین الاقوامی ناموں کے ساتھ punycode کے طور پر لکھا ہوا ہے، اور کم از کم دو لیبلز ہوں۔ اس میں بیک سلیشس، اسپیس، انکوڈ شدہ سلیش (%2f, %5c) یا ./.. راستے کے حصے پلیٹ فارم کینونیکل شکل رکھتا ہے: اسکیم اور میزبان چھوٹے کیس، اور / ایک خالی راستے کے لیے۔ باقی سب کچھ بالکل اسی طرح رکھا گیا ہے جیسا کہ آپ نے لکھا ہے۔

جب آپ شائع کرتے ہیں تو ایک لنک کے ساتھ ایک پیکیج جو ایک اصول کو توڑتا ہے انکار کر دیا جاتا ہےکے ساتھ 422 invalid_link: engine.link.<id> is not an allowed link (<rule>)اس سے پہلے کہ کوئی چیز لائیو ہو جائے۔

جائزہ لیں

ہر نیا لنک شروع ہوتا ہے۔ pending، اور رن ٹائم کچھ بھی نہیں کھولتا جب تک کہ عملہ اسے منظور نہ کرے۔ کچھ لنکس یہ ہیں۔ خودکار طور پر مسترد: URL شارٹنرز اور ری ڈائریکٹ سروسز، جن کی منزل کوئی اور ہے۔ کنٹرولز، اور پروگرامز اور آرکائیوز کے براہ راست ڈاؤن لوڈز (.exe, .dmg, .apk, .zip اور اسی طرح)۔ ٹریکنگ پیرامیٹرز جیسے utm_* جائزہ لینے والے کے لیے جھنڈا لگایا گیا ہے۔

ایک منظوری آپ کے گیم اور اس عین URL سے تعلق رکھتی ہے۔ ایک بعد کا ورژن جس میں اسی URL کی فہرست ہے، نیچے کوئی بھی آئی ڈی، رکھتا ہے۔ URL کو تبدیل کرنے کے لیے ایک نئے جائزے کی ضرورت ہے۔ عملہ ایک منظوری منسوخ کر سکتا ہے، یا بلاک کر سکتا ہے۔ پورے میزبان، کسی بھی وقت.

اپنے لنکس اور ان کی حیثیت دیکھیں GET /api/v1/me/github-games/{id}/links:

[ { "id": "discord", "url": "https://discord.gg/abc", "status": "approved", "autoReason": null, "note": null } ]

رن ٹائم چیک کرتا ہے۔ GET /api/v1/games/{slug}/links/{id} کھلاڑی کے آغاز کے ساتھ ہر ایک کھلے پر ٹوکن جواب ہے { id, url, status }، کہاں status ہے approved, pending, rejected یا revoked، یا 404 link_unknown ایک آئی ڈی کے لیے آپ کا تعینات کردہ مینی فیسٹ اعلان نہیں کرتا ہے۔

جب آپ مقامی طور پر ترقی کرتے ہیں (--dev مقامی طور پر، یا براؤزر میں ایک لوپ بیک صفحہ، بغیر کسی لانچ کے ٹوکن)، رن ٹائم انتباہ کے پیچھے اعلان کردہ لنکس کو کھولتا ہے کہ ان کا جائزہ نہیں لیا گیا ہے۔
