دوستو

دوست API دوستی کی درخواستوں اور قبول شدہ دوستی کا انتظام کرتا ہے۔ تمام راستے نیچے ہیں۔ api/v1/me اور اجازت کی ضرورت ہے۔ فرینڈشپ اسٹیٹ گیٹس گیم دعوت دیتا ہے، اور یہ کھلے چیٹ رومز اور وائس رومز تک رسائی کو بھی کنٹرول کرتا ہے۔

خرابی کی لاشیں مختلف ہوتی ہیں؛ دیکھیں API کنونشنز.

اینڈ پوائنٹس

طریقہ راستہ تصنیف تفصیل
پوسٹ /api/v1/me/friend-requests جے ڈبلیو ٹی دوستی کی درخواست بھیجیں۔
حاصل کریں۔ /api/v1/me/friend-requests جے ڈبلیو ٹی زیر التواء آنے والی دوست کی درخواستوں کی فہرست بنائیں
پوسٹ /api/v1/me/friend-requests/{requestId}/accept جے ڈبلیو ٹی دوستی کی درخواست قبول کریں۔
پوسٹ /api/v1/me/friend-requests/{requestId}/decline جے ڈبلیو ٹی دوستی کی درخواست مسترد کریں۔
حذف کریں۔ /api/v1/me/friends/{friendUserId} جے ڈبلیو ٹی کسی صارف کو ان فرینڈ کریں۔
حاصل کریں۔ /api/v1/me/friends جے ڈبلیو ٹی موجودگی کے ساتھ قبول شدہ دوستی کی فہرست بنائیں

GET /api/v1/me/friends

دوستیاں قبول کیں۔ online موجودگی سے آتا ہے currentGame ایک فعال لانچ سے:

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

صارف سے دوستی ختم کر دیتا ہے۔ واپسی 204۔

دوستی کے دروازے دوسری خصوصیات کو کیسے پہنچاتے ہیں۔

  • گیم دعوت دیتا ہے۔ صرف دوستوں کو بھیجا جا سکتا ہے — دیکھیں گیمز.
  • گپ شپ - دوستی کے دروازے کھلے چیٹ رومز میں شامل ہوتے ہیں۔ بات چیت کے اصولوں میں غیر گیم گفتگو کے لیے دوستی کی ضرورت ہوتی ہے۔ دیکھیں گپ شپ.
  • آواز - صوتی کمرے تک رسائی کے لیے بیکنگ چیٹ گفتگو کی رکنیت درکار ہوتی ہے، اس لیے چیٹ دوستی کے اصول عبوری طور پر لاگو ہوتے ہیں۔ دیکھیں آواز.
  • فی سیشن گیم گفتگو دوستی کے اصولوں کو نظرانداز کرتی ہے۔ - ایک ہی گیم سیشن میں کھلاڑی دوست بنے بغیر اس کی منسلک چیٹ/وائس استعمال کر سکتے ہیں۔

گیم اسکوپڈ لانچ ٹوکنز

گیم اسکوپڈ لانچ ٹوکن کال کر سکتا ہے۔ GET /api/v1/me/friends، لہذا ایک گیم سیشن کے اندر ایک دوست چننے والے کو مدعو کرنے کی پیشکش کر سکتی ہے — شطرنج کے حوالہ کا نفاذ اسے بالکل اسی کے لیے استعمال کرتا ہے۔ دوسرے دوست اینڈ پوائنٹس لانچ ٹوکن کے لیے 403 واپس کرتے ہیں۔ گیم اسکوپ باڑ لگانے کے قواعد دیکھیں تصدیق.

دیکھیں اسناد کی مطابقت اور مشین پڑھنے کے قابل معاہدے.
