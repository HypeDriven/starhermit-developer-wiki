لیڈر بورڈز

لیڈر بورڈ کی تعریفیں اور اندراجات۔ ریڈز گمنام ہیں؛ سکور جمع کرانے کے لیے JWT کی ضرورت ہوتی ہے۔

بنیادی URL: https://api.starhermit.com. تمام راستے نیچے ہیں۔ /api/v1/....

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/leaderboards گمنام فہرست کی تعریفیں (استفسار scope, region, titleId)
حاصل کریں۔ /api/v1/leaderboards/{id} گمنام ایک تعریف حاصل کریں۔
حاصل کریں۔ /api/v1/leaderboards/{id}/entries?scope=&region=&friendsOnly=&page=&pageSize= گمنام صفحہ بند اندراجات؛ friendsOnly=true تصدیق کی ضرورت ہے۔
پوسٹ /api/v1/leaderboards/{id}/submit جے ڈبلیو ٹی اسکور جمع کروائیں (صرف کیٹلاگ بورڈز)
حاصل کریں۔ /api/v1/games/{slug}/leaderboards اٹھانے والا آپ کے گیم کے اپنے فعال بورڈز (لانچ ٹوکن قبول کر لیا گیا)
حاصل کریں/پوسٹ کریں۔ /api/v1/me/github-games/{id}/leaderboards JWT (کھیل کا مالک) اپنے گیم کے بورڈز کی فہرست بنائیں / بنائیں
ڈالیں / حذف کریں۔ /api/v1/me/github-games/{id}/leaderboards/{leaderboardId} JWT (کھیل کا مالک) ایک کو اپ ڈیٹ / حذف کریں۔

مستند گیمز اور ایلو

ہر مستند گیم میں ایلو لیڈر بورڈ ہوتا ہے۔ اس کی آئی ڈی سے آتی ہے۔ GET /api/v1/games/{slug} → leaderboardId (دیکھیں۔ games.md)۔ اسکور صرف اسکرپٹ کے پلیٹ فارم سے لکھے جاتے ہیں۔ eloUpdates یا کنٹینر کنٹرول چینل - براہ راست جمع کرانے سے انکار کر دیا گیا ہے۔ گیم کلائنٹس معیاری صفحہ والے اختتامی نقطہ کے ذریعے اندراجات پڑھتے ہیں۔ مثال کے طور پر، شطرنج کے حوالہ کے نفاذ کی درخواستیں:

GET /api/v1/leaderboards/{leaderboardId}/entries?friendsOnly=true&page=1&pageSize=10

گیم اسکوپڈ لانچ ٹوکن ان کے اپنے گیم کا لیڈر بورڈ پڑھ سکتے ہیں۔ پبلشر سائیڈ لیڈر بورڈ CRUD رہتا ہے۔ publisher.md.

کسی کھلاڑی کی درجہ بندی کو دوبارہ ترتیب دینا

گیم کا مالک ایک کھلاڑی کی ریٹنگ کو دوبارہ شروع پر رکھ سکتا ہے۔ 1200 - ایک smurf کے لئے، ایک بڑھا ہوا اکاؤنٹ، یا ریٹنگ بگ کرپٹ:

DELETE /api/v1/me/github-games/{id}/players/{userId}/elo      → 200 { "userId": "…", "elo": 1200 }

یہ ریٹنگ میچ میکنگ جوڑوں کو دوبارہ ترتیب دیتا ہے، ایلو بورڈ سے کھلاڑی کی قطار کو ہٹاتا ہے (یہ واپس آتا ہے اپنے اگلے ریٹیڈ میچ کے ساتھ)، اور ایک اعلیٰ سطحی عددی سیٹ کرتا ہے۔ elo آپ کے اسکرپٹ کے پلیئر دستاویز میں 1200 تک - کیونکہ آپ کا اسکرپٹ اپنی ہی دستاویز سے اگلی درجہ بندی کا حساب لگاتا ہے، صرف ری سیٹ کرتے ہوئے پلیٹ فارم کی کاپی اگلے میچ تک ختم کر دی جائے گی۔ دستاویز میں باقی سب کچھ (جیت، تاریخ) اکیلا چھوڑ دیا جاتا ہے. اگر آپ کا اسکرپٹ اپنی درجہ بندی کو کسی اور نام سے رکھتا ہے، تو یہ ہے۔ نہیں rewritten : رکھنا اس میں playerStates[id].elo مفت میں ری سیٹ حاصل کرنے کے لیے۔ پہلے سے جاری میچ اب بھی رپورٹ کر سکتا ہے۔ ری سیٹ کرنے سے پہلے درجہ بندی کی جاتی ہے۔ 404 جب کھیل آپ کا نہیں ہے یا کھلاڑی کی کوئی درجہ بندی نہیں ہے۔ یہ درجہ بندی بھی کے تابع ہے۔ elo قوانین.

نظام الاوقات کو دوبارہ ترتیب دیں۔

کوئی بھی لیڈر بورڈ — ایک گیم کا اپنا بورڈ، یا کیٹلاگ کا عنوان — ایک شیڈول پر دوبارہ شروع کر سکتا ہے:

resetSchedule شروع ہوتا ہے۔
daily ہر روز 00:00 UTC پر
weekly ہر پیر کو 00:00 UTC پر
monthly ہر مہینے کی 1 تاریخ کو 00:00 UTC پر
چھوڑ دیا گیا null یا "never" کبھی نہیں

کوئی دوسری قدر ہے a 400. تعریف رپورٹ کرتی ہے۔ currentPeriodStartedAt اور nextResetAt (دونوں null ایک بورڈ کے لیے جو کبھی ری سیٹ نہیں ہوتا ہے)، تاکہ ایک کلائنٹ دکھا سکے۔ "2 دنوں میں ری سیٹ ہو جائے گا۔".

جب بورڈ ہوتا ہے تو دوبارہ ترتیب کا اطلاق ہوتا ہے۔ پڑھیں: اندراجات کا اختتامی نقطہ صرف اس وقت سے جمع کرائے گئے اسکور دکھاتا ہے۔ موجودہ دور شروع ہوا، اور رینک کی گنتی مدت کے اندر کی جاتی ہے۔ پر کچھ بھی حذف نہیں کیا گیا ہے۔ حد، لہذا ری سیٹ بالکل 00:00 UTC پر اثر انداز ہوتا ہے۔ اس کا مطلب یہ بھی ہے کہ شیڈول تبدیل کیا جا سکتا ہے۔ کسی بھی وقت - یہ تبدیل کرتا ہے کہ کون سی اندراجات دکھائی جاتی ہیں، نہ کہ رکھی جاتی ہیں۔ پچھلے ادوار نہیں ہیں۔ API کے ذریعے پڑھنے کے قابل۔

آپ کے گیم کے اپنے لیڈر بورڈز

اس کے ایلو بورڈ کے ساتھ، a کے ساتھ ایک گیم server= سکرپٹ یا container.image= پسدید ہو سکتا ہے اس کے اپنے لیڈر بورڈز — اعلی سکور، تیز ترین لیپ، سب سے زیادہ ہلاکتیں — تخلیق کردہ کھیل کے مالک. آپ کو پبلشر اکاؤنٹ کی ضرورت نہیں ہے: گیم کا مالک ہونا آپ کو اس کا ناشر بنا دیتا ہے۔

ایلو بورڈ کی طرح، صرف آپ کے گیم کا سرور انہیں لکھتا ہے۔ آپ کا اسکرپٹ واپس آتا ہے۔ scores: { "<key>": { "<userId>": score } } کسی بھی ہک سے (دیکھیں۔ گیم اسکرپٹس - لیڈر بورڈز)، یا آپ کا کنٹینر بھیجتا ہے۔ scores کنٹرول پیغام. POST /leaderboards/{id}/submit ہے انکار کر دیا، لہذا ایک ترمیم شدہ کلائنٹ اسکور پوسٹ نہیں کر سکتا۔

ایک بنائیں - POST /api/v1/me/github-games/{id}/leaderboards

{
  "key": "high-score",
  "name": "High score",
  "scoreType": "integer",
  "sortDirection": "desc",
  "minScore": 0,
  "maxScore": 1000000,
  "isActive": true
}

واپسی 201 a کے ساتھ LeaderboardDefinitionDto جس کا gameDefinitionId اور key مقرر ہیں

میدان مطلب
key درکار ہے۔ آپ کا سرور جس نام کے تحت جمع کرتا ہے: 1–64 حروف، ہندسے، ., _, -. فی گیم منفرد۔
name درکار ہے۔ ڈسپلے نام، زیادہ سے زیادہ 200 حروف۔
scoreType integer (پہلے سے طے شدہ) decimal، یا time-ms (ملی سیکنڈز کی ایک غیر منفی پوری تعداد)
sortDirection desc (پہلے سے طے شدہ - زیادہ بہتر ہے) یا asc (نیچا بہتر ہے، جیسے لیپ ٹائم)
minScore / maxScore اختیاری حدود؛ ان کے باہر کا سکور نظر انداز کر دیا جاتا ہے۔
isActive طے شدہ true. ایک غیر فعال بورڈ کوئی اسکور قبول نہیں کرتا اور کھلاڑیوں کے لیے درج نہیں ہوتا۔
resetSchedule اختیاری: daily, weekly یا monthly - دیکھیں نظام الاوقات کو دوبارہ ترتیب دیں۔. ڈیفالٹ: کبھی بھی ری سیٹ نہیں ہوتا ہے۔

key, scoreType اور sortDirection تخلیق کے بعد تبدیل نہیں ہو سکتا: آپ کا سرور کلید کے ذریعے جمع کرتا ہے، اور پہلے سے ذخیرہ شدہ سکور دوسرے دو کے ذریعہ منتخب کیے گئے تھے۔ ایک مختلف کی ضرورت ہے؟ ایک نیا بورڈ بنائیں۔ PUT .../leaderboards/{leaderboardId} قبول کرتا ہے name, minScore, maxScore, isActive اور resetSchedule (بھیجیں "never" ری سیٹ کرنا بند کرنے کے لیے) DELETE بورڈ کو ہٹاتا ہے اور اس کے اندراجات - سیٹ isActive: false اسے ریٹائر کرنے اور انہیں رکھنے کے لیے۔ ایک کھیل زیادہ سے زیادہ ہو سکتا ہے 2048 بورڈز

اسکور کیسے رکھے جاتے ہیں۔

  • فی کھلاڑی ایک اندراج: ان کا بہترین۔ "بہترین" بورڈ کی پیروی کرتا ہے۔ sortDirection. جمع کرنا a بدتر سکور کچھ نہیں بدلتا، لہذا ہر میچ کے بعد پہلے چیک کیے بغیر رپورٹ کریں۔ کے ساتھ ایک بورڈ پر ایک ری سیٹ شیڈول، یہ سب سے بہتر ہے اس مدت: ری سیٹ کے بعد پہلا سکور ہمیشہ شمار ہوتا ہے، آخری دور میں کھلاڑی کا اسکور اگرچہ اچھا تھا۔
  • سیشن میں صرف کھلاڑی ہی سکور کر سکتے ہیں۔ AI سیٹ اور کسی اور کو نظر انداز کر دیا جاتا ہے۔
  • ایک اسکور جو بورڈ کے قواعد کو توڑتا ہے (حد سے باہر، ایک پر ایک حصہ integer بورڈ، ایک منفی time-ms) کو نظر انداز کر دیا جاتا ہے، جیسا کہ ایک کلید ہے جس میں کوئی فعال بورڈ نہیں ہے۔ آپ کے سرور کو کچھ بھی واپس نہیں کیا گیا ہے۔

انہیں اپنے کھیل میں دکھائیں۔

GET /api/v1/games/{slug}/leaderboards گیم کے فعال بورڈز کو ان کے ساتھ فہرست کرتا ہے۔ id اور key, اور گیم کے لانچ ٹوکن کے ساتھ کام کرتا ہے۔ اوپر معیاری صفحہ کے اختتامی نقطہ کے ساتھ اندراجات پڑھیں — GET /api/v1/leaderboards/{id}/entries - جس پر لانچ ٹوکن بھی ان بورڈز تک پہنچ سکتا ہے۔

مرحلہ وار: ٹیوٹوریل: لیڈر بورڈز اور آپ کے گیم کے لیے کامیابیاں.

دیکھیں API کنونشنز غلطی کی تجزیہ کے لیے۔

دیکھیں اسناد کی مطابقت اور مشین پڑھنے کے قابل معاہدے.
