پروفائل

پروفائل API تصدیق شدہ صارف کے اپنے اکاؤنٹ کا احاطہ کرتا ہے (/api/v1/me/...)، دوسرے صارفین کی عوامی تلاش، عوامی چابیاں، منسلک شناخت، رازداری کی ترتیبات، حقدار، اور موجودگی دل کی دھڑکن۔ اکاؤنٹ کے راستوں کے لیے اجازت درکار ہوتی ہے۔ موجودہ شرائط کی دستاویز عوامی ہے۔

خرابی کی لاشیں مختلف ہوتی ہیں؛ دیکھیں API کنونشنز.

اینڈ پوائنٹس

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/me جے ڈبلیو ٹی (Permission-user.profile.read) اپنا پروفائل حاصل کریں۔
پیچ /api/v1/me جے ڈبلیو ٹی (Permission-user.profile.update) صارف نام، ای میل، میٹا ڈیٹا، یا عرفی نام کو اپ ڈیٹ کریں۔
حاصل کریں۔ /api/v1/terms گمنام StarHermit کی موجودہ شرائط اور ان کی ہیش پڑھیں
پوسٹ /api/v1/me/terms/accept اکاؤنٹ JWT یا پلیئر لانچ ٹوکن StarHermit کی موجودہ شرائط کو قبول کریں۔
ڈالو /api/v1/me/avatar جے ڈبلیو ٹی (Permission-user.profile.update) اپنا اوتار اپ لوڈ کریں۔
حاصل کریں۔ /api/v1/me/avatar جے ڈبلیو ٹی (Permission-user.profile.read) اپنا اوتار حاصل کریں۔
حاصل کریں۔ /api/v1/users/{id}/avatar جے ڈبلیو ٹی کسی بھی صارف کا اوتار حاصل کریں۔
حاصل کریں۔ /api/v1/users/{id}/profile جے ڈبلیو ٹی کسی بھی صارف کا عوامی پروفائل حاصل کریں۔
حاصل کریں۔ /api/v1/me/public-keys جے ڈبلیو ٹی (Permission-user.profile.read) اپنی عوامی چابیاں درج کریں۔
پوسٹ /api/v1/me/public-keys OAuth سے تصدیق شدہ جے ڈبلیو ٹی (Permission-user.profile.update) فوری طور پر ایک عوامی کلید شامل کریں۔
حذف کریں۔ /api/v1/me/public-keys/{keyId} OAuth سے تصدیق شدہ جے ڈبلیو ٹی (Permission-user.profile.update) ایک کلید اور اس کے سیشنز کو منسوخ کریں۔
حذف کریں۔ /api/v1/me/public-keys/all OAuth سے تصدیق شدہ جے ڈبلیو ٹی (Permission-user.profile.update) ہر فعال کلید اور اس کے سیشنز کو منسوخ کریں۔
حذف کریں۔ /api/v1/me/public-keys/current عوامی کلیدی سیشن (Permission-user.profile.update) اس سیشن کے ساتھ سائن ان کردہ کلید اور اس کے سیشنز کو کالعدم کریں۔ اس کی کوئی کلید نہیں ہے، اس لیے یہ کسی بہن بھائی تک نہیں پہنچ سکتی۔ ایک سیشن جس میں کلید نہیں ملتی ہے۔ 409 no_public_key_session
حاصل کریں۔ /api/v1/me/identities جے ڈبلیو ٹی (Permission-user.profile.read) اپنی منسلک شناختوں کی فہرست بنائیں
پوسٹ /api/v1/me/identities جے ڈبلیو ٹی (Permission-user.profile.update) ایک شناخت لنک کریں (صرف غیر OAuth فراہم کنندگان)
حذف کریں۔ /api/v1/me/identities/{identityId} جے ڈبلیو ٹی (Permission-user.profile.update) کسی شناخت کا لنک ختم کریں۔
حاصل کریں۔ /api/v1/me/privacy جے ڈبلیو ٹی (Permission-user.profile.read) اپنی رازداری کی ترتیبات حاصل کریں۔
ڈالو /api/v1/me/privacy جے ڈبلیو ٹی (Permission-user.profile.update) اپنی رازداری کی ترتیبات کو تبدیل کریں۔
حاصل کریں۔ /api/v1/me/entitlements جے ڈبلیو ٹی (Permission-user.profile.read) اپنے سافٹ ویئر کے حقوق کی فہرست بنائیں
پوسٹ /api/v1/me/heartbeat جے ڈبلیو ٹی دل کی دھڑکن کی موجودگی LastSeenAt لکھیں)

PATCH /api/v1/me

تمام فیلڈز اختیاری۔ پابندیاں: username 1-32 حروف؛ nickname ≤64 حروف (کئی اکاؤنٹس میں کوئی نہیں ہے؛ metadata ≤4096 حروف۔ صارف نام اور عرفی نام ایک کا اشتراک کرتے ہیں۔ کیس غیر حساس نام کی جگہ: 409 جب کوئی دوسرا اکاؤنٹ اس نام کو اپنے صارف نام یا عرفی نام کے طور پر استعمال کرتا ہے، کیس نظر انداز. عرفی نام NFKC-نارملائزڈ ہیں، اور کنٹرول یا پوشیدہ حروف ہیں۔ 400. بدل رہا ہے۔ email اس کے علاوہ ایک کی ضرورت ہے OAuth سے تصدیق شدہ سیشن کیونکہ اکاؤنٹ ای میل اسناد کے لنکس کو منظور کر سکتا ہے؛ ایک عوامی کلید یا ای میل کی تصدیق کا سیشن ملتا ہے۔ 403 اس فیلڈ کے لیے لیکن پھر بھی دوسروں کو اپ ڈیٹ کر سکتے ہیں۔ 204 کو واپس کرتا ہے۔ کامیابی، تنازعہ پر 409 (صارف کا نام یا عرفی نام پہلے ہی لے لیا گیا ہے)۔

{
  "username": "newname",
  "email": "new@example.com",
  "metadata": "{}",
  "nickname": "New Nick"
}

شرائط کی قبولیت

محفوظ REST اینڈ پوائنٹس استعمال کرنے یا WebSockets کھولنے سے پہلے، اکاؤنٹ کو قبول کرنا چاہیے۔ موجودہ StarHermit شرائط. یہ اکاؤنٹ ٹوکنز اور پلیئر لانچ ٹوکنز پر لاگو ہوتا ہے، بشمول اکاؤنٹس ایک پرانی نظرثانی کو قبول کیا۔ یہ گمنام وسائل/سائن ان یا کنٹینر سرور پر لاگو نہیں ہوتا ہے۔ اپنی تعیناتی کا ٹوکن۔ GET /api/v1/me اور قبولیت کا اختتامی نقطہ ان کے معمول کے ساتھ دستیاب رہتا ہے۔ اکاؤنٹ کی اجازتیں جب کہ قبولیت زیر التواء ہے۔

GET /api/v1/me شامل ہیں currentTermsHash اور termsAcceptanceRequired. ذخیرہ شدہ termsAcceptedHash اور termsAcceptedAt پہلی قبولیت سے پہلے کالعدم ہیں۔ میں دکھایا گیا ہیش پروفائل کی مثال اوپر مختصر ہے؛ ہمیشہ API کے ذریعہ واپس کردہ مکمل ہیش کا استعمال کریں۔

GET /api/v1/terms

گمنام؛ پلیئر لانچ ٹوکن کے ساتھ بھی پڑھنے کے قابل۔ واپسی 200 کے ساتھ Cache-Control: no-store:

{ "hash": "<current-64-character-lowercase-sha256>", "text": "<complete terms text>" }

رینڈر text سادہ متن کے طور پر. hash عین مطابق UTF-8 دستاویز بائٹس کا SHA-256 ہے۔ واپس کا استعمال کریں دوبارہ فارمیٹ شدہ ڈسپلے ٹیکسٹ کو ہیش کرنے کے بجائے قدر۔

POST /api/v1/me/terms/accept

صارف کے پڑھنے اور واضح طور پر نظرثانی کو قبول کرنے کے بعد، اس کی ہیش بھیجیں:

POST /api/v1/me/terms/accept
Authorization: Bearer <account-access-token>
Content-Type: application/json

{ "hash": "<hash-returned-with-the-displayed-text>" }

واپسی 200 کے ساتھ { "termsAcceptedHash", "termsAcceptedAt" }. OAuth اور عوامی کلیدی اکاؤنٹ سیشنز اور پلیئر گیم اسکوپڈ لانچ ٹوکنز قبول کر سکتے ہیں. کنٹینر سرور ٹوکن کسی کھلاڑی کے لیے کام نہیں کر سکتا۔ قبولیت کو اکاؤنٹ میں محفوظ کیا جاتا ہے اور اس پر اثر ہوتا ہے۔ اسی اب بھی درست ٹوکن کے ساتھ اگلی درخواست؛ ٹوکن کو ریفریش کرنا غیر ضروری ہے۔

غائب/خالی ہیش یا 64 حروف سے زیادہ لمبا ایک واپس آتا ہے۔ 400. ایک ہیش جو بالکل نہیں ہے۔ موجودہ نظرثانی کے ریٹرن سے ملائیں۔ 409:

{
  "error": "terms_version_mismatch",
  "termsHash": "<current-hash>",
  "termsUrl": "/api/v1/terms"
}

نئی دستاویز لائیں اور ڈسپلے کریں اور دوبارہ قبولیت طلب کریں۔ خاموشی سے متبادل کو قبول نہ کریں۔ نظر ثانی زیر التوا قبولیت واپسی کے ساتھ دیگر محفوظ درخواستیں۔ 403:

{
  "error": "terms_acceptance_required",
  "message": "Accept the latest terms of service before using the API.",
  "termsHash": "<current-hash>",
  "termsUrl": "/api/v1/terms",
  "acceptUrl": "/api/v1/me/terms/accept"
}

ایک میزبان گیم شرائط کو ظاہر کر سکتا ہے اور ڈسپلے شدہ ہیش کو اپنے پلیئر لانچ ٹوکن کے ساتھ جمع کر سکتا ہے۔ جب کھلاڑی Accept دباتا ہے، تو دوبارہ کوشش کریں۔ یہ کھلاڑی کو ان کے اکاؤنٹ UI پر بھی بھیج سکتا ہے۔ بار بار سائن ان یا ٹوکن ریفریش زیر التواء قبولیت کو ٹھیک نہیں کرتا ہے۔ HTTP کے ساتھ WebSocket اپ گریڈ سے انکار کر دیا گیا ہے۔ 403 کھولنے سے پہلے؛ براؤزر رسپانس باڈی کو چھپا سکتے ہیں، لہذا منسلک ہونے سے پہلے REST کے ذریعے قبولیت کو ہینڈل کریں۔

اکاؤنٹ یا گیم کلائنٹ کی مثال (کال acceptDisplayedTerms صرف صارف کی قبول کارروائی سے):

const api = 'https://api.starhermit.com';
async function loadTerms() {
  const response = await fetch(`${api}/api/v1/terms`);
  if (!response.ok) throw new Error(`Terms fetch failed: ${response.status}`);
  return response.json(); // Display text, retain this document's hash.
}
async function acceptDisplayedTerms(accountToken, displayedTerms) {
  const response = await fetch(`${api}/api/v1/me/terms/accept`, {
    method: 'POST',
    headers: { Authorization: `Bearer ${accountToken}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ hash: displayedTerms.hash })
  });
  if (response.status === 409) {
    throw new Error('Terms changed. Reload and display them for a new acceptance.');
  }
  if (!response.ok) throw new Error(`Acceptance failed: ${response.status}`);
  return response.json();
}

اوتار

PUT /api/v1/me/avatar ایک PNG تصویر، مربع، ≤512×512 پکسلز، ≤1 MB قبول کرتا ہے:

{ "imageBase64": "iVBORw0KGgoAAAANSUhEUg..." }

واپسی 204۔ GET /api/v1/me/avatar آپ کے اوتار کو بطور واپس کرتا ہے۔ image/png بائٹس

دوسرے صارفین

  • GET /api/v1/users/{id}/avatar - کسی بھی صارف کے لیے PNG اوتار۔
  • GET /api/v1/users/{id}/profile:

  "username": "pk-a1b2c3d4e5f6",

عوامی چابیاں

ایک رجسٹرڈ کلید ایک API کی سند ہے: اس کا ہولڈر مکمل کر سکتا ہے۔ عوامی کلیدی چیلنج کا بہاؤ اور ایک عام رسائی/ریفریش ٹوکن حاصل کریں۔ جوڑی یہ ایک علیحدہ لیبل والی کلید کو ڈیسک ٹاپ کلائنٹ یا تعیناتی پائپ لائن کے لیے موزوں بناتا ہے۔

کلیدوں کو شامل کرنے یا دیگر کلیدوں کو منسوخ کرنے کے لیے OAuth سے تصدیق شدہ سیشن کی ضرورت ہوتی ہے۔ ایک عوامی کلید سیشن صرف اس کی اپنی کلید کو منسوخ کر سکتا ہے۔ DELETE /api/v1/me/public-keys/current. یہ نہیں کر سکتا تبدیلیوں کا اندراج کریں یا دوسرے آلات کو منسوخ کریں۔ کسی بھی مکمل اکاؤنٹ سیشن کے لیے فہرست دستیاب رہتی ہے۔ گیم لانچ اور سرور ٹوکن اکاؤنٹ کیز کا نظم نہیں کر سکتے۔

GET /api/v1/me/public-keys

فہرست میں آڈٹ ٹریل کے طور پر منسوخ شدہ قطاریں شامل ہیں:

[

    "id": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "keyType": "Ed25519",
    "keyData": "<base64-raw-32-byte-public-key>",
    "label": "orbit-league-production",
    "fingerprint": "4d9f3c...",
    "createdAt": "2026-07-01T12:00:00Z",
    "lastUsedAt": "2026-07-30T09:00:00Z",
    "isRevoked": false,
    "revokedAt": null,
    "metadata": null

POST /api/v1/me/public-keys

OAuth سے تصدیق شدہ سیشن کی ضرورت ہوتی ہے اور فوری طور پر کلید منسلک کرتا ہے۔ گمنام کے برعکس رجسٹریشن، کوئی ای میل راؤنڈ ٹرپ کی ضرورت نہیں ہے۔

{
  "keyType": "Ed25519",
  "keyData": "<base64-raw-32-byte-public-key>",
  "label": "orbit-league-production"
}

label اختیاری ہے (زیادہ سے زیادہ 128 حروف)۔ قبول شدہ کلیدی اقسام ہیں۔ Ed25519, ECDSA-P256، اور RSA-PSS; مواد معیاری Base64 ہونا چاہیے: Ed25519 کے لیے ایک خام 32 بائٹ عوامی کلید، ایک انکوڈ شدہ P-256 ECDSA کے لیے وکر پوائنٹ، یا RSA کے لیے عوامی SPKI۔ RSA کیز 2048–8192 بٹس ہونی چاہئیں۔ پلیٹ فارم درست مواد کو کینونیکلائز کرتا ہے اور اکاؤنٹ کو بطور ڈیفالٹ 20 فعال کلیدوں تک محدود کرتا ہے۔ fingerprint ہے کینونیکل کا لوئر کیس SHA-256 ہیکس ڈائجسٹ keyType:keyData تار

واپسی 201 تخلیق شدہ کلید کے ساتھ۔ غلط مواد کی واپسی۔ 400; پہلے سے فعال کلید یا مکمل کلیدی فہرست کی واپسی 409 (مؤخر الذکر میں شامل ہے۔ limit)۔ فعال کلیدی مواد منفرد پلیٹ فارم وسیع ہے۔

DELETE /api/v1/me/public-keys/{keyId}

OAuth سے تصدیق شدہ سیشن کی ضرورت ہے۔ تنسیخ غیرمعمولی ہے اور ریفریش سیشن کو ختم کرتا ہے۔ کلید کی طرف سے؛ ان کی اگلی درخواست پر اسے نام دینے والے ٹوکن تک رسائی سے انکار کر دیا جاتا ہے۔ واپسی:

{ "revoked": [{ "id": "...", "isRevoked": true }], "sessionsEnded": 1 }

اس اکاؤنٹ پر ایک نامعلوم کلید واپس آتی ہے۔ 404.

DELETE /api/v1/me/public-keys/all

کمپرومائز رسپانس آپریشن: ہر فعال کلید کو منسوخ کریں اور ان تمام سیشنز کو ختم کریں جن کی انہوں نے تصدیق کی ہے۔ اس میں واضح ہے۔ /all راستہ تاکہ غلطی سے خالی کلیدی ID بڑی تعداد میں منسوخی نہیں بن سکتی۔ وہی لوٹاتا ہے۔ { revoked, sessionsEnded } شکل

DELETE /api/v1/me/public-keys/current

عوامی کلید کے ساتھ توثیق شدہ ایک مکمل اکاؤنٹ سیشن اس سیشن کے لیے استعمال ہونے والی کلید کو منسوخ کر سکتا ہے، کلیدی ID کا نام لیے بغیر۔ اس کے لیے استعمال کریں۔ اس ڈیوائس کو بھول جائیں۔. وہی لوٹاتا ہے۔ { revoked, sessionsEnded } اس کلید کا استعمال کرتے ہوئے سیشن کو شکل دیتا ہے اور اسے باطل کرتا ہے۔ ذخیرہ شدہ ٹوکنز کو ضائع کریں۔ اور کامیابی کے بعد مقامی نجی کلید۔ ایک سیشن جس میں کوئی عوامی کلید واپس نہیں آتی ہے۔ 409 کے ساتھ code: "no_public_key_session"; گیم لانچ ٹوکن سے انکار کر دیا گیا ہے۔

مکمل مشین کی تعیناتی کی مثال کے لیے، دیکھیں OAuth کے اندراج شدہ عوامی کلید کے ساتھ CI/CD سے تعمیرات اپ لوڈ کریں۔.

گیم اسکوپڈ لانچ ٹوکنز

اس صفحہ کے اختتامی نکات میں سے، ایک گیم اسکوپڈ لانچ ٹوکن صرف کال کر سکتا ہے:

  • GET /api/v1/users/{id}/avatar
  • GET /api/v1/users/{id}/profile
  • GET /api/v1/me/friends (دیکھیں۔ دوستو)
  • GET /api/v1/terms
  • POST /api/v1/me/terms/accept
  • POST /api/v1/me/heartbeat

باقی سب کچھ گیم اسکوپ باڑ کے تحت 403 لوٹاتا ہے جس میں بیان کیا گیا ہے۔ تصدیق.
