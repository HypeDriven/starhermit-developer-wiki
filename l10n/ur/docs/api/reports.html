کریش اور بگ رپورٹس

کھلاڑی کسی بھی گیم کے اندر سے کریش یا بگ کی اطلاع دے سکتے ہیں جس میں سلگ ہے — صرف براؤزر گیمز شامل - گیم کے لانچ ٹوکن یا مکمل صارف ٹوکن کا استعمال کرتے ہوئے۔ گیم کا مالک پڑھتا ہے، ٹرائیز اور ان کے ذریعے حذف کرتا ہے۔ /api/v1/me/github-games/{id}/reports.

کنٹینر گیم کے اپنے سرور آؤٹ پٹ اور کریش ریکارڈز کے لیے، دیکھیں کنٹینر کی میزبانی والے گیم سرورز - آپ کے سرور کی آؤٹ پٹ اور کریش رپورٹس.

اینڈ پوائنٹس

طریقہ راستہ تصنیف تفصیل
پوسٹ /api/v1/games/{slug}/reports اس گیم، یا JWT کے لیے ٹوکن لانچ کریں۔ کریش یا بگ رپورٹ درج کریں۔
حاصل کریں۔ /api/v1/games/{slug}/reports/mine اس گیم، یا JWT کے لیے ٹوکن لانچ کریں۔ اس گیم کے لیے آپ کی 50 تازہ ترین رپورٹس، ان کی حیثیت کے ساتھ
حاصل کریں۔ /api/v1/me/github-games/{id}/reports JWT (مالک) رپورٹس کی فہرست: ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
حاصل کریں۔ /api/v1/me/github-games/{id}/reports/{reportId} JWT (مالک) ایک رپورٹ، اس کی منسلکہ فہرست کے ساتھ
حاصل کریں۔ /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} JWT (مالک) ایک منسلکہ، ہمیشہ ڈاؤن لوڈ کے طور پر
پیچ /api/v1/me/github-games/{id}/reports/{reportId} JWT (مالک) سیٹ status
حذف کریں۔ /api/v1/me/github-games/{id}/reports/{reportId} JWT (مالک) رپورٹ حذف کریں → 204

رپورٹ درج کروائیں۔

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind ہے crash یا bug; title درکار ہے (≤200 حروف)۔
  • باقی سب کچھ اختیاری ہے۔ userAgent درخواست کی ڈیفالٹس User-Agent ہیڈر
  • جواب: 201 { "id", "kind", "status": "open", "createdAt" }.
حیثیت مطلب
400 ناقص: نامعلوم kind، لاپتہ title، غلط base64، یا JSON نہیں۔
404 نامعلوم یا ہٹا دیا گیا گیم
413 تفصیل، اٹیچمنٹ کی گنتی یا اٹیچمنٹ بائٹس گیم کی حدود سے زیادہ
429 اس گیم کے لیے روزانہ کی رپورٹ کی حد سے زیادہ؛ دیکھیں Retry-After

حدود

آپریٹرز ان میں سے ہر ایک کو پورے پلیٹ فارم اور انفرادی گیمز کے لیے تبدیل کر سکتے ہیں۔ روزانہ کی حد ایک کھلاڑی کے لیے بھی سیٹ کیا جا سکتا ہے۔

حد طے شدہ
رپورٹس فی کھلاڑی فی گیم فی دن 20
تفصیل کی لمبائی 20,000 حروف
منسلکات فی رپورٹ 4
اٹیچمنٹ بائٹس فی رپورٹ 2 ایم آئی بی
رپورٹس فی گیم رکھی جاتی ہیں۔ 2,000
بائٹس فی گیم رکھی جاتی ہیں۔ 256 ایم بی
برقرار رکھنا 90 دن

جب کوئی گیم اپنی اسٹوریج کی حد تک پہنچ جاتی ہے، تو سب سے پرانی رپورٹس — جو پہلے حل ہو جاتی ہیں — کو ہٹا دیا جاتا ہے۔ جگہ بنائیں پوری فی گیم بائٹ کی حد سے بڑی ایک رپورٹ کے ساتھ انکار کر دیا گیا ہے۔ 413.

ٹرائیج رپورٹس (گیم مالک)

فہرست واپس آتی ہے۔ { "items", "total", "page", "pageSize" }; ہر شے پر رپورٹر کا نام ہوتا ہے، kind, status, title، کلائنٹ کی تفصیلات اور اس کے منسلکہ شمار۔ ایک رپورٹ کے ذریعے منتقل کریں open → acknowledged → resolved کے ساتھ:

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

منسلکات کو ڈاؤن لوڈ کے طور پر پیش کیا جاتا ہے (Content-Disposition: attachment, nosniff، ایک سینڈ باکسنگ CSP)۔ صرف inert قسمیں اپنے اعلان کردہ مواد کی قسم کو رکھتی ہیں — ٹیکسٹ، JSON، PNG، JPEG، WebP، GIF، zip اور gzip کچھ اور، مارک اپ شامل، کے طور پر پیش کیا جاتا ہے۔ application/octet-stream.

JavaScript SDK سے

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports

دیکھیں JavaScript SDK.

مشترکہ API کنونشنز جوابی تجزیہ، ٹائم اسٹیمپ، صفحہ بندی، اور دوبارہ کوششوں کی وضاحت کریں۔

دیکھیں اسناد کی مطابقت اور مشین پڑھنے کے قابل معاہدے.
