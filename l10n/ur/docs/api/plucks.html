پلکس

پلکس (علامت پی ایل کے) StarHermit کی کرنسی ہیں۔ کھلاڑی انہیں آپ کے گیم تک رسائی پر خرچ کرتے ہیں۔ اشیاء جو آپ اس کے اندر بیچتے ہیں۔ آپ وصول کرتے ہیں۔ 99% ہر فروخت پر، اور پلیٹ فارم 1% کمیشن رکھتا ہے، مکمل پلک تک گول: 1-100 PLK کی فروخت پر 1 PLK، 101-200 پر 2 PLK، وغیرہ۔ ہر توازن صفر سے شروع ہوتا ہے۔

کھلاڑی پلکس کو کیسے خریدتے یا کماتے ہیں اس کا ابھی فیصلہ نہیں ہوا ہے۔ جب تک ایسا نہ ہو، توازن صرف اس کے ذریعے ہی بدل جاتا ہے۔ سیلز اور آپریٹر گرانٹس۔

اینڈ پوائنٹس

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/me/plucks جے ڈبلیو ٹی آپ کا بیلنس: { balance, currency: "Plucks", symbol: "PLK" }
حاصل کریں۔ /api/v1/me/plucks/transactions جے ڈبلیو ٹی آپ کی تاریخ، تازہ ترین پہلے: ?before=&limit= (≤100)
ڈالو /api/v1/me/github-games/{id}/plucks/access-price JWT (مالک) { price } (1–1,000,000,000، یا null مفت میں)
حاصل کریں۔ /api/v1/me/github-games/{id}/plucks/items JWT (مالک) آپ کے آئٹم کا کیٹلاگ
ڈالو /api/v1/me/github-games/{id}/plucks/items/{key} JWT (مالک) بنائیں یا اپ ڈیٹ کریں۔ { name, price, active }
حذف کریں۔ /api/v1/me/github-games/{id}/plucks/items/{key} JWT (مالک) ایک آئٹم کو ہٹا دیں → 204
حاصل کریں۔ /api/v1/me/github-games/{id}/plucks/sales JWT (مالک) ادا شدہ آئٹم آرڈرز، پہلے تازہ ترین
حاصل کریں۔ /api/v1/games/{slug}/plucks/access ٹوکن یا JWT لانچ کریں۔ { price, hasAccess, isOwner } کال کرنے والے کے لیے
حاصل کریں۔ /api/v1/games/{slug}/plucks/items گمنام آپ کی فعال اشیاء
پوسٹ /api/v1/games/{slug}/plucks/orders ٹوکن یا JWT لانچ کریں۔ کھلاڑی سے خریدنے کو کہیں۔ { itemKey }
حاصل کریں۔ /api/v1/games/{slug}/plucks/orders/{id} ٹوکن یا JWT لانچ کریں۔ کھلاڑی کا حکم اور اس کی حیثیت
حاصل کریں۔ /api/v1/games/{slug}/server/plucks/orders?since= سرور ٹوکن ڈیلیور کرنے کے لیے ادا شدہ آرڈرز، سب سے پرانے پہلے
پوسٹ /api/v1/me/plucks/game-access/{gameId} JWT، OAuth سائن ان کھلاڑی رسائی خریدتا ہے: { expectedPrice }
پوسٹ /api/v1/me/plucks/orders/{id}/confirm JWT، OAuth سائن ان کھلاڑی آرڈر کے لیے ادائیگی کرتا ہے۔
پوسٹ /api/v1/me/plucks/orders/{id}/cancel جے ڈبلیو ٹی کھلاڑی ایک آرڈر سے انکار کرتا ہے۔

ہر لین دین کہتا ہے کہ اس کے پلکس کہاں سے آئے ہیں۔

ہر تاریخ کے اندراج میں ایک ہوتا ہے۔ source:

  • sale.game_access: ایک کھلاڑی نے کھیل تک رسائی خریدی۔
  • sale.game_item: ایک کھلاڑی نے ایک درون گیم آئٹم خریدا۔
  • grant: ایک آپریٹر نے پلکس جاری کیا۔

اندراجات بھی لے جاتے ہیں۔ amount (دستخط شدہ) balanceAfter, fee، گیم، آئٹم کی کلید، آرڈر اور دوسری پارٹی. لیجر صرف ضمیمہ ہے: ایک غلطی کو ایک نئے لین دین کے ساتھ درست کیا جاتا ہے، کبھی نہیں ایک پرانی ترمیم.

اپنے گیم تک رسائی بیچنا

ایک قیمت مقرر کریں، اور آپ کا گیم جاری کرتا ہے ٹوکن صرف آپ کو اور ان کھلاڑیوں کے لیے جنہوں نے رسائی خریدی ہے۔ کوئی بھی اور ملتا ہے 402 کے ساتھ code: "purchase_required" اور price. انہیں خریدنے کا راستہ دکھائیں۔

خریداری وہ قیمت بھیجتی ہے جو کھلاڑی کو دکھایا گیا تھا۔ expectedPrice. اگر آپ نے قیمت بدل دی ہے۔ چونکہ، خریداری کے ساتھ انکار کر دیا گیا ہے 409 (code: "price_changed")، تو کوئی بھی قیمت ادا نہیں کرتا جو انہوں نے کیا تھا۔ نہیں دیکھتے رسائی مستقل ہے اور بعد میں قیمت کی تبدیلیوں سے بچ جاتی ہے۔ ایک گیم کی قیمت لگانا جو مفت بھی تھا۔ گیٹس اپنے موجودہ کھلاڑیوں کو۔

آپ کے گیم کی میزبانی کی فائلیں ابھی تک بند نہیں ہیں۔ قیمت پلیٹ فارم کی خصوصیات کو روکتی ہے (سائن ان، سیشنز، سیو، کامیابیاں)، براؤزر گیم کی فائلوں کو ڈاؤن لوڈ نہیں کرنا۔

اشیاء فروخت کرنا

آپ کا کھیل کسی کھلاڑی کے پلکس کو خرچ نہیں کر سکتا۔ آپ کے گیم کا اپنا کوڈ کھلاڑی کا لانچ ٹوکن رکھتا ہے، اس لیے a ٹوکن جو خرچ کر سکتا ہے کسی بھی کھیل کو اپنے کھلاڑیوں کو نکالنے دیتا ہے۔ بہاؤ یہ ہے:

  1. آپ کا کھیل پوچھتا ہے۔ POST /api/v1/games/{slug}/plucks/orders کے ساتھ { "itemKey": "sword.gold" }. آرڈر شے کا موجودہ نام اور قیمت لیتا ہے، شروع ہوتا ہے۔ pending، اور 15 کے بعد ختم ہو جاتی ہے۔ منٹ ایک کھلاڑی کے پاس زیادہ سے زیادہ 20 آرڈرز انتظار کر سکتے ہیں (429, too_many_pending_orders).
  2. کھلاڑی StarHermit پر تصدیق کرتا ہے۔، آپ کے کھیل کے اندر کبھی نہیں. StarHermit کلائنٹ دکھاتا ہے۔ آئٹم، قیمت اور آپ کا گیم، اور پوسٹس /me/plucks/orders/{id}/confirm. اس راستے کی ضرورت ہے۔ اکاؤنٹ OAuth فراہم کنندہ کے ساتھ سائن ان ہے، جو آپ کے گیم میں کبھی نہیں ہے۔
  3. آپ اسے پہنچا دیں۔ رائے شماری GET /api/v1/games/{slug}/plucks/orders/{id} آپ کے کلائنٹ سے لے کر status ہے paid (یا cancelled، یا ماضی expiresAt)۔ ایک کنٹینر پسدید اس کے بجائے پڑھ سکتا ہے۔ GET /api/v1/games/{slug}/server/plucks/orders?since=<last completedAt>.

پلیٹ فارم فروخت کو ریکارڈ کرتا ہے۔ آئٹم کو لاگو کرنا آپ کے کھیل کا کام ہے۔ کی طرف سے ترسیل idempotent بنائیں آرڈر آئی ڈی

POST /api/v1/games/{slug}/plucks/orders
Authorization: Bearer <launch-token>
Content-Type: application/json

{ "itemKey": "sword.gold" }

{ "id": "2b0e…", "gameId": "c115…", "itemKey": "sword.gold", "itemName": "Golden Sword",
  "price": 100, "status": "pending", "expiresAt": "2026-10-28T14:15:00Z" }

آئٹم کیز 1–64 حروف کی ہیں۔ a-z 0-9 . _ -; نام 1-80 حروف ہیں؛ قیمتیں ہیں 1–1,000,000,000 PLK۔ ایک غیر فعال یا حذف شدہ شے کا آرڈر نہیں دیا جا سکتا، اور پہلے سے کیے گئے آرڈرز کو برقرار رکھا جاتا ہے۔ ان کا سنیپ شاٹ.

غلطیاں

حیثیت code مطلب
402 insufficient_plucks کھلاڑی کا بیلنس قیمت سے نیچے ہے۔
402 purchase_required ایک قیمتی گیم کے لیے لانچ ٹوکن جو کھلاڑی نے نہیں خریدا ہے۔
409 price_changed expectedPrice اب قیمت نہیں ہے
409 order_cancelled ایک آرڈر کی تصدیق کرتے ہوئے کھلاڑی نے منسوخ کر دیا۔
410 order_expired کے بعد تصدیق کرنا expiresAt
429 too_many_pending_orders بہت سارے آرڈرز تصدیق کے منتظر ہیں۔

ان کے اپنے کھیل سے خریدنے والے مالک کو مل جاتا ہے۔ 409.

آپ کی آمدنی

GET /api/v1/me/github-games/{id}/analytics/sales اور …/analytics/monetization رپورٹ یونٹس، مجموعی، پلیٹ فارم کا کمیشن اور آپ کا نیٹ فی دن، کھلاڑیوں کی ادائیگی، تبدیلی اور فی آئٹم کل وہ صرف کل کی اطلاع دیتے ہیں اور خریدار کا نام نہیں لیتے ہیں۔ پر آپ کی اپنی تاریخ /me/plucks/transactions ہر فروخت کی فہرست۔
