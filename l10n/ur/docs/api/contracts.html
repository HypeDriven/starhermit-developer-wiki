REST اور WebSocket معاہدے

یہ ڈاؤن لوڈ کے قابل معاہدے حوالہ جاتی صفحات کی تکمیل کرتے ہیں۔ آپریشنز کا معائنہ کرنے کے لیے ان کا استعمال کریں، مثال کے پے لوڈز کی توثیق کریں، یا REST درخواستوں کو OpenAPI کے موافق کلائنٹ میں درآمد کریں۔

فائل کوریج
OpenAPI REST معاہدہ عوامی REST طریقے، راستے، پیرامیٹرز، JSON درخواست کے ماڈل، کامیابی کے جوابات، اور اسنادی خاندان؛ محفوظ جنریشن آپریشنز کو غیر دستیاب کے طور پر نشان زد کیا گیا ہے۔
WebSocket JSON اسکیمے۔ پروٹوکول اور سمت کے لحاظ سے معروف ٹیکسٹ فریم؛ ایپلیکیشن کی ملکیت والا گیم پلے/سگنلنگ ڈیٹا کھلا رہتا ہے۔
بائنری لے آؤٹ ریئل ٹائم بھیجنے والے کا سابقہ، آواز کا سابقہ، غیر فریم شدہ ریلے، کنٹینر اسٹریم ہیڈر، اور ٹکڑے اپ لوڈ کریں

REST معاہدے

REST فائل استعمال کرتی ہے۔ OpenAPI 3.0.3 اور عوامی API کی اصل۔ ہر آپریشن اپنے حوالہ کے صفحے سے لنک کرتا ہے، جس میں مکمل اجازت، توثیق، حدود، اور غلطی کے اصول ہوتے ہیں۔ x-credentials قبول شدہ اسناد کے خاندانوں کی شناخت کرتا ہے؛ یہ ملکیت یا رکنیت کے چیک کو تبدیل نہیں کرتا ہے۔ x-required-policies نامزد اجازتوں کی وضاحت کرتا ہے جہاں API ان کا اطلاق کرتا ہے۔

جوابات میں اضافی فیلڈز شامل ہو سکتے ہیں۔ گیم کے لیے مخصوص JSON، میٹا ڈیٹا، تشخیص، اور اپ لوڈ نتائج کھلی شکلیں استعمال کرتے ہیں جہاں گیم یا اینڈ پوائنٹ کا حوالہ ان کے مواد کی وضاحت کرتا ہے۔ کامیابی اسکیماس کوئی وعدہ نہیں ہے کہ ہر کال کرنے والا مجاز ہے۔ اختتامی نقطہ کی خرابیاں JSON، سادہ متن، ہو سکتی ہیں خالی جوابات، یا توثیق کے مسئلے کی تفصیلات؛ استعمال کریں دفاعی ردعمل کی تجزیہ.

ریزروڈ جنریشن آپریشنز کو ورکنگ سروس کے طور پر مت سمجھیں۔ ان کا معاہدہ بیان کرتا ہے۔ موجودہ 503 overloaded جواب، مستقبل کی درخواست کے شعبوں یا نسل کا رویہ نہیں۔

WebSocket معاہدے

a کا انتخاب کریں۔ $defs آپ کے ساکٹ کے پروٹوکول اور سمت کے لیے اسکیما۔ مثال کے طور پر، ایک کلائنٹ کی توثیق کریں کے خلاف تحریک کا فریم GameRealtimeInput، عام پائیدار کے بجائے GameCommand:

{ "type": "cmd", "data": { "type": "input", "realtime": true, "seq": 1, "x": 0.5 } }

realtime تعلق رکھتا ہے اندر data. اس کے بعد گیم پلے فیلڈز آپ کے گیم کا معاہدہ ہیں۔ استعمال کریں a JSON اسکیما 2020-12 مکمل اسکیما دستاویز کے ساتھ validator تاکہ مقامی حوالہ جات حل ہو جائیں۔ روٹ دستاویز میں تعریفیں شامل ہیں۔ فریم کی توثیق کرنے کے لیے تعریف کا انتخاب ضروری ہے۔

پروٹوکول کلائنٹ کے متن کی تعریف سرور ٹیکسٹ کی تعریف بائنری ڈیٹا
گیمز GameCommand / GameRealtimeInput GameServerFrame صرف ٹیکسٹ گیم پلے
ریئل ٹائم کمرے RealtimeClientControl RealtimeServerFrame ہوسٹ روٹڈ گیم ڈیٹا، وصول کرنے پر 16 بائٹ بھیجنے والا حصہ لینے والا سابقہ
آواز VoiceClientControl VoiceServerEvent آڈیو، وصول کرنے پر 16 بائٹ بھیجنے والا صارف کا سابقہ
گپ شپ کوئی کلائنٹ کا حکم نہیں؛ REST استعمال کریں۔ ChatServerPush کوئی نہیں۔
پیر ریلے کوئی JSON فریمنگ نہیں ہے۔ کوئی JSON فریمنگ نہیں ہے۔ پے لوڈ غیر تبدیل شدہ؛ شناخت کا کوئی سابقہ ​​نہیں۔
گیم اپ لوڈ UploadClientControl UploadServerFrame آرکائیو کے ٹکڑے
کنٹینر کنٹرول ContainerControl سرور سے کوئی عام اعترافی لفافہ نہیں۔ گیم پلے علیحدہ کنٹینر استعمال کرتا ہے۔ /stream

مستقبل کے فریم کی قسموں کو وصول کو کریش کرنے کے بجائے آپ کے کلائنٹ کے نامعلوم فریم ہینڈلر تک پہنچنا چاہیے۔ لوپ JSON شکل کی توثیق گیم کے قواعد کی توثیق نہیں کرتی، رکنیت کی اجازت نہیں دیتی، یا شرح کو نافذ کرتی ہے۔ حدود حوالہ جات کے صفحات کردار اور سائز/شرح کی پابندیوں کی وضاحت کرتے ہیں۔

GUID بائٹ آرڈر

پہلے تین UUID گروپس .NET GUID بائٹ ہیڈر میں لٹل اینڈین ہیں۔ مثال کے طور پر:

UUID:  00112233-4455-6677-8899-aabbccddeeff
Bytes: 33 22 11 00 55 44 77 66 88 99 aa bb cc dd ee ff

16 بائٹ کے سابقہ ​​کے لیے ایک براؤزر ڈیکوڈر:

function guidFromDotNet(bytes) {
  if (bytes.length !== 16) throw new Error('Expected a 16-byte GUID');
  const hex = i => bytes[i].toString(16).padStart(2, '0');
  return `${hex(3)}${hex(2)}${hex(1)}${hex(0)}-${hex(5)}${hex(4)}-${hex(7)}${hex(6)}-` +
    `${hex(8)}${hex(9)}-${hex(10)}${hex(11)}${hex(12)}${hex(13)}${hex(14)}${hex(15)}`;
}

ریئل ٹائم سابقے شناخت کرتے ہیں۔ شرکاءجبکہ آواز کے سابقے شناخت کرتے ہیں۔ صارفین. ایک کنٹینر سٹریم میں ایک بائٹ کی قسم ہے جس کے بعد سیشن/صارف UUIDs ہے، لہذا اس کا JSON بائٹ سے شروع ہوتا ہے 33. دی ریلے کوئی سابقہ شامل نہیں کرتا ہے۔ ہر ساکٹ کو ایک ہی بائنری لے آؤٹ کے طور پر پڑھنے سے پے لوڈز اور شناخت خراب ہو جاتی ہے۔

دیکھیں اسناد اور شناخت کنندگان, سیشن لائف سائیکل, اور ویب ساکٹ کی خرابیوں کا سراغ لگانا.
