سرگرمی

ایکٹیویٹی API لانچ سیشنز، پلے ٹائم، اور ایکٹیویٹی فیڈ کا احاطہ کرتی ہے — دونوں کیٹلاگ ٹائٹلز اور بیرونی (غیر کیٹلاگ) گیمز کے لیے۔ تمام راستوں کو JWT کی ضرورت ہوتی ہے جب تک کہ نوٹ نہ کیا جائے۔

بنیادی URL: https://api.starhermit.com. تمام راستے نیچے ہیں۔ /api/v1/....

کیٹلاگ لانچ سیشنز اور پلے ٹائم

طریقہ راستہ تصنیف تفصیل
پوسٹ /api/v1/activity/launches/{id}/end جے ڈبلیو ٹی کیٹلاگ لانچ سیشن ختم کریں (204)
حاصل کریں۔ /api/v1/activity/software/{softwareTitleId}/playtime جے ڈبلیو ٹی ٹائٹل کے لیے میرا کل پلے ٹائم
حاصل کریں۔ /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 جے ڈبلیو ٹی ٹائٹل کے لیے دوستوں کا پلے ٹائم

لانچ سیشن کی طرف سے شروع کر رہے ہیں POST /api/v1/software/{id}/launch (دیکھیں۔ catalog.md) اور یہاں ختم ہوا۔ پلے ٹائم جواب:

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime واپسی FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

بیرونی لانچ اور پلے ٹائم

غیر کیٹلاگ گیمز کے لیے (منسلک بیرونی لائبریریاں — دیکھیں external-libraries.md):

طریقہ راستہ تصنیف تفصیل
پوسٹ /api/v1/activity/external-launches جے ڈبلیو ٹی غیر کیٹلاگ گیم کے لیے ایک سیشن شروع کریں۔
پوسٹ /api/v1/activity/external-launches/{id}/end جے ڈبلیو ٹی اس سیشن کو ختم کریں (204)
حاصل کریں۔ /api/v1/activity/external/playtime?provider=&externalId= جے ڈبلیو ٹی بیرونی کھیل کے لیے میرا کل پلے ٹائم
حاصل کریں۔ /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 جے ڈبلیو ٹی کسی بیرونی کھیل کے لیے دوستوں کا پلے ٹائم

POST /api/v1/activity/external-launches جسم (provider ≤ 64 حروف، externalSoftwareId ≤ 256 حروف، name اختیاری):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

جواب:

{
  "launchId": "…"
}

بیرونی پلے ٹائم جواب:

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

سرگرمی فیڈز

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/activity/game-feed?key=&limit=20 جے ڈبلیو ٹی ایک گیم کلید کے لیے دوستوں کے سیشنز اور درجہ بندی کے واقعات
حاصل کریں۔ /api/v1/activity/friends?since=&until=&limit= جے ڈبلیو ٹی دوستوں کی سرگرمی
حاصل کریں۔ /api/v1/activity/public?since=&until=&limit= گمنام عوامی سرگرمی
حاصل کریں۔ /api/v1/me/activity?since=&until=&limit= جے ڈبلیو ٹی میری اپنی سرگرمی

گیم فیڈ واپس آتا ہے۔ GameFeedItemDto[] ایک گیم کلید کے لیے (ایک کیٹلاگ گائیڈ یا "provider:externalId"، دیکھیں catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public، اور me/activity واپسی ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

سرگرمی type اقدار: "download", "launch", "external_launch".

/activity/friends پر سرگرمی کی قسم کے مطابق گیٹ کیا گیا ہے۔ مالک کی رازداری کی ترتیب: لانچوں کی پیروی کریں۔ recentLaunchActivity, ڈاؤن لوڈز کی پیروی recentDownloads. ہر ایک کو شامل کیا جاتا ہے جب سطح ہے FriendsOnly یا Public. ایک اکاؤنٹ جس نے کبھی منتخب نہیں کیا ہے وہ ڈیفالٹ ہو جاتا ہے (شروعات کے ساتھ اشتراک کیا جاتا ہے۔ دوست، ڈاؤن لوڈ نجی)۔ ایک ناقابل مطالعہ رازداری کی دستاویز کو مکمل طور پر نجی سمجھا جاتا ہے۔ دیکھیں profile.md.

دیکھیں API کنونشنز غلطی کی تجزیہ کے لیے۔

دیکھیں اسناد کی مطابقت اور مشین پڑھنے کے قابل معاہدے.
