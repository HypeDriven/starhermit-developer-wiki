بیرونی لائبریریاں

صارف کی Steam، Epic، یا GOG لائبریری کو لنک کرنا تاکہ ان کے بیرونی گیمز کو فہرست، لانچ اور ٹریک کیا جا سکے۔ تمام راستوں کو JWT کی ضرورت ہوتی ہے۔

بنیادی URL: https://api.starhermit.com. تمام راستے نیچے ہیں۔ /api/v1/....

لنک کرنا اور ان لنک کرنا

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/me/external-libraries جے ڈبلیو ٹی میرے منسلک فراہم کنندگان کی فہرست بنائیں
پوسٹ /api/v1/me/external-libraries/link جے ڈبلیو ٹی ایک فراہم کنندہ کو لنک کریں اور اس کے عنوانات کو ہم آہنگ کریں۔
حذف کریں۔ /api/v1/me/external-libraries/{provider} جے ڈبلیو ٹی ایک لنک اور اس کی ملکیت کو ہٹا دیں۔

منسلک لائبریریاں:

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

لنک باڈی:

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

واپسی 204۔ لنکنگ فراہم کنندہ کے عنوانات کو بھی ہم آہنگ کرتی ہے۔ لائبریری کی مطابقت پذیری فی الحال کے لیے ڈیمو عنوانات واپس کرتی ہے۔ steam/epic/gog جبکہ حقیقی فراہم کنندہ کے انضمام کو حتمی شکل دی گئی ہے۔

بیرونی سافٹ ویئر اور لانچنگ کی ملکیت

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/me/external-software?provider=&page=&pageSize= جے ڈبلیو ٹی میرے بیرونی عنوانات کی صفحہ بندی کی فہرست
پوسٹ /api/v1/external-software/{ownershipId}/launch جے ڈبلیو ٹی لانچ URI حاصل کریں اور ایک بیرونی لانچ ریکارڈ کریں۔

بیرونی سافٹ ویئر کی فہرست:

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

جواب شروع کریں:

{
  "launchUri": "steam://run/…"
}

فراہم کنندہ کے ذریعہ URI فارمیٹس شروع کریں: steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. لانچنگ ایک بیرونی لانچ کی سرگرمی کو ریکارڈ کرتی ہے — دیکھیں activity.md. بیرونی گیمز یکساں گیم کلید استعمال کرتے ہیں۔ "provider:externalId" ریٹنگز اور فیڈز کے لیے — دیکھیں catalog.md.

دیکھیں API کنونشنز غلطی کی تجزیہ کے لیے۔

دیکھیں اسناد کی مطابقت اور مشین پڑھنے کے قابل معاہدے.
