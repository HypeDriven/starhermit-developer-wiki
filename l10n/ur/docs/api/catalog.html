سافٹ ویئر کیٹلاگ

سافٹ ویئر کیٹلاگ براؤزنگ اور دعوی کرنے والے عنوانات، فہرست سازی، ڈاؤن لوڈ، کلاؤڈ سیو، خواہش کی فہرست اور درجہ بندی کا احاطہ کرتا ہے۔ ریڈز گمنام ہیں؛ لکھنے کے لیے JWT کی ضرورت ہوتی ہے۔

بنیادی URL: https://api.starhermit.com. تمام راستے نیچے ہیں۔ /api/v1/....

براؤزنگ اور عنوانات کا دعوی کرنا

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/software گمنام تلاش کریں اور کیٹلاگ کو صفحہ بنائیں
حاصل کریں۔ /api/v1/software/{id} گمنام ایک عنوان حاصل کریں، یا 404
حاصل کریں۔ /api/v1/software/{id}/builds?page=&pageSize= گمنام عنوان کے لیے تعمیرات کی صفحہ بندی کی فہرست
پوسٹ /api/v1/software/{id}/claim جے ڈبلیو ٹی استحقاق دیتے ہوئے ایک مفت عنوان کا خود دعوی کریں۔
پوسٹ /api/v1/software/{id}/launch جے ڈبلیو ٹی لانچ سیشن شروع کریں (استحقاق کی ضرورت ہے)

GET /api/v1/software استفسار کے پیرامیٹرز کو قبول کرتا ہے۔ q (مکمل متن) category, tag, publisherId, platform, releaseStatus, sort, page، اور pageSize. درست sort اقدار: name, name_desc, created, created_desc, updated, updated_desc. یہ لوٹاتا ہے a PagedResult:

{
  "items": [
    {
      "id": "…",
      "name": "…",
      "description": "…",
      "publisherId": "…",
      "category": "…",
      "platform": "…",
      "releaseStatus": "…",
      "tags": ["…"],
      "priceCents": 0,
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

GET /api/v1/software/{id}/builds واپسی a PagedResult کی SoftwareBuild:

{
  "items": [
    {
      "id": "…",
      "titleId": "…",
      "version": "…",
      "releaseDate": "…",
      "releaseNotes": "…",
      "metadata": "…",
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

POST /api/v1/software/{id}/claim صرف مفت عنوانات کے لیے کام کرتا ہے (priceCents == 0); یہ کال کرنے والے کو ایک استحقاق دیتا ہے اور 204 واپس کرتا ہے۔ ادا شدہ عنوانات کے لیے یہ 402 اس کے ساتھ واپس کرتا ہے:

{"error": "purchasing is not available yet"}

POST /api/v1/software/{id}/launch ایک استحقاق کی ضرورت ہے (بصورت دیگر 403) اور واپسی a LaunchSession:

{
  "launchId": "…",
  "startTime": "…"
}

یہ ایک لانچ کی سرگرمی کو ریکارڈ کرتا ہے، جو چھپا ہوتا ہے اگر صارف کی رازداری کی ترتیبات ایسا کہتی ہیں (دیکھیں profile.md)۔ کے ساتھ سیشن ختم کریں۔ POST /api/v1/activity/launches/{id}/end - دیکھیں activity.md. صارف کے استحقاق بذریعہ درج ہیں۔ GET /api/v1/me/entitlements (دیکھیں۔ profile.md).

ڈاؤن لوڈز

طریقہ راستہ تصنیف تفصیل
پوسٹ /api/v1/software/{id}/download جے ڈبلیو ٹی ایک دستخط شدہ ڈاؤن لوڈ یو آر ایل حاصل کریں (استحقاق کی ضرورت ہے)

ایک استحقاق درکار ہے (403 دوسری صورت میں)۔ واپسی:

{
  "downloadUrl": "…"
}

URL تازہ ترین تعمیر کے پہلے ڈاؤن لوڈ کے قابل اثاثہ کو نشانہ بناتا ہے۔ کال ڈاؤن لوڈ کی سرگرمی کو ریکارڈ کرتی ہے۔ کیٹلاگ بائنری تقسیم فی الحال ایک پیش نظارہ ہے۔ لوٹائے گئے یو آر ایل پیداوار کی ضمانت نہیں ہیں۔ ڈاؤن لوڈز دیکھیں خصوصیت کی دستیابی اس اشاعت کے بہاؤ پر انحصار کرنے سے پہلے۔

کلاؤڈ سیوز

فی گیم ایک سلاٹ، آخری لکھنے کی جیت۔ تمام راستوں کے لیے JWT کی ضرورت ہوتی ہے — ایک مکمل صارف ٹوکن، یا گیم کا اس گیم کے اپنے سلاٹ کے لیے ٹوکن لانچ کریں (نیچے)۔

10 MB کیپ (10,485,760 بائٹس) پر لاگو ہوتا ہے۔ ڈی کوڈ محفوظ کریں، درخواست نہیں۔ PUT لیتا ہے JSON میں بیس64-انکوڈ کو محفوظ کریں، لہذا جسم محفوظ سے تقریباً ایک تہائی بڑا ہے — تقریباً 14 ایم بی کیپ - اور API اسے قبول کرتا ہے۔

حد (فی اکاؤنٹ) طے شدہ انکار
ایک محفوظ، ضابطہ کشائی 10 ایم بی 413 cloud_save_too_large
ایک بچت کے ساتھ کھیل 200 409 cloud_save_slots_exhausted (ایک نئی گیم کے لیے بچت)
سب مل کر بچاتے ہیں۔ 1 جی بی 507 cloud_save_quota_exceededکے ساتھ used
اپ لوڈز 30 فی منٹ 429کے ساتھ Retry-After

ہر انکار طاقت میں موجود نمبر کو بطور نام دیتا ہے۔ limit. کل حساب سے ماپا جاتا ہے۔ دوسرے محفوظ کرتا ہے، لہذا سلاٹ کو ہمیشہ کسی بڑی چیز کے ساتھ اوور رائٹ کیا جا سکتا ہے۔ آپریٹرز میں سے کسی کو بھی تبدیل کر سکتے ہیں۔ یہ ایک اکاؤنٹ کے لیے۔

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/me/cloud-saves/{gameKey}/info جے ڈبلیو ٹی میٹا ڈیٹا محفوظ کریں: { exists, sizeBytes, updatedAt? }
حاصل کریں۔ /api/v1/me/cloud-saves/{gameKey} جے ڈبلیو ٹی application/zip بائٹس، 404 اگر کوئی نہیں۔
ڈالو /api/v1/me/cloud-saves/{gameKey} جے ڈبلیو ٹی سیو اپ لوڈ کریں (ڈی کوڈ شدہ سیو ≤ 10 ایم بی، gameKey ≤ 300 حروف)

جسم ڈالیں:

{
  "dataBase64": "…"
}

جواب ڈالیں:

{
  "gameKey": "…",
  "sizeBytes": 0,
  "updatedAt": "…"
}

کھیل کے اندر سے بچت (لانچ ٹوکن)

اپنے لانچ ٹوکن کے ساتھ چلنے والا گیم کھلاڑی کی بچت کو پڑھ اور لکھ سکتا ہے۔ وہ کھیل. آپ کا گیم جہاں بھی چلتا ہے خود کو بچاتا ہے — ایک براؤزر، یا StarHermit ڈیسک ٹاپ ایپ، جو چلتی ہے۔ ایک براؤزر میں بھی گیمز کی میزبانی کرتا ہے - لہذا بچت ان کے درمیان کھلاڑی کی پیروی کرتی ہے۔

کلید ہے game:<gameId>، کہاں <gameId> آپ کے گیم کی آئی ڈی ہے — وہی قدر جو اس کی سلگ، اس کی <gameId>.starhermit.com ایڈریس، اور game_scope لانچ ٹوکن کا دعویٰ:

const key = `game:${gameScope}`;            // e.g. "game:3fa85f64-5717-4562-b3fc-2c963f66afa6"

// Load on startup — 404 means no save yet.
const res = await fetch(`/api/v1/me/cloud-saves/${key}`, { headers: { Authorization: `Bearer ${launchToken}` } });
if (res.status !== 404 && !res.ok) throw new Error(`Save load failed: ${res.status}`);
const save = res.status === 404 ? null : new Uint8Array(await res.arrayBuffer());
const etag = res.headers.get("ETag");
if (save && !etag) throw new Error("Save version unavailable; do not overwrite it.");
// Validate/decode your own save format before adopting it or enabling uploads.

// Save at checkpoints, not every frame.
const written = await fetch(`/api/v1/me/cloud-saves/${key}`, {
  method: "PUT",
  headers: {
    Authorization: `Bearer ${launchToken}`, "Content-Type": "application/json",
    ...(etag ? { "If-Match": etag } : { "If-None-Match": "*" }),
  },
  body: JSON.stringify({ dataBase64: base64(zipBytes) }), // Your ZIP encoder and bytes.
});
if (written.status === 412) throw new Error("Another device saved. Reload before writing again.");
if (!written.ok) throw new Error(`Save write failed: ${written.status}`);
const acknowledgement = await written.json(); // Retain acknowledgement.etag for your next write.
  • صرف وہی عین کلید۔ کوئی دوسری کلید — کسی اور گیم کی، اسٹور گیم کی، یا کوئی مختلف ہجے آپ کا (اپر کیس، ننگی آئی ڈی) — ہے۔ 403 لانچ ٹوکن کے لیے۔ اس میں شامل ہیں۔ github:<gameId>, علیحدہ سلاٹ جو ڈیسک ٹاپ ایپ استعمال کرتی ہے جب کوئی کھلاڑی آپ کے گیم کے لیے مقامی سیو فولڈر کو ہم آہنگ کرتا ہے۔ وہ مطابقت پذیری آپ کے گیم کے لکھے محفوظ کرنے کو کبھی بھی اوور رائٹ نہیں کرسکتی ہے۔
  • کوئی بھی فارمیٹ۔ پلیٹ فارم محفوظ کو کبھی نہیں کھولتا ہے۔ جو کچھ بھی آپ کا گیم واپس پڑھ سکتا ہے اسے اسٹور کریں (یہ ہے۔ کے طور پر خدمت کی application/zip قطع نظر)۔ 10 MB تک۔
  • غیر مشروط تحریریں آخری تحریر کی جیت ہیں۔بغیر تاریخ کے۔ پتہ لگانے کے لیے مشروط تحریریں استعمال کریں۔ دو ٹیبز/آلات ایک ساتھ محفوظ کر رہے ہیں۔ شروع پر لوڈ کریں اور پیش منظر کی چوکیوں پر محفوظ کریں۔ صفحہ سے باہر نکلیں۔ اپ لوڈز بہترین کوشش ہیں اور براؤزر کے جسم کے سائز کی حد ہوتی ہے۔ دیکھیں محفوظ بچانے کا نسخہ.
  • ہر محفوظ کا ایک ورژن ہوتا ہے۔ اس کا ETag ڈاؤن لوڈ پر ہے، آن /info (بھی etag) اور پر دی PUT جواب بطور واپس بھیجیں۔ If-Match اور لکھنا صرف اس صورت میں ہوتا ہے جب کسی نے بچایا نہ ہو۔ چونکہ؛ دوسری صورت میں 412 {"error":"precondition_failed","etag":"<current>"} آپ کو ورژن بتاتا ہے۔ لوڈ If-Match: * موجودہ بچت کی ضرورت ہے؛ If-None-Match: * صرف اس وقت لکھتا ہے جب کوئی نہ ہو۔ کسی ہیڈر کے ساتھ a PUT غیر مشروط ہے - آخری لکھنے کی جیت۔ اے GET کے ساتھ If-None-Match: <etag> جوابات 304 جب آپ کے پاس پہلے سے ہی تازہ ترین بچت ہے۔
  • ایک گیم جس کی میزبانی کی گئی فہرست نہیں ہے (آپریٹر کی طرف سے فراہم کردہ گیم) میں کوئی سلاٹ نہیں ہے۔

چھوٹی، بار بار تبدیل ہونے والی ترجیحات اس میں شامل ہیں۔ فی کھلاڑی کی ترتیبات اس کے بجائے وہ لانچ ٹوکن کے ساتھ بھی قابل رسائی ہیں اور جزوی اپ ڈیٹس کی حمایت کرتے ہیں۔

خواہش کی فہرست

تمام راستوں کو JWT کی ضرورت ہوتی ہے۔

طریقہ راستہ تصنیف تفصیل
حاصل کریں۔ /api/v1/me/wishlist جے ڈبلیو ٹی { titleIds: guid[] }
ڈالو /api/v1/me/wishlist/{titleId} جے ڈبلیو ٹی خواہش کی فہرست میں شامل کریں، 204 (بے حسی)
حذف کریں۔ /api/v1/me/wishlist/{titleId} جے ڈبلیو ٹی خواہش کی فہرست سے ہٹائیں، 204

ریٹنگز

تمام راستوں کو JWT کی ضرورت ہوتی ہے۔ یونیفارم گیم کلید ایک کیٹلاگ گائیڈ ہے، یا "provider:externalId" بیرونی کھیلوں کے لیے (دیکھیں۔ external-libraries.md).

طریقہ راستہ تصنیف تفصیل
ڈالو /api/v1/me/ratings جے ڈبلیو ٹی ایک گیم کے لیے میری درجہ بندی کو بڑھا دیں۔
پوسٹ /api/v1/ratings/query جے ڈبلیو ٹی بیچ کی بازیافت کی درجہ بندی کے خلاصے۔
حاصل کریں۔ /api/v1/ratings/reviews?key=&top= جے ڈبلیو ٹی کھیل کے لیے جائزے (top پہلے سے طے شدہ 10)

جسم ڈالیں:

{
  "gameKey": "…",
  "stars": 4,
  "review": "…"
}

stars 0-5 ہے؛ review اختیاری ہے. جواب ہے a RatingSummaryDto:

{
  "gameKey": "…",
  "average": 4.5,
  "count": 12,
  "myStars": 4
}

POST /api/v1/ratings/query جسم اور ردعمل:

{
  "keys": ["…", "…"]
}

واپسی RatingSummaryDto[]. GET /api/v1/ratings/reviews واپسی GameReviewDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "stars": 4,
    "review": "…",
    "timestamp": "…"
  }
]
