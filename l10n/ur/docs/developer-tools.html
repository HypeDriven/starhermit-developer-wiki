StarHermit ڈویلپر ٹولز

قابل اشاعت سکرپٹ گیم پیکجز بنائیں، انہیں StarHermit پر اپ لوڈ کریں، اور اپنے کوڈنگ اسسٹنٹ کو مقامی MCP کنکشن دیں۔ ان ٹولز کی ضرورت نہیں ہے۔ زنگ کی تنصیب یا انجن کا ذریعہ چیک آؤٹ۔ کھیل کا اپنا ہو سکتا ہے۔ انحصار بنائیں، جیسے Node.js.

اپنے کمپیوٹر کے لیے محفوظ شدہ دستاویزات نیچے دیے گئے جدول سے، یا یہاں سے ڈاؤن لوڈ کریں۔ https://engine.starhermit.com/engine/tools/latest.json (یہ ہر ایک کی فہرست دیتا ہے آرکائیو کا پتہ، سائز اور SHA-256)، اور اس کے SHA-256 کا موازنہ اس کے ساتھ چیکسم (<archive>.sha256)۔ اسے کھولیں اور اس کی ڈائرکٹری کو PATH پر رکھیں، یا نیچے دیے گئے کمانڈز میں ایگزیکیوٹیبل کا مکمل راستہ استعمال کریں۔ macOS ڈاؤن لوڈز ہیں۔ Apple Silicon کے لیے الگ سے فراہم کیا گیا (macos-aarch64) اور انٹیل (macos-x86_64)۔ وہ ایپل کے نوٹرائزڈ نہیں ہیں، اور کوئی ڈاؤن لوڈ نہیں ہے۔ مستند کوڈ یا ڈیولپر ID پر دستخط کیے گئے ہیں۔ ایپل سلیکون کی تعمیر ہے۔ کراس مرتب کردہ؛ مسائل کی اطلاع دیں.

https://engine.starhermit.com/engine/tools/latest.json ہمیشہ فہرست کرتا ہے تازہ ترین ٹولز: ہر ڈاؤن لوڈ کا پتہ، سائز، SHA-256 اور ورژن۔

ایک گیم چیک کریں اور پیک کریں۔

starhermit-tools --version
starhermit-tools check my-game
starhermit-tools package --web my-game --out upload --remote-out remote-objects

گیم ڈائرکٹری پر مشتمل ہے۔ starhermit.txt اور وہ فائلیں جن کی گیم کو ضرورت ہے۔ engine.version ایک شائع شدہ انجن کی رہائی کو پن کرتا ہے؛ ٹول اسے پڑھتا ہے۔ engine.starhermit.com سے ظاہر ہوتا ہے اور ایک ہیش پن لوڈر اور فائل لکھتا ہے۔ انڈیکس --engine-version X.Y.Z ایک مطابقت پذیر ریلیز کو واضح طور پر منتخب کرتا ہے۔ فائلوں کا اعلان engine.remote.files کو لکھا جاتا ہے۔ remote-objects; جب engine.remote.urls=platformشائع کرنے سے پہلے انہیں اپ لوڈ کیا جاتا ہے۔

check مینی فیسٹ، پیکیج پاتھز اور فائل اسٹرکچر کی توثیق کرتا ہے۔ یہ کرتا ہے اسکرپٹ پر عمل نہ کریں۔ اس سے پہلے براؤزر میں پیکڈ ویب گیم کی جانچ کریں۔ اشاعت ڈویلپرز اضافی طور پر مماثل مقامی کو ڈاؤن لوڈ کرسکتے ہیں۔ انجن کی ریلیز سے رن ٹائم (ونڈوز، لینکس، اور انجن 1.26.2 سے macOS 11 یا بعد میں Intel اور Apple Silicon) اور استعمال کریں۔ starhermit check my-game بغیر سر کے ایگزیکیوشن چیک کے لیے۔ میک او ایس رن ٹائمز ایڈہاک پر دستخط شدہ ہیں اور نوٹریائزڈ نہیں ہیں، اور وہ ابھی تک نہیں ہوئے ہیں۔ اصلی ایپل ہارڈ ویئر پر تجربہ کیا گیا۔ براؤزر میں ڈاؤن لوڈ کردہ ٹربال ہے۔ quarantined : دوڑنا xattr -d com.apple.quarantine starhermit یا اجازت دیں سسٹم کی ترتیبات میں۔

شائع کریں۔

عوامی کلید آن بورڈنگ کے بعد، اپنی رجسٹرڈ تعیناتی کلید استعمال کریں۔ اور ڈویلپر ویکی میں CI/CD گائیڈز۔ سیٹ STARHERMIT_PUBLIC_KEY اور STARHERMIT_PRIVATE_KEY آپ کے شیل یا آپ کے CI خفیہ اسٹور میں۔ متبادل طور پر، سیٹ STARHERMIT_ACCESS_TOKEN اکاؤنٹ تک رسائی کے ٹوکن تک۔ یہ مت ڈالو گیم میں اقدار، انہیں کمٹ کریں، یا انہیں MCP کنفیگریشن میں شامل کریں۔

starhermit-tools publish --game-id YOUR-GAME-ID --upload upload --remote-out remote-objects

یہ گیم کی تعینات کردہ فائلوں کی جگہ لے لیتا ہے۔ --mode merge ایک موجودہ پیچ اس کے بجائے اپ لوڈ کریں. ایک نیا گیم بنانے کے لیے، تبدیل کریں۔ --game-id YOUR-GAME-ID کے ساتھ --new. --socket اپ لوڈ WebSocket کو منتخب کرتا ہے؛ بڑے اپ لوڈز اسے منتخب کرتے ہیں۔ خود بخود --display-name اور --description اپ لوڈ کردہ کو اوور رائیڈ کریں۔ مینی فیسٹ کا نام اور تفصیل۔ ناشر میزبان یو آر ایل کی رپورٹ کرتا ہے۔ اور اپ لوڈ کے ساتھ شائع شدہ رپورٹ لکھتا ہے۔

اکاؤنٹ گیم کا مالک ہونا چاہیے۔ ایک سند کی غلطی یا انکار کی حد ایک ہے۔ غلطی کسی اور کی اسناد کے ساتھ اس کے ارد گرد کام نہ کریں. ریموٹ گیم کے پاس پہلے سے موجود اشیاء کو دوبارہ استعمال کیا جاتا ہے۔ رکاوٹ آبجیکٹ اپ لوڈز دوبارہ شروع کریں ایک نیا گیم تخلیق کیا جا سکتا ہے اس سے پہلے کہ بعد میں کوئی آبجیکٹ اپ لوڈ ہو جائے؛ دوسرا بنانے کے بجائے دوبارہ کوشش کرنے کے لیے اس کی اطلاع شدہ گیم ID کا استعمال کریں۔

STARHERMIT_API_BASE ایک اور HTTPS تعیناتی کا انتخاب کرتا ہے۔ STARHERMIT_CA_FILE ایک PEM ٹرسٹ بنڈل کا انتخاب کرتا ہے، مثال کے طور پر ایک ترقی CA; TLS تصدیق ہمیشہ فعال ہوتی ہے۔ عام استعمال کو متغیر کی ضرورت نہیں ہے۔

کوڈنگ اسسٹنٹ کو MCP کے ساتھ جوڑیں۔

absolute کا استعمال کرتے ہوئے اپنے اسسٹنٹ کی کنفیگریشن میں ایک stdio MCP سرور شامل کریں۔ آپ کے کمپیوٹر کے لیے موزوں راستے:

{
  "mcpServers": {
    "starhermit": {
      "command": "/absolute/path/to/starhermit-tools",
      "args": ["mcp", "--package", "/absolute/path/to/my-game"]
    }
  }
}

سرور پیش کرتا ہے۔ check_package, package_web، اور package_native. اگر گیم میں Node.js اسکرپٹ ہے تو شامل کریں۔ --build-script اور اس کے بے نقاب کرنے کے لئے MCP دلائل کا مطلق راستہ a build ٹول یہ چلتا ہے۔ وہ ترتیب شدہ اسکرپٹ؛ یہ MCP سے صوابدیدی احکامات کو قبول نہیں کرتا ہے۔ package_web اختیاری لیتا ہے outDir, remoteOut، اور engineVersion; رشتہ دار آؤٹ پٹ پاتھ گیم ڈائرکٹری سے متعلق ہیں۔ پہلے سے طے شدہ طور پر لکھتا ہے starhermit-build/upload اور starhermit-build/remote کے سوا گیم ڈائرکٹری. package_native کے لیے گیم کی مقامی فائل انڈیکس لکھتا ہے۔ ایک معاون StarHermit کلائنٹ کے ذریعے انسٹالیشن، جو انجن کو انسٹال کرتا ہے۔ پلیئر کے پلیٹ فارم کے لیے رن ٹائم (macOS شامل ہے، انجن 1.26.2 سے)۔ کوئی بھی ٹول کچھ بھی شائع نہیں کرتا ہے۔

مقامی رن ٹائم انسٹال ہونے کے ساتھ، شامل کریں۔ --runtime اور اس کے فعال کرنے کے لیے MCP آرگیومینٹس کا مطلق قابل عمل راستہ run_checks. وہ ٹول گیم کے کوڈ کو ترتیب شدہ رن ٹائم میں چلاتا ہے۔ اشاعت صرف ایک واضح CLI کمانڈ کے طور پر دستیاب ہے اور یہ کبھی بھی MCP ٹول نہیں ہے۔
