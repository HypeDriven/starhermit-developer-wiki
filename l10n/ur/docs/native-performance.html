اسکرپٹ گیمز کے لیے مقامی کارکردگی

ایک StarHermit انجن گیم ایک ہی پیکیج کو براؤزرز میں اور مقامی طور پر چلاتا ہے۔ دونوں آپ کا کوڈ بہت چلاتے ہیں۔ مختلف طریقے سے، اس لیے منتخب کریں کہ بھاری کام کہاں رہتا ہے اس سے پہلے کہ آپ اسے پورٹ کریں یا لکھیں۔ یہ صفحہ اسکرپٹ کا احاطہ کرتا ہے۔ رفتار، WebAssembly، GPU کے پابند مناظر، کارکنان اور پیمائش۔ اعداد و شمار انجن کی پیمائش سے ہیں۔ اکتوبر 2026، انجن 1.26.1 کے مطابق۔

آپ کا کوڈ کیسے چلتا ہے۔

براؤزرز میں مقامی طور پر
کھیل جاوا اسکرپٹ براؤزر کا V8، پوری رفتار انجن کا اپنا ترجمان، کوئی JIT نہیں (ڈیزائن کے لحاظ سے، سیکورٹی کے لیے)
WebAssembly، مرکزی دائرہ براؤزر کی ویب اسمبلی انجن 1.26.1 سے پلیٹ فارم سے مرتب کردہ مقامی کوڈ (تفصیلات); دوسری صورت میں انجن کا ترجمان (میزبان API 1.25 اور بعد میں)
ویب اسمبلی میں starhermit:script کارکنان انجن کا ترجمان، تھوڑا سا درست نتائج کے لیے پلیٹ فارم سے مرتب کردہ مقامی کوڈ، جیسا کہ مرکزی دائرے میں ہے۔
  • مقامی طور پر، اصلی گیم JavaScript کے بارے میں ہے۔ V8 سے 15–25× سست. مائیکرو بینچ مارکس تجویز کر سکتے ہیں۔ تقریبا 8 ×. ان پر بھروسہ نہ کریں۔
  • مقامی ویب اسمبلی جس پر پلیٹ فارم نے مرتب کیا ہے۔ تقریبا V8 رفتار: تقریباً 7× تیز انجن کے سمولیشن بینچ مارک پر مترجم کے مقابلے میں، تقریباً 1.4× V8 کا وقت۔ تشریح کی گئی WebAssembly V8 سے تقریباً 8–18× سست ہے۔
  • starhermit check جاوا اسکرپٹ کو بالکل اسی طرح چلاتا ہے جیسا کہ ونڈو والا گیم کرتا ہے۔ ایک کے ساتھ بینچ مارک --release صرف انجن کی تعمیر.

مرتب کردہ WebAssembly

انجن 1.26.1 سے، جب آپ ایک گیم شائع کرتے ہیں۔ .wasm ماڈیولز، پلیٹ فارم ہر ایک کو مرتب کرتا ہے۔ ماڈیول وقت سے پہلے ایک سینڈ باکسڈ بلڈ میں اور نتیجہ پر دستخط کرتا ہے۔ مقامی رن ٹائم اسے ڈاؤن لوڈ کرتا ہے، دستخط کی تصدیق کرتا ہے، اسے کیش کرتا ہے اور اسے مقامی کوڈ کے طور پر چلاتا ہے۔ آپ کو گیم تبدیل کرنے کی ضرورت نہیں ہے۔ صرف اسے شائع کریں.

  • کہاں: Windows x86-64، Linux x86-64 اور Intel macOS، CPUs پر x86-64-v2 یا جدید تر (SSE4.2 اور POPCNT)۔ Apple Silicon Macs اور پرانے CPUs اب بھی تشریح کرتے ہیں، اور اسی طرح ماڈیول بھی کرتے ہیں۔ SIMD استعمال کریں۔
  • جب: مرتب شدہ کوڈ کے ڈاؤن لوڈ ہونے سے پہلے بنائی گئی ایک مثال تشریح کرتی رہتی ہے۔ بعد میں مثالیں مرتب کی جاتی ہیں، بشمول اگلی لانچ، جو اسے ڈسک کیشے سے لوڈ کرتی ہے۔
  • ایک جیسے نتائج: مرتب کردہ کوڈ انٹرپریٹر بٹ فار بٹ سے میل کھاتا ہے، بشمول ایندھن اور ٹریپس۔
  • چیک کریں اور غیر فعال کریں: کے ساتھ --dev، لاگ ہر ماڈیول کے لیے ظاہر کرتا ہے کہ آیا یہ مرتب ہوا یا تشریح، اور کیوں. STARHERMIT_WASM_AOT=0 تالیف کو بند کر دیتا ہے۔
  • براؤزر غیر تبدیل شدہ ہیں: مرکزی دائرہ براؤزر کی WebAssembly استعمال کرتا ہے، اور کارکن استعمال کرتے ہیں۔ انجن کا ترجمان

بھاری فی فریم کام

سمولیشن، میشنگ، پاتھ فائنڈنگ اور انٹیٹی بلڈز معمول کے گرم مقامات ہیں۔

  1. ہاٹ کوڈ کو Rust یا دوسری WASM زبان میں لکھیں۔ اور اسے بطور WebAssembly چلائیں، مثالی طور پر a میں starhermit:script کارکن ایک بار گیم شائع ہونے کے بعد، یہ مقامی طور پر V8 کی رفتار سے چلتا ہے، جبکہ سادہ جاوا اسکرپٹ تقریباً 15–25× سست رہتا ہے۔
  2. کے ساتھ ایک راستہ منتخب کریں۔ runtime() سے starhermit:engine (میزبان API 1.26)۔ "web" V8 کا مطلب ہے، تو جاوا اسکرپٹ وہاں ٹھیک ہے۔ "native" اس کا مطلب ہے کہ آپ کو WASM راستے کو ترجیح دینی چاہیے۔ کارکن ہمیشہ لیتے ہیں۔ مقامی راستہ ہے اور درآمد نہیں کر سکتا starhermit:engine.
  3. گیم منطق، UI اور آرکیسٹریشن کے لیے سادہ JavaScript رکھیں۔ فریموں میں نایاب بھاری کام پھیلائیں۔
  4. رفتار کے لیے JavaScript یا TypeScript کو WebAssembly میں مرتب نہ کریں۔ نتیجہ اب بھی ایک کی ضرورت ہے جاوا اسکرپٹ آبجیکٹ ماڈل، لہذا اس سے کچھ حاصل نہیں ہوتا ہے۔

بہت سے ملتے جلتے اداروں کے لیے، starhermit:world دانا مقامی طور پر بھی چلائیں.

GPU سے منسلک مناظر

مقامی طور پر، GPU عام طور پر اسکرپٹ ٹائم کے کنٹرول میں ہونے کے بعد ہی حد بن جاتا ہے۔

  • استعمال کریں۔ InstancedMesh.setLevels([...]) کم پولی لیولز اور قرعہ اندازی کے فاصلے کے ساتھ، اور تین کے LOD (میزبان API 1.26)۔
  • موڑ castShadow چھوٹے یا دور کے سہارے کے لیے بند۔
  • کے ساتھ شیڈو جھرنوں کو محدود کریں۔ shadow.cascades = { count, maxDistance }، انجن کی توسیع۔
  • سیٹ STARHERMIT_GPU_PASS_TIMES=1 ہر پاس کے لیے GPU ٹائم پرنٹ کرنے کے لیے۔

ورکرز

  • میزبان API 1.27 سے پہلے، ہر اس کارکن کا حوالہ رکھیں جسے آپ استعمال کرتے ہیں، کیونکہ کوڑا اٹھانا اسے ختم کرتا ہے. 1.27 سے، سامعین کے ساتھ ایک کارکن اس وقت تک رہتا ہے۔ terminate().
  • کارکن پیکج فائلوں کو پڑھ سکتے ہیں (files) میزبان API 1.26 سے۔
  • کارکن میزبان API 1.25 سے بائنری اور قابل منتقلی پیغامات بھیج سکتے ہیں۔

پیمائش کرنا

  • ایک ہی تعمیر کا استعمال کرتے ہوئے مقامی اور ویب کا موازنہ کریں۔
  • انجن کے فریم کے اعدادوشمار اسکرپٹ ٹائم کو فریم ٹائم سے الگ رپورٹ کرتے ہیں۔ اسکرپٹ بینچ نمبرز ہیں۔ حوالہ دینے کے لیے موزوں ہے۔
