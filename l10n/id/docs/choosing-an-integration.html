Pilih integrasi

Mulailah dengan tempat game Anda berjalan dan siapa yang memvalidasi gameplay. Game browser yang dihosting tidak memerlukan a backend server untuk menggunakan proses masuk, penyimpanan cloud, pengaturan, kontrol, atau ruang waktu nyata.

Integrasi Otoritas gameplay Multipemain Kemajuan Skor dan prestasi
Hanya browser, pemutar tunggal yang berdiri sendiri Peramban pemain Tidak ada Simpan di memori dalam mode unsigned yang direkomendasikan Tidak ada platform yang menulis
Game browser yang dihosting dengan permainan akun Peramban pemain Kamar opsional yang dialihkan oleh tuan rumah Penyimpanan cloud untuk pemain yang masuk Tambahkan skrip atau wadah untuk menulis papan dan pencapaian milik game
Ruang real-time yang diarahkan ke host Klien pemain host Lobi, undangan, kode gabung, gabung cepat; input biner dan snapshot Penyimpanan cloud klien, atau sesi server terikat opsional Backend yang terikat dapat menulis; ia harus secara independen memvalidasi apa yang diberikannya
Naskah resmi Skrip permainan Anda Sesi perjodohan, undangan teman, latihan, atau pertandingan terikat ruangan Sesi dan status per pemain dikelola oleh skrip Anda Server menulis Elo, skor, dan pencapaian
Wadah resmi Server permainan Anda API sesi yang sama; ruang waktu nyata mendukung jaringan yang lebih besar Snapshot lengkap dan status per pemain Server menulis Elo, skor, dan pencapaian
Judul katalog, seperti executable asli Arsitektur klien/server pilihan Anda Gunakan API yang sama dengan akun atau token peluncuran Slot penyimpanan cloud dipilih oleh klien akun Papan katalog dan pencapaian memiliki API penerbit dan klaim klien yang terpisah

Tiga titik awal yang umum

Game browser pemain tunggal: mengikuti mulai cepat browser. Menawarkan Masuk dengan StarHermit untuk kemajuan akun dan Mainkan pemain tunggal (kemajuan tidak disimpan) untuk segera diputar. Mulai tanpa backend; tambahkan satu ketika Anda membutuhkan kompetitif yang tervalidasi hasil. Pengaturan dan penyimpanan cloud tidak memerlukan a server= garis.

Multiplayer kasual dengan teman: menggunakan ruangan waktu nyata. Tuan rumah menjalankan simulasi, tamu mengirimkan masukan, dan tuan rumah menyiarkan snapshot. Game Anda menerapkan AI dan host migrasi. Platform ini menyediakan kursi, identitas, dan perutean. Kepercayaan pada tuan rumah adalah bagian dari model ini.

Multiplayer berperingkat atau persisten: menggunakan sebuah naskah atau sebuah wadah, dengan kamar jika Anda membutuhkan lobi. Validasi gameplay sebelumnya menghadiahkan apa pun. Skrip meminta tick rate dalam batas atas yang didukung (30 Hz secara default); container menjalankan loop simulasinya sendiri. Penjodohan langsung kontainer saat ini memiliki implisit Antrean 1v1, tetapi ruangan dapat membuat sesi penampung N-pemain.

Hosting dan penerbitan

Bangunan Anda Publikasikan melalui Baca selanjutnya
Folder yang dapat didistribusikan Unggah folder; rilis berikutnya menggunakan unggahan bundel Tampak, unggah API
Repositori GitHub publik Daftarkan repositori, buktikan kepemilikan, terapkan versi yang dipilih permainan GitHub
Gambar kontainer Daftarkan/unggah game, lalu nyatakan gambar registri yang disematkan atau dorong server/image.tar Protokol kontainer, unggahan CI
Klien game eksternal/asli Panggil API publik secara langsung; menggunakan kredensial pemain Orientasi kunci publik, SDK Persatuan
Katalog dapat dieksekusi Judul penerbit/alur kerja pembuatan; penerbitan biner memerlukan hibah Penerbit, ketersediaan saat ini

UUID game yang dihosting adalah slug dan subdomain API-nya. Nama tampilan dan nama repositori bukan API pengidentifikasi. Melihat kredensial dan pengidentifikasi sebelum permintaan pengkabelan.

Data Toko Penulis
Lari pemain tunggal yang tidak terlacak Status permainan dalam memori Permainan lokal
Kemajuan proses masuk milik klien game:<gameId> slot penyimpanan cloud Klien permainan pemain
Volume, grafik, aksesibilitas, preferensi Pengaturan permainan per pemain Klien permainan pemain
Penggantian keyboard Mengontrol API, setelah deklarasi manifes Klien permainan pemain
Statistik pertandingan/negara dunia dan pemain yang divalidasi Pengembalian skrip atau snapshot/hasil kontainer Backend game resmi

Penyimpanan cloud berisi satu dokumen buram per slot, bukan riwayat kecocokan. Tayangan ulang berisi status sesi selesai yang dipilih backend Anda untuk dipertahankan, bukan video atau masukan yang direkam secara otomatis aliran. Melihat menabung dengan aman Dan siklus hidup sesi.
