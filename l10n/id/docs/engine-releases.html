Rilis mesin StarHermit

Mesin StarHermit — runtime yang diputar permainan skrip — adalah diterbitkan di wiki ini sebagai rilis berversi dan tidak dapat diubah di bawah wiki.starhermit.com/engine/. Game menyematkan satu rilis persis dengan engine.version di mereka starhermit.txt; halaman game memuat runtime web rilis dari asal mesin di browser, klien Windows StarHermit menginstal rilis asli runtime dan memainkan game di dalamnya, dan pengembang mengunduh runtime rilis dari sini untuk membangunnya.

Muat mesin dari engine.starhermit.com

Belum dibuka untuk umum. engine.starhermit.com sedang dibuka untuk pemain di luar Jaringan StarHermit sendiri. Hingga catatan ini dihapus, terus muat mesin dari wiki ini; itu platform masih menulis ulang URL mesin permainan yang dihosting setelah wiki menghapus versinya.

Halaman game harus memuat mesinnya https://engine.starhermit.com/engine/X.Y.Z/, bukan dari wiki ini. Wiki hanya menyimpan rilis terbaru: dibatasi pada 1 GB, jadi versi terlama juga demikian dihapus ketika halaman baru diterbitkan, dan halaman yang memuat mesinnya dari wiki berhenti bekerja ketika versinya berjalan. engine.starhermit.com melayani setiap rilis daftar wiki, dalam waktu sekitar sepuluh menit publikasi, dan menyimpan setiap rilis untuk mendapatkan ruang. File-file di sana adalah byte demi byte yang diterbitkan wiki, jadi hash SRI yang sama menyematkannya.

  • Daftar rilis tetap di sini. versions.json hanya dibaca dari https://wiki.starhermit.com/engine/versions.json. Ia memutuskan rilis mana yang ada dan mana yang ada dicabut, dan engine.starhermit.com sengaja tidak menyajikannya.
  • Halaman pemuat yang Anda tulis sendiri impor https://engine.starhermit.com/engine/X.Y.Z/starhermit.js dan nama https://engine.starhermit.com/engine/X.Y.Z/manifest.json di dalam #starhermit-config, dengan sama integrity nilai sebagai URL wiki.
  • Permainan yang dikemas: starhermit package --web menulis pemuat ini dari alat pengembang 1.25.1 kapan bertanya dengan --loader-base https://engine.starhermit.com/engine/ (atau STARHERMIT_WEB_LOADER_BASE). Itu masih membaca daftar dari wiki, dan jika rilisnya tidak aktif engine.starhermit.com namun, itu menulis URL wiki dan memperingatkan Anda untuk mengemas lagi. Defaultnya menjadi arsip nanti rilis. Paket tanpa opsi membawa URL wiki, dan platform menulis ulang dua game yang dihosting URL mesin ke engine.starhermit.com ketika wiki telah menghapus versinya. Permainan diselenggarakan di tempat lain tidak ada penulisan ulang, jadi kemas ulang dengan alat yang lebih baru.
  • Rilis yang dicabut tidak disimpan. Pelepasan yang ditarik karena tidak aman tidak diberikan dari kedua negara asal. Sematkan yang lebih baru.

Alat pengembang

Itu alat pengembang mandiri menyediakan otomatis penerbitan dan pengembangan permainan skrip MCP di macOS (Apple Silicon dan Intel), Linux dan Windows. Tidak diperlukan instalasi Rust atau akses repositori pribadi. Rilis alat tidak bergantung pada runtime game yang disematkan game.

Versi

Sebuah rilis adalah X.Y.Z. X adalah versi utama host API, itu engine.api sebuah permainan menyatakan, jadi setiap rilis 1.x.x dijalankan engine.api=1 pertandingan; rilis ini juga mencatat versi minor API host, yang tumbuh seiring bertambahnya anggota (permainan dapat memerlukan anggota dengan engine.minor). Rilis yang diterbitkan tidak pernah berubah: perbaikan adalah versi berikutnya.

Catatan rilis

1.24.0

API Tuan Rumah 1.26: sematkan engine.version=1.24.0 dan tambahkan engine.minor=26 untuk perubahan yang ditandai (1.26); segalanya lainnya berlaku untuk setiap pertandingan. Game yang mendeklarasikan versi 1.25 atau lebih akan berperilaku seperti sebelumnya.

  • File paket pekerja (1.26): starhermit:script pekerja membaca file paket game melalui a files global dengan starhermit:enginedibaca, secara asli dan di browser.
  • Tingkat detail dan aliran bayangan (1.26): three.js r185 LOD; ekstensi mesin InstancedMesh.setLevels(...) (tingkat per-instance, secara asli) dan directionalLight.shadow.cascades (1–4 peta terbagi atas tampilan seperti yang dilakukan CSM).
  • Ruang warna keluaran (1.26): renderer.outputColorSpace Dan ColorManagement seperti yang dimiliki three.js r185; LinearSRGBColorSpace menulis cahaya linier di setiap backend.
  • Tata letak UI (1.26): membungkus baris dengan gap, ukuran persentase, maxWidth/maxHeight, properti khusus dengan var(), teks huruf kecil dan ui.lastRect().
  • Kait bahan (1.26): pass_kind() Dan is_shadow_pass() beri tahu hook mana yang dilewatinya.
  • Kecepatan: peta bayangan dan prepass hanya menggambar apa yang mencapainya; bola pemusnahan pertama dari jerat berkulit dibuat secara asli; literal array yang lebih cepat, destrukturisasi dan pencarian Map/Set dalam skrip; Bingkai WebGL 2 tidak lagi menunggu getError, dan Wayland asli berada di depan frame callback.
  • Perbaikan: o[4294967295] dibaca sebagai kunci biasa; Metode Map dan Set menolak penerima yang lain; package --web selalu paket starhermit-remote.json.
  • Perkembangan: --local-container URL menjalankan sesi permainan kontainer di server milik pengembang dengan host platform lokal.

1.23.0

API Tuan Rumah 1.25: sematkan engine.version=1.23.0 dan tambahkan engine.minor=25 untuk perubahan yang ditandai (1.25); segalanya lainnya berlaku untuk setiap pertandingan. Game yang menyatakan versi 1.24 atau lebih tua berperilaku seperti sebelumnya.

  • Animasi kerangka (1.25): Bone, Skeleton Dan SkinnedMesh seperti yang dimiliki three.js r185, semuanya dikuliti tahap puncak materi di setiap backend (termasuk kait, bayangan, dan prepass); GLTFLoader memuat skin dan klip animasi.
  • Majelis Web (1.25): itu WebAssembly global secara asli dan dalam starhermit:script pekerja, di dalam mesin itu sendiri juru bahasa sandbox (inti WebAssembly 2.0 dan SIMD lebar tetap, tanpa JIT); memori dibatasi oleh engine.limits.wasm_mib (standarnya 256 MiB). Hasil bilangan bulat cocok dengan browser sedikit demi sedikit.
  • Tekstur data mengambang (1.25): FloatType Dan HalfFloatType DataTextures mencapai ShaderMaterial dan menghubungkan WGSL tidak dijepit, disimpan sebagai setengah mengapung.
  • Pesan pekerja biner (1.25): pesan pekerja mungkin berisi ArrayBuffers, array yang diketik dan DataViews, disalin atau dipindahkan dengan daftar transfer.
  • Kamar (1.25): rooms.joined() mencantumkan ruangan tempat pemain duduk; rooms.browse() ringkasan dibawa metadata; server game yang masih bangun mencapai skrip sebagai unavailable dengan code "server_starting" Dan retryAfter.
  • Perbaikan dan kecepatan: TextEncoder.prototype.encodeInto secara asli; banyak TextureLoader memuat sekaligus tidak lagi melebihi anggaran aset yang diterjemahkan; pemeriksaan menjaga pekerja tetap selaras dengan jam yang disimulasikan; penduduk asli Wayland melewatkan bingkai komposer tidak akan muncul; tekstur mengubah setiap pembaruan bingkai di Vulkan dan OpenGL ES.
  • Perkembangan: dibutuhkan halaman web loopback ?quality=LEVEL.

1.22.0

Host API 1.24: sematkan engine.version=1.22.0 dan tambahkan engine.minor=24 untuk perubahan yang ditandai (1.24); segalanya lainnya berlaku untuk setiap pertandingan. Game yang menyatakan versi 1.23 atau lebih tua berperilaku seperti sebelumnya.

  • Tautan eksternal (1.24): sebuah manifes menyatakan hingga 16 engine.link.<id>=<https URL> garis, dan openLink(id) dari starhermit:engine membuka satu saat menangani pers pemain, hanya setelah konfirmasi runtime sendiri setelah administrator StarHermit menyetujui URL tersebut. Tautan yang belum ditinjau terbuka, dengan peringatan, hanya di pembangunan berjalan.
  • Parameter bahan (1.24): disalin sebagai three.js r185 setValues menyalinnya, jadi satu Warna diteruskan ke dua materi (atau dua bidang) tidak lagi dibagikan. Game lama terus membagikannya dan diperingatkan sekali di konsol.
  • Kesalahan 3D yang lebih jelas: kumpulan 3D yang ditolak, meneruskan data atau contoh memberi nama bidang dan nilai, dan tidak terbatas nilai material atau seragam diberi nama berdasarkan material dan properti. Warna emisif kalikan intensitasnya melebihi rentang setengah pelampung diambil pada titik terbesarnya alih-alih menolak operan.
  • Skrip lebih cepat: Centang IsoCity dan pembaruan tamu IsoCoaster 1,6×, pencarian catur 1,07–1,17× lebih cepat; menyatu instruksi mengisi bahan bakar sedikit lebih sedikit. Tidak ada perubahan perilaku.
  • Aksesibilitas: di browser, aktivasi widget pembaca layar berfungsi setelah ketukan jari.

1.21.0

Host API 1.23: sematkan engine.version=1.21.0 dan tambahkan engine.minor=23 untuk perubahan yang ditandai (1.23); segalanya lainnya berlaku untuk setiap pertandingan. Game yang mendeklarasikan versi 1.22 atau lebih lama dirender persis seperti sebelumnya.

  • Unit ringan (1.23): setiap lampu dan material menyala seperti yang dilakukan three.js r155+ (lampu yang benar secara fisik), jadi a port three.js tidak lagi membagi intensitas dengan π; cahaya sekitar dan belahan bumi bukan lagi logam ringan; glTF KHR_lights_punctual intensitas diambil sesuai yang diberikan file.
  • Bayangan (1.23): bayangan three.js r185: masing-masing cahaya miliknya shadow.camera, normalBias dalam satuan dunia, tiga default (512 peta, bias 0), filter PCF-nya, shadow.intensity, material.shadowSide, dan permainannya mapSize apa pun level grafisnya. Bayangan point-light, VSM, dan cache peta bayangan belum cocok.
  • Bidang teks (1.23): bidang teks yang diberi gaya mengambil ukuran gayanya (padding, batas, ukuran teks, min dan tetap lebar dan tinggi), seperti halnya input CSS.
  • Lingkungan: PMREMGenerator.fromScene mengambil adegan apa pun (katakanlah kubah langit dan sprite matahari), digambar seperti tiga adegan; bahan yang tidak menyala persis, bahan yang menyala kira-kira.
  • UI: ui.pointerCaptured() mengatakan apakah penekanan atau ketukan bingkai ini masuk ke UI (jangkauan sentuhan jari termasuk).
  • emoji: ⚖️ dan ✖️ menggambar warna dengan U+FE0F (833 mesin terbang).

1.20.2

Host API 1.22, sebagai 1.20.1: sematkan ulang ke 1.20.2 (engine.version=1.20.2). Semuanya di sini berlaku untuk setiap pertandingan.

  • Pemandangan: material.depthFunc dengan konstanta tiga (NeverDepth … NotEqualDepth), dihormati di setiap anak di bawah umur; tidak disetel, ini mengikuti default minor (LessEqual dari 1,20, Kurang sebelumnya). Mengatur LessDepth untuk mempertahankan kemenangan imbang pertama permukaan koplanar dalam satu mesh di bawah 1,20+.
  • UI: ui.select opsi mengambil opsi HTML label.
  • emoji: 🪴 dan ◻ (831 mesin terbang).

1.20.1

Host API 1.22, sebagai 1.20.0: sematkan ulang ke 1.20.1 (engine.version=1.20.1). Semuanya di sini berlaku untuk setiap pertandingan.

  • Emoji kanvas: fonts.load(font, text), fonts.check, fonts.status, dan sebuah fonts.ready yang menunggu font emoji, seperti di web document.fonts. Kanvas yang membuat emoji pernah menunggu fonts.load pertama (sebelumnya, emoji yang digambar sebelum font yang dimuat dengan lambat tiba tetap kosong). Mesin terbang berwarna terlalu besar untuk melakukan rasterisasi skala gambar.
  • Perbaiki (adegan): garis yang melintasi bidang dekat kamera digambar sebagai garis di setiap backend (perangkat lunak rasterizer menggambar mereka sebagai bentuk terisi besar); biaya anggaran garis mesh tidak berubah.
  • UI: bobot teks dapat berupa angka dari 1 hingga 1000, seperti dalam CSS.
  • emoji: 〰 U+3030 (829 mesin terbang).
  • dokumen: anggaran kerja kanvas dan berapa biaya setiap operasi menggambar.

1.20.0

Host API 1.22: sematkan engine.version=1.20.0 dan tambahkan engine.minor=22 untuk perubahan yang ditandai (1.22); segalanya lainnya berlaku untuk setiap pertandingan. Game yang mendeklarasikan versi 1.21 atau lebih lama berperilaku persis seperti sebelumnya.

  • Isi penggeser (1.22): gaya penggeser fill bagian mencakup lintasan dari minimum hingga nilainya (dari kanan dalam tata letak kanan-ke-kiri); CSS accent-color Dan ::-moz-range-progress mencapainya.
  • lampu glTF (1.22): GLTFLoader membangun KHR_lights_punctual lampu titik, titik dan arah sebagai tiga r185 melakukannya, dengan intensitas dalam satuan lampu mesin (spesifikasi, "unit ringan"). File yang memerlukan ekstensi sekarang dimuat untuk setiap game (tanpa lampu di bawah 1,22) alih-alih gagal.
  • Kamar: RoomSocket.sendReady(false) penarikan siap.
  • Aksesibilitas: ui.announce jangan pernah menampilkan banyak pengumuman dalam satu frame; itu menyimpan empat terbaru dan memperingatkan sekali.
  • Perbaiki (audio): di browser, context.currentTime bisa tetap di 0 selamanya saat laporan pertama dari worklet audio datang sebelum dirender, jadi game yang menunggu jam tidak pernah mengeluarkan suara.
  • dokumen: aturan porting untuk lingkungan ruang three.js berdasarkan rilis (spesifikasi, "pelabuhan lingkungan").

1.19.3

Host API 1.21, seperti 1.19.2, hanya diperbaiki: sematkan ulang ke 1.19.3 (engine.version=1.19.3).

  • Perbaiki (adegan): Raycaster.intersectObject(s) menguji mesh dengan presisi ganda, seperti yang dilakukan three.js di JavaScript, sehingga sinar yang datang jauh tidak lagi mengenai benda kecil dan sinar yang dekat a CircleGeometrypusatnya tidak lagi tergelincir di antara keduanya segitiga-segitiganya.
  • dokumen: satuan cahaya. Di setiap minor, lampu tepat waktu menggunakan penskalaan tiga warisan (pra-r155): dari tiga r155+, membagi intensitas cahaya sekitar, belahan bumi, arah, titik dan titik dengan π (spesifikasi, "unit ringan").

1.19.2

Host API 1.21, seperti 1.19.1, hanya diperbaiki: sematkan ulang ke 1.19.2 (engine.version=1.19.2).

  • Perbaiki (teks): sintesis huruf tebal (serif dan monospace di browser, dan keluarga apa pun tanpa huruf tebal) semakin berani setiap garis besar mesin terbang merata, seperti yang dilakukan Chrome, alih-alih menggambar, teks kembali digeser ke kanan, jadi teks tebal tidak lagi mencoreng tetangganya. Kemajuan dan measureText tidak berubah; asli dan browser menggambarnya secara identik.
  • emoji: 🏊 🛹 🐄 (828 mesin terbang).
  • dokumen: memutar skrip' tap adalah klik mouse; penggunaan tes tata letak telepon touch untuk satu jari.

1.19.1

Host API 1.21, seperti 1.19.0, hanya diperbaiki: sematkan ulang ke 1.19.1 (engine.version=1.19.1).

  • Perbaiki (UI): dialog runtime meredupkan seluruh jendela lagi, termasuk sudut persegi (latar belakang dialog bergaya mengambil radius sudut tema, sehingga permainan ditampilkan tanpa redup di sudut); latar belakang dialog bergaya permainan adalah persegi secara default juga. Probe layar pemeriksaan render asli lolos setiap saat # viewport skala.
  • Perbaiki (masukan): input.touchControlsVisible() Dan primaryPointer() langsung dari ruang lingkup modul permainan di a perangkat sentuh pertama, tidak hanya dari frame pertama.
  • Cek: naskah drama key Dan hold langkah-langkah menyembunyikan kontrol sentuh seperti yang dilakukan tombol pemain; dialog-satu-file-a- batas kedua mengikuti jam cek.

1.19.0

Host API 1.21: sematkan engine.version=1.19.0 dan tambahkan engine.minor=21 untuk perubahan yang ditandai (1.21); segalanya lainnya berlaku untuk setiap pertandingan. Game yang mendeklarasikan 1.20 berperilaku persis seperti pada 1.18.0.

  • Gambar: kanvas yang ditarik ke overlay membebaskan gambarnya dengan kanvas (kanvas berumur pendek kehabisan anggaran 120 gambar), dan anggaran penuh mendaur ulang gambar yang tidak digambar dalam bingkai ini. engine.limits.images meningkatkan hitungan hingga 1.024 (1,21). Setiap file diterbitkan apa adanya (tidak ada nama file yang diawali dengan _ atau .), dan Halaman GitHub menyajikannya dengan Access-Control-Allow-Origin: *.

versions.json

{
  "format": 2,
  "versions": [
    {
      "api": {"major": 1, "minor": 4},
      "date": "2026-10-20T13:55:50Z",
      "native": {
        "windows-x86_64": {"manifest": "1.1.0/native/windows-x86_64/native.json", "sha256": "<SHA-256 of native.json>"}

      "version": "1.1.0",

web adalah {"manifest": "sha384-…"}, hash SRI dari web rilis manifest.json, atau null untuk rilis tanpa runtime web. native menyematkan setiap platform native.json oleh SHA-256-nya. SEBUAH rilis ditarik karena tidak aman katanya "revoked": true dengan a "revokedReason"; itu adalah hanya diperlukan perubahan pada entri yang diterbitkan, kecuali penghapusan: untuk menjaga wiki dalam 1 GB Halaman GitHub rilis terlama meninggalkan area mesin, dan entri mereka tetap terdaftar sebagai dicabut "removed": true (1.0.0 hingga 1.6.0 dihapus dengan cara ini pada 26-10-2026, 1.7.0 hingga 1.15.1 pada 27-10-2026, 1.15.2 hingga 1.17.0 pada 28-10-2026, 1.17.1 dan 1.18.0 pada 29-10-2026).

native.json

native.json mencantumkan file folder mesin yang diinstal klien — starhermit.exe, release.json (versi rilis, API host, dan launcher protokol runtime-nya berbicara), LICENSE-engine dan pemberitahuan pihak ketiga — masing-masing dengan miliknya sendiri size, sha256 Dan chunks. Sepotong adalah hamparan file, disimpan dengan kompresi zlib sebagai chunks/<first two hex digits>/<sha256>.z dan diberi nama oleh SHA-256 dari byte yang tidak terkompresi; batas potongan mengikuti konten, jadi tidak berubah stretch menjaga bongkahannya dari satu rilis ke rilis berikutnya. Jika lebih kecil, file juga akan dicantumkan patches dari file yang sama pada rilis sebelumnya ("from": SHA-256 dari file sebelumnya). downloads mencantumkan unduhan pengembang dengan miliknya size Dan sha256; klien tidak pernah menginstalnya. Dalam rilis dengan runtime web, folder asli juga berlaku web-manifest.json, web rilis manifes, sehingga pengembang mengunduh paket game untuk web tanpa jaringan.

Waktu proses web

Runtime web rilis adalah file di sampingnya manifest.json, yang mencantumkan masing-masing dengan miliknya sendiri size Dan sha384 dan mencatat versi rilis, API host, dan build. Halaman pemuat game (index.html, ditulis oleh starhermit package --web) tidak memiliki skripnya sendiri: ia memuat starhermit.js Dan manifest.json dari https://engine.starhermit.com/engine/X.Y.Z/ (atau, dari alat yang lebih tua, https://wiki.starhermit.com/engine/X.Y.Z/) dengan hash SRI, dan mesinnya mengambil setiap file lain yang diperlukan (starhermit.wasm, worklet audio, font) dan memeriksanya menentang manifesto tersebut. Halaman ini hanya menjalankan mesin — input, menu runtime, audio, penyimpanan, sesi platform dan suara — dan TypeScript game berjalan di pekerja yang dimulai dan dapat dihentikan.

Runtime web menggabungkan fontnya sendiri, Liberation 2.1.5 (SIL Open Font License 1.1) dan DejaVu Sans 2.37 (lisensi Bitstream Vera dan Arev); pemberitahuan mereka sudah masuk licenses/ dengan yang lain.

Integritas

Satu rantai hash mencakup setiap byte yang dijalankan klien:

  1. versions.json (atau API platform di bawah) memberikan SHA-256 rilis native.json.
  2. native.json memberikan SHA-256 setiap file dan setiap potongan.
  3. Klien hanya mengambil potongan yang belum ditampungnya, memeriksa ukuran masing-masing potongan yang disimpan, memperbesar ukuran dan SHA-256, menyatukan setiap file, memeriksa SHA-256 file dan baru kemudian memindahkannya pelepasan ke tempatnya. Sebuah patch diperiksa terhadap SHA-256 miliknya sendiri, dan file yang dipatch diperiksa terhadapnya file itu; setiap kegagalan akan kembali menjadi bagian-bagiannya.

Unduhan pengembang dicakup oleh rantai yang sama melalui entrinya downloads. Sebuah peramban halaman pemuat game menyematkan runtime web starhermit.js Dan manifest.json dengan hash SRI, dan runtime memeriksa setiap file lain yang dimuat terhadap manifes.

Mesin melepaskan API

Platform ini menyajikan daftar yang sama, dengan setiap URL di wiki ini, sehingga klien menanyakan API mesin yang mana untuk mengambil:

GET /api/v1/engine/releases → setiap rilis, yang terbaru terlebih dahulu:

{"releases": [{
  "version": "1.1.0", "api": {"major": 1, "minor": 4}, "revoked": false, "date": "2026-10-20T13:55:50Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.1.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"windows-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.1.0/native/windows-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} → satu rilis, atau 404 bila tidak terdaftar. Keduanya anonim dan dapat di-cache (Cache-Control: public, max-age=60 dengan sebuah ETag). Rilis yang dicabut membawa revokedReason; web adalah null untuk rilis tanpa runtime web. Meskipun platform tersebut belum pernah membaca daftarnya (wiki tidak dapat dijangkau sejak dimulai), mereka menjawab 503 dengan Retry-After.

Permainan skrip di platform

Saat root game starhermit.txt menyatakan engine.version, platform memperlakukannya sebagai skrip permainan:

  • setiap penerbitan mencatat rilis pin file, sebagai hosting.engineVersion, dan set hosting.deployWarning (juga dalam jawaban bundel Push) ketika rilis itu tidak terdaftar atau terdaftar dicabut. Peringatan tidak pernah menghentikan publikasi.
  • setiap halaman game yang dihosting disajikan dengan Kebijakan Keamanan Konten yang hanya menerima skrip dari dua asal mesin (dan mesin itu sendiri blob: pekerja), jadi satu-satunya kode adalah skrip halaman permainan yang dapat dijalankan adalah mesin resmi:
default-src 'self'; script-src https://wiki.starhermit.com https://engine.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com https://engine.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com https://engine.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

Halaman permainan skrip tanpa versi browser (seperti halaman biasa yang diunggah oleh game khusus Windows untuk browser) tidak memerlukan skrip dan tidak terpengaruh.

Pencabutan

Rilis yang dicabut tetap terdaftar sehingga klien dapat mengetahui alasan mereka menolaknya: klien StarHermit melakukannya tidak menginstal atau memulainya dan memberi tahu pemain, perintah pengemasan menolak mengemas game untuk itu ketika mereka membaca versions.json, dan platform memperingatkan pemilik game yang memasang pin saat mereka melakukannya mempublikasikan. Sematkan ulang ke rilis yang menggantikannya dan publikasikan lagi (lihat Pindah ke mesin yang lebih baru).
