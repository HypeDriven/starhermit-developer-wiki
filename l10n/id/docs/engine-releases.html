Rilis mesin StarHermit

Mesin StarHermit — runtime yang diputar permainan skrip — adalah diterbitkan di wiki ini sebagai rilis berversi dan tidak dapat diubah di bawah wiki.starhermit.com/engine/. Game menyematkan satu rilis persis dengan engine.version di mereka starhermit.txt; halaman game memuat runtime web rilis di sini, di browser, klien Windows StarHermit menginstal runtime asli rilis dan memutarnya permainan di dalamnya, dan pengembang mengunduh runtime rilis dari sini untuk membangunnya.

Versi

Sebuah rilis adalah X.Y.Z. X adalah versi utama host API, itu engine.api sebuah permainan menyatakan, jadi setiap rilis 1.x.x dijalankan engine.api=1 pertandingan; rilis ini juga mencatat versi minor API host, yang tumbuh seiring bertambahnya anggota (permainan dapat memerlukan anggota dengan engine.minor). Rilis yang diterbitkan tidak pernah berubah: perbaikan adalah versi berikutnya.

Dokumentasinya selalu menjelaskan rilis terbaru. Halaman di sini mungkin di-cache hingga sepuluh menit setelah rilis dipublikasikan; versions.json mengatakan rilis yang mana terbaru.

Catatan rilis

1.9.0

Tuan rumah API 1.13. Game yang disematkan ke rilis sebelumnya tetap berjalan di dalamnya. Sematkan ulang ke 1.9.0 (engine.version=1.9.0) untuk perbaikan siklus hidup; menambahkan engine.minor=13 untuk perilaku UI baru.

  • Konten UI yang diputar (engine.minor=13): suatu gaya rotate mengubah semua yang digambar kotaknya, sebagai CSS transform melakukan: teks dengan bayangan, cahaya, guratan dan isian gradien, gambar, sembilan irisan, dekorasi gambar dan bayangan kabur, dengan tepi halus. Tata letak, pengujian pukulan, dan fokus tetap pada tempatnya. SEBUAH widget yang digambar game itu sendiri draw tetap tegak. Game yang mendeklarasikan anak di bawah umur yang lebih tua, atau tidak sama sekali, menyimpan teks, gambar dan bayangan kabur tegak.
  • Jari di UI game (engine.minor=13): hovered Dan hoverWithin tidak pernah cocok satu jari pun, dan pressed hanya cocok saat jari berada di bawah pada widget, jadi tidak ada yang tetap menyala setelah diketuk. Ketuk dapatkan target berukuran sentuhan dan tarikan di area gulir akan menggulirkannya. Mouse dan pena tidak berubah.
  • onSuspend Dan onResume di browser: tab tersembunyi atau browser yang diperkecil sekarang menangguhkan permainan sebagai a jendela yang diperkecil berfungsi secara asli; onSuspend berjalan setelah frame sedang berlangsung dan apa yang ditulisnya ke penyimpanan disimpan, dan onResume berjalan sebelum frame berikutnya ketika halaman ditampilkan.
  • onQuit: sebagian besar tidak pernah berjalan, secara asli atau di browser, karena jendela atau halaman penutup biasanya menemukan a bingkai sedang berlangsung. Sekarang berjalan sekali, setelah frame itu (setelah onSuspend jika gamenya disembunyikan terlebih dahulu), dan penulisan penyimpanannya disimpan. Secara alami, ia memiliki yang kedua; di browser, halaman yang hilang menunggu 0,2 detik untuk permainan dengan storage kemampuan. Penyimpanan cloud, salinan pengaturan akun dan panggilan platform dilakukan onQuit tetap tidak keluar: simpan selama frame.
  • Perbaikan: bingkai pertama jendela yang diperkecil setelah muncul kembali tidak lagi membutuhkan satu langkah waktu yang lama.

1.8.1

Host API 1.12, sebagai 1.8.0: sematkan ulang ke 1.8.1 (engine.version=1.8.1) untuk mendapatkan ini; tidak diperlukan perubahan kode.

  • Suara pendek di browser: bunyi pada grafik sintesis (starhermit:audio's context) yang dimulai pada context.currentTime dan berlangsung kurang dari beberapa detik tidak pernah terdengar di browser: perintah grafik mencapai mixer beberapa detik terlambat. Mereka sekarang tiba sekaligus, dan currentTime adalah waktu mixer pada keduanya runtime, juga tepat setelah tab tersembunyi atau jendela yang diperkecil muncul kembali. Jika permainan kalian silent atau meleset short efek di browser pada 1.8.0 atau lebih lama, sematkan ulang ke 1.8.1.
  • Waktu proses Linux: unduhan pengembang, starhermit-1.8.1-linux-x86_64.tar.gz, untuk Linux 64-bit dengan glibc 2.35 atau lebih baru. Dia native.json mencantumkan apa yang dibutuhkannya. Unggahan asli masih diputar oleh klien Windows.
  • Default peramban: saat permainan berjalan, halamannya menyimpan menu klik kanan browser, memilih, menyalin dan tempel, menjatuhkan file, gulir otomatis klik tengah, tombol mundur dan maju mouse serta pintasan seperti Ctrl+S, Ctrl+F, Ctrl+P, zoom, F1, F3 dan Alt dari game, dan kunci yang diikat game mencapainya dengan Ctrl, Alt atau Cmd juga. F11, F12, muat ulang dan tombol tab browser masih berfungsi. Halaman yang menyematkan game dalam dokumen yang lebih besar dapat menjaga perilaku browser browserDefaults: "page".
  • Kehabisan memori di browser: permainan yang menghabiskan memori browser berakhir "permainan kehabisan skrip memori" alih-alih merusak halaman.
  • Perbaikan: warga asli http:// permintaan mencoba setiap alamat yang ditentukan oleh nama (localhost di Windows); itu Unduhan Windows starhermit.exe menyimpan bit yang dapat dieksekusi saat dibuka ritsletingnya di Linux atau WSL.

1.8.0

Tuan rumah API 1.12. Game yang disematkan pada rilis sebelumnya tetap berjalan di dalamnya; menyematkan ulang (dengan engine.minor=12 untuk anggota baru) untuk menggunakan ini.

  • Gaya untuk UI game: mendaftar terlihat sekali dengan ui.setStyles berdasarkan jenis dan kelas widget, dengan ui.setTokens nilai, dan memberi nama kelas per widget dengan ui.style(...). Gradien, gambar, dan sembilan irisan isian, batas per sisi, sudut membulat atau terpotong, bayangan dan cahaya, dekorasi, keburaman latar belakang, dan teks dengan spasi huruf, bayangan, garis luar, dan isian gradien. Blok status (arahkan kursor, tekan, fokus terlihat, dicentang, dipilih, dinonaktifkan, pertama, terakhir, ganjil, genap, masuk, keluar) dan inside aturan berfungsi seperti di CSS, dan parts penggeser gaya, kotak centang, pilihan, tab, meter, dan dialog. Ukurannya kotak pembatas.
  • Gerakan: transisi antar tampilan, animasi keyframe dengan anak terhuyung, masuk dan keluar animasi, dan skala dan putar. Gerakan yang dikurangi menjadikannya instan atau diam.
  • Tata letak dan widget: kisi-kisi dengan baris bergaris dan bergaris, tumpukan, penempatan berlabuh, justify dan spacer, regangkan, isi dan kembangkan, margin; tombol yang dibuat dari konten, ui.widget untuk widget yang digambar tangan yang menjaga fokus, navigasi dan pembaca layar, tooltips, meter, grup radio, sakelar dan ui.document.
  • Dari CSS: ui.stylesFromCss dan itu starhermit css FILE perintah mengonversi gaya pembuatan browser lembar ke dalam gaya, animasi, token, dan tata letak, mencantumkan apa yang tidak memiliki gaya.
  • Kursor: input.setCursor menyetel penunjuk berdasarkan nama kursor CSS, atau ke gambar game itu sendiri 64x64.
  • Ukuran antarmuka pemutar, ukuran teks, kontras tinggi, dan pengurangan gerakan masih berlaku pada gaya.
  • Perbaikan: Tekstur yang hanya digunakan dalam suatu gaya disimpan di browser (isinya tidak menghasilkan apa pun); font ditambahkan dengan canvas.fonts menggambar di setiap bingkai; engine.preferences() setuju dengan ui.preferences() setiap bingkai; renderer.capture() membutuhkan hingga 4 tangkapan sekaligus dan selalu mengendap; klik penggeser dan seret mendarat langkah, dan bilah geser dan footer menu Opsi berperilaku pada ukuran besar dan pada halaman lambat.

1.7.0

Tuan rumah API 1.11. Game yang disematkan pada rilis sebelumnya tetap berjalan di dalamnya; menyematkan ulang (dengan engine.minor=11 untuk anggota baru) untuk menggunakan ini.

  • Kelas ruang tampilan: renderer.grade.space = "display" menilai warna yang ditampilkan layar, per saluran setelah pemetaan nada, seperti yang dilakukan tingkat kanvas pembuatan web: saturasi, kontras pada tampilan 0,5, bayangan dan warna highlight, a night (desaturasi dan warna cahaya bulan yang menyisakan piksel hangat dan cerah, dengan spareSaturation Dan brightScale), sebuah sorotan lift, Dan flashSpace: "display" untuk sekejap malam tidak berwarna. Tidak ada biaya tambahan untuk tingkat kualitas apa pun. Standarnya "linear" kelas tidak berubah.
  • Target render kecil: RGFormat Dan RedFormat dengan UnsignedByteType (RG8, R8) pada 2 dan 1 byte a piksel, setiap persamaan campuran dijepit ke 0–1.
  • UI game mengikuti pengaturan pemain, seperti yang didokumentasikan: ukuran antarmuka, ukuran teks, kontras tinggi (lebih setTheme, label color dan sebuah wadah background) dan gerakan berkurang. ui.preferences() mengatakan apa yang berlaku bingkai ini dan ui.measureText() mengukur teks seperti yang ditata oleh UI. Sebuah game yang mengukur UI-nya dengan tangan harus memeriksanya pada ukuran yang lebih besar.
  • Teks besar: bingkai yang teksnya melebihi atlas mesin terbang sekarang memperbesarnya (menjadi 1024, lalu 2048 px) alih-alih tidak menggambar teks bingkai itu.
  • Audio di browser: context.state adalah "suspended" sampai penekanan pertama pada pemutar memulai audio, lalu "running", dengan statechange Dan resume() menyelesaikan. A setValueAtTime atau setTargetAtTime menggantikan satu pada saat yang sama tepat sebelumnya, jadi memperbarui parameter setiap frame tidak lagi mencapai batas peristiwa sementara jamnya berhenti.
  • jendela: runtime membawa informasi versi dan ikon StarHermit, jadi Task Manager mencantumkan game di bawah "Pertapa Bintang" (bukan nama yang salah dengan ikon kosong).

1.6.0

Tuan rumah API 1.10. Game yang disematkan pada rilis sebelumnya tetap berjalan di dalamnya; menyematkan ulang (dengan engine.minor=10 untuk anggota baru) untuk menggunakan ini.

  • UI lebih cepat: label yang tidak diubah mempertahankan tata letaknya di seluruh bingkai, dan persegi panjang widget menjangkau skrip tanpanya JSON. Bingkai UI-berat yang berisi sekitar 800 widget turun dari sekitar 4 mdtk menjadi 0,7 mdtk di browser dan dari sekitar 3 mdtk di browser hingga 0,75 ms secara asli, dengan keluaran yang identik dengan piksel.
  • Tumpukan skrip yang lebih ramping: tabel penerjemah asli mengembalikan memori setelah ledakan sampah (setelah 8 kebanyakan mengosongkan koleksi berturut-turut, hingga penggunaannya dua kali lipat); dalam pertempuran besar, puncak tumpukan turun dari sekitar 205 MiB hingga di bawah 185 MiB.
  • Bahan: seragam hingga 16 KiB per bahan, dan textureLoad(tex, coords, 0) untuk pembacaan texel yang tepat (dijepit ke dalam tekstur pada setiap runtime).
  • Render target dan blending: target setengah mengambang dua dan satu saluran (RGFormat, RedFormat dengan HalfFloatType) pada setengah atau seperempat memori RGBA16F; CustomBlending dengan campuran persamaan dan faktor (pengurangan terbalik, min, maks) dan SubtractiveBlending; renderer.render menjadi target menggunakan bahan sebagaimana adanya sedang menelepon.
  • Memori tekstur: piksel DataTexture dapat meninggalkan tumpukan skrip setelah diunggah (image.data = null, atau di onUpdate); itu terus menggambar dan bertahan dari kehilangan perangkat atau konteks.
  • Penggunaan adegan: engine.usage() Dan engine.budgets() menghitung node, objek, instance, jerat yang dipasang, sprite, material, program, dan lampu melebihi batasnya.

1.5.1

Host API 1.9, hanya perbaikan: pin ulang dari 1.5.0 tanpa perubahan lainnya.

  • Menyalin berhasil: clipboard.writeText menempatkan teks pada clipboard sistem secara asli (Windows, X11, Wayland) dan di browser; sudah lulus pemeriksaan sebelumnya tetapi teksnya tidak pernah sampai.
  • Menempel secara asli: Ctrl+V, Shift+Sisipkan atau tombol Tempel tempelkan ke dalam bidang teks terfokus. Hanya waktu proses membaca clipboard, atas isyarat pemain; permainan melihat teks yang ditempel sebagai pengetikan.
  • frustumCulled = false tidak pernah dimusnahkan: jaring tempat pengait titik mempertahankan bayangannya bahkan saat pengait menempatkannya lebih dekat ke cahaya daripada batasnya, dan NaN, bola pembatas tak terhingga atau kosong tidak menyisihkan apa pun bukannya melempar.

1.5.0

API Tuan Rumah 1.9. Game yang disematkan pada rilis sebelumnya tetap berjalan di dalamnya; menyematkan ulang (dengan engine.minor=9 untuk ini) untuk menggunakannya.

  • File yang dipilih pemain: files.saveAs(name, data, {type}) Dan files.open({accept}) buka yang terpercaya dialog hanya saat menangani penekanan pemain (atau dalam waktu 5 detik setelahnya): pemilih file runtime sendiri secara asli, pengunduhan browser dan pemilih file di web. Permainan melihat nama dan byte, tidak pernah jalur; paling banyak 64 MiB, dan program, skrip, dan nama halaman ditolak.
  • Menangkap: renderer.capture({ui}) mengembalikan PNG dari bingkai game itu sendiri (dengan hamparan 2D jika diminta), tidak pernah menu runtime; mode foto adalah files.saveAs("photo.png", await renderer.capture()).
  • Pembaca layar: ui.announce(text, { politeness }) mengungkapkan apa yang tidak bisa dilakukan oleh papan gambar (Otomasi UI, AT-SPI, wilayah langsung di browser), paling banyak 500 karakter dan beberapa detik.
  • Tautan undangan: platform.launchContext() memberikan sesi peluncurannya (undangan yang diterima, a notifikasi), sehingga permainan dapat membuka meja itu alih-alih lobinya.
  • Anggaran gambar: engine.limits.image_mib meningkatkan anggaran gambar game dari 56 MiB hingga 512 MiB gpu_mib.
  • Bahan dan pencahayaan: 5 tekstur per material khusus, render target tanpa kedalaman dan dengan mipmaps, memasang jerat pada anggaran 262.144 instans, pengait cahaya dan kabut, pas pos layar penuh dengan warna dan kedalaman pemandangan, kabut yang muncul di belakang kamera, kelembutan bayangan, dan lampu kilat yang rata.
  • Skrip lebih cepat: alokasi juru bahasa dari kumpulan yang digunakan kembali, lebih murah for…of dan Peta/Set; objek-berat kode permainan sekitar 10–20% lebih cepat secara asli. Di browser, panggilan host dengan string pendek sekitar 3× lebih murah.
  • engine.stats().heapBytes Dan heapLimitBytes tidak ada di browser, bukan 0.

1.4.1

Host API 1.8, hanya perbaikan: pin ulang dari 1.4.0 tanpa perubahan lainnya.

  • Bidang teks di browser: fokus ui.textField (dan bidang runtime sendiri) perlu mengetik, menempel, dan metode input komposisi di browser, di mana tidak ada teks yang mencapainya; aslinya metode masukan hanya aktif sementara suatu bidang memiliki fokus, dengan kandidatnya berada di tanda sisipan.
  • Klip audio di browser: setiap klip yang dimuat game akan mencapai mixer, berapa pun banyaknya klip yang dimuat di awal (mereka mengantri dan mengunggah sedikit demi sedikit secara berurutan) alih-alih sebagian besar hilang secara diam-diam; klip yang tidak bisa dilakukan lemparan ketika dimainkan.
  • Tidak ada kesalahan konsol tanpa penyimpanan cloud: runtime menanyakan apakah ada penyimpanan sebelum mengunduhnya, jadi pemain yang belum menyimpan tidak lagi menyebabkan 404 di konsol.
  • Platform lokal (--dev --local-platform): perintah yang ditolak menjawab pengirimnya dengan kesalahan platform bingkai, dan skrip server mendapatkan konteks langsung (ruangan, kehadiran, peringkat dan tim, perjodohan).

1.4.0

Tuan rumahAPI 1.8. Game yang disematkan pada rilis sebelumnya tetap berjalan di dalamnya; sematkan ulang untuk menggunakan ini.

  • Bawa pemain build JS SDK ke sana: penyimpanan cloud yang tidak ditulis oleh mesin (build JS SDK) tidak lagi kesalahan. saves.foreign() memberikannya { text, bytes }, status simpannya adalah "foreign", dan tidak ada apa pun diunggah hingga game memigrasikannya dan menelepon saves.save(data, { replaceForeign: true }), yang menggantikan hanya versi yang ditampilkan. settings.legacyKeys(), legacy(key), removeLegacy(key) Dan onLegacy membaca dan menghapus kunci pengaturan lama game tersebut (di luar game.).
  • Kompresi: compress Dan decompress ("gzip", "deflate", "deflate-raw") di dalam starhermit:engine, dibatasi dan dengan byte yang sama secara asli dan di browser; atob Dan btoa secara asli juga.
  • File jarak jauh yang dihosting platform: engine.remote.urls=platform menyajikan file jarak jauh game dari StarHermit di bawah asal permainan itu sendiri, dan cargo starhermit publish hanya mengunggah objek yang tidak dimiliki game tersebut.
  • Render target: WebGLRenderTarget dengan renderer.setRenderTarget Dan render (ikon, tanda tanah), kedalaman pemandangan untuk material khusus (partikel lembut), dan pengambilan sampel tekstur yang lebih banyak pada pengait material.
  • UI: tidak ada klik yang hilang saat penekanan dan pelepasan terjadi di antara dua bingkai (ketuk cepat pada bingkai lambat); ui.scrollArea dapat digulir dan dibaca skripnya; ukuran teks per widget, kelompok dan berat, dan keluarga generik serif, monospace Dan cursive.
  • Peramban: loadClip, loadBuffer, createImageBitmap(path) Dan FontFace.load() tidak lagi membuat halaman menunggu file yang belum diambil, files.fetch mengambil file paket dan menyimpannya, dan paling banyak 16 pengambilan dijalankan sekaligus (antrian sisanya).
  • Skrip klasik di browser: game yang memuat skrip klasik (loadClassic) sekarang mulai di browser; itu global halaman seperti fetch, WebSocket Dan location dapat ditetapkan oleh game sebagai aslinya.
  • Bacaan berkisar: files.readBytes(path, offset, length) membaca bagian dari paket atau file jarak jauh.
  • Skrip: Intl.NumberFormat dengan style: "currency" secara asli (simbol, akuntansi, CLDR 48), dan formatToParts. Sebuah skrip server mendeklarasikan tickRateHz: 0 tidak perlu onTick di dalam authority(), seperti pada platform.

1.3.0

Tuan rumah API 1.7. Game yang disematkan pada rilis sebelumnya tetap berjalan di dalamnya; sematkan ulang untuk menggunakan ini.

  • Skrip yang lebih cepat dan ramping: penerjemah asli menyimpan nilai dalam satu kata mesin dan menyimpan properti dalam cache pencarian, dan x | 0, x >>> 0 dan pergeseran berdasarkan konstanta dijalankan sebagai instruksi tunggal. Penggunaan game yang banyak objek sekitar setengah heap, dan pembuatan peta berjalan sekitar 1,2–1,3× lebih cepat. Game yang melewati batas tumpukannya akan dikumpulkan dan tabel-tabelnya menyusut sebelum diakhiri; STARHERMIT_HEAP_CENSUS=<seconds> dengan --dev mencetak apa tumpukan memegang.
  • File jarak jauh (host API 1.7): engine.remote.files=, engine.remote.urls= Dan engine.remote.redirects= tandai file yang dilayani oleh host HTTPS game itu sendiri. Perintah pengemasan tidak menyertakannya dari unggahan dan sematkan masing-masing berdasarkan ukuran dan SHA-256 in starhermit-remote.json (--remote-out DIR menulis mereka objek dengan hash). Runtime mengambil, memeriksa, dan menyimpannya dalam cache; files.fetch(paths, onProgress) membuat mereka siap, files.status(path) memberitahukan di mana file berada, dan pemuat mengambil apa yang dimuatnya.
  • Batas unggahan: --max-upload-mib Dan --max-upload-paths (atau STARHERMIT_MAX_UPLOAD_MIB / _PATHS) melewati batas permainan yang ditinggikan, dan dengan --game-id alat tersebut membaca batasan yang dilaporkan platform.
  • glTF: Jerat terkompresi Draco (KHR_draco_mesh_compression) Dan KHR_mesh_quantization memuat melalui GLTFLoader.
  • Geometri dan material (host API 1.7): BufferAttribute.onUpload menjatuhkan susunan geometri dari tumpukan setelah mencapai GPU; kompak Int8, Uint8 Dan Int16 atribut; empat vec4 khusus per instans (setCustomAt(i, v, slot)); pra-perkalian dan perbanyak pencampuran; pemusnahan oleh boundingSphere Dan frustumCulled = false. Warna titik di luar 0–1 tidak lagi menjatuhkan jaring secara diam-diam.
  • jaring: pembersihan awal halaman tidak lagi mengeluarkan undian kosong, jadi WebGPU berhenti memperingatkan titik nol menghitung.

1.2.0

API Tuan Rumah 1.6. Game yang disematkan ke 1.1.0 tetap berjalan di 1.1.0; sematkan ulang untuk menggunakan ini.

  • BigInt secara asli, seperti di browser: 1n << 64n dan BigInt ES2022 lainnya (BigInt.asIntN, asUintN, BigInt64Array, BigUint64Array, pengakses BigInt DataView). BigInt dapat menampung paling banyak 220 bit secara asli. Host API dan JSON.stringify menolak BigInts (TypeError).
  • Modul di browser: modul yang mengimpor pengikatan dan mengekspornya lagi sekarang dimuat ketika dua modul saling mengimpor (gagal dengan "Ekspor '…' tidak ditentukan dalam modul"), seperti halnya export { x } from Dan import() dalam siklus seperti itu.
  • starhermit check menautkan modul saat browser mendapatkannya dan gagal, dengan file dan baris, di mana a browser tidak memuat game; memperingatkan tentang bawaan yang hanya dimiliki browser; mencetak permainannya console keluaran (--quiet menyembunyikannya); dan gagal dalam permainan yang akan memunculkan "tidak merespons" layar.
  • Anggaran waktu: evaluasi modul memiliki bahan bakar 60 detik (tadinya 2 detik), TypedArray set Dan fill hanya biaya apa yang mereka tulis, dan kesalahan untuk nama waktu fase, waktu berjalan dan batasnya. Anggaran secara bertahap ada di tutorial.
  • Hingga 128 tindakan yang dapat di-rebind (platform menyimpan 32 yang pertama dengan akun, runtime tetap sisanya di pengaturan pemutar yang disinkronkan), dan engine.group.<action>=Heading mengelompokkan mereka di layar kontrol.
  • Paket tidak menyertakan file pengembangan (node_modules/, tsconfig.json, package.json, kunci file, peta sumber,…) dan apa pun a .starhermitignore daftar. package --web --out DIR menulis sebuah unggahan tanpa mereka; indeks yang ditulis di tempat mencantumkannya di bawah "excluded".
  • Halaman: file diubah setelah pengemasan diberi nama pada layar kesalahan dengan daftar dan ukuran sebenarnya dan SHA-256; pemuat memberi nama ikon permainan (no /favicon.ico meminta); sebuah peramban tanpa WebGPU atau WebGL 2 mendapat pesan yang jelas.
  • Bahan khusus (host API 1.6): permainan simpul WGSL dan kait permukaan pada standar, fisik, Lambert dan bahan dasar dan a ShaderMaterial, diperiksa dan dikotak pasir oleh mesin; sebuah pengait permukaan aditif MeshBasicMaterial memberi cahaya.
  • Adegan dan alat (host API 1.5): GLTFLoader di dalam starhermit:scene, engine.setBusy(label) untuk pekerjaan panjang yang tidak dapat diiris, skrip akan menumpuk engine.stats(), dan profiler pengambilan sampel (STARHERMIT_SAMPLE dengan --dev).
  • Skrip lebih cepat: loop array yang diketik 25–30% lebih cepat dan Math bawaan yang dihitung secara inline.

1.0.0

Rilis pertama: runtime Windows (x86-64), tanpa runtime web.

Area mesin

engine/
  versions.json            every release: host API, date, runtimes, revocation
  X.Y.Z/
    native/windows-x86_64/
      native.json          the Windows runtime's files, each with its size, SHA-256 and chunks
      starhermit-X.Y.Z-windows-x86_64.zip
                           the developer download: the same files as one archive
    manifest.json          the web runtime's files, each with its size and sha384
    starhermit.js          the module a game's loader page loads
    starhermit.wasm, *.js  the runtime, its audio mixer and worklets
    starhermit.d.ts        the host API's declarations
    fonts/, licenses/      the runtime's fonts and every licence notice
                           (all of the web runtime only in a release that has one)
  chunks/ab/<sha256>.z     pieces of the native files, shared by every release
  patches/ab/<sha256>.p    binary patches from earlier releases' files

Setiap file diterbitkan apa adanya (tidak ada nama file yang diawali dengan _ atau .), dan Halaman GitHub menyajikannya dengan Access-Control-Allow-Origin: *.

versions.json

{
  "format": 2,
  "versions": [
    {
      "api": {"major": 1, "minor": 4},
      "date": "2026-10-20T13:55:50Z",
      "native": {
        "windows-x86_64": {"manifest": "1.1.0/native/windows-x86_64/native.json", "sha256": "<SHA-256 of native.json>"}
      },
      "revoked": false,
      "version": "1.1.0",
      "web": {"manifest": "sha384-<SRI hash of manifest.json>"}
    }
  ]
}

web adalah {"manifest": "sha384-…"}, hash SRI dari web rilis manifest.json, atau null untuk rilis tanpa runtime web. native menyematkan setiap platform native.json oleh SHA-256-nya. SEBUAH rilis ditarik karena tidak aman katanya "revoked": true dengan a "revokedReason"; itu adalah hanya mengubah entri yang diterbitkan.

native.json

native.json mencantumkan file folder mesin yang diinstal klien — starhermit.exe, release.json (versi rilis, API host, dan launcher protokol runtime-nya berbicara), LICENSE-engine dan pemberitahuan pihak ketiga — masing-masing dengan miliknya sendiri size, sha256 Dan chunks. Sepotong adalah hamparan file, disimpan dengan kompresi zlib sebagai chunks/<first two hex digits>/<sha256>.z dan diberi nama oleh SHA-256 dari byte yang tidak terkompresi; batas potongan mengikuti konten, jadi tidak berubah stretch menjaga bongkahannya dari satu rilis ke rilis berikutnya. Jika lebih kecil, file juga akan dicantumkan patches dari file yang sama pada rilis sebelumnya ("from": SHA-256 dari file sebelumnya). downloads mencantumkan unduhan pengembang dengan miliknya size Dan sha256; klien tidak pernah menginstalnya. Dalam rilis dengan runtime web, folder asli juga berlaku web-manifest.json, web rilis manifes, sehingga pengembang mengunduh paket game untuk web tanpa jaringan.

Waktu proses web

Runtime web rilis adalah file di sampingnya manifest.json, yang mencantumkan masing-masing dengan miliknya sendiri size Dan sha384 dan mencatat versi rilis, API host, dan build. Halaman pemuat game (index.html, ditulis oleh starhermit package --web) tidak memiliki skripnya sendiri: ia memuat starhermit.js Dan manifest.json dari https://wiki.starhermit.com/engine/X.Y.Z/ dengan hash SRI, dan mesin mengambil setiap file lain yang diperlukan (starhermit.wasm, worklet audio, font) dan memeriksanya menentang manifesto tersebut. Halaman ini hanya menjalankan mesin — input, menu runtime, audio, penyimpanan, sesi platform dan suara — dan TypeScript game berjalan di pekerja yang dimulai dan dapat dihentikan.

Runtime web menggabungkan fontnya sendiri, Liberation 2.1.5 (SIL Open Font License 1.1) dan DejaVu Sans 2.37 (lisensi Bitstream Vera dan Arev); pemberitahuan mereka sudah masuk licenses/ dengan yang lain.

Integritas

Satu rantai hash mencakup setiap byte yang dijalankan klien:

  1. versions.json (atau API platform di bawah) memberikan SHA-256 rilis native.json.
  2. native.json memberikan SHA-256 setiap file dan setiap potongan.
  3. Klien hanya mengambil potongan yang belum ditampungnya, memeriksa ukuran masing-masing potongan yang disimpan, memperbesar ukuran dan SHA-256, menyatukan setiap file, memeriksa SHA-256 file dan baru kemudian memindahkannya pelepasan ke tempatnya. Sebuah patch diperiksa terhadap SHA-256 miliknya sendiri, dan file yang dipatch diperiksa terhadapnya file itu; setiap kegagalan akan kembali menjadi bagian-bagiannya.

Unduhan pengembang dicakup oleh rantai yang sama melalui entrinya downloads. Sebuah peramban halaman pemuat game menyematkan runtime web starhermit.js Dan manifest.json dengan hash SRI, dan runtime memeriksa setiap file lain yang dimuat terhadap manifes.

Mesin melepaskan API

Platform ini menyajikan daftar yang sama, dengan setiap URL di wiki ini, sehingga klien menanyakan API mesin yang mana untuk mengambil:

GET /api/v1/engine/releases → setiap rilis, yang terbaru terlebih dahulu:

{"releases": [{
  "version": "1.1.0", "api": {"major": 1, "minor": 4}, "revoked": false, "date": "2026-10-20T13:55:50Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.1.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"windows-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.1.0/native/windows-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} → satu rilis, atau 404 bila tidak terdaftar. Keduanya anonim dan dapat di-cache (Cache-Control: public, max-age=60 dengan sebuah ETag). Rilis yang dicabut membawa revokedReason; web adalah null untuk rilis tanpa runtime web. Meskipun platform tersebut belum pernah membaca daftarnya (wiki tidak dapat dijangkau sejak dimulai), mereka menjawab 503 dengan Retry-After.

Permainan skrip di platform

Saat root game starhermit.txt menyatakan engine.version, platform memperlakukannya sebagai skrip permainan:

  • setiap penerbitan mencatat rilis pin file, sebagai hosting.engineVersion, dan set hosting.deployWarning (juga dalam jawaban bundel Push) ketika rilis itu tidak terdaftar atau terdaftar dicabut. Peringatan tidak pernah menghentikan publikasi.
  • setiap halaman game yang dihosting disajikan dengan Kebijakan Keamanan Konten yang hanya menerima skrip dari wiki ini (dan milik mesinnya sendiri blob: pekerja), jadi satu-satunya kode yang bisa dimiliki halaman permainan skrip run adalah mesin resmi:
default-src 'self'; script-src https://wiki.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

Halaman permainan skrip tanpa versi browser (seperti halaman biasa yang diunggah oleh game khusus Windows untuk browser) tidak memerlukan skrip dan tidak terpengaruh.

Pencabutan

Rilis yang dicabut tetap terdaftar sehingga klien dapat mengetahui alasan mereka menolaknya: klien StarHermit melakukannya tidak menginstal atau memulainya dan memberi tahu pemain, perintah pengemasan menolak mengemas game untuk itu ketika mereka membaca versions.json, dan platform memperingatkan pemilik game yang memasang pin saat mereka melakukannya mempublikasikan. Sematkan ulang ke rilis yang menggantikannya dan publikasikan lagi (lihat Pindah ke mesin yang lebih baru).
