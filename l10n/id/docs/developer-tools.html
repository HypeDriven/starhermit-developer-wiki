Alat pengembang StarHermit

Buat paket permainan skrip yang dapat diterbitkan, unggah ke StarHermit, dan berikan asisten pengkodean Anda koneksi MCP lokal. Alat-alat ini tidak memerlukan Instalasi karat atau checkout sumber mesin. Permainan ini mungkin memiliki permainannya sendiri membangun dependensi, seperti Node.js.

Unduh arsip untuk komputer Anda dari tabel di bawah, atau dari https://engine.starhermit.com/engine/tools/latest.json (ini mencantumkan masing-masing alamat arsip, ukuran dan SHA-256), dan bandingkan SHA-256-nya dengan checksum di sampingnya (<archive>.sha256). Buka kemasannya dan letakkan direktorinya di PATH, atau gunakan path lengkap executable pada perintah di bawah ini. unduhan macOS adalah disediakan secara terpisah untuk Apple Silicon (macos-aarch64) dan Intel (macos-x86_64). Mereka tidak disahkan oleh Apple, dan tidak ada unduhan Authenticode atau ID Pengembang ditandatangani. Pembuatan Apple Silicon adalah dikompilasi silang; melaporkan masalah.

Periksa dan kemas game

starhermit-tools --version
starhermit-tools check my-game
starhermit-tools package --web my-game --out upload --remote-out remote-objects

Direktori permainan berisi starhermit.txt dan file yang dibutuhkan game. engine.version menyematkan rilis mesin yang diterbitkan; alat membacanya manifes dari engine.starhermit.com dan menulis pemuat dan file yang diberi pin hash indeks. --engine-version X.Y.Z memilih rilis yang kompatibel secara eksplisit. File dideklarasikan oleh engine.remote.files ditulis ke remote-objects; Kapan engine.remote.urls=platform, menerbitkan, mengunggahnya terlebih dahulu.

check memvalidasi manifes, jalur paket, dan struktur file. Memang benar tidak menjalankan skrip. Uji game web yang dikemas di browser sebelumnya penerbitan. Pengembang juga dapat mengunduh versi asli yang cocok runtime dari rilis mesin (Windows, Linux, dan dari mesin 1.26.2 macOS 11 atau lebih baru di Intel dan Apple Silicon) dan gunakan starhermit check my-game untuk pemeriksaan eksekusi tanpa kepala. macOS runtime ditandatangani secara ad-hoc dan tidak diaktakan, dan hal tersebut belum ditandatangani diuji pada perangkat keras Apple asli. Tarball yang diunduh di browser adalah dikarantina: lari xattr -d com.apple.quarantine starhermit atau mengizinkannya di Pengaturan Sistem.

Menerbitkan

Gunakan kunci penerapan terdaftar Anda sendiri, setelah orientasi kunci publik dan panduan CI/CD di wiki pengembang. Mengatur STARHERMIT_PUBLIC_KEY Dan STARHERMIT_PRIVATE_KEY di shell Anda atau penyimpanan rahasia CI Anda. Alternatifnya, mengatur STARHERMIT_ACCESS_TOKEN ke token akses akun. Jangan letakkan ini nilai dalam game, komit, atau tambahkan ke konfigurasi MCP.

starhermit-tools publish --game-id YOUR-GAME-ID --upload upload --remote-out remote-objects

Ini menggantikan file game yang dikerahkan. --mode merge menambal yang sudah ada unggah saja. Untuk membuat game baru, ganti --game-id YOUR-GAME-ID dengan --new. --socket memilih unggahan WebSocket; unggahan besar pilih itu secara otomatis. --display-name Dan --description menimpa yang diunggah nama dan deskripsi manifes. Penerbit melaporkan URL yang dihosting dan menulis laporan publikasi di samping unggahan.

Akun tersebut harus memiliki game tersebut. Kesalahan kredensial atau batas ditolak adalah kesalahan; jangan menyiasatinya dengan kredensial orang lain. Terpencil benda-benda yang sudah dipegang oleh permainan digunakan kembali; unggahan objek terputus melanjutkan. Game baru dapat dibuat sebelum pengunggahan objek berikutnya gagal; gunakan ID permainan yang dilaporkan untuk mencoba lagi daripada membuat yang lain.

STARHERMIT_API_BASE memilih penerapan HTTPS lainnya. STARHERMIT_CA_FILE memilih paket kepercayaan PEM, misalnya pengembangan CA; Verifikasi TLS selalu diaktifkan. Penggunaan normal tidak memerlukan variabel apa pun.

Hubungkan asisten pengkodean dengan MCP

Tambahkan server stdio MCP ke konfigurasi asisten Anda, menggunakan absolute jalur yang sesuai untuk komputer Anda:

{
  "mcpServers": {
    "starhermit": {
      "command": "/absolute/path/to/starhermit-tools",
      "args": ["mcp", "--package", "/absolute/path/to/my-game"]
    }
  }
}

Server menawarkan check_package, package_web, Dan package_native. Jika game memiliki skrip build Node.js, tambahkan --build-script dan itu jalur absolut ke argumen MCP untuk mengekspos a build alat. Ini berjalan skrip yang dikonfigurasi itu; itu tidak menerima perintah sewenang-wenang dari MCP. package_web mengambil opsional outDir, remoteOut, Dan engineVersion; jalur keluaran relatif relatif terhadap direktori game. Secara default itu menulis starhermit-build/upload Dan starhermit-build/remote di samping direktori permainan. package_native menulis indeks file asli game untuk instalasi oleh klien StarHermit yang didukung, yang menginstal mesin runtime untuk platform pemain (termasuk macOS, dari mesin 1.26.2). Tidak ada alat yang mempublikasikan apa pun.

Dengan runtime asli terinstal, tambahkan --runtime dan itu jalur absolut yang dapat dieksekusi ke argumen MCP untuk diaktifkan run_checks. Alat tersebut mengeksekusi kode permainan dalam runtime yang dikonfigurasi. Penerbitan hanya tersedia sebagai perintah CLI eksplisit dan tidak pernah merupakan alat MCP.
