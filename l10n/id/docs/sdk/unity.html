SDK Persatuan

Itu SDK Persatuan Pertapa Bintang (HypeDriven/starhermit-unity-sdk) adalah paket Unity Package Manager dengan klien C# asinkron yang diketik untuk platform. Ini menangani Permintaan HTTP, penguraian JSON, penyegaran token, dan koneksi ulang WebSocket.
Kemasan com.starhermit.sdk, versi 0.1.0
Ruang nama Starhermit
Garis dasar API REST v1 dan WebSocket v1
Fitur REST yang lebih baru Menggunakan client.Raw dan model RawJson ketika versi SDK ini tidak memiliki anggota yang diketik
Protokol WebSocket semuanya 6, masing-masing satu kelas koneksi
Lisensi MIT

SDK adalah klien, bukan implementasi kedua dari platform. Otorisasi, persahabatan, hak, keanggotaan kamar, validasi skor, hasil permainan, dan anggaran penyimpanan tetap otoritatif server persis seperti yang didokumentasikan pada halaman di bawah ini — SDK menampilkan jawaban server dan batasan yang dipublikasikan daripada memutuskan atau menyimpannya dalam cache.

Halaman ini adalah panduan integrasi. Dokumentasi paket lengkap ada di repositori di bawah Packages/com.starhermit.sdk/Documentation~.

Persyaratan

  • Unity 2021.3 LTS atau lebih baru, tingkat kompatibilitas API Standar .NET 2.1, C# 9.
  • Mono dan IL2CPP, dengan pengupasan terkelola dari Dinonaktifkan hingga Tinggi (paket dikirimkan sendiri Runtime/link.xml).
  • Tidak ada refleksi, tidak ada pembuatan kode dinamis, tidak ada plugin asli wajib.

Setiap modul dikompilasi untuk setiap target pembangunan. Jika target benar-benar tidak memiliki kemampuan – tidak mikrofon di server tanpa kepala, tidak ada header jabat tangan di browser — panggilan muncul StarhermitFeatureUnavailableException dengan kandang Reason, daripada gagal dalam build atau menonaktifkan fitur yang tidak terkait.

Memasang

Manajer Paket → Tambahkan paket dari URL git, atau entri masuk Packages/manifest.json. Paketnya berada di subfolder repositori, jadi dibutuhkan URL path=:

{
  "dependencies": {
    "com.starhermit.sdk": "https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk"
  }
}

Sematkan rilis dengan menambahkan #<tag-or-commit>:

https://github.com/HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk#v0.1.0

Unity berusaha keras git, jadi repositori pribadi hanya terselesaikan jika git editor dapat mengautentikasi non-interaktif — kunci SSH (git@github.com:HypeDriven/starhermit-unity-sdk.git?path=/Packages/com.starhermit.sdk) atau a pembantu kredensial yang dikonfigurasi. Jalur lokal atau registri tercakup bekerja dengan cara yang sama. Impor memodifikasi no pengaturan proyek dan tidak melakukan akses jaringan.

Buat klien

using Starhermit;

var client = StarhermitClient.Create(new StarhermitOptions
{
    ApiBaseUri = new Uri("https://api.starhermit.com/api/v1/"),
    GameSlug   = "83fd04b1-3cbe-4b09-a251-3733ad4b9d94",
    TokenStore = myPlatformSecureStore,
    LogLevel   = StarhermitLogLevel.Warning
});

await client.InitializeAsync();               // loads a stored session, refreshes it if expired
var me = await client.Me.GetProfileAsync();

Create tidak melakukan I/O. Tidak ada yang menyentuh jaringan sampai Anda menginisialisasi, memanggil layanan atau membuka a koneksi. Basis WebSocket berasal dari ApiBaseUri (wss://<host>/ws/v1/) kecuali Anda menyetelnya WebSocketBaseUri dirimu sendiri.

StarhermitClient adalah IDisposable: pembuangan membatalkan permintaan dalam penerbangan, menutup setiap koneksi itu dibagikan, menghentikan detak jantung dan melepaskan audio. Tidak ada keadaan statis yang bisa berubah dalam paket, jadi dua klien dapat berjalan berdampingan melawan lingkungan yang berbeda, dan satu klien bertahan dalam banyak adegan.

Sebuah game yang diterbitkan di platform dilayani dari https://<slug>.starhermit.com dengan /api Dan /ws diproksi dengan asal yang sama (lihat Permainan GitHub). Build WebGL memublikasikannya cara harus menunjuk ke asalnya sendiri sehingga browser membuat panggilan dengan asal yang sama:

ApiBaseUri = new Uri("https://83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com/api/v1/") // your game's uid

Untuk backend lokal, AllowInsecureTransport = true izin http/ws. Konstruksi klien menolak a alamat non-HTTPS tanpanya, dan validasi build editor akan menggagalkan build pemain non-pengembangan itu masih disetel. Itu tidak pernah menonaktifkan validasi sertifikat.

Masuk

Tiga jenis kredensial yang dijelaskan dalam Otentikasi adalah tipe terpisah secara terpisah disimpan di SDK; tidak ada yang bisa menggantikan yang lain.

OAuth — SDK membuka URL otorisasi melalui injeksi IStarhermitOAuthBrowser dan selesai pertukaran:

var session = await client.Auth.SignInWithOAuthAsync("google");

Menggunakan BuildAuthorizeUri(provider) plus CompleteOAuthAsync(...) alih-alih ketika platform Anda menyerahkannya mengalihkan kembali melalui tautan dalam atau pipa browser tertanamnya.

Kunci publik — aliran tanpa kata sandi untuk pemutar tertanam, konsol, dan server khusus (lihat Server Khusus + Orientasi Pemain Tertanam). Jenis kunci yang didukung adalah Ed25519, ECDSA-P256 Dan RSA-PSS; SDK tidak pernah membuat atau menyimpan a kunci pribadi, itu memanggil suntikan IStarhermitSigner:

var session = await client.Auth.SignInWithPublicKeyAsync(signer);   // or (), using Options.Signer

Detail kontrak perlu diketahui. Penyebaran ini memverifikasi tanda tangan tantangan terhadap miliknya sendiri Serialisasi tantangan PascalCase, sedangkan JSON yang Anda terima adalah camelCase - serialisasi ulang tanggapannya tidak akan pernah terverifikasi. StarhermitChallenge.CanonicalPayload mereproduksi byte yang tepat untuk tanda tangan, jadi tanda tangan linting tangan harus melakukan hal yang sama.

Token peluncuran permainan — dicetak per game dan dipagari ke permukaan game itu:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();
var fenced = chess.WithLaunchToken();     // subsequent calls authorise with the launch token

Mencetak token peluncuran tidak pernah menggantikan sesi akun. Kredensial mana yang dibawa oleh permintaan ditentukan oleh jalur permintaan, bukan oleh layanan yang Anda hubungi.

Penyegaran token akses dikoordinasikan: a 401 membeli paling banyak satu penyegaran dan satu pemutaran ulang, dan secara bersamaan penelepon menunggu penyegaran yang sama daripada memulai beberapa kali — dengan token penyegaran yang berputar, sedetik pertukaran akan mencabut keluarga dan mengeluarkan pemain tersebut. Penolakan yang pasti muncul SessionExpired sekali; kegagalan transportasi membuat sesi tetap utuh.

Menerima persyaratan saat ini

Periksa penerimaan sebelum memulai detak jantung, permintaan permainan, atau soket. Versi 0.1.0 memiliki AcceptTermsAsync, tetapi bidang profil dan penemuan istilah yang lebih baru menggunakan dukungan JSON mentahnya:

var profile = await client.Me.GetProfileAsync(ct);
var needsAcceptance = profile.RawJson["termsAcceptanceRequired"].AsBooleanOrDefault();
var terms = await client.Raw.SendForJsonAsync(new StarhermitRequest("GET", "terms"), ct);
var textToDisplay = terms["text"].AsStringOrNull();
var displayedHash = terms["hash"].AsStringOrNull();
// Display textToDisplay. Retain displayedHash for this displayed revision.
// Only in the user's Accept handler, using an account session:
// await client.Me.AcceptTermsAsync(displayedHash, ct);

Jangan gunakan label revisi sampel seperti terms-2026-08: hanya hash saat ini dari API saja diterima. Pada 409, ambil dan tampilkan teks baru untuk penerimaan lainnya. Pada 403 terms_acceptance_required, selesaikan penerimaan sebelum mencoba lagi; token peluncuran pemain juga dapat mengirimkan penerimaan melalui API setelah persetujuan eksplisit. Melihat Profil untuk aliran lengkap.

Sesi ujung ke ujung

Siklus hidup dari panduan integrasi, di C#:

var chess = client.Games.ForSlug("83fd04b1-3cbe-4b09-a251-3733ad4b9d94");
await chess.AcquireLaunchTokenAsync();

var ticket = await chess.EnqueueMatchmakingAsync();
while (!ticket.IsMatched)
{
    await Task.Delay(TimeSpan.FromSeconds(2), ct);
    ticket = await chess.GetMatchmakingAsync(ct) ?? ticket;
}

using var game = client.CreateGameConnection(ticket.SessionId!.Value, "83fd04b1-3cbe-4b09-a251-3733ad4b9d94", useLaunchToken: true);
game.FrameReceived       += frame => ApplyServerState(frame);
game.AchievementUnlocked += unlock => ShowToast(unlock);
game.PresenceChanged     += (userId, online) => UpdateOpponentDot(userId, online);
game.ErrorReceived       += message => ShowError(message);

await game.ConnectAsync(ct);
await game.SendCommandAsync(writer =>
{
    writer.Write("type", "move");
    writer.Write("from", "e2");
    writer.Write("to",   "e4");
}, ct);

SendCommandAsync membungkus muatan sebagai {"type":"cmd","data":…}; SendRealtimeInputAsync adalah jalur dengan kecepatan terbatas untuk input berkelanjutan. Koneksi tidak mencentang logika permainan, memprediksi secara otoritatif nyatakan, mengarang hasil, atau mengirim ulang perintah yang mungkin non-idempoten setelah ambigu putuskan sambungan — server tetap menjadi satu-satunya otoritas atas apa yang terjadi.

Setiap koneksi berbagi satu mesin status: Disconnected, Connecting, Connected, Reconnecting, Closing, Faulted, dengan StateChanged, Closed Dan Faulted acara, antrian keluar yang dibatasi dengan tekanan balik yang eksplisit, dan pengiriman yang dipesan. Penyambungan kembali menggunakan backoff yang terputus-putus, memperoleh kembali arus token sebelum setiap upaya, dan berhenti untuk selamanya pada otorisasi atau penutupan kebijakan daripada menggedor pintu hingga platform tertutup. Tidak pernah diasumsikan bahwa keanggotaan dapat bertahan dari kesenjangan: masing-masing protokol mengambil kembali atau bergabung kembali saat menyambung kembali.

Kredensial naik Authorization header di mana platform mengizinkannya dan ?access_token= pada /ws/** jika tidak, karena browser tidak dapat menyetel header jabat tangan. Token kueri dihapus dari setiap log.

Async, threading, dan Persatuan

Setiap operasi I/O kembali Task dan mengambil jejak CancellationToken. Tidak ada async void metode dan tidak ada metode publik yang memblokir thread panggilan.

Callback peristiwa dan kemajuan diposting ke konteks sinkronisasi tempat klien dibuat — jadi jika Anda membuatnya di thread utama Unity, seorang penangan mungkin akan menyentuhnya GameObjects secara langsung. Server tanpa kepala dapat melewati hop dengan options.CallbackDispatcher = ImmediateCallbackDispatcher.Instance. Panggilan balik adalah dipesan per koneksi, dan penangan yang melakukan pelemparan dilaporkan ke diagnostik tanpa menghentikan menerima lingkaran.

StarhermitLifecycle.Attach(client) menjembatani peristiwa aplikasi Unity: kehadiran detak jantung dijeda dalam penangguhan dan segera mengirimkan resume, dan klien dibuang saat berhenti tanpa sinkron kerja jaringan.

Model tidak pernah merujuk GameObject, MonoBehaviour atau sebuah adegan. StarhermitTextures mengkonversi avatar dan byte cover-art menjadi a Texture2D di thread utama — penelepon memiliki hasilnya dan harus menghancurkannya.

Kesalahan, percobaan ulang, dan penomoran halaman

Status Pengecualian
400 / 422 StarhermitBadRequestException, StarhermitValidationException (kesalahan bidang dikunci berdasarkan nama kabel)
401 StarhermitAuthenticationException
402 StarhermitEntitlementException
403 StarhermitAuthorizationException
404 StarhermitNotFoundException
409 StarhermitConflictException
429 StarhermitRateLimitException (membawa RetryAfter)
5xx StarhermitServerException

Masing-masing membawa status, milik server {"error":"..."} pesan, kode apa pun yang dapat dibaca mesin, permintaan identitas, Retry-After, header yang disunting, dan badan yang disunting dengan batasan ukuran. Permintaan yang tidak pernah sampai API meningkat StarhermitTransportException atau StarhermitTimeoutException — kegagalan transportasi tidak pernah terjadi didandani sebagai respons API. Pembatalan selalu muncul sebagai OperationCanceledException.

Percobaan ulang dibatasi, gelisah, terhormat Retry-After hingga batas tertentu, dan terbatas pada kegagalan sedetik upaya dapat bertahan: kesalahan koneksi, batas waktu habis, 408, 429 dan sementara 5xx. 403, 404, 409 dan kegagalan validasi tidak pernah dicoba ulang, dan POST hanya dicoba ulang jika ikut serta AsIdempotent. Anggaran percobaan ulang di seluruh proses menghentikan beberapa klien mengubah satu pemadaman menjadi badai.

Daftar titik akhir kembali StarhermitPage<T> membawa metadata paging milik server sendiri, plus malas enumerasi yang mengambil halaman hanya saat halaman tersebut digunakan:

await foreach (var title in client.Software.EnumerateTitlesAsync(query, cancellationToken: ct)) { … }

Unduhan mengalir ke an IStarhermitFileStore melalui file sementara, verifikasi SHA-256 yang disediakan dan dipromosikan secara atom; OpenDownloadAsync laporan IsResumed hanya untuk yang nyata 206, karena menambahkan seluruh file ke sebagian akan merusaknya sambil tetap melewati pemeriksaan panjangnya.

Menyimpan kredensial

Paketnya tidak mengirimkan toko yang mengklaim aman. Standarnya adalah di dalam memori; keikutsertaan EncryptedFileTokenStore (AES-CBC dengan HMAC-SHA256 melalui kunci yang disediakan aplikasi Anda) didokumentasikan sebagai kebingungan saat istirahat, bukan gantungan kunci. Kabel IStarhermitTokenStore ke keamanan platform itu sendiri penyimpanan — Gantungan Kunci, Keystore, penyimpanan pengguna SDK konsol. PlayerPrefs tidak pernah disajikan sebagai aman.

Token, token penyegaran, kunci pribadi, rahasia klien, dan kunci pemanggilan tidak pernah diserialkan menjadi a ScriptableObject, sebuah adegan, Resources, log, pesan pengecualian, peristiwa telemetri, atau build artefak. StarhermitSettings hanya menyimpan default proyek non-rahasia: alamat, slug, level log, batas waktu dan bendera pengembangan.

Redaksi bersifat struktural — berdasarkan header, parameter kueri, dan nama anggota JSON, pada setiap kedalaman — jadi a kredensial yang belum pernah didengar oleh versi SDK ini masih dihilangkan dari log, pengecualian, dan telemetri. Fragmen URL dihilangkan seluruhnya. Tidak ada telemetri yang dikumpulkan secara default; wastafel yang disuntikkan menerima nama acara, id operasi, durasi, kelompok status, jumlah percobaan ulang, id permintaan dan hasil, tidak pernah URL, badan atau konten pemutar.

Saat platform mengirimkan sesuatu yang baru

Model tidak dapat diubah dan tetap menggunakan JSON tempat model tersebut diurai, sehingga bidang ditambahkan ke penerapan setelahnya Versi SDK ini masih dapat dibaca, dan titik akhir yang tidak diketik oleh versi ini masih dapat dipanggil kredensial, percobaan ulang, dan redaksi yang sama seperti panggilan yang diketik:

var value = profile.RawJson["shippedAfterThisSdk"].AsStringOrNull();

var json  = await client.Raw.SendForJsonAsync(
    new StarhermitRequest("GET", "some/new/route").WithQuery("page", 1), ct);

Bingkai soket dikirimkan berdasarkan diskriminator tipenya dengan fallback bingkai tidak diketahui yang mempertahankan payload, string enum yang tidak diketahui disimpan sebagai string, bukan dipaksa, dan tingkat privasi yang tidak diketahui dibaca sebagai paling interpretasi pribadi. Optional<T> membedakan dihilangkan, eksplisit null dan nilai, yang merupakan apa yang dibutuhkan oleh tubuh PATCH.

client.GetDiagnostics() mengembalikan status koneksi, kedalaman antrian, jumlah koneksi kembali, masa berlaku token, jam kesegaran, permintaan dalam penerbangan, percobaan ulang yang dilakukan, dan kesalahan terakhir yang disunting — cuplikan untuk dilampirkan ke a laporan bug.

Sampel

Delapan sampel dikirimkan bersama paket dan dikompilasi di CI, sehingga tidak dapat menyimpang dari API mereka demonstrasikan: Otentikasi dan Profil, Teman dan Obrolan, Game Menjodohkan, Waktu Nyata dan Relai, Suara, Layanan Katalog, Alat Penerbit, dan Server Khusus.

Status verifikasi

Rangkaian SDK sendiri (144 pengujian kedap udara di bawah dotnet test, file yang sama berjalan sebagai Unity EditMode pengujian) dan manifes cakupan yang dihasilkan yang gagal dalam pembangunan ketika operasi API tidak memiliki pemetaan SDK berjalan pada setiap perubahan; lima tes lebih lanjut membaca penerapan langsung ketika diarahkan ke salah satunya, dan dilewati sebaliknya. Matriks editor dan IL2CPP build pemain untuk Linux, Android, dan WebGL ditentukan di CI tetapi memerlukan build farm berlisensi, jadi tabel platform di atas menyatakan dukungan yang dimaksudkan — perlakukan target sebagai memenuhi syarat hanya setelah Anda membangunnya itu sendiri.
