JavaScript SDK (permainan peramban)

starhermit-sdk.js adalah klien file tunggal, bebas ketergantungan untuk game browser diterbitkan di StarHermit. Ia membaca token peluncuran, terus memperbaruinya, dan menyediakan bantuan untuk hal-hal umum API token peluncuran cakupan game: identitas, penyimpanan cloud, pengaturan dan kontrol per pemain, undangan, perjodohan, sesi dan soket gameplay, pencapaian, papan peringkat, pemutaran ulang, obrolan, suara dan ruang waktu nyata.
Mengajukan docs/sdk/starhermit-sdk.js — salin ke dalam game Anda tanpa perubahan
Global window.StarHermit (Juga module.exports di bawah Node, untuk pengujian)
Ketergantungan tidak ada — ia menggunakan milik browsernya sendiri fetch, WebSocket dan (untuk membaca simpanan terkompresi) DecompressionStream
Garis dasar API REST v1 dan WebSocket v1, hanya permukaan token peluncuran

SDK adalah klien, bukan implementasi kedua dari platform. Skor dan pencapaian terbuka hanya ditulis oleh server game (hasil skrip atau pesan kontrol kontainer) — klien tidak pernah bisa mempostingnya, dan SDK hanya membacanya. Segala sesuatu yang lain tetap otoritatif server persis seperti yang didokumentasikan di halaman API.

Pembantu yang diautentikasi tidak membuat permintaan API tanpa token peluncuran. Pembacaan umumnya terselesaikan untuk null, [], atau peta kosong; menulis mungkin teratasi null/false dan penyelamatan yang didebounce tidak dapat dilakukan dengan segera nilai kembalian. Soket tetap terputus. Simpan kemajuan mandiri dalam memori jika pemain memilih pemutaran yang tidak terlacak. Panggilan signOut() sebelum beralih dari permainan akun ke mode itu sehingga perpanjangan berhenti.

Memasang

Salin file di samping skrip statis game Anda yang lain — ke mana pun build Anda mengirimkannya — dan muat itu sebelum kode Anda sendiri:

<script src="starhermit-sdk.js"></script>
<script>
  StarHermit.init();          // as early as possible: it reads and strips the token from the URL fragment
</script>

Panggilan init() sekali, sebelum router apa pun bersentuhan location.hash. Pilihan: init({ base, gameId, autoRefresh, launcherUrl }) — base menunjuk panggilan REST di tempat asal yang resmi selama pengembangan lokal (game yang dihosting platform menggunakan asal yang sama). gameId, jika disediakan, harus cocok UUID yang dihosting untuk masuk; halaman lokal/eksternal bukan asal masuk game yang valid. autoRefresh: false meninggalkan pembaruan token ke game itu menjalankan rantainya sendiri, dan launcherUrl mengesampingkan di mana relaunch() mengirimkan pemain (default https://dashboard.starhermit.com/).

Masuk dan identitas

Membutuhkan Panggilan
Apakah ada pemain yang masuk? StarHermit.signedIn, StarHermit.userId, StarHermit.slug
Bereaksi terhadap proses masuk/keluar/kedaluwarsa StarHermit.on('auth', ({ signedIn, reason }) => …)
Tunjukkan a Masuk tombol hanya kapan StarHermit.canSignIn() (berlaku pada subdomain UUID game tanpa token); di klik StarHermit.signIn()
Nama pemain/avatar await StarHermit.profile() → { userId, username, nickname, displayName }; StarHermit.avatarUrl()
Teman-teman await StarHermit.friends()

SDK menangani kedua bentuk peluncuran — #game_token=<jwt>[&session_id=…] dari perpustakaan atau an mengundang, dan #access_token=<jwt> kembali dari proses masuk langsung — dan memperbarui token melalui POST /api/v1/games/{slug}/launch-token sebelum habis masa berlakunya (lihat meluncurkan token). Nama tampilan adalah profil nickname; /api/v1/me tidak dapat dijangkau dengan token peluncuran.

Simpanan cloud

Slot permainannya adalah game:<slug> (katalog: menyimpan dari dalam game); SDK membangun jalur, meng-zip payload dan menangani /info memeriksa.

const remote = await StarHermit.loadJSON();          // null: empty slot, signed out — or a failed read
if (StarHermit.saveLoadFailed()) showSyncError();    // tell those apart when it matters
else if (remote && isNewer(remote, local)) adopt(remote);

StarHermit.saveJSON(state);                          // debounced (2 s) checkpoint upload
addEventListener('pagehide', () => StarHermit.flushSave(true));   // keepalive flush
StarHermit.on('saved', ok => setSyncIndicator(ok));

Muat sebelum Anda menyimpan. Bandingkan dan adopsi salinan cloud sebelum tulisan apa pun dapat dijangkau saveJSON — termasuk pengaturan, nama panggilan atau pos pemeriksaan yang ditulis saat boot — atau salinan lokal yang sudah basi menimpa penyimpanan baru yang dibuat di perangkat lain. Tahan penyimpanan awal hingga beban permulaan selesai.

SDK melindungi separuh lainnya dari perlombaan itu: ketika pembacaan gagal (kesalahan jaringan atau server, misalnya berlawanan dengan slot kosong) ia terbenam saveLoadFailed(), memancarkan saveerror, dan menolak menulis sampai /info memastikan slotnya kosong atau lebih baru loadSave() berhasil. Penulisan yang ditolak teratasi false dan memancarkan saved dengan false.

Penulisan setelah pemuatan bersifat kondisional. SDK mengingat versinya (ETag) dari menyimpannya terakhir membaca atau menulis dan mengirimkannya kembali, sehingga penulisan hanya mendarat pada penyimpanan yang menjadi dasarnya — atau, untuk sebuah slot itu kosong, hanya selagi masih ada. Ketika perangkat lain disimpan di antaranya, penulisan ditolak (412): SDK mengeluarkan saveconflict, set saveConflicted(), dan menolak penulisan lebih lanjut sampai a loadSave() memungkinkan game menggabungkan atau mengadopsi penyimpanan yang lebih baru. Sebuah permainan yang tidak pernah memuat tulisan tanpa syarat, seperti sebelumnya.

StarHermit.on('saveconflict', async () => {
  const remote = await StarHermit.loadJSON();       // lifts the block
  StarHermit.saveJSON(merge(remote, local));        // conditional on the version just loaded
});

Tingkat yang lebih rendah: loadSave() / writeSave(text) untuk string mentah, saveInfo() untuk { exists, sizeBytes, updatedAt, etag }.

Laporan kerusakan dan bug

Pemain dapat melaporkan masalah dari dalam game; pemilik melakukan triase melalui melaporkan API.

await StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', {
  clientVersion: '1.4.2',
  attachments: [{ fileName: 'state.json', contentType: 'application/json', data: JSON.stringify(state) }],
});
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports
const mine = await StarHermit.myReports();               // [{ id, kind, status, title, ... }]

report(kind, title, description, opts) adalah bentuk umum (reportBug Dan reportCrash memperbaiki baik hati). captureCrashes file paling banyak satu laporan per pesan berbeda dan tiga laporan per halaman dimuat, jadi a crash loop tidak dapat menghabiskan jatah harian pemain (20 per game secara default). Tanyakan kepada pemain sebelumnya melampirkan sesuatu yang bersifat pribadi.

Pengaturan dan kontrol

Membutuhkan Panggilan
Preferensi per pemain (volume, preset grafis, bahasa, aksesibilitas…) getSettings(), getSetting(key), setSetting(key, value), patchSettings({…}) (a null nilai menghapus kunci), deleteSetting(key), clearSettings()
Pengikatan keyboard dinyatakan dalam starhermit.txt sebagai control.<action>=… await loadBindings(defaults) → { action: codes[] } dengan penggantian pemain diterapkan
Layar yang mengikat ulang getControls(), setControl(action, codes), setControls(bindings), resetControls()

Rute keydown melalui event.code dan ikatan dari loadBindings. Melihat tambahkan kontrol ke game Anda dan itu starhermit.txt tampak.

Untuk menu Grafik, graphics-options.js berada di atas panggilan pengaturan: itu secara otomatis mendeteksi preset kualitas, mempertahankan pilihan pemain localStorage dan per game mereka pengaturan, dan mengirimkan panel yang sudah jadi. Melihat pilihan grafis dengan kualitas terdeteksi otomatis.

Untuk bagian Audio, lihat opsi audio dengan batas suara yang terdeteksi secara otomatis: kontrol volume dan suara yang disarankan, yang murni audio-options.js pembantu, dan batas pemutaran yang diberlakukan oleh mixer Anda.

Untuk bagian Bahasa, lihat lokalkan game Anda dan tambahkan pengaturan bahasa: paket terjemahan sepuluh bahasa, bendera SVG, tata letak kanan ke kiri, dan a ui.language preferensi disimpan dengan pengaturan permainan. Menggunakan api() ketika Anda perlu menampilkan kegagalan baca/tulis pengaturan.

Multipemain, undangan, dan sosial

Sesi gameplay, perjodohan, pencapaian game, papan peringkat, dan tayangan ulang memerlukan server (naskah atau wadah). Kamar waktu nyata dan teman tidak. Sesi obrolan dan suara memerlukan keanggotaan percakapan yang sesuai.

Daerah Panggilan
Sesi mySessions(), getSession(id), sessionRecovery(id), leaveSession(id), startAiSession(); StarHermit.launchSessionId setelah peluncuran undangan
Soket gameplay const conn = connect(sessionId, { onGame, onError, onPresence, onAchievement, onResumed, onAbandoned, onOpen, onClose, onAuthLost }), Kemudian conn.send(data); terhubung kembali dengan back-off, memperbarui token terlebih dahulu, dan berhenti pada penutupan normal/kebijakan/oversize (1000/1008/1009), 4403/4404, atau ketika perpanjangan ditolak (lihat menghubungkan kembali)
Penjaruman queues(), joinQueue([keys]), matchStatus(), cancelMatch(), waitForMatch(opts)
Undangan sendInvite(toUserId[, sessionId]) (dengan a sessionId teman itu bergabung dalam sesi lari itu), invites(), acceptInvite(id), declineInvite(id); inviteLink(query) untuk tautan berbagi
Posting lari ke papan peringkat Anda submitScores({ boardKey: number }) → kunci yang diterima (lihat papan peringkat pemain tunggal)
Prestasi dan papan peringkat (hanya baca) achievements(), linkedAchievements(otherSlug), leaderboards(), leaderboard(key, opts), leaderboardEntries(boardId, opts); membuka kunci roti panggang melalui on('achievement', …)
Pemutaran ulang myReplays(limit), getReplay(id)
Sesi obrolan chatMessages(id), sendChat(id, text), pollChat(id, onMessages, intervalMs) — REST dan polling hanya untuk token peluncuran
Ruang suara / waktu nyata StarHermit.voice.* (REST; sinyal WebRTC diserahkan pada permainan), StarHermit.realtime.* (kamar plus ws/v1/realtime)

Apa pun yang belum dibungkus hanya berjarak satu panggilan: StarHermit.api(path, { method, body }) mengirimkan sebuah permintaan JSON yang diautentikasi (terselesaikan null pada 404/204 atau saat keluar, ditolak { status, message } pada kegagalan lainnya, perbarui sekali pada 401).

Papan peringkat pemain tunggal

Klien tidak pernah bisa memposting skor — hanya server game yang bisa — jadi game pemain tunggal memerlukan a skrip platform kecil untuk memiliki papannya. score-script.js adalah satu: salin berikutnya ke game Anda, nyatakan masuk starhermit.txt sebagai server=score-script.js, dan edit saja itu BOARDS blok, yang mencantumkan setiap papan sebagai Anda buat itu:

var BOARDS = {
  "high-score": { "name": "High score", "scoreType": "integer", "sortDirection": "desc", "minScore": 0, "maxScore": 1000000 }
};

Saat lari berakhir, poskan dan tunjukkan tempat pemain:

const accepted = await StarHermit.submitScores({ 'high-score': total });   // [] when signed out or refused
if (accepted.includes('high-score')) {
  const board = await StarHermit.leaderboard('high-score', { pageSize: 100 });
  const me = board.items.find(e => e.userId === StarHermit.userId);
  showRank(me && me.rank);
}

submitScores membuka sesi latihan (POST .../sessions/ai), mengirimkan {type:'result', scores} pada soket gameplay, dan menyelesaikan kunci papan yang diterima skrip; itu juga memancarkan scores dengan daftar itu. Skrip menjatuhkan skor yang bukan merupakan angka yang sesuai dengan jenis papan atau berada di luar angka tersebut minScore/maxScore, memposting sisanya melaluinya scores kembali, dan mengakhiri sesi. Klien masih melaporkan hasilnya. Skor yang diciptakan dalam rentang bisa lulus; papan ini cocok untuk santai bermain. Untuk kompetisi, validasi proses dalam skrip atau wadah sebelum memberikan penghargaan. Pengakuan mencantumkan kunci yang diterima skrip; ini bukan bukti bahwa setiap dewan aktif atau ada yang terbaik dari diri mereka sendiri telah disimpan. Melihat kepercayaan dan ketersediaan.

Menghubungkan kembali dan token kedaluwarsa

Soket membawa token peluncuran di URL-nya, dan jabat tangan dengan token yang kedaluwarsa ditolak sebelumnya pemutakhiran — browser hanya melaporkan kode tutup 1006, persis seperti penurunan jaringan. Jadi gagal menyambungkan kembali mungkin merupakan kegagalan autentikasi, dan mencoba kembali URL yang sama tidak akan pernah dapat dipulihkan. Pembaruan hanya berfungsi selama token saat ini valid dan dalam waktu 12 jam sejak peluncuran awal; setelah itu hanya peluncur dapat membuat token baru.

connect() menangani ini sendiri: sebelum setiap penyambungan kembali, token akan diperbarui POST /api/v1/games/{slug}/launch-token (kecuali jika diperbarui sejak soket dibuka) dan dibuka kembali dengan yang baru. Kesalahan jaringan atau server saat memperbarui mundur dan memperbarui lagi — tidak pernah terjadi membuka kembali URL lama. Jika perpanjangan ditolak atau token telah habis masa berlakunya, SDK akan keluar (auth dengan reason: 'expired'), berhenti menyambung kembali dan menelepon onAuthLost():

const conn = StarHermit.connect(sessionId, {
  onGame, onClose,
  onAuthLost: () => showReconnectPanel(),   // e.g. "Session expired — Back to StarHermit"
});
backButton.onclick = () => StarHermit.relaunch();

relaunch() mengirim pemain kembali untuk mendapatkan token peluncuran baru: melalui masuk saat game dibuka seperti itu (StarHermit.launchKind === 'sign-in'), jika tidak, ke peluncur. Di dalam peluncur bingkai permainan itu menavigasi jendela atas, yang diizinkan browser hanya dari isyarat pengguna, jadi sebut saja dari satu klik; itu kembali false ketika navigasi ditolak.

Browser dapat menyembunyikan sesi yang telah selesai, persyaratan, keanggotaan, atau kegagalan build sebagai 1006. Sebelum sebuah coba lagi otomatis, connect() memeriksa status sesi melalui REST dan, kapan opts.build disediakan, membandingkannya dengan info game. onUnavailable(error) menerima kegagalan REST permanen atau berakhir sesi; onTermsRequired(body) meminta penerimaan persyaratan eksplisit. Buat koneksi baru setelahnya menyelesaikan ini. onClose(1008) berarti koneksi tersebut digantikan atau melanggar kebijakan; jangan membukanya kembali secara otomatis.

Soket permainan Anda terbuka sendiri (realtime.socketUrl(roomId), voice.socketUrl(roomId)) membutuhkan aturan yang sama. Sebelum membukanya kembali, teleponlah renewForReconnect() dan bertindak berdasarkan hasilnya:

async function reopen() {
  const r = await StarHermit.renewForReconnect();
  if (r === 'renewed') ws = new WebSocket(StarHermit.realtime.socketUrl(roomId)); // fresh token in the URL
  else if (r === 'retry') setTimeout(reopen, backoff());                         // renewal itself failed
  else if (r === 'terms-required') showTermsPanel();                              // explicit acceptance
  else showReconnectPanel();                                                     // 'relaunch'
}

Perpanjangan serentak berbagi satu permintaan. terms-required mempertahankan token pemain dan memancarkannya termsrequired; menampilkan getTerms() dan menelepon acceptTerms(displayed.hash) hanya pada pemain Terima tindakan, lalu coba lagi. Soket yang dikelola game Anda juga memerlukan pemeriksaan REST untuk sumber daya yang habis dan harus berhenti pada penutupan kebijakan. Melihat pemecahan masalah.

Acara

StarHermit.on(type, fn) mengembalikan fungsi berhenti berlangganan; off(type, fn) juga berfungsi.

Peristiwa Muatan
auth { signedIn, userId } saat masuk; { signedIn: false, reason } saat keluar atau habis masa berlakunya (reason: 'expired' ketika perpanjangan ditolak — penawaran relaunch())
saved true / false setelah setiap cloud menulis
saveerror { op: 'load' } setelah gagal membaca; { op: 'write', blocked: true } untuk penulisan yang ditolak
achievement pembukaan kunci didorong pada soket gameplay
scores kunci papan diterima oleh submitScores ([] ketika tidak ada yang diposting)
saveconflict { etag } ketika perangkat lain mengubah penyimpanan; muat ulang sebelum menggabungkan/menyimpan
termsrequired Kesalahan istilah dikembalikan oleh pembaruan token peluncuran; simpan token dan minta persetujuan

Menjaga salinan Anda tetap terkini

Perlakukan file sebagai file yang dijual: salin tanpa perubahan, jangan pernah mengedit salinan Anda, dan ganti secara grosir kapan pun file halaman ini berubah. Pastikan langkah pembuatan atau pengemasan Anda mengirimkannya bersamaan dengan langkah game file statis lainnya.
