Kredensial dan pengidentifikasi

Gunakan kredensial dengan hak paling rendah yang dapat melakukan tindakan tersebut. Masuk tidak menggantikan pemeriksaan sumber daya: penelepon masih memerlukan persahabatan, hak, keanggotaan, atau kepemilikan yang relevan.

API Generasi adalah dipesan dan tidak tersedia. Token tidak membuatnya dapat digunakan. Aturan khusus titik akhir pada halaman referensi diutamakan atas ikhtisar ini; kontrak SISA mengidentifikasi keluarga kredensial per operasi.

Mandat Seumur hidup bawaan Pembaruan

Token penyegaran akun 7 hari Rotasi sekali pakai; penyegaran bersamaan harus berbagi satu permintaan

Baca kembali seumur hidup. Token peluncuran pemain bukan token akun dan tidak memiliki token penyegaran. Itu tidak dapat pulih sendiri setelah habis masa berlakunya. Tawarkan login game atau kembali ke peluncur. Soket terbuka mungkin akan bertahan lebih lama dari masa berlaku token, namun penyambungan kembali memerlukan kredensial saat ini.

Peluncur memasok #game_token=<jwt>; pengembalian login game yang dihosting secara langsung #access_token=<jwt>. Baca dan hapus ini sebelum router atau skrip lain menggunakan fragmen tersebut. Dekode klaim hanya untuk membuat URL dan menampilkan identitas; API memvalidasi kredensial.

Menggunakan Authorization: Bearer <token> untuk REST. Soket browser menggunakan yang baru ?ticket= dari POST /api/v1/realtime/connection-tickets, atau didukung ?access_token=. Tiket mewarisi cakupan pemanggil dan tidak memberikan akses ke sumber daya lain. Jangan pernah menempatkan kredensial akun di akun Anda membangun publik atau meneruskannya ke URL game. Melihat otentikasi.

Metode autentikasi penting

Sesi akun yang diautentikasi OAuth dapat mendaftarkan kunci, mencabut kunci lain, mengubah email akun, dan menghapus identitas penyedia. Sesi akun kunci publik dapat menggunakan API akun biasa dan mencabutnya memiliki kunci melalui /me/public-keys/current, tetapi tidak dapat mengelola kredensial lainnya. Token peluncuran tidak dapat mengelola kunci akun, meskipun dibuat dari sesi kunci publik.

Penerimaan persyaratan saat ini adalah tindakan pemain yang didukung oleh akun dan meluncurkan token. Tampilkan dokumen dan kirimkan hashnya hanya pada penerimaan eksplisit.
