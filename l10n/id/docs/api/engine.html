Mesin

Di mana mendapatkan mesin StarHermit, runtime yang diputar permainan skrip. API platform adalah tempat untuk menemukan rilis: ia mencantumkan setiap rilis, menyatakan mana yang dicabut, dan memberikan URL dan hash dari setiap file rilis. Bacaan bersifat anonim.

URL Dasar: https://api.starhermit.com. Semua rute berada di bawah /api/v1/....

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/engine/releases Anonim Setiap rilis, versi terbaru terlebih dahulu, termasuk yang dicabut
MENDAPATKAN /api/v1/engine/releases/{version} Anonim Satu rilis dengan versi persisnya (X.Y.Z), atau 404 
{"releases": [{
  "version": "1.37.0", "api": {"major": 1, "minor": 37}, "revoked": false, "date": "2026-11-05T13:04:04Z",
  "web": {"base": "https://wiki.starhermit.com/engine/1.37.0/", "manifestIntegrity": "sha384-<SRI hash>"},
  "native": {"linux-x86_64": {
    "manifestUrl": "https://wiki.starhermit.com/engine/1.37.0/native/linux-x86_64/native.json",
    "manifestSha256": "<SHA-256 of native.json>"}}
}]}

GET /api/v1/engine/releases/{version} menjawab satu objek tersebut tanpa releases pembungkus. URL mengarah ke wiki.starhermit.com untuk rilis terkini dan di engine.starhermit.com untuk yang lebih tua; gunakan sebagaimana yang diberikan.

  • api adalah API host yang ditawarkan rilis. Jurusnya adalah jurusan rilis dan engine.api sebuah permainan menyatakan; minornya bertambah seiring bertambahnya anggota (permainan dapat memerlukannya engine.minor).
  • revoked: true dilengkapi dengan a revokedReason. Rilis yang dicabut tetap terdaftar sehingga klien dapat mengetahui alasannya mereka menolaknya.
  • web adalah null untuk rilis tanpa runtime web. manifestIntegrity adalah hash SRI web waktu proses manifest.json, nilai yang disematkan pada halaman pemuat.
  • native memiliki satu entri per platform (windows-x86_64, linux-x86_64, macos-x86_64, macos-aarch64), atau adalah {}. manifestSha256 adalah hex SHA-256 dari platform itu native.json; periksa sebelum mempercayai daftar file di dalamnya.

Kedua rute mengirim Cache-Control: public, max-age=60 dengan sebuah ETag dan menjawab 304 ke pencocokan If-None-Match. Jika platform belum membaca daftar rilis sejak dimulai, mereka menjawab 503 dengan Retry-After.

Rilis yang dipublikasikan tidak pernah berubah: perbaikan adalah versi berikutnya. Mesinnya tutorial menjelaskan rilis terbaru; API ini mengatakan yang mana itu.

Unduh mesinnya

Pengembang mengunduh runtime asli rilis untuk menulis, memeriksa, mengemas, dan memainkan game. Pemain melakukannya tidak ada: klien StarHermit dan halaman game mengambil rilis pin game.

  1. Tanyakan API untuk rilis, yang terbaru, atau yang disematkan game Anda:

    curl -s https://api.starhermit.com/api/v1/engine/releases/1.37.0

  2. Ambil platform Anda native.<platform>.manifestUrl, ambil itu native.json dan periksa SHA-256 melawan manifestSha256.

  3. native.json's downloads beri nama unduhan pengembang dengan miliknya size Dan sha256. Arsip duduk di sebelah native.json: mengganti native.json di akhir manifestUrl dengan arsipnya nama. Unduh dan periksa SHA-256-nya.

Langkah-langkah yang sama seperti satu skrip (kebutuhan curl, jq Dan sha256sum; pada penggunaan macOS shasum -a 256):

version=1.37.0 platform=linux-x86_64   # or windows-x86_64, macos-x86_64, macos-aarch64
release=$(curl -fsS "https://api.starhermit.com/api/v1/engine/releases/$version")
manifest_url=$(jq -r --arg p "$platform" '.native[$p].manifestUrl' <<<"$release")
manifest_sha=$(jq -r --arg p "$platform" '.native[$p].manifestSha256' <<<"$release")
curl -fsSO "$manifest_url"
echo "$manifest_sha  native.json" | sha256sum -c -
archive=$(jq -r '.downloads | keys[0]' native.json)
curl -fsSO "${manifest_url%native.json}$archive"
echo "$(jq -r --arg a "$archive" '.downloads[$a].sha256' native.json)  $archive" | sha256sum -c -

Di PowerShell, Invoke-RestMethod membaca rilis dan Get-FileHash -Algorithm SHA256 memberikan hash untuk membandingkan. Itu tutorial mencakup membongkar dan putaran pertama.

Itu alat pengembang mandiri (penerbitan otomatis dan a server MCP pengembangan) dirilis secara terpisah dari runtime.

Integritas

Satu rantai hash mencakup setiap byte yang dijalankan klien:

  1. API memberikan SHA-256 dari rilis native.json.
  2. native.json memberikan SHA-256 dan ukuran setiap file, dan unduhan pengembangnya ada di bawah downloads.
  3. Klien StarHermit hanya mengambil bagian dari rilis yang belum dimilikinya, memeriksa masing-masing, menyatukan setiap file dan memeriksanya sebelum memindahkan rilis ke tempatnya.

Halaman pemuat game browser menyematkan waktu proses web starhermit.js Dan manifest.json dengan SRI hash, dan runtime memeriksa setiap file lain yang dimuat terhadap manifes.

Waktu proses web

Halaman pemuat game (index.html, ditulis oleh starhermit package --web) memuat starhermit.js Dan manifest.json dari https://engine.starhermit.com/engine/X.Y.Z/, dengan hash SRI yang sama dengan URL di bawah web.base. Menggunakan engine.starhermit.com di halaman pemuat mana pun yang Anda tulis sendiri: halaman itu tetap ada setiap rilis, sedangkan URL di bawah web.base hanya simpan yang terbaru dan rilis lama akan hilang dari mereka. Alat dari 1.26.0 menulis engine.starhermit.com secara default (--loader-base URL atau STARHERMIT_WEB_LOADER_BASE menimpanya). Untuk game yang dihosting yang dikemas dengan alat yang lebih lama, platform menulis ulang dua URL mesin ketika rilis tidak lagi berjalan web.base; mengemas ulang game yang dihosting di tempat lain. Rilis yang dicabut tidak dilayani dari kedua asal tersebut.

Permainan skrip di platform

Saat root game starhermit.txt menyatakan engine.version, platformnya memperlakukannya sebagai permainan skrip:

  • setiap penerbitan mencatat rilis pin file, sebagai hosting.engineVersion, dan set hosting.deployWarning (juga dalam jawaban bundel Push) ketika rilis itu tidak terdaftar atau terdaftar dicabut. Peringatan tidak pernah menghentikan publikasi.
  • setiap halaman game yang dihosting disajikan dengan Kebijakan Keamanan Konten yang hanya menerima skrip dari dua asal mesin (dan mesin itu sendiri blob: pekerja), jadi satu-satunya kode adalah skrip halaman permainan yang dapat dijalankan adalah mesin resmi:
default-src 'self'; script-src https://wiki.starhermit.com https://engine.starhermit.com 'wasm-unsafe-eval' blob:; worker-src blob:;
connect-src 'self' https://wiki.starhermit.com https://engine.starhermit.com; img-src 'self' blob: data:; media-src 'self' blob:;
style-src 'self' 'unsafe-inline'; font-src 'self' https://wiki.starhermit.com https://engine.starhermit.com;
frame-ancestors https://dashboard.starhermit.com; base-uri 'self'; form-action 'none'

Halaman permainan skrip tanpa versi browser (seperti halaman biasa yang diunggah oleh game khusus Windows untuk browser) tidak memerlukan skrip dan tidak terpengaruh.

Pencabutan

Pelepasan yang ditemukan tidak aman akan dicabut. Klien StarHermit tidak menginstal atau memulainya dan memberitahukan pemain, perintah pengemasan menolak mengemas game untuk itu, dan platform memperingatkan pemiliknya game yang menyematkannya saat dipublikasikan. Rilis yang dicabut selalu diikuti dengan rilis yang diperbaiki: sematkan ulang ke rilis tersebut dan mempublikasikan (lihat Pindah ke mesin yang lebih baru).
