memetik

Memetik (simbol PLK) adalah mata uang StarHermit. Pemain membelanjakannya untuk akses ke game Anda atau di barang yang Anda jual di dalamnya. Anda menerima 99% dari setiap penjualan, dan platform mendapat komisi 1%, dibulatkan menjadi Pluck keseluruhan: 1 PLK pada penjualan 1–100 PLK, 2 PLK pada 101–200, dan seterusnya. Setiap saldo dimulai dari nol.

Bagaimana pemain membeli atau mendapatkan Plucks belum diputuskan. Sampai saat ini, saldo hanya berubah melalui penjualan dan hibah operator.

Titik akhir

MENDAPATKAN /api/v1/games/{slug}/plucks/items Anonim Item aktif Anda

POS /api/v1/me/plucks/orders/{id}/confirm JWT, masuk OAuth Pemain membayar pesanan
POS /api/v1/me/plucks/orders/{id}/cancel JWT Pemain menolak perintah

Setiap transaksi menyatakan dari mana Plucksnya berasal

Setiap entri sejarah memiliki source:

  • sale.game_access: pemain membeli akses ke game.
  • sale.game_item: pemain membeli item dalam game.
  • grant: operator mengeluarkan Plucks.

Entri juga dibawa amount (ditandatangani), balanceAfter, fee, permainan, kunci item, urutan dan pihak lain. Buku besar hanya bersifat tambahan: kesalahan diperbaiki dengan transaksi baru, tidak pernah diperbaiki mengedit yang lama.

Menjual akses ke game Anda

Tetapkan harga, dan game Anda akan mengeluarkan token peluncuran hanya untuk Anda dan pemain yang membeli akses. Siapapun yang lain mendapat 402 dengan code: "purchase_required" dan itu price. Tunjukkan pada mereka cara untuk membeli.

Pembelian mengirimkan harga yang ditunjukkan kepada pemain expectedPrice. Jika Anda telah mengubah harga sejak itu, pembelian ditolak dengan 409 (code: "price_changed"), jadi tidak ada yang membayar harga yang mereka bayarkan tidak melihat. Akses bersifat permanen dan bertahan pada perubahan harga selanjutnya. Harga permainan yang gratis juga gerbang pemain yang ada.

File yang dihosting game Anda belum dipagari. Harga menahan fitur platform (masuk, sesi, penyimpanan, pencapaian), bukan pengunduhan file game browser.

Menjual barang

Game Anda tidak dapat menghabiskan Plucks pemain. Kode permainan Anda menyimpan token peluncuran pemain, jadi a token yang bisa dibelanjakan akan membuat game apa pun menguras pemainnya. Alirannya adalah:

  1. Permainanmu bertanya. POST /api/v1/games/{slug}/plucks/orders dengan { "itemKey": "sword.gold" }. Pesanan mengambil nama dan harga item saat ini, dimulai pending, dan habis masa berlakunya setelah tanggal 15 menit. Seorang pemain dapat menunggu paling banyak 20 pesanan (429, too_many_pending_orders).
  2. Pemain mengonfirmasi pada StarHermit, tidak pernah berada di dalam game Anda. Klien StarHermit menunjukkan item, harga dan permainan Anda, dan posting /me/plucks/orders/{id}/confirm. Rute itu membutuhkan akun masuk dengan penyedia OAuth, yang tidak pernah dimiliki game Anda.
  3. Anda mengirimkannya. Pemilihan GET /api/v1/games/{slug}/plucks/orders/{id} dari klien Anda sampai status adalah paid (atau cancelled, atau masa lalu expiresAt). Backend container malah bisa membaca GET /api/v1/games/{slug}/server/plucks/orders?since=<last completedAt>.

Platform mencatat penjualan; menerapkan item adalah tugas game Anda. Jadikan pengiriman idempoten dengan nomor pesanan.

POST /api/v1/games/{slug}/plucks/orders
Authorization: Bearer <launch-token>
Content-Type: application/json

{ "itemKey": "sword.gold" }

{ "id": "2b0e…", "gameId": "c115…", "itemKey": "sword.gold", "itemName": "Golden Sword",
  "price": 100, "status": "pending", "expiresAt": "2026-10-28T14:15:00Z" }

Kunci item terdiri dari 1–64 karakter a-z 0-9 . _ -; nama terdiri dari 1–80 karakter; harga adalah 1–1.000.000.000PLK. Item yang tidak aktif atau dihapus tidak dapat dipesan, dan pesanan yang sudah dibuat tetap disimpan cuplikan mereka.

Kesalahan

Status code Arti
402 insufficient_plucks Saldo pemain berada di bawah harga
402 purchase_required Token peluncuran untuk game dengan harga yang belum dibeli oleh pemain
409 price_changed expectedPrice bukan lagi harganya
409 order_cancelled Mengonfirmasi pesanan yang dibatalkan pemain
410 order_expired Mengonfirmasi setelahnya expiresAt
429 too_many_pending_orders Terlalu banyak pesanan menunggu konfirmasi

Pemilik yang membeli dari permainannya sendiri mendapat 409.

Pendapatan Anda

GET /api/v1/me/github-games/{id}/analytics/sales Dan …/analytics/monetization unit laporan, kotor, komisi platform dan pendapatan bersih Anda per hari, pemain yang membayar, konversi, dan per item total. Mereka hanya melaporkan total dan tidak pernah menyebutkan nama pembeli. Sejarah Anda sendiri di /me/plucks/transactions mencantumkan setiap penjualan.
