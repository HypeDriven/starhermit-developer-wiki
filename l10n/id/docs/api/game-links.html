Tautan eksternal

Game bermesin StarHermit (host API 1.24) dapat membuka halaman web, tetapi hanya satu halaman yang dapat dibuka oleh staf StarHermit telah menyetujui permainan Anda. Game Anda membuka tautan berdasarkan id dan tidak pernah meneruskan URL, sehingga tidak dapat ditambahkan apa pun menjadi satu.

Deklarasikan tautan Anda

Di dalam starhermit.txt:

engine.minor=24
engine.link.discord=https://discord.gg/abc
engine.link.store=https://example.com/game
  • Anda dapat mendeklarasikan hingga 16 tautan. Setiap id terdiri dari 1–32 karakter a-z 0-9 - dan mungkin hanya muncul sekali.
  • Setiap engine.link.* kebutuhan utama engine.minor=24, jadi runtime yang lebih lama menolak game tersebut.
  • Panggilan skrip Anda openLink("discord"). Runtime menunjukkan konfirmasinya sendiri, dengan tautannya host dan URL lengkap, dan membuka halaman hanya jika pemain memilih Buka.

Tautan apa yang mungkin ada

Tautan harus ada https, tanpa port, tidak user@, tidak ada alamat IP dan tidak ada nama lokal (localhost, .local, .internal). Hostnya harus ASCII, dengan nama internasional yang ditulis sebagai punycode, dan memiliki setidaknya dua label. Ini tidak boleh mengandung garis miring terbalik, spasi, garis miring yang dikodekan (%2f, %5c) atau ./.. segmen jalur. Platform ini mempertahankan bentuk kanoniknya: skema dan hostnya huruf kecil, dan / untuk jalan yang kosong. Segala sesuatu yang lain disimpan persis seperti yang Anda tulis.

Paket dengan tautan yang melanggar aturan akan ditolak saat Anda mempublikasikannya, dengan 422 invalid_link: engine.link.<id> is not an allowed link (<rule>), sebelum semuanya ditayangkan.

Tinjauan

Setiap tautan baru dimulai pending, dan runtime tidak membuka apa pun sampai staf menyetujuinya. Beberapa tautan adalah ditolak secara otomatis: penyingkat URL dan layanan pengalihan, yang tujuannya orang lain kontrol, dan pengunduhan langsung program dan arsip (.exe, .dmg, .apk, .zip dan serupa). Parameter pelacakan seperti utm_* ditandai untuk pengulas.

Persetujuan adalah milik game Anda dan URL persisnya. Versi yang lebih baru mencantumkan URL yang sama, di bawah ID apa pun, simpanlah. Mengubah URL memerlukan peninjauan baru. Staf dapat mencabut persetujuan, atau memblokir a seluruh host, kapan saja.

Lihat tautan Anda dan statusnya di GET /api/v1/me/github-games/{id}/links:

[ { "id": "discord", "url": "https://discord.gg/abc", "status": "approved", "autoReason": null, "note": null } ]

Pemeriksaan waktu proses GET /api/v1/games/{slug}/links/{id} di setiap pembukaan, dengan peluncuran pemain tanda. Jawabannya adalah { id, url, status }, Di mana status adalah approved, pending, rejected atau revoked, atau 404 link_unknown untuk id yang tidak dideklarasikan oleh manifes yang Anda terapkan.

Saat Anda mengembangkan secara lokal (--dev secara asli, atau halaman loopback di browser, tanpa peluncuran token), runtime membuka tautan yang dinyatakan di balik peringatan bahwa tautan tersebut belum ditinjau.
