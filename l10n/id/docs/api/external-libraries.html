Perpustakaan Eksternal

Menautkan perpustakaan Steam, Epic, atau GOG pengguna sehingga game eksternal mereka dapat dicantumkan, diluncurkan, dan dilacak. Semua rute memerlukan JWT.

URL Dasar: https://api.starhermit.com. Semua rute berada di bawah /api/v1/....

Menautkan dan memutuskan tautan

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/me/external-libraries JWT Cantumkan penyedia tertaut saya
POS /api/v1/me/external-libraries/link JWT Tautkan penyedia dan sinkronkan judulnya
MENGHAPUS /api/v1/me/external-libraries/{provider} JWT Hapus tautan dan kepemilikannya

Perpustakaan tertaut:

[
  {
    "provider": "steam",
    "externalUserId": "…",
    "createdAt": "…"
  }
]

Badan tautan:

{
  "provider": "steam",
  "externalUserId": "…",
  "accessToken": "…",
  "refreshToken": "…"
}

Mengembalikan 204. Tautan juga menyinkronkan judul penyedia. Sinkronisasi perpustakaan saat ini mengembalikan judul demo steam/epic/gog sementara integrasi penyedia sebenarnya diselesaikan.

Perangkat lunak dan peluncuran eksternal yang dimiliki

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/me/external-software?provider=&page=&pageSize= JWT Daftar halaman judul eksternal saya
POS /api/v1/external-software/{ownershipId}/launch JWT Dapatkan URI peluncuran dan rekam peluncuran eksternal

Daftar perangkat lunak eksternal:

{
  "items": [
    {
      "id": "…",
      "provider": "steam",
      "externalSoftwareId": "…",
      "name": "…",
      "softwareTitleId": "…"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}

Tanggapan peluncuran:

{
  "launchUri": "steam://run/…"
}

Luncurkan format URI menurut penyedia: steam://run/{id}, com.epicgames.launcher://apps/{id}?action=launch, goggalaxy://openGameView/{id}. Peluncuran mencatat aktivitas peluncuran eksternal — lihat activity.md. Permainan eksternal menggunakan kunci permainan seragam "provider:externalId" untuk peringkat dan feed — lihat catalog.md.

Melihat konvensi API untuk penguraian kesalahan.
