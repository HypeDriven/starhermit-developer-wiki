konvensi API

REST menggunakan https://api.starhermit.com/api/v1/...; penggunaan soket wss://api.starhermit.com/ws/v1/.... Game yang dihosting dapat menelepon /api/v1/... Dan /ws/v1/... pada asal mereka sendiri. Klien asli menggunakan asal API publik. Halaman pengembangan di asal lain memerlukan asal CORS yang diizinkan pada game tuan rumah; menyetel URL dasar SDK saja tidak mengotorisasi asal tersebut.

Permintaan dan tanggapan

Kirim JSON dengan Content-Type: application/json, kecuali unggahan paket gzip mentah. Nama anggota JSON adalah camelCase. Kirim kredensial pembawa di REST Authorization tajuk.

Tanggapan Bagaimana cara membacanya
200 / 201 JSON Parsing objek atau array yang didokumentasikan; mentolerir bidang tambahan
204 Sukses tanpa tubuh; jangan menelepon response.json()
302 Pengalihan masuk/konfirmasi browser; menavigasi daripada mengambil halaman OAuth
304 Pembacaan bersyarat tidak berubah; simpan data yang sudah Anda simpan
Gambar, lampiran, penyimpanan cloud Baca byte, menggunakan tipe konten respons dan kontrak titik akhir
Kesalahan Baca statusnya terlebih dahulu, lalu parsing tubuhnya secara defensif

Bentuk kesalahan yang umum adalah { "error": "...", "code": "..." }, dengan bidang opsional bergantung pada titik akhir. error sering kali dapat dibaca manusia; code adalah diskriminator yang stabil jika disediakan. Persyaratan dan beberapa titik akhir lainnya langsung memasukkan diskriminator error. Beberapa titik akhir kembali normal teks, isi kosong, atau objek Detail Masalah validasi dengan title, status Dan errors. Klien tidak boleh berasumsi bahwa setiap respons yang gagal adalah JSON atau memiliki kolom yang sama.

export async function readResponse(response) {
  if (response.status === 204 || response.status === 304) return null;
  const text = await response.text();
  let body;
  try { body = text ? JSON.parse(text) : null; } catch { body = text || null; }
  if (!response.ok) {
    const message = (body && typeof body === 'object' && (body.error || body.message || body.title))
      || (typeof body === 'string' && body) || response.statusText;
    throw Object.assign(new Error(message), {
      status: response.status, code: body?.code, body,
      retryAfter: response.headers.get('Retry-After'),
    });
  }
  return body;
}

Waktu, ukuran, dan nol

  • createdAt, updatedAt, finishedAt, dan stempel waktu akun/sumber daya serupa adalah string ISO 8601 dengan offset. Perlakukan tidak hadir atau null nilai opsional sebagai tidak tersedia.
  • ctx.now, summary.deadline, daftar sesi deadline, Dan /time.serverTime adalah bilangan bulat Unix milidetik. Konversi dengan new Date(value), bukan Date.parse(value).
  • Nilai batas dalam byte adalah byte, bukan karakter Base64. Unggahan JSON Base64 lebih besar dari aslinya isi yang diterjemahkan. Gunakan batas efektif yang dilaporkan oleh titik akhir bila tersedia.
  • Kelalaian, null, dan objek kosong tidak setara secara universal. Pengaturan PATCH menghapus a bernama kunci dengan null; pengaturan satu tombol PUT toko null sebagai sebuah nilai. Koleksi PUT menggantikan seluruh peta. Baca aturan pembaruan setiap titik akhir.
  • Patch pengaturan digabungkan kunci tingkat atas. Nilai objek yang diberikan menggantikan nilai kunci tersebut; itu tidak menggabungkan properti bersarang secara rekursif.

Paginasi

Paging berbasis satu tempat page/pageSize didukung. API yang berbeda sengaja dibuat berbeda amplop tanggapan; jangan menggunakan kembali parser yang menggunakan nama kolom hitungan tunggal.

Daerah Bentuk koleksi Ukuran halaman default/maksimum
Judul dan build perangkat lunak { items, totalCount, page, pageSize } 20 / 100
Pesan obrolan { conversationId, items, totalCount, page, pageSize } 50 / 100
Entri papan peringkat { items, total, page, pageSize } 20 / 100
Perangkat lunak eksternal { items, total, page, pageSize } 20; minta ukuran halaman positif kecil
Laporan, catatan kerusakan kontainer, daftar moderasi { items, total, page, pageSize } 20 / 100
Sesi, teman, daftar permainan, prestasi Array Batasan khusus titik akhir; tidak ada kursor halaman berikutnya yang umum
Umpan penarikan moderasi Berbasis kursor Pertahankan kursor yang dikembalikan; pulih dari 410 seperti yang didokumentasikan

Metadata halaman respons mencerminkan halaman yang ditayangkan jika tersedia. Halaman referensi Dan kontrak yang dapat dibaca mesin menjelaskan parameter kueri khusus titik akhir.

Coba lagi dan konkurensi

Situasi Tindakan
Token akses akun ditolak dengan 401 Segarkan sekali, menggunakan satu permintaan penyegaran bersama; lalu masuk jika ditolak
Token peluncuran sudah habis masa berlakunya Dapatkan token baru melalui masuk/peluncur; token yang kadaluwarsa tidak dapat memperbarui dirinya sendiri
403 terms_acceptance_required Tampilkan dan terima persyaratan saat ini secara eksplisit, lalu coba lagi
Lainnya 403 Menyelesaikan cakupan, keanggotaan, izin, atau status akun; jangan menyegarkan dalam satu lingkaran
409 Menyelesaikan konflik duplikat/status/revisi; baca ulang sebelum mengubah sumber daya
Hemat cloud 412 Muat versi yang lebih baru dan biarkan game menggabungkan atau mengadopsinya
429 atau sementara 503 Menghormati Retry-After, tambahkan jitter, dan percobaan ulang terikat
Kegagalan jaringan saat menulis Hasilnya mungkin tidak diketahui; periksa status sumber daya sebelum mengulangi tindakan

Retry-After bisa dalam hitungan detik atau tanggal HTTP. Jangan membuat header idempotensi: API tidak melakukannya menjanjikan mekanisme kunci idempotensi umum. Percobaan ulang pembuatan sesi atau undangan dapat dibuat sumber daya lain atau konflik dengan sumber daya pertama. Lebih suka membaca dan operasi idempoten secara eksplisit percobaan ulang otomatis. Segarkan rotasi, selesaikan unggahan, persetujuan persyaratan, dan hasil permainan terminal masing-masing mempunyai aturan sendiri.

Untuk penulisan bandingkan-dan-tukar, gunakan ETag penyimpanan cloud, ruangan expectedRevision, atau revisi moderasi jika didukung. Penulisan yang berhasil belum tentu merupakan penerapan container yang selesai; verifikasi itu status sebelum mengirim pemain ke build baru. Melihat pemecahan masalah.
