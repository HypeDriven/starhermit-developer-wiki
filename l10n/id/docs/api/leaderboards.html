Papan peringkat

Definisi dan entri papan peringkat. Bacaan bersifat anonim; mengirimkan skor membutuhkan JWT.

URL Dasar: https://api.starhermit.com. Semua rute berada di bawah /api/v1/....

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/leaderboards Anonim Definisi daftar (query scope, region, titleId)
MENDAPATKAN /api/v1/leaderboards/{id} Anonim Dapatkan satu definisi
MENDAPATKAN /api/v1/leaderboards/{id}/entries?scope=&region=&friendsOnly=&page=&pageSize= Anonim Entri halaman; friendsOnly=true membutuhkan autentikasi
POS /api/v1/leaderboards/{id}/submit JWT Kirimkan skor (hanya papan katalog)
MENDAPATKAN /api/v1/games/{slug}/leaderboards Pembawa Papan aktif milik game Anda (token peluncuran diterima)
DAPATKAN/POSTING /api/v1/me/github-games/{id}/leaderboards JWT (pemilik permainan) Daftar / buat papan permainan Anda
MASUKKAN/HAPUS /api/v1/me/github-games/{id}/leaderboards/{leaderboardId} JWT (pemilik permainan) Perbarui / hapus satu

Definisinya adalah LeaderboardDefinitionDto[]:

[
  {
    "id": "…",
    "softwareTitleId": "…",
    "gameDefinitionId": null,
    "key": null,
    "name": "…",
    "scoreType": "…",
    "sortDirection": "…",
    "resetSchedule": "weekly",
    "currentPeriodStartedAt": "2026-10-12T00:00:00+00:00",
    "nextResetAt": "2026-10-19T00:00:00+00:00",
    "minScore": 0,
    "maxScore": 100,
    "scope": "…",
    "region": "…",
    "isActive": true,
    "createdAt": "…",
    "updatedAt": "…"
  }
]

Tanggapan entri:

{
  "items": [
    {
      "id": "…",
      "userId": "…",
      "username": "…",
      "score": 1500,
      "rank": 1,
      "region": "…",
      "submittedAt": "…"
    }
  ],
  "total": 1,
  "page": 1,

Kirimkan isi:

{
  "score": 1500
}

Skor tersebut divalidasi berdasarkan definisi minScore/maxScore dan aturan penerbit; responnya adalah hasil entri.

Game resmi dan Elo

Setiap game resmi memiliki papan peringkat elo; idnya berasal GET /api/v1/games/{slug} → leaderboardId (melihat games.md). Skor HANYA ditulis oleh platform dari skrip eloUpdates atau saluran kendali kontainer — pengiriman langsung ditolak. Klien game membaca entri melalui titik akhir halaman standar; misalnya, permintaan implementasi referensi catur:

GET /api/v1/leaderboards/{leaderboardId}/entries?friendsOnly=true&page=1&pageSize=10

Token peluncuran dalam cakupan game dapat membaca papan peringkat game mereka sendiri. CRUD berada di papan peringkat sisi penerbit publisher.md.

Menyetel ulang peringkat pemain

Pemilik game dapat mengembalikan rating satu pemain ke awal 1200 — untuk smurf, dikuatkan akun, atau peringkat bug rusak:

DELETE /api/v1/me/github-games/{id}/players/{userId}/elo      → 200 { "userId": "…", "elo": 1200 }

Ini mengatur ulang peringkat pasangan perjodohan, menghapus baris pemain dari papan elo (mengembalikan dengan peringkat pertandingan berikutnya), dan menetapkan angka tingkat atas elo dalam dokumen pemutar skrip Anda hingga 1200 — karena skrip Anda menghitung peringkat berikutnya dari dokumennya sendiri, dan hanya menyetel ulang salinan platform akan dibatalkan pada pertandingan berikutnya. Segala sesuatu yang lain dalam dokumen (kemenangan, sejarah) ditinggal sendirian. Jika skrip Anda mempertahankan peringkatnya dengan nama lain, itu benar bukan ditulis ulang: simpan itu masuk playerStates[id].elo untuk mendapatkan reset secara gratis. Pertandingan yang sudah berlangsung mungkin masih melaporkan a peringkat dihitung sebelum reset. 404 ketika game tersebut bukan milik Anda atau pemain tidak memiliki rating itu. Peringkat tersebut juga tunduk pada aturan elo.

Atur ulang jadwal

Papan peringkat apa pun — papan milik game, atau milik judul katalog — dapat dimulai kembali sesuai jadwal:

resetSchedule Dimulai dari awal
daily setiap hari pada pukul 00:00 UTC
weekly setiap hari Senin pukul 00:00 UTC
monthly pada tanggal 1 setiap bulan pukul 00:00 UTC
dihilangkan, null atau "never" tidak pernah

Nilai lainnya adalah a 400. Laporan definisi currentPeriodStartedAt Dan nextResetAt (keduanya null untuk papan yang tidak pernah direset), sehingga klien dapat menampilkannya "reset dalam 2 hari".

Reset diterapkan saat papan berada membaca: titik akhir entri hanya menampilkan skor yang dikirimkan sejak itu periode saat ini dimulai, dan peringkat dihitung dalam periode tersebut. Tidak ada yang dihapus di batas, jadi pengaturan ulang akan berlaku tepat pada pukul 00:00 UTC. Artinya jadwalnya juga bisa diubah kapan saja — ini mengubah entri mana yang ditampilkan, bukan entri mana yang disimpan. Periode sebelumnya tidak dapat dibaca melalui API.

Papan peringkat game Anda sendiri

Di samping papan elo-nya, ada permainan dengan a server= naskah atau container.image= backend dapat memiliki papan peringkatnya sendiri — skor tinggi, putaran tercepat, pembunuhan terbanyak — dibuat oleh pemilik permainan. Anda tidak memerlukan akun penerbit: memiliki game menjadikan Anda penerbitnya.

Seperti papan elo, hanya server game Anda yang menulis kepada mereka. Skrip Anda kembali scores: { "<key>": { "<userId>": score } } dari kait apa pun (lihat Skrip Game — Papan Peringkat), atau kontainer Anda mengirimkan a scores pesan kontrol. POST /leaderboards/{id}/submit adalah ditolak, jadi klien yang dimodifikasi tidak dapat memposting skor.

Buat satu — POST /api/v1/me/github-games/{id}/leaderboards

{
  "key": "high-score",
  "name": "High score",
  "scoreType": "integer",
  "sortDirection": "desc",
  "minScore": 0,
  "maxScore": 1000000,
  "isActive": true
}

Kembali 201 dengan a LeaderboardDefinitionDto yang gameDefinitionId Dan key sudah diatur.

Bidang Arti
key Diperlukan. Nama yang dikirimkan server Anda: 1–64 huruf, angka, ., _, -. Unik per game.
name Diperlukan. Nama tampilan, maksimal 200 karakter.
scoreType integer (bawaan), decimal, atau time-ms (bilangan bulat non-negatif dalam milidetik)
sortDirection desc (default — lebih tinggi lebih baik) atau asc (lebih rendah lebih baik, misalnya waktu putaran)
minScore / maxScore Batasan opsional; skor di luarnya diabaikan
isActive Bawaan true. Papan yang tidak aktif tidak menerima skor dan tidak dicantumkan kepada pemain.
resetSchedule Opsional: daily, weekly atau monthly - melihat Atur ulang jadwal. Default: tidak pernah diatur ulang.

key, scoreType Dan sortDirection tidak dapat berubah setelah penciptaan: server Anda mengirimkan berdasarkan kunci, dan skor yang sudah disimpan dipilih oleh dua lainnya. Butuh yang lain? Buat papan baru. PUT .../leaderboards/{leaderboardId} menerima name, minScore, maxScore, isActive Dan resetSchedule (mengirim "never" untuk berhenti mengatur ulang); DELETE menghapus papan dan entri-entrinya - mengatur isActive: false untuk pensiun dan mempertahankannya. Sebuah game mungkin memiliki paling banyak 2048 papan.

Bagaimana skor disimpan

  • Satu entri per pemain: yang terbaik. "Terbaik" mengikuti papan sortDirection. Mengirimkan a skor yang lebih buruk tidak mengubah apa pun, jadi laporkan setelah setiap pertandingan tanpa memeriksa terlebih dahulu. Di papan dengan jadwal reset, itu yang terbaik periode ini: skor pertama setelah reset selalu dihitung, betapapun bagusnya skor pemain pada periode terakhir.
  • Hanya pemain dalam sesi tersebut yang dapat mencetak gol; kursi AI dan siapa pun diabaikan.
  • Skor yang melanggar peraturan papan (di luar jangkauan, pecahan per satu integer papan, negatif time-ms) diabaikan, begitu pula kunci tanpa papan aktif. Tidak ada yang dilaporkan kembali ke server Anda.

Tunjukkan pada game Anda

GET /api/v1/games/{slug}/leaderboards mencantumkan papan aktif permainan dengan papannya id Dan key, dan berfungsi dengan token peluncuran game. Baca entri dengan titik akhir halaman standar di atas — GET /api/v1/leaderboards/{id}/entries — yang mungkin juga dijangkau oleh token peluncuran ke papan ini.
