Moderasi konten

Game memeriksa teks yang dibagikan, dokumen JSON, dan gambar PNG/JPEG/WebP sebelum menampilkannya kepada orang lain pemain. Hanya arus allow mengizinkan pembagian. review, block, tidak diketahui, tertunda, gagal, hasil kebijakan yang kedaluwarsa dan tidak kompatibel membuat konten tetap tersembunyi.

Pemeriksaan moderasi saat ini tidak tersedia pada penerapan publik. Baca penemuan sebelumnya mengaktifkan berbagi. Cek kembali 503 overloaded dengan Retry-After: 300; ini tidak menjanjikan ketersediaan setelah lima menit. Biarkan konten tetap tersembunyi sampai Anda menerima keputusan izin saat ini. Generasi juga tidak tersedia.

Kontrak di bawah menjelaskan panggilan moderasi yang didukung dan perilakunya jika tersedia. Hanya saja bukti yang dapat diakses dan disaring dikembalikan melalui API tinjauan pemilik.

Penelepon dan rute

Awalan pemain adalah /api/v1/games/{slug}/moderation. JWT dan token peluncuran membawa pemain; token peluncuran harus cocok dengan game ini. Token server kontainer langsung juga harus cocok dengan game. Asli klien menggunakan URL dasar API; game browser dapat menggunakan asal gamenya /api proksi.

Metode Akhiran Penelepon Hasil
MENDAPATKAN (akar) Pemain atau server Ketersediaan, batasan efektif, konten yang didukung, dan kebijakan saat ini
POS /check Pemain atau server 200 kumpulan lengkap atau 202 pemeriksaan tertunda
MENDAPATKAN /checks/{checkId} Pemain yang diatribusikan atau membuat server game 200 status; 410 setelah retensi hasil
POS /decisions/lookup Pemain atau server 200 hash memenuhi syarat yang diketahui/tidak diketahui
POS /flags Pemain 201 tanda terima bendera; server tidak dapat mengajukan tanda
MENDAPATKAN /removed?since=&pageSize= Pemain atau server Penarikan halaman dan kursor berikutnya

Pemain tidak dapat memeriksa sebagai pemain lain. Server biasanya mengirim sessionId Dan participantUserId; peserta harus berada dalam sesi aktif permainan ini, dan tarif ceknya dikenakan. Untuk a periksa ulang dunia yang gigih tanpa ada yang online, kirim attribution: "game" dan hilangkan kedua bidang. Ini menghabiskan tarif server terpisah dan anggaran permainan, tidak mencatat pemain dan mengizinkan pemungutan suara hanya dengan identitas server resmi game tersebut. Penyegaran token tidak mengubah identitas logis tersebut.

Tersedianya

GET /api/v1/games/{slug}/moderation kembali:

{
  "checksAvailable": false,
  "contentReportingAvailable": false,
  "disabledReason": "moderation_not_configured",
  "policyVersion": "<current effective version>",
  "supportedKinds": ["text", "image"],
  "supportedContexts": ["chat", "name", "generated-content", "user-content"],
  "limits": { "moderation.check.items": 20, "moderation.decision.allow_ttl_seconds": 3600 },
  "acceptedPreviousPolicyVersion": null,
  "previousPolicyValidUntil": null,
  "deliveredContentGraceSeconds": 0
}

limits berisi nilai registri moderasi yang efektif, di luar dua yang diilustrasikan. Pemain nilai termasuk penggantian pemain tersebut; penemuan server mengungkapkan tunjangan permainan, tidak pernah yang lain milik pemain. Anggaran item game nol juga menonaktifkan pemeriksaan (game_budget_disabled). Gunakan nilai tumpang tindih kebijakan dan nilai tenggang yang dikembalikan; defaultnya tidak menyediakan keduanya.

Periksa konten yang tepat

POST /api/v1/games/{slug}/moderation/check
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "items": [
    { "id": "story", "kind": "text", "context": "user-content", "text": "abc" }
  ]
}

ID item bersifat unik dalam satu batch dan maksimal 128 karakter. Hanya membawa teks text; gambar membawa contentType dan standar yang ketat empuk dataBase64, tanpa spasi. Gambar yang dideklarasikan jenis harus cocok dengan headernya, dan byte serta piksel dibatasi. WAV, Ogg Vorbis, Model dan font glTF tidak didukung (415 unsupported_kind); dukungan audio ditangguhkan.

Hashnya adalah sha256: diikuti oleh 64 digit hex huruf kecil SHA-256 pada byte konten yang tepat:

  • Untuk teks, dekodekan string dengan JSON dan enkodekan nilai skalar Unicode sebagai UTF-8 tanpa BOM. Pertahankan spasi putih, akhiran baris, dan normalisasi Unicode; menolak pengganti yang tidak berpasangan.
  • Dokumen JSON yang dikirimkan sebagai teks di-hash sebagai string dokumen persisnya, tanpa penguraian, menyusun ulang atau melakukan serialisasi ulang.
  • Untuk sebuah gambar, hashkan byte yang didekodekan sebelum mengubah ukuran, transcoding, atau perubahan metadata.

Tiga byte ASCII abc hash ke sha256:ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad. Menambahkan baris baru akan mengubah hash. Amplop permintaan, ID item, konteks, jenis media, dan base64 pengkodean bukan input hash. Platform menghitung hash yang dikirimkan; menerima permainan juga harus hash byte yang sebenarnya mereka simpan dan bandingkan pengidentifikasinya.

Barang lengkap ada status: "complete", contentHash, decision, kategori, revisi, checkedAt Dan decisionPolicyVersion. Hanya izin yang dibawa validUntil. Amplop tanggapan memiliki arus yang efektif policyVersion. Validasi menolak seluruh batch jika ada item salah format. Item yang diterima bisa gagal secara terpisah, dengan status: "failed", kode dan tidak ada keputusan.

Batas waktu sinkron defaultnya adalah dua detik. Barang yang belum selesai diproduksi 202 dengan checkId, pollAfterSeconds, expiresAt Dan Retry-After. Jajak pendapat cek; item yang tertunda tidak memiliki keputusan. Batas waktu latar belakang defaultnya adalah 60 detik, lalu item yang belum selesai gagal timeout dan masukan biasa terhapus. Hasil terminal tetap dapat dibaca selama satu jam secara default.

Melakukan polling pada item yang telah selesai berkonsultasi dengan keputusan langsung yang memenuhi syarat, kebijakan saat ini, dan retensi. Cek yang lama tidak dapat memperbaharui persetujuan yang dicabut. Pemblokiran/ulasan saat ini dikembalikan seperti itu; keputusan yang basi, kadaluwarsa, atau tidak ada menghasilkan item yang gagal dan tidak ada validitas yang diperbarui.

Pemulihan pencarian dan penarikan

{
  "hashes": ["sha256:ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"],
  "kind": "text",
  "context": "user-content"
}

Kirim ini ke /decisions/lookup. Pencarian gambar juga nama contentType. Persetujuan memenuhi syarat oleh permainan, jenis, jenis dan konteks media yang divalidasi. Entrinya adalah known dengan keputusan, revisi, decisionPolicyVersion dan mengizinkan validitas, atau unknown dengan not_checked, policy_changed atau expired. Pemblokiran manusia tetap efektif setelah perubahan kebijakan dan retensi keputusan biasa.

Izinkan default validitas menjadi satu jam dan dapat diturunkan oleh operator. Validasi ulang sebelum habis masa berlakunya; tidak ada masa tenggang yang diaktifkan untuk pemadaman dan tidak ada versi dasar sebelumnya yang diterima. Berubah kebijakan permainan segera membatalkan persetujuan sebelumnya. Izin manusia hanya bertahan setelah pemeriksaan ulang untuk temuan serupa yang masih melewati baseline saat ini berdasarkan kebijakan yang sama.

Pemilihan /removed sebelum membagikan paket bersama dan secara teratur selama bermain. Sembunyikan hash yang cocok dan menghentikan distribusi pada saat penarikan; penghapusan mencakup pengesahan bendera dan reklasifikasi dari mengizinkan untuk meninjau/memblokir. Entri umpan mencakup kualifikasi, cakupan, keputusan, revisi, kebijakan, waktu penghapusan dan alasan aman. Kursor adalah penanda pemesanan yang buram; gunakan kursor yang dikembalikan daripada mengambilnya dari suatu waktu.

Kursor yang kedaluwarsa kembali 410 cursor_expired. Ambil kursor baru tanpa since, pencarian batch semua memuat hash bersama, dan melanjutkan hanya jika divalidasi. Absen dari feed tidak pernah berarti persetujuan. Salinan lokal yang disimpan tidak mengizinkan redistribusi. Umpan defaultnya adalah riwayat 90 hari; blok manusia yang tahan lama akan hidup lebih lama darinya.

Bendera dan ulasan pemilik

Seorang pemain mengirim /flags a reason (maksimal 64 karakter), opsional dibatasi note, dan konten, pemain target, atau keduanya. Bukti isi menggunakan bentuk barang yang sama dengan cek. Jika contentHash juga disediakan, platform menghitung ulangnya dan membutuhkan kesetaraan. Hash kosong bukanlah bukti; referensi pekerjaan/pemeriksaan tidak diterapkan. Bendera target pemain memerlukan a sessionId daftar siapa mencakup reporter dan target. Mengarsipkan bendera tidak mengubah keputusan atau secara otomatis memblokir siapa pun.

Bukti konten dicadangkan dan disimpan di karantina sebelum klasifikasi untuk perutean. Tertunda, penyaringan yang gagal atau tidak tersedia tidak pernah membuka akses pemilik. Izin pemeriksaan yang aman bagi pemilik saat ini daftar/detail/unduh/triase. Temuan staf menyembunyikan tanda dan membatasi tanda dan tinjauan yang ada dari bukti yang sama. Tanpa pengklasifikasi, tanda konten akan kembali 403 content_reporting_disabled tanpa saran percobaan ulang atau bukti yang disimpan; bendera khusus pemain tetap dapat digunakan.

Rute pemilik memerlukan JWT penuh dan kepemilikan game, di bawah /api/v1/me/github-games/{id}/moderation:

Metode Akhiran Perilaku
DAPATKAN / TEMPATKAN /policy Baca/atur peringkat dan ambang kategori yang lebih ketat dengan expectedVersion
MENDAPATKAN /flags / /flags/{flagId} Metadata yang disaring dalam halaman / satu tanda yang dapat diakses
MENDAPATKAN /flags/{flagId}/evidence Pengunduhan terkontrol; 410 setelah bukti habis masa berlakunya
tambalan /flags/{flagId} action: "uphold" atau "dismiss", catatan opsional dan expectedRevision
MENDAPATKAN /reviews / /reviews/{reviewId} Metadata tinjauan yang diadakan dalam halaman / satu ulasan yang dapat diakses
MENDAPATKAN /reviews/{reviewId}/content Pengunduhan terkontrol; 410 review_expired ketika tidak tersedia
tambalan /reviews/{reviewId} action: "allow" atau "block", catatan opsional dan expectedRevision

Daftar diambil status, page Dan pageSize (default 20, maksimum 100). Hanya kebijakan pemilik yang lebih ketat pegangan yang saat ini melewati garis dasar platform mungkin diperbolehkan; penahan dasar memerlukan platform ulasan di luar API pemilik game. Bukti terbatas tidak pernah terlihat oleh pemiliknya. Revisi yang basi adalah 409 revision_conflict. Memutuskan suatu peninjauan akan menghapus konten yang disimpannya; kadaluarsa juga mencegah pengunduhan atau persetujuannya. Mengabaikan sebuah bendera tidak membatalkan pemblokiran lainnya, dan tidak ada pemiliknya rute mengangkat blok manusia.

Bukti adalah application/octet-stream lampiran dengan nosniff, kotak pasir CSP dan no-store. Simpan catatan/alasan sebagai teks tidak tepercaya di UI ulasan Anda. Jangan menjadikannya sebagai markup atau menggunakannya sebagai URL lampiran.

Operator dapat menyesuaikan batas permainan; tarif pemain juga mendukung penggantian per pengguna. Baca penemuan untuk nilai-nilai aktual yang berlaku.

Kehabisan antrian/penyimpanan menolak bukti baru dibandingkan mengusir kasus aktif. Hormati aksesibilitas dan kedaluwarsa yang dilaporkan oleh setiap titik akhir bukti/tinjauan.

Ada kesalahan { error, code, retryAfterSeconds? }. 400 mencakup konten/kualifikasi yang formatnya salah, 401 otentikasi hilang, 403 batasan ruang lingkup/delegasi atau dasar, 404 tidak ada/tidak dapat diakses catatan, 409 konflik hash/revisi/kebijakan, 410 konten/pemeriksaan/kursor kedaluwarsa, 413 byte/barang/ batas piksel, dan 415 jenis/tipe yang tidak didukung. 429 mencakup tarif/anggaran/antrian/penyimpanan dengan Retry-After. Pemadaman pengklasifikasi adalah 503 moderation_unavailable; saat ini tidak dikonfigurasi penggantinya tetap ada 503 overloaded. Tidak ada kesalahan, percobaan ulang, atau pembayaran pengganti untuk keputusan yang diizinkan.

Dibagikan konvensi API menjelaskan penguraian respons, stempel waktu, penomoran halaman, dan percobaan ulang.

Melihat kompatibilitas kredensial Dan kontrak yang dapat dibaca mesin.
