Aktivitas

API aktivitas mencakup sesi peluncuran, waktu bermain, dan umpan aktivitas — untuk judul katalog dan game eksternal (non-katalog). Semua rute memerlukan JWT kecuali disebutkan.

URL Dasar: https://api.starhermit.com. Semua rute berada di bawah /api/v1/....

Sesi peluncuran katalog dan waktu bermain

Metode Jalur Penulis Keterangan
POS /api/v1/activity/launches/{id}/end JWT Mengakhiri sesi peluncuran katalog (204)
MENDAPATKAN /api/v1/activity/software/{softwareTitleId}/playtime JWT Total waktu bermain saya untuk sebuah judul
MENDAPATKAN /api/v1/activity/software/{softwareTitleId}/friends-playtime?top=5 JWT Waktu bermain teman untuk sebuah judul

Sesi peluncuran dimulai oleh POST /api/v1/software/{id}/launch (melihat catalog.md) dan berakhir di sini. Respon waktu bermain:

{
  "softwareTitleId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

friends-playtime kembali FriendPlaytimeDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "minutes": 60,
    "seconds": 3600
  }
]

Peluncuran eksternal dan waktu bermain

Untuk game non-katalog (perpustakaan eksternal tertaut — lihat external-libraries.md):

Metode Jalur Penulis Keterangan
POS /api/v1/activity/external-launches JWT Mulai sesi untuk permainan non-katalog
POS /api/v1/activity/external-launches/{id}/end JWT Akhiri sesi itu (204)
MENDAPATKAN /api/v1/activity/external/playtime?provider=&externalId= JWT Total waktu bermain saya untuk game eksternal
MENDAPATKAN /api/v1/activity/external/friends-playtime?provider=&externalId=&top=5 JWT Waktu bermain teman untuk game eksternal

POST /api/v1/activity/external-launches tubuh (provider ≤ 64 karakter, externalSoftwareId ≤ 256 karakter, name opsional):

{
  "provider": "steam",
  "externalSoftwareId": "…",
  "name": "…"
}

Tanggapan:

{
  "launchId": "…"
}

Respons waktu bermain eksternal:

{
  "provider": "steam",
  "externalId": "…",
  "totalMinutes": 120,
  "totalSeconds": 7200
}

Umpan aktivitas

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/activity/game-feed?key=&limit=20 JWT Sesi teman dan acara pemeringkatan untuk satu kunci permainan
MENDAPATKAN /api/v1/activity/friends?since=&until=&limit= JWT Aktivitas teman
MENDAPATKAN /api/v1/activity/public?since=&until=&limit= Anonim Aktivitas publik
MENDAPATKAN /api/v1/me/activity?since=&until=&limit= JWT Aktivitas saya sendiri

Umpan game kembali GameFeedItemDto[] untuk satu kunci permainan (panduan katalog atau "provider:externalId", melihat catalog.md):

[
  {
    "type": "launch",
    "userId": "…",
    "username": "…",
    "timestamp": "…",
    "minutes": 45,
    "stars": 4
  }
]

friends, public, Dan me/activity kembali ActivityDto[]:

[
  {
    "id": "…",
    "userId": "…",
    "username": "…",
    "type": "launch",
    "timestamp": "…",
    "softwareTitleId": "…",
    "titleName": "…",
    "metadata": "…"
  }
]

Aktivitas type nilai: "download", "launch", "external_launch".

/activity/friends diberi gerbang per jenis aktivitas di milik pemilik pengaturan privasi: peluncuran menyusul recentLaunchActivity, unduhan menyusul recentDownloads. Masing-masing disertakan saat levelnya FriendsOnly atau Public. Akun yang tidak pernah dipilih akan mendapatkan default (peluncuran dibagikan dengan teman, unduh pribadi). Dokumen privasi yang tidak dapat dibaca dianggap sepenuhnya pribadi. Melihat profile.md.

Melihat konvensi API untuk penguraian kesalahan.

Melihat kompatibilitas kredensial Dan kontrak yang dapat dibaca mesin.
