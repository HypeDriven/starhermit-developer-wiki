Katalog Perangkat Lunak

Katalog perangkat lunak mencakup penjelajahan dan mengklaim judul, pembuatan daftar, pengunduhan, penyimpanan di cloud, daftar keinginan, dan peringkat. Bacaan bersifat anonim; menulis membutuhkan JWT.

URL Dasar: https://api.starhermit.com. Semua rute berada di bawah /api/v1/....

Menjelajah dan mengklaim judul

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/software Anonim Cari dan halaman katalog
MENDAPATKAN /api/v1/software/{id} Anonim Dapatkan satu gelar, atau 404
MENDAPATKAN /api/v1/software/{id}/builds?page=&pageSize= Anonim Daftar halaman build untuk sebuah judul
POS /api/v1/software/{id}/claim JWT Klaim sendiri hak milik gratis, berikan hak
POS /api/v1/software/{id}/launch JWT Memulai sesi peluncuran (memerlukan hak)

GET /api/v1/software menerima parameter kueri q (teks lengkap), category, tag, publisherId, platform, releaseStatus, sort, page, Dan pageSize. Sah sort nilai: name, name_desc, created, created_desc, updated, updated_desc. Ini mengembalikan a PagedResult:

{
  "items": [
    {
      "id": "…",
      "name": "…",
      "description": "…",
      "publisherId": "…",
      "category": "…",
      "platform": "…",
      "releaseStatus": "…",
      "tags": ["…"],
      "priceCents": 0,
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

GET /api/v1/software/{id}/builds mengembalikan a PagedResult dari SoftwareBuild:

{
  "items": [
    {
      "id": "…",
      "titleId": "…",
      "version": "…",
      "releaseDate": "…",
      "releaseNotes": "…",
      "metadata": "…",
      "createdAt": "…",
      "updatedAt": "…"
    }
  ],
  "totalCount": 1,
  "page": 1,
  "pageSize": 20
}

POST /api/v1/software/{id}/claim hanya berfungsi untuk judul gratis (priceCents == 0); itu memberi penelepon hak dan mengembalikan 204. Untuk judul berbayar, ia mengembalikan 402 dengan:

{"error": "purchasing is not available yet"}

POST /api/v1/software/{id}/launch membutuhkan hak (403 sebaliknya) dan mengembalikan a LaunchSession:

{
  "launchId": "…",
  "startTime": "…"
}

Ini mencatat aktivitas peluncuran, yang disembunyikan jika pengaturan privasi pengguna menyatakan demikian (lihat profile.md). Akhiri sesi dengan POST /api/v1/activity/launches/{id}/end - melihat activity.md. Hak pengguna dicantumkan melalui GET /api/v1/me/entitlements (melihat profile.md).

Unduhan

Metode Jalur Penulis Keterangan
POS /api/v1/software/{id}/download JWT Dapatkan URL unduhan yang ditandatangani (memerlukan hak)

Membutuhkan hak (403 sebaliknya). Pengembalian:

{
  "downloadUrl": "…"
}

URL ini menargetkan aset pertama yang dapat diunduh dari versi terbaru. Panggilan tersebut mencatat aktivitas pengunduhan. Distribusi biner katalog saat ini sedang dalam pratinjau; URL yang dikembalikan tidak dijamin produksinya unduhan. Melihat ketersediaan fitur sebelum mengandalkan alur penerbitan ini.

Simpanan cloud

Satu slot per game, penulisan terakhir menang. Semua rute memerlukan JWT — token pengguna penuh, atau token game meluncurkan token untuk slot game itu sendiri (di bawah).

Batas 10 MB (10.485.760 byte) berlaku untuk simpan yang diterjemahkan, bukan permintaannya. PUT mengambil simpanan yang dikodekan base64 dalam JSON, jadi ukurannya sekitar sepertiga lebih besar dari simpanan — kira-kira berukuran 14 MB batasnya — dan API menerimanya.

Batas (per akun) Bawaan Penolakan
Satu simpanan, diterjemahkan 10 MB 413 cloud_save_too_large
Game dengan penyelamatan 200 409 cloud_save_slots_exhausted (simpanan untuk permainan baru)
Semua menghemat bersama-sama 1 GB 507 cloud_save_quota_exceeded, dengan used
Unggahan 30 menit 429, dengan Retry-After

Setiap penolakan menyebutkan nomor yang berlaku sebagai limit. Totalnya diukur berdasarkan akun lainnya menyimpan, sehingga slot selalu dapat ditimpa dengan sesuatu yang tidak lebih besar. Operator dapat mengubah apa pun ini untuk satu akun.

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/me/cloud-saves/{gameKey}/info JWT Simpan metadata: { exists, sizeBytes, updatedAt? }
MENDAPATKAN /api/v1/me/cloud-saves/{gameKey} JWT application/zip byte, 404 jika tidak ada
MELETAKKAN /api/v1/me/cloud-saves/{gameKey} JWT Unggah simpanan (simpan yang diterjemahkan ≤ 10 MB, gameKey ≤ 300 karakter)
MENGHAPUS /api/v1/me/cloud-saves/{gameKey} JWT (token pengguna penuh) Hapus slotnya, 204 (idempoten)

Itu DELETE adalah milik pemilik akun — hanya token pengguna penuh. Token peluncuran game dapat membaca dan tulis slotnya sendiri tapi tidak bisa menghapusnya (403), jadi game tidak akan pernah bisa menghapus simpanan pemainnya berharap untuk dipertahankan.

MENEMPATKAN tubuh:

{
  "dataBase64": "…"
}

Tanggapan PUT:

{
  "gameKey": "…",
  "sizeBytes": 0,
  "updatedAt": "…"
}

Menyimpan dari dalam game (token peluncuran)

Game yang berjalan dengan token peluncurannya dapat membaca dan menulis simpanan pemain permainan itu. Game Anda menyimpan dirinya sendiri di mana pun ia dijalankan — browser, atau aplikasi desktop StarHermit, yang dijalankan game juga dihosting di browser — jadi penyimpanannya mengikuti pemain di antara game-game tersebut.

Kuncinya adalah game:<gameId>, Di mana <gameId> adalah id game Anda — nilainya sama dengan slug-nya, nya <gameId>.starhermit.com alamat, dan game_scope klaim token peluncuran:

const key = `game:${gameScope}`;            // e.g. "game:3fa85f64-5717-4562-b3fc-2c963f66afa6"

// Load on startup — 404 means no save yet.
const res = await fetch(`/api/v1/me/cloud-saves/${key}`, { headers: { Authorization: `Bearer ${launchToken}` } });
if (res.status !== 404 && !res.ok) throw new Error(`Save load failed: ${res.status}`);
const save = res.status === 404 ? null : new Uint8Array(await res.arrayBuffer());
const etag = res.headers.get("ETag");
if (save && !etag) throw new Error("Save version unavailable; do not overwrite it.");
// Validate/decode your own save format before adopting it or enabling uploads.

// Save at checkpoints, not every frame.
const written = await fetch(`/api/v1/me/cloud-saves/${key}`, {
  method: "PUT",
  headers: {
    Authorization: `Bearer ${launchToken}`, "Content-Type": "application/json",
    ...(etag ? { "If-Match": etag } : { "If-None-Match": "*" }),
  },
  body: JSON.stringify({ dataBase64: base64(zipBytes) }), // Your ZIP encoder and bytes.
});
if (written.status === 412) throw new Error("Another device saved. Reload before writing again.");
if (!written.ok) throw new Error(`Save write failed: ${written.status}`);
const acknowledgement = await written.json(); // Retain acknowledgement.etag for your next write.
  • Hanya kunci persisnya itu. Kunci lainnya — permainan lain, permainan toko, atau ejaan lain milik Anda (huruf besar, id kosong) — adalah 403 untuk token peluncuran. Itu termasuk github:<gameId>, slot terpisah yang digunakan aplikasi desktop saat pemain menyinkronkan folder penyimpanan lokal untuk game Anda, jadi sinkronisasi itu tidak akan pernah bisa menimpa tulisan save game Anda.
  • Format apa pun. Platform tidak pernah membuka penyimpanan; simpan apa pun yang dapat dibaca kembali oleh game Anda (itu disajikan sebagai application/zip tanpa memedulikan). Hingga 10MB.
  • Penulisan tanpa syarat adalah kemenangan penulisan terakhir, tanpa sejarah. Gunakan penulisan bersyarat untuk mendeteksi menyimpan dua tab/perangkat sekaligus. Muat saat mulai dan simpan di pos pemeriksaan latar depan. Keluar dari halaman pengunggahan merupakan upaya terbaik dan memiliki batasan ukuran badan browser; melihat resep hemat yang aman.
  • Setiap penyimpanan memiliki versinya. Dia ETag sedang diunduh, aktif /info (juga sebagai etag) dan seterusnya itu PUT tanggapan. Kirim kembali sebagai If-Match dan penulisan hanya terjadi jika tidak ada yang menyimpan sejak; jika tidak 412 {"error":"precondition_failed","etag":"<current>"} memberitahu Anda versinya memuat. If-Match: * membutuhkan penyimpanan yang sudah ada; If-None-Match: * menulis hanya ketika tidak ada. Tanpa tajuk a PUT tidak bersyarat — penulisan terakhir menang. A GET dengan If-None-Match: <etag> jawaban 304 ketika Anda sudah memegang simpanan terbaru.
  • Game tanpa daftar yang dihosting (game yang disediakan operator) tidak memiliki slot.

Preferensi kecil yang sering berubah termasuk di dalamnya pengaturan per pemain alih-alih; mereka juga dapat dijangkau dengan token peluncuran dan mendukung pembaruan parsial.

Daftar Keinginan

Semua rute memerlukan JWT.

Metode Jalur Penulis Keterangan
MENDAPATKAN /api/v1/me/wishlist JWT { titleIds: guid[] }
MELETAKKAN /api/v1/me/wishlist/{titleId} JWT Tambahkan ke wishlist, 204 (idempoten)
MENGHAPUS /api/v1/me/wishlist/{titleId} JWT Hapus dari daftar keinginan, 204

Peringkat

Semua rute memerlukan JWT. Kunci permainan seragam adalah panduan katalog, atau "provider:externalId" untuk permainan eksternal (lihat external-libraries.md).

Metode Jalur Penulis Keterangan
MELETAKKAN /api/v1/me/ratings JWT Tingkatkan peringkat saya untuk sebuah game
POS /api/v1/ratings/query JWT Ringkasan pemeringkatan pengambilan batch
MENDAPATKAN /api/v1/ratings/reviews?key=&top= JWT Ulasan untuk sebuah game (top bawaan 10)

MENEMPATKAN tubuh:

{
  "gameKey": "…",
  "stars": 4,
  "review": "…"
}

stars adalah 0–5; review adalah opsional. Respon adalah a RatingSummaryDto:

{
  "gameKey": "…",
  "average": 4.5,
  "count": 12,
  "myStars": 4
}

POST /api/v1/ratings/query tubuh dan respons:

{
  "keys": ["…", "…"]
}

kembali RatingSummaryDto[]. GET /api/v1/ratings/reviews kembali GameReviewDto[]:

[
  {
    "userId": "…",
    "username": "…",
    "stars": 4,
    "review": "…",
    "timestamp": "…"
  }
]

Melihat konvensi API untuk penguraian kesalahan. Terkait: achievements.md, leaderboards.md.
