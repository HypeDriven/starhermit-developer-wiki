Teman-teman

API teman mengelola permintaan pertemanan dan menerima pertemanan. Semua rute berada di bawah api/v1/me dan memerlukan otorisasi. Undangan permainan gerbang negara persahabatan, dan juga mengontrol akses ke ruang obrolan terbuka dan ruang suara.

Badan kesalahan bervariasi; melihat konvensi API.

Titik akhir

Metode Jalur Penulis Keterangan
POS /api/v1/me/friend-requests JWT Kirim permintaan pertemanan
MENDAPATKAN /api/v1/me/friend-requests JWT Daftar permintaan pertemanan masuk yang tertunda
POS /api/v1/me/friend-requests/{requestId}/accept JWT Terima permintaan pertemanan
POS /api/v1/me/friend-requests/{requestId}/decline JWT Tolak permintaan pertemanan
MENGHAPUS /api/v1/me/friends/{friendUserId} JWT Batalkan pertemanan dengan pengguna
MENDAPATKAN /api/v1/me/friends JWT Daftar pertemanan yang diterima dengan kehadiran

Permintaan pertemanan

POST /api/v1/me/friend-requests

{ "toUserId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }

Mengembalikan 204.

GET /api/v1/me/friend-requests

Permintaan masuk yang tertunda:

[
  {
    "id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "senderUserId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "senderUsername": "pk-a1b2c3d4e5f6",
    "createdAt": "2026-07-20T09:30:00Z"
  }
]

POST /api/v1/me/friend-requests/{requestId}/accept

Mengembalikan 204; kedua pengguna menjadi teman.

POST /api/v1/me/friend-requests/{requestId}/decline

Mengembalikan 204.

Teman-teman

GET /api/v1/me/friends

Persahabatan yang diterima. online berasal dari kehadiran, currentGame dari peluncuran aktif:

[
  {
    "userId": "9b2f5c74-1d2e-4a6b-8c0d-1e2f3a4b5c6d",
    "username": "pk-a1b2c3d4e5f6",
    "online": true,
    "currentGame": "chess"
  }
]

DELETE /api/v1/me/friends/{friendUserId}

Membatalkan pertemanan dengan pengguna. Mengembalikan 204.

Bagaimana persahabatan membuka ciri-ciri lainnya

  • Undangan permainan hanya dapat dikirim ke teman — lihat Pertandingan.
  • Mengobrol — gerbang persahabatan bergabung dengan ruang obrolan terbuka; aturan obrolan memerlukan persahabatan untuk percakapan non-game. Melihat Mengobrol.
  • Suara — akses ruang suara memerlukan keanggotaan percakapan obrolan pendukung, sehingga aturan pertemanan obrolan berlaku secara transitif. Melihat Suara.
  • Percakapan game per sesi mengabaikan aturan pertemanan — Pemain dalam sesi permainan yang sama dapat menggunakan obrolan/suara terlampir tanpa menjadi teman.

Token peluncuran dalam lingkup game

Token peluncuran dalam lingkup game mungkin menelepon GET /api/v1/me/friends, sehingga game dapat menawarkan pemilih undangan teman di dalam suatu sesi — implementasi referensi catur menggunakannya untuk hal tersebut. Titik akhir teman lainnya mengembalikan 403 untuk token peluncuran; lihat aturan anggar lingkup permainan di Otentikasi.

Melihat kompatibilitas kredensial Dan kontrak yang dapat dibaca mesin.
