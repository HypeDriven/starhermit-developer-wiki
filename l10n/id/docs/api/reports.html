Laporan Kerusakan dan Bug

Pemain dapat melaporkan kerusakan atau bug dari dalam game apa pun yang memiliki slug — game khusus browser disertakan — menggunakan token peluncuran game atau token pengguna penuh. Pemilik game membaca, melakukan triase, dan menghapusnya melalui /api/v1/me/github-games/{id}/reports.

Untuk keluaran server dan catatan kerusakan game kontainer itu sendiri, lihat Server Game yang dihosting kontainer — Laporan keluaran dan kerusakan server Anda.

Titik akhir

Metode Jalur Penulis Keterangan
POS /api/v1/games/{slug}/reports Luncurkan token untuk game itu, atau JWT Ajukan laporan kerusakan atau bug
MENDAPATKAN /api/v1/games/{slug}/reports/mine Luncurkan token untuk game itu, atau JWT 50 laporan terbaru Anda untuk game ini, beserta statusnya
MENDAPATKAN /api/v1/me/github-games/{id}/reports JWT (pemilik) Daftar laporan: ?kind=crash|bug&status=open|acknowledged|resolved&page=&pageSize= (≤100)
MENDAPATKAN /api/v1/me/github-games/{id}/reports/{reportId} JWT (pemilik) Satu laporan, dengan daftar lampirannya
MENDAPATKAN /api/v1/me/github-games/{id}/reports/{reportId}/attachments/{attachmentId} JWT (pemilik) Lampiran, selalu sebagai unduhan
tambalan /api/v1/me/github-games/{id}/reports/{reportId} JWT (pemilik) Mengatur status
MENGHAPUS /api/v1/me/github-games/{id}/reports/{reportId} JWT (pemilik) Hapus laporan → 204

Ajukan laporan

POST /api/v1/games/{slug}/reports
Authorization: Bearer <launch-token>
Content-Type: application/json

{
  "kind": "crash",
  "title": "Crash entering the second level",
  "description": "TypeError: cannot read properties of undefined (reading 'tiles')\n    at loadLevel (game.js:812)",
  "clientVersion": "1.4.2",
  "platform": "web",
  "buildId": "a1b2c3d",
  "sessionId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "attachments": [
    { "fileName": "console.log", "contentType": "text/plain", "dataBase64": "…" }
  ]
}
  • kind adalah crash atau bug; title diperlukan (≤200 karakter).
  • Segala sesuatu yang lain adalah opsional. userAgent default ke permintaan User-Agent tajuk.
  • Tanggapan: 201 { "id", "kind", "status": "open", "createdAt" }.
Status Arti
400 Salah format: tidak diketahui kind, hilang title, base64 tidak valid, atau bukan JSON
404 Game tidak dikenal atau dihapus
413 Deskripsi, jumlah lampiran, atau byte lampiran melebihi batas permainan
429 Melebihi batas laporan harian untuk game ini; melihat Retry-After

Batasan

Operator dapat mengubah masing-masing hal ini untuk keseluruhan platform dan untuk game individual; batas harian juga dapat diatur untuk satu pemain.

Membatasi Bawaan
Laporan per pemain per game per hari 20
Panjang deskripsi 20.000 karakter
Lampiran per laporan 4
Byte lampiran per laporan 2 MiB
Laporan disimpan per game 2,000
Byte disimpan per game 256 MiB
Penyimpanan 90 hari

Saat game mencapai batas penyimpanannya, laporan terlama — yang diselesaikan terlebih dahulu — akan dihapus memberi ruang. Satu laporan yang lebih besar dari batas byte keseluruhan per game ditolak 413.

Laporan triase (pemilik game)

Daftarnya kembali { "items", "total", "page", "pageSize" }; setiap item membawa nama reporter, kind, status, title, detail klien dan jumlah lampirannya. Pindahkan laporan open → acknowledged → resolved dengan:

PATCH /api/v1/me/github-games/{id}/reports/{reportId}
Content-Type: application/json

{ "status": "resolved" }

Lampiran disajikan sebagai unduhan (Content-Disposition: attachment, nosniff, kotak pasir CSP). Hanya tipe inert yang mempertahankan tipe konten yang dinyatakan — teks, JSON, PNG, JPEG, WebP, GIF, zip, dan gzip; hal lain, termasuk markup, disajikan sebagai application/octet-stream.

Dari SDK JavaScript

StarHermit.reportBug('Score did not save', 'Finished level 3, score shows 0', { clientVersion: '1.4.2' });
StarHermit.captureCrashes({ clientVersion: '1.4.2' });   // opt-in: uncaught errors become crash reports

Lihat SDK JavaScript.

Dibagikan konvensi API menjelaskan penguraian respons, stempel waktu, penomoran halaman, dan percobaan ulang.

Melihat kompatibilitas kredensial Dan kontrak yang dapat dibaca mesin.
