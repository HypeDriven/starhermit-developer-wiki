Mengobrol

Obrolan StarHermit mencakup pesan langsung, ruang grup, dan percakapan sesi permainan, melalui REST API (api/v1/chat) ditambah saluran push WebSocket server-ke-klien (ws/v1/chat). Semua titik akhir REST memerlukan autentikasi. Badan kesalahan bervariasi; melihat konvensi API.

titik akhir REST

Basis: https://api.starhermit.com/api/v1/chat.

Metode Jalur Penulis Keterangan
POS /conversations JWT Buat percakapan (1 teman = langsung, ≥2 = grup)
tambalan /conversations/{id} JWT Mengganti nama percakapan (anggota mana pun)
POS /conversations/{id}/invites JWT Undang pengguna ke dalam grup
MENDAPATKAN /invites JWT Cantumkan undangan obrolan Anda yang tertunda
POS /invites/{id}/accept JWT Terima undangan obrolan
POS /invites/{id}/decline JWT Tolak undangan ngobrol
MENDAPATKAN /rooms/joinable JWT Buat daftar ruang terbuka dengan ≥1 teman di dalamnya
POS /conversations/{id}/join JWT Bergabunglah di ruang terbuka (harus berteman dengan anggota)
POS /conversations/{id}/participants JWT Tambahkan peserta ke percakapan
MENGHAPUS /conversations/{id}/participants/{userId} JWT Menghapus peserta (diri sendiri: anggota mana pun; orang lain: hanya pembuat grup)
POS /conversations/{id}/leave JWT Tinggalkan percakapan
MENDAPATKAN /conversations JWT Buat daftar percakapan, termasuk setiap hitungan yang belum dibaca
MENDAPATKAN /conversations/{id} JWT Dapatkan percakapan, termasuk jumlah yang belum dibaca
MENDAPATKAN /unread JWT Dapatkan jumlah total pesan yang belum dibaca
POS /conversations/{id}/read JWT Tandai percakapan yang sudah dibaca
MENDAPATKAN /conversations/{id}/messages?page=&pageSize= JWT Dapatkan riwayat pesan berhalaman
POS /conversations/{id}/messages JWT Kirim pesan (tarif terbatas)
MELETAKKAN /conversations/{conversationId}/messages/{messageId} JWT Mengedit pesan
MENGHAPUS /conversations/{conversationId}/messages/{messageId} JWT Hapus pesan (batu nisan)

Buat percakapan

POST /conversations

{
  "participantIds": ["<guid>"],
  "name": "Friday night lobby",
  "friendUserId": "<guid>",
  "joinPolicy": "closed"
}

Semua bidang bersifat opsional. Salah satu teman peserta membuat a langsung percakapan; dua atau lebih membuat a kelompok. joinPolicy adalah "open" atau "closed" (bawaan "closed"). Pengembalian a ConversationDto.

Ganti nama percakapan

PATCH /conversations/{id} dengan { "name": "New name" } → ConversationDto. Setiap anggota dapat mengganti nama; catatan sistem dengan kind: "system_rename" sedang disiarkan.

Undangan

POST /conversations/{id}/invites dengan { "toUserId": "<guid>" } → ChatInviteDto. Undangan adalah satu-satunya jalan masuk ke ruangan tertutup.

GET /invites → ChatInviteDto[]:

[
  {
    "id": "<guid>",
    "conversationId": "<guid>",
    "conversationName": "Friday night lobby",
    "fromUserId": "<guid>",
    "fromUsername": "alice",
    "toUserId": "<guid>",
    "status": "pending",
    "createdAt": "2026-07-22T07:00:00Z"
  }
]

POST /invites/{id}/accept Dan POST /invites/{id}/decline → ChatInviteDto.

Bergabung dengan ruangan

GET /rooms/joinable → JoinableRoomDto[] — ruang terbuka yang memiliki setidaknya satu teman Anda di dalamnya:

[
  {
    "id": "<guid>",
    "name": "Friday night lobby",
    "joinPolicy": "open",
    "createdAt": "2026-07-22T07:00:00Z",
    "participants": [{ "userId": "<guid>", "username": "alice" }]
  }
]

POST /conversations/{id}/join → ConversationDto. Bergabung dengan ruang terbuka; Anda harus berteman dengan anggota.

Peserta

POST /conversations/{id}/participants dengan { "participantIds": ["<guid>"] } → ConversationDto.

DELETE /conversations/{id}/participants/{userId} → 204. Setiap anggota dapat mengeluarkan dirinya sendiri; menghapus orang lain memerlukan menjadi pembuat grup.

POST /conversations/{id}/leave → 204.

Membaca percakapan

GET /conversations → ConversationDto[].

GET /conversations/{id} → ConversationDto:

{
  "id": "<guid>",
  "type": "group",
  "name": "Friday night lobby",
  "createdByUserId": "<guid>",
  "joinPolicy": "closed",
  "createdAt": "2026-07-22T07:00:00Z",
  "participants": [{ "userId": "<guid>", "username": "alice" }],
  "otherParticipant": { "userId": "<guid>", "username": "bob" },
  "unreadCount": 3
}

type adalah salah satu dari direct, group, game. name, createdByUserId, Dan otherParticipant mungkin tidak ada. unreadCount menghitung pesan teks yang belum dibaca yang dikirim oleh anggota lain setelah cakrawala baca per percakapan penelepon.

Status belum dibaca

GET /unread mengembalikan jumlah yang belum dibaca di seluruh percakapan penelepon:

{ "total": 7 }

POST /conversations/{id}/read memajukan cakrawala baca penelepon untuk percakapan itu. Gunakan setelah menampilkan transkrip saat ini. Server memancarkan a conversation_read acara ke semua soket milik penelepon, memungkinkan beberapa klien yang masuk untuk menghapus lencana mereka. Pesan baru dan yang dihapus dapat mengubah totalnya, jadi klien harus memperbarui dari acara WebSocket atau mengambil kembali secara berkala /unread.

Pesan

GET /conversations/{id}/messages?page=1&pageSize=50 → PagedMessagesDto:

{
  "conversationId": "<guid>",
  "page": 1,
  "pageSize": 50,
  "totalCount": 123,
  "items": []
}

POST /conversations/{id}/messages dengan { "content": "hello" } → MessageDto. Tarif dibatasi hingga 10 pesan/menit per pengguna; melebihi itu kembali 429.

PUT /conversations/{conversationId}/messages/{messageId} dengan { "content": "edited" } → MessageDto.

DELETE /conversations/{conversationId}/messages/{messageId} → 204. Penghapusan adalah batu nisan: pesan tetap ada isDeleted: true.

MessageDto:

{
  "id": "<guid>",
  "conversationId": "<guid>",
  "senderId": "<guid>",
  "senderUsername": "alice",
  "content": "hello",
  "kind": "text",
  "metadata": { "key": "value" },
  "sentAt": "2026-07-22T07:00:00Z",
  "editedAt": null,
  "isDeleted": false
}

kind adalah "text" atau "system_rename"; content, metadata (a Dictionary<string,string>), Dan editedAt mungkin tidak ada/null.

Soket Web: ws/v1/chat

Hubungkan ke wss://api.starhermit.com/ws/v1/chat dengan JWT melalui Authorization tajuk, ?ticket=, atau ?access_token=.

Ini adalah sebuah server murni→saluran dorong klien: frame klien diabaikan (hanya Close dihormati). Setiap bingkai adalah sebuah amplop:

{ "type": "<event>", "payload": { } }
Peristiwa type Muatan
conversation_created ConversationDto
conversation_renamed ConversationDto
participants_added ConversationDto
participant_removed ConversationDto
chat_invite ChatInviteDto
chat_invite_responded ChatInviteDto
new_message MessageDto
message_updated MessageDto
message_deleted MessageDto
conversation_read Perubahan status baca untuk pengguna yang masuk; mengambil kembali jumlah yang belum dibaca
game_invite { "inviteId", "kind", "gameSlug", "gameName", "roomId", "from": { "userId", "username" }, "createdAt", "acceptPath", "declinePath", "inProgress", "sessionId" } — lihat di bawah

game_invite: satu acara untuk kedua sistem undangan

Siapa pun dapat diundang untuk bermain dengan dua cara, dan acara tunggal ini membawa keduanya — klien menerapkan satu toast, bukan dua:

kind Dikeluarkan oleh Menerimanya
"session" POST /games/{slug}/invites Membuat sesi permainan baru untuk Anda berdua
"room" POST /realtime/rooms/{id}/invites Mengambil tempat duduk di ruangan yang sudah diduduki oleh pengundang; roomId apakah ruangan itu

acceptPath Dan declinePath adalah titik akhir yang menjawab ini undang - gunakanlah dan perbedaannya tidak menjadi masalah. Menjawab di titik akhir sistem lain adalah a 404: keduanya menyimpan id undangan terpisah.

inProgress adalah true ketika menerima bergabung dengan permainan yang sudah dimainkan — undangan sesi yang menyebutkan sesi yang sedang berjalan, atau undangan ruang ke ruang yang dimulai yang memungkinkan bergabung dalam proses — dan sessionId adalah sesi permainan itu. Gunakan itu untuk mengatakan "bergabung dengan permainan mereka" alih-alih "bermain".

{
  "type": "game_invite",
  "payload": {
    "inviteId": "e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b",
    "kind": "room",
    "gameSlug": "poker",
    "gameName": "StarHermit Poker",
    "roomId": "b1d2c3e4-5f60-4a71-8b92-c3d4e5f60718",
    "from": { "userId": "9b2f8c1a-1111-4222-8333-444455556666", "username": "alice" },
    "createdAt": "2026-07-26T14:10:00Z",
    "acceptPath": "/api/v1/realtime/rooms/invites/e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b/accept",
    "declinePath": "/api/v1/realtime/rooms/invites/e7f1a2b3-4c5d-4e6f-8a9b-0c1d2e3f4a5b/decline"
  }
}

roomId adalah null untuk "session" mengundang. Token peluncuran dalam cakupan game tidak dapat membuka soket ini atau membaca seluruh akun /me/game-invites kotak masuk. Jajak pendapat klien game GET /api/v1/games/{slug}/invites untuk undangan sesi dan GET /api/v1/realtime/rooms/invites untuk undangan ruang permainan mereka. Klien akun dapat membaca kedua jenis tersebut GET /api/v1/me/game-invites.

Mengobrol di dalam sesi permainan

Token peluncuran dalam lingkup game tidak bisa membuka ws/v1/chat — diblokir karena soket mengalirkan semua percakapan pengguna. Luncurkan token mungkin gunakan obrolan REST API pada percakapan yang dilampirkan ke sesi permainan mereka sendiri: detail sesi mengembalikan a chatConversationId, percakapannya bertipe "game", pesertanya adalah pemain sesi, dan aturan pertemanan dilewati.

Oleh karena itu, klien game biasanya memuat riwayat melalui REST dan melakukan polling untuk pesan baru alih-alih menggunakan soket. Misalnya, implementasi referensi catur polling setiap 5 detik:

GET /api/v1/chat/conversations/{chatConversationId}/messages?page=1&pageSize=50
Authorization: Bearer <launch-token>

POST /api/v1/chat/conversations/{chatConversationId}/messages
Authorization: Bearer <launch-token>
Content-Type: application/json

{ "content": "good game" }

Lihat juga

  • Suara — ruang suara berlabuh untuk percakapan obrolan
  • Teman-teman — gerbang persahabatan obrolan langsung dan bergabung ke ruang
  • Pertandingan — sesi permainan dan mereka chatConversationId

Melihat kompatibilitas kredensial Dan kontrak yang dapat dibaca mesin.
