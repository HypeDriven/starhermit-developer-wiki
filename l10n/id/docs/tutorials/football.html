Contoh permainan: bagaimana Football menggunakan mesin StarHermit

Sepak Bola Pertapa Bintang adalah publik, lengkap permainan skrip. Ini adalah sepak bola 3D waktu nyata untuk 1 hingga 22 pemain, dengan rekan satu tim AI, dengan lampu sorot stadion, lobi online, obrolan suara dan teks, tayangan ulang, papan peringkat, prestasi, dan sembilan bahasa. Halaman ini menguraikannya selangkah demi selangkah untuk menunjukkan bagaimana game sebenarnya menggunakan mesin tersebut. Masing-masing langkah memberi nama modul mesin yang terlibat dan tautan ke sumber permainan, tempat Anda dapat membaca kode lengkap.

Panduan ini ditulis untuk mesin 1.40.0, rilis terbaru. Setiap panggilan yang ditampilkan terdaftar di referensi API mesin. Baca tutorial mesin pertama jika Anda belum membuat skrip permainan.

Tautan sumber menunjuk ke komit 33bd9bd. Saat itu komit mesin pin permainan 1.39.0 dengan engine.minor=39. Tidak ada yang lebih baru yang digunakan, jadi begitulah berjalan tidak berubah pada 1.40.0; memindahkannya adalah perubahan satu baris ke engine.version (melihat langkah 12).

Bentuk permainannya

Jalur Peran
starhermit.txt Manifes: nama, pin mesin, skrip server, kontrol, kemampuan
server.js Simulasi satu pertandingan: dijalankan oleh platform sebagai server resmi, dan dimuat oleh klien untuk latihan dan prediksi offline
engine/src/main.ts Modul entri: callback siklus hidup dan mesin status layar
engine/src/match.ts, logic/ Alur kecocokan, netcode, interpolasi, dan prediksi
engine/src/world/ Stadion, pesepakbola, bola, dan penonton dalam adegan 3D
engine/src/screens/, hud.ts Menu (starhermit:ui) dan HUD dalam pertandingan (starhermit:draw)
engine/src/net.ts, platform.ts, chat.ts, voice.ts Segala sesuatu yang berhubungan dengan platform StarHermit
engine/src/audio.ts, i18n.ts, quality.ts Tingkat suara, bahasa, dan grafik
assets/, sfx/ Gambar, tabel string dan klip suara

1. Manifes

starhermit.txt menjadikan folder tersebut permainan skrip, dan juga mendeklarasikan skrip server dan kontrolnya:

name=Football
launch=index.html
server=server.js
control.up=KeyW+ArrowUp | Run forward
control.shoot=Space+KeyJ | Shoot (hold) / tap to pass
control.tackle=KeyK | Slide tackle / pressure
engine.api=1
engine.entry=engine/src/main.ts
engine.version=1.39.0
engine.minor=39
engine.capabilities=platform,voice,clipboard,storage
engine.gamepad.shoot=West+RightTrigger
engine.gamepad.pass=South
  • launch=index.html adalah halaman pemuat itu starhermit package --web menulis. Ia memainkan permainannya di browser pada runtime web rilis yang disematkan.
  • server=server.js adalah skrip pencocokan resmi platform (langkah 6).
  • control.* Dan engine.gamepad.* garis mendefinisikan tindakan. Runtime mengikat kunci dan pad ke dalamnya, dan pemain mengikatnya kembali di menu Opsi runtime. Game ini tidak pernah menyebutkan kunci gameplaynya.
  • engine.capabilities meminta platform (ruangan, soket, papan peringkat, pemutaran ulang, obrolan), suara, clipboard (tautan undangan) dan penyimpanan (pengaturan). Runtime menolak panggilan di luarnya.

Daftar kunci lengkap ada di itu starhermit.txt tampak.

2. Modul entri dan loop bingkai

engine/src/main.ts menyiapkan perender pada cakupan modul, lalu mendaftarkan empat callback siklus hidup dari starhermit:engine:

import { frame, onFixedUpdate, onRender, onStart, onUpdate, setFixedRate } from "starhermit:engine";
import { ACESFilmicToneMapping, PCFSoftShadowMap, PerspectiveCamera, renderer, scene } from "starhermit:scene";

const camera = new PerspectiveCamera(55, 16 / 9, 0.1, 800);
renderer.camera = camera;
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = PCFSoftShadowMap;
renderer.toneMapping = ACESFilmicToneMapping;

onStart(() => {
  setFixedRate(60);
  loadLanguages(); // string tables (step 10)
  sim();           // evaluate server.js once (step 6)
  menuScene.start(); // an AI-vs-AI match behind the menu
  // … platform listeners, settings listeners, invite polling
});

onFixedUpdate((step) => {
  if (match) match.fixedStep(step);
  else if (!replay) menuScene.fixedStep(step);
});

onUpdate((delta) => {
  pollQuality();
  if (match) match.update(Math.min(delta, 0.1));
  // … replay viewer or menu backdrop
});

onRender(() => {
  const fr = frame();
  if (Math.abs(camera.aspect - fr.width / fr.height) > 1e-6) {
    camera.aspect = fr.width / fr.height;
    camera.updateProjectionMatrix();
  }
  hud.draw();
  // … chat, in-match menu or the menu screens
});

Pola yang akan disalin:

  • Simulasi berjalan masuk onFixedUpdate, pada 60 Hz tetap.
  • Logika per-frame berjalan onUpdate, dengan delta dibatasi sehingga bingkai yang terhenti tidak dapat dibuat pemain melompat.
  • Gambar masuk onRender. Hanya ada satu dari setiap panggilan balik, jadi main.ts penggemar keluar ke layar saat ini: menu, lobi, pertandingan, pemutaran ulang, atau hasil.

3. Dunia 3D: starhermit:scene

Stadion, pesepakbola, bola, dan ofisial adalah objek biasa bergaya three.js starhermit:scene: Mesh, Group, MeshStandardMaterial, CylinderGeometry, Sprite, CanvasTexture dan sebagainya. Kode yang di-porting dari three.js sebagian besar berfungsi tidak berubah. Beberapa detail yang patut dibaca:

  • world/stadium.ts membangun lapangan, tribun, lampu sorot, dan kabut. Ini mengatur efek pasca (renderer.bloom, renderer.grade, renderer.antialias) dan bayangan untuk setiap level grafis.
  • world/environment.ts membuat peta lingkungan dengan PMREMGenerator dari a DataTexture.
  • world/crest.ts Dan world/nametags.ts menggambar lambang tim dan nama panggilan mengambang di a starhermit:canvas OffscreenCanvas, lalu gunakan sebagai CanvasTexturepasir Sprites.

4. Ribuan bagian yang bergerak: starhermit:world

Menganimasikan 22 pesepakbola secara bersama-sama, ditambah ribuan penonton, akan terlalu lambat skrip per objek pada penerjemah asli. Gerakan sepak bola yang berhasil starhermit:world tabel (barisan kolom yang diketik) dan kernel (berfungsi runtime dijalankan pada setiap baris secara asli):

import { kernel, schedule, table } from "starhermit:world";

const crowd = table("crowd", CROWD_ROWS, {
  bx: "f32", by: "f32", bz: "f32", ph: "f32", fr: "f32", av: "f32",
  q: "quat", s: "f32", sy: "f32", x: "f32", y: "f32", z: "f32",
});
const sway = kernel(crowd, (r, u: { t: number; amp: number; spd: number; sway: number; shake: number }) => {
  const j = Math.sin(u.t * u.spd * r.fr + r.ph);
  r.y = r.by + (j > 0 ? j * j : 0) * u.amp * r.av;
  // …
});
// An eighth of the crowd each frame: the work is sliced across frames.
const swayRun = schedule.update(sway, { t: 0, amp: 0, spd: 0, sway: 0, shake: 0 }, { slices: 8 });

Pesepakbola itu masuk world/rig.ts menggunakan pendekatan yang sama. A rigs tabel berisi status animasi setiap pesepakbola. A joints meja, dengan a ref:rigs kolom, menampung 15 sambungan per rig, dan ikatan mengusir node adegan darinya. Dua kernel dijadwalkan setelahnya onUpdate menghitung posenya, dan runtime menulis nodenya mengubah dirinya sendiri. Pekerjaan skrip per pesepakbola menghasilkan sekitar selusin angka dalam satu bingkai.

5. Input: tindakan, sentuhan, dan gamepad

engine/src/input.ts membaca tindakan manifes starhermit:input:

  • value(action) mengembalikan seberapa jauh suatu tindakan dilakukan (gerakannya value("up") - value("down")). onAction memberikan tepi tekan dan lepas.
  • Tampilan mouse digunakan requestPointerLock, onPointerDelta Dan onPointerLockChange. Kameranya tongkat kanan berasal gamepads(), Dan vibrate memberikan tanda centang haptik singkat.
  • Pada layar sentuh (primaryPointer() kasar), setTouchControls menunjukkan joystick dan Tombol SHOOT/PASS/TACKLE yang digambar pada saat runtime. Tombol-tombolnya terikat pada tindakan yang sama:
setTouchControls([
  { kind: "stick", up: "up", down: "down", left: "left", right: "right", anchor: "bottom-left", offset: [90, 90], radius: 66 },
  { kind: "button", action: "shoot", label: T("SHOOT").slice(0, 16), anchor: "bottom-right", offset: [66, 66], radius: 46 },
  // … PASS and TACKLE
]);

screens/controls.ts daftar saat ini bindings() dan panggilan requestRebind. Runtime kemudian menangkap kunci baru atau tombol.

6. Satu simulasi untuk klien dan server: starhermit:script

server.js adalah skrip klasik biasa tanpa impor, Date atau Math.random, sebagai kotak pasir platform membutuhkan. Ini mendefinisikan dua global:

  • globalThis.game memegang titik masuk platform (createSession, onPlayerMessage, onTick) dan deklarasi statis dibaca pada waktu publikasi:

    globalThis.game = {
  tickRateHz: 30,
  replays: true,
  achievements: [
    { key: 'debut', name: 'Debut', description: 'Finish your first match.', points: 10 },
    { key: 'hat-trick', name: 'Hat-Trick', description: 'Score three goals in one match.', points: 50 },
    // …
  ],
  createSession: function (ctx) { /* seats, AI, seed from ctx.random */ },
  // …
};

  • globalThis.FootballSim memegang simulasi yang sama (createMatch, stepMatch, AI) untuk klien.

Klien memuat file yang sama ke dalam wilayahnya sendiri dengan loadClassic dari starhermit:script (engine/src/sim.ts):

import { loadClassic } from "starhermit:script";

loadClassic("server.js");
const S = (globalThis as unknown as { FootballSim?: FootballSimApi }).FootballSim;

Langkah-langkah latihan offline FootballSim secara lokal pada 60 Hz dengan AI di setiap kursi lainnya. Daring, itu platform berjalan server.js secara otoritatif pada 30 Hz. Game ini tidak pernah menyimpan dua salinannya aturan.

7. Pertandingan online: ruangan dan soket permainan

Lobi menggunakan ruang platform melalui starhermit:platform (screens/lobby.ts):

import * as P from "starhermit:platform";

// Quick play: join any open room, or open one.
let room = await P.rooms.quickJoin();
if (!room) {
  room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, metadata: { game: "football" } });
  room = await P.rooms.open(room.id);
}

// Ranked solo vs AI: every other seat is an AI player, so starting begins the match at once.
room = await P.rooms.create({ teamCount: 2, seatsPerTeam: teamSize, backfillAfterSeconds: 30, aiPlayers: 2 * teamSize - 1, metadata: { game: "football" } });
room = await P.rooms.start(room.id);

Teman, undangan, dan perubahan kursi dilakukan P.friends.list, P.rooms.invite, P.rooms.acceptInvite Dan P.rooms.seat. P.rooms.mine memungkinkan pemain bergabung kembali dengan pertandingan yang mereka tinggalkan.

Begitu pertandingan dimulai, engine/src/net.ts membuka soket permainan dengan P.connectGame(sessionId):

  • Ini mengirimkan input pada 30 Hz dengan sendInput.
  • Ia meminta cuplikan lengkap dengan sendCommand({ type: "sync" }) pada setiap terbuka dan terus resumed.
  • Ia mendengarkan game (foto dan acara), achievement Dan stopped. stopped melaporkan alasannya soket berhenti: keluar, persyaratan diperbarui, atau kecocokan hilang.

Runtime menyimpan kredensial pemain dan terhubung kembali dengan sendirinya, sehingga game tidak menangani token dan tidak memiliki loop coba lagi.

logic/interp.ts menghaluskan snapshot server dengan interpolasi adaptif. logic/predict.ts memprediksi pergerakan pesepakbola lokal dan mengoreksinya pada setiap snapshot. Prediksi mempengaruhi hanya apa yang digambar; server tetap berwibawa.

8. Sisa platform

Fitur Panggilan Sumber

Papan peringkat P.leaderboards.list, P.leaderboards.entries (papan diumumkan di leaderboards.json) screens/leaderboard.ts
Prestasi Dinyatakan masuk server.js, diberikan penuh waktu, terdaftar dengan P.achievements.list screens/achievements.ts
Pemutaran ulang game.replays: true di dalam server.js; P.replays.list, P.replays.get screens/replays.ts, replayView.ts
Obrolan teks P.sessions.get (percakapan pertandingan), P.chat.messages, P.chat.subscribe, P.chat.post chat.ts

Tautan undangan P.inviteLink Dan clipboard dari starhermit:engine platform.ts
Laporan bug P.reportBug screens/settings.ts

Setiap panggilan dapat ditolak dengan a PlatformError. Sepak bola memperlakukan fitur online sebagai upaya terbaik: a kegagalan menunjukkan "daring tidak tersedia" atau kembali terdiam, dan tidak pernah mengakhiri permainan. Keluar, permainan ini masih menawarkan latihan offline.

9. Menu dan HUD: starhermit:ui, starhermit:draw, starhermit:canvas

  • Menu (screens/*.ts, menu dalam pertandingan dan dialog di main.ts) menggunakan starhermit:ui, UI mode langsung mesin. Widget dipanggil setiap bingkai dari onRender, Dan ui.setTheme memberi mereka warna permainan. Opsi runtime itu sendiri menu terbuka dengan openMenu.
  • HUD tersebut ( hud.ts) menggambar papan skor, jam dan spidol dengan starhermit:draw: draw.roundRect, draw.text Dan draw.image (kanvas lambang), dalam urutan panggilan di atas tempat kejadian.
  • Gambar sarat dengan createImageBitmap dari starhermit:canvas, misalnya seni kunci menu.

10. Pengaturan dan bahasa: starhermit:storage, string

  • Pengaturan per pemain (bisu, suara, bahasa, penggantian grafis) tetap ada settings dari starhermit:storage. Mereka disimpan di perangkat dan di akun. settings.onChange menerapkan perubahan yang dibuat pada perangkat lain.
  • i18n.ts banyak assets/strings.json ke dalam mesin strings tabel (strings.load, strings.t, strings.setLanguage). Ia mengambil bahasa dari pilihan yang disimpan, lalu bahasa pemain Bahasa StarHermit, lalu perangkat (preferences). l10n/font.ts memuat font skrip dengan FontFace untuk bahasa yang membutuhkannya.

11. Tingkat suara dan grafis

  • audio.ts membuat grafik Audio Web dengan starhermit:audio:
    • Klip yang ditulis tercantum dalam sfx/manifest.json (baca dengan files.readJson).
    • Synthesizer meliput acara apa pun tanpa klip, ditambah penonton dan gaung stadion.
    • Node berumur pendek dilepaskan segera setelah berakhir, karena grafik host dibatasi.
  • quality.ts mengikuti level grafis pemain (frame().level, levelSettings). Bayangan, mekar dan anti-aliasing ikuti level itu. Konten game itu sendiri (detail nada, kepadatan penonton, partikel) memiliki penggantian per pemain di atas.

12. Kemas, uji, dan publikasikan

  • Tipe-periksa dengan tsc -p engine. engine/tsconfig.json termasuk rilisnya starhermit.d.ts dan set "lib": ["ES2022"], "types": [] Dan "allowImportingTsExtensions": true.
  • Tes. npm test berjalan server.js tes regresi. engine/tests/run.sh menjalankan logikanya tes (interpolasi, prediksi, pose, lobi) di bawah Node. starhermit <folder> --check memvalidasi paket dan memutar 120 frame tanpa kepala.
  • Kemasan. starhermit package --web . menulis ulang index.html Dan starhermit-files.json, yang berkomitmen dengan setiap perubahan.
  • Menerbitkan. Game ini ditambahkan di StarHermit dari URL repositorinya. Platformnya berbunyi starhermit.txt, berjalan server.js sebagai skrip pertandingan dan membuat papan peringkat dari leaderboards.json.

Untuk memindahkan Sepak Bola, atau permainan Anda sendiri, ke mesin 1.40.0:

  1. Unduh waktu proses 1.40.0.
  2. Mengatur engine.version=1.40.0.
  3. Jalankan pemeriksaan dan paket lagi.

Mengangkat engine.minor hingga 40 hanya jika Anda ingin menghosting API 1.40 fitur baru.
