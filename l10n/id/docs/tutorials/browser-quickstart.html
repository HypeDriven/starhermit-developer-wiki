Bangun game browser pertama Anda yang dihosting

Unduh Kolektor Bintang, permainan kecil lengkap dengan dua entri pilihan: permainan akun dengan penyimpanan cloud, dan permainan pemain tunggal yang kemajuannya hanya disimpan di memori. Coba mainkan tanpa tanda tangan di wiki ini; masuk akun menjadi tersedia setelah Anda menerbitkan salinan Anda sendiri di StarHermit.

Anda memerlukan akun StarHermit untuk mempublikasikan. Game itu sendiri tidak memerlukan backend server, ketergantungan instalasi, langkah pembangunan, atau organisasi penerbit.

1. Buka zip dan mainkan secara lokal

ZIP berisi index.html, app.js, style.css, starhermit.txt, dan dua file pembantu. Sajikan folder yang diekstraksi dengan server statis lokal, misalnya:

python3 -m http.server 8000 --directory star-collector

Di Sini star-collector adalah folder tempat Anda mengekstrak. Membuka http://localhost:8000 dan pilih Mainkan pemain tunggal (kemajuan tidak disimpan). Klik bintangnya. Kembali ke awal atau memuat ulang memulai proses baru yang tidak terlacak. Mode ini tidak menulis kemajuan lokal maupun kemajuan akun.

2. Publikasikan folder yang dapat didistribusikan

Manifesnya sudah ada di folder root:

name=Star Collector Quickstart
launch=index.html
description=A small single-player game with account saves or untracked play.

Di UI penerbitan game StarHermit, tambahkan folder ini sebagai game baru. Seluruh folder yang dipilih adalah bangunan yang diterbitkan. Simpan hanya file yang ingin Anda sajikan. Setara API mengemas file di bawah client/ dan mengirimkan arsip gzip mentah:

mkdir -p bundle/client
cp -R star-collector/. bundle/client/
cp star-collector/starhermit.txt bundle/starhermit.txt
# Write the archive outside bundle so it cannot include itself.
tar -C bundle -czf star-collector.tar.gz .

curl --fail-with-body -X POST https://api.starhermit.com/api/v1/me/github-games/upload \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H 'Content-Type: application/gzip' \
  --data-binary @star-collector.tar.gz

ACCESS_TOKEN adalah token akun lengkap Anda, setelah penerimaan persyaratan saat ini secara eksplisit. Tanggapannya game.id, game.gameSlug, dan subdomain yang dihosting mengidentifikasi game Anda. Buka URL yang dihosting kembali. Untuk rilis berikutnya gunakan game itu titik akhir bundel daripada membuat daftar lain. Melihat penerbitan CI ketika siap.

3. Coba dua jalur masuk akun

Peluncuran dari StarHermit: persediaan peluncur #game_token=<jwt>. Pembantu menangkapnya dan menghapusnya dari URL sebelum modul game dijalankan. Memilih Lanjutkan dengan akun StarHermit Anda.

Buka URL yang dihosting secara langsung: memilih Masuk dengan StarHermit. Pemilih penyedia mengizinkan pemain masuk dengan akun yang ada atau buat akun. Ia kembali langsung ke game ini dengan cakupan #access_token=<jwt>; tidak ada kredensial seluruh akun yang dikirim ke game.

Permainan memuat kemajuan hanya ketika pemain memilih permainan akun. Jika persyaratan saat ini memerlukan persetujuan, ini menampilkan dokumen sebagai teks dan penawaran Terima dan lanjutkan. Penerimaan hanya mengirimkan hash revisi yang ditampilkan. Revisi yang diubah ditampilkan kembali untuk keputusan eksplisit lainnya.

4. Periksa kemajuan dan kegagalan

Kumpulkan beberapa bintang dalam mode akun, tunggu Disimpan, dan muat ulang. Hitungan kembali setelah memilih permainan akun. Buka tab kedua dengan jumlah simpanan yang sama: simpan di satu tab, lalu kumpulkan di tab lainnya. Itu yang kedua harus menunjukkan konflik dan penawaran Muat kemajuan cloud terbaru alih-alih menimpanya.

Dokumen penyimpanannya adalah { version: 1, points: <non-negative integer> }. Permainan memuat dan memvalidasi sebelum menulis, menggunakan ETag yang dimuat untuk pembaruan bersyarat, dan memblokir penulisan setelah pembacaan gagal. Ini menyimpan di setiap koleksi dan memberi label pada data yang disimpan hanya setelah pengakuan. Melihat resep hemat untuk format, migrasi, dan dokumen yang lebih besar.

Memilih pemutaran yang tidak terlacak akan membuang token pemain game dan menghentikan pembaruan latar belakang. Tidak ada awan penyimpanan, pencapaian, papan peringkat, atau penulisan kemajuan lokal terjadi. Memilih akun bermain lagi menggunakan masuk untuk mendapatkan token baru.

5. Sesuaikan dengan permainan Anda

Ganti tombol bintang dan skema kemajuan dengan gameplay Anda. Simpan pilihan entri, token penangkapan, penerimaan persyaratan eksplisit, aturan muat sebelum penyimpanan, penanganan kesalahan, dan status penyimpanan. Deklarasikan tindakan keyboard dalam manifes dan baca mengontrol API ketika game Anda membutuhkan rebinding. Masukkan preferensi volume dan grafis pengaturan.

Untuk hasil kompetitif multipemain atau tervalidasi, tambahkan skrip atau wadah. Penghitung cloud mulai cepat ini adalah kemajuan milik klien, bukan bukti skor yang sah.

Mengajukan Tujuan
index.html, style.css Entri, persyaratan, gameplay, dan UI status yang dapat diakses
app.js Mode masuk, persetujuan eksplisit, validasi kemajuan, pos pemeriksaan, konflik
starhermit-sdk.js Pengambilan token peluncuran, proses masuk yang dihosting, pembaruan token
cloud-save-store.js Resep pemuatan JSON mentah/penyimpanan bersyarat
starhermit.txt Metadata penerbitan publik

Melihat kredensial, konvensi API, Dan pemecahan masalah ketika permintaan berperilaku berbeda dari yang diharapkan.
