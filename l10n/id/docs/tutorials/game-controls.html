Tutorial: tambahkan kontrol ke game Anda

StarHermit dapat menyimpan pengikatan kunci untuk game Anda: Anda mendeklarasikan tindakan dan kunci defaultnya, dan setiap pemain dapat mengikatnya kembali. Pilihan mereka mengikuti mereka ke mesin mana pun tempat mereka masuk. permainanmu membaca binding pemain dari API kontrol dan dapat menawarkan binding miliknya sendiri "mengikat ulang kunci" layar.

Jika game Anda memanggil API kontrol dan mendapatkan ini:

404 {"error":"This game declares no controls."}

platform memilikinya tidak ada tindakan yang diumumkan untuk bangunan yang dilayaninya. Tidak ada yang Anda kirim ke API yang bisa perbaiki itu: kontrol dideklarasikan di game Anda starhermit.txt dan membaca kapan permainan tersebut diterbitkan. Halaman ini menunjukkan cara mendeklarasikannya, mempublikasikannya, memeriksa apakah sudah sampai, dan menggunakannya dari klien Anda.

  1. Nyatakan tindakannya
  2. Publikasikan mereka
  3. Periksa mereka tiba
  4. Gunakan mereka dalam permainan Anda
  5. Pemecahan masalah

1. Nyatakan tindakannya

Tambahkan satu control.<action>= baris per tindakan ke starhermit.txt:

name=Space Hopper
launch=index.html

control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.jump=Space+KeyW | Jump
control.fire=KeyJ | Fire
control.pause=Escape | Pause

Setiap baris memiliki tiga bagian:

control.<action>=<code>[+<code>...][ | <label>]
Bagian Aturan
<action> Nama game Anda untuk aksi: 1–32 karakter huruf kecil, angka, dan _ (move_left, bukan move-left). Unik per manifes.
<code> A KeyboardEvent.code nilai, seperti KeyA, ArrowLeft, Space, Digit1, ShiftLeft, Enter atau Escape. Gabungkan 1–4 kode untuk tindakan yang sama dengan +.
<label> Opsional. Ditampilkan di layar rebinding; paling banyak 64 karakter. Defaultnya adalah nama tindakan.

Hal yang perlu diketahui:

  • Menggunakan code, bukan key. Menulis KeyA, bukan a, Dan Space, bukan " ". Kode memberi nama fisik kuncinya, sehingga pengikatannya berfungsi pada tata letak keyboard apa pun. Platform hanya memeriksa apakah kodenya 1–32 huruf dan angka, jadi a atau space diterima tetapi tidak ada kunci yang memproduksinya. Ejaan dan kasus harus sama persis.
  • Sebuah kunci milik satu tindakan. Kode yang sudah digunakan oleh baris sebelumnya akan dijadikan baris berikutnya tidak valid.
  • Hingga 32 tindakan per permainan. Garis setelah tanggal 32 diabaikan.
  • Pesanan disimpan. Tindakan muncul dari API dalam urutan nyata, jadi cantumkan caranya layar pengaturan Anda akan menampilkannya.
  • Baris yang tidak valid dilewati secara diam-diam. Game ini masih diterbitkan. Jika setiap baris tidak valid, permainan tidak memiliki kontrol dan jawaban API 404. Periksa setelah diterbitkan.

2. Publikasikan

Deklarasi dibacakan saat game tersebut diterbitkan. Mengedit starhermit.txt di repositori Anda atau pada disk tidak mengubah apa pun sampai Anda menerbitkan build yang memuatnya:

Bagaimana game Anda dipublikasikan Apa yang membuat kontrol baru aktif
Dari repositori GitHub Penerapan Anda selanjutnya. Dorong perubahan, lalu terapkan versi terbaru (Perbarui versi yang diterapkan di dasbor, atau PUT /api/v1/me/github-games/{id}/deployment).
Folder atau bundel yang diunggah Unggah bangunan baru (POST /api/v1/me/github-games/{id}/bundle, atau ws/v1/game-upload) yang starhermit.txt memiliki garis.
Menambahkan permainan baru Unggahan atau kiriman pertama langsung membacanya.

Upload pengganti menampilkan kembali kontrol Anda dari manifesnya sendiri. Hapus setiap control.* garis dan permainan tidak memilikinya. A ?mode=merge tambal itu tidak membawa starhermit.txt mempertahankan kontrol saat ini.

Rebinding milik pemain bertahan dalam build baru. Pengikatan tersimpan pemain untuk tindakan yang tidak yang lebih lama ada diabaikan.

3. Periksa apakah mereka sudah sampai

Setiap titik akhir di bawah berfungsi dengan token pengguna penuh atau token peluncuran game Anda. {slug} adalah milikmu siput permainan: token peluncuran game_scope klaim, atau gameSlug di dalam GET /api/v1/me/github-games.

curl -s "https://api.starhermit.com/api/v1/games/$SLUG/controls" \
  -H "Authorization: Bearer $TOKEN" | jq

{
  "actions": [
    { "action": "left",  "label": "Move left",  "defaultCodes": ["KeyA", "ArrowLeft"],  "codes": ["KeyA", "ArrowLeft"] },
    { "action": "right", "label": "Move right", "defaultCodes": ["KeyD", "ArrowRight"], "codes": ["KeyD", "ArrowRight"] },
    { "action": "jump",  "label": "Jump",       "defaultCodes": ["Space", "KeyW"],      "codes": ["Space", "KeyW"] },
    { "action": "fire",  "label": "Fire",       "defaultCodes": ["KeyJ"],               "codes": ["KeyJ"] },
    { "action": "pause", "label": "Pause",      "defaultCodes": ["Escape"],             "codes": ["Escape"] }
  ]
}

Tindakan yang hilang berarti barisnya tidak valid; bandingkan dengan aturan di atas. A 404 berarti tidak ada yang selamat, atau build yang menyatakannya belum dipublikasikan.

4. Gunakan mereka dalam game Anda

codes adalah pengikatan efektif pemain: penggantiannya jika disetel, jika tidak, default Anda. Buat pencarian darinya dan cocokkan event.code:

const auth = { Authorization: `Bearer ${launchToken}` };

// Your built-in defaults, in the same shape the API returns.
const DEFAULT_ACTIONS = [
  { action: "left", label: "Move left", codes: ["KeyA", "ArrowLeft"] },
  { action: "jump", label: "Jump", codes: ["Space", "KeyW"] },
  /* ... */
];

function toControls(actions) {
  const byCode = new Map();
  for (const a of actions) for (const code of a.codes) byCode.set(code, a.action);
  return { actions, byCode };
}

async function loadControls(slug) {
  try {
    const res = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
    if (res.ok) return toControls((await res.json()).actions);
  } catch { /* offline: fall through */ }
  return toControls(DEFAULT_ACTIONS);                   // 404, error, or outside StarHermit
}

let controls = await loadControls(gameScope);

window.addEventListener("keydown", (e) => {
  const action = controls.byCode.get(e.code);   // e.code, never e.key
  if (action) { e.preventDefault(); onAction(action, true); }
});
window.addEventListener("keyup", (e) => {
  const action = controls.byCode.get(e.code);
  if (action) onAction(action, false);
});

Default bawaan membuat game dapat dimainkan secara offline, di luar StarHermit, atau jika kontrolnya permintaan gagal. Jaga agar mereka sejalan dengan Anda control.* garis.

Layar yang mengikat ulang. Daftar actions dengan mereka label. Simpan peta override yang lengkap, atau membaca dan mempertahankan peta efektif saat ini sebelum mengubah satu tindakan:

async function saveBinding(slug, action, codes) {
  const current = await fetch(`/api/v1/games/${slug}/controls`, { headers: auth });
  if (!current.ok) throw new Error(`Controls read failed: ${current.status}`);
  const bindings = Object.fromEntries((await current.json()).actions.map(a => [a.action, a.codes]));
  bindings[action] = codes;
  const res = await fetch(`/api/v1/games/${slug}/controls`, {
    method: "PUT",
    headers: { ...auth, "Content-Type": "application/json" },
    body: JSON.stringify({ bindings }),
  });
  if (!res.ok) throw new Error((await res.json()).error);   // e.g. a key already in use
  return res.json();                                         // the new effective map
}

PUT mengganti penggantian pemain dengan tindakan yang Anda kirim, jadi sertakan setiap tindakan pemain telah berubah, bukan hanya yang terbaru. Sisanya tetap pada default Anda. DELETE di jalur yang sama mengatur ulang semuanya ke default.

Buat serial perubahan dari layar Anda; dua pembacaan/penulisan secara bersamaan masih dapat saling menimpa. SDK browser setControl() membuat serial perubahannya sendiri dan mempertahankan peta efektif saat ini. Mengirimkan peta efektif menyematkan nilai-nilai tersebut sebagai penggantian; menggunakan DELETE untuk kembali ke default manifes.

Platform menolak penyimpanan (400) yang akan menyisakan satu kunci pada dua tindakan setelah milik pemain perubahan digabungkan dengan default Anda. Misalnya mengikat jump ke KeyJ ketika fire masih menggunakan defaultnya KeyJ ditolak. Tunjukkan kesalahannya, atau pindahkan tindakan yang bertentangan ke dalamnya simpan.

Pemecahan masalah

Tanggapan Menyebabkan Memperbaiki
404 "Game ini menyatakan tidak ada kontrol." Tidak valid control.* garis di diterbitkan membangun. Tambahkan baris ke starhermit.txt, periksa mereka aturan, Dan menerbitkan bangunan baru.
404 "Tidak ada permainan dengan siput itu." Siputnya salah, atau gamenya tidak ada siputnya. Gunakan token peluncuran game_scope atau gameSlug dari GET /me/github-games. Setiap game yang ditambahkan dari folder lokal dan setiap game repositori yang ditambahkan oleh pemilik terverifikasi memiliki slug, hanya browser atau tidak. Hanya penyerahan repositori yang pemiliknya tidak terverifikasi tidak memilikinya; mengklaimnya untuk mendapatkannya.
403 "Token ini tercakup dalam permainan '…'." Token peluncuran yang digunakan dengan slug game lain. Panggil dengan siput di token game_scope.
400 "Tindakan tidak diketahui '…' — tidak dinyatakan dalam manifes game." PUT menamai suatu tindakan yang tidak dideklarasikan oleh manifes. Menggunakan action nilai dari GET …/controls.
400 "'…' terikat pada '…' dan '…'." Setelah digabungkan dengan default Anda, satu kunci akan memicu dua tindakan. Pindahkan tindakan lainnya ke dalam hal yang sama PUT, atau pilih kunci lain.
400 "'…' bukan nilai KeyboardEvent.code yang valid." Kode dengan spasi atau tanda baca. Mengirim event.code nilai-nilai.
400 "Tindakan '…' harus mengikat 1–4 kode." Daftar kosong, atau lebih dari empat. Kirim 1–4 kode; DELETE untuk mengatur ulang.
Ada tindakan yang hilang dari respons Barisnya tidak valid: huruf besar atau - dalam nama tindakan, , alih-alih +, lebih dari 4 kode, satu kode sudah digunakan, atau melewati tindakan ke-32. Perbaiki baris tersebut dan publikasikan lagi.
Ikatan tidak pernah menyala Kode diterima tetapi tidak ada kunci yang menghasilkannya, misalnya a atau space. Gunakan tepat KeyboardEvent.code ejaan: KeyA, Space.
