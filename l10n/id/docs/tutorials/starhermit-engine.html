Tutorial: membuat game dengan mesin StarHermit

Itu Mesin StarHermit adalah cara yang disarankan untuk membuat game untuk dipublikasikan di StarHermit. Anda membuat game satu kali, dan paket yang sama secara otomatis dapat dimainkan di browser dan secara asli di semua platform yang didukung oleh mesin. Permainan asli menawarkan kinerja dan fitur tambahan. Ketersediaan bergantung pada rilis mesin: 1.0.0 saat ini hanya memiliki runtime Windows; peramban dukungan datang dalam rilis selanjutnya (lihat Publikasikan itu).

Mesin StarHermit bekerja permainan skrip: keseluruhan permainan yang ditulis dalam TypeScript (atau JavaScript) dan dimainkan oleh satu mesin bawaan yang dapat dieksekusi, runtime StarHermit, tanpa mengkompilasi kode asli apa pun. Anda menulis logika permainan berdasarkan modul bawaan mesin — adegan 3D, masukan, HUD, audio, penyimpanan dan platform StarHermit — dan runtime melakukan sisanya: windowing, rendering pada GPU, suara, menu opsi, masuk dan bermain online. Pemain mendapatkan permainan melalui Klien Windows StarHermit, yang memasang mesin yang diminta oleh game Anda dan memainkannya secara asli.

Tutorial ini dibuat Penangkap Bintang, permainan kecil di mana Anda mengarahkan keranjang untuk menangkap jatuh bintang, dan membawanya dari folder kosong ke game yang diterbitkan:

1. Apa itu permainan skrip

Permainan skrip adalah folder (a kemasan) dengan a starhermit.txt di itu root, modul TypeScript Anda, dan aset Anda. Tiga engine.* baris dalam manifes menjadikannya satu:

engine.api=1
engine.entry=src/main.ts
engine.version=1.0.0

engine.api adalah versi utama dari API host yang digunakan untuk menulis kode Anda, engine.entry itu modul runtime dimulai, dan engine.version rilis mesin yang tepat untuk game tersebut dan diuji untuk. Rilis dipublikasikan di wiki ini di bawah Rilis engine; itu game tidak pernah berisi mesin itu sendiri, jadi unggahan hanya menampung file Anda sendiri.

Runtime memperlakukan setiap game sebagai tidak tepercaya: kode Anda hanya mencapai mesin melalui API host (file paketnya sendiri, penyimpanannya sendiri, platform untuk id gamenya sendiri), tidak pernah file, proses, koneksi jaringan sewenang-wenang atau kredensial pemain. Sebagai imbalannya, game tidak dapat menghentikan runtime atau gantung jendela: panggilan yang berjalan selama tiga detik menampilkan runtime-nya sendiri "tidak merespons" layar, dan kesalahan yang tidak tertangkap mengakhiri permainan pada layar kesalahan tempat pemain dapat memulai ulang.

2. Dapatkan mesinnya

Pemain tidak melakukan apa pun: ketika mereka menekan Mainkan pada permainan skrip, klien Windows StarHermit mengunduh rilis pin game (sekali, dibagikan oleh setiap game yang menyematkannya), memeriksa setiap file terhadap hash rilis yang dipublikasikan dan memulainya.

Pengembang unduh runtime rilis dari area mesin:

  • starhermit-1.0.0-windows-x86_64.zip (Windows 10 atau 11, 64-bit), 6,7 MB.

Arsip menampung satu folder, starhermit-1.0.0-windows-x86_64, dengan starhermit.exe, itu release.json yang memberi tahu runtime rilis mana itu, LICENSE-engine dan pihak ketiga pemberitahuan. Ini adalah mesin yang sama yang dipasang klien. Ukurannya dan SHA-256 tercantum di bawah downloads dalam rilis native.json; untuk periksa salinan Anda di PowerShell, bandingkan itu sha256 dengan:

Get-FileHash .\starhermit-1.0.0-windows-x86_64.zip -Algorithm SHA256

Buka paket arsip dan buka terminal di folder yang belum dibongkar:

.\starhermit.exe --version

starhermit 0.1.0 (host API 1.4, launcher 1; engine release 1.0.0)

Perintah di bawah ini ditulis sebagai starhermit; jalankan sebagai .\starhermit.exe dari folder itu, atau tambahkan folder ke Anda PATH.

3. Buat permainannya

starhermit new star-catcher --title "Star Catcher"

Created Star Catcher in star-catcher: a script game pinned to engine 1.0.0
Play it: starhermit star-catcher
Check it: starhermit check star-catcher
For a native upload (the StarHermit client plays it): starhermit package --native star-catcher

Folder baru ini berisi titik awal yang dapat dimainkan — sebuah kubus yang melompat ketika Anda menekan Spasi:

star-catcher/
  starhermit.txt             the manifest, pinned to the runtime's own release (engine.version=1.0.0)
  tsconfig.json              TypeScript settings for checking the game
  src/main.ts                the entry module
  .starhermit/starhermit.d.ts  the host API's declarations, for your editor and the type checker

.starhermit/ dimulai dengan sebuah titik, jadi itu tidak pernah menjadi bagian dari paket. starhermit types star-catcher tulis deklarasinya lagi, misalnya setelah Anda pindah ke yang lebih baru waktu proses. Setiap modul, anggota, unit, batasan, dan kesalahan API host didokumentasikan dalam file itu.

Runtime tidak memeriksa tipe: ia menghapus tipe TypeScript saat memuat setiap modul. Periksa mereka diri Anda sendiri dengan TypeScript 5 atau lebih baru; dengan Node.js terinstal, npx menjalankannya tanpa menginstal apa pun di folder game:

cd star-catcher
npx --package typescript tsc -p .

Menyimpan node_modules dan perkakas lainnya keluar dari folder permainan: semua yang ada di folder kecuali nama titik adalah bagian dari paket dan setiap unggahan.

4. Tulis versi pertama

Ganti yang dihasilkan starhermit.txt dengan manifes permainan:

name=Star Catcher
description=Catch the falling stars before the time runs out.
launch=play.html
engine.api=1
engine.entry=src/main.ts
engine.version=1.0.0
engine.capabilities=platform,storage
control.left=KeyA+ArrowLeft | Move left
control.right=KeyD+ArrowRight | Move right
control.start=Space+Enter | Start a round
engine.gamepad.left=LeftStickLeft+DpadLeft
engine.gamepad.right=LeftStickRight+DpadRight
engine.gamepad.start=South
cache..=0

Itu control.* baris mendeklarasikan tindakan game dengan kunci defaultnya (kunci platform kontrol format) dan engine.gamepad.* default gamepad mereka. Pemain melakukan rebind mereka di menu Opsi runtime, sehingga permainan terbaca tindakan, tidak pernah kunci. engine.capabilities menanyakan apa yang digunakan game selain menggambar dan memasukkan: platform untuk pemain yang masuk dan online fitur, storage untuk data yang disimpan di perangkat dan akun pemain. launch=play.html dan halaman itu nama ikut berperan ketika Anda menerbitkan.

Lalu ganti src/main.ts:

// Star Catcher: catch the falling stars in the basket before the time runs out.
import { frame, onFixedUpdate, onRender, onStart, setFixedRate } from "starhermit:engine";
import {
  AmbientLight,
  BoxGeometry,
  Color,
  DirectionalLight,
  Mesh,
  MeshStandardMaterial,
  PerspectiveCamera,
  SphereGeometry,
  renderer,
  scene,
} from "starhermit:scene";
import { onAction, value } from "starhermit:input";
import { storage } from "starhermit:storage";
import { player } from "starhermit:platform";
import * as draw from "starhermit:draw";

// -- The scene ----------------------------------------------------------------
const camera = new PerspectiveCamera(50, 16 / 9, 0.1, 100);
camera.position.set(0, 4, 12);
camera.lookAt(0, 3, 0);
renderer.camera = camera;
scene.background = new Color(0x0b1020);

const sun = new DirectionalLight(0xfff4e0, 1.2);
sun.position.set(3, 8, 5);
scene.add(sun, sun.target, new AmbientLight(0x6070a0, 0.5));

const basket = new Mesh(new BoxGeometry(2, 0.4, 1), new MeshStandardMaterial({ color: 0x4fa3ff, roughness: 0.4 }));
scene.add(basket);

const starGeometry = new SphereGeometry(0.3, 16, 12);
const starMaterial = new MeshStandardMaterial({ color: 0xffd34d, emissive: 0xffb000, emissiveIntensity: 0.6 });
const stars = Array.from({ length: 3 }, () => {
  const mesh = new Mesh(starGeometry, starMaterial);
  scene.add(mesh);
  return { mesh, x: 0, y: 0, previousY: 0, speed: 0 };
});
type Star = (typeof stars)[number];

// -- The rules ----------------------------------------------------------------
const WIDTH = 6; // the basket moves between -WIDTH and WIDTH
const ROUND = 60; // seconds a round lasts
let basketX = 0;
let previousX = 0;
let score = 0;
let timeLeft = 0; // 0 between rounds
const saved = storage.getJson("best");
let best = typeof saved === "number" ? saved : 0;

function drop(star: Star): void {
  star.x = (Math.random() * 2 - 1) * WIDTH;
  star.y = star.previousY = 8 + Math.random() * 4;
  star.speed = 2 + Math.random() * 2 + score * 0.05;
}

onStart(() => {
  setFixedRate(60);
  for (const star of stars) drop(star);
});

onAction((event) => {
  if (event.action === "start" && event.pressed && timeLeft === 0) {
    score = 0;
    timeLeft = ROUND;
    for (const star of stars) drop(star);
  }
});

onFixedUpdate((step) => {
  previousX = basketX;
  for (const star of stars) star.previousY = star.y;
  if (timeLeft === 0) return;
  // An action's value is 0 to 1, so a stick steers gently and a key fully.
  const steer = value("right") - value("left");
  basketX = Math.max(-WIDTH, Math.min(WIDTH, basketX + steer * 9 * step));
  for (const star of stars) {
    star.y -= star.speed * step;
    if (star.y < 0.6 && star.y > 0 && Math.abs(star.x - basketX) < 1.2) {
      score += 1;
      drop(star);
    } else if (star.y < -1) {
      drop(star);
    }
  }
  timeLeft = Math.max(0, timeLeft - step);
  if (timeLeft === 0 && score > best) {
    best = score;
    storage.setJson("best", best);
  }
});

// -- Drawing ------------------------------------------------------------------
onRender((alpha) => {
  // Between two fixed steps: draw where things are at this moment.
  basket.position.set(previousX + (basketX - previousX) * alpha, 0.2, 0);
  for (const star of stars) {
    star.mesh.position.set(star.x, star.previousY + (star.y - star.previousY) * alpha, 0);
  }
  hud();
});

function hud(): void {
  const { width, height, scale } = frame();
  const size = 22 * scale;
  const name = player()?.displayName ?? "Guest";
  draw.text(`${name}   score ${score}   best ${best}`, 16 * scale, 16 * scale, { size, color: "#e8ecf4" });
  if (timeLeft > 0) {
    draw.text(`${Math.ceil(timeLeft)} s`, width - 16 * scale, 16 * scale, { size, color: "#ffd34d", align: "end" });
  } else {
    draw.rect(0, height / 2 - 40 * scale, width, 80 * scale, [0, 0, 0, 0.5]);
    draw.text("Press Space to play", width / 2, height / 2 - 12 * scale, { size, color: "#ffffff", align: "center" });
  }
}

Apa yang dilakukan setiap bagian:

  • Adegan itu. starhermit:scene mengikuti three.js: kamera, lampu, jerat yang terbuat dari geometri dan sebuah bahan, scene.add. Jarak adalah meter, sudut radian, dan warna sRGB.
  • Aturannya. onFixedUpdate berjalan pada tingkat bunga tetap setFixedRate(60) meminta, 60 kali a kedua, berapa pun kecepatan bingkainya, sehingga permainan dimainkan sama di setiap mesin. value("right") adalah nilai aksinya dari 0 hingga 1, jadi stik gamepad akan bergerak dengan lembut dan kunci akan bergerak sepenuhnya, dan onAction mendengar setiap tekanan, di sini untuk memulai putaran.
  • Menggambar. onRender berjalan sekali per frame dengan alpha, seberapa jauh jarak frame antara dua frame terakhir langkah-langkah tetap; posisi yang ditarik di antaranya previous dan nilai saat ini bergerak dengan lancar pada penyegaran apa pun menilai. starhermit:draw menggambar HUD di atas pemandangan dalam piksel jendela; frame().scale mengkonversi piksel logis untuk tampilan DPI tinggi.
  • Skor terbaik tetap berada di perangkat pemain starhermit:storage, dipisah untuk setiap pemain.

5. Jalankan secara asli

starhermit check star-catcher

package=Directory files=3 bytes=4800 name="Star Catcher" api=1 entry=src/main.ts capabilities=platform,storage actions=left,right,start
runnable=true engine="TypeScript" frames=120 probes=0
PASS package src/main.ts: valid; 120 frames headless

check memvalidasi paket (manifest, jalur, ukuran) dan memutar 120 frame tanpa jendela, jadi a kesalahan sintaksis, impor yang tidak diketahui atau pengecualian saat start-up ditampilkan di sini dengan file, baris, dan kolomnya. Kemudian mainkan:

starhermit star-catcher

Tekan Spasi untuk memulai putaran dan tombol panah (atau A dan D, atau gamepad) untuk mengarahkan. F1 selalu membuka menu runtime sendiri: grafik, audio, kontrol (rebinding), akun, dan keluar. Anda game tidak dapat menggambar atau membacanya, dan tidak ada game yang dapat mengikat F1.

Sambil berkembang, tambahkan --dev (starhermit star-catcher --dev): runtime kemudian mencetak game tersebut console.log keluaran dan titik kesalahan pada baris TypeScript Anda.

6. Banyak hal sekaligus: starhermit:world

TypeScript game Anda berjalan di penerjemah skrip mesin itu sendiri, yang menyimpan setiap game di dalamnya anggaran waktu dan memorinya. Keputusan dan beberapa lusin objek memerlukan biaya yang kecil, namun per-entitas pekerjaan - memindahkan ribuan partikel, kerumunan, kawanan - berarti ribuan langkah yang ditafsirkan setiap bingkai. Untuk itu mesinnya punya starhermit:world:

  • tabel menyimpan data entitas dalam kolom yang diketik (angka dan vektor) di memori permainan;
  • kernel adalah fungsi biasa dari satu baris yang dikompilasi dan dijalankan secara asli oleh runtime setiap baris tabel, tanpa memasukkan skrip;
  • itu jadwal menjalankan kernel setiap frame, dan ikatan menggambar meja menjadi satu InstancedMesh (atau menggerakkan node adegan), menyusun setiap instance secara asli.

Skrip Anda membuat keputusan; runtime melakukan aritmatika per baris. Tambahkan langit malam 4.000 berkilauan berkilau di belakang permainan sebagai src/sky.ts:

// The night sky behind the game: 4,000 twinkling sparkles. Their data lives
// in a starhermit:world table, a kernel moves every one of them natively each
// frame, and an instance binding draws the table as one InstancedMesh, so the
// game's script runs no per-sparkle code at all.
import { InstancedMesh, MeshBasicMaterial, SphereGeometry, scene } from "starhermit:scene";
import { bind, kernel, schedule, table } from "starhermit:world";

const COUNT = 4_000;

// One row per sparkle: where it hangs, how it twinkles, and what the kernel
// writes each frame (its height and size).
const sky = table("sky", COUNT, {
  base: "vec3",
  phase: "f32",
  rate: "f32",
  y: "f32",
  size: "f32",
});
sky.spawn(COUNT);

// Filled once from script, through typed arrays over the table's memory.
const base = sky.column("base");
const phase = sky.column("phase");
const rate = sky.column("rate");
for (let i = 0; i < COUNT; i++) {
  base[i * 3] = (Math.random() * 2 - 1) * 40;
  base[i * 3 + 1] = Math.random() * 24 - 2;
  base[i * 3 + 2] = -10 - Math.random() * 30;
  phase[i] = Math.random() * Math.PI * 2;
  rate[i] = 0.5 + Math.random() * 2;
}

// An ordinary function of one row. The runtime compiles it and runs it over
// every live row without entering script.
const twinkle = kernel(sky, (r, u: { drift: number }, f) => {
  r.y = r.base.y + Math.sin(f.time * u.drift + r.phase) * 0.3;
  r.size = 0.04 + 0.04 * Math.abs(Math.sin(f.time * r.rate + r.phase));
});

const mesh = new InstancedMesh(new SphereGeometry(1, 6, 4), new MeshBasicMaterial({ color: 0xcfd8ff }), COUNT);
scene.add(mesh);

/** Starts the sky: the kernel runs after every onUpdate, and the binding
 * composes the mesh's instances from the columns after every onRender. */
export function startSky(): void {
  schedule.update(twinkle, { drift: 0.4 });
  bind.instances(mesh, sky, { position: ["base.x", "y", "base.z"], scale: "size" });
}

dan memulainya dari src/main.ts: mengimpornya dengan impor lainnya, dan memanggilnya onStart:

import { startSky } from "./sky.js";

onStart(() => {
  setFixedRate(60);
  startSky();
  for (const star of stars) drop(star);
});

Nama-nama impor ./sky.js, konvensi TypeScript untuk modul yang ditulis sebagai sky.ts; waktu proses menyelesaikannya dengan cara yang sama. Kernel menerima subset dari bahasa — angka dan boolean, aritmatika, Math, if, dibatasi for loop, kolom baris dan seragam yang Anda lewati — dan runtime menolak apa pun dengan a SyntaxError di baris kernel saat mengkompilasinya, bukan menjalankannya perlahan. Deklarasi dari starhermit:world jelaskan subset, antrian acara itu kernel memancarkan, tabel dengan riwayat untuk gerakan langkah tetap yang mulus, dan pengikatan simpul.

7. Pemain, simpanan dan permainan online

Pemain. player() dari starhermit:platform adalah pemain yang masuk, atau null untuk a tamu; Star Catcher menunjukkan nama mereka di HUD-nya. Saat klien Windows StarHermit memulai permainan Anda, pemain masuk dari frame pertama, dengan akun klien: klien menyerahkan runtime token peluncuran untuk game Anda melalui saluran pribadi, memperbaruinya saat game berjalan, dan game tidak pernah melihatnya (tidak ada panggilan host yang mengembalikan token, kunci, atau cookie). Pemain tidak pernah masuk ke dalam a permainan; masuk dan keluar terjadi di klien.

Pembangunan berjalan. Dimulai dari terminal, sebuah paket tidak dapat mengklaim identitas platform dengan sendirinya, jadi starhermit star-catcher bermain sebagai tamu. Setelah game Anda diterbitkan, pengembangan diluncurkan beri nama:

starhermit star-catcher --game <your game's id>

dan Anda masuk melalui F1 → Akun…, dialog runtime itu sendiri (kunci di komputer ini dan satu konfirmasi melalui email, seperti pada orientasi kunci publik). Penyimpanan, pengaturan, simpan dan mainkan online lalu ikuti game dan akun itu.

Simpan dan pengaturan. starhermit:storage memiliki tiga toko, semuanya bersifat pribadi untuk game Anda: storage (data kunci/nilai pada perangkat, seperti yang digunakan Star Catcher), settings (opsi permainan, disimpan di akun pemain di bawah platform pengaturan per pemain), Dan saves (yang penyimpanan game, di perangkat, dan di pemain slot penyimpanan awan dengan konflik penanganan).

Bermain daring. Semua yang ditawarkan platform game ada di dalamnya starhermit:platform untuk permainanmu id sendiri: teman dan kehadiran, undangan, ruangan waktu nyata, perjodohan, itu soket permainan (connectGame), papan peringkat, pencapaian, tayangan ulang, obrolan, dan suara. Untuk multipemain otoritatif server, deklarasikan a naskah permainan:

server=server.js

Platform menjalankannya sebagai otoritas untuk sesi game Anda; starhermit:script's authority("server.js", …) menjalankan file yang sama pada pekerja lokal untuk latihan offline, persis seperti itu platform melakukannya, jadi permainan offline dan online berbagi satu jalur kode. Skor papan peringkat, prestasi dan hasil pertandingan hanya ditulis oleh skrip server, tidak pernah ditulis oleh game itu sendiri; membuat papan seperti yang dijelaskan dalam papan peringkat dan prestasi.

8. Publikasikan

Game skrip yang diterbitkan adalah game StarHermit biasa yang filenya adalah paket Anda. Pemain menemukan itu di perpustakaan mereka; klien Windows StarHermit menginstalnya dengan mesin yang disematkannya dan memutarnya secara asli.

Halaman untuk browser. Platform ini menghosting setiap game yang diunggah di alamatnya sendiri dan memerlukan sebuah halaman di sana untuk membuka. Sampai game Anda memiliki versi browser, halaman biasa yang menyatakan tempat memainkannya sudah cukup; Nama manifes Star Catcher play.html:

<!doctype html>
<html lang="en">
<meta charset="utf-8">
<title>Star Catcher</title>
<p>Star Catcher runs in the StarHermit Windows client: find it in your library and press Play.</p>
</html>

Gunakan nama selain index.html: versi browser yang lebih baru akan menulis sendiri index.html.

Indeks berkas. Klien menginstal dan memperbarui game yang diunggah berdasarkan indeks filenya, starhermit-files.json: setiap file dengan ukurannya dan SHA-256. Tuliskan setelah setiap perubahan pada game, sebagai langkah terakhir sebelum mengupload:

starhermit package --native star-catcher

Native upload: star-catcher (6 files, 7553 bytes to upload; the platform takes at most 50 MiB)
Wrote star-catcher\starhermit-files.json for engine 1.0.0: the StarHermit client installs the game by it
Not checked against versions.json (read offline): https://wiki.starhermit.com/engine/versions.json says whether 1.0.0 is still current

Ia memeriksa paket terhadap aturan pengunggahan platform (no api/ atau ws/ folder, paling banyak 9.998 jalur dan 50 MiB) dan lepaskan pin game Anda, yang harus dipublikasikan dengan Windows runtime dan tidak dicabut. Runtime memeriksa rilisnya sendiri secara offline; --versions menyebutkan salinannya versions.json untuk memeriksa terhadap yang lain.

Unggah itu. Folder tersebut adalah unggahannya, persis seperti apa adanya: klien memeriksa setiap file terhadap indeks, jadi unggah file folder tanpa perubahan, dengan jumlah yang sama starhermit.txt keduanya di dalam folder dan di akar bundel (platform menerbitkan salinan akar di tempat folder). Seperti di Tambahkan game dari folder lokal:

mkdir -p bundle/client
cp -R star-catcher/. bundle/client/
rm -rf bundle/client/.starhermit
cp star-catcher/starhermit.txt bundle/starhermit.txt
tar -C bundle -czf star-catcher.tar.gz .

curl --fail-with-body -X POST https://api.starhermit.com/api/v1/me/github-games/upload \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H 'Content-Type: application/gzip' \
  --data-binary @star-catcher.tar.gz

ACCESS_TOKEN adalah token akses akun Anda (lihat unggahan yang dibuat dari CI/CD untuk masuk tanpa browser). Jawabannya adalah game.id adalah id game Anda, dan game tersebut langsung ditayangkan https://<id>.starhermit.com/. Untuk setiap versi selanjutnya, tulis kembali indeksnya dan dorong jenis yang sama dari bundel ke permainan dengan POST /api/v1/me/github-games/{id}/bundle; klien pemain kemudian hanya mengunduh file yang hashnya diubah. A server= naskah di folder tersebut mendapatkan backend game tersebut saat unggahan dipublikasikan.

Dari repositori. Sebuah permainan diterbitkan dari GitHub bekerja dengan cara yang sama: melakukan starhermit.txt dengan itu engine.* baris di root repositori. Klien menginstal dan memperbarui permainan repositori dengan git, hanya mengambil apa yang ditambahkan setiap komit, sehingga tidak memerlukan indeks file.

Di browser. starhermit package --web menulis unggahan browser game: filenya, halaman pemuat yang memuat rilis mesin yang disematkan dari wiki ini dengan hash, dan indeks filenya. Ini perlu pelepasan dengan waktu proses web; 1.0.0 hanya untuk Windows, jadi pembuatan browser dimulai dengan rilis yang lebih baru, dan package --web mengatakan demikian sampai saat itu. Di platform, halaman permainan skrip hanya dapat menjalankan halaman resmi mesin dari wiki ini (lihat Rilis engine).

9. Pindah ke mesin yang lebih baru

Sebuah game berjalan persis pada rilis yang disematkannya: tidak ada yang mengupgradenya di belakang Anda, dan diterbitkan rilis tidak pernah berubah. Untuk pindah ke yang lebih baru, unduh runtime-nya, jalankan game Anda dan periksa di atasnya, lalu sematkan ulang dengan cara menggantinya engine.version di dalam starhermit.txt, tulis lagi indeks file dan mempublikasikan. Klien pemain mengunduh mesin baru satu kali (hanya yang berubah dari rilis yang sudah mereka rilis tahan) dan file game Anda diubah.

Versi utama rilis ini adalah API host: engine.api=1 game bergerak bebas dalam 1.x.x. Sebuah permainan yang memerlukan anggota API host yang ditambahkan dalam versi minor dapat mengatakannya engine.minor=N; seorang yang lebih tua runtime kemudian menolaknya dengan pesan alih-alih gagal nanti.

Rilisan yang ditemukan tidak aman adalah dicabut: versions.json menandainya dengan alasannya, klien menolak untuk menginstal atau memulainya (dan memberi tahu pemain alasannya), dan kemasannya perintah menolaknya setiap kali mereka membaca version.json. Pelepasan yang dicabut selalu diikuti dengan pelepasan yang tetap; sematkan ulang ke sana dan publikasikan.

10. Batasan dan izin

Runtime menjaga setiap game sesuai anggaran, yang mungkin akan menurunkan anggaran paket engine.limits.* tapi never raise: waktu skrip 32 ms untuk setiap panggilan balik (panggilan balik yang menggunakannya akan dijeda dan berlanjut pada frame berikutnya; setelah tiga detik runtime-nya "tidak merespons" layar memungkinkan pemain menunggu atau menghentikan permainan), tumpukan skrip 256 MiB, penyimpanan 64 MiB, paling banyak 512 MiB dan 65.536 file dalam satu paket dan, untuk unggahan, jalur platform 50 MiB dan 9.998. Melewati batas dimana suatu operasi bisa gagal (alokasi, panggilan host) melempar a RangeError; kehabisan tumpukan atau panggilan kedalaman mengakhiri permainan di layar kesalahan. Deklarasi API host mencantumkan setiap batasan.
