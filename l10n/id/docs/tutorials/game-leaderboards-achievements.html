Tutorial: papan peringkat dan pencapaian untuk game Anda

Jika Anda memiliki game di StarHermit, Anda adalah penerbitnya. Anda bisa memberikannya papan peringkat (skor tinggi, lari tercepat, pukulan terpanjang) dan prestasi tanpa akun penerbit atau akun khusus apa pun izin. Hanya dibutuhkan kepemilikan atas game ini.

Ada satu aturan di balik semua yang ada di halaman ini: Anda mendefinisikannya, tulis server game Anda mereka. Klien pemain tidak pernah dapat memposting skor atau mengklaim pencapaian untuk hal ini, dan server Anda harus memvalidasi gameplay yang menghasilkan skor tersebut. Menolak pengiriman API langsung sendiri tidak menghentikan klien yang dimodifikasi untuk menciptakan event game. Itulah sebabnya game ini membutuhkan backend yang otoritatif: a server= naskah atau a container.image= di dalam starhermit.txt.

Tutorial ini dibuat untuk game arcade kecil, Kolektor Bintang: lari berakhir ketika pemain crash, dan memiliki total poin dan waktu berjalan.

Sebelum Anda mulai

Anda membutuhkan:

  • Sebuah game dengan backend server yang Anda miliki: yang Anda tambahkan dari repositori Anda sendiri, unggah sebagai folder, atau diklaim. Jawaban permainan khusus browser 409 untuk setiap panggilan di bawah, dengan pesan yang menyatakan alasannya.
  • Token akses pengguna penuh, bukan token peluncuran game. Token peluncuran dipagari ke dalam game permukaan pemain dan tidak dapat menjangkau /me/....
  • ID permainan Anda (itu juga miliknya <id>.starhermit.com alamat):
ACCESS_TOKEN='your-full-user-access-token'
API=https://api.starhermit.com

curl -s "$API/api/v1/me/github-games" -H "Authorization: Bearer $ACCESS_TOKEN" |
  jq '.[] | {id, displayName, gameSlug}'

GAME_ID='the-id-from-above'

gameSlug adalah apa yang klien Anda sebut sebagai permainan /api/v1/games/{slug}/.... Setiap game yang Anda tambahkan atau yang diunggah memiliki satu, game khusus browser yang disertakan, sehingga tidak memberi tahu Anda apakah ada server: GET /api/v1/games/{slug} tidak - itu menjawab 404 sampai game memiliki backend.

1. Buat papan peringkat

Star Collector mendapat dua papan: poin terbanyak (lebih tinggi lebih baik) dan lari tercepat hingga 100 poin (lebih rendah lebih baik).

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/leaderboards" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "high-score", "name": "High score",
        "scoreType": "integer", "sortDirection": "desc",
        "minScore": 0, "maxScore": 1000000 }'

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/leaderboards" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "fastest-100", "name": "Fastest to 100",
        "scoreType": "time-ms", "sortDirection": "asc" }'

Setiap panggilan kembali 201 dan dewan, termasuk dewannya id Dan key. Server Anda menggunakan kunci, jadi pilihlah dengan hati-hati. Kuncinya, scoreType Dan sortDirection tidak dapat diubah nanti.

scoreType Menerima
integer bilangan bulat
decimal nomor berapa pun
time-ms keseluruhan, milidetik non-negatif

Mengatur minScore/maxScore dengan apa yang sebenarnya dapat dihasilkan oleh game Anda. Skor di luar mereka dijatuhkan, yang merupakan pelindung murah terhadap bug di logika server Anda sendiri.

2. Ciptakan prestasi

Anda dapat memberikan pencapaian game dengan dua cara, dan Anda dapat menggunakan keduanya sekaligus:

Dideklarasikan dalam kode Dibuat melalui API
Di mana game.achievements dalam skrip Anda, atau /describe dalam wadah Anda POST /me/github-games/{id}/achievements
Diubah oleh menerbitkan pembaruan panggilan API, yang segera berlaku
Bagus untuk pencapaian yang dibangun oleh kode Anda menambahkan atau menulis ulang beberapa tanpa rilis

Kedua jenis tersebut dibuka dengan cara yang sama, oleh server Anda yang mengembalikan kuncinya. Di sini kita membuat dua tembus APInya:

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "century", "name": "Century",
        "description": "Collect 100 stars in one run.", "points": 10 }'

curl -s -X POST "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "key": "untouchable", "name": "Untouchable",
        "description": "Reach 500 points without losing a shield.",
        "points": 50, "secret": true }'

A secret pencapaian tetap tersembunyi dari pemain sampai mereka membukanya.

Untuk melihat semua yang dimiliki game, termasuk pencapaian yang diumumkan kode Anda, cantumkan pencapaian tersebut:

curl -s "$API/api/v1/me/github-games/$GAME_ID/achievements" \
  -H "Authorization: Bearer $ACCESS_TOKEN" | jq '.[] | {key, origin, unlocks}'

origin adalah declared untuk pencapaian dari kode Anda dan owner atas pencapaian yang Anda buat di sini. Anda hanya dapat mengedit dan menghapus owner yang. A declared yang satu akan dikembalikan oleh yang berikutnya perbarui, jadi API menolak (409) dan Anda mengubahnya dalam kode.

3. Posting skor dan buka pencapaian dari skrip Anda

Skrip Anda melaporkan kedua jenis hasil dalam nilai kembaliannya. Ia dapat melakukan ini dari kait apa pun: createSession, onPlayerMessage atau onTick.

  • scores: kunci papan → id pemain → nomor.
  • achievements: id pemain → kunci untuk membuka kunci.
'use strict';

function endRun(ctx, s, playerId) {
  var run = s.runs[playerId];
  var scores = { "high-score": {} };
  scores["high-score"][playerId] = run.points;
  if (run.reached100At) {
    scores["fastest-100"] = {};
    scores["fastest-100"][playerId] = run.reached100At - run.startedAt;
  }

  var unlocked = [];
  if (run.stars >= 100) unlocked.push("century");
  if (run.points >= 500 && !run.lostShield) unlocked.push("untouchable");
  var achievements = {};
  achievements[playerId] = unlocked;

  run.over = true;
  return {
    ok: true,
    sessionState: s,
    scores: scores,
    achievements: achievements,
    broadcast: [{ to: [playerId], data: { type: "run-over", points: run.points } }]
  };
}

globalThis.game = {
  tickRateHz: 10,

  createSession(ctx) {
    var runs = {};
    ctx.players.forEach(function (p) {
      runs[p.id] = { points: 0, stars: 0, lostShield: false, startedAt: ctx.now,
                     reached100At: null, over: false };
    });
    return { ok: true, sessionState: { runs: runs } };
  },

  onPlayerMessage(ctx) {
    var s = ctx.sessionState;
    var from = ctx.message.from;
    var run = s.runs[from];
    var msg = ctx.message.data || {};
    if (!run || run.over) return { ok: false, error: "No run in progress" };

    // The client reports what happened; the script decides what it is worth.
    if (msg.type === "collect") {
      run.stars += 1;
      run.points += 5;
      if (run.points >= 100 && !run.reached100At) run.reached100At = ctx.now;
      return { ok: true, sessionState: s };
    }
    if (msg.type === "shield-lost") {
      run.lostShield = true;
      return { ok: true, sessionState: s };
    }
    if (msg.type === "crash") return endRun(ctx, s, from);
    return { ok: false, error: "Unknown command" };
  },

  onTick(ctx) { return { ok: true }; }
};

Hal-hal yang Anda lakukan bukan perlu menangani:

  • Skor yang lebih buruk. Setiap pemain menyimpan skor terbaiknya di setiap papan, dinilai oleh dewan sortDirection. Laporkan setiap proses dan platform akan menyimpan yang terbaik.
  • Ulangi pembukaan kunci. Membuka kunci sesuatu yang sudah dimiliki pemain tidak akan menghasilkan apa-apa, jadi kembalikan kuncinya kapanpun kondisinya bertahan.
  • ID orang lain. Mencetak skor dan membuka kunci untuk orang-orang yang tidak berada dalam sesi tersebut, termasuk AI kursi, diabaikan.

Kunci yang tidak diketahui, papan yang tidak aktif, dan skor di luar jangkauan akan dijatuhkan secara diam-diam. Skrip Anda mendapat no kesalahan bagi mereka, jadi periksa papan Anda sekali, seperti pada bagian 4.

Game sebenarnya seharusnya membuat server menentukan poin dan waktu dari status otoritatifnya sendiri, bukan kepercayaan collect pesan sebagaimana adanya. Contoh ini dibuat singkat untuk menunjukkan pelaporan. Skrip Permainan memiliki kontrak bentuk pengembalian penuh.

3b. Hal yang sama dari sebuah wadah

Sebuah game container mengirimkan dua hal yang sama pada kontrolnya WebSocket:

{ "type": "scores", "sessionId": "…",
  "scores": { "high-score": { "<userId>": 740 }, "fastest-100": { "<userId>": 41250 } } }

{ "type": "achievements", "sessionId": "…",
  "unlocks": { "<userId>": ["century"] } }

scores juga dapat disertakan dalam amplop respons apa pun yang menjadi asal pengembalian kontainer Anda /sessions. Itu aturan yang sama berlaku: hanya peserta, skor terbaik disimpan, kunci yang tidak diketahui diabaikan. Melihat Server Game Kontainer.

4. Tunjukkan pada game Anda

Klien Anda membaca semuanya dengan token peluncuran yang sudah dimilikinya. Tidak ada apa pun di sini yang membutuhkan token pemilik.

Temukan papannya.

const boards = await api(`/api/v1/games/${slug}/leaderboards`);
// [{ id, key: "high-score", name: "High score", sortDirection: "desc", ... }, ...]
const high = boards.find(b => b.key === "high-score");

Hanya papan aktif yang terdaftar.

Membaca papan.

const page = await api(`/api/v1/leaderboards/${high.id}/entries?page=1&pageSize=10`);
// { items: [{ rank, username, score, ... }], total, page, pageSize }
const friends = await api(`/api/v1/leaderboards/${high.id}/entries?friendsOnly=true&pageSize=10`);

Untuk a time-ms papan, format skor sebagai waktu: 41250 → 0:41.25.

Prestasi.

  • GET /api/v1/games/{slug}/achievements mencantumkan setiap pencapaian dengan milik pemain unlocked negara. Rahasia tetap tersembunyi sampai diperoleh.
  • Pembukaannya sendiri akan berlangsung secara langsung ws/v1/games sebagai {"type":"achievement","data":{key,name,description,points,...}}. Bersulanglah saat itu terjadi. Panggilan daftar saat memuat menangkap apa pun yang tidak terkunci saat soket ditutup.

Melihat Prestasi untuk bingkai.

5. Jagalah mereka

Ganti nama papan atau ubah batasnya.

curl -s -X PUT "$API/api/v1/me/github-games/$GAME_ID/leaderboards/$BOARD_ID" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{ "name": "All-time high score", "maxScore": 2000000 }'

Batasan baru hanya berlaku untuk skor baru.

Pensiunkan dewan tetapi pertahankan skornya. Mengirim { "isActive": false }. Dewan berhenti menerima mencetak gol dan menghilang dari daftar permainan. Entrinya masih bisa dibaca oleh id.

Atur ulang sesuai jadwal. Berikan papan "resetSchedule": "daily", "weekly" atau "monthly" (pada buat, atau nanti dengan PUT) dan dimulai pada pukul 00:00 UTC setiap periode — cocok untuk a "ini minggu terbaik" papan di samping papan sepanjang masa. Tidak ada yang perlu dilakukan dalam skrip Anda: laporkan skor seperti biasa, dan skor pertama setiap pemain pada periode baru dihitung. Melihat Atur ulang jadwal.

Mulailah musim baru dengan tangan. Untuk musim yang hanya satu kali saja, bukan jadwal, buatlah papan baru (high-score-s2), arahkan skrip Anda ke sana, dan pensiunkan yang lama.

Hapus papan. DELETE .../leaderboards/{id} menghapus papan dan semua entrinya, dan tidak dapat dibatalkan.

Edit pencapaian. PUT .../achievements/{achievementId} dengan salah satu dari name, description, icon, secret Dan points. Kuncinya tidak pernah berubah.

Hapus pencapaian. Ini hanya berfungsi untuk yang Anda buat yang belum dibuka oleh siapa pun. Prestasi yang diperoleh bersifat permanen.

Pindahkan pencapaian ke dalam kode. Deklarasikan kunci yang sama game.achievements dan mempublikasikan. Itu deklarasi mengambil alih pencapaian yang ada, dan pemain yang memilikinya mempertahankannya.

Tanggapan Arti
404 Game tersebut bukan milik Anda, atau papan atau pencapaiannya bukan miliknya
409 "…bagian belakang server…" Permainan tidak memiliki server= atau container.image=
409 "sudah memiliki…" Kuncinya diambil, oleh dewan atau oleh prestasi yang dinyatakan atau diciptakan
409 "dideklarasikan oleh server game" Ubah pencapaian itu dalam kode Anda
409 "sudah terbuka" Pemain menahannya, jadi tidak bisa dihapus
400 Kunci dengan karakter lain, nama yang hilang, atau minScore > maxScore

Batasan: 2048 papan peringkat dan 200 pencapaian yang dibuat per game, ditambah hingga 100 pencapaian yang diumumkan.

Daftar periksa

  • [ ] Permainan ini memiliki server= naskah atau container.image=, Dan gameSlug sudah diatur GET /me/github-games.
  • [ ] Setiap papan memiliki kunci stabil dan kanan scoreType Dan sortDirection (mereka tidak dapat mengubahnya nanti).
  • [ ] Server kembali scores Dan achievements (skrip) atau mengirimkan pesan kontrol (wadah), dikerjakan dari keadaan otoritatif.
  • [ ] Klien menemukan papan dengan GET /games/{slug}/leaderboards, tidak pernah melakukan hard-code id mereka, dan membaca entri berdasarkan id.
  • [ ] Klien memuat GET /games/{slug}/achievements dan bersulang di achievement bingkai.
  • [ ] Papan lama sudah tidak digunakan lagi isActive: false daripada dihapus, kecuali Anda benar-benar ingin skornya hilang.
