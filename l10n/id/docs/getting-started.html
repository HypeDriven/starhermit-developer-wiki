Memulai

Pertapa Bintang adalah platform distribusi game dan perangkat lunak dengan lapisan sosial bawaan, yang diekspos melalui REST dan WebSockets. Halaman ini memberi Anda gambaran umum: apa yang dilakukan platform, di mana platform mendengarkan, cara kerja autentikasi dan pembuatan versi, serta dua cara game Anda dapat berintegrasi dengannya.

Untuk game browser pertama Anda, unduh dan publikasikan mulai cepat. Untuk arsitektur lain, memilih integrasi, lalu periksa kredensial, konvensi API, Dan ketersediaan fitur. Menggunakan pemecahan masalah ketika panggilan gagal.

Apa yang disediakan StarHermit

  • Pengguna & otentikasi — pendaftaran kunci publik (tanpa kata sandi) dan proses masuk OAuth melalui penyedia mana pun yang kredensial penerapannya; melihat Otentikasi.
  • Profil & kehadiran — profil pengguna, avatar, pengaturan privasi, hak, dan detak jantung kehadiran; melihat Profil.
  • Teman-teman — permintaan pertemanan dan status pertemanan; melihat Teman-teman.
  • Obrolan teks — percakapan dan pesan; melihat Mengobrol.
  • Suara waktu nyata — ruang suara; melihat Suara.
  • Penerbit — akun penerbit yang memiliki entri katalog; melihat Penerbit.
  • Katalog perangkat lunak — judul perangkat lunak dengan build dan aset yang dapat diunduh; melihat Katalog.
  • Hak — hibah perangkat lunak katalog per pengguna (bagian dari Profil).
  • Prestasi & papan peringkat — pencapaian otoritatif server untuk game dengan skrip atau backend container, ditambah pencapaian yang diklaim klien untuk judul katalog; melihat Prestasi Dan Papan peringkat.
  • Relai rekan — fan-out byte buram terikat pertandingan dengan otorisasi daftar dan batas nilai yang berasal dari nilai tick game; melihat Menyampaikan.
  • Ruangan waktu nyata — lobi, perjodohan, pemain AI dan pengisian ulang, serta transportasi waktu nyata untuk game bertempo cepat; juga dapat menjembatani ke sesi skrip yang terikat ruangan untuk permainan otoritatif server; melihat Ruangan Waktu Nyata.
  • Permainan resmi — Game yang dihosting platform yang aturannya dijalankan sebagai JavaScript dalam kotak pasir Skrip Permainan atau a Server Permainan Kontainer; klien menggunakan yang dibagikan API Permainan.

URL dan port dasar

  • API REST Publik: https://api.starhermit.com, di bawah api/v1/....
  • Soket Web Publik: wss://api.starhermit.com/ws/v1/....
  • Game yang dipublikasikan di platform disajikan di https://<slug>.starhermit.com dengan /api Dan /ws tersedia dengan asal yang sama, jadi game yang dihosting platform harus menggunakan jalur relatif.

Pembuatan versi

Semua rute REST memiliki versi: api/v1/.... Rute WebSocket ada di bawah ws/v1/... dan bersifat netral terhadap versi.

Cara yang disarankan untuk memasuki game yang dihosting

Game yang dihosting di StarHermit disarankan untuk menawarkan dua opsi yang jelas di layar awalnya:

  1. Masuk dengan akun StarHermit yang ada — biarkan pemain menggunakan akun mereka untuk menyimpan kemajuan dan fitur platform yang didukung, seperti pencapaian dan papan peringkat. Gunakan alur masuk game yang dihosting ketika tidak ada token peluncuran yang valid; pemain yang datang dengan token yang valid dapat langsung melanjutkan.
  2. Mainkan pemain tunggal tanpa masuk — menawarkan versi pemain tunggal mandiri yang tidak memerlukan akun dan tidak melacak atau menyimpan kemajuan. Simpan kemajuan dalam memori untuk sesi bermain saat ini, tanpa menulis penyimpanan cloud, penyimpanan lokal terus-menerus, pencapaian, atau skor papan peringkat.

Beri label opsi kedua dengan jelas, misalnya Mainkan pemain tunggal (kemajuan tidak disimpan), sehingga pemain memahami apa yang diharapkan sebelum memulai. Mode ini harus berjalan tanpa panggilan atau soket StarHermit API yang diautentikasi.

Model autentikasi (ikhtisar)

  • Token akses adalah JWT dengan masa pakai 15 menit; token penyegaran berputar dan bertahan 7 hari. Melihat Otentikasi untuk format token dan titik akhir penyegaran/keluar.
  • Kirim token akses sebagai a Authorization: Bearer <token> header pada setiap permintaan yang diautentikasi. Untuk /ws/** jalur saja, kredensial juga diterima sebagai ?ticket= (tiket koneksi satu kali dari POST /api/v1/realtime/connection-tickets) atau sebagai ?access_token= (masih didukung). Browser tidak dapat menyetel header pada jabat tangan WebSocket.
  • Game juga digunakan token peluncuran cakupan game — JWT berumur pendek yang dicetak per game yang memagari pemanggil ke permukaan API game tersebut. Melihat Otentikasi Dan Pertandingan.

Game yang dihosting yang dibuka langsung di browser dapat menawarkan a Tombol masuk. Starhermit menangani proses masuk atau pembuatan akun dan mengembalikan token cakupan game langsung ke game.

Sebelum memanggil titik akhir yang dilindungi atau membuka soket, sebuah akun harus menerima persyaratan saat ini. Menggunakan GET /api/v1/me untuk memeriksa termsAcceptanceRequired, tampilkan dokumen dari GET /api/v1/terms, dan mengirimkan hashnya hanya setelah pengguna menerimanya. A 403 dengan error: "terms_acceptance_required" berarti Anda harus menampilkan dokumen saat ini dan menawarkan yang eksplisit Terima tindakan. Sesi akun dan token peluncuran pemain dapat mengirimkan penerimaan; token server tidak bisa. Menyegarkan token tidak mencatat penerimaan.

Dua cara untuk mengintegrasikan game Anda

  1. Game yang dihosting platform. Anda menerbitkan game dari repo GitHub dengan a starhermit.txt manifes — atau, jika tidak ada di repositori, unggah folder secara langsung dan lewati git sepenuhnya. Ini mungkin hanya browser, gunakan kotak pasir server.js, atau arahkan ke gambar kontainer yang disematkan intisari untuk logika server. Platform menyajikan permainan di <slug>.starhermit.com dengan /api Dan /ws diproksikan asal yang sama. Jalur skrip didemonstrasikan secara end-to-end oleh implementasi referensi catur di https://github.com/HypeDriven/starhermit-chess. Melihat Permainan GitHub, Skrip Permainan, Server Game Kontainer, dan itu Panduan Integrasi.
  2. Klien game eksternal. Klien Anda sendiri memanggil REST dan WebSocket API secara langsung, menggunakan autentikasi JWT dan, jika sesuai, token peluncuran game. Halaman referensi API di bawah mendokumentasikan permukaannya. Di Unity, itu SDK Persatuan sudah mengimplementasikan permukaan tersebut sebagai klien C# yang diketik — termasuk aturan penyegaran token, percobaan ulang, dan penyambungan ulang soket — untuk pembuatan desktop, seluler, WebGL, konsol, dan server tanpa kepala.

Kedua rute ke dalam game yang dihosting platform melewati satu file kecil: lihat Itu starhermit.txt tampak untuk formatnya, di mana ia harus diletakkan, dan mengapa folder yang Anda unggah harus merupakan bangunan yang dapat didistribusikan, bukan pohon sumber Anda.

Jam server — GET /api/v1/time

Tenggat waktu yang diberikan platform kepada Anda (ringkasan sesi deadline, sebuah naskah ctx.now) berada di server jam, sehingga klien yang membuat hitungan mundur terhadap jamnya sendiri akan melayang. Ini titik akhir sengaja dibuat anonim — sinkronisasi harus berfungsi sebelum login — dan secara eksplisit diizinkan token peluncuran dalam cakupan game, sehingga game yang dihosting dapat memanggilnya sambil dipagari ke permukaannya sendiri.

{
  "serverTime": 1785060842000,
  "serverTimeIso": "2026-07-25T09:14:02+00:00",
  "clientTime": 1785060841200,
  "skew": 800
}

clientTime (unix ms, opsional) digaungkan kembali tanpa disentuh sehingga respons dapat dicocokkan dengan responsnya permintaan; skew adalah yang naif serverTime - clientTime untuk klien yang tidak ingin pulang pergi matematika. Untuk perkiraan sebenarnya, lakukan dengan gaya NTP: bagi dua perjalanan pulang pergi dan hitung offset = serverTime + rtt/2 - now.

Perilaku lintas sektoral

  • Header keamanan ditetapkan pada semua tanggapan.
  • Pembatasan tarif — pesan obrolan dibatasi hingga 10 pesan per menit per pengguna; titik akhir lainnya mungkin menghasilkan 429 seperti yang didokumentasikan per halaman.
  • Kesalahan selalu dikembalikan sebagai {"error":"..."} dengan kode status standar (400/401/403/404/409/422/429). Masing-masing halaman mencatat kasus kesalahan spesifik titik akhir saja.
