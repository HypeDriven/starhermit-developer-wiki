Memecahkan masalah integrasi

Mulailah dengan status HTTP, titik akhir, dan kelompok kredensial. Reproduksi permintaan terkecil menggunakan ID game dan kredensial yang sama, lalu periksa status sumber daya saat ini. Simpan token dan pemain menyimpan data dari log dan laporan dukungan.

Masuk dan akses

Gejala Memeriksa Tindakan selanjutnya
401 pada REST Kedaluwarsa token dan apakah itu akun atau token peluncuran Refresh sesi akun satu kali; perbarui token peluncuran yang masih valid atau masuk untuk peluncuran baru
403 terms_acceptance_required Dokumen terkini dari /api/v1/terms Tampilkan dan terima hashnya hanya pada tindakan pemain; token peluncuran akun dan pemain berfungsi
403 dicakup ke game lain game_scope versus permainan/ruangan/penyimpanan yang diminta Gunakan UUID game Anda sendiri dan persisnya game:<gameId> kunci penyimpanan cloud
403 pada /me/game-invites dari sebuah permainan Token peluncuran tidak dapat membaca kotak masuk seluruh akun Pemilihan /games/{slug}/invites Dan /realtime/rooms/invites
403 oauth_session_required Tindakan ini mengubah kredensial akun Masuk melalui penyedia langsung; sesi kunci publik hanya dapat mencabut kuncinya sendiri
403 untuk akun yang ditangguhkan Pesan yang dikembalikan Hentikan percobaan masuk/penyegaran ulang otomatis; arahkan pemain ke dukungan akun
Pengembalian masuk langsung 400 returnUrl harus HTTPS persis di tempat asal game tersebut Gunakan URL game yang dihosting; URL pengembangan lokal bukan tujuan pengembalian yang diizinkan
Proses masuk gagal sewaktu-waktu Invalid signature. Tantangan serialisasi, khususnya + dalam sekejap Gunakan yang tepat byte penandatanganan kunci publik
Pendaftaran kembali 429 Tunjangan pendaftaran email/IP Menghormati Retry-After; konfirmasi email sebelum mengirim pendaftaran lain

Pengaturan dan penyimpanan game

Gejala Memeriksa Tindakan selanjutnya
/games/{slug} kembali 404, tapi pengaturannya berfungsi Apakah game memiliki backend skrip atau container? Game khusus browser memiliki pengaturan dan token peluncuran tetapi tidak memiliki info game/sesi yang resmi
Kontrol kembali 404 Sah control.* baris dalam manifes yang dipublikasikan Publikasikan deklarasi; menulis tidak dapat membuat tindakan yang tidak dideklarasikan
Mengikat ulang satu kunci akan menyetel ulang kunci lainnya Kontrol PUT menggantikan semua penggantian Kirim peta penggantian lengkap, atau gunakan SDK setControl() yang mempertahankan peta efektif
Pengaturan menghilang setelahnya PUT Koleksi PUT menggantikan seluruh peta Menggunakan PATCH untuk kunci tingkat atas yang diubah; objek bersarang diganti sebagai satu nilai
Penyimpanan cloud pemain baru kembali 404 Belum ada penyimpanan untuk slot itu Mulailah dari awal hanya untuk hasil ini; kegagalan lainnya harus memblokir unggahan
Simpan pengembalian tulis 412 Perangkat lain menulis versi baru Muat ulang, validasi, dan gabungkan/adopsi sebelum penulisan bersyarat lainnya
Simpan pengembalian 413, 409, atau 507 Simpan ukuran, jumlah slot, atau kuota akun Periksa yang dikembalikan code Dan limit; mengurangi ukuran atau menyelesaikan kapasitas
Batas waktu tidak ada dalam daftar sesi summary.deadline jenis Mengembalikan stempel waktu Unix bilangan bulat dalam milidetik, bukan string ISO
Skor/prestasi tidak muncul Kunci, definisi aktif, peserta, batasan nilai Verifikasi definisi dan keluaran server; penulisan yang tidak valid diabaikan; laporan klien bukanlah bukti
Perjodohan kembali 404 setelah pertandingan Sesi yang cocok mungkin telah berakhir Kembali ke lobi dan mulai pencarian baru alih-alih membuka kembali tiket lama

soket web

Pembaruan browser yang gagal biasanya muncul sebagai kode penutup 1006, menyembunyikan respons HTTP. Sebelum mencoba lagi, lakukan panggilan REST ke game/sesi/ruangan yang sama untuk membedakan otentikasi, persyaratan, keanggotaan, sesi selesai, dan kegagalan memulai server sementara. Periksa kompatibilitas build melalui info game saat Anda menyediakan ?build=. Dapatkan tiket koneksi baru untuk setiap peningkatan.

Tutup/hasil Arti Tindakan
1000 Tutup biasa Berhenti kecuali pemutar secara eksplisit memulai koneksi lain
1001 ditambah kesalahan resume Dunia belum bisa dilanjutkan Hubungkan kembali dengan backoff setelah memeriksa status sesi
1006 Kehilangan jaringan atau peningkatan yang ditolak Periksa status REST dan kredensial saat ini; percobaan ulang terikat
1008 Pelanggaran kebijakan atau koneksi yang digantikan Hentikan sambungan ulang otomatis; menawarkan penyambungan kembali yang disengaja setelah memperbaiki penyebabnya
1009 Pesan terlalu besar Kurangi ukuran bingkai sebelum menyambungkannya kembali
HTTP 409 build_mismatch Ketidakcocokan build klien/server Muat ulang build yang kompatibel; jangan menciptakan nilai build yang cocok
HTTP 410 session_not_active Sesi selesai Kembali ke lobi atau memutar ulang; berhenti menyambung kembali
error: "Too many commands; slow down." Tunjangan perintah tahan lama skrip Kecepatan perintah diskrit; masukkan input berkelanjutan ke dalam data dengan type: "input", realtime: true

Minta status permainan penuh setelah tersambung kembali; jangan memutar ulang gerakan atau gerakan non-idempoten lainnya secara membabi buta perintah. resumed berarti membuang prediksi dan menyinkronkan ulang. abandoned adalah terminal. Melihat Kontrak WebSocket.

Penerbitan dan startup kontainer

Gejala Memeriksa Tindakan selanjutnya
Mengunggah 413 dengan limitBytes Tunjangan upload/hosting yang efektif Kurangi bundel atau pohon gabungan yang dihasilkan
Unggahan HTTP besar 413 tanpa bidang kesalahan platform Batas isi permintaan sebelum API Menggunakan ws/v1/game-upload; mengirim complete setelah semua byte
Mengunggah 422 Tata letak arsip, peluncuran file, keamanan jalur, manifes Perbaiki kesalahan bernama; API mengharapkan mentah .tar.gz, bukan multi-bagian
Pengunggahan berhasil tetapi server tidak tersedia Kesiapan penempatan Penyebaran jajak pendapat; byte yang diterima tidak berarti penampung sudah siap
Permulaan ruang kontainer kembali bersifat sementara 503 Server mungkin bangun Pertahankan lobi dan coba lagi dengan kemunduran; jangan kembali ke simulasi klien
Permintaan kontainer gagal dalam validasi kunci pemanggilan Lingkungan startup dan perbandingan header yang tepat Baca kunci pemanggilan yang disuntikkan saat ini; laporkan kegagalan terus-menerus dengan ID game dan log yang dibersihkan
Kegagalan penerapan yang terus-menerus Status penerapan dan log/kerusakan yang terlihat oleh pemilik Perbaiki build atau konfigurasi dan publikasikan rilis baru yang berfungsi

Untuk laporan dukungan yang berguna, sertakan ID game, versi klien/build, titik akhir dan metode, status/kode, perkiraan waktu UTC, langkah reproduksi, dan log sanitasi yang relevan. ID sesi/ruangan membantu menemukan lokasi sumber daya. Jangan melampirkan kredensial, kunci pribadi, atau penyimpanan penuh pemain tanpa persetujuan mereka.
