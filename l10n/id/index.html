Wiki Pengembang StarHermit

Dokumentasi untuk API publik Pertapa Bintang — permainan/perangkat lunak distribusi + platform sosial: pengguna & OAuth autentikasi, teman, obrolan teks, suara waktu nyata, penerbit, katalog perangkat lunak dengan build/aset, hak, pencapaian, papan peringkat, relay rekan, dan game multipemain resmi server yang aturannya dijalankan di a file JavaScript sandbox atau wadah yang disediakan pengembang. Wiki ini adalah integrasi umum panduan untuk setiap game yang menargetkan platform.

Contoh referensi yang digunakan di seluruh wiki ini adalah HypeDriven/catur pertapa bintang — sebuah permainan catur korespondensi (situs statis tanpa pembuatan + satu file aturan JS sisi server) yang menggunakan peluncuran token, perjodohan elo, undangan teman, gameplay WebSocket, obrolan dalam game, suara, papan peringkat, dan tayangan ulang — dapat dimainkan langsung di 83fd04b1-3cbe-4b09-a251-3733ad4b9d94.starhermit.com (alamat game adalah uid yang ditetapkan platformnya, bukan namanya). Ini adalah salah satu implementasi nyata dari pola yang dijelaskan di sini, bukan subjek dokumen.

Di mana untuk memulai

  • Mulai cepat peramban — unduh game lengkap dengan proses masuk akun, penerimaan persyaratan eksplisit, penyimpanan cloud yang aman, dan permainan pemain tunggal yang tidak terlacak.

  • Pilih integrasi — bandingkan game khusus browser, ruangan yang dirutekan host, skrip, wadah, dan judul katalog.

  • Kredensial dan pengidentifikasi — token mana yang dapat memanggil API mana, dan perbedaan ID game, pengguna, sesi, ruang, dan peserta.

  • konvensi API — penguraian respons/kesalahan, unit stempel waktu, penomoran halaman, pembaruan semantik, dan percobaan ulang.

  • Pemecahan masalah — mendiagnosis proses masuk, cakupan, penyimpanan konflik, soket, unggahan, dan permulaan kontainer.

  • Siklus hidup sesi dan pemulihan — jeda/lanjutkan, putuskan sambungan versus keluar, batas snapshot, dan masa berlaku pemulihan.

  • Ketersediaan dan kepercayaan — API yang tersedia, opsional, pratinjau, dan dipesan; apa yang membuat suatu skor dapat dipercaya.

  • Kontrak REST dan WebSocket — OpenAPI yang dapat diunduh, skema bingkai JSON, dan tata letak biner.

  • Sinkronisasi penyimpanan cloud yang aman — pembantu pemuatan/validasi/penulisan bersyarat yang lengkap dengan penanganan konflik.

  • Itu starhermit.txt tampak — satu file untuk setiap game yang diterbitkan kebutuhannya, di mana letaknya di folder yang Anda unggah, dan mengapa folder itu harus menjadi milik Anda build yang dapat didistribusikan: semua yang ada di samping manifes diunggah dan disajikan kepada pemain. Juga mencakup masa pakai cache aset dan asal CORS tambahan.

  • Memulai — URL dasar, pembuatan versi, model autentikasi, dan cara untuk mengintegrasikan (permainan platform yang diterbitkan dari GitHub atau diunggah sebagai folder, dengan skrip opsional atau server kontainer, atau klien eksternal yang memanggil REST/WS API secara langsung).

  • Tutorial: panduan integrasi end-to-end (menggunakan contoh referensi catur) — siklus hidup penuh dari token peluncuran hingga penampil pemutaran ulang, dengan panggilan persis ke klien game buat, diilustrasikan dengan implementasi referensi catur.

  • Tutorial: gunakan AI untuk memasukkan StarHermit ke dalam game Anda — perintah yang dapat disalin dan ditempel untuk asisten pengkodean AI, satu per fitur dan semuanya mega-cepat.

  • Tutorial: publikasikan server khusus dan pemain onboard dalam game — mendorong bundel kontainer, memperbarui token servernya, dan menggunakan registrasi kunci publik untuk melakukan onboarding Pemain Steam/Epic/GOG/asli tanpa OAuth atau kunjungan dasbor StarHermit.

  • Tutorial: pemain onboard dengan kunci publik — buat dan masuk ke akun StarHermit dengan kunci yang dihasilkan game di perangkat pemain dan satu lagi konfirmasi melalui email: format kunci, byte yang tepat untuk ditandatangani, menunggu konfirmasi, sesi, perangkat kedua dan kunci yang hilang, dan apa yang tidak dapat dilakukan oleh akun yang hanya memiliki kunci.

  • Tutorial: mengunggah build dari CI/CD — daftarkan yang berdedikasi penerapan kunci publik dari sesi OAuth, autentikasi non-interaktif, dan publikasikan klien atau container dibuat dari GitHub Actions (termasuk unggahan besar melalui WebSockets).

  • Tutorial: membangun pembalap kart multipemain — delapan kart pembalap di ruang waktu nyata: lobi, gabung cepat, driver CPU, kode net biner yang dirutekan host di dalam batas kecepatan soket, migrasi host, dan varian skrip 30 Hz resmi server untuk permainan peringkat, dengan prediksi dan rekonsiliasi sisi klien.

  • Tutorial: sesi persisten — permainan yang dijeda saat semua orang keluar — sertakan skrip atau game kontainer ke dalam sesi yang dijeda alih-alih diakhiri, pertahankan jam game tetap berjalan dengan ctx.pausedMs, dan bergabung kembali dengan dunia yang dijeda dari klien.

  • Tutorial: papan peringkat dan pencapaian untuk game Anda — sebagai pemilik game, Anda adalah penerbitnya: buat papan dan pencapaian dengan skor tinggi dan waktu melalui API, poskan skor dan buka pencapaian dari skrip atau wadah Anda, dan tampilkan mereka di klien Anda.

  • Tutorial: pilihan grafis dengan kualitas terdeteksi otomatis — mampir graphics-options.js: preset kualitas dipilih dari 0–20 tingkat perangkat keras (Galaxy S20 hingga RTX 5090), penggantian per efek, resolusi adaptif, kecepatan setengah penyegaran aktif ponsel, opsi FPS maksimum manual, panel opsi, dan pengaturan itu ikuti pemain per GPU melalui StarHermit; ditransfer ke penyaji three.js.

  • Tutorial: opsi audio dengan batas suara yang terdeteksi otomatis — kontrol volume dasar dan obrolan suara, rekomendasi konkurensi Otomatis yang sadar perangkat dan CPU, dan batasan kebijakan pemutaran; termasuk bebas ketergantungan audio-options.js pembantu.

  • Tutorial: lokalkan game Anda dan tambahkan pengaturan bahasa — sepuluh bahasa yang sama dengan wiki, label asli, dan bendera SVG, serta bagian Bahasa di sampingnya Grafik/Audio/Kontrol, teks kanan ke kiri, paket terjemahan, dan sinkronisasi preferensi per pemain.

  • Tutorial: tambahkan kontrol ke game Anda — nyatakan dapat di-rebindable tindakan keyboard di starhermit.txt, publikasikan, baca binding pemain dengan token peluncuran, buat layar rebinding, dan perbaiki "This game declares no controls.".

  • Tutorial: klaim game yang ditambahkan orang lain — membuktikan kontrol repositori, mengambil alih daftar yang ada, dan mengelola hosting dan penerapannya.

SDK Klien

Jika Anda membangun mesin dengan SDK yang dikelola, mulailah dari sana, bukan dengan HTTP mentah — the API yang sama, dengan aturan penyegaran token, percobaan ulang, penyambungan kembali, dan redaksi sudah diterapkan.

Platform Halaman Kemasan
Persatuan SDK Persatuan com.starhermit.sdk — mengetik klien untuk REST API v1 dan keenam protokol WebSocket
Peramban (JavaScript) SDK JavaScript starhermit-sdk.js — satu file bebas ketergantungan yang mencakup permukaan token peluncuran: masuk, penyimpanan cloud, pengaturan, kontrol, undangan, perjodohan, soket gameplay, dan pencapaian/papan peringkat hanya-baca

Referensi API

Konvensi yang dimiliki oleh semua titik akhir: REST di bawah api/v1/... pada https://api.starhermit.com, WebSockets di bawah ws/v1/..., autentikasi pembawa JWT (?access_token= diperbolehkan menyala /ws/**), kasus unta JSON; konvensi respons dan kesalahan.

Catatan

  • Ketersediaan fitur relay, suara, dan realtime room mungkin berbeda-beda.

Validasi perubahan

Situs ini tidak memiliki pembuatan aplikasi. Untuk dokumentasi dan contoh pemeriksaan, gunakan Node.js 22 atau yang lebih baru, Python 3, dan npm ci, Kemudian npm test. npm run test:browser tambahan membutuhkan Chrome/Chromium (CHROME_PATH dapat memilih yang dapat dieksekusi).

Setelah mengedit pembantu mulai cepat, jalankan python3 scripts/build-quickstart.py untuk menyegarkan contoh dan ZIP. Untuk memperbarui indeks operasi REST dari checkout sumber yang cocok, jalankan python3 scripts/build-contracts.py /path/to/platform-checkout, tinjau perbedaan kontrak, dan jalankan kembali tes. Penggantian respons dipertahankan di scripts/rest-contract-overrides.json.
